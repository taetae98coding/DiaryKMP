# 필터 Bottom Sheet 디자인

기준 스펙: [태그 필터 스펙](../spec/tag-filter.md), [MemoHome 목록 스펙](../spec/memo-home.md), [CalendarHome 화면 스펙](../spec/calendar-home.md), [TagHome 목록 스펙](../spec/tag-home.md), [TagDetail 화면 스펙](../spec/tag-detail.md)

이 문서는 화면에서 필터를 여는 버튼의 표현과 필터 Bottom Sheet의 공통 구조, 닫는 조작, 적응형 배치를 소유한다.

Bottom Sheet 안에 어떤 필터를 어떤 순서로 담는지, 각 필터의 표현과 조작, 무엇을 적용된 상태로 보는지, 화면에 보이는 정확한 문구는 각 화면 디자인이 소유한다.

## 필터 아이콘 버튼

필터 아이콘 버튼은 상단 바 액션의 가장 끝에 배치하고, 아이콘만 표시하며 라벨은 표시하지 않는다. 아이콘에는 위가 넓고 아래가 좁은 깔때기 모양의 필터 아이콘을 사용한다. 같은 아이콘을 [목록 빈 상태 디자인](./list-empty-state.md)의 좁힌 빈 상태에도 쓴다.

필터가 적용되지 않았으면 기본 상단 바 아이콘 색을 사용한다. 필터가 적용되었으면 아이콘을 주요 색으로 표시해 필터가 적용되었음을 알린다. 어떤 필터가 적용되었는지는 아이콘으로 구분하지 않고 배지나 숫자도 표시하지 않는다.

무엇을 적용된 상태로 볼지는 화면이 담은 필터에 따라 다르므로 각 화면 디자인이 소유한다.

목록이 비어 있어도, 필터를 적용해 두었어도 버튼은 같은 모양과 같은 자리에 표시하며 비활성 표현을 사용하지 않는다.

접근성에서는 버튼에 필터를 여는 동작임을 알리는 이름을 두고, 필터가 적용된 동안에는 적용되었음을 알리는 상태 설명을 함께 제공한다.

## Bottom Sheet 표시

필터 아이콘 버튼을 누르면 현재 화면 위에 필터 Bottom Sheet를 표시한다. 아래에 있던 화면은 닫거나 교체하지 않고 어둡게 처리한 배경 아래에 그대로 유지하며, 공통 내비게이션도 계속 표시한다. 목록과 상세를 함께 표시하는 배치에서는 두 영역을 모두 아래에 유지한다.

Bottom Sheet 상단에는 드래그 핸들을 표시하고, 그 아래에 제목을 배치한다. 별도 닫기 버튼은 표시하지 않는다.

제목이나 필터 영역 소제목과 같은 줄의 오른쪽 끝에는 그 영역의 선택을 되돌리는 동작 버튼을 둘 수 있다. 어떤 줄에 어떤 버튼을 두는지는 각 필터의 디자인이 정한다.

제목만 Bottom Sheet 위쪽에 고정하고, 필터 내용은 하나의 세로 스크롤 영역에 둔다. 내용이 표시 영역보다 길면 제목 영역은 유지하고 내용만 스크롤한다.

필터 내용의 좌우는 제목 영역과 맞춘다.

## 닫는 조작

사용자는 Bottom Sheet 바깥 영역, 뒤로가기 또는 아래 방향 드래그로 Bottom Sheet를 닫을 수 있다.

필터를 바꾸어도 Bottom Sheet는 열린 상태를 유지해 여러 필터를 이어서 바꿀 수 있게 한다. 바뀐 결과는 Bottom Sheet 아래에 그대로 보이는 화면에 즉시 반영된다.

키보드나 포인터를 사용하는 환경에서는 Bottom Sheet 안의 조작 요소에 차례로 초점을 이동할 수 있고, `Enter` 또는 `Space`로 조작하며 `Escape`로 닫을 수 있다.

## 적응형 배치

좁은 창에서는 Bottom Sheet가 창 아래쪽 너비를 사용하고, 내용이 길면 시스템 상태 영역을 침범하지 않는 범위까지 높아진다.

넓은 창에서는 Material 기본 최대 너비 안에서 Bottom Sheet를 창 가운데에 배치해 과도하게 넓어지지 않게 한다.

창 크기와 관계없이 Bottom Sheet 내용은 시스템 내비게이션 영역과 디스플레이 컷아웃에 가려지지 않게 표시한다.
