# RoutineFinishedList 목록·상세 배치 디자인

기준 스펙: [RoutineFinishedList 목록·상세 배치 스펙](../spec/client/routine-finished-list-detail.md)

배치, 크기 조절, 버튼 노출, 선택 전 상세와 조절 상태 표시의 공통 표현은 [목록·상세 배치 공통 디자인](./list-detail-pane.md)을 따른다.

## 두 영역에 두는 화면

목록 영역에는 [RoutineFinishedList 화면 디자인](./routine-finished-list.md)의 완료된 루틴 목록을, 상세 영역에는 선택한 루틴의 [RoutineDetail 화면](./routine-detail.md)을 표시한다. RoutineHome의 루틴 목록과 달력은 이 배치의 어느 영역에도 표시하지 않는다.

목록 영역이 좁아져도 완료된 루틴 목록은 1열을 유지하고 카드가 함께 좁아진다.

상세 영역의 RoutineDetail 화면에서 연 태그의 상세와 추가 화면은 이 배치에 두지 않고 단독으로 표시한다.

각 상태에서 사용할 화면과 뒤로가기 결과, 공통 내비게이션 제공 여부는 기준 스펙과 각 화면 스펙을 따른다.

## 선택 전 상세

아직 루틴을 선택하지 않았으면 상세 영역에 루틴을 나타내는 아이콘과 루틴을 선택하라는 안내를 표시한다. 아이콘은 [목록 빈 상태 디자인](./list-empty-state.md)이 RoutineHome 목록 보기의 루틴 목록에 쓰는 루틴 아이콘과 같은 것을 쓴다.

[Routine 목록·상세 배치 디자인](./routine-list-detail.md)과 달리 선택 전 상세에 RoutineAdd 화면을 두지 않는다.

## 버튼 노출

목록의 상단 바에는 뒤로가기 버튼을 계속 표시하고, 누르면 RoutineHome의 목록 보기로 돌아간다.

이 화면에는 떠 있는 루틴 추가 버튼이 없으므로 상세 영역에 RoutineAdd 화면이 나타나지 않고, 루틴 추가 단축키도 처리하지 않는다.

## 상세 영역이 닫히는 표시

상세 영역의 RoutineDetail 화면에서 루틴 삭제에 성공하거나 시스템 뒤로가기를 사용하면 목록을 그대로 두고 상세 영역만 선택 전 상세로 바꾼다.

상세 영역의 RoutineDetail 화면에서 루틴을 다시 시작하면 그 카드는 목록에서 사라지지만 상세 영역은 같은 RoutineDetail 화면을 계속 표시한다. 그 상세에서 다시 완료하면 카드가 목록 순서에 맞는 자리에 다시 나타난다.

상세 영역에서 기록을 넣거나 빼도 목록의 카드 문구는 `완료` 그대로 둔다. 제목이나 컬러, 시작 날짜를 고치면 목록의 그 카드가 바뀐 제목과 컬러로, 순서에 맞는 자리에 표시되며, 카드가 자리를 옮기는 표현은 [RoutineHome 화면 디자인](./routine-home.md)의 `카드 조작`을 따른다.
