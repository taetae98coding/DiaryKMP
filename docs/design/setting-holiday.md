# SettingHoliday 화면 디자인

기준 스펙: [SettingHoliday 화면 스펙](../spec/setting-holiday.md)

## 화면 구조

SettingHoliday의 단독·목록/상세 배치와 표시 상태에 따른 뒤로가기 동작 노출은 [Setting 목록·상세 배치 디자인](./setting-list-detail.md)을 따른다.

화면 상단에는 검색어 입력을 담은 상단 바를 두고, 뒤로가기 동작을 제공하는 상태에서는 상단 바의 시작 쪽에 함께 배치한다. 상단 바에는 별도의 화면 제목을 두지 않는다. 제목 자리를 검색어 입력이 차지하며, 무엇을 검색하는 자리인지는 입력의 자리 표시 문구가 알린다.

본문에는 공휴일 항목을 세로 목록으로만 배치한다. 목록이 표시 영역보다 길면 위아래로 스크롤할 수 있고, 스크롤해도 상단 바는 화면 위쪽에 그대로 남는다.

본문 오른쪽 아래에는 일괄 선택 동작 버튼을 목록 위에 겹쳐 띄운다.

## 검색어 입력

상단 바의 시작 쪽에는 뒤로가기 동작을 제공하는 상태에서만 뒤로가기 버튼을 두고, 그 옆의 남은 폭 전체를 검색어 입력이 차지한다.

검색어 입력의 해부구조, 조작, 접근성 문구는 [검색 입력 디자인](./search-input.md)을 따른다. 검색어 입력은 접거나 펼치지 않고 언제나 활성 상태로 놓이며, 필터링된 공휴일 목록은 본문의 같은 자리에 그대로 표시한다.

검색어가 비어 있으면 무엇을 검색하는 자리인지 알리는 안내 문구를 자리 표시 문구로 두고, 검색어가 있으면 그 검색어를 그대로 보여 준다.

이 화면의 기본 흐름은 목록에서 항목을 고르는 것이므로 화면이 열릴 때 검색어 입력에 초점을 두지 않고 소프트 키보드도 열지 않는다. 사용자가 입력을 누르면 초점이 옮겨 가고 소프트 키보드가 열린다.

## 표시 영역과 소프트 키보드

소프트 키보드가 열리면 본문만 키보드 위 영역으로 줄어들고, 상단 바는 자리를 옮기지 않는다. 공휴일 목록, 검색 결과 없음 안내와 일괄 선택 동작 버튼은 줄어든 본문 안에서 같은 기준으로 놓이므로, 마지막 항목과 동작 버튼이 키보드에 가리지 않는다. 키보드가 닫히면 본문이 원래 높이로 되돌아간다.

화면은 상태 표시 영역, 시스템 탐색 영역과 카메라 컷아웃 등 기기가 가리는 영역을 침범하지 않게 배치한다.

## 공휴일 목록

공휴일 목록은 검색어 입력 아래 본문에 놓인다. 검색어가 있으면 같은 자리에 필터링된 목록을 표시하며, 항목 표현과 항목 사이 [항목 간격](./dimens.md)은 검색어가 있는지와 관계없이 같다.

목록의 좌우에는 [화면 가로 여백](./dimens.md)을 둔다. 마지막 항목이 일괄 선택 동작 버튼에 가리지 않도록 목록 내용 아래쪽에 `88dp` 여백을 둔다. 검색어가 있어 동작 버튼을 감춘 동안에도 같은 여백을 둔다.

목록과 검색 결과 없음 안내가 서로 바뀔 때는 두 표시가 교차하며 흐려지는 전환을 사용한다.

### 공휴일 항목

각 항목에는 공휴일 이름과 선택 상태를 표시하며 항목 전체를 선택 대상으로 사용한다.

쉬는 날인 항목에는 색상만 사용하지 않고 `쉬는 날` 문구가 있는 강조 표시를 함께 제공한다. 강조 표시는 양 끝이 둥근 모양 안에 문구를 두고, 문구 좌우에 `8dp`, 위아래에 `4dp` 안쪽 여백을 둔다. 화면 낭독 도구로도 쉬는 날임을 알 수 있게 한다. 쉬는 날이 아닌 항목에는 이 강조 표시를 제공하지 않는다.

## 검색 결과 없음

검색어와 일치하는 항목이 없으면 목록이 놓이는 자리 가운데에 정렬한 안내 문구를 표시한다. 검색 입력은 그대로 남아 있어 사용자가 검색어를 고치거나 지울 수 있다.

## 일괄 선택 동작 버튼

본문 오른쪽 아래에 떠 있는 하나의 동작 버튼을 두고, [화면 가로 여백](./dimens.md)과 [화면 세로 여백](./dimens.md)만큼 표시 영역 가장자리에서 떨어뜨린다.

접힌 동작 버튼에는 일괄 선택을 뜻하는 체크 목록 아이콘을 둔다. 펼치면 버튼이 닫기 아이콘으로 바뀌어 다시 누르면 접힌다는 것을 알린다. 두 아이콘 사이의 전환과 버튼 크기 변화는 애니메이션으로 잇고, 아이콘은 전환이 절반을 지나는 시점에 바뀐다.

펼치면 동작 버튼 위쪽에 `전체 선택`, `전체 해제`, `쉬는 날만 선택`을 위에서 아래로 이 순서로 쌓아 표시한다. 각 항목에는 문구와 함께 아이콘을 두고, 모두 선택을 뜻하는 아이콘, 선택을 해제하는 아이콘, 휴식을 뜻하는 아이콘을 각각 사용한다. 항목은 하나씩 차례로 나타나고 접을 때는 역순으로 사라진다.

항목을 하나 고르면 그 동작을 실행하고 동작 버튼을 접는다.

검색어가 있는 동안에는 동작 버튼을 자리까지 감춘다. 비활성 상태로 남기지 않는 것은 사용자가 누를 수 없는 이유를 화면에서 알 수 없기 때문이다. 검색어를 모두 지우면 같은 자리에 다시 표시한다.

## 상태 표현

확인 중에는 본문에 진행 중임을 알리는 표시를 보여 준다.

확인 중에도 일괄 선택 동작 버튼은 같은 자리에 그대로 두고 비활성으로 표시하지 않는다. 사용자는 동작을 펼쳐 고를 수 있고, 고른 동작은 바로 실행된다.

## 문구와 접근성

한국어 환경과 그 외 기본 환경에서는 다음 문구를 사용한다.

| 문구 | 한국어 | 그 외 기본 |
| --- | --- | --- |
| 뒤로가기 접근성 이름 | `뒤로가기` | `Navigate up` |
| 검색어 입력 자리 표시 문구 | `공휴일을 검색하세요` | `Search for a holiday` |
| 검색 결과 없음 안내 | `검색 결과가 없습니다` | `No search results` |
| 접힌 일괄 선택 버튼 접근성 이름 | `일괄 선택` | `Bulk select` |
| 펼친 일괄 선택 버튼 접근성 이름 | `일괄 선택 닫기` | `Close bulk select` |
| 전체 선택 | `전체 선택` | `Select all` |
| 전체 해제 | `전체 해제` | `Deselect all` |
| 쉬는 날만 선택 | `쉬는 날만 선택` | `Select days off` |
| 쉬는 날 표시 | `쉬는 날` | `Day off` |
| 확인 중 접근성 이름 | `공휴일 확인 중` | `Loading holidays` |

검색어 입력과 지우기 버튼의 접근성 문구는 [검색 입력 디자인](./search-input.md)이 소유한다.

일괄 선택 항목의 아이콘에는 별도의 접근성 이름을 두지 않는다. 항목의 문구가 그 이름이 된다.

상단 바에 화면 제목을 두지 않으므로 화면 이름을 낭독으로 알리는 문구도 두지 않는다. 사용자는 설정 목록에서 고른 항목과 검색 입력의 자리 표시 문구로 현재 화면을 안다.
