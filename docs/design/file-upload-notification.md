# 파일 올리기 알림 디자인

기준 스펙: [파일 올리기 알림 스펙](../spec/client/file-upload-notification.md)

이 문서는 파일 올리기의 진행 알림과 결과 알림이 사용자에게 보이는 문구와 표현을 소유한다. 알림을 언제 보내고 무엇을 담는지는 기준 스펙이 소유한다.

알림은 앱 화면이 아니라 Android와 iOS의 알림 표시 영역에 놓이므로, 배치와 크기는 플랫폼의 기본 알림 표현을 그대로 따르고 이 문서에서 따로 정하지 않는다.

## 진행 알림

Android에서만 표시한다. 제목 한 줄, 본문 한 줄과 진행 막대로 구성한다.

| 요소 | 표시 |
| --- | --- |
| 제목 | `문구`의 진행 알림 제목 |
| 본문 | 올리는 파일의 이름. 한 줄을 넘으면 시스템 기본 동작대로 말줄임한다 |
| 진행 막대 | 백분율이 있으면 보낸 양만큼 찬 막대, 아직 보낸 양이 없으면 끝없이 흐르는 막대 |

백분율 숫자는 따로 쓰지 않고 진행 막대로만 나타낸다. 진행 막대는 백분율이 1% 이상 바뀔 때만 다시 그린다. 알림이 자주 다시 그려지면 알림 목록이 깜빡이고 시스템이 갱신을 늦출 수 있기 때문이다.

진행 알림은 진행 중 알림으로 표시해 알림 목록의 위쪽 진행 중 영역에 놓는다. Android 13 이하에서는 옆으로 밀어 지울 수 없고, Android 14 이상에서는 시스템이 지우는 것을 허용한다. 소리, 진동, 화면 위 떠오름을 쓰지 않는다. 진행 알림에는 동작 버튼을 두지 않는다.

## 결과 알림

Android와 iOS에서 표시한다. 제목 한 줄과 본문 한 줄로 구성한다.

| 결과 | 제목 | 본문 |
| --- | --- | --- |
| 성공 | `문구`의 성공 제목 | 올린 파일의 이름 |
| 크기 초과 실패 | `문구`의 실패 제목 | `문구`의 크기 초과 본문 |
| 그 밖의 실패 | `문구`의 실패 제목 | 고른 파일의 이름. 이름을 알 수 없으면 본문을 두지 않는다 |

파일 이름은 줄이거나 바꾸지 않고 그대로 쓰며, 표시 영역에 들어가지 않는 부분은 각 플랫폼의 기본 동작대로 말줄임한다.

결과 알림은 사용자가 직접 지울 수 있고, 알림을 선택해 앱이 열리면 알림 목록에서 사라진다. Android에서는 진행 알림이 사라진 자리에 결과 알림이 새로 나타나며, 두 플랫폼 모두 결과 알림은 알림 목록에 하나만 남는다.

## 표시 방식

| 플랫폼 | 표시 방식 |
| --- | --- |
| Android | 소리와 화면 위 떠오름이 없고 알림 목록과 상태 표시줄에만 남는 중요도. 아래 `Android 알림 채널`이 이 중요도를 가진다 |
| iOS | 알림 배너와 알림 센터에 표시하고 소리와 배지는 쓰지 않는다. 앱이 앞에 있어도 알림 배너로 표시한다 |

## 아이콘

Android에서는 [일일 메모 알림 디자인](./daily-memo-notification.md)의 `아이콘`과 같은 알림 전용 아이콘을 작은 아이콘으로 쓰고, 색은 시스템 기본값을 따른다. 큰 아이콘이나 별도의 이미지는 두지 않는다. 진행 알림과 결과 알림이 같은 아이콘을 쓴다.

iOS에서는 시스템이 알림에 붙이는 앱 아이콘을 그대로 쓰고 앱이 따로 아이콘을 지정하지 않는다.

## Android 알림 채널

Android 시스템의 알림 설정에서 사용자가 이 알림만 따로 끌 수 있도록 전용 알림 채널을 하나 둔다. 진행 알림과 결과 알림이 이 채널을 함께 쓰고, 다른 알림과는 공유하지 않는다.

| 요소 | 한국어 | 영어 |
| --- | --- | --- |
| 채널 이름 | `파일 올리기` | `File uploads` |
| 채널 설명 | `파일을 올리는 동안의 진행과 결과를 알려 줍니다.` | `Shows the progress and result of file uploads.` |

## 문구

알림 문구는 기기의 앱 언어를 따른다.

| 항목 | 한국어 | 영어 |
| --- | --- | --- |
| 진행 알림 제목 | `파일 올리는 중` | `Uploading file` |
| 성공 제목 | `파일을 올렸습니다` | `File uploaded` |
| 실패 제목 | `파일을 올리지 못했습니다` | `Couldn't upload the file` |
| 크기 초과 본문 | `50MB 이하 파일만 올릴 수 있습니다.` | `Only files up to 50 MB can be uploaded.` |

크기 초과 본문은 [FileHome 화면 디자인](./file-home.md)의 크기 초과 안내와 같은 문구다. 앱 이름은 두 플랫폼 모두 알림 머리말에 자동으로 붙으므로 문구에 다시 넣지 않는다.

## 접근성

화면 낭독기는 알림의 제목과 본문을 이어서 읽고, Android 진행 알림에서는 시스템이 진행 막대의 진행을 함께 읽는다. 문구 자체가 안내와 내용이므로 별도의 접근성 이름이나 설명을 덧붙이지 않는다.

알림을 선택하는 조작에는 별도의 접근성 이름을 두지 않고, 각 플랫폼이 알림에 기본으로 제공하는 열기 동작을 그대로 쓴다.
