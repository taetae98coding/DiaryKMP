# TagDetail 메모 탭 디자인

기준 스펙: [TagDetail 메모 탭 스펙](../spec/client/tag-detail-memo.md)

화면 전체의 구조, 상단 바, 탭 행, 페이지 전환과 떠 있는 버튼의 교체는 [TagDetail 화면 디자인](./tag-detail.md)이 소유한다. 이 문서는 메모 탭 안의 표현만 정한다. 웹 탭과 장소 탭의 표현은 [TagDetail 웹 탭 디자인](./tag-detail-web.md), [TagDetail 장소 탭 디자인](./tag-detail-place.md)이 소유한다.

## 탭 구성

메모 탭 안은 위에서부터 정렬 줄과 메모 목록을 세로로 쌓는다. 두 요소 사이에는 [공통 구성요소 간격](./dimens.md)을 둔다.

메모 탭은 대상 태그의 조회 상태와 관계없이 같은 구성을 표시한다. 태그를 아직 조회하지 못해 상단 바에 제목이 없는 동안에도 정렬 줄과 목록은 같은 기준으로 표시한다.

## 완료된 메모 진입

목록 위 정렬 줄의 끝 쪽에 완료된 메모 진입 버튼을 둔다. 버튼의 해부구조, 자리와 폭, 상태, 조작과 접근성은 [목록 진입 버튼 디자인](./list-entry-button.md)을 따른다.

버튼의 라벨에는 `문구와 접근성`의 완료된 메모 진입 라벨을 쓴다.

버튼을 누르면 같은 태그의 TagMemoFinishedList 화면을 표시하고, 화면의 구조와 문구는 [TagMemoFinishedList 화면 디자인](./tag-memo-finished-list.md)을 따른다.

대상 태그를 아직 조회하지 못해 상단 바에 제목이 없는 동안에도 버튼은 같은 모양으로 표시한다.

## 메모 추가

메모 추가는 [TagDetail 화면 디자인](./tag-detail.md)의 `떠 있는 버튼`에 따라 메모 탭을 선택한 동안 떠 있는 메모 추가 버튼으로 제공한다. 대상 태그의 완료 여부와 삭제 여부는 이 버튼의 노출을 바꾸지 않는다.

메모 추가를 선택하면 MemoAdd 화면을, 메모를 선택하면 MemoDetail 화면을 표시한다. 두 화면은 창 너비와 관계없이 TagDetail 화면과 함께 배치하지 않고 단독으로 표시한다.

## 정렬 줄

정렬 줄은 탭 줄 바로 아래, 메모 목록 위에 둔다. 완료된 메모 진입 버튼과 같은 줄을 쓰고 정렬 컨트롤을 시작 쪽에, 완료된 메모 진입 버튼을 끝 쪽에 둔다. 정렬 줄과 정렬 선택 Bottom Sheet의 구조, 조작, 아이콘과 문구는 [목록 정렬 디자인](./list-sort.md)을 따른다.

## 목록

메모 카드의 제목, 컬러, 기간과 카드 사이 간격은 [MemoHome 목록 디자인](./memo-home.md)을 따른다.

기간 없는 메모는 목록 맨 위에 헤더 없이 표시한다. 기간 있는 메모는 시작 날짜별로 묶고 각 묶음 위에 날짜 헤더를 둔다. 헤더의 표시와 고정 방식은 MemoHome 목록 디자인을 따른다.

아직 준비되지 않은 자리에는 [페이지 조회 목록의 자리 표시 디자인](./paged-list-placeholder.md)에 따라 자리 표시 카드를 표시한다.

기준 스펙의 `빈 상태` 조건을 만족하면 목록 자리에 [목록 빈 상태 디자인](./list-empty-state.md)의 빈 상태를 표시한다. 아이콘과 제목·보조 문구는 그 문서의 표가 소유한다. 빈 상태에서도 정렬 줄의 완료된 메모 진입 버튼과 떠 있는 메모 추가 버튼은 같은 자리에 그대로 표시한다. 정렬 컨트롤은 [목록 정렬 디자인](./list-sort.md)의 `항목이 없는 동안의 정렬 줄`에 따라 감춘다.

조회 실패에는 별도 오류 안내나 재시도 버튼을 표시하지 않는다. 조회에 실패해 표시할 메모가 없을 때도 같은 빈 상태를 사용한다.

목록의 스크롤 위치는 다른 탭에 다녀와도 그대로 유지한다.

## 새로고침

목록을 아래로 당겨 새로고침하며, 당기는 조작과 진행 표시는 [새로고침 디자인](./sync-refresh.md)을 따른다. 목록이 빈 상태일 때도 같은 자리에서 당길 수 있다. 정렬 줄은 당김 컨테이너에 넣지 않는다.

## 완료·삭제 제스처와 피드백

[SwipeToFinishAndDelete 컴포넌트 디자인](./swipe-to-finish-and-delete.md)에 따라 카드를 왼쪽에서 오른쪽으로 스와이프하면 완료하고, 오른쪽에서 왼쪽으로 스와이프하면 삭제한다.

완료 또는 삭제 뒤의 피드백과 실행 취소는 스낵바로 표시한다. 스낵바는 [TagDetail 화면 디자인](./tag-detail.md)의 화면 공통 자리를 사용한다.

## 키보드 단축키

메모 탭을 선택한 동안 물리 키보드로 `Command + A`를 눌러 메모를 추가한다. 단축키 표는 [TagDetail 화면 디자인](./tag-detail.md)의 `키보드 단축키`가 소유한다.

다른 탭을 선택한 동안에는 이 단축키를 처리하지 않는다. 웹 탭과 장소 탭도 같은 `Command + A`를 쓰지만 선택한 탭의 추가 동작만 처리한다.

## 문구와 접근성

한국어 환경과 그 외 기본 환경에서는 다음 문구를 사용한다.

| 문구 | 한국어 | 그 외 기본 |
| --- | --- | --- |
| 완료된 메모 진입 라벨 | `완료된 메모` | `Finished memos` |
| 추가 버튼 접근성 이름 | `메모 추가` | `Add memo` |
| 완료 안내 | `메모가 완료되었습니다.` | `Memo finished.` |
| 삭제 안내 | `메모가 삭제되었습니다.` | `Memo deleted.` |
| 실행 취소 동작 | `실행 취소` | `Undo` |
| 완료 스와이프 아이콘 접근성 이름 | `메모 완료` | `Finish memo` |
| 삭제 스와이프 아이콘 접근성 이름 | `메모 삭제` | `Delete memo` |
| 오늘 날짜 헤더 | `오늘` | `Today` |
