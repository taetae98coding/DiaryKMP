# MemoFinishedList 목록·상세 배치 디자인

기준 스펙: [MemoFinishedList 목록·상세 배치 스펙](../spec/client/memo-finished-list-detail.md)

배치, 크기 조절, 버튼 노출, 선택 전 상세와 조절 상태 표시의 공통 표현은 [목록·상세 배치 공통 디자인](./list-detail-pane.md)을 따른다.

## 두 영역에 두는 화면

목록 영역에는 [MemoFinishedList 화면 디자인](./memo-finished-list.md)의 완료된 메모 목록을, 상세 영역에는 선택한 메모의 MemoDetail 화면을 표시한다. MemoHome 목록은 이 배치의 어느 영역에도 표시하지 않는다.

상세 영역의 MemoDetail 화면에서 연 태그, 웹 항목, 연락처, 장소의 상세와 추가 화면은 이 배치에 두지 않고 단독으로 표시한다.

각 상태에서 사용할 화면과 뒤로가기 결과, 공통 내비게이션 제공 여부는 기준 스펙과 각 화면 스펙을 따른다.

## 선택 전 상세

아직 메모를 선택하지 않았으면 상세 영역에 메모를 나타내는 아이콘과 메모를 선택하라는 안내를 표시한다. 이는 [항목 완료 메모 목록·상세 배치 디자인](./entity-memo-finished-list-detail.md)의 선택 전 상세와 같은 표현이다.

## 버튼 노출

목록의 상단 바에는 뒤로가기 버튼을 계속 표시하고, 누르면 MemoHome 목록으로 돌아간다.

이 화면에는 떠 있는 메모 추가 버튼이 없으므로 상세 영역에 MemoAdd 화면이 나타나지 않고, 메모 추가 단축키도 처리하지 않는다.

## 상세 영역이 닫히는 표시

상세 영역의 MemoDetail 화면에서 메모 삭제에 성공하거나 시스템 뒤로가기를 사용하면 목록을 그대로 두고 상세 영역만 선택 전 상세로 바꾼다.

상세 영역의 MemoDetail 화면에서 메모를 다시 시작하면 그 카드는 목록에서 사라지지만 상세 영역은 같은 MemoDetail 화면을 계속 표시한다.

## 문구와 접근성

한국어 환경과 그 외 기본 환경에서는 다음 문구를 사용한다.
