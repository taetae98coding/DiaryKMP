# MemoDetail 화면 디자인

기준 스펙: [MemoDetail 화면 스펙](../spec/client/memo-detail.md), [항목 공유 공통 스펙](../spec/client/entity-share.md)

## 적응형 화면 구조

MemoHome 목록에서 진입하면 넓은 화면에서는 메모 목록과 MemoDetail 화면을 좌우로 함께 표시하고, 좁은 화면에서는 MemoDetail 화면만 표시한다. 함께 표시할 때의 배치와 버튼 노출은 [Memo 목록·상세 배치 디자인](./memo-list-detail.md)을 따른다.

TagDetail 메모 탭, ContactDetail·PlaceDetail·WebDetail 메모 탭, SearchHome, 캘린더 홈이나 캘린더 시간표, Spotlight 검색 결과에서 진입하면 창 너비와 관계없이 MemoDetail 화면만 단독으로 표시한다. TagMemoFinishedList에서 진입하면 넓은 화면에서는 그 목록과 MemoDetail 화면을 좌우로 함께 표시하고, 좁은 화면에서는 MemoDetail 화면만 표시하며, 함께 표시할 때의 배치와 버튼 노출은 [TagMemoFinishedList 목록·상세 배치 디자인](./tag-memo-finished-list-detail.md)을 따른다. ContactMemoFinishedList·PlaceMemoFinishedList·WebMemoFinishedList에서 진입할 때도 같은 기준으로 표시하며, 배치와 버튼 노출은 [항목 완료 메모 목록·상세 배치 디자인](./entity-memo-finished-list-detail.md)을 따른다. MemoFinishedList에서 진입할 때도 같은 기준으로 표시하며, 배치와 버튼 노출은 [MemoFinishedList 목록·상세 배치 디자인](./memo-finished-list-detail.md)을 따른다.

화면 상단에는 메모 제목을 표시하는 상단 바를 둔다. MemoDetail 화면을 단독으로 표시할 때 상단 바에 뒤로가기 버튼을 표시한다.

상단 바의 메모 제목은 [항목 상세 화면 공통 디자인](./entity-detail.md)의 `상단 바 제목`에 따라 표시한다.

단독 화면에서는 상단 바의 뒤로가기 버튼이나 시스템 뒤로가기를 사용하면 진입하기 전 화면으로 돌아간다. 목록과 상세를 함께 표시하는 동안에는 뒤로가기 버튼을 숨기고, 시스템 뒤로가기를 사용하면 상세 영역을 선택한 메모가 없을 때의 표시로 바꾼다. 그 표시는 각 목록·상세 배치 디자인을 따른다.

상단 바 오른쪽에는 공유 버튼, 작성 도우미를 여는 버튼, 완료 상태를 전환하는 버튼, 복사 버튼, 삭제 버튼을 차례로 표시한다. 공유 버튼은 다른 상세 화면과 같이 끝 쪽 버튼 묶음의 맨 앞에 두며, 그리는 조건은 `공유`를 따른다. 다섯 버튼은 메모 조회가 완료되면 표시한다. 복사 버튼은 이미 자리를 익힌 완료·삭제 버튼의 위치를 바꾸지 않도록 두 버튼 사이에 두고, 되돌리기 어려운 삭제 버튼을 계속 마지막에 둔다.

작성 도우미 버튼은 공유 버튼 바로 뒤에 둔다. 메모의 내용을 채우는 동작이라 저장된 메모의 상태를 바꾸는 완료·복사·삭제 버튼보다 앞에 오고, 마지막 자리는 삭제가 계속 지킨다. 버튼의 아이콘, 표시 조건과 다이얼로그는 [메모 Gemini 작성 도우미 디자인](./memo-gemini.md)을 따른다.

본문의 구성과 순서, 적응형 배치, 영역 여백과 스크롤은 [메모 본문 배치 디자인](./memo-form.md)을 따른다.

수정 동작은 본문 위에 떠 있는 수정 버튼으로 제공하고, 버튼의 자리는 [메모 본문 배치 디자인](./memo-form.md)을 따른다.

본문과 수정 버튼, 스낵바의 표시 영역과 소프트 키보드 대응도 [메모 본문 배치 디자인](./memo-form.md)을 따른다.

## 로딩과 내용 표시

메모를 조회하는 동안에는 본문을 좌우로 나누지 않고 본문 전체에 로딩 진행 표시를 표시하며, 상단 바 제목, 제목, 설명, 컬러, 날짜·시간, 태그 입력, 웹 입력, 연락처 입력과 장소 카드, 공유·작성 도우미·수정·완료·복사·삭제 버튼은 숨긴다. 뒤로가기 버튼은 `적응형 화면 구조`의 기준대로 로딩 중에도 표시한다. 조회에 실패해도 오류 표시로 바꾸지 않고 로딩 진행 표시를 유지한다.

조회가 완료되면 입력과 동작 버튼을 표시하고 로딩 진행 표시를 숨긴다. 로딩 상태와 내용 표시 상태 사이에는 교차 전환을 적용한다.

기간이 있는 메모는 날짜·시간 입력의 스위치를 켜고 저장된 기간과 종일 여부를 표시한다. 기간이 없으면 스위치를 끈 상태로 표시한다.

## 태그 변경

태그 변경 결과는 태그 칩과 선택 목록에 즉시 반영한다. 태그 변경만으로 수정 버튼의 노출 여부나 진행 표시를 바꾸지 않는다.

태그 변경 성공과 실패에는 스낵바나 재시도 버튼을 표시하지 않는다.

## 수정 동작과 피드백

현재 입력한 제목, 설명, 컬러와 기간 중 하나라도 저장된 값과 다를 때만 수정 버튼을 표시한다. 값이 모두 같으면 수정 버튼을 숨긴다. 버튼이 나타나고 사라지는 표현은 [나타나고 사라지는 버튼 디자인](./button-visibility.md)을 따른다.

사용자는 수정 버튼을 누르거나, 수정 버튼이 표시된 상태에서 물리 키보드의 `Cmd`(또는 `Meta`)와 `Enter`를 함께 눌러 수정을 실행한다.

수정 버튼에는 체크 아이콘을 표시한다. 수정을 처리하는 동안에는 수정 버튼의 아이콘을 진행 표시로 바꾼다. 수정에 성공하면 성공 안내를 스낵바로 표시한다. 새 안내를 표시할 때 이미 보이는 스낵바가 있으면 표시 시간이 지나기를 기다리지 않고 즉시 새 안내로 바꾼다. 수정 실패에는 스낵바나 재시도 버튼을 표시하지 않는다.

사용자가 제목을 편집하는 동안 상단 바에는 저장된 제목을 계속 표시하고, 수정에 성공한 뒤 새 제목으로 바꾼다.

## 복사

복사 버튼에는 문서 두 장이 겹친 복사 아이콘을 표시한다. 복사를 처리하는 동안 복사 버튼의 아이콘을 진행 표시로 바꾼다.

복사에 성공하면 상세 대상을 복사본 메모로 바꾼다. 복사본 메모를 불러오는 동안에는 `로딩과 내용 표시`의 기준대로 로딩 진행 표시가 잠깐 보일 수 있다. 불러오기가 끝나면 상단 바 제목과 본문 입력에 복사본 메모의 저장된 내용을 표시하고, 복사 성공 안내를 스낵바로 표시한다.

복사본은 완료되지 않은 상태이므로 복사 직후 완료 상태 전환 버튼은 켜지지 않은 상태로 표시한다.

복사에 실패하면 스낵바나 재시도 버튼을 표시하지 않고 원본 메모의 내용을 그대로 유지한다.

## 공유

공유 버튼의 아이콘, 접근성 이름과 설명, 비활성과 숨김 표현, 공유 시트가 나타나는 모습, 복사로 대신했을 때와 공유하지 못했을 때의 안내는 [항목 공유 공통 디자인](./entity-share.md)을 따른다. 공유를 제공하지 않는 환경에서 버튼을 그리지 않으면 작성 도우미·완료·복사·삭제 버튼이 빈자리 없이 이어진다.

메모를 조회하는 동안에는 이 화면의 다른 상단 바 버튼과 같이 공유 버튼도 표시하지 않고, 조회가 끝나면 다른 버튼과 함께 나타난다. 이는 [항목 공유 공통 디자인](./entity-share.md)의 `비활성`에 따른 것이다.

수정, 완료·다시 시작, 복사, 삭제를 처리하는 동안에도 공유 버튼은 그대로 누를 수 있다.

입력 중인 기간이 없거나 일정 파일을 공유할 수 없는 웹과 데스크톱에서는 공유 버튼을 누르면 공유 형식 선택 Bottom Sheet 없이 곧바로 글을 담은 공유 시트를 연다. 글 공유를 복사로 대신하는 환경이면 공유 시트 대신 곧바로 글을 복사하고 복사 안내 스낵바를 표시한다. 복사 안내는 `메모 복사` 버튼의 복사 성공 안내와 다른 문구이며, 두 안내를 표시하는 자리와 교체 기준은 같다.

### 공유 형식 선택 Bottom Sheet

입력 중인 기간이 있고 일정 파일을 공유할 수 있으면 공유 버튼을 누를 때 현재 화면 위에 공유 형식 선택 Bottom Sheet를 표시한다. iOS의 상단 바 버튼에는 펼침 메뉴를 붙일 수 없으므로 모든 플랫폼에서 같은 Bottom Sheet를 쓴다. Bottom Sheet의 표시, 드래그 핸들과 제목의 배치, 닫는 조작, 적응형 배치는 [필터 Bottom Sheet 디자인](./filter-bottom-sheet.md)의 `Bottom Sheet 표시`, `닫는 조작`, `적응형 배치`와 같은 기준을 쓴다. 제목은 [공통 스타일](./styles.md)의 `Bottom Sheet 제목`, 줄을 담는 영역은 `Bottom Sheet 내용`을 따른다.

제목 아래에는 위에서부터 글로 공유하는 줄, 일정 파일로 공유하는 줄을 한 줄씩 둔다. 기간이 없어도 고를 수 있는 글을 먼저 둔다. 각 줄에는 형식 이름 하나만 두고 아이콘, 보조 문구, 선택 표시는 두지 않는다. 지금 고른 상태를 나타내는 선택이 아니라 누르면 곧바로 실행되는 동작이기 때문이다.

각 줄은 [공통 스타일](./styles.md)의 `Bottom Sheet 선택 줄`을 따르고, 줄 전체가 하나의 누를 수 있는 대상이다. 줄을 누르면 Bottom Sheet를 닫고 곧바로 그 형식의 공유 시트를 연다. 줄을 고르지 않고 Bottom Sheet를 닫으면 공유 시트를 열지 않는다.

Bottom Sheet가 열려 있는 동안 화면이 회전하거나 재생성되어도 Bottom Sheet는 열린 채로 남는다.

### 보내는 글의 기간 줄

글의 기간 줄은 [MemoHome 목록 화면 디자인](./memo-home.md)의 메모 카드가 보여 주는 기간 글과 같은 표기를 쓰며, 기기의 앱 언어를 따른다.

| 기간 | 한국어 | 그 외 기본 |
| --- | --- | --- |
| 종일, 하루 | `2026. 11. 20.` | `Nov 20, 2026` |
| 종일, 여러 날 | `2026. 11. 20. ~ 2026. 11. 22.` | `Nov 20, 2026 ~ Nov 22, 2026` |
| 날짜·시간, 같은 날 | `2026. 11. 20. 오후 7:00 ~ 오후 9:00` | `Nov 20, 2026 7:00 PM ~ 9:00 PM` |
| 날짜·시간, 다른 날 | `2026. 11. 20. 오후 11:00 ~ 2026. 11. 21. 오전 1:00` | `Nov 20, 2026 11:00 PM ~ Nov 21, 2026 1:00 AM` |

## 완료·다시 시작·삭제

완료 상태 전환 버튼은 완료 여부와 관계없이 톱니 모양 배지에 체크가 들어간 같은 완료 아이콘을 쓰는 토글 버튼이다. 완료되지 않은 메모에서는 버튼을 켜지지 않은 상태로, 완료된 메모에서는 켜진 상태로 강조해 표시한다. 완료 또는 다시 시작을 처리하는 동안 해당 버튼의 아이콘을 진행 표시로 바꾼다.

완료나 다시 시작에 성공해도 스낵바를 표시하지 않고, 버튼의 표시와 접근성 이름이 바뀌는 것으로 결과를 알린다.

삭제 버튼은 누르면 확인 대화상자 없이 바로 삭제를 실행한다. 삭제를 처리하는 동안에는 삭제 버튼의 아이콘을 진행 표시로 바꾼다.

삭제에 성공하면 단독 화면에서는 뒤로가기와 같은 방식으로 화면을 닫는다. 목록과 상세를 함께 표시하는 상태에서는 상세 영역을 선택한 메모가 없을 때의 표시로 바꾸며, 그 표시는 각 목록·상세 배치 디자인을 따른다.

## 문구와 접근성

한국어 환경과 그 외 기본 환경에서 다음 문구를 사용한다.

| 항목 | 한국어 | 그 외 기본 |
| --- | --- | --- |
| 뒤로가기 버튼 접근성 이름 | `뒤로가기` | `Navigate up` |
| 수정 버튼 접근성 이름 | `메모 수정` | `Update memo` |
| 완료 버튼 접근성 이름 | `메모 완료` | `Finish memo` |
| 다시 시작 버튼 접근성 이름 | `메모 다시 시작` | `Restart memo` |
| 복사 버튼 접근성 이름 | `메모 복사` | `Copy memo` |
| 삭제 버튼 접근성 이름 | `메모 삭제` | `Delete memo` |
| 수정 성공 안내 | `메모가 수정되었습니다.` | `Memo updated.` |
| 복사 성공 안내 | `메모가 복사되었습니다.` | `Memo copied.` |
| 공유 형식 선택 Bottom Sheet 제목 | `공유` | `Share` |

공유 버튼의 문구와 복사로 대신했을 때와 공유하지 못했을 때의 안내는 [항목 공유 공통 디자인](./entity-share.md)을, 태그 입력의 문구는 [메모 태그 입력 컴포넌트 디자인](./memo-tag-input.md)을, 웹 입력의 문구는 [메모 웹 입력 컴포넌트 디자인](./memo-web-input.md)을, 연락처 입력의 문구는 [메모 연락처 입력 컴포넌트 디자인](./memo-contact-input.md)을, 장소 카드의 문구는 [메모 장소 카드 컴포넌트 디자인](./memo-place-card.md)을, 제목 입력의 문구는 [제목 입력 디자인](./title-input.md)을, 그 밖의 입력 배치는 [메모 본문 배치 디자인](./memo-form.md)을, 작성 도우미의 문구는 [메모 Gemini 작성 도우미 디자인](./memo-gemini.md)을 따른다.
