# RoutineFinishedList 화면 디자인

기준 스펙: [RoutineFinishedList 화면 스펙](../spec/client/routine-finished-list.md)

화면 구조, 목록과 빈 상태·새로고침의 공통 표현은 [완료 목록 공통 디자인](./finished-list.md)을 따른다. 같은 문서의 `정렬 줄`은 따르지 않는다.

## 화면 구조와 이동

상단 바에는 `완료된 루틴` 제목을 표시한다.

상단 바 아래 본문은 완료된 루틴 목록 하나로 채운다. 기준 스펙의 `정렬 선택 미제공`에 따라 정렬 줄을 두지 않으며, 목록은 상단 바 바로 아래에서 시작하고 정렬 줄이 있던 자리를 비워 두지 않는다. RoutineHome의 보기 전환 버튼, 필터 버튼, 완료된 루틴 진입 줄과 달력 보기도 이 화면에 두지 않는다.

루틴을 선택하면 RoutineDetail 화면을 표시한다. 창 너비가 compact보다 넓으면 [RoutineFinishedList 목록·상세 배치 디자인](./routine-finished-list-detail.md)에 따라 목록과 함께 상세 영역에 표시하고, compact이면 단독으로 표시한다.

## 목록

루틴 카드의 컬러 원형 표시와 제목, 카드 문구의 표현과 언어별 표기는 [RoutineHome 화면 디자인](./routine-home.md)의 `루틴 카드`를 따르고, 카드는 같은 문서의 `루틴 목록`에 따라 1열 목록으로 놓는다.

이 목록의 카드 문구는 모두 `완료`이며, 달성률과 진행 막대는 두지 않는다. 카드에는 빠른 기록 버튼을 두지 않고, 글 묶음이 카드의 가로 폭을 모두 쓴다. 카드를 길게 눌러도 양을 입력하는 창이 열리지 않으며, 카드는 누르는 조작과 `다시 시작·삭제 제스처와 피드백`의 스와이프만 받는다.

진행 중인 루틴과 시작 전인 루틴 사이에는 구분선이나 묶음 이름을 두지 않고, 두 상태를 카드에서 구분해 표시하지도 않는다.

아직 준비되지 않은 자리에는 [페이지 조회 목록의 자리 표시 디자인](./paged-list-placeholder.md)에 따라 자리 표시 카드를 표시한다. 자리 표시 카드의 비움 형태는 [RoutineHome 화면 디자인](./routine-home.md)의 `자리 표시`와 같다.

## 빈 상태

빈 상태의 아이콘과 문구는 [목록 빈 상태 디자인](./list-empty-state.md)이 `RoutineFinishedList 완료된 루틴 목록`으로 정한 값을 따른다.

## 다시 시작·삭제 제스처와 피드백

[SwipeToFinishAndDelete 컴포넌트 디자인](./swipe-to-finish-and-delete.md)에 따라 카드를 왼쪽에서 오른쪽으로 스와이프하면 다시 시작하고, 오른쪽에서 왼쪽으로 스와이프하면 삭제한다.

시작 방향의 상태 아이콘에는 완료 아이콘 대신 화살표가 원을 그리는 다시 시작 아이콘을 표시한다. 끝 방향의 삭제 아이콘은 RoutineHome의 루틴 목록과 같다.

다시 시작 또는 삭제 뒤의 피드백과 실행 취소는 스낵바로 표시한다. 표시 시간과 새 안내로 바꾸는 방식, 저장되지 못했을 때 스낵바를 표시하지 않는 것은 [RoutineHome 화면 디자인](./routine-home.md)의 `완료와 삭제 제스처`와 같다.

## 문구와 접근성

[완료 목록 공통 디자인](./finished-list.md)의 `문구와 접근성`에 더해 한국어 환경과 그 외 기본 환경에서 다음 문구를 사용한다. 카드 문구의 표기와 루틴 카드의 접근성 이름은 [RoutineHome 화면 디자인](./routine-home.md)의 `카드 문구 표기`와 `문구와 접근성`을 따르며, 빠른 기록 버튼의 이름은 쓰지 않는다.

| 항목 | 한국어 | 그 외 기본 |
| --- | --- | --- |
| 상단 바 제목 | `완료된 루틴` | `Finished Routines` |
| 다시 시작 안내 | `루틴을 다시 시작했습니다.` | `Routine restarted.` |
| 삭제 안내 | `루틴이 삭제되었습니다.` | `Routine deleted.` |
| 실행 취소 동작 | `실행 취소` | `Undo` |
| 다시 시작 스와이프 아이콘 접근성 이름 | `루틴 다시 시작` | `Restart routine` |
| 삭제 스와이프 아이콘 접근성 이름 | `루틴 삭제` | `Delete routine` |
