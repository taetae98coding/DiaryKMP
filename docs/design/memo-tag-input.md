# 메모 태그 입력 컴포넌트 디자인

기준 스펙: [메모 태그 입력 컴포넌트 스펙](../spec/memo-tag-input.md)

칩 영역과 추가 칩, 태그 선택 목록과 그 안의 검색·태그 추가 버튼·빈 상태·준비 상태 표현은 [태그 선택 입력 공통 디자인](./tag-select-input.md)을 따른다. 이 문서는 이 입력에만 있는 대표 태그 표현과 그 문구를 소유한다.

화면마다 다른 자리와 표시 조건은 [메모 본문 배치 디자인](./memo-form.md)이 소유한다.

## 태그 칩

대표 태그가 아닌 태그 칩은 [태그 선택 입력 공통 디자인](./tag-select-input.md)의 `태그 칩`을 그대로 따른다.

대표 태그 칩은 원형 표시 대신 칩의 배경 전체를 태그 컬러로 채운다. 태그 이름은 그 컬러 위에서 읽을 수 있는 색으로 표시하고, 대표 태그임을 알리는 접근성 이름을 제공한다.

대표 태그 칩도 다른 칩과 같은 방식으로 눌러 그 태그의 TagDetail 화면으로 이동한다.

## 태그 추가 칩

이 입력의 추가 칩은 태그 추가 칩이며, 표현과 동작은 [태그 선택 입력 공통 디자인](./tag-select-input.md)의 `추가 칩`을 그대로 따른다.

## 태그 선택 목록

목록의 각 항목에는 공통 디자인의 구성에 더해 [선택 목록 항목 디자인](./picker-row.md)의 끝 쪽 버튼 자리에 대표 태그 지정 버튼을 표시한다. 버튼을 누르면 해당 태그의 대표 태그 지정 여부를 바꾼다.

자리 표시 항목의 대표 태그 지정 버튼은 지정하지 않은 상태로 표시한다.

## 문구와 접근성

[태그 선택 입력 공통 디자인](./tag-select-input.md)의 `문구와 접근성`에 더해 한국어 환경과 그 외 기본 환경에서 다음 문구를 사용한다.

| 항목 | 한국어 | 그 외 기본 |
| --- | --- | --- |
| 태그 추가 칩 라벨 | `태그 선택` | `Select tag` |
| 태그 선택 동작 접근성 이름 | `태그 선택` | `Select tag` |
| 태그 선택 목록 제목 | `태그 선택` | `Select Tag` |
| 대표 태그 지정 버튼 접근성 이름 | `대표 태그 지정` | `Set as primary tag` |
| 대표 태그 지정 해제 버튼 접근성 이름 | `대표 태그 지정 해제` | `Unset primary tag` |
| 대표 태그 칩 접근성 이름 | `대표 태그` | `Primary tag` |
