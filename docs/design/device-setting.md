# 기기 설정 화면 공통 디자인

기준 스펙: [기기 설정 화면 공통 스펙](../spec/client/device-setting.md)

이 문서는 설정 목록에서 진입해 값을 이 기기에만 보관하는 설정 화면들이 함께 쓰는 화면 구조, 저장된 값을 확인하기 전의 표시, 입력한 뒤 저장하는 설정의 저장 버튼과 표시 영역·소프트 키보드·초점 표현, 공통 문구를 소유한다. 본문에 두는 영역과 입력의 구성, 저장 버튼의 표시를 가르는 값, 화면에만 있는 다이얼로그나 도구의 표현과 문구는 각 화면 문서가 정한다.

상단 바에 검색어 입력을 두는 [SettingHoliday 화면](./setting-holiday.md)은 화면 구조가 달라 이 문서를 따르지 않는다.

## 화면 구조

설정 화면의 단독·목록/상세 배치와 표시 상태에 따른 뒤로가기 동작 노출은 [Setting 목록·상세 배치 디자인](./setting-list-detail.md)을 따른다.

화면 상단에는 제목이 있는 상단 바를 두고, 뒤로가기 동작을 제공하는 상태에서는 상단 바에 함께 배치한다.

본문이 표시 영역보다 길어지면 위아래로 스크롤할 수 있다.

## 저장된 값을 확인하기 전

[SettingFile 화면](./setting-file.md), [SettingGemini 화면](./setting-gemini.md), [SettingMap 화면](./setting-map.md), [SettingPlaylist 화면](./setting-playlist.md)은 저장된 값을 확인하기 전이거나 읽지 못한 상태에서 그 값을 보여 주는 자리를 표시하지 않고, 별도의 로딩 안내나 오류 안내도 표시하지 않는다. 어느 자리까지 감추는지는 각 화면 문서가 정한다.

## 입력한 뒤 저장하는 설정

이 절은 [SettingGemini 화면](./setting-gemini.md)과 Android·iOS의 [SettingPlaylist 화면](./setting-playlist.md)처럼 값을 입력한 뒤 저장 버튼으로 저장하는 설정이 따른다.

### 저장 버튼

저장 버튼은 떠 있는 버튼으로 두고 아이콘은 다른 화면의 저장 동작과 같은 확인 모양을 쓴다. 설정 목록과 함께 표시할 때도 상세 영역 안에 둔다.

편집 중인 값이 저장된 값과 다를 때만 저장 버튼을 표시하고, 모두 같으면 저장 버튼을 자리까지 감춘다. 어느 값을 비교하는지는 각 화면 문서가 정한다. 버튼이 나타나고 사라지는 표현은 [나타나고 사라지는 버튼 디자인](./button-visibility.md)을 따라 다른 상세 화면의 수정 버튼과 같다.

저장 처리 중에는 저장 버튼의 확인 아이콘을 진행 표시로 바꾼다. 처리 중에도 표시 조건은 그대로 적용하므로, 처리하는 동안 사용자가 값을 저장된 값과 같게 되돌리면 진행 표시까지 함께 사라진다.

저장에 성공하면 편집 중인 값이 저장된 값과 같아지므로 저장 버튼은 같은 전환으로 사라진다. 저장에 실패하면 편집 중인 값이 그대로 남아 저장 버튼도 그대로 표시한다.

저장 성공과 저장 실패 피드백은 스낵바로 표시한다.

### 표시 영역과 소프트 키보드

본문, 저장 버튼과 스낵바는 상태 표시 영역, 시스템 탐색 영역과 카메라 컷아웃 등 기기가 가리는 영역을 침범하지 않게 배치한다.

소프트 키보드가 나타나면 세 요소를 키보드 위 영역에 맞춰 배치하고, 초점이 있는 입력이 키보드에 가리지 않도록 본문을 세로로 스크롤한다. 키보드가 닫히면 원래 표시 영역으로 되돌린다.

### 초점과 키보드 단축키

화면이 열릴 때는 어느 입력에도 초점을 두지 않으므로 소프트 키보드도 열지 않는다. 저장된 값을 확인하러 들어오는 경우가 많아 곧바로 입력을 시작한다고 보지 않기 때문이다.

저장에는 키보드 단축키를 두지 않는다.

## 문구와 접근성

한국어 환경과 그 외 기본 환경에서 다음 문구를 함께 사용한다. 상단 바 제목과 화면마다 다른 문구는 각 화면 문서가 정한다.

| 문구 | 한국어 | 그 외 기본 |
| --- | --- | --- |
| 뒤로가기 접근성 이름 | `뒤로가기` | `Navigate up` |

입력한 뒤 저장하는 설정은 다음 문구도 함께 사용한다.

| 문구 | 한국어 | 그 외 기본 |
| --- | --- | --- |
| 저장 버튼 접근성 이름 | `저장` | `Save` |
| 저장 성공 안내 | `저장되었습니다.` | `Saved.` |
| 저장 실패 안내 | `저장하지 못했습니다.` | `Couldn't save.` |
