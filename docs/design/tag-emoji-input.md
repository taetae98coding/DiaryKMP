# 태그 이모지 입력 컴포넌트 디자인

기준 스펙: [TagAdd 화면 스펙](../spec/tag-add.md), [TagDetail 화면 스펙](../spec/tag-detail.md)

## 이모지 칸

이모지 입력은 카드 형태의 정사각형 칸 하나로 표시한다. 세로 크기는 제목 입력과 같고 가로와 세로의 비율은 `1:1`이므로, 제목 입력과 한 행에 나란히 두면 위아래가 맞고 남은 폭은 제목 입력이 모두 사용한다.

칸 안의 내용은 가로와 세로 모두 가운데에 정렬한다.

이모지가 있으면 그 문자를 가운데에 표시한다. 이모지가 비어 있으면 대신 `이모지` 라벨 문구를 가운데에 표시해 무엇을 입력하는 칸인지 알린다.

칸 안에서는 문자를 직접 입력하지 않으므로 칸을 눌러도 소프트 키보드가 열리지 않고 지우기 버튼도 표시하지 않는다.

## 이모지 입력 다이얼로그

사용자가 이모지 칸을 누르면 현재 이모지가 채워진 이모지 입력 다이얼로그를 연다.

다이얼로그에는 다음을 위에서 아래 순서로 표시한다.

- `이모지` 제목
- 한 줄 입력 칸
- 취소 버튼과 확인 버튼

다이얼로그를 열면 입력 칸에 자동으로 초점을 맞추고 소프트 키보드를 연다. 입력 칸에는 지우기 버튼을 표시하지 않는다. 입력한 문자가 하나뿐이므로 사용자는 키보드의 지우기로 바로 비울 수 있다.

화면이 회전하거나 시스템에 의해 재생성되어도 다이얼로그는 열린 상태와 편집 중인 문자를 유지한다.

### 입력 제한

입력 칸에는 사용자에게 보이는 문자 하나만 남는다. 이미 문자가 있는 상태에서 문자를 이어서 입력하면 앞의 문자는 사라지고 새로 입력한 문자만 남는다. 여러 문자를 한 번에 붙여 넣으면 마지막 문자만 남고 나머지는 입력 칸에 나타나지 않는다.

이모지가 아닌 문자도 그대로 입력 칸에 표시한다. 별도의 경고나 오류 표시는 하지 않는다.

전용 이모지 키보드를 강제로 열지 않고 기기의 기본 문자 키보드를 사용한다.

### 확인과 취소

확인 버튼을 선택하면 다이얼로그를 닫고 입력한 문자를 이모지 칸에 반영한다. 입력 칸을 비운 채 확인하면 이모지 칸을 비운다.

취소 버튼, 다이얼로그 바깥 영역 선택, 시스템 뒤로가기로 닫으면 편집을 버리고 이모지 칸의 내용을 그대로 둔다.

## 문구

한국어 환경과 그 외 기본 환경에서는 다음 문구를 사용한다.

| 문구 | 한국어 | 그 외 기본 |
| --- | --- | --- |
| 이모지 칸 라벨 | `이모지` | `Emoji` |
| 다이얼로그 제목 | `이모지` | `Emoji` |
| 취소 버튼 | `취소` | `Cancel` |
| 확인 버튼 | `확인` | `Confirm` |
