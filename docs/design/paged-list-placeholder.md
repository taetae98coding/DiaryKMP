# 페이지 조회 목록의 자리 표시 디자인

기준 스펙: [페이지 조회 목록의 자리 표시 스펙](../spec/paged-list-placeholder.md)

이 문서는 페이지 단위로 조회하는 목록에서 아직 준비되지 않은 자리를 어떻게 표시하는지를 소유한다. 항목 자체의 구성과 목록 배치는 각 화면과 컴포넌트의 디자인이 소유하며, 이 문서는 그 항목을 비운 형태만 정의한다.

## 자리 표시 항목

자리 표시 항목은 준비된 항목과 같은 구성으로 배치해 같은 크기를 차지한다. 텍스트와 컬러 표시처럼 내용에서 오는 부분은 비워 두고, 체크 표시나 버튼처럼 항목이 항상 가지는 요소는 자리를 유지한다.

체크 표시는 선택하지 않은 상태로, 상태를 나타내는 버튼은 지정하지 않은 상태로 표시한다.

자리 표시 항목에는 별도의 진행 표시나 안내 문구를 함께 두지 않는다. 목록을 처음 열었을 때도 같은 자리 표시 항목으로 나타낸다.

## 조작과 접근성

자리 표시 항목은 누를 수 없는 상태로 두고 스와이프에도 반응하지 않는다. 항목 안의 조작 요소도 함께 누를 수 없는 상태로 둔다.

자리 표시 항목과 그 안의 조작 요소에는 접근성 이름을 두지 않는다. 읽을 내용이 없는 자리를 화면 낭독 도구가 항목으로 읽지 않게 하기 위한 것이다.

## 준비된 항목으로의 전환

내용이 준비되면 같은 자리에서 준비된 항목으로 바꾼다. 이때 항목의 크기, 목록의 높이, 다른 항목의 위치는 바뀌지 않는다.

전환에는 별도의 강조 애니메이션을 두지 않는다.

준비가 끝났는데 표시할 항목이 하나도 없으면 자리 표시 항목 대신 빈 상태를 표시한다. 빈 상태의 표시 형태와 자리 표시에서 넘어갈 때의 전환은 [목록 빈 상태 디자인](./list-empty-state.md)을 따르며, 그 문서의 적용 대상이 아닌 목록에는 빈 상태를 두지 않는다.
