# CalendarBarText 컴포넌트 디자인

기준 스펙: [CalendarBarText 컴포넌트 스펙](../spec/calendar-bar-text.md)

## 구성

색상 바와 글을 왼쪽에서 오른쪽으로 나란히 배치한다. 색상 바를 앞에 두고 글을 뒤에 둔다.

컴포넌트 전체에는 배경을 두지 않는다. 색상 바 뒤와 글 뒤 모두 캘린더 아이템 영역의 배경이 그대로 보인다.

색상 바와 글 사이에는 두 요소가 붙어 보이지 않을 만큼의 `2dp` 간격을 둔다.

바깥 여백은 [CalendarText 컴포넌트 디자인](calendar-text.md)의 글 표시와 같은 값을 사용해, 같은 캘린더 안에서 두 컴포넌트가 같은 줄 높이를 차지하도록 한다.

## 색상 바

색상 바는 글보다 좁은 너비 `3dp`의 세로 막대로 표시하고, 높이는 글의 높이에 맞춘다. 글이 짧아도 길어도 바의 너비는 달라지지 않는다.

색상 바의 모서리는 둥글게 표시한다.

색상 바는 스펙의 색상 결정에 따라 정해진 색을 채워서 표시한다.

## 글 표시

글은 [CalendarText 컴포넌트 디자인](calendar-text.md)과 같은 글자 스타일로 한 줄에 표시하고, 색상 바를 제외한 남은 영역 안에서 가운데 정렬한다.

글이 한 줄에 다 들어가지 않아도 줄을 바꾸거나 뒷부분을 생략하지 않는다. 넘치는 글은 [CalendarText 컴포넌트 디자인](calendar-text.md)의 넘치는 글 표시와 같이 가로로 흐르며 반복해서 지나가도록 표시한다.

글자색은 CalendarBarText가 배치된 화면의 기본 글자색을 사용한다. 색상 바의 색이 밝든 어둡든 글자색은 달라지지 않는다.
