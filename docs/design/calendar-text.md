# CalendarText 컴포넌트 디자인

기준 스펙: [CalendarText 컴포넌트 스펙](../spec/calendar-text.md)

## 글 표시

글은 한 줄로 표시하고 배경 위에 가운데 정렬한다.

배경의 모서리는 둥글게 표시하며, 배경과 글 사이에는 글이 배경 경계에 붙지 않을 만큼의 여백을 둔다.

## 넘치는 글 표시

글이 한 줄에 다 들어가지 않아도 줄을 바꾸거나 뒷부분을 생략하지 않는다.

넘치는 글은 가로로 흐르며 반복해서 지나가도록 표시한다.

## 색상

배경색은 스펙의 색상 결정에 따라 정해진 값을 사용한다.

글자색은 배경색 위에서 읽기 좋도록 배경색의 밝기에 따라 자동으로 정한다. 배경색이 어두우면 흰색, 밝으면 검은색을 사용한다.
