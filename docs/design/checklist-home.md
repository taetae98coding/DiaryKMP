# ChecklistHome 화면 디자인

기준 스펙: [ChecklistHome 화면 스펙](../spec/client/checklist-home.md), [새로고침 스펙](../spec/client/sync-refresh.md), [페이지 조회 목록의 자리 표시 스펙](../spec/client/paged-list-placeholder.md), [목록 빈 상태 스펙](../spec/client/list-empty-state.md)

## 화면 구조

ChecklistHome 화면은 `더보기`에서 이어지는 세부 화면으로 창 너비와 관계없이 단독 표시하고, 공통 내비게이션 영역은 [TopLevelNavigation 디자인](./top-level-navigation.md)의 `세부 화면에서의 노출`에 따라 숨긴다. 목록과 상세를 함께 두는 배치는 두지 않는다.

화면 상단에는 상단 바를 두고, 상단 바 시작 쪽에 뒤로가기 동작을, 그 바로 뒤에 화면 이름을 제목으로 표시한다. 제목은 시작 쪽에 맞추고 상단 바 끝 쪽에는 동작을 두지 않는다. iOS에서는 [상단 바](./top-bar.md)의 iOS 표현대로 제목을 가운데에 둔다. 정렬 줄은 두지 않는다.

본문 전체는 체크리스트 목록 영역 하나로 채우고, 오른쪽 아래에 체크리스트 추가를 실행하는 플로팅 액션 버튼을 겹쳐 표시한다.

## 체크리스트 추가 버튼

버튼에는 추가를 뜻하는 Material Symbols `add` 아이콘만 표시하고 라벨은 두지 않는다. 버튼의 모양과 크기는 플랫폼 기본 플로팅 액션 버튼을 따른다. 버튼의 이름을 알려 주는 설명 표시는 [아이콘 버튼 설명 디자인](./icon-button-tooltip.md)을 따른다.

버튼은 모든 환경에서 목록의 상태와 관계없이 같은 자리에 같은 모양으로 표시하고 비활성으로 표시하지 않는다. 버튼을 누르면 진행 표시 없이 바로 [ChecklistAdd 화면](./checklist-add.md)으로 이동한다.

## 목록

각 체크리스트는 카드로 표시한다. 카드에는 위에서부터 제목, 진행 글, 진행 막대를 이어서 표시한다. 설명과 체크 항목의 내용은 카드에 표시하지 않는다.

제목은 카드의 기본 글자 크기로 한 줄에 표시하며, 카드에서 사용할 수 있는 폭을 넘으면 기본 이동 속도와 간격으로 가로 이동을 시작하고 카드가 표시되는 동안 횟수 제한 없이 반복한다. 이는 [WebHome 화면 디자인](./web-home.md)의 카드 제목과 같은 표현이다. 접근성에는 생략하지 않은 전체 제목을 제공한다.

진행 글은 제목보다 작은 글씨와 본문 보조 색으로 `체크한 항목 수/전체 항목 수`를 공백 없이 숫자로 한 줄에 표시한다. 예: `3/5`. 체크 항목이 없으면 `0/0`을 표시한다. 숫자는 언어와 관계없이 같은 형식이다.

진행 막대는 카드 안쪽 폭을 모두 쓰는 Material 기본 직선형 진행 표시로, 전체 항목 수 가운데 체크한 항목 수의 비율만큼 채운다. 모두 체크하면 끝까지 채우고, 체크 항목이 없거나 하나도 체크하지 않았으면 채우지 않은 막대만 남긴다. 진행 정도가 바뀌면 막대는 진행 표시의 기본 애니메이션으로 새 비율까지 움직이고, 진행 글은 전환 효과 없이 바로 바뀐다. 막대는 진행 중임을 알리는 표시가 아니므로 움직이는 무한 진행 표현을 쓰지 않는다.

카드의 안쪽 여백은 [공통 스타일](./styles.md)의 `카드 내용`을 따르고, 제목과 진행 글 사이, 진행 글과 진행 막대 사이에는 각각 [카드 줄 간격](./dimens.md)을 둔다.

카드는 화면 너비와 관계없이 한 행에 두 개씩 표시되는 2열 고정 그리드로 배치하고, 카드 사이에는 가로와 세로로 각각 [공통 항목 간격](./dimens.md)을 둔다. 격자 바깥 여백은 [공통 화면 가로 여백과 세로 여백](./dimens.md)을 따른다. 모든 카드가 한 줄 제목, 한 줄 진행 글과 막대로 이루어져 높이가 같으므로 지그재그 격자를 쓰지 않는다.

카드 전체를 누를 수 있는 자리로 둔다. 누르는 동안에는 카드에 기본 눌림 표현만 두고, 누른 뒤 카드를 선택된 상태로 남기는 표시는 두지 않는다. 카드를 누르면 진행 표시 없이 바로 그 체크리스트의 [ChecklistDetail 화면](./checklist-detail.md)으로 이동한다. 자리 표시 카드는 누를 수 없다.

## 삭제 스와이프

사용자는 체크리스트 카드를 오른쪽에서 왼쪽으로 스와이프해 삭제한다. 체크리스트에는 완료 여부가 없으므로 왼쪽에서 오른쪽으로 미는 조작에는 반응하지 않는다.

스와이프 중 상태 아이콘, 삭제 기준, 취소와 비활성 표현은 [SwipeToFinishAndDelete 컴포넌트 디자인](./swipe-to-finish-and-delete.md)을 따른다. 자리 표시 카드는 스와이프가 시작되지 않는다.

삭제가 성립하면 카드를 격자에서 없애고, 결과 안내와 실행 취소 동작을 스낵바로 표시한다. 스낵바의 표시 시간, 교체와 자리는 [WebHome 화면 디자인](./web-home.md)의 `삭제 스와이프`와 같다.

삭제가 저장되지 못하면 스낵바를 표시하지 않는다.

실행 취소로 돌아온 카드는 스와이프 전 모양과 진행 정도로 정렬 기준에 맞는 자리에 다시 나타난다.

목록이 갱신될 때 카드가 자리를 옮기면 기본 항목 이동 애니메이션으로 옮긴다.

## 자리 표시

아직 준비되지 않은 자리에는 [페이지 조회 목록의 자리 표시 디자인](./paged-list-placeholder.md)에 따라 자리 표시 카드를 표시한다. 이 목록의 자리 표시 카드는 제목, 진행 글과 진행 막대를 비워 두고, 준비된 카드와 같은 높이를 차지한다.

## 빈 상태

표시할 체크리스트가 하나도 없으면 격자 자리에 [목록 빈 상태 디자인](./list-empty-state.md)의 빈 상태를 표시한다. 이 목록은 Material Symbols `checklist` 아이콘과 아래 `문구와 접근성`의 제목 문구·보조 문구를 사용하며, 격자와 빈 상태 사이의 전환도 그 문서를 따른다.

빈 상태에서도 플로팅 액션 버튼은 같은 자리에 같은 모양으로 둔다.

## 새로고침

본문 전체가 체크리스트 목록 영역이므로 본문 전체를 [새로고침 디자인](./sync-refresh.md)의 당김 새로고침 컨테이너로 감싼다.

진행 표시는 본문 위쪽 가로 가운데에 겹쳐 표시하고 격자를 밀어내지 않는다. 진행 표시의 모양과 크기, 임계값, 나타나고 사라지는 모션, 진행 중 조작 가능 여부는 [새로고침 디자인](./sync-refresh.md)을 그대로 따른다.

격자는 맨 위에 있을 때만 당김이 시작된다. 격자 대신 빈 상태를 표시하는 동안에는 스크롤할 것이 없으므로 당김이 곧바로 시작된다.

진행 표시가 나타나 있는 동안에도 카드를 누르거나 스와이프해 삭제하고 목록을 스크롤하고 체크리스트 추가 버튼과 뒤로가기를 누르는 조작을 그대로 할 수 있으며, 어떤 요소도 비활성으로 표시하지 않는다.

## 시스템 영역과 적응형 배치

상단 바는 상태 표시줄 영역을 피해 배치하고, 본문과 플로팅 액션 버튼, 스낵바는 내비게이션 바와 디스플레이 컷아웃 영역을 피해 배치한다. 격자의 마지막 카드가 플로팅 액션 버튼에 가리지 않게 배치한다. 격자 내용 아래쪽 여백은 [공통 여백과 간격 디자인](./dimens.md)의 `플로팅 액션 버튼 아래 여백` 사용 기준을 따른다. 입력이 없으므로 소프트 키보드를 고려한 배치는 두지 않는다.

격자는 창 너비, 창 높이와 자세에 관계없이 2열을 유지하므로 창이 넓어지면 카드와 진행 막대가 함께 넓어진다.

## 키보드 단축키

물리 키보드 환경에서는 `Command + A`를 눌러 체크리스트 추가 버튼과 같은 동작을 실행한다. 키 조합과 처리 조건은 [목록 추가 단축키 디자인](./list-add-shortcut.md)을 따른다.

## 문구와 접근성

한국어 환경과 그 외 기본 환경에서 다음 문구를 사용한다.

| 항목 | 한국어 | 그 외 기본 |
| --- | --- | --- |
| 상단 바 제목 | `체크리스트` | `Checklist` |
| 뒤로가기 접근성 이름 | `뒤로가기` | `Navigate up` |
| 체크리스트 추가 버튼 접근성 이름 | `체크리스트 추가` | `Add checklist` |
| 진행 정도 접근성 설명 | `전체 {전체 항목 수}개 중 {체크한 항목 수}개 체크` | `{체크한 항목 수} of {전체 항목 수} checked` |
| 빈 상태 제목 문구 | `아직 체크리스트가 없습니다` | `No checklists yet` |
| 빈 상태 보조 문구 | `추가 버튼으로 새 체크리스트를 만들 수 있습니다` | `Use the add button to create a checklist.` |
| 삭제 안내 | `체크리스트가 삭제되었습니다.` | `Checklist deleted.` |
| 실행 취소 동작 | `실행 취소` | `Undo` |
| 삭제 스와이프 아이콘 접근성 이름 | `체크리스트 삭제` | `Delete checklist` |

체크리스트 카드의 접근성 이름은 카드에 표시한 제목을 그대로 쓰고, 진행 정도는 `진행 정도 접근성 설명` 문구로 함께 읽는다. 화면에 보이는 진행 글 `3/5`와 진행 막대는 화면 낭독 도구가 따로 읽지 않아 같은 정보가 두 번 읽히지 않게 한다. 자리 표시 카드의 접근성 처리는 [페이지 조회 목록의 자리 표시 디자인](./paged-list-placeholder.md)을 따른다.
