# ChecklistHome 화면 디자인

기준 스펙: [ChecklistHome 화면 스펙](../spec/client/checklist-home.md)

## 화면 구조

ChecklistHome 화면의 구조, 시스템 영역 처리와 적응형 배치는 [더보기 준비 중 화면 공통 디자인](./more-menu-placeholder.md)을 따른다.

## 문구와 접근성

한국어 환경과 그 외 기본 환경에서 다음 문구를 사용한다.

| 항목 | 한국어 | 그 외 기본 |
| --- | --- | --- |
| 상단 바 제목 | `체크리스트` | `Checklist` |
| 뒤로가기 접근성 이름 | `뒤로가기` | `Navigate up` |
