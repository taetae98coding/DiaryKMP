# ChecklistHome 화면 디자인

기준 스펙: [ChecklistHome 화면 스펙](../spec/client/checklist-home.md), [Checklist 목록·상세 배치 스펙](../spec/client/checklist-list-detail.md), [새로고침 스펙](../spec/client/sync-refresh.md), [페이지 조회 목록의 자리 표시 스펙](../spec/client/paged-list-placeholder.md), [목록 빈 상태 스펙](../spec/client/list-empty-state.md)

화면 구조, 추가 버튼의 자리, 카드 조작, 삭제 스와이프, 자리 표시·빈 상태·새로고침, 격자와 시스템 영역, 추가 단축키의 공통 표현은 [항목 목록 화면 공통 디자인](./entity-home.md)을 따른다. 이 문서는 ChecklistHome에서만 다른 표현을 다룬다.

## 화면 구조

목록이 상세 영역과 자리를 나눠 쓰는 배치와 그 자리에서의 버튼 노출은 [Checklist 목록·상세 배치 디자인](./checklist-list-detail.md)을 따른다.

상단 바 시작 쪽에 뒤로가기 동작을, 그 바로 뒤에 화면 이름을 제목으로 표시한다. 제목은 시작 쪽에 맞추고 상단 바 끝 쪽에는 동작을 두지 않는다. 정렬 줄은 두지 않는다.

본문 전체는 체크리스트 목록 영역 하나로 채운다.

## 체크리스트 추가 버튼

버튼에는 추가를 뜻하는 Material Symbols `add` 아이콘만 표시하고 라벨은 두지 않는다. 버튼의 모양과 크기는 플랫폼 기본 플로팅 액션 버튼을 따른다. 버튼의 이름을 알려 주는 설명 표시는 [아이콘 버튼 설명 디자인](./icon-button-tooltip.md)을 따른다.

버튼은 모든 환경에서 비활성으로 표시하지 않는다. 버튼을 누르면 진행 표시 없이 바로 [ChecklistAdd 화면](./checklist-add.md)으로 이동한다.

## 목록

각 체크리스트는 카드로 표시한다. 카드에는 위에서부터 제목, 진행 글, 진행 막대를 이어서 표시한다. 설명과 체크 항목의 내용은 카드에 표시하지 않는다.

제목은 카드의 기본 글자 크기로 한 줄에 표시한다.

진행 글은 제목보다 작은 글씨와 본문 보조 색으로 `체크한 항목 수/전체 항목 수`를 공백 없이 숫자로 한 줄에 표시한다. 예: `3/5`. 체크 항목이 없으면 `0/0`을 표시한다. 숫자는 언어와 관계없이 같은 형식이다.

진행 막대는 카드 안쪽 폭을 모두 쓰는 Material 기본 직선형 진행 표시로, 전체 항목 수 가운데 체크한 항목 수의 비율만큼 채운다. 모두 체크하면 끝까지 채우고, 체크 항목이 없거나 하나도 체크하지 않았으면 채우지 않은 막대만 남긴다. 진행 정도가 바뀌면 막대는 진행 표시의 기본 애니메이션으로 새 비율까지 움직이고, 진행 글은 전환 효과 없이 바로 바뀐다. 막대는 진행 중임을 알리는 표시가 아니므로 움직이는 무한 진행 표현을 쓰지 않는다.

카드의 안쪽 여백은 [공통 스타일](./styles.md)의 `카드 내용`을 따르고, 제목과 진행 글 사이, 진행 글과 진행 막대 사이에는 각각 [카드 줄 간격](./dimens.md)을 둔다.

카드는 2열 고정 그리드로 배치한다. 모든 카드가 한 줄 제목, 한 줄 진행 글과 막대로 이루어져 높이가 같으므로 지그재그 격자를 쓰지 않는다. 목록 영역이 넓어지면 카드와 진행 막대가 함께 넓어진다.

카드를 누르면 진행 표시 없이 바로 그 체크리스트의 [ChecklistDetail 화면](./checklist-detail.md)으로 이동한다. 자리 표시 카드는 누를 수 없다.

## 삭제 스와이프

실행 취소로 돌아온 카드는 스와이프 전 진행 정도로 돌아온다.

## 자리 표시

이 목록의 자리 표시 카드는 제목, 진행 글과 진행 막대를 비워 두고, 준비된 카드와 같은 높이를 차지한다.

## 빈 상태

빈 상태에는 Material Symbols `checklist` 아이콘과 아래 `문구와 접근성`의 제목 문구·보조 문구를 사용한다.

## 새로고침

본문 전체가 체크리스트 목록 영역이므로 본문 전체를 당김 새로고침 컨테이너로 감싸고, 진행 표시는 본문 위쪽 가로 가운데에 둔다.

## 시스템 영역

상단 바는 상태 표시줄 영역을 피해 배치하고, 본문과 플로팅 액션 버튼, 스낵바는 내비게이션 바와 디스플레이 컷아웃 영역을 피해 배치한다. 입력이 없으므로 소프트 키보드를 고려한 배치는 두지 않는다.

## 문구와 접근성

한국어 환경과 그 외 기본 환경에서 다음 문구를 사용한다. 뒤로가기 접근성 이름과 실행 취소 동작은 [항목 목록 화면 공통 디자인](./entity-home.md)의 `문구와 접근성`을 따른다.

| 항목 | 한국어 | 그 외 기본 |
| --- | --- | --- |
| 상단 바 제목 | `체크리스트` | `Checklist` |
| 체크리스트 추가 버튼 접근성 이름 | `체크리스트 추가` | `Add checklist` |
| 진행 정도 접근성 설명 | `전체 {전체 항목 수}개 중 {체크한 항목 수}개 체크` | `{체크한 항목 수} of {전체 항목 수} checked` |
| 빈 상태 제목 문구 | `아직 체크리스트가 없습니다` | `No checklists yet` |
| 빈 상태 보조 문구 | `추가 버튼으로 새 체크리스트를 만들 수 있습니다` | `Use the add button to create a checklist.` |
| 삭제 안내 | `체크리스트가 삭제되었습니다.` | `Checklist deleted.` |
| 삭제 스와이프 아이콘 접근성 이름 | `체크리스트 삭제` | `Delete checklist` |

체크리스트 카드의 접근성 이름은 카드에 표시한 제목을 그대로 쓰고, 진행 정도는 `진행 정도 접근성 설명` 문구로 함께 읽는다. 화면에 보이는 진행 글 `3/5`와 진행 막대는 화면 낭독 도구가 따로 읽지 않아 같은 정보가 두 번 읽히지 않게 한다.
