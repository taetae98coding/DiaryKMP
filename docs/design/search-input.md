# 검색 입력 디자인

이 문서는 화면 위쪽에 두는 검색 입력의 해부구조, 조작, 표현을 소유한다. 어떤 화면에 검색을 두는지, 검색이 무엇을 찾고 결과를 어디에 어떻게 표시하는지는 그 검색을 쓰는 화면 디자인이 소유하고, 이 문서는 검색 입력 자체만 정한다.

이 문서는 이미 있는 검색의 표현만 다루고 사용자 행위나 제품 정책을 새로 정의하지 않으므로 기준 스펙을 두지 않는다.

## 적용 대상

화면 위쪽에서 그 화면의 내용을 찾는 검색 입력에 적용한다. 검색 입력은 접거나 펼치지 않고 늘 같은 자리에 활성 상태로 놓이며, 검색 결과는 그 화면의 본문에 그대로 표시한다.

검색을 진입점으로 접어 두고 눌러서 펼치는 표현은 두지 않는다. 펼친 검색은 표시 영역 전체를 덮는 별도의 창이어서, 목록과 상세를 좌우로 함께 표시하는 넓은 창에서 검색과 상관없는 영역까지 덮는다. 게다가 결과를 본문과 펼친 창이 각각 그려 같은 목록을 두 번 그린다. 검색 입력을 늘 두면 두 문제가 함께 사라지고, 사용자가 검색을 시작하려고 한 번 더 누를 일도 없다.

검색이 그 화면의 주된 일인지 보조 수단인지는 검색 입력의 표현을 가르지 않는다. 갈리는 것은 진입할 때 검색 입력에 초점을 두는지이며, 그것은 각 화면 스펙이 정한다.

다이얼로그 안에서 목록을 좁히는 입력은 이 문서의 대상이 아니다. 그 입력은 다이얼로그 내용의 일부이므로 각 다이얼로그 디자인이 소유한다.

## 해부구조

검색 입력은 다음 네 자리로 이루어진다.

| 자리 | 내용 |
| --- | --- |
| 컨테이너 | 좌우 끝이 완전히 둥근 알약 모양의 채운 면 |
| 시작 쪽 | 돋보기 아이콘 |
| 가운데 | 한 줄 입력과 자리 표시 문구 |
| 끝 쪽 | 지우기 버튼 |

컨테이너의 모양, 색, 높이는 Material 3 검색 바의 기본값을 그대로 쓰고 이 문서에서 수치를 정하지 않는다. 검색 입력이 놓이는 상단 바보다 한 단계 진한 면이므로, 상단 바 위에서 입력이 하나의 누를 수 있는 자리로 읽힌다.

입력 위에 별도의 라벨은 두지 않는다. 자리 표시 문구가 무엇을 찾는 자리인지 알린다.

### 시작 쪽

시작 쪽에는 돋보기 아이콘을 둔다. 이 아이콘은 검색 입력임을 알리는 장식이며 누를 수 없다.

### 화면을 떠나는 뒤로가기

화면을 떠나는 뒤로가기는 검색 입력 안에 두지 않고, 상단 바의 시작 쪽에서 검색 입력과 나란히 둔다. 검색 입력 안의 자리는 검색에 속한 동작만 갖고, 화면 사이를 옮기는 동작은 화면의 상단 바가 갖는다.

이때 뒤로가기 아이콘과 검색 입력의 돋보기 아이콘이 나란히 놓이지만, 하나는 상단 바 위의 누를 수 있는 버튼이고 다른 하나는 알약 안의 장식이므로 놓인 면으로 구분된다.

### 끝 쪽

입력한 값이 있으면 끝 쪽에 내용을 한 번에 지우는 지우기 버튼을 표시하고, 값이 비어 있으면 자리까지 함께 감춘다. 나타나고 사라지는 표현은 [나타나고 사라지는 버튼 디자인](./button-visibility.md)을 따른다.

지우기 버튼을 누르면 검색어만 지우고 초점은 검색 입력에 남긴다. 지운 사용자가 다음에 할 일은 다른 검색어를 넣는 것이므로 초점을 옮기지 않는다.

## 조작

입력한 값이 폭을 넘어도 줄을 늘리지 않고 한 줄을 유지하며, 커서가 있는 자리가 보이도록 입력 안에서 가로로 움직인다.

소프트 키보드는 일반 텍스트 키보드를 요청하고, 키보드의 동작 키는 검색으로 표시한다. 동작 키를 눌러도 검색을 다시 실행하지 않고 소프트 키보드만 닫는다. 검색은 입력만으로 스스로 적용되므로 사용자가 동작 키로 검색을 시작할 필요가 없다. 입력한 검색어가 결과에 반영되는 시점은 그 검색을 쓰는 화면의 기준 스펙이 정한다. SearchHome은 입력을 멈추면 반영하고, SettingHoliday는 입력하는 대로 반영한다.

포인터를 쓰는 환경에서 입력을 누르면 초점이 그 입력으로 옮겨 가고, 물리 키보드에서는 초점을 받은 입력에 바로 입력할 수 있다.

## 문구와 접근성

한국어 환경과 그 외 기본 환경에서 다음 문구를 사용한다.

| 문구 | 한국어 | 그 외 기본 |
| --- | --- | --- |
| 검색 입력 접근성 이름 | `검색` | `Search` |
| 검색 입력 상태 안내 | `아래의 추천 검색어` | `Suggestions below` |
| 지우기 버튼 접근성 이름 | `지우기` | `Clear text` |

검색 입력 접근성 이름과 상태 안내는 Material 3 검색 입력이 스스로 제공하는 문구이며 화면마다 바꾸지 않는다.

자리 표시 문구는 무엇을 찾는 자리인지 알리므로 화면마다 다르고, 각 화면 디자인이 소유한다. 이 문구는 화면과 낭독 도구 모두에 전달한다. 검색 입력이 제공하는 이름은 `검색` 하나뿐이어서 무엇을 찾는지 알리지 못하므로, 자리 표시 문구를 낭독에서 지우면 낭독 도구를 쓰는 사용자에게 검색 대상이 남지 않는다.

돋보기 아이콘에는 접근성 이름을 두지 않는다. 누를 수 없는 장식이고 검색 입력이 이미 이름을 제공한다.

상단 바의 뒤로가기 버튼은 아이콘만 표시하므로 [아이콘 버튼 설명 디자인](./icon-button-tooltip.md)의 설명 표시를 함께 둔다.
