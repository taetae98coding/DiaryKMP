# 설명 입력 컴포넌트 디자인

기준 스펙: [설명 입력 컴포넌트 스펙](../spec/description-input.md)

## 구성

컴포넌트는 위에서부터 탭 행과 페이지 영역을 세로로 쌓아 하나의 카드 안에 담는다.

페이지 영역은 좌우로 넘길 수 있는 두 개의 페이지로 구성한다.

- 첫 번째 페이지: 설명을 입력하는 입력 페이지
- 두 번째 페이지: 입력한 설명을 마크다운으로 보여 주는 미리보기 페이지

컴포넌트가 처음 표시될 때 어느 페이지부터 보여 줄지는 스펙의 `domain > 첫 표시 상태`가 정한다. 채워진 설명이 없으면 입력 페이지를, 채워진 설명이 있으면 미리보기 페이지를 애니메이션 없이 곧바로 보여 주고, 탭 행에서는 보여 주는 페이지의 탭이 선택된 상태로 표시한다.

컴포넌트의 높이는 탭 행 높이와 페이지 높이를 더한 값이다.

## 탭 행

카드 최상단에 탭 행을 표시한다. 탭 행은 카드의 가로 폭을 모두 차지하고, `입력` 탭과 `미리보기` 탭이 왼쪽부터 순서대로 폭을 균등하게 나눠 가진다. 탭 순서는 페이지 순서와 같게 둔다.

각 탭은 아이콘만 표시하고 라벨 문구는 두지 않는다. 입력 탭은 연필 아이콘을, 미리보기 탭은 번개 아이콘을 사용한다. 선택된 탭의 강조 표시는 Material 기본 탭 표현을 따른다.

## 페이지 전환

사용자는 다음 두 가지 방법으로 입력 페이지와 미리보기 페이지를 오간다.

- 탭 행에서 보고 싶은 페이지의 탭을 선택한다. 페이지 영역이 선택한 페이지로 가로로 미끄러지며 전환된다.
- 페이지 영역 위에서 좌우로 스와이프한다. 왼쪽으로 스와이프하면 미리보기 페이지로, 오른쪽으로 스와이프하면 입력 페이지로 이동한다.

이미 보고 있는 페이지의 탭을 다시 선택하면 아무 변화도 일어나지 않는다.

선택된 탭 표시는 항상 보고 있는 페이지를 가리킨다. 스와이프하는 동안에는 손을 떼었을 때 도달할 페이지가 정해지는 시점에 선택된 탭 표시가 함께 바뀌고, 전환 애니메이션이 끝날 때까지 기다리지 않는다.

## 입력 페이지

`설명` 라벨이 붙은 입력 칸 하나를 표시한다.

입력 칸은 10줄 높이로 시작하고, 입력한 내용이 그보다 길어지면 최대 20줄 높이까지 늘어난다. 내용이 20줄을 넘으면 더 늘리지 않고 입력 칸 안에서 세로로 스크롤해 볼 수 있게 한다.

입력 칸에 내용이 있으면 지우기 버튼을 표시하고, 내용이 없으면 표시하지 않는다. 나타나고 사라지는 표현은 [나타나고 사라지는 버튼 디자인](./button-visibility.md)을 따른다. 지우기 버튼을 선택하면 입력 내용을 모두 지운다.

## 미리보기 페이지

입력한 설명을 마크다운 문법으로 해석한 결과를 표시한다. 해석한 결과와 카드 가장자리 사이에는 [카드 안쪽 여백](./dimens.md)을 둔다.

미리보기 페이지의 높이는 입력 페이지와 같게 한다. 입력 칸이 내용에 따라 늘어나므로 미리보기 높이도 함께 달라지며, 해석된 결과가 그 높이를 넘으면 미리보기 페이지 안에서 세로로 스크롤해 볼 수 있게 한다.

### 제목 크기

Material 기본 제목 표현은 카드 안 미리보기에 비해 지나치게 커서, 제목(h1~h6)은 기본 스타일에서 글자 크기와 줄 높이만 줄여 표시한다. 본문(16sp)과의 위계가 유지되도록 h1부터 h6까지 순서대로 작아진다.

| 제목 | 글자 크기 | 줄 높이 |
| --- | --- | --- |
| h1 | 28sp | 36sp |
| h2 | 24sp | 32sp |
| h3 | 22sp | 30sp |
| h4 | 20sp | 28sp |
| h5 | 18sp | 26sp |
| h6 | 16sp | 24sp |

## 접근성

탭은 아이콘만 표시하므로 각 탭 아이콘에 접근성 이름을 둔다. 선택된 탭은 선택 상태로 읽히게 한다.

| 접근성 이름 | 한국어 | 그 외 기본 |
| --- | --- | --- |
| 입력 탭 | `입력` | `Input` |
| 미리보기 탭 | `미리보기` | `Preview` |
