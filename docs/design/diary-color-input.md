# DiaryColorInput 컴포넌트 디자인

기준 스펙: [컬러 입력 컴포넌트 스펙](../spec/client/diary-color-input.md)

## 컬러 카드

DiaryColorInput은 가로 폭을 모두 차지하는 카드 형태로 표시하고, 모서리는 Material 기본 중간 크기 모양으로 둥글린다. 카드 전체가 누를 수 있는 영역이다.

카드 가운데에는 현재 선택된 컬러를 두 줄로 표시한다.

- 첫째 줄: Hex 코드를 `#FFFFFF` 형식으로, 강조한 중간 크기 제목 글자로 표시
- 둘째 줄: R, G, B 채널 값을 `RGB(255, 255, 255)` 형식으로, 작은 라벨 글자로 표시

카드 가장자리와 두 줄 사이에는 [카드 안쪽 여백](./dimens.md)을 둔다.

카드 배경은 현재 선택된 컬러로 채운다. Hex 코드와 RGB 값은 배경 밝기에 따라 검정 또는 흰색으로 표시한다.

## 컬러 선택 다이얼로그

사용자가 카드를 누르면 현재 선택된 컬러가 반영된 컬러 선택 다이얼로그를 연다.

다이얼로그에는 제목 없이 다음을 표시한다.

- 편집 중인 컬러로 칠한 미리보기 영역
- 미리보기 가운데의 Hex 코드 입력 칸. 라벨과 밑줄 없이 한 줄로 가운데 정렬해 입력한다.
- 미리보기 오른쪽 위의 무작위 컬러 버튼. 새로고침 모양 아이콘만 표시한다.
- R, G, B 각 채널을 조절하는 슬라이더 세 개와 각 채널의 현재 값
- 취소 버튼과 확인 버튼

미리보기 영역은 다이얼로그 맨 위에서 여백 없이 가로를 가득 채우고 높이는 `140dp`다. 무작위 컬러 버튼은 미리보기의 위쪽과 끝 쪽 가장자리에서 `8dp` 떨어뜨린다.

슬라이더 세 개는 좌우 `24dp`, 위아래 `8dp` 여백 안에 `8dp` 간격으로 쌓고, 각 슬라이더 줄의 채널 이름, 슬라이더, 현재 값 사이에는 `8dp`를 둔다. 취소 버튼과 확인 버튼은 다이얼로그의 끝 쪽에 `8dp` 간격으로 두고, 좌우 `24dp`, 아래 `16dp` 여백을 둔다.

미리보기 위의 Hex 입력 글자와 무작위 컬러 버튼은 미리보기 컬러의 밝기에 따라 검정 또는 흰색으로 표시한다.

### 슬라이더 조절

R, G, B 슬라이더를 움직이면 미리보기와 Hex 입력을 조절된 컬러로 함께 갱신한다.

Hex 입력에 유효한 코드를 입력하면 미리보기와 세 슬라이더를 입력한 컬러로 함께 갱신한다. 슬라이더는 기존 채널 값에서 입력한 컬러의 채널 값으로 부드럽게 전환한다.

유효하지 않은 내용이 입력된 동안에는 미리보기와 슬라이더가 마지막으로 유효했던 컬러를 유지한다.

### 무작위 컬러

무작위 컬러 버튼을 선택하면 미리보기, 세 슬라이더, Hex 입력을 무작위로 정한 컬러로 함께 갱신한다. 슬라이더는 기존 채널 값에서 새 채널 값으로 부드럽게 전환한다.

### 확인과 취소

확인 버튼을 선택하면 다이얼로그를 닫고 스펙에서 정한 컬러를 카드에 반영한다. 카드 배경은 기존 컬러에서 편집한 컬러로 부드럽게 전환한다.

취소 버튼, 다이얼로그 바깥 영역 선택, 시스템 뒤로가기로 닫으면 편집을 취소한다.

## 색상 대비

카드의 Hex 코드와 RGB 값, 다이얼로그 미리보기 위의 글자와 커서, 버튼은 배경 컬러의 밝기를 기준으로 색을 정한다. 배경의 상대 휘도가 `0.5` 이상이면 검정, 그보다 어두우면 흰색을 사용한다.

R, G, B 채널 이름은 각각 빨강, 초록, 파랑으로 표시하되 밝은 테마와 어두운 테마에서 읽을 수 있는 톤을 사용한다. 밝은 테마는 Material 3 기준 팔레트의 tone 40, 어두운 테마는 tone 80 계열이다.

| 채널 | 밝은 테마 | 어두운 테마 |
| --- | --- | --- |
| R | `#B3261E` | `#F2B8B5` |
| G | `#386A20` | `#9CD67D` |
| B | `#0B57D0` | `#A8C7FA` |

## 문구

| 문구 | 한국어 | 그 외 기본 |
| --- | --- | --- |
| 취소 버튼 | `취소` | `Cancel` |
| 확인 버튼 | `확인` | `Confirm` |
| 무작위 컬러 버튼 접근성 이름 | `무작위 컬러` | `Random color` |

R, G, B 채널 이름은 언어와 관계없이 `R`, `G`, `B`로 표시한다.
