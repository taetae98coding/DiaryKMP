# DiaryDateTimeInput 컴포넌트 디자인

기준 스펙: [DiaryDateTimeInput 컴포넌트 스펙](../spec/diary-date-time-input.md)

## 구성

컴포넌트는 카드 형태로 표시한다. 상단에는 날짜·시간 라벨과 사용 여부를 전환하는 스위치를 한 줄로 배치한다.

스위치가 꺼져 있으면 기간 선택 영역을 표시하지 않는다. 스위치가 켜져 있으면 스위치 아래에 다음을 차례로 표시한다.

- 종일 여부를 선택하는 체크박스와 종일 라벨
- 시작 라벨과 시작 값
- 종료 라벨과 종료 값

상단 한 줄과 기간 선택 영역은 좌우에 [카드 안쪽 여백](./dimens.md)을 두고, 기간 선택 영역 아래에는 `8dp` 여백을 둔다.

## 사용 여부 전환

날짜·시간 라벨과 스위치가 배치된 상단 한 줄은 카드의 좌우 가장자리까지 전체 너비를 차지하고 기본 최소 조작 크기를 보장한다. 이 영역의 어느 곳을 눌러도 사용 여부를 전환한다.

스위치를 켜면 기간 선택 영역을 아래로 펼치며 점차 나타낸다.

스위치를 끄면 기간 선택 영역을 즉시 조작할 수 없게 하고, 위로 줄이며 점차 사라지게 한 뒤 표시하지 않는다.

## 종일 여부 전환

종일 체크박스와 라벨은 `8dp` 간격을 두고 한 줄로 표시한다. 이 한 줄은 내용 주변의 좌우 여백 `8dp`까지 조작 영역에 포함하고 기본 최소 조작 크기를 보장한다. 이 영역의 어느 곳을 눌러도 종일 여부를 전환하며 원형 터치 피드백을 표시한다.

종일이면 시작 값과 종료 값에 날짜만 표시한다.

종일이 아니면 시작 값과 종료 값에 날짜와 시간을 함께 표시하며, 시간 값은 옆으로 펼치며 점차 나타낸다.

종일로 전환하면 시간 값을 즉시 조작할 수 없게 하고, 옆으로 줄이며 점차 사라지게 한 뒤 표시하지 않는다.

## 날짜 선택

시작 또는 종료 날짜를 누르면 누른 항목의 현재 날짜가 선택된 날짜 선택 다이얼로그를 표시한다.

날짜를 고르고 확인을 누르면 다이얼로그를 닫고 해당 날짜를 반영한다. 취소를 누르거나 다이얼로그 바깥을 눌러 닫으면 기존 값을 유지한다.

## 시간 선택

종일이 아닐 때 시작 또는 종료 시간을 누르면 누른 항목의 현재 시간이 선택된 시간 선택 다이얼로그를 표시한다.

다이얼로그는 시계 위에 실행 환경이 제공하는 기본 제목을 표시한다.

다이얼로그의 시계는 기기의 시간 형식 설정을 따른다. 기기가 12시간제이면 오전·오후를 함께 고르는 시계로, 24시간제이면 오전·오후 없는 시계로 표시한다.

시간을 고르고 확인을 누르면 다이얼로그를 닫고 해당 시간을 반영한다. 취소를 누르거나 다이얼로그 바깥을 눌러 닫으면 기존 값을 유지한다.

## 값 변경 전환

날짜 또는 시간 값이 바뀔 때 새 값이 이전 값보다 나중 날짜 또는 늦은 시간이면 아래에서 위로, 이전 날짜 또는 이른 시간이면 위에서 아래로 움직이며 표시한다.

## 표시 형식

날짜와 시간은 사용자의 언어에 맞는 형식으로 표시한다.

| 값 | 한국어 | 그 외 기본 |
| --- | --- | --- |
| 날짜 | `2026. 7. 19.` | `Jul 19, 2026` |
| 시간 | `오후 1:30` | `1:30 PM` |

날짜의 월과 일, 시간의 시는 앞자리를 `0`으로 채우지 않고, 시간의 분은 항상 두 자리로 표시한다.

시간은 두 언어 모두 12시간제로 표시한다. 자정은 `오전 12:00`과 `12:00 AM`, 정오는 `오후 12:00`과 `12:00 PM`으로 표시한다.

이 표시 형식은 시간 선택 다이얼로그의 시계 형식과 무관하다. 기기가 24시간제로 설정되어 있어도 고른 값은 위 표의 12시간제 형식으로 표시한다.

날짜 선택 다이얼로그가 고른 날짜를 다시 보여 주는 문구는 이 표시 형식을 따르지 않고 실행 환경이 제공하는 기본 형식을 그대로 사용한다. 예를 들어 한국어 환경에서 시작 값이 `2026. 7. 19.`로 표시되는 동안 다이얼로그 문구는 `2026년 7월 19일`로 표시될 수 있다.

## 문구

| 문구 | 한국어 | 그 외 기본 |
| --- | --- | --- |
| 날짜·시간 라벨 | `날짜·시간` | `Date & time` |
| 종일 라벨 | `종일` | `All day` |
| 시작 라벨 | `시작` | `Start` |
| 종료 라벨 | `종료` | `End` |
| 다이얼로그 확인 | `확인` | `OK` |
| 다이얼로그 취소 | `취소` | `Cancel` |
| 월 이름 | 숫자 그대로 (`7`) | 세 글자 약어 (`Jul`) |
| 정오 이전 | `오전` | `AM` |
| 정오 이후 | `오후` | `PM` |
