# WebHome 화면 디자인

기준 스펙: [WebHome 화면 스펙](../spec/client/web-home.md), [새로고침 스펙](../spec/client/sync-refresh.md), [페이지 조회 목록의 자리 표시 스펙](../spec/client/paged-list-placeholder.md), [목록 빈 상태 스펙](../spec/client/list-empty-state.md)

화면 구조, 추가 버튼, 카드 조작, 삭제 스와이프, 자리 표시·빈 상태·새로고침, 격자와 시스템 영역, 추가 단축키의 공통 표현은 [항목 목록 화면 공통 디자인](./entity-home.md)을 따른다. 이 문서는 WebHome에서만 다른 표현을 다룬다.

## 화면 구조

창 너비에 따라 단독으로 표시하거나 [Web 목록·상세 배치 디자인](./web-list-detail.md)에 따라 [WebAdd 화면](./web-add.md)과 자리를 나눠 표시한다. 목록과 [WebDetail 화면](./web-detail.md)을 함께 표시하는 배치는 두지 않는다.

상단 바에는 검색 버튼을 두고 다른 액션은 두지 않는다.

본문은 위에서부터 정렬 줄과 웹 목록 영역으로 채운다.

## 검색 진입

상단 바의 끝 쪽에 검색 아이콘 버튼을 하나 배치한다. 검색을 액션의 첫 자리에 두는 것은 [MemoHome 목록 디자인](./memo-home.md), [TagHome 목록 디자인](./tag-home.md), [PlaceHome 화면 디자인](./place-home.md)도 같으므로, 사용자는 어느 화면에서도 같은 자리에서 검색을 찾는다.

버튼에는 돋보기 아이콘만 표시하고 라벨, 배지, 숫자는 표시하지 않으며 기본 상단 바 아이콘 색을 사용한다.

버튼을 누르면 [SearchHome 화면](./search-home.md)을 창 너비와 관계없이 단독으로 표시하고, 웹 탭이 선택된 상태로 시작한다.

## 정렬 줄

정렬 줄은 상단 바 바로 아래, 웹 목록 위에 둔다. 정렬 줄과 정렬 선택 Bottom Sheet의 구조, 조작, 아이콘과 문구는 [목록 정렬 디자인](./list-sort.md)을 따른다.

## 목록

각 웹 항목은 카드로 표시한다. 카드에는 제목과 URL을 위아래로 이어서 표시하고, 제목을 위에 둔다. 설명과 요청 헤더는 카드에 표시하지 않는다.

제목은 카드의 기본 글자 크기로, URL은 제목보다 작은 글씨로 표시한다.

카드의 안쪽 여백은 [공통 스타일](./styles.md)의 `카드 내용`을 따르고, 제목·URL 두 줄 사이에는 [카드 줄 간격](./dimens.md)을 둔다. 웹 항목에는 저장된 컬러가 없으므로 장소 카드의 컬러 원형 표시에 해당하는 요소는 두지 않고, 그 자리를 비워 두지도 않는다.

카드는 2열 고정 그리드로 배치한다. 제목과 URL이 모두 한 줄이어서 카드 높이가 서로 같으므로 지그재그 격자를 쓰지 않는다.

카드를 누르면 그 웹 항목의 [WebDetail 화면](./web-detail.md)으로 이동한다.

## 자리 표시

이 목록의 자리 표시 카드는 제목과 URL을 비워 두고, 준비된 카드와 같은 높이를 차지한다.

## 빈 상태

빈 상태에는 웹 아이콘과 아래 `문구와 접근성`의 제목 문구·보조 문구를 사용한다.

빈 상태에서도 상단 바의 검색 버튼은 같은 자리에 같은 모양으로 표시하고 비활성 표현을 사용하지 않는다.

## 새로고침

웹 목록 영역만 당김 새로고침 컨테이너로 감싼다. 정렬 줄은 감싸지 않으므로 정렬 줄을 세로로 끌어도 새로고침이 시작되지 않는다.

진행 표시는 본문 위쪽에, 플로팅 액션 버튼은 본문 오른쪽 아래에 놓이므로 두 요소는 겹치지 않는다.

## 문구와 접근성

한국어 환경과 그 외 기본 환경에서 다음 문구를 사용한다. 뒤로가기 접근성 이름과 실행 취소 동작은 [항목 목록 화면 공통 디자인](./entity-home.md)의 `문구와 접근성`을 따른다.

| 항목 | 한국어 | 그 외 기본 |
| --- | --- | --- |
| 상단 바 제목 | `웹` | `Web` |
| 검색 버튼 접근성 이름 | `검색` | `Search` |
| 웹 추가 버튼 접근성 이름 | `웹 추가` | `Add web` |
| 빈 상태 제목 문구 | `아직 웹이 없습니다` | `No webs yet` |
| 빈 상태 보조 문구 | `추가 버튼으로 새 웹을 만들 수 있습니다` | `Use the add button to create a web.` |
| 삭제 안내 | `웹이 삭제되었습니다.` | `Web deleted.` |
| 삭제 스와이프 아이콘 접근성 이름 | `웹 삭제` | `Delete web` |

웹 카드에는 카드가 누를 수 있는 요소임을 알리는 별도의 접근성 이름을 두지 않고, 카드에 표시한 제목과 URL을 접근성 이름으로 그대로 쓴다.
