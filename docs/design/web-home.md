# WebHome 화면 디자인

기준 스펙: [WebHome 화면 스펙](../spec/client/web-home.md), [새로고침 스펙](../spec/client/sync-refresh.md), [페이지 조회 목록의 자리 표시 스펙](../spec/client/paged-list-placeholder.md), [목록 빈 상태 스펙](../spec/client/list-empty-state.md)

## 화면 구조

WebHome 화면은 `더보기`에서 이어지는 세부 화면이며, 공통 내비게이션 영역은 [TopLevelNavigation 디자인](./top-level-navigation.md)에 따라 숨긴다. 창 너비에 따라 단독으로 표시하거나 [Web 목록·상세 배치 디자인](./web-list-detail.md)에 따라 [WebAdd 화면](./web-add.md)과 자리를 나눠 표시한다.

화면 상단에는 제목과 뒤로가기 동작, 검색 버튼이 있는 상단 바를 표시한다. 상단 바에는 다른 액션을 두지 않는다.

본문 전체는 웹 목록 영역 하나로 채우고, 오른쪽 아래에 웹 추가를 실행하는 플로팅 액션 버튼을 겹쳐 표시한다. 버튼에는 추가를 뜻하는 더하기 아이콘을 표시하고, 목록의 상태와 관계없이 같은 자리에 같은 모양으로 표시한다. 버튼의 노출 조건은 [목록·상세 배치 공통 디자인](./list-detail-pane.md)의 `버튼 노출`을 따른다.

공통 내비게이션 영역의 노출은 [TopLevelNavigation 디자인](./top-level-navigation.md)의 `세부 화면에서의 노출`을 따른다.

## 검색 진입

상단 바의 끝 쪽에 검색 아이콘 버튼을 하나 배치한다. 검색을 액션의 첫 자리에 두는 것은 [MemoHome 목록 디자인](./memo-home.md), [TagHome 목록 디자인](./tag-home.md), [PlaceHome 화면 디자인](./place-home.md)도 같으므로, 사용자는 어느 화면에서도 같은 자리에서 검색을 찾는다.

버튼에는 돋보기 아이콘만 표시하고 라벨, 배지, 숫자는 표시하지 않으며 기본 상단 바 아이콘 색을 사용한다.

버튼을 누르면 [SearchHome 화면](./search-home.md)을 창 너비와 관계없이 단독으로 표시하고, 웹 탭이 선택된 상태로 시작한다.

## 정렬 줄

정렬 줄은 상단 바 바로 아래, 웹 목록 위에 둔다. 정렬 줄과 정렬 선택 Bottom Sheet의 구조, 조작, 아이콘과 문구는 [목록 정렬 디자인](./list-sort.md)을 따른다.

## 목록

각 웹 항목은 카드로 표시한다. 카드에는 제목과 URL을 위아래로 이어서 표시하고, 제목을 위에 둔다. 설명과 요청 헤더는 카드에 표시하지 않는다.

제목은 카드의 기본 글자 크기로, URL은 제목보다 작은 글씨로 표시한다. 두 줄 모두 각각 한 줄을 유지하며, 카드에서 사용할 수 있는 폭을 넘으면 기본 이동 속도와 간격으로 가로 이동을 시작하고 카드가 표시되는 동안 횟수 제한 없이 반복한다. 접근성에는 생략하지 않은 전체 제목과 전체 URL을 제공한다.

카드의 안쪽 여백은 [공통 스타일](./styles.md)의 `카드 내용`을 따르고, 제목·URL 두 줄 사이에는 [카드 줄 간격](./dimens.md)을 둔다. 웹 항목에는 저장된 컬러가 없으므로 장소 카드의 컬러 원형 표시에 해당하는 요소는 두지 않고, 그 자리를 비워 두지도 않는다.

카드는 화면 너비와 관계없이 한 행에 두 개씩 표시되는 2열 고정 그리드로 배치하고, 카드 사이에는 가로와 세로로 각각 [공통 항목 간격](./dimens.md)을 둔다. 격자 바깥 여백은 [공통 화면 가로 여백과 세로 여백](./dimens.md)을 따른다. 제목과 URL이 모두 한 줄이어서 카드 높이가 서로 같으므로 지그재그 격자를 쓰지 않는다.

카드 전체를 누를 수 있는 자리로 둔다. 누르는 동안에는 카드에 기본 눌림 표현만 두고, 누른 뒤 카드를 선택된 상태로 남기는 표시는 두지 않는다. 카드를 누르면 그 웹 항목의 [WebDetail 화면](./web-detail.md)으로 이동한다.

## 삭제 스와이프

사용자는 웹 카드를 오른쪽에서 왼쪽으로 스와이프해 삭제한다. 웹 항목에는 완료 여부가 없으므로 왼쪽에서 오른쪽으로 미는 조작에는 반응하지 않는다.

스와이프 중 상태 아이콘, 삭제 기준, 취소와 비활성 표현은 [SwipeToFinishAndDelete 컴포넌트 디자인](./swipe-to-finish-and-delete.md)을 따른다. 자리 표시 카드는 스와이프가 시작되지 않는다.

삭제가 성립하면 카드를 격자에서 없애고, 결과 안내와 실행 취소 동작을 스낵바로 표시한다. 실행 취소 동작이 있는 스낵바는 Material 기본의 긴 표시 시간을 쓴다. 이미 보이는 스낵바가 있으면 표시 시간이 지나기를 기다리지 않고 즉시 새 안내로 바꾼다. 스낵바는 플로팅 액션 버튼에 가리지 않는 자리에 둔다. 표현은 [MemoHome 목록 디자인](./memo-home.md)의 완료·삭제 스낵바와 같다.

삭제가 저장되지 못하면 스낵바를 표시하지 않는다.

실행 취소로 돌아온 카드는 스와이프 전 모양으로 정렬 기준에 맞는 자리에 다시 나타난다.

목록이 갱신될 때 카드가 자리를 옮기면 기본 항목 이동 애니메이션으로 옮긴다.

## 자리 표시

아직 준비되지 않은 자리에는 [페이지 조회 목록의 자리 표시 디자인](./paged-list-placeholder.md)에 따라 자리 표시 카드를 표시한다. 이 목록의 자리 표시 카드는 제목과 URL을 비워 두고, 준비된 카드와 같은 높이를 차지한다.

## 빈 상태

표시할 웹 항목이 하나도 없으면 격자 자리에 [목록 빈 상태 디자인](./list-empty-state.md)의 빈 상태를 표시한다. 이 목록은 웹 아이콘과 아래 `문구와 접근성`의 제목 문구·보조 문구를 사용하며, 격자와 빈 상태 사이의 전환도 그 문서를 따른다.

빈 상태에서도 상단 바의 검색 버튼은 같은 자리에 같은 모양으로 표시하고, 플로팅 액션 버튼을 표시하는 동안에는 그 버튼도 같은 자리에 같은 모양으로 둔다. 어느 버튼에도 비활성 표현을 사용하지 않는다.

## 새로고침

본문 전체가 웹 목록 영역이므로 본문 전체를 [새로고침 디자인](./sync-refresh.md)의 당김 새로고침 컨테이너로 감싼다.

진행 표시는 본문 위쪽 가로 가운데에 겹쳐 표시하고 격자를 밀어내지 않는다. 진행 표시의 모양과 크기, 임계값, 나타나고 사라지는 모션, 진행 중 조작 가능 여부는 [새로고침 디자인](./sync-refresh.md)을 그대로 따르며 이 화면에서 따로 정하지 않는다.

격자는 맨 위에 있을 때만 당김이 시작된다. 격자 대신 빈 상태를 표시하는 동안에는 스크롤할 것이 없으므로 당김이 곧바로 시작된다.

진행 표시는 본문 위쪽에, 플로팅 액션 버튼은 본문 오른쪽 아래에 놓이므로 두 요소는 겹치지 않는다. 진행 표시가 나타나 있는 동안에도 카드를 누르거나 스와이프해 삭제하고 목록을 스크롤하고 웹 추가 버튼과 검색 버튼, 뒤로가기를 누르는 조작을 그대로 할 수 있으며, 어떤 요소도 비활성으로 표시하지 않는다.

## 적응형 배치

격자는 창 너비, 창 높이와 자세에 관계없이 2열을 유지하므로 목록 영역이 넓어지면 카드가 함께 넓어진다. 목록이 [WebAdd 화면](./web-add.md)과 자리를 나눠 쓰는 배치와 그 자리에서의 버튼 노출은 [Web 목록·상세 배치 디자인](./web-list-detail.md)이 정하며, 목록과 [WebDetail 화면](./web-detail.md)을 함께 표시하는 배치는 두지 않는다.

본문은 시스템 상태 영역과 디스플레이 컷아웃에 가려지지 않는 자리에 두고, 격자의 마지막 카드가 플로팅 액션 버튼에 가리지 않게 배치한다.

## 문구와 접근성

한국어 환경과 그 외 기본 환경에서 다음 문구를 사용한다.

| 항목 | 한국어 | 그 외 기본 |
| --- | --- | --- |
| 상단 바 제목 | `웹` | `Web` |
| 뒤로가기 접근성 이름 | `뒤로가기` | `Navigate up` |
| 검색 버튼 접근성 이름 | `검색` | `Search` |
| 웹 추가 버튼 접근성 이름 | `웹 추가` | `Add web` |
| 빈 상태 제목 문구 | `아직 웹이 없습니다` | `No webs yet` |
| 빈 상태 보조 문구 | `추가 버튼으로 새 웹을 만들 수 있습니다` | `Use the add button to create a web.` |
| 삭제 안내 | `웹이 삭제되었습니다.` | `Web deleted.` |
| 실행 취소 동작 | `실행 취소` | `Undo` |
| 삭제 스와이프 아이콘 접근성 이름 | `웹 삭제` | `Delete web` |

웹 카드에는 카드가 누를 수 있는 요소임을 알리는 별도의 접근성 이름을 두지 않고, 카드에 표시한 제목과 URL을 접근성 이름으로 그대로 쓴다. 자리 표시 카드의 접근성 처리는 [페이지 조회 목록의 자리 표시 디자인](./paged-list-placeholder.md)을 따른다.
