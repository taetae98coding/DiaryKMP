# SettingHome 화면 디자인

기준 스펙: [SettingHome 화면 스펙](../spec/setting-home.md)

## 화면 구조

SettingHome의 단독·목록/상세 배치와 표시 상태에 따른 뒤로가기 동작 노출은 [Setting 목록·상세 배치 디자인](./setting-list-detail.md)을 따른다.

화면 상단에는 제목과 뒤로가기 동작이 있는 상단 바를 둔다.

본문에는 설정 항목을 세로 목록으로 배치하고, 배경과 모양, 항목 사이 간격, 누름 상태의 표현은 [묶음 목록 항목 디자인](./segmented-list-item.md)을 따른다.

각 항목에는 설정 이름 문구만 두고 아이콘이나 보조 문구를 두지 않는다. 항목을 선택하면 그 설정의 세부 화면으로 이동하므로 선택 상태로 남는 항목은 없다.

항목과 순서는 기준 스펙을 따른다. 현재 환경에서 제공하는 항목을 확인하기 전에는 목록을 자리까지 함께 표시하지 않고 상단 바만 남기며, 별도의 로딩 안내나 오류 안내도 표시하지 않는다.

## 문구와 접근성

한국어 환경과 그 외 기본 환경에서는 다음 문구를 사용한다.

| 문구 | 한국어 | 그 외 기본 |
| --- | --- | --- |
| 상단 바 제목 | `설정` | `Settings` |
| 뒤로가기 접근성 이름 | `뒤로가기` | `Navigate up` |
| 공휴일 항목 이름 | `공휴일` | `Holiday` |
| 지도 항목 이름 | `지도` | `Map` |
| Gemini 항목 이름 | `Gemini` | `Gemini` |
| 브라우저 항목 이름 | `브라우저` | `Browser` |
| 다운로드 항목 이름 | `다운로드` | `Download` |
