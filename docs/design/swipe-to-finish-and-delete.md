# SwipeToFinishAndDelete 컴포넌트 디자인

기준 스펙: [SwipeToFinishAndDelete 컴포넌트 스펙](../spec/swipe-to-finish-and-delete.md)

## 스와이프 제스처

카드를 왼쪽에서 오른쪽으로 스와이프하면 진행 상태를 바꾸는 동작을, 오른쪽에서 왼쪽으로 스와이프하면 삭제 동작을 선택한다.

스와이프가 실행 기준을 넘으면 해당 방향의 동작을 실행한다. 기준을 넘기 전에 손을 떼면 카드를 원래 자리로 되돌린다.

비활성화된 카드는 좌우 스와이프에 움직이지 않는다.

## 상태 아이콘과 전환

스와이프하는 동안 카드 뒤의 스와이프 방향 쪽에 상태 아이콘을 표시한다.

카드를 절반 넘게 스와이프하기 전에는 원형 아이콘을 표시하고, 절반을 넘으면 방향에 해당하는 동작 아이콘으로 애니메이션 전환한다. 반대 방향의 동작 아이콘은 함께 표시하지 않는다.

## 방향별 아이콘과 접근성 이름

시작 방향의 동작 아이콘과 접근성 이름은 이 컴포넌트를 사용하는 화면에서 항목과 동작에 맞게 지정한다.

미완료 항목을 보여 주는 목록에서는 방패에 체크가 들어간 완료 아이콘을, 완료된 항목을 보여 주는 목록에서는 화살표가 원을 그리는 다시 시작 아이콘을 사용한다.

끝 방향에는 화면과 관계없이 삭제 아이콘을 사용하고, 접근성 이름만 항목에 맞게 지정한다.

| 사용 화면 | 시작 방향 접근성 이름 | 끝 방향 접근성 이름 |
| --- | --- | --- |
| MemoHome, TagDetail 메모 탭 | `메모 완료` | `메모 삭제` |
| MemoFinishedList, TagMemoFinishedList | `메모 다시 시작` | `메모 삭제` |
