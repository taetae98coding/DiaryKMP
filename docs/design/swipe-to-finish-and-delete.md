# SwipeToFinishAndDelete 컴포넌트 디자인

기준 스펙: [SwipeToFinishAndDelete 컴포넌트 스펙](../spec/client/swipe-to-finish-and-delete.md)

## 스와이프 제스처

카드를 왼쪽에서 오른쪽으로 스와이프하면 진행 상태를 바꾸는 동작을, 오른쪽에서 왼쪽으로 스와이프하면 삭제 동작을 선택한다.

진행 상태를 바꾸는 동작이 없는 목록에서는 오른쪽에서 왼쪽으로 스와이프하는 삭제만 두고, 왼쪽에서 오른쪽으로 미는 조작에는 카드가 움직이지 않는다.

손을 뗀 위치가 원래 자리에서 `56dp` 이상 벗어났거나 카드를 그 방향으로 빠르게 밀어 던지면 실행 기준을 넘은 것으로 보고, 카드를 그 방향 끝까지 밀어낸 뒤 해당 방향의 동작을 실행한다. 기준을 넘기 전에 손을 떼면 카드를 원래 자리로 되돌린다. 기준 거리와 던지는 속도는 Material 3 스와이프로 치우기의 기본값을 따른다.

비활성화된 카드는 좌우 스와이프에 움직이지 않는다. 내용이 준비되지 않은 자리 표시 카드가 그렇다.

스와이프 동작은 손가락이나 포인터로 끄는 조작으로만 제공하며, 키보드나 화면 낭독 도구에서 실행하는 별도 동작은 두지 않는다.

## 상태 아이콘과 전환

스와이프하는 동안 카드 뒤의 스와이프 방향 쪽에 상태 아이콘을 표시한다.

카드를 절반 넘게 스와이프하기 전에는 원형 아이콘을 표시하고, 절반을 넘으면 방향에 해당하는 동작 아이콘으로 크기와 투명도를 함께 바꾸며 교차 전환한다. 원형 아이콘에서 동작 아이콘으로 바뀌는 지점은 실행 기준과 별개이므로, 원형 아이콘이 보이는 동안 손을 떼도 실행 기준을 넘었으면 동작을 실행한다. 반대 방향의 동작 아이콘은 함께 표시하지 않는다.

상태 아이콘은 `32dp` 정사각형 자리의 가운데에 두고, 원형 아이콘은 그 안에 `16dp` 크기로 표시한다. 상태 아이콘 자리는 카드 뒤 좌우 끝에서 `16dp` 안쪽에 둔다.

## 방향별 아이콘과 접근성 이름

시작 방향의 동작 아이콘과 접근성 이름은 이 컴포넌트를 사용하는 화면에서 항목과 동작에 맞게 지정한다.

미완료 항목을 보여 주는 목록에서는 방패에 체크가 들어간 완료 아이콘을, 완료된 항목을 보여 주는 목록에서는 화살표가 원을 그리는 다시 시작 아이콘을 사용한다.

끝 방향에는 화면과 관계없이 삭제 아이콘을 사용하고, 접근성 이름만 항목에 맞게 지정한다.

| 사용 화면 | 시작 방향 접근성 이름 | 끝 방향 접근성 이름 |
| --- | --- | --- |
| MemoHome, TagDetail 메모 탭, ContactDetail·PlaceDetail·WebDetail 메모 탭 | `메모 완료` | `메모 삭제` |
| MemoFinishedList, TagMemoFinishedList | `메모 다시 시작` | `메모 삭제` |
| WebHome, TagDetail 웹 탭 | 없음 | `웹 삭제` |

그 외 기본 환경에서는 `Finish memo`, `Restart memo`, `Delete memo`, `Delete web`을 쓴다.

SearchHome의 메모 검색 결과처럼 이 표에 없는 목록의 카드는 스와이프에 반응하지 않는다.
