# 태그 선택 입력 공통 디자인

기준 스펙: [태그 선택 입력 공통 스펙](../spec/tag-select-input.md)

이 문서는 태그를 고르는 입력들이 공통으로 쓰는 칩 영역, 추가 칩, 태그 선택 목록과 그 안의 검색·빈 상태·준비 상태 표현을 소유한다. 각 입력 문서는 그 입력에서만 다른 칩 구성, 목록 항목의 추가 요소, 라벨과 문구만 남긴다.

이 문서를 따르는 디자인 문서는 다음과 같다.

- [항목 태그 입력 컴포넌트 디자인](./entity-tag-input.md)
- [메모 태그 입력 컴포넌트 디자인](./memo-tag-input.md)
- [태그 연결 입력 컴포넌트 디자인](./tag-link-input.md)

이 문서에서 `추가 칩`은 칩 영역 마지막에 두어 태그 선택 목록을 여는 칩을 가리킨다. 칩의 라벨과 접근성 이름은 입력마다 다르므로 각 문서가 소유한다.

## 구성과 배치

태그 입력에는 현재 고른 태그의 칩과 추가 칩을 표시하는 칩 영역을 둔다. 추가 칩이 태그 입력임을 드러내므로 별도의 라벨은 두지 않는다.

태그 입력은 높이를 정하지 않는 자리에 두므로 칩 영역은 [공통 칩 영역 높이](./dimens.md)를 최소 높이로 쓴다. 고른 태그가 늘어 칩이 여러 줄이 되면 칩 영역이 그만큼 커지고, 뒤에 이어지는 요소는 커진 만큼 밀린다.

칩은 칩 영역의 가로·세로 가운데에 표시한다. 선택 상태가 바뀌어 내용이 달라질 때는 페이드로 전환한다.

칩은 가로로 배치하고 한 줄에 모두 들어가지 않으면 다음 줄로 넘긴다.

세 입력이 다루는 대상만 다르고 사용자가 보는 표현은 같게 두어, 사용자가 어느 화면에서든 같은 방식으로 태그를 고른다.

## 태그 칩

태그 칩과 선택 목록 항목의 태그 이름은 [TagHome 목록 디자인](./tag-home.md)의 `이모지와 제목 표시`를 따른다. 태그 이름이 칩에서 쓸 수 있는 폭을 넘었을 때의 표시와 칩 하나의 최대 폭은 [칩 이름 표시 디자인](./chip.md)을 따르며, 추가 칩에도 같은 규칙이 적용된다.

태그 칩에는 태그에 저장된 컬러로 채운 작은 원형 표시와 태그 이름을 표시한다.

태그 칩은 그 태그의 완료 여부와 관계없이 같은 표현을 사용한다. 완료된 태그임을 알리는 별도의 표시나 접근성 이름을 두지 않는다.

태그 칩을 누르면 그 태그의 TagDetail 화면으로 이동한다. 칩에는 버튼 역할과 태그 상세로 이동함을 알리는 동작 접근성 이름을 제공한다. 칩을 눌러도 태그 선택 목록은 열지 않는다.

## 추가 칩

칩 영역의 태그 칩 흐름 마지막에는 추가 칩을 표시한다. 선택 상태가 바뀌어 칩이 자리를 옮겨도 추가 칩은 항상 마지막에 둔다.

추가 칩에는 추가를 나타내는 플러스 아이콘과 그 입력의 라벨을 표시한다. 고른 태그가 없으면 칩 영역에는 추가 칩만 표시한다.

추가 칩을 누르면 기준 스펙의 `추가 항목의 동작 판정`에 따라 태그 선택 목록을 열거나 TagAdd 화면으로 이동한다. 어떤 동작으로 이어지든 칩의 표현은 같으며, 상황에 따라 라벨이나 아이콘을 바꾸지 않는다. 칩에는 버튼 역할과 그 동작으로 이어짐을 알리는 동작 접근성 이름을 제공한다.

TagAdd 화면으로 이동할 때 별도의 안내나 전환 표시를 두지 않고 바로 이동한다.

## 태그 선택 목록

추가 칩으로 태그 선택 목록이 열리면 다음과 같이 표시한다.

목록은 대화상자로 표시하고, 제목과 목록 내용의 여백은 확인 버튼이 없어도 Material 기본 대화상자 여백을 따른다.

목록의 각 항목에는 선택 여부를 나타내는 체크 표시, 태그 컬러로 채운 작은 원형 표시, 태그 이름을 표시한다. 항목 끝에 두는 버튼이 있는지는 각 입력 문서가 정한다.

목록이 차지하는 자리는 [공통 선택 목록 높이](./dimens.md)로 고정하고, 항목이 그보다 많으면 그 자리 안에서 세로로 스크롤할 수 있게 한다. 항목 수가 바뀌거나 검색으로 결과가 줄어도 대화상자의 크기가 바뀌지 않아, 사용자가 보고 있던 목록과 아래에 두는 요소가 자리를 옮기지 않는다. 항목이 그 높이를 채우지 못하면 남는 자리는 비워 둔다.

목록 항목은 그 태그의 완료 여부와 관계없이 같은 표현을 사용하고, 완료된 태그를 별도 구간으로 묶지 않고 다른 항목과 같은 정렬 순서에 함께 배치한다. 항목이 목록에 들어오거나 빠질 때는 위치 변화에 애니메이션을 적용한다.

사용자가 항목을 누르면 그 태그의 선택 여부를 바꾼다.

사용자는 목록 바깥을 누르거나 뒤로가기로 목록을 닫을 수 있다. 확인 버튼은 두지 않는다. 항목을 누르는 것이 곧 반영이므로 별도의 확인 단계를 두지 않는다.

## 태그 선택 목록의 태그 추가 버튼

목록 아래에 태그 추가 버튼을 둔다. 목록만 세로로 스크롤되고 태그 추가 버튼은 스크롤과 함께 움직이지 않으므로, 사용자는 목록을 어디까지 내렸든 같은 자리에서 버튼을 누를 수 있다.

태그 추가 버튼에는 추가를 나타내는 플러스 아이콘과 `태그 추가` 라벨을 표시하고, 대화상자의 가로 폭을 모두 사용하는 텍스트 버튼으로 배치한다. 버튼 자체의 여백만 두고 목록과 버튼 사이에 별도의 간격은 두지 않는다.

나타낼 태그가 없어 목록 영역이 비어 있어도, 검색 결과 없음 안내를 표시하는 동안에도 태그 추가 버튼은 같은 자리에 그대로 표시한다. 목록이 짧아 스크롤이 없을 때도 버튼의 자리는 바뀌지 않는다.

태그 추가 버튼은 태그 입력의 추가 칩과 이어지는 동작을 구분해야 하므로 칩과 다른 라벨을 쓴다. 추가 칩은 그 입력의 라벨로 선택 목록을 여는 동작을, 이 버튼은 `태그 추가`로 TagAdd 화면으로 이동하는 동작을 나타낸다.

버튼을 누르면 목록을 닫고 TagAdd 화면으로 이동한다. 이동할 때 별도의 안내나 전환 표시를 두지 않는다. 버튼에는 버튼 역할과 태그 추가로 이어짐을 알리는 동작 접근성 이름을 제공한다.

## 태그 선택 목록의 검색 입력

목록 제목 바로 아래, 목록 위에 검색 입력을 상시 표시한다. 검색어 입력이 목록보다 먼저 읽히도록 두고, 목록을 여는 조작 외에 검색을 여는 조작은 따로 두지 않는다.

검색 입력은 단일 줄 텍스트 입력으로 대화상자의 가로 폭을 모두 사용한다. 입력의 시작 쪽에는 돋보기 아이콘을 두고, 입력한 값이 있으면 끝 쪽에 내용을 한 번에 지우는 지우기 버튼을 표시한다. 값이 비어 있으면 지우기 버튼을 자리까지 함께 감춘다. 지우기 버튼의 표현과 접근성 이름은 공통 입력 컴포넌트의 기본값을 그대로 쓰고, 나타나고 사라지는 표현은 [나타나고 사라지는 버튼 디자인](./button-visibility.md)을 따른다.

입력이 비어 있으면 무엇을 입력하는 자리인지 알리는 안내 문구를 자리 표시 문구로 둔다. 입력 위에 별도의 라벨은 두지 않으며, 이 자리 표시 문구가 입력의 접근성 이름이 된다.

입력한 값이 폭을 넘어도 줄을 늘리지 않고 한 줄을 유지하며, 커서가 있는 자리가 보이도록 입력 안에서 가로로 움직인다.

검색 입력과 목록 사이에는 [공통 구성요소 간격](./dimens.md)을 둔다. 검색 입력은 목록과 함께 스크롤되지 않고 제목 아래 같은 자리에 머문다.

목록을 열 때 검색 입력에 초점을 두지 않는다. 사용자가 목록을 여는 것은 대부분 이미 나타난 태그를 고르기 위해서이므로, 소프트 키보드가 곧바로 열려 목록을 가리지 않게 한다. 사용자가 입력을 누르면 그때 초점이 옮겨 가고 소프트 키보드가 함께 열린다.

소프트 키보드는 일반 텍스트 키보드를 요청하고, 키보드의 동작 키는 검색으로 표시한다. 동작 키를 눌러도 이미 적용된 검색을 다시 실행하지 않고 소프트 키보드만 닫는다. 검색은 입력을 멈추면 스스로 적용되므로 사용자가 동작 키로 검색을 시작할 필요가 없다.

소프트 키보드가 열리면 대화상자는 키보드에 가리지 않는 높이로 줄어들고, 줄어든 높이는 목록 영역이 흡수한다. 제목, 검색 입력과 목록 아래에 두는 요소는 키보드가 열려 있는 동안에도 계속 보인다.

## 태그 선택 목록의 검색 결과 없음

검색어를 입력해 나타낼 태그가 없어지면 목록 자리에 안내 문구를 표시한다. 기준 스펙의 `태그 검색`이 정한 조건을 만족할 때만 표시한다.

안내는 아이콘이나 배경 도형 없이 제목 문구와 보조 문구만 세로로 잇고, 목록 자리를 그대로 채우며 가로·세로 가운데에 정렬한다. 두 문구 사이에는 [공통 항목 간격](./dimens.md)을 두고, 안내 위아래로는 [공통 화면 세로 여백](./dimens.md)을 둔다. 화면 본문 목록의 빈 상태와 달리 아이콘을 두지 않는 것은, 대화상자에서 제목과 검색 입력이 이미 무엇을 찾는 자리인지 알리고 있고 안내가 목록 자리보다 커지지 않게 하기 위한 것이다.

문구는 가운데 정렬하고, 폭이 좁아 한 줄에 들어가지 않으면 줄바꿈해 여러 줄로 표시한다. 안내에는 버튼이나 링크를 두지 않는다.

목록과 안내는 같은 자리를 쓰며 동시에 보이지 않고, 두 상태 사이는 교차 페이드로 전환한다. 검색어가 비어 있어 목록이 비는 동안에는 안내를 두지 않고 목록 자리를 비워 둔다.

안내를 표시하는 동안에도 검색 입력과 목록 아래에 두는 요소는 같은 자리에 그대로 둔다.

## 태그 선택 목록의 준비 상태

아직 준비되지 않은 자리에는 [페이지 조회 목록의 자리 표시 디자인](./paged-list-placeholder.md)에 따라 자리 표시 항목을 둔다. 자리 표시 항목은 컬러 표시와 태그 이름을 비워 두고, 체크 표시는 고르지 않은 상태로 표시한다.

목록을 처음 불러오거나 다음 태그를 이어서 불러오는 데 실패해도 별도의 오류 표시나 재시도 동작을 두지 않고 이미 나타난 항목을 그대로 표시한다.

검색어가 비어 있는데 나타낼 태그가 없으면 목록 영역을 비워 두고 별도의 안내 문구를 두지 않는다. 검색어를 입력해 나타낼 태그가 없어졌을 때의 표시는 `태그 선택 목록의 검색 결과 없음`을 따른다.

목록을 닫았다가 다시 열면 스크롤 위치를 이어받지 않고 목록의 맨 위에서 시작한다.

## 반영 표시

선택과 해제에는 진행 표시를 두지 않는다. 항목을 누르면 체크 표시가 곧바로 바뀌고, 반영된 결과는 칩 영역에 이어서 나타난다.

선택과 해제가 실패해도 별도의 오류 안내를 두지 않으며, 반영되지 않은 항목은 이전 상태로 표시된다.

## 문구와 접근성

한국어 환경과 그 외 기본 환경에서 다음 문구를 사용한다.

| 항목 | 한국어 | 그 외 기본 |
| --- | --- | --- |
| 태그 상세 이동 동작 접근성 이름 | `태그 상세 보기` | `Open tag detail` |
| 태그 선택 목록 검색 입력 자리 표시 문구 | `태그 검색` | `Search tags` |
| 태그 선택 목록 검색 결과 없음 제목 문구 | `검색 결과가 없습니다` | `No search results` |
| 태그 선택 목록 검색 결과 없음 보조 문구 | `다른 검색어로 찾아보세요` | `Try a different search query.` |
| 태그 선택 목록 태그 추가 버튼 라벨 | `태그 추가` | `Add tag` |
| 태그 추가 동작 접근성 이름 | `태그 추가` | `Add tag` |

추가 칩의 라벨, 그 동작의 접근성 이름과 태그 선택 목록의 제목은 입력마다 다르므로 각 입력 문서가 소유한다.
