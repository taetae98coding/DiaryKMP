# Spotlight 항목 디자인

기준 스펙: [Spotlight 항목 노출 스펙](../spec/client/spotlight.md)

이 문서는 iOS Spotlight 검색 결과에 앱의 항목이 보이는 제목, 부제, 아이콘을 소유한다. 어떤 항목이 나타나고 무엇으로 찾을 수 있는지, 고른 항목이 어느 화면에 열리는지는 기준 스펙을 따른다.

Spotlight 결과는 앱 화면이 아니라 운영체제의 검색 화면에 놓인다. 결과의 배치, 글자 크기와 색, 앱 이름 머리말, 결과 순서와 결과를 길게 눌렀을 때의 표현은 운영체제가 정하며, 이 문서는 항목마다 넘기는 글과 아이콘만 정한다.

## 항목 표시

항목 하나는 제목 한 줄, 그 아래 부제, 앞쪽 아이콘으로 보인다. 값이 비어 있는 줄은 두지 않으며, 부제의 값이 모두 비어 있으면 제목만 보인다.

| 항목 | 제목 | 부제 |
| --- | --- | --- |
| 메모 | 제목 | 설명 |
| 태그 | 이모지가 있으면 `{이모지} {제목}`, 없으면 제목 | 설명 |
| 장소 | 제목 | 첫 줄 주소, 다음 줄 설명 |
| 웹 | 제목 | 첫 줄 URL, 다음 줄 설명 |
| 연락처 | 이름 | 설명 |
| 체크리스트 | 제목 | 설명 |
| QR | 제목 | 설명 |
| 곡 | 제목 | 가수 |
| 디데이 | 제목 | 설명 |
| 루틴 | 제목 | 설명 |

제목과 부제는 저장된 글을 줄이거나 바꾸지 않고 그대로 넘긴다. 길이를 넘는 부분과 부제가 보이는 줄 수는 운영체제가 줄임표로 줄인다. 그래서 장소와 웹은 부제 첫 줄에 항목을 알아보기 쉬운 주소와 URL을 두고 설명을 그 뒤에 둔다.

연락처는 기준 스펙의 `담는 정보`에 알게 된 경로가 없으므로, 이름이 같은 연락처가 있어도 [연락처 표시 이름](./contact-name.md)의 경로를 붙이지 않고 이름만 보여 준다. 고른 뒤 열리는 상세 화면에서 구분한다.

QR의 내용은 기준 스펙대로 담지 않으므로 어느 줄에도 보이지 않는다. 루틴의 카드 문구와 루틴 기록도 기준 스펙대로 담지 않으므로, 루틴의 부제에는 합계나 달성률을 두지 않고 설명만 둔다.

## 아이콘

항목 앞에는 항목 종류를 나타내는 아이콘을 둔다. 아이콘 모양은 [앱 동작 디자인](./app-action.md)의 `항목 종류 이름`에 있는 SF Symbol과 같아서, 단축어와 Spotlight에서 같은 종류의 항목이 같은 아이콘으로 보인다.

| 항목 | 아이콘 색 |
| --- | --- |
| 메모, 태그, 장소, 디데이, 루틴 | 그 항목의 색 |
| 웹, 연락처, 체크리스트, QR, 곡 | 앱의 주 색 |

아이콘은 투명한 바탕에 그려 넘기며, 크기와 모서리 모양은 운영체제가 결과 자리에 맞춘다. 밝은 모양과 어두운 모양에서 같은 아이콘을 쓴다. 항목의 색이 바탕과 구분되지 않을 만큼 밝거나 어두워도 색을 바꾸지 않는다. 앱 화면에서 같은 항목을 그 색으로 보여 주는 것과 같게 하기 위해서다.

웹 항목에 사이트 아이콘을 쓰지 않는다. 기준 스펙의 `기기 안의 자료`대로 Spotlight에 담는 정보는 기기에 저장된 항목에서만 가져오기 때문이다.

## 접근성

화면 낭독 도구는 운영체제가 제목과 부제를 이어 읽는다. 아이콘은 제목이 이미 전하는 항목을 그림으로 거듭 보여 주는 장식이므로 따로 접근성 이름을 두지 않는다.
