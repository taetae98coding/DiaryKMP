# 항목 태그 입력 컴포넌트 디자인

기준 스펙: [항목 태그 입력 컴포넌트 스펙](../spec/entity-tag-input.md)

칩 영역과 추가 칩, 태그 선택 목록과 그 안의 검색·태그 추가 버튼·빈 상태·준비 상태 표현은 [태그 선택 입력 공통 디자인](./tag-select-input.md)을 따른다. 이 문서는 이 입력에서만 다른 칩 구성과 문구를 소유한다.

이 문서에서 `대상 항목`은 태그 입력이 다루는 웹 항목 또는 장소 하나를 가리킨다. 네 화면에서 같은 표현과 조작을 사용하며, 화면마다 다른 자리와 표시 조건은 [WebAdd 화면 디자인](./web-add.md), [WebDetail 화면 디자인](./web-detail.md), [PlaceAdd 화면 디자인](./place-add.md), [PlaceDetail 화면 디자인](./place-detail.md)이 소유한다.

## 태그 칩

대상 항목은 대표 태그를 갖지 않으므로 칩에 대표 태그를 나타내는 표시나 대표 태그 지정 버튼을 두지 않는다. [메모 태그 입력 컴포넌트 디자인](./memo-tag-input.md)의 칩과 이 점만 다르다.

## 태그 추가 칩

이 입력의 추가 칩은 태그 추가 칩이며, 표현과 동작은 [태그 선택 입력 공통 디자인](./tag-select-input.md)의 `추가 칩`을 그대로 따른다.

## 태그 선택 목록

대상 항목은 대표 태그를 갖지 않으므로 목록 항목 끝에 두는 버튼은 없다. 목록 아래의 태그 추가 버튼은 공통 디자인을 그대로 따른다.

## 문구와 접근성

[태그 선택 입력 공통 디자인](./tag-select-input.md)의 `문구와 접근성`에 더해 한국어 환경과 그 외 기본 환경에서 다음 문구를 사용한다.

| 항목 | 한국어 | 그 외 기본 |
| --- | --- | --- |
| 태그 추가 칩 라벨 | `태그 선택` | `Select tag` |
| 태그 선택 동작 접근성 이름 | `태그 선택` | `Select tag` |
| 태그 선택 목록 제목 | `태그 선택` | `Select Tag` |

칩 라벨과 목록 제목은 [메모 태그 입력 컴포넌트 디자인](./memo-tag-input.md)과 같은 문구를 쓴다. 두 입력 모두 항목에 태그를 고르는 입력이므로, 사용자가 화면을 옮겨도 같은 이름의 동작으로 읽히게 한다. 태그와 태그를 잇는 [태그 연결 입력](./tag-link-input.md)만 `태그 연결`이라는 다른 문구를 쓴다.
