# TagAdd 화면 디자인

기준 스펙: [TagAdd 화면 스펙](../spec/client/tag-add.md)

화면 구조, 태그 입력의 자리, 표시 영역과 소프트 키보드, 초점과 단축키, 진행과 피드백의 공통 표현은 [항목 추가 화면 공통 디자인](./entity-add.md)을 따른다.

## 화면 구조와 적응형 배치

TagHome에서 진입하면 넓은 화면에서는 태그 목록과 TagAdd 화면을 함께 표시하고, 좁은 화면에서는 TagAdd 화면만 표시한다. 함께 표시할 때의 구체적인 배치와 버튼 노출은 [Tag 목록·상세 배치 디자인](./tag-list-detail.md)을 따른다.

태그 필터나 메모 태그 입력처럼 태그 목록이 아닌 화면에서 진입한 TagAdd 화면은 창 너비와 관계없이 단독으로 표시한다.

화면 상단에는 제목이 있는 상단 바를 둔다. TagAdd 화면을 단독 표시할 때만 뒤로가기 버튼을 표시한다.

본문에는 이모지 입력과 단일 줄 제목 입력을 한 행에 배치한 제목 행, 설명 입력, 컬러 입력, 태그 연결 입력을 순서대로 배치하고 각 입력 사이에 [공통 구성요소 간격](./dimens.md)을 둔다. 태그 연결 입력의 구성과 조작은 [태그 연결 입력 컴포넌트 디자인](./tag-link-input.md)을 따른다. 추가 동작은 떠 있는 버튼으로 표시한다.

제목 행에서는 이모지 입력을 왼쪽에, 제목 입력을 오른쪽에 두고 둘 사이에 [공통 구성요소 간격](./dimens.md)을 둔다. 이모지 입력의 크기와 조작은 [태그 이모지 입력 컴포넌트 디자인](./tag-emoji-input.md)을 따르고, 제목 입력이 남은 폭을 모두 사용한다. 제목 입력의 구성과 문구는 [제목 입력 디자인](./title-input.md)을 따른다.

## 키보드 단축키

물리 키보드 환경에서는 TagHome 화면의 `Cmd` 또는 `Meta`와 `A`를 함께 눌러 TagAdd 화면으로 이동할 수 있다.

## 진행과 피드백

추가에 성공해 고른 연결을 비울 때는 칩 영역의 칩이 페이드로 사라지고 태그 연결 칩만 남는다.

## 문구와 접근성

[항목 추가 화면 공통 디자인](./entity-add.md)의 `문구와 접근성`에 더해 한국어 환경과 그 외 기본 환경에서는 다음 문구를 사용한다.

| 문구 | 한국어 | 그 외 기본 |
| --- | --- | --- |
| 상단 바 제목 | `태그 추가` | `Add Tag` |
| TagHome 추가 버튼 접근성 이름 | `태그 추가` | `Add tag` |
| TagAdd 추가 버튼 접근성 이름 | `태그 추가` | `Add tag` |
| 추가 성공 안내 | `태그가 추가되었습니다.` | `Tag added.` |
| 제목 미입력 안내 | `제목을 입력해 주세요.` | `Please enter a title.` |
