# ContactHome 화면 디자인

기준 스펙: [ContactHome 화면 스펙](../spec/client/contact-home.md), [SwipeToFinishAndDelete 컴포넌트 스펙](../spec/client/swipe-to-finish-and-delete.md), [페이지 조회 목록의 자리 표시 스펙](../spec/client/paged-list-placeholder.md), [목록 빈 상태 스펙](../spec/client/list-empty-state.md), [목록 정렬 스펙](../spec/client/list-sort.md), [목록 필터 반영 스펙](../spec/client/list-filter.md), [새로고침 스펙](../spec/client/sync-refresh.md)

화면 구조, 추가 버튼, 카드 조작, 삭제 스와이프, 자리 표시·빈 상태·새로고침, 격자와 시스템 영역, 추가 단축키의 공통 표현은 [항목 목록 화면 공통 디자인](./entity-home.md)을 따른다. 이 문서는 ContactHome에서만 다른 표현을 다룬다.

## 화면 구조

목록이 상세 영역과 자리를 나눠 쓰는 배치와 그 자리에서의 버튼 노출은 [Contact 목록·상세 배치 디자인](./contact-list-detail.md)을 따른다.

상단 바의 액션에는 필터 아이콘 버튼 하나만 둔다. 연락처 검색은 기준 스펙의 범위 밖이므로 [MemoHome 목록 디자인](./memo-home.md)이 필터 버튼 앞에 두는 검색 버튼에 해당하는 자리를 비워 둔다.

본문은 위에서부터 정렬 줄과 연락처 목록 영역으로 채운다.

## 필터 진입

필터 아이콘 버튼은 상단 바의 가장 끝에 배치한다. 버튼의 아이콘과 적용 상태 표현, Bottom Sheet의 표시, 닫는 조작, 필터 반영 전환, 적응형 배치는 [필터 Bottom Sheet 디자인](./filter-bottom-sheet.md)을 따른다. 적용 여부의 기준은 [목록 필터 반영 스펙](../spec/client/list-filter.md)의 `필터 적용 상태`를 따른다.

필터 아이콘 버튼을 누르면 목록과 넓은 화면의 상세 영역을 어둡게 처리한 배경 아래에 그대로 유지한 채 필터 Bottom Sheet를 표시한다.

## 필터 Bottom Sheet 구성

Bottom Sheet 상단에는 드래그 핸들을 표시하고, 그 아래에 `필터` 제목을 배치한다. 별도 닫기 버튼은 표시하지 않는다.

제목 아래에는 유무 필터 영역 하나만 둔다. 제목만 Bottom Sheet 위쪽에 고정하고, 유무 필터 영역은 세로 스크롤 영역에 둔다. 다른 필터 영역이 없으므로 구분선과 소제목은 두지 않는다.

유무 필터 영역에는 생일, 태어난 연도, 전화번호를 이 순서로 한 축에 한 행씩 세로로 배치한다. 연락처를 추가할 때 입력하는 순서와 같다. 행의 배치, 세그먼트 버튼의 순서와 표현, 선택 조작, 키보드 조작은 [MemoHome 목록 디자인](./memo-home.md)의 `유무 필터 영역`을 그대로 따르며, 축만 생일, 태어난 연도, 전화번호 세 개로 바꾼다. 어떤 축도 고르지 않은 처음 상태에서는 세 행 모두 `전체`가 선택된 상태로 표시한다.

## 정렬 줄

정렬 줄은 상단 바 바로 아래, 연락처 목록 위에 둔다. 정렬 줄과 정렬 선택 Bottom Sheet의 구조, 조작, 아이콘과 문구는 [목록 정렬 디자인](./list-sort.md)을 따르며, 이 목록은 그 문서의 `이름순`과 `최근 수정순` 두 줄을 사용한다.

## 목록

각 연락처는 카드로 표시한다. 카드에는 이름 줄, 첫 번째 전화번호 줄, 생일 줄을 위에서부터 이 순서로 이어서 표시한다. 생일 없이 태어난 연도만 있는 연락처는 생일 줄 자리에 태어난 연도를 표시한다. 설명, 키, 신발 사이즈, 고향과 나머지 전화번호는 카드에 표시하지 않는다.

전화번호가 하나도 없는 연락처는 전화번호 줄을, 생일과 태어난 연도가 모두 없는 연락처는 생일 줄을 두지 않는다. 빈 줄을 자리 표시로 남기지 않으므로 카드 높이는 그 연락처가 가진 줄 수만큼만 차지한다. 이름만 있는 연락처의 카드는 한 줄 높이가 된다.

이름은 카드의 기본 글자 크기로, 전화번호와 생일은 이름보다 작은 글씨로 표시한다.

카드의 안쪽 여백은 [공통 스타일](./styles.md)의 `카드 내용`을, 줄 사이의 간격은 [공통 여백과 간격](./dimens.md)의 `카드 줄 간격`을 따른다. 연락처에는 저장된 컬러가 없으므로 컬러 원형 표시에 해당하는 요소는 두지 않고, 그 자리를 비워 두지도 않는다.

목록과 상세를 함께 표시하는 동안 상세 영역에 어느 연락처가 놓여 있는지는 상세 영역의 상단 바 제목이 알리므로, 격자에서 선택 표시를 따로 두지 않는다. 이는 [MemoHome 화면 디자인](./memo-home.md)의 메모 목록과 같은 기준이다.

카드를 누르면 그 연락처의 [ContactDetail 화면](./contact-detail.md)으로 이동하고, 목록과 상세를 함께 표시하는 동안에는 이동하지 않고 상세 영역이 그 연락처의 상세로 바뀐다.

## 삭제 스와이프

즐겨찾기 아이콘 위에서 시작한 스와이프도 카드 전체의 스와이프로 다룬다.

목록과 상세를 함께 표시하는 배치에서 삭제 안내 스낵바의 자리는 [목록·상세 배치 공통 디자인](./list-detail-pane.md)의 `진행과 피드백`을 따른다.

실행 취소로 돌아온 카드는 스와이프 전 모양으로 즐겨찾기 묶음과 정렬 기준에 맞는 자리에 다시 나타나며, 즐겨찾기인 연락처는 즐겨찾기 아이콘을 그대로 가진 채 돌아온다.

지그재그 격자에서 카드를 없애거나 다시 넣으면 그 열의 아래 카드는 기본 항목 이동 애니메이션으로 자리를 옮긴다.

## 격자

카드는 2열 지그재그 격자로 배치한다.

전화번호와 생일의 유무에 따라 카드가 한 줄에서 세 줄까지 서로 다른 높이를 가지므로, 각 열은 앞 카드 바로 아래에서 이어져 카드 사이에 빈 자리가 생기지 않는다. 같은 행의 카드를 가장 높은 카드에 맞춰 늘리지 않으며, 짧은 카드 아래에 남는 자리를 비워 두지 않는다. 이는 주소가 있는 카드와 없는 카드의 높이가 다른 [장소 보기 모드 디자인](./place-view-mode.md)의 `장소 목록 격자`와 같은 기준이다.

## 즐겨찾기 표시

즐겨찾기인 연락처의 카드에는 이름 줄의 시작 쪽, 이름 바로 앞에 채워진 별 아이콘을 둔다. 아이콘 크기는 이름 글자 크기에 맞춘 `18dp`로 두고, 아이콘과 이름 사이는 이름이 아이콘에 붙어 읽히지 않을 만큼인 `4dp`만 띄운다.

즐겨찾기가 아닌 연락처의 카드에는 아이콘을 두지 않고 그 자리를 비워 두지도 않는다. 이름이 아이콘 자리만큼 들여쓰이지 않고 카드 안쪽 여백에서 바로 시작한다. 즐겨찾기가 하나도 없는 목록에서 모든 카드의 이름 왼쪽에 빈 자리가 남지 않게 하기 위한 것이다.

아이콘은 표시 전용이므로 누를 수 없고, 누름 표현도 두지 않는다. 카드를 누르는 조작은 아이콘 위에서도 카드 전체의 조작으로 다룬다. 즐겨찾기를 바꾸는 조작은 [ContactDetail 화면 디자인](./contact-detail.md)의 `상단 바 액션`에만 둔다.

즐겨찾기임을 알리는 문구는 카드의 접근성 이름 맨 앞에 두고 이름·전화번호·생일과 하나로 이어 읽히게 한다. 아이콘을 별도 요소로 읽히게 두면 사용자가 카드 하나를 읽을 때 즐겨찾기와 이름이 두 번에 끊겨 읽힌다.

즐겨찾기가 바뀌어 아이콘이 나타날 때는 작은 크기에서 제 크기로 커지면서 함께 진해지고, 사라질 때는 작아지면서 함께 흐려진다. 크기와 투명도는 같은 구간에서 바꾸고, 지속 시간과 완급은 전환 기본값을 따른다. 이 아이콘은 누를 수 없으므로 [나타나고 사라지는 버튼 디자인](./button-visibility.md)의 적용 대상이 아니지만, 같은 면 위에서 자리를 나눠 쓰는 요소이므로 그 문서가 아이콘 버튼에 두는 것과 같은 표현을 쓴다.

아이콘이 나타나고 사라지면서 이름 줄의 남은 폭이 바뀌지만, 이름은 줄바꿈 없이 한 줄을 유지하므로 카드 높이는 바뀌지 않는다.

## 생일 표시

생일 줄에는 저장된 생일을 연·월·일 순으로 표시한다. 날짜의 표시 형식은 [DiaryDateTimeInput 컴포넌트 디자인](./diary-date-time-input.md)의 `표시 형식`을 따라 [ContactAdd 화면 디자인](./contact-add.md)의 생일 버튼과 같은 형식을 쓴다. 두 화면이 같은 값을 다른 형식으로 보여 주지 않게 하기 위한 것이다.

저장된 달력 구분이 음력이면 날짜 앞에 음력임을 알리는 문구를 붙이고, 양력이면 아무 문구도 붙이지 않는다. 양력이 기본값이므로 붙이지 않는 쪽을 기본으로 두고, 기본과 다른 음력만 드러낸다. 붙이는 문구는 `문구와 접근성`을 따른다.

달력 구분은 별도의 아이콘이나 색으로 구분하지 않는다. 카드에는 이미 이름과 전화번호가 있어 표시 수단을 늘리면 읽을 것이 많아지고, 음력 여부는 날짜와 함께 읽혀야 의미가 있기 때문이다.

음력 생일도 저장된 연·월·일을 그대로 표시하고 양력 날짜로 환산하지 않는다. 이는 기준 스펙의 `연락처 목록`이 정한 기준이다.

접근성에는 생략하지 않은 전체 생일을 달력 구분 문구까지 포함해 제공한다.

생일 없이 태어난 연도만 있으면 생일 줄에 `문구와 접근성`의 태어난 연도 표시 문구를 생일과 같은 글자 크기로 표시한다. 달력 구분 문구는 붙이지 않는다. 생일이 있으면 태어난 연도는 생일 날짜에 이미 보이므로 따로 표시하지 않는다. 접근성에도 화면에 표시한 문구를 그대로 제공한다.

## 새로고침

본문 전체가 정렬 줄과 연락처 목록 영역이므로 연락처 목록 영역만 당김 새로고침 컨테이너로 감싼다. 정렬 줄은 감싸지 않아 정렬 줄을 세로로 끌어도 새로고침이 시작되지 않는다.

진행 표시는 목록 영역 위쪽에, 플로팅 액션 버튼은 본문 오른쪽 아래에 놓이므로 두 요소는 겹치지 않는다.

## 자리 표시

이 목록의 자리 표시 카드는 이름과 전화번호를 비워 둔 두 줄 높이를 차지하고, 생일 줄과 즐겨찾기 아이콘은 두지 않는다.

준비되지 않은 자리에는 그 연락처가 전화번호와 생일을 가졌는지 알 수 없으므로, 자리 표시 카드의 높이를 준비된 카드에 맞추지 않고 두 줄로 고정한다. 준비가 끝나 카드가 채워질 때 높이가 달라지면 [공통 항목 간격](./dimens.md)을 유지한 채 지그재그 격자가 그 아래 카드를 이어서 올린다.

## 빈 상태

빈 상태의 아이콘과 문구는 필터를 적용해 두었는지에 따라 달라진다. 필터 적용 여부의 기준은 `필터 진입`에서 필터 아이콘 버튼을 주요 색으로 표시하는 기준과 같다.

| 상태 | 아이콘 | 제목 문구 |
| --- | --- | --- |
| 필터 아이콘이 기본 색인 상태 | 연락처 아이콘 | `아직 연락처가 없습니다` |
| 필터 아이콘이 주요 색인 상태 | 필터 아이콘 | `조건에 맞는 연락처가 없습니다` |

두 빈 상태 사이의 전환과 보조 문구를 포함한 정확한 문구는 [목록 빈 상태 디자인](./list-empty-state.md)을 따른다.

연락처 아이콘은 `더보기`의 연락처 메뉴에서 쓰는 아이콘과 같다.

빈 상태에서 정렬 줄은 [목록 정렬 디자인](./list-sort.md)의 `항목이 없는 동안의 정렬 줄`에 따라 감춘다.

빈 상태에서도 당김 새로고침 컨테이너와 진행 표시는 `새로고침`이 정한 자리에 그대로 둔다. 상단 바의 필터 아이콘 버튼도 같은 자리에 같은 모양으로 표시한다.

## 문구와 접근성

한국어 환경과 그 외 기본 환경에서 다음 문구를 사용한다. 뒤로가기 접근성 이름과 실행 취소 동작은 [항목 목록 화면 공통 디자인](./entity-home.md)의 `문구와 접근성`을 따른다.

| 항목 | 한국어 | 그 외 기본 |

| 상단 바 제목 | `연락처` | `Contacts` |
| 연락처 추가 버튼 접근성 이름 | `연락처 추가` | `Add contact` |

| 필터 버튼 접근성 이름 | `필터` | `Filter` |
| 필터 적용 상태 접근성 설명 | `필터 적용됨` | `Filter applied` |
| Bottom Sheet 제목 | `필터` | `Filter` |
| 생일 축 이름 | `생일` | `Birthday` |

| 세그먼트 버튼 `있음` | `있음` | `With` |
| 세그먼트 버튼 `없음` | `없음` | `Without` |
| 세그먼트 버튼 `전체` | `전체` | `All` |
| 음력 생일 앞에 붙이는 문구 | `음력 ` | `Lunar ` |
| 태어난 연도 표시 문구 | `{연도}년생` | `Born {연도}` |
| 즐겨찾기 카드 접근성 문구 | `즐겨찾기` | `Favorite` |
| 삭제 안내 | `연락처가 삭제되었습니다.` | `Contact deleted.` |
| 삭제 스와이프 아이콘 접근성 이름 | `연락처 삭제` | `Delete contact` |

연락처 카드에는 카드가 누를 수 있는 요소임을 알리는 별도의 접근성 이름을 두지 않고, 카드에 표시한 이름과 전화번호, 생일을 접근성 이름으로 그대로 쓴다. 즐겨찾기인 카드는 그 앞에 즐겨찾기 카드 접근성 문구를 더한다.

유무 필터의 세그먼트 버튼은 접근성 이름에 축 이름과 상태 라벨을 이 순서로 한 칸 띄어 이어 읽힌다. 예를 들어 생일 축의 세 버튼은 `생일 있음`, `생일 없음`, `생일 전체`로, 그 외 기본 환경에서는 `Birthday With`, `Birthday Without`, `Birthday All`로 읽는다.

음력 생일 앞에 붙이는 문구는 뒤에 오는 날짜와 한 칸 띄어 이어 붙인다. 이 문구는 [ContactAdd 화면 디자인](./contact-add.md)의 `음력 칸 라벨`과 같은 낱말을 쓰되, 그 라벨은 고르는 칸의 이름이고 이 문구는 날짜 앞에 붙는 수식어이므로 서로 다른 문구로 둔다.
