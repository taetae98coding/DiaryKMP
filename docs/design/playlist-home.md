# PlaylistHome 화면 디자인

기준 스펙: [PlaylistHome 화면 스펙](../spec/client/playlist-home.md), [SwipeToFinishAndDelete 컴포넌트 스펙](../spec/client/swipe-to-finish-and-delete.md), [MusicAdd 화면 스펙](../spec/client/music-add.md), [MusicDetail 화면 스펙](../spec/client/music-detail.md), [Playlist 목록·상세 배치 스펙](../spec/client/playlist-list-detail.md), [새로고침 스펙](../spec/client/sync-refresh.md), [페이지 조회 목록의 자리 표시 스펙](../spec/client/paged-list-placeholder.md), [목록 빈 상태 스펙](../spec/client/list-empty-state.md)

화면 구조, 추가 버튼, 카드 조작, 삭제 스와이프, 자리 표시·빈 상태·새로고침, 격자와 시스템 영역, 추가 단축키의 공통 표현은 [항목 목록 화면 공통 디자인](./entity-home.md)을 따른다. 이 문서는 PlaylistHome에서만 다른 표현을 다룬다.

## 화면 구조

목록이 상세 영역과 자리를 나눠 쓰는 배치와 그 자리에서의 버튼 노출은 [Playlist 목록·상세 배치 디자인](./playlist-list-detail.md)을 따른다.

상단 바에는 액션을 두지 않는다. 이번 범위에는 곡 검색이 없으므로 다른 목록 화면이 상단 바 끝 쪽에 두는 검색 버튼은 두지 않는다.

본문 전체는 곡 목록 영역 하나로 채운다.

## 정렬 줄

정렬 줄은 상단 바 바로 아래, 곡 목록 위에 둔다. 정렬 줄과 정렬 선택 Bottom Sheet의 구조, 조작, 아이콘과 문구는 [목록 정렬 디자인](./list-sort.md)을 따른다.

## 목록

각 곡은 카드로 표시한다. 카드에는 썸네일, 제목, 가수를 위에서부터 이어서 표시한다.

제목은 카드의 기본 글자 크기로, 가수는 제목보다 작은 글씨로 표시한다. 가수가 없는 곡은 가수 줄을 없애지 않고 빈 줄로 남겨 두어 가수가 있는 곡과 카드 높이를 같게 유지한다.

제목과 가수 두 줄은 [공통 스타일](./styles.md)의 `카드 내용`으로 감싸고, 두 줄 사이에는 [카드 줄 간격](./dimens.md)을 둔다. 썸네일은 이 여백 밖에 둔다. 곡에는 저장된 컬러가 없으므로 컬러를 나타내는 요소는 두지 않는다.

카드는 2열 지그재그 격자로 배치한다. 각 열은 앞 카드 바로 아래에서 이어지며, 같은 행의 카드를 가장 높은 카드에 맞춰 늘리지 않는다. 썸네일 영역의 높이가 카드 폭으로 정해지고 제목과 가수가 모두 한 줄이어서 카드 높이가 서로 같으므로 두 열의 카드는 나란히 놓인다.

카드를 누르면 그 곡의 [MusicDetail 화면](./music-detail.md)으로 이동한다. 목록에서 지금 보고 있는 곡을 따로 강조하는 선택 표현은 두지 않는다.

아직 준비되지 않은 자리 표시 카드는 가리키는 곡이 없으므로 누를 수 있는 자리로 두지 않는다.

## 썸네일

썸네일은 카드 맨 위에 카드의 가로 폭을 모두 쓰는 `16:9` 영역으로 두고, 안쪽 여백 없이 카드의 위쪽 모서리에 맞붙인다. 제목과 가수의 안쪽 여백은 썸네일 아래부터 적용한다.

이미지는 영역을 가득 채우도록 잘라서 표시한다. YouTube가 주는 썸네일은 `4:3`이고 위아래에 검은 띠가 들어 있을 수 있으므로, 맞춰 넣지 않고 잘라 넣어 띠가 카드에 남지 않게 한다.

썸네일 영역은 다음 세 경우에 같은 크기를 그대로 차지한다. 곡마다 카드 높이가 달라지면 지그재그 격자의 두 열이 어긋나고, 이미지가 도착할 때마다 그 열의 아래 카드가 자리를 옮기기 때문이다.

| 상태 | 표시 |
| --- | --- |
| 썸네일이 있고 이미지를 받아왔다 | 이미지를 잘라 채운다 |
| 이미지를 아직 받아오는 중이다 | 빈 자리로 둔다 |
| 링크가 없거나 영상을 가리키지 않거나 썸네일 주소를 열 수 없다 | 빈 자리로 둔다 |

빈 자리에는 카드 배경보다 한 단계 어두운 면만 두고 아이콘이나 문구를 넣지 않는다. 썸네일이 없는 것은 사용자가 고칠 수 있는 오류가 아니라 그 곡의 링크가 가진 상태이므로, 다시 시도할 것이 있다는 인상을 주지 않는다.

이미지가 도착하면 빈 자리에서 이미지로 바꾸고, 이때 카드의 다른 요소는 자리를 옮기지 않는다.

자리 표시 카드의 썸네일 영역도 준비된 카드와 같은 크기를 차지한다.

## 자리 표시

이 목록의 자리 표시 카드는 썸네일, 제목과 가수를 비워 두고, 준비된 카드와 같은 높이를 차지한다.

## 빈 상태

빈 상태에는 플레이리스트 아이콘과 아래 `문구와 접근성`의 제목 문구·보조 문구를 사용한다.

정렬 줄은 [목록 정렬 디자인](./list-sort.md)의 `항목이 없는 동안의 정렬 줄`에 따라 감춘다.

## 새로고침

본문 전체가 곡 목록 영역이므로 본문 전체를 당김 새로고침 컨테이너로 감싸고, 진행 표시는 본문 위쪽 가로 가운데에 둔다.

진행 표시는 본문 위쪽에, 플로팅 액션 버튼은 본문 오른쪽 아래에 놓이므로 두 요소는 겹치지 않는다.

## 문구와 접근성

한국어 환경과 그 외 기본 환경에서 다음 문구를 사용한다. 뒤로가기 접근성 이름과 실행 취소 동작은 [항목 목록 화면 공통 디자인](./entity-home.md)의 `문구와 접근성`을 따른다.

| 항목 | 한국어 | 그 외 기본 |
| --- | --- | --- |
| 상단 바 제목 | `플레이리스트` | `Playlist` |
| 곡 추가 버튼 접근성 이름 | `곡 추가` | `Add music` |
| 빈 상태 제목 문구 | `아직 곡이 없습니다` | `No music yet` |
| 빈 상태 보조 문구 | `추가 버튼으로 새 곡을 담을 수 있습니다` | `Use the add button to add music.` |
| 삭제 안내 | `곡이 삭제되었습니다.` | `Song deleted.` |
| 삭제 스와이프 아이콘 접근성 이름 | `곡 삭제` | `Delete song` |

곡 카드에는 카드에 표시한 제목과 가수를 접근성 이름으로 그대로 쓰고, 가수가 없는 곡은 제목만 쓴다. 누르면 무엇이 일어나는지는 낭독 도구가 알리는 기본 동작 설명에 맡긴다.

썸네일은 영상의 내용을 글로 옮길 수 없고 같은 카드의 제목과 가수가 이미 그 곡을 가리키므로, 낭독 도구에 이름을 따로 두지 않고 장식으로 다룬다.
