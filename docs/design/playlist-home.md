# PlaylistHome 화면 디자인

기준 스펙: [PlaylistHome 화면 스펙](../spec/playlist-home.md), [MusicAdd 화면 스펙](../spec/music-add.md), [MusicDetail 화면 스펙](../spec/music-detail.md), [곡 다운로드 스펙](../spec/music-download.md), [곡 다운로드 프록시 스펙](../spec/music-download-proxy.md), [Playlist 목록·상세 배치 스펙](../spec/playlist-list-detail.md), [새로고침 스펙](../spec/sync-refresh.md), [페이지 조회 목록의 자리 표시 스펙](../spec/paged-list-placeholder.md), [목록 빈 상태 스펙](../spec/list-empty-state.md)

## 화면 구조

PlaylistHome 화면은 `더보기`에서 이어지는 세부 화면이며, 공통 내비게이션 영역은 [TopLevelNavigation 디자인](./top-level-navigation.md)의 `세부 화면에서의 노출`에 따라 숨긴다. 창 너비에 따라 단독으로 표시하거나 [Playlist 목록·상세 배치 디자인](./playlist-list-detail.md)에 따라 상세 영역과 자리를 나눠 표시한다.

화면 상단에는 제목과 뒤로가기 동작, 다운로드 버튼이 있는 상단 바를 표시한다. 상단 바에는 다른 액션을 두지 않는다. 이번 범위에는 곡 검색이 없으므로 다른 목록 화면이 상단 바 끝 쪽에 두는 검색 버튼은 두지 않는다.

본문 전체는 곡 목록 영역 하나로 채우고, 오른쪽 아래에 곡 추가를 실행하는 플로팅 액션 버튼을 겹쳐 표시한다. 버튼에는 추가를 뜻하는 더하기 아이콘을 표시하고, 목록의 상태와 관계없이 같은 자리에 같은 모양으로 표시한다. 버튼의 노출 조건은 [목록·상세 배치 공통 디자인](./list-detail-pane.md)의 `버튼 노출`을 따른다.

## 상단 바 다운로드 버튼

상단 바의 끝 쪽에 다운로드 아이콘 버튼을 하나 배치한다. 다른 목록 화면이 이 자리에 검색 버튼을 두므로, 사용자는 목록 화면의 액션을 언제나 상단 바 끝에서 찾는다.

버튼에는 아래를 향한 화살표와 받침선으로 된 다운로드 아이콘만 표시하고 라벨, 배지, 숫자는 표시하지 않으며 기본 상단 바 아이콘 색을 사용한다. 버튼의 설명 표시는 [아이콘 버튼 설명 디자인](./icon-button-tooltip.md)을 따른다.

내려받기를 준비하는 동안과 받을 곡이 남아 있는 동안에는 버튼의 아이콘 자리를 진행 표시로 바꾸고 버튼의 크기와 자리는 그대로 둔다. 진행 표시에는 전체 진행률을 나타내지 않고 끝을 알 수 없는 원형 진행 표시를 쓴다. 전체가 몇 곡인지는 사용자가 목록에서 보고 있고, 곡마다의 진행은 각 카드가 보여 주기 때문이다.

내려받기를 준비하는 동안에는 아직 어떤 곡에도 상태가 없으므로, 이 진행 표시가 다운로드가 시작되었음을 알리는 유일한 표시다. 준비는 대개 도구가 이미 있거나 프록시에 곧 연결되어 곧바로 끝나고, JVM 데스크톱에서 도구 설치가 필요할 때만 눈에 띄게 길어진다.

진행 중에도 버튼을 비활성으로 표시하지 않고 접근성 이름과 설명 문구도 그대로 유지한다. 이때 버튼을 눌러도 아무 일이 일어나지 않는 것은 [곡 다운로드 스펙](../spec/music-download.md)의 `다시 실행 성립 조건`을 따른다.

버튼은 목록의 상태와 관계없이 언제나 같은 자리에 같은 모양으로 표시한다. 곡이 하나도 없는 빈 상태에서도, 다운로드를 제공하지 않는 웹에서도 같다. 일부 플랫폼에서만 버튼을 숨기거나 흐리게 두면 같은 화면이 플랫폼마다 달라 보이고, 사용자가 무엇을 잘못했는지 찾게 된다.

## 정렬 줄

정렬 줄은 상단 바 바로 아래, 곡 목록 위에 둔다. 정렬 줄과 정렬 선택 Bottom Sheet의 구조, 조작, 아이콘과 문구는 [목록 정렬 디자인](./list-sort.md)을 따른다.

## 목록

각 곡은 카드로 표시한다. 카드에는 썸네일, 제목, 가수를 위에서부터 이어서 표시한다.

제목은 카드의 기본 글자 크기로, 가수는 제목보다 작은 글씨로 표시한다. 가수가 없는 곡은 가수 줄을 없애지 않고 빈 줄로 남겨 두어 가수가 있는 곡과 카드 높이를 같게 유지한다. 두 줄 모두 각각 한 줄을 유지하며, 카드에서 사용할 수 있는 폭을 넘으면 기본 이동 속도와 간격으로 가로 이동을 시작하고 카드가 표시되는 동안 횟수 제한 없이 반복한다. 접근성에는 생략하지 않은 전체 제목과 전체 가수를 제공한다.

카드의 안쪽 여백과 제목·가수 두 줄 사이의 간격은 [WebHome 화면 디자인](./web-home.md)의 웹 카드와 같게 한다. 곡에는 저장된 컬러가 없으므로 컬러를 나타내는 요소는 두지 않는다.

카드는 화면 너비와 관계없이 한 행에 두 개씩 표시되는 2열 고정 그리드로 배치하고, 카드 사이에는 가로와 세로로 각각 [공통 항목 간격](./dimens.md)을 둔다. 격자 바깥 여백은 [공통 화면 가로 여백과 세로 여백](./dimens.md)을 따른다. 썸네일 영역의 높이가 카드 폭으로 정해지고 제목과 가수가 모두 한 줄이어서 카드 높이가 서로 같으므로 지그재그 격자를 쓰지 않는다.

카드 전체를 누를 수 있는 자리로 두고, 누르면 그 곡의 [MusicDetail 화면](./music-detail.md)으로 이동한다. 카드에는 기본 눌림 표현을 쓰고, 목록에서 지금 보고 있는 곡을 따로 강조하는 선택 표현은 두지 않는다. 곡을 지우는 수단은 상세의 삭제 버튼 하나이므로 카드를 옆으로 미는 조작에는 반응하지 않는다.

아직 준비되지 않은 자리 표시 카드는 가리키는 곡이 없으므로 누를 수 있는 자리로 두지 않는다.

목록이 갱신될 때 카드가 자리를 옮기면 기본 항목 이동 애니메이션으로 옮긴다.

## 썸네일

썸네일은 카드 맨 위에 카드의 가로 폭을 모두 쓰는 `16:9` 영역으로 두고, 안쪽 여백 없이 카드의 위쪽 모서리에 맞붙인다. 제목과 가수의 안쪽 여백은 썸네일 아래부터 적용한다.

이미지는 영역을 가득 채우도록 잘라서 표시한다. YouTube가 주는 썸네일은 `4:3`이고 위아래에 검은 띠가 들어 있을 수 있으므로, 맞춰 넣지 않고 잘라 넣어 띠가 카드에 남지 않게 한다.

썸네일 영역은 다음 세 경우에 같은 크기를 그대로 차지한다. 곡마다 카드 높이가 달라지면 2열 격자에서 같은 행의 두 카드가 어긋나기 때문이다.

| 상태 | 표시 |
| --- | --- |
| 썸네일이 있고 이미지를 받아왔다 | 이미지를 잘라 채운다 |
| 이미지를 아직 받아오는 중이다 | 빈 자리로 둔다 |
| 링크가 없거나 영상을 가리키지 않거나 썸네일 주소를 열 수 없다 | 빈 자리로 둔다 |

빈 자리에는 카드 배경보다 한 단계 어두운 면만 두고 아이콘이나 문구를 넣지 않는다. 썸네일이 없는 것은 사용자가 고칠 수 있는 오류가 아니라 그 곡의 링크가 가진 상태이므로, 다시 시도할 것이 있다는 인상을 주지 않는다.

이미지가 도착하면 빈 자리에서 이미지로 바꾸고, 이때 카드의 다른 요소는 자리를 옮기지 않는다.

자리 표시 카드의 썸네일 영역도 준비된 카드와 같은 크기를 차지하며, 그 표현은 [페이지 조회 목록의 자리 표시 디자인](./paged-list-placeholder.md)을 따른다.

## 내려받기 준비 안내

[곡 다운로드 스펙](../spec/music-download.md)의 `내려받기 준비`가 정한 결과 중 사용자에게 알려야 하는 것은 스낵바로 표시한다. 스낵바를 두는 자리는 목록과 상세를 함께 표시하는 배치에서도 [목록·상세 배치 공통 디자인](./list-detail-pane.md)의 `진행과 피드백`을 따른다.

| 플랫폼 | 알리는 때 | 표시 |
| --- | --- | --- |
| 모두 | 준비가 되어 곧바로 받기 시작한다 | 아무것도 알리지 않는다 |
| JVM 데스크톱 | 없는 도구를 설치하고 이어서 받기 시작한다 | 아무것도 알리지 않는다 |
| JVM 데스크톱 | Homebrew가 없어 설치할 수 없다 | 직접 설치할 것을 알리는 스낵바 |
| JVM 데스크톱 | 설치하지 못했다 | 준비하지 못했음을 알리는 스낵바 |
| Android, iOS | 프록시 주소가 저장되어 있지 않다 | 설정에서 주소를 입력할 것을 알리는 스낵바 |
| Android, iOS | 프록시에 연결할 수 없다 | 연결할 수 없음을 알리는 스낵바 |

설치에 성공한 경우를 따로 알리지 않는 것은, 사용자가 요청한 일이 다운로드이지 설치가 아니기 때문이다. 설치가 끝나면 곡 카드에 상태가 나타나므로 다운로드가 시작된 것을 그 자리에서 확인한다.

Homebrew가 없을 때의 문구에는 사용자가 무엇을 해야 하는지가 드러나야 하므로 설치할 도구의 이름을 그대로 담는다. 설치에 실패했을 때는 원인을 나누지 않고 한 문구로 알린다. 사용자가 할 수 있는 일이 도구를 직접 확인하고 다시 시도하는 것으로 같기 때문이다.

프록시 주소가 없을 때의 문구에는 어디에서 무엇을 해야 하는지가 드러나야 하므로 설정 화면과 프록시 주소를 그대로 담는다. 연결할 수 없을 때는 주소가 틀린 것인지 JVM 데스크톱 앱이 꺼진 것인지 나누지 않고 한 문구로 알린다. 사용자가 확인할 곳이 설정의 주소와 JVM 데스크톱 앱 둘로 같기 때문이다.

스낵바에는 동작 버튼을 두지 않는다. 다시 시도하는 수단은 상단 바의 다운로드 버튼 하나로 충분하고, 설정으로 이동하는 버튼을 두면 진행 중인 목록 화면을 떠나게 된다.

## 다운로드 상태 표시

[곡 다운로드 스펙](../spec/music-download.md)의 `진행 확인`이 정한 곡별 상태를 그 곡의 썸네일 영역 위에 겹쳐 표시한다. 썸네일 영역은 카드에서 가장 넓고 글자가 없는 자리이므로, 상태를 여기에 두면 제목과 가수를 가리지 않는다.

상태를 표시해도 썸네일 영역과 카드의 크기는 바뀌지 않는다. 배지와 진행 막대는 모두 썸네일 위에 겹쳐 놓고 카드의 다른 요소를 밀어내지 않는다.

### 상태 배지

배지는 썸네일 영역의 오른쪽 위 모서리에 두고, 배지와 썸네일 가장자리 사이에 `8dp`를 둔다.

배지는 카드 표면보다 진한 불투명한 배경 위에 내용을 올린 알약 모양으로, 최소 크기는 `24dp`이고 내용에 맞춰 가로로만 늘어난다. 썸네일 이미지 위에서도 읽혀야 하므로 반투명하게 두지 않는다.

| 상태 | 배지 내용 | 색 |
| --- | --- | --- |
| 대기 | 시계 아이콘 | 기본 표면 위 내용 색 |
| 진행 중, 백분율 있음 | `62%`처럼 정수로 반올림한 백분율 글자 | 기본 표면 위 내용 색 |
| 진행 중, 백분율 없음 | 끝을 알 수 없는 원형 진행 표시 | 기본 표면 위 내용 색 |
| 완료 | 체크 아이콘 | 기본 표면 위 내용 색 |
| 실패 | 느낌표 아이콘 | 오류 색 |

아이콘과 원형 진행 표시의 크기는 `16dp`로 두고, 원형 진행 표시의 선 굵기는 `2dp`로 둔다. 백분율 글자는 가수 줄과 같은 작은 글자 크기를 쓴다. 배지의 내용과 양 끝 사이에는 `6dp`의 가로 여백을 둔다.

백분율이 없는 진행 중은 [곡 다운로드 스펙](../spec/music-download.md)의 `곡의 다운로드 상태`에 따라 Android와 iOS에서 프록시가 영상을 받아 합치는 동안에만 있다. 이때 `0%`를 표시하면 멈춘 것처럼 보이므로 숫자 대신 움직이는 진행 표시로 기다리고 있음을 알린다.

실패에만 오류 색을 쓰고 완료에는 강조 색을 쓰지 않는다. 대부분의 곡이 완료로 끝나므로 완료를 강조하면 격자 전체가 색으로 뒤덮이고, 그 안에서 실패한 곡이 묻힌다.

### 진행 막대

진행 중인 곡에만 썸네일 영역의 아래 변에 가로 진행 막대를 겹쳐 표시한다. 막대는 썸네일 폭 전체를 쓰고 높이는 `4dp`이며, 백분율이 있으면 받은 만큼을 채우고 백분율이 없으면 끝을 알 수 없는 가로 진행 표시로 움직인다.

진행 막대는 진행 중일 때만 둔다. 대기, 완료, 실패에는 막대를 두지 않고 배지만으로 알린다. 받고 있지 않은 곡에 빈 막대를 남겨 두면 곧 진행될 것처럼 읽힌다.

막대와 배지는 같은 백분율을 나타낸다. 멀리서 격자를 훑을 때는 막대의 길이로, 한 곡을 볼 때는 배지의 숫자로 읽는다. 백분율이 생기면 움직이던 막대가 그 자리에서 채워지는 막대로 바뀐다.

### 표시하지 않는 곡

다음 곡에는 배지와 진행 막대를 두지 않는다. 자리만 남겨 두지도 않는다.

- 다운로드를 실행한 적이 없어 아직 상태가 없는 곡
- 링크가 없거나 링크에서 영상을 얻을 수 없어 [곡 다운로드 스펙](../spec/music-download.md)의 `다운로드 대상 곡`에 해당하지 않는 곡
- 아직 준비되지 않은 자리 표시 카드

대상이 아닌 곡에 받을 수 없다는 표시를 따로 두지 않는다. 링크가 없는 것은 사용자가 고쳐야 하는 오류가 아니라 그 곡이 가진 상태이며, 같은 이유로 `썸네일` 절도 빈 자리에 아이콘이나 문구를 두지 않는다.

### 상태 전환

한 곡의 상태가 바뀌면 배지의 내용을 교차 전환으로 바꾸고 배지의 자리는 그대로 둔다. 진행 막대는 진행 중에 들어설 때 나타나고 진행 중에서 벗어날 때 사라지며, 채워지는 길이는 값이 바뀔 때마다 끊기지 않게 이어서 움직인다.

목록이 갱신되어 카드가 자리를 옮겨도 배지와 진행 막대는 그 카드를 따라 함께 움직인다.

## 자리 표시

아직 준비되지 않은 자리에는 [페이지 조회 목록의 자리 표시 디자인](./paged-list-placeholder.md)에 따라 자리 표시 카드를 표시한다. 이 목록의 자리 표시 카드는 썸네일, 제목과 가수를 비워 두고, 준비된 카드와 같은 높이를 차지한다.

## 빈 상태

표시할 곡이 하나도 없으면 격자 자리에 [목록 빈 상태 디자인](./list-empty-state.md)의 빈 상태를 표시한다. 이 목록은 플레이리스트 아이콘과 아래 `문구와 접근성`의 제목 문구·보조 문구를 사용하며, 격자와 빈 상태 사이의 전환도 그 문서를 따른다.

빈 상태에서도 상단 바의 다운로드 버튼은 같은 자리에 같은 모양으로 표시하고, 플로팅 액션 버튼을 표시하는 동안에는 그 버튼도 같은 자리에 같은 모양으로 둔다. 어느 요소에도 비활성 표현을 사용하지 않는다. 정렬 줄은 [목록 정렬 디자인](./list-sort.md)의 `항목이 없는 동안의 정렬 줄`에 따라 감춘다.

## 새로고침

본문 전체가 곡 목록 영역이므로 본문 전체를 [새로고침 디자인](./sync-refresh.md)의 당김 새로고침 컨테이너로 감싼다.

진행 표시는 본문 위쪽 가로 가운데에 겹쳐 표시하고 격자를 밀어내지 않는다. 진행 표시의 모양과 크기, 임계값, 나타나고 사라지는 모션, 진행 중 조작 가능 여부는 [새로고침 디자인](./sync-refresh.md)을 그대로 따르며 이 화면에서 따로 정하지 않는다.

격자는 맨 위에 있을 때만 당김이 시작된다. 격자 대신 빈 상태를 표시하는 동안에는 스크롤할 것이 없으므로 당김이 곧바로 시작된다.

목록과 상세를 함께 표시하는 배치에서 당김과 진행 표시를 두는 영역은 [새로고침 디자인](./sync-refresh.md)의 `적응형 배치`를 따라 목록 영역에만 둔다.

진행 표시는 본문 위쪽에, 플로팅 액션 버튼은 본문 오른쪽 아래에 놓이므로 두 요소는 겹치지 않는다. 진행 표시가 나타나 있는 동안에도 목록을 스크롤하고 곡 추가 버튼과 뒤로가기를 누르는 조작을 그대로 할 수 있으며, 어떤 요소도 비활성으로 표시하지 않는다.

## 적응형 배치

격자는 창 너비, 창 높이와 자세에 관계없이 2열을 유지하므로 목록 영역이 넓어지면 카드가 함께 넓어진다. 목록이 상세 영역과 자리를 나눠 쓰는 배치와 그 자리에서의 버튼 노출은 [Playlist 목록·상세 배치 디자인](./playlist-list-detail.md)이 정한다.

다운로드 버튼은 창 너비와 관계없이 이 화면의 상단 바 끝에 둔다. 상세 영역과 자리를 나눠 표시하는 동안에도 목록 영역의 상단 바에 그대로 두고 상세 영역의 상단 바로 옮기지 않는다. 다운로드의 대상이 목록의 곡 전체이기 때문이다.

격자의 카드가 좁아져도 상태 배지의 크기와 진행 막대의 높이는 그대로 두어 어느 폭에서도 같게 읽히게 한다.

본문은 시스템 상태 영역과 디스플레이 컷아웃에 가려지지 않는 자리에 두고, 격자의 마지막 카드가 플로팅 액션 버튼에 가리지 않게 배치한다.

## 문구와 접근성

한국어 환경과 그 외 기본 환경에서 다음 문구를 사용한다.

| 항목 | 한국어 | 그 외 기본 |
| --- | --- | --- |
| 상단 바 제목 | `플레이리스트` | `Playlist` |
| 뒤로가기 접근성 이름 | `뒤로가기` | `Navigate up` |
| 곡 추가 버튼 접근성 이름 | `곡 추가` | `Add music` |
| 다운로드 버튼 접근성 이름 | `곡 다운로드` | `Download music` |
| 대기 상태 이름 | `다운로드 대기 중` | `Waiting to download` |
| 진행 중 상태 이름, 백분율 있음 | `다운로드 중 62%` | `Downloading 62%` |
| 진행 중 상태 이름, 백분율 없음 | `다운로드 중` | `Downloading` |
| 완료 상태 이름 | `다운로드 완료` | `Downloaded` |
| 실패 상태 이름 | `다운로드 실패` | `Download failed` |
| Homebrew 없음 안내 | `yt-dlp와 ffmpeg이 필요합니다. 직접 설치한 뒤 다시 시도해 주세요` | `yt-dlp and ffmpeg are required. Install them and try again.` |
| 도구 준비 실패 안내 | `다운로드 도구를 준비하지 못했습니다` | `Could not prepare the download tools.` |
| 프록시 주소 없음 안내 | `설정의 다운로드에서 프록시 주소를 입력해 주세요` | `Enter the proxy address in Settings > Download.` |
| 프록시 연결 실패 안내 | `다운로드 프록시에 연결할 수 없습니다` | `Could not connect to the download proxy.` |
| 빈 상태 제목 문구 | `아직 곡이 없습니다` | `No music yet` |
| 빈 상태 보조 문구 | `추가 버튼으로 새 곡을 담을 수 있습니다` | `Use the add button to add music.` |

진행 중 상태 이름의 숫자 자리에는 배지에 표시한 백분율을 그대로 넣고, 백분율이 없는 동안에는 숫자 없이 진행 중임만 읽힌다.

곡 카드에는 카드에 표시한 제목과 가수를 접근성 이름으로 그대로 쓰고, 가수가 없는 곡은 제목만 쓴다. 누르면 무엇이 일어나는지는 낭독 도구가 알리는 기본 동작 설명에 맡긴다.

다운로드 상태가 있는 곡은 상태 배지에 그 상태 이름을 접근성 이름으로 둔다. 카드를 낭독할 때 제목과 가수에 이어 상태 이름이 함께 읽힌다. 진행 막대에는 이름을 두지 않는다. 배지와 막대가 같은 값을 나타내므로 이름을 두 곳에 두면 같은 상태를 두 번 읽는다.

썸네일은 영상의 내용을 글로 옮길 수 없고 같은 카드의 제목과 가수가 이미 그 곡을 가리키므로, 낭독 도구에 이름을 따로 두지 않고 장식으로 다룬다. 자리 표시 카드의 접근성 처리는 [페이지 조회 목록의 자리 표시 디자인](./paged-list-placeholder.md)을 따른다.
