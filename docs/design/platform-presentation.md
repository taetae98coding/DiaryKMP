# 플랫폼별 컴포넌트 표현 범위 디자인

이 문서는 iOS에서 시스템 표현으로 그리는 공통 컴포넌트의 목록을 소유한다. 각 컴포넌트의 iOS 표현은 그 컴포넌트를 소유하는 문서가 정하고, 이 문서는 어느 컴포넌트가 플랫폼별 표현을 갖는지만 정한다.

이 문서는 이미 있는 컴포넌트의 표현 범위만 다루고 사용자 행위나 제품 정책을 새로 정의하지 않으므로 기준 스펙을 두지 않는다.

## iOS에서 시스템 표현으로 그리는 컴포넌트

iOS에서는 다음 컴포넌트만 iOS 26의 시스템 Liquid Glass 표현으로 그린다. 모두 본문 위에 떠서 화면을 조작하는 요소다.

| 컴포넌트 | iOS 표현을 소유하는 문서 |
| --- | --- |
| 떠 있는 동작 버튼(추가·확인·올리기 버튼과 떠 있는 메뉴 버튼) | [떠 있는 동작 버튼](./floating-action-button.md) |
| 상단 바의 뒤로가기 버튼 | [상단 바](./top-bar.md) |
| 상단 바의 동작 버튼 | [상단 바](./top-bar.md) |
| 상단 바의 검색 입력 | [상단 바](./top-bar.md) |

이 목록에 없는 컴포넌트는 iOS에서도 다른 플랫폼과 같은 Material 3 표현을 쓴다. 새 컴포넌트를 iOS 시스템 표현으로 그리려면 이 목록에 먼저 더한다.
