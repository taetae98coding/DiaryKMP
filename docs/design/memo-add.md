# MemoAdd 화면 디자인

기준 스펙: [MemoAdd 화면 스펙](../spec/memo-add.md)

## 적응형 화면 구조

MemoHome에서 진입하면 넓은 화면에서는 메모 목록과 MemoAdd 화면을 좌우로 함께 표시하고, 좁은 화면에서는 MemoAdd 화면만 표시한다. 함께 표시할 때의 배치와 버튼 노출은 [Memo 목록·상세 배치 디자인](./memo-list-detail.md)을 따른다.

TagDetail 메모 탭에서 진입하면 창 너비와 관계없이 MemoAdd 화면만 단독으로 표시한다. 그 기준은 [TagDetail 메모 탭 디자인](./tag-detail-memo.md)의 `메모 추가`를 따른다.

캘린더 홈에서 진입한 MemoAdd 화면은 창 너비와 관계없이 단독으로 표시한다.

화면 상단에는 제목을 표시하는 상단 바를 둔다. MemoAdd 화면을 단독으로 표시할 때 상단 바에 뒤로가기 버튼을 표시한다.

상단 바 끝 쪽 액션 자리에는 작성 도우미를 여는 버튼 하나를 둔다. 버튼의 아이콘, 표시 조건과 다이얼로그는 [메모 Gemini 작성 도우미 디자인](./memo-gemini.md)을 따른다.

본문의 구성과 순서, 적응형 배치, 영역 여백과 스크롤은 [메모 본문 배치 디자인](./memo-form.md)을 따른다.

메모 추가 동작은 본문 위에 떠 있는 추가 버튼으로 제공하고, 버튼의 자리는 [메모 본문 배치 디자인](./memo-form.md)을 따른다.

본문과 추가 버튼, 스낵바의 표시 영역과 소프트 키보드 대응도 [메모 본문 배치 디자인](./memo-form.md)을 따른다.

상단 바의 뒤로가기 버튼이나 시스템 뒤로가기를 사용하면 진입하기 전 화면으로 돌아간다.

## 입력 상태

제목 입력은 단일 줄 입력 칸으로 표시한다. 초점을 어느 입력에 두고 언제 옮기는지는 기준 스펙이 정하며, 초점이 옮겨 간 입력에는 그 입력에 맞는 소프트 키보드를 연다.

MemoHome이나 TagDetail 메모 탭에서 진입하면 기간 입력은 스위치가 꺼진 상태로 표시한다.

캘린더 홈에서 선택한 기간으로 진입하면 기간 입력의 스위치를 켜고, 전달된 시작일과 종료일을 종일 기간으로 표시한다.

TagDetail 메모 탭에서 진입하면 상세 대상 태그를 대표 태그 칩으로 표시한다.

## 추가 동작과 피드백

사용자는 추가 버튼을 누르거나 물리 키보드에서 `Cmd`(또는 `Meta`)와 `Enter`를 함께 눌러 메모 추가를 실행한다.

추가를 처리하는 동안에는 추가 버튼의 추가 아이콘을 진행 표시로 바꾼다.

추가에 성공하면 컬러에 새 무작위 값을 표시하고, 기간과 태그 입력, 웹 입력은 현재 선택을 유지한다. 성공 안내는 스낵바로 표시한다.

제목 미입력 안내도 스낵바로 표시한다.

## 문구와 접근성

한국어 환경과 그 외 기본 환경에서 다음 문구를 사용한다.

| 항목 | 한국어 | 그 외 기본 |
| --- | --- | --- |
| 상단 바 제목 | `메모 추가` | `Add Memo` |
| 뒤로가기 버튼 접근성 이름 | `뒤로가기` | `Navigate up` |
| 추가 버튼 접근성 이름 | `메모 추가` | `Add memo` |
| 추가 성공 안내 | `메모가 추가되었습니다.` | `Memo added.` |
| 제목 미입력 안내 | `제목을 입력해 주세요.` | `Please enter a title.` |

태그 입력의 문구는 [메모 태그 입력 컴포넌트 디자인](./memo-tag-input.md)을, 웹 입력의 문구는 [메모 웹 입력 컴포넌트 디자인](./memo-web-input.md)을, 작성 도우미의 문구는 [메모 Gemini 작성 도우미 디자인](./memo-gemini.md)을 따른다.
