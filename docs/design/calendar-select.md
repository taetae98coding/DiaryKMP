# Calendar 날짜 선택 디자인

기준 스펙: [Calendar 날짜 선택 스펙](../spec/client/calendar-select.md)

이 문서의 조작, 촉각 피드백, 선택 표시는 달 화면과 주 목록 어디에 배치하든 같게 적용하고, 선택 중 달 이동만 달을 넘겨 보는 화면에 적용한다.

## 선택 영역

선택 영역은 배치하는 화면이 선택에 사용하는 주 목록이 차지하는 사각 영역 전체다. 영역의 가로는 일요일부터 토요일까지 일곱 칸으로, 세로는 목록에 놓인 주의 수만큼 같은 높이로 나눈다.

각 날짜의 선택 영역은 날짜 숫자와 그 아래 아이템 영역을 포함한 날짜 칸의 세로 영역 전체다. 아이템이 표시된 영역에서 선택 조작을 시작해도 해당 위치의 날짜를 선택한다. 다만 배치하는 화면이 특정 아이템에 별도의 길게 누르기 조작을 지정하면 그 아이템 영역에서는 선택을 시작하지 않는다. 캘린더 홈의 메모 제목은 [캘린더 메모 이동 디자인](calendar-memo-move.md)의 이동 조작을 시작한다.

포인터가 선택 영역 밖으로 나가면 영역 안에서 가장 가까운 날짜 칸을 가리키는 것으로 다룬다.

## 선택 조작

사용자가 날짜 칸을 길게 누르면 해당 날짜에서 선택을 시작한다.

길게 누른 상태를 유지한 채 다른 날짜 칸으로 드래그하면 현재 날짜를 바꾸고 선택 기간을 갱신한다. 사용자는 위아래로 드래그해 주 경계를 넘는 기간도 선택할 수 있다.

사용자가 손을 떼면 선택을 완료한다. 다른 날짜로 드래그하지 않고 손을 떼면 처음 날짜 하루로 완료한다.

시스템이 제스처를 중단하면 손을 뗀 것과 같이 그 시점의 기간으로 선택을 완료한다. 화면이 재생성되어 제스처가 끊기면 선택을 완료하지 않고, 재생성된 화면에는 선택 표시를 그리지 않는다. 날짜 선택을 위한 드래그는 선택 영역을 담은 스와이프나 스크롤 조작으로 처리하지 않는다. 달을 넘겨 보는 화면에서 선택 중의 달 이동은 아래 선택 중 달 이동의 가장자리 머무름으로만 일어난다.

## 촉각 피드백

날짜 칸의 길게 누르기가 인식되어 선택이 시작되는 순간에는 플랫폼의 길게 누르기 촉각 피드백을 한 번 제공한다.

선택을 시작한 뒤 드래그로 선택 기간이 달라질 때마다 많은 연속 선택지를 넘길 때 사용하는 가벼운 구간 전환 촉각 피드백을 한 번 제공한다. 같은 날짜 칸 안에서 움직이는 것처럼 선택 기간이 그대로인 경우에는 반복하지 않는다.

촉각 피드백의 실제 제공 여부와 세기는 기기의 지원 범위와 사용자의 시스템 설정을 따른다. 촉각 피드백이 제공되지 않아도 날짜 선택과 표시는 동일하게 동작한다.

## 선택 중 달 이동

이 절은 한 달의 주를 모두 보여 주며 달을 넘겨 보는 화면에만 적용한다. 주 목록이 고정된 화면에서는 가장자리 영역을 두지 않고, 선택 중에 목록을 스크롤하거나 화면을 넘기지 않는다.

선택 중 달 이동을 트리거하는 가장자리 영역은 캘린더 좌우 끝에서 안쪽으로 24dp 너비다.

드래그 중인 손가락이 가장자리 영역에 들어오면 곧바로 달 이동을 시작한다. 달 전환이 끝난 시점에 손가락이 여전히 가장자리 영역에 있으면 다음 이동을 이어서 시작하고, 가장자리 영역을 벗어나면 반복을 멈춘다.

달 전환은 스와이프 달 이동과 같은 페이지 전환으로 표현한다. 전환이 진행되는 동안에도 선택 배경은 선택 표시를 따라 그대로 유지된다.

## 선택 표시

선택된 기간은 날짜 칸을 덮는 배경으로 표시한다.

각 주에서는 선택 기간과 겹치는 날짜 칸에 걸쳐 배경을 가로로 이어서 표시한다. 선택 기간이 주 경계를 넘으면 겹치는 각 주에 나누어 표시한다.

선택 배경은 날짜 숫자와 아이템 뒤에 배치해 내용을 가리지 않는다.

배경에는 화면 테마의 주 색상을 불투명도 `24%`로 옅게 적용한 색을 사용해 날짜 숫자와 아이템을 읽는 데 방해되지 않게 한다.
