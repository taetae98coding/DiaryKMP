# SettingBrowser 화면 디자인

기준 스펙: [SettingBrowser 화면 스펙](../spec/setting-browser.md)

## 화면 구조

SettingBrowser의 단독·목록/상세 배치와 표시 상태에 따른 뒤로가기 동작 노출은 [Setting 목록·상세 배치 디자인](./setting-list-detail.md)을 따른다.

화면 상단에는 제목이 있는 상단 바를 두고, 뒤로가기 동작을 제공하는 상태에서는 상단 바에 함께 배치한다.

본문에는 브라우저 설정을 설정별 영역으로 나누어 세로로 배치한다. 설정 항목이 늘어나 본문이 표시 영역보다 길어지면 위아래로 스크롤할 수 있다.

## Chrome 프로필 선택

`Chrome 로그인 이어받기` 설정 이름을 선택 줄 묶음 위에 두고, 그 아래에 설정이 무엇을 하는지 알리는 보조 문구를 설정 이름보다 작은 글자와 낮은 강조 색으로 둔다. 설정 이름과 보조 문구는 묶음 안에 넣지 않고 묶음 바깥의 영역 제목으로 둔다.

설정 이름과 보조 문구는 묶음의 바깥 가장자리에 맞춰 시작 쪽으로 정렬하고, 보조 문구와 묶음 사이에는 [항목 간격](./dimens.md)을 둔다.

묶음에는 `선택 안 함`을 첫 줄로 두고, 그 아래에 Chrome 프로필을 기준 스펙이 정한 순서로 한 줄씩 표시한다. 각 프로필 줄에는 프로필 이름만 표시한다. 줄의 배경과 모양, 줄 사이 간격, 누름과 선택 상태의 표현은 [묶음 목록 항목 디자인](./segmented-list-item.md)의 하나만 고르는 묶음을 따른다. 줄 사이에는 구분선을 두지 않는다.

현재 선택 한 줄만 선택 상태로 표시한다. 저장된 프로필이 목록에 없으면 `선택 안 함` 줄을 선택 상태로 표시한다. 사용자는 줄 전체를 선택할 수 있고, 줄 시작 쪽의 라디오 버튼만 따로 누르는 대상으로 두지 않는다.

Chrome 프로필이 하나도 없으면 묶음에 `선택 안 함` 한 줄만 두고, 프로필이 없다는 별도 안내는 두지 않는다.

프로필 목록을 읽지 못했으면 묶음에 `선택 안 함` 한 줄만 두고, 묶음 아래에 [항목 간격](./dimens.md)을 띄워 조회할 수 없다는 안내 문구를 보조 문구와 같은 글자와 색으로 둔다.

저장된 선택을 확인하기 전이거나 읽지 못한 상태에서는 이 설정 영역을 설정 이름까지 함께 표시하지 않는다. 별도의 로딩 안내나 오류 안내도 표시하지 않는다.

## 문구와 접근성

한국어 환경과 그 외 기본 환경에서는 다음 문구를 사용한다.

| 문구 | 한국어 | 그 외 기본 |
| --- | --- | --- |
| 상단 바 제목 | `브라우저 설정` | `Browser Settings` |
| 뒤로가기 접근성 이름 | `뒤로가기` | `Navigate up` |
| Chrome 로그인 이어받기 설정 이름 | `Chrome 로그인 이어받기` | `Use Chrome logins` |
| Chrome 로그인 이어받기 보조 문구 | `고른 Chrome 프로필에서 로그인한 사이트를 앱 안에서도 로그인된 상태로 엽니다` | `Opens sites you're signed in to in the chosen Chrome profile as signed in inside the app` |
| 선택 안 함 항목 이름 | `선택 안 함` | `None` |
| 프로필 조회 실패 안내 | `Chrome 프로필을 조회할 수 없습니다` | `Couldn't load Chrome profiles` |
| 프로필 항목 이름 | Chrome 프로필 이름 | Chrome 프로필 이름 |
