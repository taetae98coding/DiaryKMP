# 제목 입력 디자인

기준 스펙: [제목 입력 스펙](../spec/client/title-input.md)

이 문서는 항목의 제목을 한 줄로 입력하는 제목 입력의 구성, 라벨, 지우기 버튼, 소프트 키보드와 문구를 소유한다. 각 화면 문서는 제목 입력을 본문 어느 자리에 두는지와 그 화면에서만 다른 표현만 남긴다.

이 문서를 따르는 디자인 문서는 다음과 같다.

- [MusicAdd 화면 디자인](./music-add.md)
- [MusicDetail 화면 디자인](./music-detail.md)
- [PlaceAdd 화면 디자인](./place-add.md)
- [PlaceDetail 화면 디자인](./place-detail.md)
- [RoutineAdd 화면 디자인](./routine-add.md)
- [TagAdd 화면 디자인](./tag-add.md)
- [TagDetail 화면 디자인](./tag-detail.md)
- [WebAdd 화면 디자인](./web-add.md)
- [WebDetail 화면 디자인](./web-detail.md)

## 구성

제목 입력은 카드 하나 안에 단일 줄 텍스트 입력 칸 하나를 담는다. 카드의 모양과 색은 카드 컴포넌트의 기본값을 그대로 쓰고, 입력 칸은 카드의 가로 폭을 모두 사용한다. 제목 입력의 가로 폭은 배치한 자리가 정한다.

입력 칸은 채움 텍스트 입력의 기본 배경을 쓰고, 입력 칸 아래의 밑줄 표시는 초점 여부와 관계없이 두지 않는다. 카드 안에 담아 다른 입력과 이미 구분되므로 밑줄로 한 번 더 경계를 긋지 않는다. 이는 [설명 입력 컴포넌트 디자인](./description-input.md)이 입력을 카드에 담는 기준과 같다.

제목 입력의 높이는 단일 줄 텍스트 입력의 기본 높이이며, 입력한 제목의 길이와 관계없이 바뀌지 않는다. [태그 이모지 입력 컴포넌트 디자인](./tag-emoji-input.md)은 이 높이에 맞춰 크기를 정한다.

## 라벨과 입력

입력 칸에는 `제목` 라벨을 둔다. 라벨은 Material 텍스트 입력의 기본 표현을 따라, 입력 칸이 비어 있고 초점이 없으면 입력 칸 안에 표시하고, 초점을 받거나 값이 있으면 입력 칸 위쪽으로 작게 옮겨 표시한다. 라벨이 입력 칸의 접근성 이름이 된다. 자리 표시 문구는 따로 두지 않는다.

제목이 필요한 화면이어도 라벨에 필수 표시를 두지 않고, 비어 있는 입력에 오류 색을 상시로 두지 않는다. 필요한 안내는 각 화면 문서가 정한 방식으로 추가나 수정을 실행한 시점에만 제공한다.

입력한 제목이 폭을 넘어도 줄을 늘리지 않고 한 줄을 유지하며, 커서가 있는 자리가 보이도록 입력 칸 안에서 가로로 움직인다.

## 지우기 버튼

입력한 값이 있으면 입력 칸 끝 쪽에 지우기 버튼을 표시하고, 값이 비어 있으면 자리까지 함께 감춘다. 나타나고 사라지는 표현과 누른 뒤의 초점은 [나타나고 사라지는 버튼 디자인](./button-visibility.md)을 따르고, 아이콘만 표시하므로 [아이콘 버튼 설명 디자인](./icon-button-tooltip.md)의 설명 표시를 함께 둔다.

지우기 버튼을 누르면 입력한 제목을 모두 지우고 초점은 제목 입력에 남긴다.

## 소프트 키보드와 초점

소프트 키보드는 일반 텍스트 키보드를 요청한다. 한 줄 입력이므로 동작 키는 줄바꿈이 아니라 완료로 표시되고, 누르면 소프트 키보드를 닫는다.

초점을 언제 제목 입력에 두는지는 기준 스펙과 각 화면 스펙이 정한다. 초점을 받으면 커서를 입력 칸에 두고 소프트 키보드를 연다.

## 물리 키보드 초점 이동

물리 키보드 환경에서는 제목 입력에서 `Tab`을 눌러 다음 입력으로 초점을 옮긴다. 옮겨 갈 곳은 기준 스펙의 `domain > 제목 다음 초점`을 따른다. 제목 입력 바로 뒤에 설명 입력이 있고 설명 입력이 입력 페이지를 보여 주고 있으면, 입력 칸 끝의 지우기 버튼을 건너뛰고 설명 입력 페이지의 입력 칸으로 초점을 옮긴다. 설명 입력이 미리보기 페이지를 보여 주고 있으면 화면에 놓인 순서대로 지우기 버튼부터 초점을 옮긴다.

## 문구와 접근성

한국어 환경과 그 외 기본 환경에서 다음 문구를 사용한다.

| 항목 | 한국어 | 그 외 기본 |
| --- | --- | --- |
| 입력 라벨 | `제목` | `Title` |
| 지우기 버튼 접근성 이름 | `지우기` | `Clear text` |
