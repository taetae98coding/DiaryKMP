# 공유로 항목 추가 디자인

기준 스펙: [공유로 항목 추가 스펙](../spec/client/share-add.md)

이 문서는 다른 앱의 공유 대상 목록에 Diary가 보이는 모습, 공유를 받는 동안과 받지 못했을 때의 안내, 공유로 열린 추가 화면의 표시를 소유한다. 어떤 공유를 받고 어느 화면을 열며 무엇을 채우는지는 기준 스펙을 따른다.

공유 대상 목록과 공유 시트는 운영체제가 그리며, 배치, 크기, 순서, 글자 크기와 색은 운영체제가 정한다. 이 문서는 운영체제에 넘기는 이름과 아이콘, Diary가 직접 보여 주는 안내만 정한다.

## 공유 대상

Diary는 공유 대상 목록에 앱 아이콘과 앱 이름 하나로 보인다. 이름은 [앱 이름 스펙](../spec/client/app-name.md)의 환경별 앱 이름이고, 아이콘은 홈 화면의 앱 아이콘과 같다. 기능을 설명하는 부제나 항목 종류별 대상은 두지 않는다.

| 플랫폼 | 보이는 곳 |
| --- | --- |
| Android | 공유 시트의 앱 목록 |
| iOS, iPadOS | 공유 시트 위쪽의 앱 아이콘 줄 |

Android에서는 최근 대화 상대처럼 특정 대상을 바로 고르는 바로 공유 항목을 두지 않는다. iOS에서는 공유 시트 아래쪽의 동작 목록에 Diary를 두지 않는다.

## 공유를 받는 동안

사용자가 Diary를 고른 뒤 공유 Add 화면이 보이기 전까지 Diary는 따로 진행 표시를 두지 않는다. 공유 내용을 읽는 일은 짧게 끝나므로 진행 표시가 잠깐 나타났다 사라지는 깜빡임을 만들지 않기 위해서다.

| 플랫폼 | 표시 |
| --- | --- |
| Android | 공유하던 앱의 화면이 그대로 보이다가 Diary 앱으로 넘어간다 |
| iOS, iPadOS | Diary가 그린 내용이 없는 공유 시트가 잠깐 나타났다가 Diary 앱으로 넘어간다 |

## 공유 Add 화면

공유 Add 화면은 다른 경로로 연 같은 추가 화면과 같은 디자인을 쓴다. 화면 구조, 입력, 버튼, 문구와 접근성은 [WebAdd 화면 디자인](./web-add.md), [MemoAdd 화면 디자인](./memo-add.md), [ContactAdd 화면 디자인](./contact-add.md)을 따른다.

공유 Add 화면은 목록과 함께 놓이지 않는 단독 화면으로 표시하므로, 상단 바에는 각 화면 디자인이 단독 표시에서 두는 뒤로가기 버튼이 보인다. 목록과 상세를 함께 쓸 수 있는 넓은 창에서도 단독 화면의 표현을 따른다.

공유로 채운 값은 사용자가 입력한 값과 같은 모습으로 보인다. 채운 값을 따로 강조하거나 공유로 채웠다는 표시를 두지 않는다. 입력 초점이 놓이는 자리는 각 화면 디자인이 그 화면에 처음 들어왔을 때 두는 자리다.

## 받지 못했을 때의 안내

기준 스펙이 안내하도록 정한 경우에만 Diary 화면을 열지 않고 공유하던 앱 위에 짧은 안내를 보여 준다. 받지 않는 공유는 안내 없이 끝나며, iOS에서는 공유 시트가 바로 닫힌다.

| 플랫폼 | 안내의 모습 | 닫힘 |
| --- | --- | --- |
| Android | 화면 아래쪽에 잠깐 떠올랐다 사라지는 시스템 안내 한 줄 | 짧은 표시 시간이 지나면 저절로 사라진다 |
| iOS, iPadOS | 공유 시트 위에 제목, 본문과 `확인` 버튼이 있는 시스템 경고 | `확인`을 누르면 경고와 공유 시트가 함께 닫힌다 |

iOS 경고는 버튼 하나만 두며 다시 시도하는 버튼은 두지 않는다. 기준 스펙에 따라 공유 내용을 남기지 않으므로 사용자는 공유하던 앱에서 다시 공유한다.

Android에는 공유한 내용이 너무 길 때의 안내만, iOS에는 Diary 앱을 열지 못했을 때의 안내만 있다.

## 문구

문구는 기기의 앱 언어를 따른다. 앱 이름은 환경마다 다르므로 문구에 넣지 않는다.

| 안내 | 요소 | 한국어 | 영어 |
| --- | --- | --- | --- |
| 너무 긴 공유 | Android 안내 | `공유한 내용이 너무 깁니다` | `The shared content is too long` |
| 앱을 열지 못함 | iOS 경고 제목 | `앱을 열지 못했습니다` | `Couldn't open the app` |
| 앱을 열지 못함 | iOS 경고 본문 | `다시 공유해 주세요.` | `Please try sharing again.` |
| 앱을 열지 못함 | iOS 경고 버튼 | `확인` | `OK` |

## 접근성

공유 대상의 이름은 운영체제가 앱 이름으로 읽는다. 아이콘은 이름을 그림으로 거듭 보여 주는 장식이므로 따로 접근성 이름을 두지 않는다.

Android 안내는 시스템이 나타날 때 한 번 읽는다. iOS 경고는 시스템이 제목과 본문을 이어 읽고, 초점을 `확인` 버튼에 둔다.
