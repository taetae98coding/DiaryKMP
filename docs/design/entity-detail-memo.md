# 항목 상세 메모 탭 공통 디자인

기준 스펙: [항목 상세 메모 탭 공통 스펙](../spec/entity-detail-memo.md)

이 문서는 ContactDetail, PlaceDetail, WebDetail 화면의 메모 탭 안에서 공통으로 쓰는 표현을 소유한다. 화면 전체의 구조, 상단 바, 탭 행과 탭 전환, 떠 있는 버튼의 교체, 메모 탭이 놓이는 자리는 [ContactDetail 화면 디자인](./contact-detail.md), [PlaceDetail 화면 디자인](./place-detail.md), [WebDetail 화면 디자인](./web-detail.md)이 각각 소유한다.

## 이 문서를 참조하는 문서

- [ContactDetail 화면 디자인](./contact-detail.md)
- [PlaceDetail 화면 디자인](./place-detail.md)
- [WebDetail 화면 디자인](./web-detail.md)

## 탭 구성

메모 탭 안은 위에서부터 정렬 줄과 메모 목록을 세로로 쌓는다. 두 요소 사이에는 [공통 구성요소 간격](./dimens.md)을 둔다.

메모 탭에는 목록 위에 다른 목록으로 이동하는 진입 버튼을 두지 않는다. 이 탭은 완료된 메모를 모아 보는 화면을 갖지 않기 때문이며, 이는 완료된 메모 진입 버튼을 두는 [TagDetail 메모 탭 디자인](./tag-detail-memo.md)과 다른 기준이다.

메모 탭은 상세 대상 항목의 조회 상태와 관계없이 같은 구성을 표시한다. 항목을 아직 조회하지 못해 상단 바에 제목이 없는 동안에도 정렬 줄과 목록은 같은 기준으로 표시한다.

## 메모 추가

메모 추가는 메모 탭을 선택한 동안 떠 있는 메모 추가 버튼으로 제공한다. 버튼에는 추가를 나타내는 플러스 아이콘을 쓰며, 이는 [MemoHome 목록 디자인](./memo-home.md)의 메모 추가 버튼과 같은 아이콘이다. 상세 대상 항목의 삭제 여부와 조회 결과는 이 버튼의 노출을 바꾸지 않는다.

버튼을 두는 자리와 다른 탭의 떠 있는 버튼과 교체되는 표현은 각 화면 디자인이 정한다.

메모 추가를 선택하면 MemoAdd 화면을, 메모를 선택하면 MemoDetail 화면을 표시한다. 두 화면은 창 너비와 관계없이 상세 화면과 함께 배치하지 않고 단독으로 표시한다.

MemoAdd 화면은 상세 대상 항목을 해당 입력에 이미 고른 상태로 시작한다. 연락처는 [메모 연락처 입력 디자인](./memo-contact-input.md)의 연락처 칩으로, 웹 항목은 [메모 웹 입력 디자인](./memo-web-input.md)의 웹 칩으로, 장소는 [메모 장소 카드 디자인](./memo-place-card.md)의 장소 표시로 나타나며, 별도의 강조나 잠금 표시를 두지 않아 사용자가 그 선택을 해제할 수 있음을 드러낸다. 태그 입력은 고른 태그가 없는 상태로 시작한다.

## 정렬 줄

정렬 줄은 탭 행 바로 아래, 메모 목록 위에 둔다. 줄의 시작 쪽에 정렬 컨트롤을 두고 끝 쪽은 비워 둔다. 정렬 줄과 정렬 선택 Bottom Sheet의 구조, 조작, 아이콘과 문구는 [목록 정렬 디자인](./list-sort.md)을 따른다.

## 목록

메모 카드의 제목, 컬러, 기간과 카드 사이 간격은 [MemoHome 목록 디자인](./memo-home.md)을 따른다.

기간 없는 메모는 목록 맨 위에 헤더 없이 표시한다. 기간 있는 메모는 시작 날짜별로 묶고 각 묶음 위에 날짜 헤더를 둔다. 헤더의 표시와 고정 방식은 MemoHome 목록 디자인을 따른다.

아직 준비되지 않은 자리에는 [페이지 조회 목록의 자리 표시 디자인](./paged-list-placeholder.md)에 따라 자리 표시 카드를 표시한다.

표시할 메모가 하나도 없으면 목록 자리에 [목록 빈 상태 디자인](./list-empty-state.md)의 빈 상태를 표시한다. 세 탭 모두 메모 아이콘을 쓰고, 제목 문구는 그 문서의 문구 표가 화면마다 정한다. 빈 상태에서도 떠 있는 메모 추가 버튼은 같은 자리에 그대로 표시한다. 정렬 줄은 [목록 정렬 디자인](./list-sort.md)의 `항목이 없는 동안의 정렬 줄`에 따라 감춘다.

조회 실패에는 별도 오류 안내나 재시도 버튼을 표시하지 않는다. 조회에 실패해 표시할 메모가 없을 때도 같은 빈 상태를 사용한다.

목록의 스크롤 위치는 다른 탭에 다녀와도 그대로 유지한다.

## 새로고침

목록을 아래로 당겨 새로고침하며, 당기는 조작과 진행 표시는 [새로고침 디자인](./sync-refresh.md)을 따른다. 목록이 빈 상태일 때도 같은 자리에서 당길 수 있다.

## 완료·삭제 제스처와 피드백

[SwipeToFinishAndDelete 컴포넌트 디자인](./swipe-to-finish-and-delete.md)에 따라 카드를 왼쪽에서 오른쪽으로 스와이프하면 완료하고, 오른쪽에서 왼쪽으로 스와이프하면 삭제한다.

완료 또는 삭제 뒤의 피드백과 실행 취소는 스낵바로 표시한다. 스낵바는 각 화면 디자인이 정한 화면 공통 자리를 사용하므로, 다른 탭의 수정 성공 안내와 같은 자리에 표시된다.

## 키보드 단축키

메모 탭을 선택한 동안 물리 키보드로 `Command + A`를 눌러 메모를 추가한다. 이는 [TagDetail 화면 디자인](./tag-detail.md)의 목록 탭이 쓰는 추가 단축키와 같은 기준이다.

다른 탭을 선택한 동안에는 이 단축키를 처리하지 않는다. 각 화면이 다른 탭에서 처리하는 단축키는 그 화면 디자인이 정한다.

## 문구와 접근성

한국어 환경과 그 외 기본 환경에서는 다음 문구를 사용한다.

| 문구 | 한국어 | 그 외 기본 |
| --- | --- | --- |
| 메모 탭 접근성 이름 | `메모` | `Memo` |
| 추가 버튼 접근성 이름 | `메모 추가` | `Add memo` |
| 완료 안내 | `메모가 완료되었습니다.` | `Memo finished.` |
| 삭제 안내 | `메모가 삭제되었습니다.` | `Memo deleted.` |
| 실행 취소 동작 | `실행 취소` | `Undo` |
| 완료 스와이프 아이콘 접근성 이름 | `메모 완료` | `Finish memo` |
| 삭제 스와이프 아이콘 접근성 이름 | `메모 삭제` | `Delete memo` |
| 오늘 날짜 헤더 | `오늘` | `Today` |

메모 카드의 접근성 이름은 [MemoHome 목록 디자인](./memo-home.md)을 따른다. 빈 상태 문구는 [목록 빈 상태 디자인](./list-empty-state.md)의 문구 표가 소유한다.
