# Setting 목록·상세 배치 디자인

기준 스펙: [Setting 목록·상세 배치 스펙](../spec/client/setting-list-detail.md)

배치, 크기 조절, 버튼 노출, 선택 전 상세와 조절 상태 표시의 공통 표현은 [목록·상세 배치 공통 디자인](./list-detail-pane.md)을 따른다.

## 두 영역에 두는 화면

목록 영역에는 설정 목록을 두고, 상세 영역에는 선택한 설정 화면을 표시한다. 각 상태에서 사용할 화면과 뒤로가기 결과, 공통 내비게이션 제공 여부는 기준 스펙과 각 화면 스펙을 따른다.

## 선택 전 상세

아직 설정 항목을 선택하지 않았으면 상세 영역에 설정을 나타내는 아이콘과 설정 항목을 선택하라는 안내를 표시한다.

## 문구와 접근성

한국어 환경과 그 외 기본 환경에서는 다음 문구를 사용한다.

| 문구 | 한국어 | 그 외 기본 |
| --- | --- | --- |
| 선택 전 상세 안내 | `설정 항목을 선택하세요` | `Choose a setting` |
