# PlaceHome 화면 디자인

기준 스펙: [PlaceHome 화면 스펙](../spec/place-home.md), [새로고침 스펙](../spec/sync-refresh.md), [페이지 조회 목록의 자리 표시 스펙](../spec/paged-list-placeholder.md)

본문의 영역 분할과 적응형 배치, 보기 모드 전환 표현, 장소 격자와 장소 카드, 지도 핀, 정렬 줄과 빈 상태와 새로고침이 놓이는 자리는 [장소 보기 모드 디자인](./place-view-mode.md)이 소유한다. 이 문서에는 PlaceHome 화면의 상단 바 구성, 전환 버튼과 검색 버튼을 두는 자리, 장소 추가 버튼과 이 화면의 문구만 둔다.

## 화면 구조

PlaceHome 화면은 `더보기`에서 이어지는 세부 화면으로 단독 표시하며, 공통 내비게이션 영역은 숨긴다.

화면 상단에는 제목과 뒤로가기 동작, 검색 버튼과 보기 모드 전환 버튼이 있는 상단 바를 표시한다. 상단 바는 보기 모드와 관계없이 같은 자리에 같은 구성으로 표시한다.

상단 바 아래의 본문은 [장소 보기 모드 디자인](./place-view-mode.md)의 `본문 구성`과 `적응형 배치`를 따른다.

공통 내비게이션 영역의 노출은 [TopLevelNavigation 디자인](./top-level-navigation.md)의 `세부 화면에서의 노출`을 따른다.

## 상단 바 액션 배치

상단 바의 끝 쪽에는 검색 아이콘 버튼과 보기 모드 전환 아이콘 버튼을 이 순서로 나란히 배치한다. 검색 버튼을 액션의 첫 자리에 두는 것은 [MemoHome 목록 디자인](./memo-home.md)과 [TagHome 목록 디자인](./tag-home.md)도 같으므로, 사용자는 어느 화면에서도 같은 자리에서 검색을 찾는다.

두 버튼 모두 아이콘만 표시하고 라벨은 표시하지 않으며, 버튼의 이름은 [아이콘 버튼 설명 디자인](./icon-button-tooltip.md)의 설명 표시와 접근성 이름으로 제공한다.

## 검색 진입

검색 아이콘 버튼에는 돋보기 아이콘을 표시하고 기본 상단 바 아이콘 색을 사용한다. 배지나 숫자는 표시하지 않는다.

버튼을 누르면 [SearchHome 화면](./search-home.md)을 창 너비와 관계없이 단독으로 표시하고, 장소 탭이 선택된 상태로 시작한다.

보기 모드와 관계없이, 지도가 표시되지 않는 동안에도 버튼은 같은 자리에 같은 모양으로 표시하며 비활성 표현을 사용하지 않는다.

## 보기 모드 전환 버튼

상단 바에서 검색 버튼 다음에 보기 모드 전환 아이콘 버튼을 배치한다. 버튼은 하나이고, 누를 때마다 지도 모드와 목록 모드를 오간다.

버튼에 표시하는 아이콘, 전환할 때의 교차 페이드, 접근성 이름은 [장소 보기 모드 디자인](./place-view-mode.md)의 `보기 모드 전환 표현`과 `문구와 접근성`을 따른다. 상단 바에서는 기본 상단 바 아이콘 색을 사용하고 라벨과 배지는 표시하지 않는다.

상단 바에 두므로 이 버튼은 본문의 어느 배치에서도 자리를 옮기지 않고, 지도가 표시되지 않는 동안에도 같은 자리에 같은 모양으로 남는다.

## 장소 추가 동작

화면 오른쪽 아래에 장소 추가를 실행하는 플로팅 액션 버튼을 배치한다. 버튼에는 추가를 뜻하는 더하기 아이콘을 표시한다.

기본 지도나 현재 위치를 확인하는 동안처럼 본문의 지도가 표시되지 않는 상태에서도, 목록 모드에서도 플로팅 액션 버튼은 같은 자리에 그대로 표시한다. 버튼을 선택하면 [PlaceAdd 화면](./place-add.md)으로 이동한다.

버튼이 다른 요소와 겹치지 않는 배치는 [장소 보기 모드 디자인](./place-view-mode.md)의 `다른 요소와 겹치지 않는 배치`를 따른다.

## 문구와 접근성

한국어 환경과 그 외 기본 환경에서 다음 문구를 사용한다.

| 항목 | 한국어 | 그 외 기본 |
| --- | --- | --- |
| 상단 바 제목 | `장소` | `Place` |
| 뒤로가기 접근성 이름 | `뒤로가기` | `Navigate up` |
| 장소 추가 버튼 접근성 이름 | `장소 추가` | `Add place` |
| 검색 버튼 접근성 이름 | `검색` | `Search` |

보기 모드 전환 버튼의 접근성 이름은 [장소 보기 모드 디자인](./place-view-mode.md)의 문구 표가 소유한다. 장소 카드의 접근성 이름과 핀의 접근성 이름도 그 문서를 따른다.
