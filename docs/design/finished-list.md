# 완료 목록 공통 디자인

기준 스펙: [완료 목록 공통 스펙](../spec/client/finished-list.md)

이 문서는 완료된 항목만 모아 보여 주는 목록 화면들이 공통으로 쓰는 화면 구조, 정렬 줄 자리, 목록 표현과 빈 상태·새로고침 표현을 소유한다. 각 화면 문서는 그 화면에서만 다른 상단 바 제목, 카드 표현, 빈 상태 문구와 제스처만 남긴다.

이 문서를 따르는 디자인 문서는 다음과 같다.

- [MemoFinishedList 화면 디자인](./memo-finished-list.md)
- [TagFinishedList 화면 디자인](./tag-finished-list.md)
- [TagMemoFinishedList 화면 디자인](./tag-memo-finished-list.md)

## 화면 구조와 이동

완료 목록 화면은 창 너비와 관계없이 짝이 되는 목록이나 그 상세 영역과 함께 배치하지 않고 단독으로 표시한다. 완료 목록 자체가 상세와 함께 쓰는 배치를 두는 경우에는 그 배치 디자인 문서를 따른다.

화면 상단에는 뒤로가기 버튼이 있는 상단 바를 둔다. 상단 바에는 별도 액션 버튼을 두지 않는다. 이 화면이 이미 완료 목록이므로 완료 목록 진입 버튼을 다시 두지 않는다.

이 화면에서는 항목을 추가할 수 없으므로 떠 있는 추가 버튼을 표시하지 않고, 추가 키보드 단축키도 제공하지 않는다.

## 정렬 줄

정렬 줄은 상단 바 바로 아래, 완료 목록 위에 둔다. 정렬 줄과 정렬 선택 Bottom Sheet의 구조, 조작, 아이콘과 문구는 [목록 정렬 디자인](./list-sort.md)을 따른다.

## 목록

카드의 표현은 짝이 되는 목록의 카드 디자인을 그대로 따르고, 준비되지 않은 자리의 자리 표시도 그 목록과 같게 표시한다.

완료된 항목은 완료되지 않은 항목과 같은 카드 형태로 표시하고, 완료를 나타내는 별도 배지나 흐린 표현을 더하지 않는다. 이 화면에 있는 항목은 모두 완료된 항목이므로 카드마다 완료를 다시 표시하지 않는다.

## 빈 상태

표시할 항목이 하나도 없으면 목록 자리에 [목록 빈 상태 디자인](./list-empty-state.md)의 빈 상태를 표시한다. 이 화면에서는 항목을 추가할 수 없으므로 보조 문구를 두지 않는다.

빈 상태의 아이콘과 문구는 화면마다 다르며 [목록 빈 상태 디자인](./list-empty-state.md)이 소유한다.

조회 실패에는 별도 오류 안내나 재시도 버튼을 표시하지 않는다. 조회에 실패해 표시할 항목이 없을 때도 같은 빈 상태를 사용한다.

## 새로고침

목록은 아래로 당겨 새로고침할 수 있고, 진행 표시는 [새로고침 디자인](./sync-refresh.md)을 따른다. 빈 상태에서도 같은 자리에서 당겨 새로고침할 수 있다.

## 문구와 접근성

한국어 환경과 그 외 기본 환경에서 다음 문구를 사용한다.

| 항목 | 한국어 | 그 외 기본 |
| --- | --- | --- |
| 뒤로가기 버튼 접근성 이름 | `뒤로가기` | `Navigate up` |

상단 바 제목은 화면마다 다르므로 각 화면 문서가 정하고, 빈 상태 문구는 [목록 빈 상태 디자인](./list-empty-state.md)이 소유한다.
