# MemoFinishedList 화면 디자인

기준 스펙: [MemoFinishedList 화면 스펙](../spec/memo-finished-list.md)

화면 구조, 정렬 줄 자리, 목록과 빈 상태·새로고침의 공통 표현은 [완료 목록 공통 디자인](./finished-list.md)을 따른다.

## 화면 구조와 이동

상단 바에는 `완료된 메모` 제목을 표시한다.

메모를 선택하면 MemoDetail 화면을 창 너비와 관계없이 단독으로 표시한다.

## 목록

메모 카드의 제목, 컬러 원형 표시, 기간 표기와 카드 사이 간격은 [MemoHome 목록 디자인](./memo-home.md)의 `메모 카드`와 `기간과 날짜 문구`를 따른다.

기간 없는 메모는 목록 맨 위에 헤더 없이 표시한다. 기간 있는 메모는 시작 날짜별로 묶고 각 묶음 위에 날짜 헤더를 둔다. 헤더의 표시와 스크롤 고정 방식은 MemoHome 목록 디자인의 `날짜 헤더`를 따른다.

아직 준비되지 않은 자리에는 [페이지 조회 목록의 자리 표시 디자인](./paged-list-placeholder.md)에 따라 자리 표시 카드를 표시한다.

## 빈 상태

빈 상태의 아이콘과 문구는 [목록 빈 상태 디자인](./list-empty-state.md)이 `MemoFinishedList 완료된 메모 목록`으로 정한 값을 따른다.

## 다시 시작·삭제 제스처와 피드백

[SwipeToFinishAndDelete 컴포넌트 디자인](./swipe-to-finish-and-delete.md)에 따라 카드를 왼쪽에서 오른쪽으로 스와이프하면 다시 시작하고, 오른쪽에서 왼쪽으로 스와이프하면 삭제한다.

시작 방향의 상태 아이콘에는 완료 아이콘 대신 화살표가 원을 그리는 다시 시작 아이콘을 표시한다. 끝 방향의 삭제 아이콘은 MemoHome 목록과 같다.

다시 시작 또는 삭제 뒤의 피드백과 실행 취소는 스낵바로 표시한다.

## 문구와 접근성

[완료 목록 공통 디자인](./finished-list.md)의 `문구와 접근성`에 더해 한국어 환경과 그 외 기본 환경에서 다음 문구를 사용한다.

| 항목 | 한국어 | 그 외 기본 |
| --- | --- | --- |
| 상단 바 제목 | `완료된 메모` | `Finished Memos` |
| 다시 시작 안내 | `메모를 다시 시작했습니다.` | `Memo restarted.` |
| 삭제 안내 | `메모가 삭제되었습니다.` | `Memo deleted.` |
| 실행 취소 동작 | `실행 취소` | `Undo` |
| 다시 시작 스와이프 아이콘 접근성 이름 | `메모 다시 시작` | `Restart memo` |
| 삭제 스와이프 아이콘 접근성 이름 | `메모 삭제` | `Delete memo` |
| 오늘 날짜 헤더 | `오늘` | `Today` |
