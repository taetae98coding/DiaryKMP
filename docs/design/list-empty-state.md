# 목록 빈 상태 디자인

기준 스펙: [목록 빈 상태 스펙](../spec/list-empty-state.md)

이 문서는 화면 본문을 차지하는 목록이 비어 있을 때의 표시 형태, 배치, 전환과 문구를 소유한다. 목록 항목의 표현과 목록 자체의 배치는 각 화면 디자인이 소유하고, 아직 준비되지 않은 자리의 표현은 [페이지 조회 목록의 자리 표시 디자인](./paged-list-placeholder.md)이 소유한다.

적용 대상은 [목록 빈 상태 스펙](../spec/list-empty-state.md)의 `적용 대상`을 따른다.

## 빈 상태 구성

빈 상태는 배경 도형에 담은 아이콘 하나와 문구로 구성한다. 아이콘을 위에, 문구를 아래에 두고 세로로 잇는다.

| 요소 | 표시 |
| --- | --- |
| 아이콘 배경 도형 | 한 변 `96dp`, 화면 배경보다 한 단계 높은 표면 색 |
| 아이콘 | 한 변 `48dp`, 본문 보조 색 |
| 제목 문구 | 본문 기본 글자 크기, 본문 보조 색 |
| 보조 문구 | 제목 문구보다 작은 글씨, 본문 보조 색 |

배경 도형과 제목 문구 사이, 제목 문구와 보조 문구 사이에는 모두 [공통 항목 간격](./dimens.md)을 둔다.

보조 문구는 `문구`가 정한 목록에만 둔다. 보조 문구가 없는 목록에서는 그 자리를 비워 두지 않고 제목 문구까지만 배치한다.

아이콘은 배경 도형의 가로와 세로 가운데에 놓는다. 배경 도형은 원이나 사각형이 아니라 가장자리가 여러 번 굽은 Material 3 도형 하나를 쓰고, 모든 목록에서 같은 도형을 쓴다. 도형에는 테두리를 두지 않고, 그림이나 삽화를 아이콘 대신 쓰지 않는다. 아이콘 종류는 `아이콘`을 따른다.

배경 도형은 아이콘만 놓였을 때보다 빈 자리가 비어 있음을 알아보기 쉽게 하려고 두며, 목록에 따라 색이나 모양을 달리하지 않는다.

같은 배경 도형과 아이콘 크기는 목록·상세 배치의 선택 전 상세도 그대로 쓴다. 그 자리의 아이콘과 문구는 [Setting 목록·상세 배치 디자인](./setting-list-detail.md)과 [TagMemoFinishedList 목록·상세 배치 디자인](./tag-memo-finished-list-detail.md)이 소유한다.

빈 상태에는 버튼이나 링크를 두지 않는다. 항목을 추가하는 조작은 각 화면이 이미 제공하는 추가 버튼이 담당한다.

## 배치

빈 상태는 목록이 차지하던 영역 전체를 채우고, 그 영역의 가로와 세로 가운데에 놓는다. 목록의 항목 여백과 무관하게 좌우에는 [공통 화면 가로 여백](./dimens.md)을 둔다.

문구는 가운데 정렬한다. 폭이 좁아 한 줄에 들어가지 않으면 줄바꿈해 여러 줄로 표시하고, 줄 수를 제한하거나 말줄임하지 않는다.

빈 상태가 놓이는 영역은 각 화면 디자인이 정한 목록 영역과 같다. 목록과 상세를 함께 표시하는 배치에서는 목록 영역 안에만 두고 상세 영역에는 두지 않는다. PlaceHome과 TagDetail 장소 탭에서는 [장소 보기 모드 디자인](./place-view-mode.md)의 보기 모드에 따라 정해지는 장소 목록 영역 안에만 두고, SearchHome에서는 그 유형의 결과 영역 안에만 두어 상단 바와 유형 탭 행을 밀어내지 않는다.

빈 상태는 상단 바, 플로팅 추가 버튼, 하단 내비게이션과 겹치지 않는 자리에 두고, 시스템 상태 영역과 디스플레이 컷아웃에 가려지지 않게 한다.

## 적응형 배치

빈 상태는 창 너비와 자세에 따라 구성을 바꾸지 않는다. 어느 창 크기에서도 배경 도형에 담은 아이콘과 문구를 세로로 잇고 같은 크기를 유지하며, 놓이는 자리만 그 시점의 목록 영역 기준으로 다시 정한다.

[장소 보기 모드 디자인](./place-view-mode.md)의 지도 모드처럼 목록 영역이 본문의 절반만 차지하는 배치에서도 같은 도형 크기와 아이콘 크기, 글자 크기를 유지한다. 영역이 좁아 문구가 여러 줄이 되는 것은 그대로 둔다.

## 전환

목록과 빈 상태는 같은 자리를 쓰며 동시에 보이지 않는다. 두 상태 사이는 이전 상태가 사라지면서 다음 상태가 나타나는 교차 페이드로 전환한다. [장소 보기 모드 디자인](./place-view-mode.md)의 보기 모드 전환과 같은 표현이다.

지속 시간과 완급은 전환 기본값을 따르고 이 문서에서 따로 정하지 않는다. 배경 도형, 아이콘이나 문구가 커지거나 움직이는 등장 애니메이션은 두지 않는다.

목록의 준비가 끝나기 전에는 자리 표시 항목을 표시하므로, 자리 표시에서 빈 상태로 넘어갈 때도 같은 교차 페이드를 사용한다.

전환하는 동안에도 상단 바, 플로팅 추가 버튼, 하단 내비게이션은 자리를 옮기지 않고 그대로 조작할 수 있다.

## 새로고침과의 관계

목록을 당겨 새로고침할 수 있는 화면에서는 빈 상태를 목록과 같은 당김 새로고침 컨테이너 안에 놓는다. 사용자는 빈 상태에서도 아래로 당겨 새로고침할 수 있으며, 스크롤할 내용이 없으므로 당김이 곧바로 시작된다.

당김 새로고침을 두지 않는 SearchHome의 결과 목록에서는 빈 상태에도 당김 새로고침 컨테이너와 진행 표시를 두지 않는다. 그 자리에서 아래로 당겨도 아무 일도 일어나지 않는다.

진행 표시는 [새로고침 디자인](./sync-refresh.md)에 따라 목록 영역 위쪽 가로 가운데에 겹쳐 표시하고, 빈 상태의 아이콘과 문구를 밀어내지 않는다. 새로고침이 진행되는 동안에도 빈 상태는 그대로 유지한다.

## 아이콘

각 목록의 빈 상태에는 그 목록이 무엇을 담는지 또는 왜 비어 있는지를 나타내는 아이콘을 쓴다. 아이콘은 화면의 다른 곳에서 이미 같은 뜻으로 쓰는 것을 그대로 사용한다.

| 목록 | 아이콘 |
| --- | --- |
| TagHome 태그 목록, 좁히지 않은 상태 | 태그 아이콘 |
| TagHome 태그 목록, 좁힌 상태 | 필터 아이콘 |
| TagFinishedList 완료된 태그 목록 | 완료 아이콘 |
| TagDetail 메모 탭의 태그별 메모 목록 | 메모 아이콘 |
| TagDetail 웹 탭의 태그별 웹 목록 | 웹 아이콘 |
| TagDetail 장소 탭 목록 모드의 태그별 장소 목록 | 장소 아이콘 |
| TagDetail 장소 탭 지도 모드의 태그별 장소 목록 | 지도 아이콘 |
| TagMemoFinishedList 태그별 완료된 메모 목록 | 완료 아이콘 |
| MemoHome 메모 목록, 좁히지 않은 상태 | 메모 아이콘 |
| MemoHome 메모 목록, 좁힌 상태 | 필터 아이콘 |
| MemoFinishedList 완료된 메모 목록 | 완료 아이콘 |
| RoutineHome 루틴 목록 | 루틴 아이콘 |
| PlaceHome 지도 모드의 장소 목록 | 지도 아이콘 |
| PlaceHome 목록 모드의 장소 목록 | 장소 아이콘 |
| WebHome 웹 목록 | 웹 아이콘 |
| ContactHome 연락처 목록 | 연락처 아이콘 |
| SearchHome 메모 검색 결과 목록 | 메모 아이콘 |
| SearchHome 태그 검색 결과 목록 | 태그 아이콘 |
| SearchHome 장소 검색 결과 목록 | 장소 아이콘 |

SearchHome의 세 목록은 문구가 같으므로 아이콘이 지금 어느 유형의 결과를 보고 있는지를 알린다. 각 유형은 그 유형의 목록 화면이 쓰는 아이콘을 그대로 쓴다.

루틴 아이콘은 [TopLevelNavigation 디자인](./top-level-navigation.md)의 `루틴` 목적지 아이콘과 같다.

완료 아이콘은 [TagHome 목록 디자인](./tag-home.md), [MemoHome 목록 디자인](./memo-home.md)과 [TagDetail 메모 탭 디자인](./tag-detail-memo.md)의 완료된 목록 진입 버튼과 같은 아이콘이고, 필터 아이콘은 [필터 Bottom Sheet 디자인](./filter-bottom-sheet.md)의 필터 버튼과 같은 아이콘이다. 지도 아이콘과 장소 아이콘은 [장소 보기 모드 디자인](./place-view-mode.md)의 보기 모드 전환 컨트롤과 `더보기`의 장소 메뉴에서 쓰는 아이콘과 같다. 웹 아이콘은 [WebHome 화면 디자인](./web-home.md)이 웹을 가리킬 때 쓰는 아이콘과 같고, 연락처 아이콘은 [ContactHome 화면 디자인](./contact-home.md)이 연락처를 가리킬 때 쓰는 아이콘과 같다.

MemoHome 목록과 TagHome 목록에서 좁힌 상태와 좁히지 않은 상태 사이의 전환도 `전환`의 교차 페이드를 따른다.

TagFinishedList와 MemoFinishedList는 그 화면에서 항목을 새로 만들 수 없으므로 보조 문구를 두지 않는다.

SearchHome의 세 목록은 같은 문구를 쓴다. 유형 이름을 문구에 넣지 않는 것은 사용자가 이미 유형 탭에서 어느 유형을 보고 있는지 알고 있고, 탭을 옮길 때마다 문구가 바뀌면 결과 영역이 유형마다 다른 화면처럼 보이기 때문이다. 이 화면에서는 항목을 새로 만들 수 없으므로 보조 문구는 추가가 아니라 질의를 고치는 것을 권한다.

문구에는 오류나 실패를 뜻하는 표현을 쓰지 않는다. 조회에 실패한 경우도 같은 문구를 그대로 사용한다.

## 접근성

아이콘과 그 배경 도형은 문구가 전달하는 내용을 그림으로 되풀이하는 장식이므로 접근성 이름을 두지 않는다. 화면 낭독 도구는 제목 문구와 보조 문구만 읽는다.

제목 문구와 보조 문구는 하나의 묶음으로 읽어 두 문장이 이어서 전달되게 한다.

빈 상태는 누를 수 있는 요소를 갖지 않으므로 초점을 받지 않는다. 키보드 초점은 상단 바와 플로팅 추가 버튼 사이에서 빈 상태를 건너뛴다.

목록에서 빈 상태로, 빈 상태에서 목록으로 바뀌면 화면 낭독 도구가 바뀐 내용을 읽는다.
