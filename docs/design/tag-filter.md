# 태그 필터 디자인

기준 스펙: [태그 필터 스펙](../spec/tag-filter.md)

이 문서는 MemoHome 목록과 CalendarHome 화면이 함께 사용하는 태그 필터의 표현과 조작을 다룬다. 필터 아이콘 버튼을 어디에 두는지와 Bottom Sheet 아래에 무엇이 남는지는 화면마다 다르므로 [MemoHome 목록 디자인](./memo-home.md)의 `필터 진입`과 [CalendarHome 디자인](./calendar-home.md)의 `태그 필터 진입`에서 다룬다.

MemoHome의 Bottom Sheet는 태그 필터와 함께 유무 필터를 담으므로, 제목과 영역 구성, 스크롤 범위, 필터 아이콘 버튼의 문구는 [MemoHome 목록 디자인](./memo-home.md)이 소유한다. 이 문서의 규칙 중 태그 칩의 표현과 선택 조작, `선택 전체 해제 버튼`만 그 화면에 적용되며, 그 화면에서 태그 필터가 적용되지 않는 동안의 표현은 [MemoHome 목록 디자인](./memo-home.md)이 소유한다.

필터 아이콘 버튼의 표현과 Bottom Sheet의 공통 구조, 닫는 조작, 적응형 배치는 [필터 Bottom Sheet 디자인](./filter-bottom-sheet.md)이 소유한다.

## 필터 적용 상태

선택한 태그가 하나도 없으면 필터가 적용되지 않은 상태로, 하나 이상이면 적용된 상태로 본다. 두 상태의 아이콘 버튼 표현은 [필터 Bottom Sheet 디자인](./filter-bottom-sheet.md)의 `필터 아이콘 버튼`을 따른다.

## 태그 필터 Bottom Sheet

Bottom Sheet 제목에는 `태그 필터`를 사용한다.

태그는 제목 아래에 제목 영역과 좌우를 맞춘 칩으로 표시한다. 칩은 양쪽 끝이 완전히 둥근 형태로 가로로 이어 배치하고, 남은 폭에 들어가지 않으면 다음 줄로 넘긴다. 칩 사이에는 가로·세로로 [공통 항목 간격](./dimens.md)을 둔다.

필터 칩의 태그 이름은 [TagHome 목록 디자인](./tag-home.md)의 `이모지와 제목 표시`를 따른다. 태그 이름이 칩에서 쓸 수 있는 폭을 넘었을 때의 표시와 칩 하나의 최대 폭은 [칩 이름 표시 디자인](./chip.md)을 따른다. 태그 영역에서 쓸 수 있는 폭은 제목 영역과 좌우를 맞춘 폭이다.

선택하지 않은 태그의 칩은 테두리가 있는 기본 칩 색을 사용하고, 태그 이름 앞에 태그에 저장된 컬러로 채운 작은 원형 표시를 둔다.

선택한 태그의 칩은 원형 표시 대신 칩 배경 전체를 태그에 저장된 컬러로 채우고, 태그 이름은 그 컬러 위에서 읽을 수 있는 색으로 표시하며 테두리는 표시하지 않는다.

칩을 눌러 선택 여부를 바꿀 수 있게 한다. 칩의 조작 영역은 칩이 차지하는 영역과 같게 두고 별도의 최소 터치 크기로 넓히지 않는다. 선택이 바뀌면 칩의 표시를 즉시 갱신한다.

선택이 바뀌면 칩의 크기와 원형 표시는 전환 없이 즉시 갱신한다. 크기가 달라져 자리가 밀린 다른 칩들만 새 위치로 한 번에 건너뛰지 않고 부드럽게 이동한다. 줄바꿈이 다시 일어나 칩이 다른 줄로 옮겨질 때도 같은 이동을 적용한다. 이동 시간과 곡선은 별도 수치를 정하지 않고 플랫폼 기본 모션을 따른다.

태그가 표시 영역보다 많으면 제목 영역은 유지하고 태그 영역만 세로로 스크롤한다.

태그 조회가 진행되는 동안에는 아직 조회되지 않은 태그의 자리를 비워 두지 않고 조회된 태그의 칩만 배치한다. 태그가 추가로 조회되면 이미 배치된 칩 뒤에 정렬 순서대로 이어 붙이고, 남은 폭에 들어가지 않으면 다음 줄로 넘겨 태그 영역의 높이를 늘린다. 조회가 진행되는 동안 별도의 진행 표시나 안내 문구는 표시하지 않는다.

## 선택 전체 해제 버튼

태그 필터 제목과 같은 줄의 오른쪽 끝에 선택을 한 번에 해제하는 텍스트 버튼을 둔다. 아이콘 없이 라벨만 표시하고, 제목과 세로 가운데를 맞춘다. 제목과 버튼 사이에는 [공통 구성요소 간격](./dimens.md)을 최소 간격으로 두고, 제목이 길어 남는 폭이 부족하면 버튼이 먼저 온전한 폭을 차지하고 제목을 줄인다.

버튼은 선택 여부와 관계없이 같은 자리에 항상 표시한다. 선택한 태그가 하나 이상이면 활성으로, 하나도 없으면 Material 기본 비활성 표현으로 표시한다. 선택이 없을 때 버튼을 숨겨 제목 줄의 구성이 바뀌지 않게 하기 위해서다.

버튼을 누르면 선택한 모든 칩이 선택하지 않은 표현으로 즉시 바뀌고, 버튼은 같은 자리에서 비활성으로 바뀐다. 칩의 크기가 달라져 자리가 밀리는 다른 칩의 이동은 `태그 필터 Bottom Sheet`의 규칙을 따른다. 별도의 확인 대화상자나 실행 취소 안내는 표시하지 않고, Bottom Sheet는 열린 상태를 유지한다.

키보드나 포인터를 사용하는 환경에서 이 버튼은 [필터 Bottom Sheet 디자인](./filter-bottom-sheet.md)의 `닫는 조작`에 따라 초점을 받고 `Enter` 또는 `Space`로 실행한다. 비활성일 때는 초점을 받지 않는다.

## 문구와 접근성

한국어 환경과 그 외 기본 환경에서 다음 문구를 사용한다.

| 항목 | 한국어 | 그 외 기본 |
| --- | --- | --- |
| 필터 버튼 접근성 이름 | `태그 필터` | `Filter by tag` |
| 필터 적용 상태 접근성 설명 | `태그 필터 적용됨` | `Tag filter applied` |
| 필터 제목 | `태그 필터` | `Tag Filter` |
| 선택 전체 해제 버튼 라벨 | `지우기` | `Clear` |
| 선택 전체 해제 버튼 접근성 이름 | `태그 필터 지우기` | `Clear tag filter` |

선택 전체 해제 버튼은 라벨만으로는 무엇을 지우는지 알 수 없으므로 접근성 이름을 라벨과 다르게 둔다.
