# HolidayHome 화면 디자인

기준 스펙: [HolidayHome 화면 스펙](../spec/holiday-home.md)

## 화면 구조

HolidayHome 화면은 `더보기`에서 이어지는 세부 화면으로 단독 표시하고 공통 내비게이션 영역은 숨긴다.

화면 상단에는 상단 바를 두고, 표시 중인 년도를 제목으로 상단 바 가운데에 표시한다. 상단 바 시작 쪽에는 뒤로가기 동작을 배치한다. 년도는 좌우 스와이프로 바뀌는 값이므로, 년월을 가운데에 표시하는 [CalendarHome 화면 디자인](./calendar-home.md)의 상단 바와 같은 자리에서 읽히게 한다. 상단 바 아래에는 연차 개수 조절 영역을 항상 같은 자리에 두고, 그 아래 본문에는 표시 중인 년도의 황금연휴 목록을 배치한다.

공통 내비게이션 영역의 노출은 [TopLevelNavigation 디자인](./top-level-navigation.md)의 `세부 화면에서의 노출`을 따른다.

## 황금연휴 목록 배치

황금연휴 목록은 본문 너비 전체를 채우는 지그재그 격자로 배치한다. 항목 간격과 본문 바깥 여백은 [공통 여백과 간격](./dimens.md)의 `항목 간격`과 화면 여백을 따른다.

기준 스펙이 정한 목록 순서를 따라 첫 항목을 시작 쪽 첫 열에 두고, 이어지는 항목을 끝 쪽 열까지 채운 뒤 다음 줄로 넘긴다. 항목마다 주 수와 연차 표시가 달라 카드 높이가 서로 다르므로, 각 열은 그 열의 앞 카드 바로 아래에서 이어져 카드 사이에 빈 공간이 생기지 않는다.

열 수는 본문 너비에 따라 정하고, 한 열의 너비가 최소 `360dp`가 되도록 담을 수 있는 만큼만 열을 둔다. 남는 너비는 열이 고르게 나눠 가지므로 열이 하나뿐인 좁은 창에서는 카드가 본문 너비를 모두 차지한다. 카드 안 주별 날짜가 한 주에 일곱 칸을 나눠 쓰기 때문에 열을 더 잘게 나누면 날짜와 이름을 읽기 어려워, 넓은 창에서만 열을 늘려 한 화면에서 더 많은 연휴를 비교할 수 있게 한다.

격자가 한 화면에 들어가지 않으면 세로로 스크롤할 수 있게 한다. 열 수가 바뀌어도 항목의 순서는 그대로 유지한다.

## 년도 이동과 연차 조절

사용자는 본문을 좌우로 스와이프해 이전 년도와 다음 년도로 이동한다. 이동하면 상단 바 제목과 본문의 목록을 해당 년도로 바꾸되, 연차 조절 영역의 위치와 값은 유지한다.

스와이프하는 동안에는 이동 방향의 년도 본문이 함께 드러난다. 드러난 각 년도 본문에는 그 년도의 준비 상태에 맞는 목록, 로딩 또는 오류를 표시한다.

연차 조절 영역에는 연차 라벨, 현재 개수, 줄이기 동작과 늘리기 동작을 한 줄로 배치한다.

연차가 최솟값이면 줄이기 동작을 선택할 수 없는 상태로 표시한다. 늘리기 동작은 항상 선택할 수 있게 한다.

## 황금연휴 카드

각 황금연휴 항목을 하나의 카드로 구분한다. 카드에는 요약 줄과 그 아래의 주별 날짜 표시를 배치한다. 카드 안쪽에는 [공통 스타일](./styles.md)의 `카드 내용`을 적용하고, 요약 줄과 주별 날짜 표시 사이에는 [항목 간격](./dimens.md)을 둔다.

요약 줄에는 공휴일 이름, 시작일과 종료일, 전체 일수를 표시하고, 연차를 사용하는 경우 사용 연차 일수도 함께 표시한다. 카드 내용은 현재 선택된 대안을 기준으로 표시한다.

기간 문구 좌우에는 이전·다음 대안 동작을 배치하고, 그 옆에 현재 대안의 위치와 전체 대안 수를 표시한다. 첫 번째 대안에서는 이전 동작을, 마지막 대안에서는 다음 동작을 비활성화한다. 대안이 하나면 두 동작을 모두 비활성화한다.

대안을 바꾸면 기간, 전체 일수, 사용 연차 일수와 주별 날짜 표시를 바꾼다. 같은 항목의 공휴일 이름은 그대로 유지한다.

## 주별 날짜와 아이템

연휴 시작일이 속한 주부터 종료일이 속한 주까지 위에서 아래로 한 주에 `96dp`씩 같은 높이로 이어서 표시하며, 주 사이에는 간격을 두지 않는다. 각 주의 날짜와 아이템 배치는 [CalendarWeekOfMonth 컴포넌트 디자인](./calendar-week-of-month.md)을 따른다.

해당 연휴에 포함된 공휴일 날짜는 일요일·공휴일 색상으로 표시한다. 연차 날짜는 원래 평일의 날짜 색상을 유지하고 연차 이름으로만 구분한다.

공휴일 이름과 연차 이름은 하나의 아이템 그룹에 넣는다. 공휴일과 연차는 날짜가 겹치지 않으므로 같은 줄에 나란히 표시한다. 아이템 줄 배치는 [CalendarWeekOfMonth 컴포넌트 디자인](./calendar-week-of-month.md)을, 이름 표현은 [CalendarText 컴포넌트 디자인](./calendar-text.md)을 따른다.

연이은 연차 날짜는 하나의 아이템으로 이어서 표시한다. 연차를 사용하지 않으면 연차 이름을 표시하지 않는다.

기준 달에 속하지 않는 날짜는 주요 날짜 예외를 포함한 [CalendarWeekOfMonth 컴포넌트 디자인](./calendar-week-of-month.md)의 이웃 달 날짜 표현을 따른다.

## 카드 안 날짜 기간 선택

각 카드의 주별 날짜 표시 영역 전체를 그 카드의 선택 영역으로 삼는다. 요약 줄은 선택 영역에 넣지 않아 대안을 넘기는 동작과 겹치지 않게 한다.

선택 조작, 촉각 피드백과 선택 표시는 [Calendar 날짜 선택 디자인](./calendar-select.md)을 따른다. 선택 배경은 주별 날짜와 아이템 뒤에 깔아 공휴일 이름과 연차 이름을 가리지 않는다.

선택이 진행되는 동안에는 격자의 세로 스크롤과 년도 좌우 스와이프를 시작하지 않는다. 손을 떼면 선택 배경을 지우고 MemoAdd 화면으로 전환하며, 뒤로 돌아오면 선택 배경 없이 보던 카드를 그대로 표시한다.

## 준비 상태

아직 한 번도 결과가 준비되지 않은 년도의 공휴일을 준비하는 동안에는 본문 중앙에 contained loading indicator를 표시한다. 화면 낭독 도구에는 사용자의 언어에 맞는 로딩 접근성 이름을 제공한다.

이미 황금연휴 목록을 표시한 년도는 다시 동기화하는 동안에도 로딩 표시로 바꾸지 않고 기존 내용을 유지한다.

공휴일 준비에 실패하면 본문 중앙에 오류 안내 문구와 외곽선 형태의 재시도 버튼을 세로로 배치한다. 사용자가 재시도 버튼을 선택하면 오류 내용을 로딩 표시로 바꾼다.

공휴일이 제공되지 않는 년도에는 본문 중앙에 제공 없음 안내 문구만 배치하고 재시도 버튼은 두지 않는다. 문구의 위치와 정렬은 오류 안내와 같게 한다.

## 문구와 접근성

한국어 환경과 그 외 기본 환경에서 다음 문구를 사용한다.

| 항목 | 한국어 | 그 외 기본 |
| --- | --- | --- |
| 상단 바 제목 예시 | `2026년` | `2026` |
| 뒤로가기 접근성 이름 | `뒤로가기` | `Navigate up` |
| 연차 라벨 | `연차` | `Annual leave` |
| 연차 줄이기 접근성 이름 | `연차 줄이기` | `Decrease annual leave` |
| 연차 늘리기 접근성 이름 | `연차 늘리기` | `Increase annual leave` |
| 연휴 기간 예시 | `2월 16일 ~ 2월 18일` | `Feb 16 ~ Feb 18` |
| 연휴 일수 예시 | `3일` | `3 days` |
| 사용 연차 일수 예시 | `연차 1일` | `1 leave` |
| 이전 대안 접근성 이름 | `이전 연휴 안` | `Previous option` |
| 다음 대안 접근성 이름 | `다음 연휴 안` | `Next option` |
| 대안 위치 예시 | `1 / 2` | `1 / 2` |
| 연차 아이템 이름 | `연차` | `Leave` |
| 로딩 접근성 이름 | `공휴일 확인 중` | `Loading holidays` |
| 오류 안내 | `공휴일을 불러오지 못했어요` | `Holidays could not be loaded` |
| 제공 없음 안내 | `이 년도의 공휴일은 제공하지 않아요` | `Holidays are not provided for this year` |
| 재시도 | `다시 시도` | `Retry` |

연휴 기간의 월 표기는 한국어에서 `1월`부터 `12월`, 그 외 기본에서 `Jan`부터 `Dec`를 사용한다.
