# MusicAdd 화면 디자인

기준 스펙: [MusicAdd 화면 스펙](../spec/music-add.md)

화면 구조, 표시 영역과 소프트 키보드, 초점과 단축키, 진행과 피드백은 [항목 추가 화면 공통 디자인](./entity-add.md)을 따른다.

## 화면 구조

MusicAdd 화면은 창 너비와 관계없이 단독으로 표시한다. 이번 범위에는 곡 목록과 상세를 함께 두는 배치가 없으므로 목록·상세 배치를 적용하지 않고, 뒤로가기 버튼은 언제나 상단 바에 표시한다.

본문에는 단일 줄 제목 입력과 단일 줄 가수 입력을 순서대로 배치한다.

입력 순서는 곡을 가리키는 이름인 제목을 먼저 두고, 같은 제목의 곡을 구분하는 가수를 바로 뒤에 둔다. 이 화면에는 태그 입력을 두지 않는다.

## 가수 입력

가수는 단일 줄 텍스트 입력으로 배치하고, 입력한 값이 있으면 내용을 한 번에 지우는 지우기 버튼을 끝 쪽에 표시한다. 지우기 버튼이 나타나고 사라지는 표현은 [나타나고 사라지는 버튼 디자인](./button-visibility.md)을 따른다.

가수 입력은 제목 입력과 같은 폭과 높이를 가지며, 제목 입력과 같은 카드 표현을 사용한다. 두 입력은 같은 자격의 필수 입력이므로 한쪽을 더 작게 두거나 보조 입력처럼 표현하지 않는다.

가수 입력에는 일반 텍스트 소프트 키보드를 사용한다. 입력 중에는 값이 비어 있는지 검사해 막거나 오류 색을 표시하지 않으며, 미입력은 사용자가 추가를 실행한 뒤 안내 문구로만 알린다.

## 표시 영역과 소프트 키보드

배치는 창 너비, 창 높이와 기기 자세에 따라 달라지지 않는다.

## 진행과 피드백

추가에 성공하면 제목과 가수를 비운다. 본문에 다른 요소가 없으므로 화면의 높이 구성은 바뀌지 않는다.

## 문구와 접근성

[항목 추가 화면 공통 디자인](./entity-add.md)의 `문구와 접근성`에 더해 한국어 환경과 그 외 기본 환경에서는 다음 문구를 사용한다.

| 문구 | 한국어 | 그 외 기본 |
| --- | --- | --- |
| 상단 바 제목 | `곡 추가` | `Add Music` |
| 뒤로가기 접근성 이름 | `뒤로가기` | `Navigate up` |
| 추가 버튼 접근성 이름 | `곡 추가` | `Add music` |
| 가수 입력 이름 | `가수` | `Artist` |
| 추가 성공 안내 | `곡이 추가되었습니다.` | `Music added.` |
| 제목 미입력 안내 | `제목을 입력해 주세요.` | `Please enter a title.` |
| 가수 미입력 안내 | `가수를 입력해 주세요.` | `Please enter an artist.` |

제목 입력의 이름과 표현은 그 입력 컴포넌트의 디자인을 따른다.
