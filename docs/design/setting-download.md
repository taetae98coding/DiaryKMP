# SettingDownload 화면 디자인

기준 스펙: [SettingDownload 화면 스펙](../spec/client/setting-download.md), [곡 다운로드 프록시 스펙](../spec/client/music-download-proxy.md)

## 화면 구조

SettingDownload의 단독·목록/상세 배치와 표시 상태에 따른 뒤로가기 동작 노출은 [Setting 목록·상세 배치 디자인](./setting-list-detail.md)을 따른다.

화면 상단에는 제목이 있는 상단 바를 두고, 뒤로가기 동작을 제공하는 상태에서는 상단 바에 함께 배치한다. 상단 바 제목은 플랫폼과 관계없이 같다.

본문은 플랫폼에 따라 다르다. JVM 데스크톱에서는 `프록시 주소 확인` 영역 하나를, Android와 iOS에서는 `프록시 주소 입력` 하나를 둔다. 본문이 표시 영역보다 길어지면 위아래로 스크롤할 수 있다.

프록시 상태나 저장된 주소를 확인하기 전이거나 읽지 못한 상태에서는 본문을 자리까지 함께 표시하지 않고 상단 바만 남긴다. 별도의 로딩 안내나 오류 안내도 표시하지 않는다.

## 프록시 주소 확인 (JVM 데스크톱)

`이 기기의 프록시 주소` 설정 이름을 영역 위에 두고, 그 아래에 이 주소를 어디에 쓰는지 알리는 보조 문구를 설정 이름보다 작은 글자와 낮은 강조 색으로 둔다. 설정 이름과 보조 문구는 [SettingBrowser 화면 디자인](./setting-browser.md)의 영역 제목과 같은 방식으로 묶음 바깥에 둔다.

보조 문구 아래에 [항목 간격](./dimens.md)을 띄우고 주소 묶음을 둔다. 묶음의 배경과 모양, 줄 사이 간격은 [묶음 목록 항목 디자인](./segmented-list-item.md)을 따른다.

| 프록시 상태 | 묶음의 내용 |
| --- | --- |
| 제공 중이고 주소 후보가 있음 | 주소 후보를 한 줄에 하나씩, 기준 스펙이 정한 순서 없이 기기가 알려 주는 순서대로 |
| 제공 중이지만 주소 후보가 없음 | 닿을 주소가 없다는 안내 한 줄 |
| 제공하지 못함 | 프록시를 시작하지 못했다는 안내 한 줄 |

주소 줄에는 `http://192.168.0.10:54321`처럼 주소 전체를 한 줄로 표시한다. 다른 기기에 옮겨 적는 것이 이 화면의 목적이므로 주소의 어느 부분도 줄이거나 가리지 않으며, 주소가 폭을 넘으면 줄을 바꿔 전체를 표시한다. 주소 줄은 누를 수 있는 자리가 아니다.

안내 한 줄은 주소 줄과 같은 글자 크기로 둔다. 프록시를 시작하지 못했을 때의 안내에는 앱을 다시 실행해야 함을 함께 담는다.

## 프록시 주소 입력 (Android, iOS)

프록시 주소 입력은 `프록시 주소` 라벨이 붙은 단일 줄 텍스트 입력을 카드 안에 두고 본문 좌우 폭을 모두 사용한다. 입력의 밑줄은 표시하지 않는다. 카드 아래에는 JVM 데스크톱의 어디에서 주소를 확인하는지 알리는 보조 문구를 라벨보다 작은 글자와 낮은 강조 색으로 둔다.

입력이 비어 있는 동안에는 `http://192.168.0.10:54321`을 자리 표시 문구로 보여 주어 어떤 형태의 값을 넣어야 하는지 알린다.

소프트 키보드는 URI 입력용 키보드를 요청하고 자동 수정과 자동 대문자 변환을 사용하지 않는다. 키보드의 동작 키는 완료로 표시하고, 누르면 키보드를 닫는다. 동작 키로 저장을 실행하지 않는다.

## 저장 동작 (Android, iOS)

저장 버튼은 떠 있는 버튼으로 두고 아이콘은 다른 화면의 저장 동작과 같은 확인 모양을 쓴다. 설정 목록과 함께 표시할 때도 상세 영역 안에 둔다.

편집 중인 주소가 저장된 주소와 다를 때만 저장 버튼을 표시한다. 같으면 저장 버튼을 자리까지 감춘다. 버튼이 나타나고 사라지는 표현은 [나타나고 사라지는 버튼 디자인](./button-visibility.md)을 따라 [SettingGemini 화면 디자인](./setting-gemini.md)의 저장 버튼과 같다.

저장 처리 중에는 저장 버튼의 확인 아이콘을 진행 표시로 바꾼다. 처리 중에도 표시 조건은 그대로 적용하므로, 처리하는 동안 사용자가 값을 저장된 값과 같게 되돌리면 진행 표시까지 함께 사라진다.

저장에 성공하면 편집 중인 값이 저장된 값과 같아지므로 저장 버튼은 같은 전환으로 사라진다. 저장에 실패하면 편집 중인 값이 그대로 남아 저장 버튼도 그대로 표시한다.

저장 성공과 저장 실패 피드백은 스낵바로 표시한다.

## 표시 영역과 소프트 키보드

본문, 저장 버튼과 스낵바는 상태 표시 영역, 시스템 탐색 영역과 카메라 컷아웃 등 기기가 가리는 영역을 침범하지 않게 배치한다.

소프트 키보드가 나타나면 세 요소를 키보드 위 영역에 맞춰 배치하고, 초점이 있는 입력이 키보드에 가리지 않도록 본문을 세로로 스크롤한다. 키보드가 닫히면 원래 표시 영역으로 되돌린다.

## 초점과 키보드 단축키

화면이 열릴 때는 입력에 초점을 두지 않으므로 소프트 키보드도 열지 않는다. 저장된 주소를 확인하러 들어오는 경우가 많기 때문이다.

저장에는 키보드 단축키를 두지 않는다. 다른 설정 화면과 같다.

## 문구와 접근성

한국어 환경과 그 외 기본 환경에서는 다음 문구를 사용한다.

| 문구 | 한국어 | 그 외 기본 |
| --- | --- | --- |
| 상단 바 제목 | `다운로드 설정` | `Download Settings` |
| 뒤로가기 접근성 이름 | `뒤로가기` | `Navigate up` |
| 이 기기의 프록시 주소 설정 이름 | `이 기기의 프록시 주소` | `This device's proxy address` |
| 이 기기의 프록시 주소 보조 문구 | `같은 네트워크의 Android나 iOS 앱에서 이 주소를 입력하면 이 기기가 대신 영상을 받아 전달합니다` | `Enter this address in the Android or iOS app on the same network to have this device download videos for it` |
| 닿을 주소 없음 안내 | `같은 네트워크의 다른 기기가 닿을 주소가 없습니다` | `No address that other devices on the same network can reach` |
| 프록시 시작 실패 안내 | `프록시를 시작하지 못했습니다. 앱을 다시 실행해 주세요` | `Couldn't start the proxy. Restart the app.` |
| 프록시 주소 입력 라벨 | `프록시 주소` | `Proxy address` |
| 프록시 주소 자리 표시 문구 | `http://192.168.0.10:54321` | `http://192.168.0.10:54321` |
| 프록시 주소 보조 문구 | `같은 네트워크에서 실행 중인 데스크톱 앱의 설정 > 다운로드에서 확인한 주소를 입력합니다` | `Enter the address shown in Settings > Download of the desktop app running on the same network` |
| 저장 버튼 접근성 이름 | `저장` | `Save` |
| 저장 성공 안내 | `저장되었습니다.` | `Saved.` |
| 저장 실패 안내 | `저장하지 못했습니다.` | `Couldn't save.` |

주소 줄의 접근성 이름은 주소 전체를 그대로 둔다. 안내 한 줄은 그 문구를 그대로 읽힌다.

프록시 주소 입력의 접근성 이름은 `프록시 주소` 라벨과 보조 문구를 이어 읽히게 둔다.
