# 항목 상세 화면 공통 디자인

기준 스펙: [항목 상세 화면 공통 스펙](../spec/client/entity-detail.md)

이 문서는 저장된 항목 하나를 확인하고 수정하는 상세 화면들이 함께 쓰는 상단 바 제목의 표현, 삭제 버튼의 자리, 수정 실행 단축키, 피드백 스낵바의 교체, 진입할 때의 초점 표현을 소유한다. 상단 바에 두는 동작 버튼과 순서, 탭과 본문 구성, 수정 버튼의 자리와 표시 조건, 화면에만 있는 표현과 문구는 각 화면 문서가 정한다.

## 상단 바 제목

상단 바에는 저장된 항목의 제목을 표시한다. 제목은 한 줄을 유지하고, 사용할 수 있는 폭을 넘으면 기본 이동 속도와 간격으로 가로 이동을 시작해 화면에 표시되는 동안 횟수 제한 없이 반복한다. 접근성에는 생략하지 않은 전체 제목을 제공한다. 이는 목록 카드의 제목과 같은 표현이다.

## 삭제 버튼의 자리

상단 바 끝 쪽에 동작 버튼을 두는 화면은 삭제 버튼을 맨 끝 모서리에 둔다. 되돌릴 수 없는 삭제를 모서리에 고정해 두어 다른 동작이 늘어도 삭제 버튼의 자리가 바뀌지 않게 한다.

## 수정 실행 단축키

물리 키보드 환경에서는 수정 버튼이 표시된 동안 `Cmd` 또는 `Meta`와 `Enter`를 함께 눌러 수정 반영을 실행할 수 있다. 이는 [항목 추가 화면 공통 디자인](./entity-add.md)의 `초점과 키보드 단축키`가 정한 추가 실행 단축키와 같은 기준이다.

## 피드백 스낵바

새 피드백을 표시할 때 이미 보이는 스낵바가 있으면 표시 시간이 지나기를 기다리지 않고 즉시 새 피드백으로 바꾼다. 이는 [항목 추가 화면 공통 디자인](./entity-add.md)의 `진행과 피드백`과 같은 기준이다.

## 진입할 때의 초점

진입할 때는 어느 입력에도 초점을 두지 않으므로 소프트 키보드도 열지 않는다. 초점을 옮길 때의 스크롤과 키보드 표현은 [항목 추가 화면 공통 디자인](./entity-add.md)의 `초점과 키보드 단축키`를 따른다.
