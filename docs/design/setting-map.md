# SettingMap 화면 디자인

기준 스펙: [SettingMap 화면 스펙](../spec/client/setting-map.md)

화면 구조, 저장된 값을 확인하기 전의 표시와 공통 문구는 [기기 설정 화면 공통 디자인](./device-setting.md)을 따른다. 이 문서는 이 화면에서만 다른 표현을 다룬다.

## 화면 구조

본문에는 지도 설정을 설정별 영역으로 나누어 세로로 배치한다.

## 기본 지도 선택

`기본 지도` 설정 이름을 선택 줄 묶음 위에 두고, 그 아래에 `네이버`, `Google`을 각각 한 줄로 표시한다. 설정 이름은 묶음 안에 넣지 않고 묶음 바깥의 영역 제목으로 둔다.

설정 이름은 묶음의 바깥 가장자리에 맞춰 시작 쪽으로 정렬하고, 이름과 묶음 사이에는 [항목 간격](./dimens.md)을 둔다.

두 줄의 배경과 모양, 줄 사이 간격, 누름과 선택 상태의 표현은 [묶음 목록 항목 디자인](./segmented-list-item.md)의 하나만 고르는 묶음을 따른다. 줄 사이에는 구분선을 두지 않는다.

저장된 기본 지도 한 줄만 선택 상태로 표시한다. 사용자는 줄 전체를 선택할 수 있고, 줄 시작 쪽의 라디오 버튼만 따로 누르는 대상으로 두지 않는다.

저장된 기본 지도를 확인하기 전이거나 읽지 못한 상태에서는 기본 지도 설정 영역을 설정 이름까지 함께 감춘다.

## 문구와 접근성

한국어 환경과 그 외 기본 환경에서는 다음 문구를 사용한다. 뒤로가기 접근성 이름은 [기기 설정 화면 공통 디자인](./device-setting.md)의 `문구와 접근성`을 따른다.

| 문구 | 한국어 | 그 외 기본 |
| --- | --- | --- |
| 상단 바 제목 | `지도 설정` | `Map Settings` |
| 기본 지도 설정 이름 | `기본 지도` | `Default Map` |
| 네이버 지도 항목 이름 | `네이버` | `Naver` |
| Google 지도 항목 이름 | `Google` | `Google` |
