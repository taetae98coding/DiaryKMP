# 목록 진입 버튼 디자인

이 문서는 목록 위 정렬 줄의 끝 쪽에 두어 같은 대상의 다른 목록으로 이동하는 진입 버튼의 해부구조와 조작, 접근성을 소유한다. 어느 목록으로 이동하는지와 버튼의 라벨 문구는 그 버튼을 쓰는 화면 디자인이 소유한다.

이 문서는 이미 스펙이 정의한 이동 동작의 표현만 다루고 사용자 행위나 제품 정책을 새로 정의하지 않으므로 기준 스펙을 두지 않는다. 같은 기준을 쓰는 [아이콘 버튼 설명 디자인](./icon-button-tooltip.md)과 같다.

## 적용 대상

목록을 담은 화면에서 그 목록과 짝이 되는 다른 목록으로 이동하는 진입에 이 버튼을 쓴다. 완료된 메모 목록과 완료된 태그 목록처럼, 지금 보고 있는 목록이 걸러 낸 항목을 모아 보여 주는 목록으로 가는 진입이 여기에 해당한다.

같은 화면의 다른 목적지로 가는 검색과, 지금 목록의 표시 조건을 바꾸는 필터는 이 버튼을 쓰지 않는다. 두 동작은 상단 바에 아이콘 버튼으로 남긴다. 상단 바에는 라벨을 둘 자리가 없고, 화면마다 같은 자리에서 검색과 필터를 찾을 수 있어야 하기 때문이다.

## 해부구조

버튼에는 이동할 목록을 가리키는 라벨과 다음 화면으로 이동함을 뜻하는 오른쪽 방향 화살표 아이콘을 시작 쪽에서부터 이 순서로 둔다. 화살표 아이콘의 크기는 글자 버튼 안 아이콘의 기본 크기를 따른다.

아이콘만 두지 않고 라벨을 함께 두는 것은, 같은 줄의 시작 쪽 정렬 컨트롤도 라벨을 표시하고 있어 끝 쪽만 아이콘 하나면 어디로 이동하는지 알기 어렵기 때문이다.

버튼은 같은 줄의 정렬 컨트롤과 같은 글자 버튼 색과 모양을 쓰고, 배경을 채운 버튼으로 두지 않는다. 모양은 [목록 정렬 디자인](./list-sort.md)의 `정렬 줄`이 정한 완전히 둥근 모양을 그대로 따른다. 목록을 바꿔 보는 보조 동작이므로 목록 항목과 떠 있는 추가 버튼보다 앞서 보이지 않게 한다.

이동할 목록의 항목 개수를 나타내는 배지나 숫자는 표시하지 않는다.

## 자리와 폭

버튼은 [목록 정렬 디자인](./list-sort.md)의 `정렬 줄` 끝 쪽에 두고, 정렬 컨트롤과 같은 줄을 쓴다. 줄을 둘로 나누면 목록이 쓸 수 있는 높이만 줄기 때문이다. 줄의 좌우 바깥 여백은 [목록 정렬 디자인](./list-sort.md)의 `정렬 줄`이 정한 값을 따르며, 이 버튼의 끝 쪽 끝은 목록 항목의 끝 쪽 끝과 같은 세로선에 놓인다.

좁은 창에서 줄의 폭이 모자라면 이 버튼은 라벨을 줄이지 않고 내용에 맞는 폭을 유지하며, 정렬 컨트롤의 이름이 먼저 줄어든다. 줄어드는 기준은 [목록 정렬 디자인](./list-sort.md)의 `정렬 줄`을 따른다.

## 상태

이동할 목록이 비어 있어도, 지금 목록이 빈 상태여도, 목록을 아직 준비하는 중이어도 버튼은 같은 자리에 같은 모양으로 표시하며 비활성 표현을 사용하지 않는다. 사용자는 어느 상태에서도 다른 목록을 확인할 수 있다.

## 조작과 접근성

버튼 전체가 하나의 누를 수 있는 대상이며, 라벨을 눌러도 화살표 아이콘을 눌러도 같은 동작을 실행한다.

화면에 적힌 라벨을 그대로 접근성 이름으로 읽히게 하고 별도의 접근성 이름을 더하지 않는다. 버튼 안의 화살표 아이콘에는 접근성 이름을 두지 않아 이름이 두 번 읽히지 않게 한다. 이는 [목록 정렬 디자인](./list-sort.md)의 `접근성`에서 정렬 컨트롤을 다루는 기준과 같다.

라벨을 함께 표시하므로 [아이콘 버튼 설명 디자인](./icon-button-tooltip.md)의 설명 표시는 두지 않는다.

키보드나 포인터를 사용하는 환경에서는 버튼에 초점을 이동해 `Enter` 또는 `Space`로 실행할 수 있다.
