# TagMemoFinishedList 화면 디자인

기준 스펙: [TagMemoFinishedList 화면 스펙](../spec/tag-memo-finished-list.md)

화면 구조, 정렬 줄 자리, 목록과 빈 상태·새로고침의 공통 표현은 [완료 목록 공통 디자인](./finished-list.md)을 따른다.

## 화면 구조와 이동

TagMemoFinishedList 화면은 창 너비와 관계없이 TagHome이나 TagDetail과 함께 배치하지 않는다. 완료된 메모 목록과 메모 상세를 함께 표시하는 배치는 [TagMemoFinishedList 목록·상세 배치 디자인](./tag-memo-finished-list-detail.md)을 따른다.

상단 바에는 두 줄 제목을 둔다. 첫 줄에는 대상 태그의 저장 이모지와 제목을, 그 아래 보조 줄에는 `완료된 메모`를 표시한다. 두 줄을 함께 두어 사용자는 어느 태그의 목록인지와 완료된 메모만 모은 목록인지를 한 번에 확인한다.

첫 줄의 표시 형태는 [TagHome 목록 디자인](./tag-home.md)의 `이모지와 제목 표시`를 따른다. 첫 줄은 한 줄을 유지하고, 사용 가능한 폭을 넘으면 [TagDetail 화면 디자인](./tag-detail.md)의 상단 바 제목과 같은 기본 이동 속도와 간격으로 가로 이동을 반복한다. 접근성에는 생략하지 않은 전체 제목을 제공한다.

보조 줄은 태그와 무관한 고정 문구이므로 가로 이동을 하지 않는다.

대상 태그를 아직 조회하지 못한 동안에는 첫 줄을 비우고 보조 줄만 표시한다. 이때도 뒤로가기 버튼과 목록은 그대로 표시한다.

메모를 선택하면 MemoDetail 화면을 표시한다. 완료된 메모 목록과 함께 표시하는지 단독으로 표시하는지는 [TagMemoFinishedList 목록·상세 배치 디자인](./tag-memo-finished-list-detail.md)을 따른다.

## 목록

메모 카드의 제목, 컬러 원형 표시, 기간 표기와 카드 사이 간격은 [MemoHome 목록 디자인](./memo-home.md)의 `메모 카드`와 `기간과 날짜 문구`를 따른다.

기간 없는 메모는 목록 맨 위에 헤더 없이 표시한다. 기간 있는 메모는 시작 날짜별로 묶고 각 묶음 위에 날짜 헤더를 둔다. 헤더의 표시와 스크롤 고정 방식은 MemoHome 목록 디자인의 `날짜 헤더`를 따른다.

아직 준비되지 않은 자리에는 [페이지 조회 목록의 자리 표시 디자인](./paged-list-placeholder.md)에 따라 자리 표시 카드를 표시한다.

## 빈 상태

빈 상태의 아이콘과 문구는 [목록 빈 상태 디자인](./list-empty-state.md)이 `TagMemoFinishedList 태그별 완료된 메모 목록`으로 정한 값을 따른다.

대상 태그를 아직 조회하지 못해 상단 바 첫 줄이 비어 있는 동안에도 목록과 빈 상태는 같은 기준으로 표시한다.

## 다시 시작·삭제 제스처와 피드백

[SwipeToFinishAndDelete 컴포넌트 디자인](./swipe-to-finish-and-delete.md)에 따라 카드를 왼쪽에서 오른쪽으로 스와이프하면 다시 시작하고, 오른쪽에서 왼쪽으로 스와이프하면 삭제한다.

시작 방향의 상태 아이콘에는 완료 아이콘 대신 화살표가 원을 그리는 다시 시작 아이콘을 표시한다. 끝 방향의 삭제 아이콘은 TagDetail 메모 탭의 메모 목록과 같다.

다시 시작 또는 삭제 뒤의 피드백과 실행 취소는 스낵바로 표시한다.

## 문구와 접근성

상단 바 첫 줄은 언어 환경과 관계없이 대상 태그에 저장된 이모지와 제목을 그대로 표시한다.

[완료 목록 공통 디자인](./finished-list.md)의 `문구와 접근성`에 더해 한국어 환경과 그 외 기본 환경에서는 다음 문구를 사용한다.

| 문구 | 한국어 | 그 외 기본 |
| --- | --- | --- |
| 상단 바 보조 제목 | `완료된 메모` | `Finished Memos` |
| 다시 시작 안내 | `메모를 다시 시작했습니다.` | `Memo restarted.` |
| 삭제 안내 | `메모가 삭제되었습니다.` | `Memo deleted.` |
| 실행 취소 동작 | `실행 취소` | `Undo` |
| 다시 시작 스와이프 아이콘 접근성 이름 | `메모 다시 시작` | `Restart memo` |
| 삭제 스와이프 아이콘 접근성 이름 | `메모 삭제` | `Delete memo` |
| 오늘 날짜 헤더 | `오늘` | `Today` |
