# TagFinishedList 화면 디자인

기준 스펙: [TagFinishedList 화면 스펙](../spec/client/tag-finished-list.md)

화면 구조, 정렬 줄 자리, 목록과 빈 상태·새로고침의 공통 표현은 [완료 목록 공통 디자인](./finished-list.md)을 따른다.

## 화면 구조와 이동

상단 바에는 `완료된 태그` 제목을 표시한다.

태그를 선택하면 TagDetail 화면을 창 너비와 관계없이 단독으로 표시한다.

## 목록

태그 카드의 이모지와 제목 표시, 컬러 원형 표시, 2열 고정 그리드 배치와 카드 사이 간격은 [TagHome 목록 디자인](./tag-home.md)의 `이모지와 제목 표시`와 `목록`을 따른다.

아직 준비되지 않은 자리의 자리 표시 카드는 [TagHome 목록 디자인](./tag-home.md)의 `목록`과 같게 표시한다.

## 빈 상태

빈 상태는 격자 자리에 표시하고, 아이콘과 문구는 [목록 빈 상태 디자인](./list-empty-state.md)이 `TagFinishedList 완료된 태그 목록`으로 정한 값을 따른다.

## 카드 조작

카드를 누르는 조작은 `화면 구조와 이동`을 따른다.

## 다시 시작·삭제 제스처와 피드백

[SwipeToFinishAndDelete 컴포넌트 디자인](./swipe-to-finish-and-delete.md)에 따라 카드를 왼쪽에서 오른쪽으로 스와이프하면 다시 시작하고, 오른쪽에서 왼쪽으로 스와이프하면 삭제한다. 2열 격자에서 카드마다 따로 스와이프하는 것과 자리 표시 카드가 스와이프되지 않는 것은 [TagHome 목록 디자인](./tag-home.md)의 `완료와 삭제 제스처`와 같다.

시작 방향의 상태 아이콘에는 완료 아이콘 대신 화살표가 원을 그리는 다시 시작 아이콘을 표시한다. 끝 방향의 삭제 아이콘은 TagHome 목록과 같다.

다시 시작 또는 삭제 뒤의 피드백과 실행 취소는 스낵바로 표시한다. 표시 시간과 새 안내로 바꾸는 방식, 저장되지 못했을 때 스낵바를 표시하지 않는 것, 실행 취소로 돌아온 카드의 모양과 자리는 [TagHome 목록 디자인](./tag-home.md)의 `완료와 삭제 제스처`와 같다.

## 문구와 접근성

[완료 목록 공통 디자인](./finished-list.md)의 `문구와 접근성`에 더해 한국어 환경과 그 외 기본 환경에서 다음 문구를 사용한다.

| 항목 | 한국어 | 그 외 기본 |
| --- | --- | --- |
| 상단 바 제목 | `완료된 태그` | `Finished Tags` |
| 다시 시작 안내 | `태그를 다시 시작했습니다.` | `Tag restarted.` |
| 삭제 안내 | `태그가 삭제되었습니다.` | `Tag deleted.` |
| 실행 취소 동작 | `실행 취소` | `Undo` |
| 다시 시작 스와이프 아이콘 접근성 이름 | `태그 다시 시작` | `Restart tag` |
| 삭제 스와이프 아이콘 접근성 이름 | `태그 삭제` | `Delete tag` |
