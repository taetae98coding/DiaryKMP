# Login 화면 디자인

기준 스펙: [Login 화면 스펙](../spec/client/login.md)

## 화면 구조

Login 화면은 앱의 공통 내비게이션 영역 없이 단독으로 표시한다.

화면 상단에는 로그인 화면임을 알리는 상단 바와 뒤로가기 버튼을 표시한다. 본문 중앙에는 Apple 로그인 버튼과 Google 로그인 버튼을 같은 크기의 아이콘 버튼으로 가로로 나란히 배치하며, Apple 로그인 버튼을 앞에 둔다. 두 버튼 사이 간격은 [공통 여백과 간격](./dimens.md)의 `구성요소 간격`을 쓴다.

두 로그인 버튼은 모든 플랫폼에서 같은 구성으로 표시한다.

상단 바의 뒤로가기 버튼이나 시스템 뒤로가기를 사용하면 진입하기 전 화면으로 돌아간다.

## 로그인 버튼

Google 로그인 버튼은 Google 공식 가이드의 아이콘 모드 버튼으로 표시한다. 표준 색상의 Google `G` 로고는 색상, 비율, 형태를 바꾸지 않는다. 시스템이 밝은 모양이면 흰색 바탕에 회색 테두리, 어두운 모양이면 어두운 바탕에 밝은 회색 테두리로 표시한다.

Apple 로그인 버튼은 Apple 공식 가이드가 허용하는 로고 전용 버튼으로 표시한다. 버튼 전체 색은 흰색 또는 검은색을 유지하고 Apple 로고의 비율과 형태를 바꾸지 않는다. 시스템이 밝은 모양이면 흰색 버튼, 어두운 모양이면 검은색 버튼으로 표시하고, Google 로그인 버튼과 같은 테두리 색을 쓴다.

두 로고 모두 장식 요소나 로고 자체만으로 사용하지 않는다. 로그인 행동임을 알 수 있는 경계와 터치 영역을 가진 버튼 안에 배치한다.

## 상태와 피드백

진행 표시는 다음 두 구간에 보인다.

- 앱 로그인 요청을 처리하는 동안
- 흐름의 끝을 알 수 있는 플랫폼(스펙의 `로그인 요청 제한`)에서 플랫폼의 로그인 흐름이 진행되는 동안

이 구간에는 로그인 버튼 대신 본문 영역 가운데에 Material 3의 바탕이 있는 로딩 표시(ContainedLoadingIndicator)를 보여 준다. 진행 표시에는 별도의 접근성 이름을 두지 않는다. 로그인 버튼과 진행 표시는 서로 교차해 사라지고 나타나며 바뀐다. 플랫폼의 로그인 흐름에서 앱 로그인 처리로 넘어갈 때는 진행 표시가 끊기지 않고 그대로 이어진다. 진행 중에도 상단 바와 뒤로가기 버튼은 계속 표시한다. 플랫폼의 로그인 창이 Login 화면을 덮는 동안에는 그 창이 보이고, 창이 닫히면 뒤에 있던 진행 표시가 보인다.

흐름의 끝을 알 수 없는 플랫폼(데스크톱)에서는 플랫폼의 로그인 흐름이 진행되는 동안 Login 화면의 표시를 바꾸지 않고 로그인 버튼을 그대로 보여, 사용자가 다시 선택할 수 있게 한다. 앱 로그인 처리가 시작되면 위와 같이 진행 표시로 바뀐다.

사용자가 플랫폼의 로그인 흐름을 취소하면 안내 없이 진행 표시가 로그인 버튼으로 바뀐다. 흐름의 끝을 알 수 없는 플랫폼에서는 로그인 버튼이 그대로 보인다.

로그인에 실패하면 실패 안내를 짧게 보이는 스낵바로 표시한다. 이미 표시 중인 스낵바가 있으면 그 스낵바를 닫고 새 안내를 표시한다. 실패 후에는 진행 표시를 종료하고 로그인 버튼을 다시 표시한다.

## 데스크톱 Apple 로그인 결과 페이지

데스크톱에서 Apple 웹 로그인이 끝나 브라우저가 앱의 로컬 수신 주소로 돌아오면, 브라우저에는 앱으로 돌아가라는 한 문장만 담은 결과 페이지를 표시한다. 결과 페이지에는 인증 결과나 오류 내용을 표시하지 않는다. 문구는 기기의 언어가 한국어이면 한국어, 그 밖에는 영어로 표시한다.

데스크톱의 Google 로그인이 끝났을 때 브라우저에 표시되는 결과 페이지는 앱이 따로 정하지 않고 로그인 도구가 제공하는 기본 페이지를 그대로 쓴다.

## 문구와 접근성

한국어 환경과 그 외 기본 환경에서 다음 문구를 사용한다.

| 항목 | 한국어 | 그 외 기본 |
| --- | --- | --- |
| 상단 바 제목 | `로그인` | `Login` |
| 뒤로가기 버튼 접근성 이름 | `뒤로가기` | `Navigate up` |
| Google 로그인 버튼 접근성 이름 | `Google로 로그인` | `Sign in with Google` |
| Apple 로그인 버튼 접근성 이름 | `Apple로 로그인` | `Sign in with Apple` |
| 로그인 실패 안내 | `로그인에 실패했습니다.` | `Sign-in failed.` |
| 데스크톱 Apple 로그인 결과 페이지 | `이 창을 닫고 앱으로 돌아가세요.` | `You can close this window and return to the app.` |
