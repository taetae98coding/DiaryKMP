# 태그 연결 입력 컴포넌트 디자인

기준 스펙: [태그 연결 입력 컴포넌트 스펙](../spec/tag-link-input.md)

칩 영역과 추가 칩, 태그 선택 목록과 그 안의 검색·태그 추가 버튼·빈 상태·준비 상태 표현은 [태그 선택 입력 공통 디자인](./tag-select-input.md)을 따른다. 이 문서는 이 입력에서만 다른 칩 구성과 문구를 소유한다.

화면마다 다른 자리와 표시 조건은 [TagAdd 화면 디자인](./tag-add.md)과 [TagDetail 화면 디자인](./tag-detail.md)이 소유한다.

## 태그 칩

연결은 한 방향만 다루므로 칩에 방향을 나타내는 화살표나 별도의 표시를 두지 않는다.

## 태그 연결 칩

이 입력의 추가 칩은 태그 연결 칩이며, 표현과 동작은 [태그 선택 입력 공통 디자인](./tag-select-input.md)의 `추가 칩`을 그대로 따른다.

## 태그 선택 목록

목록 항목 끝에 두는 버튼은 없다. 메모 태그 입력의 선택 목록과 이 점이 다르다. 목록 아래의 태그 추가 버튼은 공통 디자인을 그대로 따르며, 칩의 `태그 연결`과 달리 `태그 추가` 라벨로 두 동작을 구분한다.

## 문구와 접근성

[태그 선택 입력 공통 디자인](./tag-select-input.md)의 `문구와 접근성`에 더해 한국어 환경과 그 외 기본 환경에서 다음 문구를 사용한다.

| 항목 | 한국어 | 그 외 기본 |
| --- | --- | --- |
| 태그 연결 칩 라벨 | `태그 연결` | `Link tag` |
| 태그 연결 동작 접근성 이름 | `태그 연결` | `Link tag` |
| 태그 선택 목록 제목 | `태그 연결` | `Link Tag` |

이 입력만 `태그 연결` 문구를 쓴다. 항목에 태그를 고르는 다른 두 입력과 달리 태그와 태그를 잇는 동작이므로, 사용자가 두 동작을 이름으로 구분할 수 있게 한다.
