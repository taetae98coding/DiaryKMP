# MoreHome 화면 디자인

기준 스펙: [MoreHome 화면 스펙](../spec/more-home.md)

## 화면 구조

MoreHome 화면은 앱의 공통 내비게이션 영역과 함께 표시한다.

화면 상단에는 다국어 제목을 표시하는 상단 바를 둔다. 상단 바 끝 쪽에는 설정 화면으로 이동하는 아이콘 동작 하나를 둔다.

본문에는 계정 카드를 먼저 배치하고 그 아래에 기능 바로가기 메뉴를 둔다.

기능 바로가기는 앞으로 항목이 늘어날 수 있는 격자로 배치한다. 각 항목의 최소 너비는 `64dp`이고, 화면 너비에 맞춰 한 줄의 항목 수와 각 항목 너비를 자동으로 조정한다. 계정 카드와 메뉴, 인접한 메뉴 항목 사이에는 앱의 공통 구성요소 간격을 적용한다.

## 계정 카드

계정 카드는 프로필 영역과 계정 동작 하나로 구성한다.

사용자 정보를 다시 확인하는 동안에는 진행 표시를 두지 않고 카드의 표현을 바꾸지 않는다. 확인이 끝나 프로필 이미지가 바뀌면 그 자리에서 새 이미지로 바뀐다.

프로필 이미지는 항상 표시한다. 계정 확인 중에는 프로필 옆의 이름이나 라벨을 비우고, 계정 동작은 누를 수 없는 자리 표시 상태로 나타낸다. 게스트 상태에서는 게스트 라벨과 로그인 동작을, 사용자 상태에서는 이메일과 로그아웃 동작을 나타낸다.

사용자 상태에서는 프로필 이미지를 누를 수 있는 대상으로 두고, 누르면 ProfileImageEdit 화면으로 이동한다. 누를 수 있는 범위와 누름 표시는 프로필 이미지와 같은 원형이며, 이메일 문구는 누름 대상에 넣지 않는다. 바꾸려는 대상이 사진 자체이므로 누름 대상과 바뀌는 대상을 일치시킨다. 확인 중과 게스트 상태에서는 프로필 이미지를 누를 수 없고 누름 표시도 두지 않는다.

계정 동작에는 문구 앞에 동작을 나타내는 아이콘을 함께 둔다. 로그인은 안으로 들어가는 방향, 로그아웃은 밖으로 나가는 방향의 아이콘을 쓰고, 두 아이콘은 읽는 방향이 오른쪽에서 왼쪽인 언어에서 좌우를 뒤집는다. 아이콘은 문구가 이미 전달하는 뜻을 그림으로 거듭 보여주는 장식이므로 별도 접근성 이름을 두지 않는다. 자리 표시 상태에서는 아이콘도 두지 않는다.

## 로그아웃 확인 다이얼로그

로그아웃 동작을 눌렀을 때 확인이 필요하면 화면 가운데에 확인 다이얼로그를 띄운다. 다이얼로그는 위에서 아래로 제목, 안내 문구, 동작 줄을 둔다.

다이얼로그의 너비는 대화상자 컴포넌트의 기본값을 따르고, 높이는 내용에 맞춘다. 창 크기와 플랫폼에 따라 구성이 달라지지 않는다.

제목 위에 아이콘을 두지 않는다. 로그아웃은 기기에 저장된 내용을 지우지 않으므로 경고 아이콘으로 위험을 알릴 상황이 아니고, 제목과 안내 문구가 무엇을 확인하는지 이미 전달한다.

안내 문구에는 남아 있는 변경의 개수나 종류를 넣지 않는다. 사용자가 개수를 보고 할 수 있는 다른 선택이 없고, 개수를 세는 동안 다이얼로그가 늦게 뜨기 때문이다.

동작 줄은 대화상자 컴포넌트의 기본 배치를 그대로 쓴다. 로그아웃을 끝 쪽에, 취소를 그 앞에 둔다. 두 동작은 모두 배경 없는 텍스트 버튼으로 두고, 로그아웃을 강조 색이나 오류 색으로 구분하지 않는다.

사용자는 다이얼로그 바깥을 누르거나 뒤로가기로 다이얼로그를 닫을 수 있고, 물리 키보드 환경에서는 `Esc`로도 닫을 수 있다. 닫는 동안 로그아웃은 실행되지 않는다.

다이얼로그가 떠 있는 동안 뒤의 화면은 흐려진 가림막으로 덮고, 뒤의 컨트롤은 누를 수 없다.

## 기능 바로가기

각 바로가기는 선택 가능한 카드로 표현하고, 기능을 나타내는 아이콘과 이름을 함께 표시한다. 항목과 순서는 기준 스펙을 따른다.

아직 기능을 제공하지 않는 화면으로 이동하는 항목도 다른 항목과 같은 카드로 표현하고, 준비 중임을 나타내는 표시나 비활성 표현을 두지 않는다. 그 화면의 표현은 [더보기 준비 중 화면 공통 디자인](./more-menu-placeholder.md)이 소유한다.

## 문구와 접근성

한국어 환경과 그 외 기본 환경에서는 다음 문구를 사용한다.

| 문구 | 한국어 | 그 외 기본 |
| --- | --- | --- |
| 상단 바 제목 | `더보기` | `More` |
| 설정 동작 접근성 이름 | `설정` | `Settings` |
| 게스트 라벨 | `게스트` | `Guest` |
| 로그인 동작 | `로그인` | `Sign in` |
| 로그아웃 동작 | `로그아웃` | `Sign out` |
| 로그아웃 확인 제목 | `로그아웃할까요?` | `Sign out?` |
| 로그아웃 확인 안내 | `아직 서버에 반영되지 않은 변경이 있습니다. 로그아웃하면 이 기기에서 다시 로그인하기 전까지 반영되지 않습니다.` | `Some changes haven't been sent to the server yet. If you sign out, they won't be sent until you sign in again on this device.` |
| 로그아웃 확인 동작 | `로그아웃` | `Sign out` |
| 로그아웃 취소 동작 | `취소` | `Cancel` |
| 프로필 이미지 접근성 이름 | `프로필 이미지` | `Profile image` |
| 프로필 이미지 편집 동작 접근성 이름 | `프로필 이미지 편집` | `Edit profile photo` |
| QR 항목 이름 | `QR` | `QR` |
| 검색 항목 이름 | `검색` | `Search` |
| 디데이 항목 이름 | `디데이` | `D-Day` |
| 연락처 항목 이름 | `연락처` | `Contacts` |
| 웹 항목 이름 | `웹` | `Web` |
| 장소 항목 이름 | `장소` | `Place` |
| 체크리스트 항목 이름 | `체크리스트` | `Checklist` |
| 파일 항목 이름 | `파일` | `Files` |
| 플레이리스트 항목 이름 | `플레이리스트` | `Playlist` |
| 황금연휴 항목 이름 | `황금연휴` | `Golden Holiday` |

설정 동작과 프로필 이미지에는 표에 정의한 사용자 언어별 접근성 이름을 제공한다.

사용자 상태에서는 프로필 이미지에 접근성 이름과 함께 누름 동작의 접근성 이름도 제공해, 이미지가 무엇인지와 누르면 무엇을 하는지를 따로 알린다.

로그아웃 확인 다이얼로그에는 별도의 접근성 이름을 두지 않는다. 화면 낭독기는 제목과 안내 문구를 순서대로 읽고, 두 동작은 각자의 문구로 읽힌다.
