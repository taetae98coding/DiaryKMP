# 일일 메모 알림 디자인

기준 스펙: [일일 메모 알림 스펙](../spec/daily-memo-notification.md)

이 문서는 알림이 사용자에게 보이는 문구와 표현을 소유한다. 알림이 언제 발생하고 어떤 조건에서 보이며 무엇을 오늘의 메모로 삼는지는 기준 스펙이 소유한다.

알림은 앱 화면이 아니라 각 플랫폼의 알림 표시 영역에 놓이므로, 배치와 크기는 플랫폼의 기본 알림 표현을 그대로 따르고 이 문서에서 따로 정하지 않는다.

## 알림 구성

알림은 제목 한 줄과 본문으로 구성한다. 본문은 오늘의 메모가 하나 이상일 때만 둔다.

### 제목

제목은 기준 스펙의 `알림 내용을 정하는 시점`이 가르는 세 상태에 따라 다르다. `N`은 오늘의 메모 개수다.

| 상태 | 한국어 | 영어 |
| --- | --- | --- |
| 오늘의 메모가 1개 이상 | `오늘 확인할 메모가 N개 있어요` | `You have N memos to check today` |
| 오늘의 메모가 0개 | `오늘 확인할 메모가 없어요` | `No memos to check today` |
| 오늘의 메모를 정할 수 없음 | `오늘의 메모를 확인하세요` | `Check today's memos` |

영어에서 개수가 1이면 `You have 1 memo to check today`로 단수형을 쓴다. 한국어는 개수에 따라 형태가 바뀌지 않는다.

앱 이름은 네 플랫폼 모두 알림 머리말에 자동으로 붙으므로 문구에 다시 넣지 않는다. 날짜도 넣지 않는다.

### 본문

본문은 오늘의 메모 제목을 기준 스펙의 순서대로 한 줄에 하나씩 나열한다. 각 줄은 `- `(하이픈과 공백)으로 시작하고 그 뒤에 메모 제목을 그대로 둔다. 줄 끝에 문장 부호를 붙이지 않는다.

```text
- 치과 예약
- 주간 회의 자료 정리
- 우유 사기
```

메모 제목은 줄이거나 바꾸지 않고 저장된 그대로 쓴다. 나열하는 개수에 상한을 두지 않고, 표시 영역에 들어가지 않는 부분은 각 플랫폼의 기본 동작대로 줄바꿈하거나 말줄임한다. 앱이 따로 자르지 않는다.

오늘의 메모가 0개이거나 정할 수 없는 상태에서는 본문을 두지 않는다.

## 아이콘

Android에서는 상태 표시줄과 알림에 단색 런처 아이콘(`ic_launcher_monochrome`)을 작은 아이콘으로 쓰고, 색은 시스템 기본값을 따른다. 큰 아이콘이나 별도의 이미지는 두지 않는다.

iOS와 웹에서는 각 플랫폼이 알림에 붙이는 앱 아이콘을 그대로 쓰고 앱이 따로 아이콘을 지정하지 않는다.

JVM 데스크톱은 알림을 시스템 트레이에서 띄우므로, 알림을 처음 표시할 때 트레이에 앱 아이콘을 둔다. 이 아이콘은 앱을 실행하는 동안 트레이에 남고, 선택하면 앱 창이 앞으로 나온다.

## 표시 방식

알림은 소리를 내지 않고 화면에만 표시한다. 진동, 배지, 화면 위로 잠깐 떠오르는 표시도 쓰지 않는다. 알림 권한을 알림 표시로만 한정하는 [알림 권한 요청 스펙](../spec/notification-permission.md)의 `요청 범위`와 같은 결정이다.

플랫폼별로 이 표시 방식에 해당하는 설정은 다음과 같다.

| 플랫폼 | 표시 방식 |
| --- | --- |
| Android | 소리와 화면 위 떠오름이 없고 알림 목록과 상태 표시줄에만 남는 중요도 |
| iOS | 알림 배너만 사용하고 소리와 배지는 사용하지 않음 |
| 웹 | 소리를 내지 않는 알림 |
| JVM 데스크톱 | 시스템 트레이의 알림 유형 중 소리와 상태 아이콘이 붙지 않는 유형 |

본문이 있는 알림의 플랫폼별 표현은 다음과 같다.

| 플랫폼 | 본문 표현 |
| --- | --- |
| Android | 접힌 알림에는 본문 첫 줄이 보이고, 알림을 펼치면 긴 글 형식으로 여러 줄이 보인다. 펼쳤을 때 보이는 줄 수는 시스템이 정한다 |
| 웹 | 브라우저 알림의 본문 자리에 그대로 표시한다 |
| JVM 데스크톱 | 트레이 알림의 메시지 자리에 그대로 표시한다 |
| iOS | 본문을 두지 않는다 |

알림은 사용자가 직접 지울 수 있고, 알림을 선택해 앱이 열리면 알림 목록에서 사라진다. 사용자가 지우지 않고 두면 다음 날 알림이 그 자리를 대신한다.

## Android 알림 채널

Android 시스템의 알림 설정에서 사용자가 이 알림을 구분해 끌 수 있도록 전용 알림 채널을 하나 둔다.

| 요소 | 한국어 | 영어 |
| --- | --- | --- |
| 채널 이름 | `일일 메모 알림` | `Daily memo reminder` |
| 채널 설명 | `매일 아침 오늘의 메모를 확인하도록 안내합니다.` | `Reminds you every morning to check today's memos.` |

채널은 이 알림에만 쓰고 다른 알림과 공유하지 않는다.

## 접근성

화면 낭독기는 알림의 제목 문구를 읽고, 본문이 있으면 본문을 이어서 읽는다. 문구 자체가 안내와 내용이므로 별도의 접근성 이름이나 설명을 덧붙이지 않는다.

알림을 선택하는 조작에는 별도의 접근성 이름을 두지 않고, 각 플랫폼이 알림에 기본으로 제공하는 열기 동작을 그대로 쓴다.
