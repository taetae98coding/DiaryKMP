# SettingFile 화면 디자인

기준 스펙: [SettingFile 화면 스펙](../spec/client/setting-file.md), [파일 내려받기 스펙](../spec/client/file-download.md)

## 화면 구조

SettingFile의 단독·목록/상세 배치와 표시 상태에 따른 뒤로가기 동작 노출은 [Setting 목록·상세 배치 디자인](./setting-list-detail.md)을 따른다.

화면 상단에는 제목이 있는 상단 바를 두고, 뒤로가기 동작을 제공하는 상태에서는 상단 바에 함께 배치한다.

본문에는 파일 설정을 설정별 영역으로 나누어 세로로 배치한다. 지금은 `다운로드 위치` 영역 하나다. 본문이 표시 영역보다 길어지면 위아래로 스크롤할 수 있다.

## 다운로드 위치

`다운로드 위치` 설정 이름을 묶음 위에 두고, 그 아래에 설정이 무엇을 하는지 알리는 보조 문구를 설정 이름보다 작은 글자와 낮은 강조 색으로 둔다. 설정 이름과 보조 문구의 자리와 정렬, 묶음과의 간격은 [SettingBrowser 화면 디자인](./setting-browser.md)의 영역 제목과 같다.

묶음의 배경과 모양, 줄 사이 간격과 누름 표현은 [묶음 목록 항목 디자인](./segmented-list-item.md)을 따른다. 묶음에는 위에서부터 다음 줄을 둔다.

| 줄 | 내용 | 누를 수 있는가 |
| --- | --- | --- |
| 현재 위치 | 시작 쪽에 폴더 아이콘. 제목 줄에 위치 이름, 보조 줄에 위치 설명 | 그렇다. 누르면 폴더 선택 도구를 연다 |
| 기본 위치로 되돌리기 | 시작 쪽에 되돌리기 아이콘, `기본 위치로 되돌리기`. 고른 폴더가 있을 때만 둔다 | 그렇다 |

현재 위치 줄은 고른 폴더가 있는지와 플랫폼에 따라 다음을 표시한다.

| 상태 | 제목 줄 | 보조 줄 |
| --- | --- | --- |
| 고른 폴더가 없음 | `기본 위치` | 플랫폼별 기본 위치 설명 |
| 고른 폴더가 있음 (Android, iOS) | 고를 때 시스템이 알려 준 폴더 이름. 이름이 없으면 `고른 폴더` | `고른 폴더`. 이름이 없어 제목 줄이 `고른 폴더`이면 보조 줄을 두지 않는다 |
| 고른 폴더가 있음 (JVM 데스크톱) | 폴더 이름 | 폴더의 전체 경로 |

제목 줄과 보조 줄은 줄바꿈해 전체를 표시하고 말줄임하지 않는다. 사용자가 파일을 찾아갈 위치이므로 일부가 가려지면 안 되기 때문이다.

현재 위치를 보여 주는 줄과 위치를 바꾸는 줄을 따로 두지 않고, 현재 위치 줄을 눌러 바로 바꾸게 한다.

`기본 위치로 되돌리기` 줄이 나타나거나 사라질 때는 묶음 아래쪽이 자연스럽게 늘고 줄도록 크기 변화에 기본 전환을 쓴다.

저장된 설정을 확인하기 전이거나 읽지 못한 상태에서는 이 영역을 설정 이름까지 함께 표시하지 않는다. 별도의 로딩 안내나 오류 안내도 표시하지 않는다.

## 폴더 선택 도구

현재 위치 줄을 누르면 플랫폼이 제공하는 폴더 선택 도구를 연다.

| 플랫폼 | 폴더 선택 도구 |
| --- | --- |
| Android | 시스템 문서 화면의 폴더 고르기 |
| iOS | 시스템 파일 선택 화면의 폴더 고르기 |
| JVM 데스크톱 | 운영체제의 폴더 열기 대화상자 |

폴더 고르기 결과를 저장하거나 되돌리는 동안에도 줄의 모양을 바꾸거나 진행 표시를 두지 않는다. 저장은 짧게 끝나며 끝나면 현재 위치 줄이 바로 바뀐다.

## 진행과 피드백

다운로드 위치를 바꾸지 못했다는 안내는 스낵바로 표시하고 동작 버튼은 두지 않는다. 표시 시간은 Material 기본의 짧은 표시 시간이다. 설정 목록과 함께 표시할 때도 상세 영역 안에 표시한다.

위치를 바꾸는 데 성공하면 현재 위치 줄이 바뀌는 것으로 결과를 알리고 스낵바를 표시하지 않는다.

## 표시 영역

본문과 스낵바는 상태 표시 영역, 시스템 탐색 영역과 카메라 컷아웃 등 기기가 가리는 영역을 침범하지 않게 배치한다. 이 화면에는 입력이 없으므로 소프트 키보드를 열지 않는다.

## 문구와 접근성

한국어 환경과 그 외 기본 환경에서는 다음 문구를 사용한다.

| 문구 | 한국어 | 그 외 기본 |
| --- | --- | --- |
| 상단 바 제목 | `파일 설정` | `File Settings` |
| 뒤로가기 접근성 이름 | `뒤로가기` | `Navigate up` |
| 다운로드 위치 설정 이름 | `다운로드 위치` | `Download location` |
| 다운로드 위치 보조 문구 | `파일 화면에서 내려받은 파일을 저장할 폴더입니다` | `The folder where files downloaded from Files are saved` |
| 기본 위치 제목 | `기본 위치` | `Default location` |
| 기본 위치 설명 (Android) | `기기의 Download 폴더` | `The device's Download folder` |
| 기본 위치 설명 (iOS) | `파일 앱의 나의 iPhone에 있는 이 앱의 폴더` | `This app's folder in On My iPhone in the Files app` |
| 기본 위치 설명 (JVM 데스크톱) | `홈 폴더의 Downloads 폴더` | `The Downloads folder in your home folder` |
| 고른 폴더 보조 줄 (Android, iOS) | `고른 폴더` | `Chosen folder` |
| 현재 위치 줄 누름 동작 이름 | `폴더 고르기` | `Choose folder` |
| 기본 위치로 되돌리기 | `기본 위치로 되돌리기` | `Reset to default location` |
| 위치 변경 실패 안내 | `다운로드 위치를 바꾸지 못했습니다.` | `Couldn't change the download location.` |

현재 위치 줄은 제목 줄과 보조 줄을 하나로 묶어 이어서 읽는 버튼으로 알리고, 누름 동작의 이름은 `폴더 고르기`로 알린다. `기본 위치로 되돌리기` 줄은 그 문구를 이름으로 하는 버튼으로 알린다.
