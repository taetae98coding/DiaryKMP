# TagDetail 웹 탭 디자인

기준 스펙: [TagDetail 웹 탭 스펙](../spec/client/tag-detail-web.md)

화면 전체의 구조, 상단 바, 탭 행, 페이지 전환과 떠 있는 버튼의 교체는 [TagDetail 화면 디자인](./tag-detail.md)이 소유한다. 이 문서는 웹 탭 안의 표현만 정한다.

## 탭 구성

웹 탭 안에는 웹 목록만 둔다. 메모 탭과 달리 목록 위에 별도의 진입 행을 두지 않는다. 웹 항목에는 완료 여부가 없어 완료된 웹 항목을 모아 보는 화면이 없기 때문이다.

웹 탭은 대상 태그의 조회 상태와 관계없이 같은 구성을 표시한다. 태그를 아직 조회하지 못해 상단 바에 제목이 없는 동안에도 목록은 같은 기준으로 표시한다.

## 웹 항목 추가

웹 항목 추가는 [TagDetail 화면 디자인](./tag-detail.md)의 `떠 있는 버튼`에 따라 웹 탭을 선택한 동안 떠 있는 웹 추가 버튼으로 제공한다. 버튼에는 추가를 나타내는 플러스 아이콘을 쓰며, 이는 [WebHome 화면 디자인](./web-home.md)의 웹 추가 버튼과 같은 아이콘이다. 대상 태그의 완료 여부와 삭제 여부는 이 버튼의 노출을 바꾸지 않는다.

웹 추가를 선택하면 WebAdd 화면을, 웹 항목을 선택하면 WebDetail 화면을 표시한다. 두 화면은 창 너비와 관계없이 TagDetail 화면과 함께 배치하지 않고 단독으로 표시한다. WebHome에서 진입할 때 쓰는 [Web 목록·상세 배치 디자인](./web-list-detail.md)은 이 경로에 적용하지 않는다.

WebAdd 화면은 대상 태그를 태그 입력에 이미 고른 상태로 시작한다. 그 표현은 [항목 태그 입력 컴포넌트 디자인](./entity-tag-input.md)의 태그 칩을 따르며, 별도의 강조나 잠금 표시를 두지 않아 사용자가 그 태그를 해제할 수 있음을 드러낸다.

## 정렬 줄

정렬 줄은 탭 줄 바로 아래, 웹 목록 위에 둔다. 정렬 줄과 정렬 선택 Bottom Sheet의 구조, 조작, 아이콘과 문구는 [목록 정렬 디자인](./list-sort.md)을 따른다.

## 목록

웹 카드의 제목, URL 표시와 카드 사이 간격은 [WebHome 화면 디자인](./web-home.md)을 따른다. 카드에는 그 웹 항목이 연결한 태그를 표시하지 않는다. 이 목록에 있는 웹 항목은 모두 대상 태그와 연결되어 있어 태그 표시가 항목을 구분해 주지 않기 때문이다.

웹 카드는 [WebHome 화면 디자인](./web-home.md)과 같은 격자로 놓고 목록은 세로로만 스크롤한다. 날짜 그룹처럼 항목을 묶는 헤더는 두지 않는다. 고를 수 있는 정렬이 제목순과 최근 수정순뿐이라 묶을 기준이 없다.

아직 준비되지 않은 자리에는 [페이지 조회 목록의 자리 표시 디자인](./paged-list-placeholder.md)에 따라 자리 표시 카드를 표시한다.

기준 스펙의 `빈 상태` 조건을 만족하면 목록 자리에 [목록 빈 상태 디자인](./list-empty-state.md)의 빈 상태를 표시한다. 아이콘과 제목·보조 문구는 그 문서의 표가 소유한다. 빈 상태에서도 떠 있는 웹 추가 버튼은 같은 자리에 그대로 표시하고, 정렬 컨트롤은 [목록 정렬 디자인](./list-sort.md)의 `항목이 없는 동안의 정렬 줄`에 따라 감춘다.

조회 실패에는 별도 오류 안내나 재시도 버튼을 표시하지 않는다. 조회에 실패해 표시할 웹 항목이 없을 때도 같은 빈 상태를 사용한다.

목록의 스크롤 위치는 다른 탭에 다녀와도 그대로 유지한다.

목록에는 완료·삭제 스와이프 제스처를 두지 않는다. 웹 항목의 삭제는 [WebDetail 화면 디자인](./web-detail.md)의 상단 바 액션에서만 제공하므로, [WebHome 화면 디자인](./web-home.md)의 목록과 같은 기준이다.

## 새로고침

목록을 아래로 당겨 새로고침하며, 당기는 조작과 진행 표시는 [새로고침 디자인](./sync-refresh.md)을 따른다. 목록이 빈 상태일 때도 같은 자리에서 당길 수 있다. 정렬 줄은 당김 컨테이너에 넣지 않는다.

## 키보드 단축키

웹 탭을 선택한 동안 물리 키보드로 `Command + A`를 눌러 웹 항목을 추가한다. 단축키 표는 [TagDetail 화면 디자인](./tag-detail.md)의 `키보드 단축키`가 소유한다.

다른 탭을 선택한 동안에는 이 단축키를 처리하지 않는다.

## 문구와 접근성

한국어 환경과 그 외 기본 환경에서는 다음 문구를 사용한다.

| 문구 | 한국어 | 그 외 기본 |
| --- | --- | --- |
| 추가 버튼 접근성 이름 | `웹 추가` | `Add web` |

웹 카드의 접근성 이름은 [WebHome 화면 디자인](./web-home.md)을 따른다. 빈 상태 문구는 [목록 빈 상태 디자인](./list-empty-state.md)의 문구 표가 소유한다.
