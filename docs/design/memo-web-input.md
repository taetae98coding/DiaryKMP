# 메모 웹 입력 컴포넌트 디자인

기준 스펙: [메모 웹 입력 컴포넌트 스펙](../spec/memo-web-input.md)

## 구성과 배치

웹 입력에는 현재 선택한 웹 항목의 칩과 웹 추가 칩을 표시하는 칩 영역을 둔다. 웹 추가 칩이 웹 입력임을 드러내므로 별도의 라벨은 두지 않는다.

웹 입력은 높이를 정하지 않는 자리에 두므로 칩 영역은 [공통 칩 영역 높이](./dimens.md)를 최소 높이로 쓴다. 선택한 웹 항목이 늘어 칩이 여러 줄이 되면 칩 영역이 그만큼 커지고, 뒤에 이어지는 요소는 커진 만큼 밀린다.

칩은 칩 영역의 가로·세로 가운데에 표시한다. 선택 상태가 바뀌어 내용이 달라질 때는 페이드로 전환한다.

칩은 가로로 배치하고 한 줄에 모두 들어가지 않으면 다음 줄로 넘긴다.

이 구성은 [메모 태그 입력 컴포넌트 디자인](./memo-tag-input.md)의 칩 영역과 같다. 두 입력이 다루는 대상만 다르고 사용자가 보는 구성은 같게 두어, 사용자가 같은 폼 안에서 같은 방식으로 대상을 고른다. 웹 입력을 폼의 어느 자리에 두는지는 [메모 본문 배치 디자인](./memo-form.md)이 소유한다.

## 웹 칩

웹 칩에는 웹 항목의 제목만 표시한다. 웹 항목에는 저장된 컬러가 없으므로 [메모 태그 입력 컴포넌트 디자인](./memo-tag-input.md)의 태그 칩이 두는 컬러 원형 표시에 해당하는 요소는 두지 않고, 그 자리를 비워 두지도 않는다. 이는 [WebHome 화면 디자인](./web-home.md)의 웹 카드가 컬러 표시를 두지 않는 기준과 같다.

제목이 칩에서 쓸 수 있는 폭을 넘었을 때의 표시와 칩 하나의 최대 폭은 [칩 이름 표시 디자인](./chip.md)을 따른다.

웹 칩을 누르면 그 웹 항목의 WebDetail 화면으로 이동한다. 칩에는 버튼 역할과 웹 상세로 이동함을 알리는 동작 접근성 이름을 제공한다. 칩을 눌러도 웹 선택 목록은 열지 않는다.

## 웹 추가 칩

칩 영역의 웹 칩 흐름 마지막에는 웹 추가 칩을 표시한다. 선택 상태가 바뀌어 칩이 자리를 옮겨도 웹 추가 칩은 항상 마지막에 둔다.

웹 추가 칩에는 추가를 나타내는 플러스 아이콘과 `웹 선택` 라벨을 표시한다. 선택한 웹 항목이 없으면 칩 영역에는 웹 추가 칩만 표시한다.

웹 추가 칩을 누르면 기준 스펙의 `추가 항목의 동작 판정`에 따라 웹 선택 목록을 열거나 WebAdd 화면으로 이동한다. 어느 동작으로 이어지든 칩의 표현은 같으며, 동작에 따라 라벨이나 아이콘을 바꾸지 않는다. 칩에는 버튼 역할과 웹 선택으로 이어짐을 알리는 동작 접근성 이름을 제공한다.

WebAdd 화면으로 이동할 때 별도의 안내나 전환 표시를 두지 않고 바로 이동한다.

## 웹 선택 목록

웹 추가 칩으로 웹 선택 목록이 열리면 다음과 같이 표시한다.

목록은 대화상자로 표시하고, 제목과 목록 내용의 여백은 [공통 여백과 간격](./dimens.md)의 `선택 대화상자 여백`을 따른다.

목록의 각 항목은 [선택 목록 항목 디자인](./picker-row.md)을 따르고, 웹 항목의 제목을 첫 줄에, URL을 보조 줄에 표시한다. 컬러 원형 표시는 두지 않는다.

같은 제목의 웹 항목이 여러 개일 수 있으므로 목록에는 URL을 함께 두어 사용자가 어느 항목인지 가릴 수 있게 한다. 칩에는 폭이 좁아 URL을 두지 않는다.

목록이 차지하는 자리는 [공통 선택 목록 높이](./dimens.md)로 고정하고, 항목이 그보다 많으면 그 자리 안에서 세로로 스크롤할 수 있게 한다. 항목 수가 바뀌거나 검색으로 결과가 줄어도 대화상자의 크기가 바뀌지 않아, 사용자가 보고 있던 목록과 아래의 웹 추가 버튼이 자리를 옮기지 않는다. 항목이 그 높이를 채우지 못하면 남는 자리는 비워 둔다.

항목이 목록에 들어오거나 빠질 때는 위치 변화에 애니메이션을 적용한다.

사용자가 항목을 누르면 그 웹 항목의 선택 여부를 바꾼다. 목록의 항목을 눌러 웹 상세로 이동하는 조작은 두지 않으며, 항목에는 웹 상세로 이동하는 별도의 버튼도 두지 않는다.

사용자는 목록 바깥을 누르거나 뒤로가기로 목록을 닫을 수 있다. 확인 버튼은 두지 않는다. 항목을 누르는 것이 곧 반영이므로 별도의 확인 단계를 두지 않는다.

## 웹 선택 목록의 검색 입력

목록 제목 바로 아래, 목록 위에 검색 입력을 상시 표시한다. 자리, 구성, 자리 표시 문구의 역할, 목록과의 간격, 초점과 소프트 키보드 동작은 [메모 태그 입력 컴포넌트 디자인](./memo-tag-input.md)의 `태그 선택 목록의 검색 입력`과 같고, 자리 표시 문구만 이 목록의 문구를 쓴다.

## 웹 선택 목록의 검색 결과 없음

검색어를 입력해 나타낼 웹 항목이 없어지면 목록 자리에 안내 문구를 표시한다. 안내의 구성, 배치, 전환은 [메모 태그 입력 컴포넌트 디자인](./memo-tag-input.md)의 `태그 선택 목록의 검색 결과 없음`과 같고, 문구만 이 목록의 문구를 쓴다. 표시하는 조건은 기준 스펙의 `웹 검색`을 따른다.

안내를 표시하는 동안에도 검색 입력과 웹 추가 버튼은 같은 자리에 그대로 두어 사용자가 검색어를 고치거나 웹 항목을 추가할 수 있게 한다.

## 웹 선택 목록의 웹 추가 버튼

목록 아래에 웹 추가 버튼을 둔다. 목록만 세로로 스크롤되고 웹 추가 버튼은 스크롤과 함께 움직이지 않으므로, 사용자는 목록을 어디까지 내렸든 같은 자리에서 버튼을 누를 수 있다.

웹 추가 버튼에는 추가를 나타내는 플러스 아이콘과 `웹 추가` 라벨을 표시하고, 대화상자의 가로 폭을 모두 사용하는 텍스트 버튼으로 배치한다. 버튼 자체의 여백만 두고 목록과 버튼 사이에 별도의 간격은 두지 않는다.

나타낼 웹 항목이 없어 목록 영역이 비어 있어도 웹 추가 버튼은 같은 자리에 그대로 표시한다. 목록이 짧아 스크롤이 없을 때도 버튼의 자리는 바뀌지 않는다.

웹 추가 버튼은 웹 입력의 웹 추가 칩과 이어지는 동작을 구분해야 하므로 칩과 다른 라벨을 쓴다. 칩은 `웹 선택`으로 선택 목록을 여는 동작을, 이 버튼은 `웹 추가`로 WebAdd 화면으로 이동하는 동작을 나타낸다. 이는 [메모 태그 입력 컴포넌트 디자인](./memo-tag-input.md)이 칩과 버튼의 라벨을 가르는 기준과 같다.

버튼을 누르면 목록을 닫고 WebAdd 화면으로 이동한다. 이동할 때 별도의 안내나 전환 표시를 두지 않는다. 버튼에는 버튼 역할과 웹 추가로 이어짐을 알리는 동작 접근성 이름을 제공한다.

## 웹 선택 목록의 준비 상태

아직 준비되지 않은 자리에는 [페이지 조회 목록의 자리 표시 디자인](./paged-list-placeholder.md)에 따라 자리 표시 항목을 둔다. 이 목록의 자리 표시 항목은 제목과 URL을 비워 두고, 체크 표시는 선택하지 않은 상태로 표시한다.

목록을 처음 불러오거나 다음 웹 항목을 이어서 불러오는 데 실패해도 별도의 오류 표시나 재시도 동작을 두지 않고 이미 나타난 항목을 그대로 표시한다.

검색어가 비어 있는데 나타낼 웹 항목이 없으면 목록 영역을 비워 두고 별도의 안내 문구를 두지 않는다. 검색어를 입력해 나타낼 웹 항목이 없어졌을 때의 표시는 `웹 선택 목록의 검색 결과 없음`을 따른다.

목록을 닫았다가 다시 열면 스크롤 위치를 이어받지 않고 목록의 맨 위에서 시작한다.

## 반영 표시

선택과 해제에는 진행 표시를 두지 않는다. 항목을 누르면 체크 표시가 곧바로 바뀌고, 반영된 결과는 칩 영역에 이어서 나타난다.

## 문구와 접근성

한국어 환경과 그 외 기본 환경에서 다음 문구를 사용한다.

| 항목 | 한국어 | 그 외 기본 |
| --- | --- | --- |
| 웹 추가 칩 라벨 | `웹 선택` | `Select web` |
| 웹 선택 동작 접근성 이름 | `웹 선택` | `Select web` |
| 웹 상세 이동 동작 접근성 이름 | `웹 상세 보기` | `Open web detail` |
| 웹 선택 목록 제목 | `웹 선택` | `Select Web` |
| 웹 선택 목록 웹 추가 버튼 라벨 | `웹 추가` | `Add web` |
| 웹 추가 동작 접근성 이름 | `웹 추가` | `Add web` |
| 웹 선택 목록 검색 입력 자리 표시 문구 | `웹 검색` | `Search webs` |
| 웹 선택 목록 검색 결과 없음 제목 문구 | `검색 결과가 없습니다` | `No search results` |
| 웹 선택 목록 검색 결과 없음 보조 문구 | `다른 검색어로 찾아보세요` | `Try a different search query.` |
