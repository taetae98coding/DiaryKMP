# 장소 검색 다이얼로그 디자인

기준 스펙: [장소 검색 다이얼로그 컴포넌트 스펙](../spec/client/place-search-dialog.md)

## 여는 컨트롤

다이얼로그를 여는 검색 버튼은 이 컴포넌트를 배치한 화면의 상단 바 끝 쪽 액션 자리에 아이콘 버튼으로 둔다. 아이콘은 돋보기 모양의 검색 아이콘을 쓴다.

배치한 화면에 지도가 표시되지 않는 동안에는 검색 버튼을 자리까지 함께 감춘다. 비활성 상태로 남기지 않는 것은 사용자가 누를 수 없는 이유를 화면에서 알 수 없기 때문이다.

각 화면에서의 자리와 다른 액션과의 순서는 [PlaceAdd 화면 디자인](./place-add.md)과 [PlaceDetail 화면 디자인](./place-detail.md)이 정한다.

## 구성과 배치

다이얼로그는 위에서 아래로 지도 영역, 결과 목록 영역, 검색어 입력 영역을 둔다. 세 영역은 서로 겹치지 않으며 사이에 구분선을 두지 않는다.

지도 영역은 다이얼로그 내용 높이의 `50%`를 차지하고 좌우 가장자리까지 채운다. 검색어 입력 영역은 입력 컴포넌트의 높이에 위아래 [화면 세로 여백](./dimens.md)을 더한 만큼을 차지하고, 결과 목록 영역이 남은 높이를 모두 채운다.

검색어 입력을 맨 아래에 두는 것은 한 손으로 드는 기기에서 입력과 소프트 키보드가 붙어 있게 하고, 입력한 검색어와 그 결과가 위아래로 이웃하게 두기 위한 것이다.

다이얼로그는 사용자가 다이얼로그 바깥을 누르거나 뒤로가기로 닫을 수 있다. 닫기 버튼과 확인 버튼은 두지 않는다. 장소를 고르는 것이 곧 확인이므로 별도의 확인 단계를 두지 않는다.

## 크기

다이얼로그의 너비는 대화상자 컴포넌트의 기본값을 따르고, 화면 크기에 따라 별도의 너비를 지정하지 않는다. 높이는 표시할 수 있는 높이를 모두 사용한다. 지도 영역이 다이얼로그 높이의 절반을 차지하므로, 높이를 내용에 맞춰 줄이면 지도와 목록이 함께 쓸 수 있는 높이를 확보하지 못한다.

세 영역의 위아래 순서와 지도 영역의 높이 비율은 창 크기와 관계없이 같다.

## 지도 영역

지도와 지도 제공자 전환 컨트롤의 구성, 지도 조작과 지도 컨트롤은 [DiaryMap 컴포넌트 디자인](./diary-map.md)을 따른다. 전환 컨트롤의 배치는 환경별 기본 구성을 그대로 쓴다.

지도 영역은 지점 선택을 사용하지 않으므로 지점 표시를 두지 않고, 지도를 눌러도 아무 일도 일어나지 않는다.

찾은 장소는 모두 핀으로 표시한다. 핀의 라벨은 그 장소의 이름이고 색은 모든 핀이 같은 색으로, 앱 테마의 기본 강조 색을 쓴다. 결과 사이에 순위나 선택 여부를 색으로 구분하지 않는다.

핀의 마커와 라벨 표현, 누를 수 있는 자리와 누르는 동안의 표현은 [DiaryMap 컴포넌트 디자인](./diary-map.md)의 `핀 표시`와 `핀 선택`을 따른다.

결과가 바뀌어 핀이 갱신되어도 지도를 결과 쪽으로 옮기지 않는다. 사용자가 검색 범위로 맞춰 둔 지도가 결과 때문에 움직이지 않게 하기 위한 것이다.

## 결과 목록

결과는 세로 목록으로 표시하고 목록 전체 높이가 영역보다 크면 세로로 스크롤할 수 있게 한다. 목록의 좌우에는 [화면 가로 여백](./dimens.md), 첫 항목 위와 마지막 항목 아래에는 [화면 세로 여백](./dimens.md)을 두고, 이 여백은 항목과 함께 스크롤된다. 항목 사이에는 [항목 간격](./dimens.md)을 둔다.

각 항목에는 장소 이름을 위에, 주소를 그 아래 작은 글씨로 둔다. 이름과 주소는 각각 한 줄로 표시하고 넘치면 끝을 줄임표로 줄인다. 주소가 없는 결과에서는 주소 줄의 자리를 남기지 않고 이름만 한 줄로 표시한다.

항목 전체를 누를 수 있는 자리로 두고 버튼 역할을 제공한다. 누르는 동안의 표현은 목록 항목의 기본 눌림 표현을 그대로 쓴다. 항목은 둘레에 `8dp` 안쪽 여백을 두고, 눌림 표현이 드러나는 자리는 모서리를 `12dp` 둥글게 깎는다.

어떤 항목이 골라져 있는 상태는 목록에 남기지 않는다. 항목을 누르면 다이얼로그가 곧바로 닫히므로 선택 표시가 사용자에게 보일 자리가 없다.

결과가 바뀌어 항목이 들어오거나 빠질 때는 자리 이동에 애니메이션을 적용하지 않고 바로 교체한다. 지도를 옮기는 동안 결과가 여러 번 바뀌므로 목록이 계속 움직이지 않게 하기 위한 것이다.

## 결과 목록의 상태 표현

| 상태 | 결과 목록 영역의 표시 |
| --- | --- |
| 검색어가 비어 있음 | 아무것도 표시하지 않고 영역을 비워 둠 |
| 검색 중 | 직전 상태의 표시를 그대로 둠 |
| 제공자를 바꿔 검색 중 | 아무것도 표시하지 않고 영역을 비워 둠 |
| 결과 있음 | 결과 항목 목록 |
| 결과 없음 | 가운데 정렬한 안내 문구 |
| 검색 실패 | 가운데 정렬한 안내 문구 |

검색 중에는 진행 표시를 두지 않는다. 검색어 입력의 지우기 버튼도 검색 중에 모양이 바뀌지 않는다. 지도를 옮길 때마다 진행 표시가 나타났다 사라지면 화면이 계속 깜빡이기 때문이다.

결과 없음과 검색 실패 안내는 같은 자리에 같은 크기로 표시하고 문구만 다르게 둔다. 실패 안내에는 다시 시도하는 버튼을 두지 않으며, 사용자가 검색어를 고치거나 지도를 옮기면 다시 검색된다.

## 검색어 입력

검색어 입력은 단일 줄 텍스트 입력으로, 좌우에 [화면 가로 여백](./dimens.md), 위아래에 [화면 세로 여백](./dimens.md)을 두고 남은 좌우 폭을 모두 사용한다. 입력의 시작 쪽에는 검색 아이콘을 두고, 입력한 값이 있으면 끝 쪽에 내용을 한 번에 지우는 지우기 버튼을 표시한다. 지우기 버튼이 나타나고 사라지는 표현은 [나타나고 사라지는 버튼 디자인](./button-visibility.md)을 따른다.

입력이 비어 있으면 무엇을 입력하는 자리인지 알리는 안내 문구를 자리 표시 문구로 둔다. 입력 위에 별도의 라벨은 두지 않는다.

소프트 키보드는 일반 텍스트 키보드를 요청하고, 키보드의 동작 키는 검색으로 표시한다. 동작 키를 눌러도 이미 실행된 검색을 다시 실행하지 않고 소프트 키보드만 닫는다. 검색은 입력을 멈추면 스스로 실행되므로 사용자가 동작 키로 검색을 시작할 필요가 없다.

## 초점과 표시 영역

초점을 어느 입력에 두고 언제 옮기는지는 기준 스펙이 정한다. 검색어 입력에 초점이 옮겨 갈 때는 소프트 키보드를 함께 연다.

소프트 키보드가 열리면 다이얼로그 전체를 키보드 위 영역에 맞춰 배치한다. 줄어든 높이에서도 지도 영역은 내용 높이의 `50%`를 유지하고 결과 목록 영역이 남은 높이를 채운다. 키보드가 닫히면 원래 크기로 되돌린다.

다이얼로그는 상태 표시 영역, 시스템 탐색 영역과 카메라 컷아웃 등 기기가 가리는 영역을 침범하지 않게 배치한다.

물리 키보드 환경에서는 `Esc`로 다이얼로그를 닫을 수 있다.

## 문구와 접근성

한국어 환경과 그 외 기본 환경에서 다음 문구를 사용한다.

| 문구 | 한국어 | 그 외 기본 |
| --- | --- | --- |
| 검색 버튼 접근성 이름 | `장소 검색` | `Search place` |
| 다이얼로그 접근성 이름 | `장소 검색` | `Search place` |
| 검색어 입력 자리 표시 문구 | `장소를 검색하세요` | `Search for a place` |
| 검색어 입력 접근성 이름 | `검색어` | `Search query` |
| 지우기 버튼 접근성 이름 | `검색어 지우기` | `Clear search query` |
| 지도 영역 접근성 이름 | `장소 검색 지도` | `Place search map` |
| 결과 없음 안내 | `검색 결과가 없습니다` | `No search results` |
| 검색 실패 안내 | `장소를 검색하지 못했습니다` | `Couldn't search for places` |

결과 항목의 접근성 이름은 장소 이름과 주소를 이어 읽히게 두고, 주소가 없으면 이름만 읽히게 한다.

지도 위 핀의 접근성 이름과 지도 제공자 전환 컨트롤의 문구와 접근성 이름은 [DiaryMap 컴포넌트 디자인](./diary-map.md)을 따른다.
