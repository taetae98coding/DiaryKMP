# Chrome 로그인 이어받기 디자인

기준 스펙: [Chrome 로그인 이어받기 스펙](../spec/client/chrome-session-import.md)

## 가져오기 실패 안내

[Chrome 로그인 이어받기 스펙](../spec/client/chrome-session-import.md)의 `가져오기 실패`에 따라 가져오기가 실패로 끝나면 앱 창 아래 가운데에 스낵바를 한 번 표시한다. 스낵바는 어느 화면을 보고 있든 화면마다 두는 스낵바와 따로 앱 창 전체를 기준으로 두며, 시스템 바, 디스플레이 컷아웃과 겹치지 않는 자리에 표시한다.

스낵바에는 안내 문구만 두고 동작 버튼과 닫기 버튼은 두지 않는다. 표시 시간은 플랫폼 기본의 짧은 시간을 따른다. 안내가 이미 표시되어 있는 동안 다시 실패하면 앞선 안내를 닫고 새 안내를 표시한다.
