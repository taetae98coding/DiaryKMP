# 메모 Gemini 작성 도우미 테스트 케이스

기준 스펙: [메모 Gemini 작성 도우미 스펙](../spec/client/memo-gemini.md)

MemoAdd 화면과 MemoDetail 화면이 같은 도우미를 제공하므로 이 문서의 케이스는 두 화면 모두에 적용된다. 반영한 내용으로 메모를 추가하거나 수정하는 케이스는 [MemoAdd 테스트 케이스](./memo-add.md)와 [MemoDetail 테스트 케이스](./memo-detail.md)에서 다룬다. Gemini 설정의 저장과 조회는 [SettingGemini 테스트 케이스](./setting-gemini.md)에서 다룬다.

## feature

### TC-25d935e9-1872-457d-9d58-087d86704c99: 설정이 갖춰져 있으면 프롬프트 입력으로 시작한다

- 근거: `feature > 도우미 시작`
- Given: 저장된 Gemini 설정의 인증 정보와 모델에 값이 있다.
- When: 사용자가 작성 도우미를 시작한다.
- Then: 도우미가 열리고 프롬프트를 입력할 수 있는 상태로 표시되며, 프롬프트는 비어 있다.

### TC-8367fbb2-b2e0-4ab9-9443-bd9c1476b591: 설정이 갖춰지지 않으면 열지 않고 설정 필요를 알린다

- 근거: `feature > 도우미 시작`
- Given: 저장된 Gemini 설정이 테스트 데이터의 상태다.
- When: 사용자가 작성 도우미를 시작한다.
- Then: 도우미가 열리지 않고 Gemini 설정이 필요하다는 안내가 표시되며, 생성 요청이 외부 경계로 나가지 않는다.
- 테스트 데이터:

| 인증 정보 | 모델 |
| --- | --- |
| 비어 있음 | 값 있음 |
| 값 있음 | 비어 있음 |
| 비어 있음 | 비어 있음 |

- 근거: `feature > 도우미 시작`

- Then: 작성 도우미를 시작할 수 없고, 별도 로딩 또는 오류 상태도 제공되지 않는다.

- Then: 생성 요청이 외부 경계로 나가고 프롬프트 입력이 필요하다는 안내는 표시되지 않는다.

### TC-43233fcb-7378-457d-af25-6c044c85e6e4: 공백뿐인 제목과 설명, 사용하지 않는 기간은 보내지 않는다

### TC-595415f5-298e-44d1-9faa-3ba4aeec9698: 프롬프트와 생성 요청·결과를 기기와 서버에 저장하지 않는다

- 근거: `data > 저장하지 않는 것`

### TC-b7074a82-cb69-40e1-b3b7-9356179bac2e: 생성은 동기화 대상이 아니다

- 근거: `data > 저장하지 않는 것`
