# 설명 입력 컴포넌트 테스트 케이스

기준 스펙: [설명 입력 컴포넌트 스펙](../spec/client/description-input.md)

## feature

### TC-DESCRIPTION-INPUT-FEATURE-001: 채워진 설명이 없으면 처음 표시될 때 설명을 입력할 수 있다

- 근거: `feature > 설명 입력`
- Given: 채워진 설명이 없는 설명 입력 컴포넌트가 포함된 화면이 있다.
- When: 화면이 처음 표시된다.
- Then: 설명을 입력할 수 있는 상태로 표시된다.

### TC-DESCRIPTION-INPUT-FEATURE-002: 설명 입력에서 마크다운 미리보기로 전환한다

- 근거: `feature > 마크다운 미리보기`
- Given: 설명 입력 상태에 `미리보기 내용`이 입력되어 있다.
- When: 사용자가 마크다운 미리보기로 전환한다.
- Then: 마크다운 미리보기 상태로 전환된다.

### TC-DESCRIPTION-INPUT-FEATURE-003: 미리보기에서 설명 입력으로 돌아간다

- 근거: `feature > 마크다운 미리보기`
- Given: 마크다운 미리보기가 표시되어 있다.
- When: 사용자가 설명 입력으로 돌아간다.
- Then: 같은 설명을 입력하고 수정할 수 있는 상태가 표시된다.

### TC-DESCRIPTION-INPUT-FEATURE-005: 여러 줄의 설명을 입력할 수 있다

- 근거: `feature > 설명 입력`
- Given: 설명을 입력할 수 있는 상태가 표시되어 있다.
- When: 사용자가 여러 줄로 이루어진 설명을 입력한다.
- Then: 입력한 여러 줄의 내용이 그대로 표시된다.

### TC-DESCRIPTION-INPUT-FEATURE-007: 설명 전체를 지운다

- 근거: `feature > 설명 입력`
- Given: 설명 내용이 입력되어 있다.
- When: 사용자가 설명 전체 지우기를 선택한다.
- Then: 입력했던 설명 내용이 모두 지워진다.

### TC-DESCRIPTION-INPUT-FEATURE-009: 미리보기 페이지에 마크다운 해석 결과가 표시된다

- 근거: `feature > 마크다운 미리보기`
- Given: 설명 입력 상태에 `**강조**`가 입력되어 있다.
- When: 사용자가 마크다운 미리보기를 선택한다.
- Then: `강조`가 굵은 내용으로 표시되고 `**` 문법 기호는 표시되지 않는다.

### TC-DESCRIPTION-INPUT-FEATURE-010: 수정한 내용이 미리보기에 반영된다

- 근거: `feature > 마크다운 미리보기`
- Given: 미리보기를 본 뒤 설명 입력으로 돌아와 내용을 수정했다.
- When: 사용자가 다시 마크다운 미리보기를 선택한다.
- Then: 수정된 내용이 해석된 결과가 표시된다.

### TC-DESCRIPTION-INPUT-FEATURE-011: 입력한 내용이 없으면 미리보기 페이지는 빈 상태다

- 근거: `feature > 마크다운 미리보기`
- Given: 설명을 아무것도 입력하지 않았다.
- When: 사용자가 마크다운 미리보기를 선택한다.
- Then: 해석된 내용이 표시되지 않는다.

### TC-DESCRIPTION-INPUT-FEATURE-012: 화면 재생성 후에도 입력 내용과 보고 있던 페이지가 유지된다

- 근거: `domain > 진행 상태 유지`
- Given: 사용자가 설명을 입력한 뒤 마크다운 미리보기를 보고 있다.
- When: 시스템에 의해 화면이 재생성된다.
- Then: 마크다운 미리보기가 그대로 표시되고, 설명 입력으로 돌아가면 입력 중이던 내용이 유지되어 있다.

### TC-DESCRIPTION-INPUT-FEATURE-017: 엔터로 나눈 줄이 미리보기에서도 나뉘어 표시된다

- 근거: `domain > 줄바꿈 해석`
- Given: 설명 입력 상태에 `첫 줄`과 `둘째 줄`이 엔터 한 번으로 나뉘어 입력되어 있다.
- When: 사용자가 마크다운 미리보기를 선택한다.
- Then: `첫 줄`과 `둘째 줄`이 한 줄로 합쳐지지 않고 서로 다른 줄에 표시된다.

### TC-DESCRIPTION-INPUT-FEATURE-018: 빈 줄로 나눈 내용은 문단으로 구분되어 표시된다

- 근거: `domain > 줄바꿈 해석`
- Given: 설명 입력 상태에 `첫 문단`과 `둘째 문단`이 빈 줄로 나뉘어 입력되어 있다.
- When: 사용자가 마크다운 미리보기를 선택한다.
- Then: `첫 문단`과 `둘째 문단`이 서로 다른 문단으로 구분되어 표시된다.

### TC-DESCRIPTION-INPUT-FEATURE-019: 코드 블록 내부의 줄바꿈은 입력한 그대로 표시된다

- 근거: `domain > 줄바꿈 해석`
- Given: 설명 입력 상태에 코드 블록 기호(```)로 감싼 `코드 첫 줄`과 `코드 둘째 줄`이 엔터 한 번으로 나뉘어 입력되어 있다.
- When: 사용자가 마크다운 미리보기를 선택한다.
- Then: 코드 블록 안에서 `코드 첫 줄`과 `코드 둘째 줄`이 입력한 줄 그대로 나뉘어 표시된다.

### TC-DESCRIPTION-INPUT-FEATURE-020: 채워진 설명이 있으면 처음 표시될 때 마크다운 미리보기가 보인다

- 근거: `feature > 마크다운 미리보기`
- Given: `# 채워진 설명`이 채워진 설명 입력 컴포넌트가 포함된 화면이 있다.
- When: 화면이 처음 표시된다.
- Then: `채워진 설명`이 해석된 마크다운 미리보기 상태로 표시되고 `#` 문법 기호는 표시되지 않는다.

### TC-DESCRIPTION-INPUT-FEATURE-021: 채워진 설명이 공백뿐이면 처음 표시될 때 설명을 입력할 수 있다

- 근거: `domain > 첫 표시 상태`
- Given: 공백 문자로만 이루어진 설명이 채워진 설명 입력 컴포넌트가 포함된 화면이 있다.
- When: 화면이 처음 표시된다.
- Then: 마크다운 미리보기가 아닌 설명을 입력할 수 있는 상태로 표시된다.

### TC-DESCRIPTION-INPUT-FEATURE-022: 처음 표시된 뒤에는 설명 내용이 바뀌어도 보고 있는 상태가 바뀌지 않는다

- 근거: `domain > 첫 표시 상태`
- Given: 채워진 설명이 없어 설명 입력 상태로 표시되어 있다.
- When: 사용자가 설명을 입력한다.
- Then: 마크다운 미리보기로 바뀌지 않고 설명 입력 상태가 그대로 유지된다.

### TC-DESCRIPTION-INPUT-FEATURE-023: 다른 설명으로 새로 채우면 시작 상태를 다시 정한다

- 근거: `domain > 첫 표시 상태`
- Given: 채워진 설명이 없어 설명 입력 상태로 표시되어 있다.
- When: 화면이 컴포넌트를 `새로 채운 설명`으로 새로 채운다.
- Then: `새로 채운 설명`이 해석된 마크다운 미리보기 상태로 표시된다.

### TC-DESCRIPTION-INPUT-FEATURE-024: 화면이 재생성되어도 시작 상태를 다시 정하지 않는다

- 근거: `domain > 진행 상태 유지`
- Given: `# 채워진 설명`이 채워져 마크다운 미리보기로 처음 표시된 뒤, 사용자가 설명 입력으로 옮겼다.
- When: 시스템에 의해 화면이 재생성된다.
- Then: 마크다운 미리보기로 돌아가지 않고 `# 채워진 설명`이 담긴 설명 입력 상태가 그대로 표시된다.
