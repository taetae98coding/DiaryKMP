# RoutineFinishedList 화면 테스트 케이스

기준 스펙: [RoutineFinishedList 화면 스펙](../spec/client/routine-finished-list.md)

이 문서에서 `domain > 노출 기준`, `domain > 대상 항목`, `feature > 빈 상태`, `feature > 상세 확인`, `feature > 추가 미제공`, `feature > 다시 시작과 삭제` 절은 [완료 목록 공통 스펙](../spec/client/finished-list.md)이 소유한다. 나머지 케이스의 절은 기준 스펙이 소유한다.

자리 표시 케이스의 `근거`가 가리키는 절은 공통 규칙을 [페이지 조회 목록의 자리 표시 스펙](../spec/client/paged-list-placeholder.md)에, 빈 상태 케이스의 `근거`가 가리키는 절은 [목록 빈 상태 스펙](../spec/client/list-empty-state.md)에 위임한다. 다시 시작·삭제의 안내와 실행 취소 케이스의 `근거`가 가리키는 절은 공통 규칙을 [SwipeToFinishAndDelete 컴포넌트 스펙](../spec/client/swipe-to-finish-and-delete.md)의 `안내와 실행 취소`에 위임하며, 카드를 미는 상호작용 자체의 케이스는 [SwipeToFinishAndDelete 테스트 케이스](./swipe-to-finish-and-delete.md)에서 다룬다.

당겨서 새로고침과 진행 표시는 [새로고침 테스트 케이스](./sync-refresh.md)가, 카드 문구의 계산은 [루틴 테스트 케이스](./routine.md)가, 삭제한 루틴의 기록이 달력에 보이지 않는 결과는 [캘린더 루틴 기록 표시 테스트 케이스](./calendar-routine.md)가, 루틴 상세를 목록과 함께 표시하는 배치와 그 뒤로가기는 [RoutineFinishedList 목록·상세 배치 테스트 케이스](./routine-finished-list-detail.md)가 다룬다.

안내와 실행 취소 동작의 문구는 [RoutineFinishedList 화면 디자인](../design/routine-finished-list.md)이 정한 문구를 기대 결과로 쓴다.

## feature

### TC-0aa087e9-d89b-45d2-9389-415f9cf0f59e: 완료되고 삭제되지 않은 루틴만 목록에 표시한다

- 근거: `feature > 목록 표시`, `domain > 노출 기준`
- Given: 현재 계정에 완료·미삭제 루틴, 미완료·미삭제 루틴, 완료·삭제 루틴, 미완료·삭제 루틴이 함께 저장되어 있다.
- When: 사용자가 RoutineFinishedList 화면을 연다.
- Then: 완료되고 삭제되지 않은 루틴만 표시된다.

  | 루틴 | 시작 날짜 | 목표량 | 오늘 기록 |
  | --- | --- | --- | --- |
  | 진행 중이고 목표량이 있는 루틴 | 2026-07-01 | 2000 | 1500 |
  | 진행 중이고 목표량이 없는 루틴 | 2026-07-01 | 없음 | 3 |
