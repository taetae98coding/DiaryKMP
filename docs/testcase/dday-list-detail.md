# DDay 목록·상세 배치 테스트 케이스

기준 스펙: [DDay 목록·상세 배치 스펙](../spec/client/dday-list-detail.md)

이 문서에서 `domain > 배치에 참여하는 화면`, `feature > 추가 진입 수단`, `feature > 함께 사용과 단독 사용`, `feature > 함께 사용할 때의 행동` 절은 [목록·상세 배치 공통 스펙](../spec/client/list-detail-pane.md)이 소유한다. 나머지 케이스의 절은 기준 스펙이 소유한다.

표시 비율 조절의 공통 행동과 유지 기준은 [목록·상세 배치 공통 스펙](../spec/client/list-detail-pane.md)에 위임되어 있다. 시스템이 앱을 정리했다가 다시 만든 뒤 상세 선택과 뒤로가기 기록을 복원하는 결과는 [테스트 케이스 문서 목록](./README.md)에 따라 [Memo 목록·상세 배치 테스트 케이스](./memo-list-detail.md)가 대표로 확인한다. 한 화면만 사용하는 환경에서 디데이 목록에서 추가나 상세로 이동하는 케이스는 [DDayHome 테스트 케이스](./dday-home.md)에서, 상세 영역에서 디데이를 작성해 추가하는 케이스는 [DDayAdd 테스트 케이스](./dday-add.md)에서, 상세 영역에서 디데이를 확인하고 수정하고 삭제하는 케이스는 [DDayDetail 테스트 케이스](./dday-detail.md)에서 다룬다.
