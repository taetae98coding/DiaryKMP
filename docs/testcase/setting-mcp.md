# SettingMcp 테스트 케이스

기준 스펙: [SettingMcp 화면 스펙](../spec/client/setting-mcp.md)

설정 화면 본문에서 `MCP` 항목을 선택해 SettingMcp로 이동하는 케이스는 [SettingHome 테스트 케이스](./setting-home.md)에서 다룬다. 연결이 실제로 시작되고 끝나는 결과는 [AI 도구 연결 테스트 케이스](./mcp-server.md)에서 다룬다.

고르면 바로 저장하는 설정의 행동, 저장된 값을 확인하기 전의 상태, 뒤로가기, 저장 시점과 기기별 보관은 [기기 설정 화면 공통 스펙](../spec/client/device-setting.md)에 위임되어 있으며, 이 문서의 케이스는 SettingMcp에서 관찰하는 결과를 기준으로 한다.

## feature

### TC-30ea3b2b-ac06-4fc0-a7b3-9f87fa6aecf0: 저장된 연결 사용 설정을 표시한다

- 근거: `feature > 연결 켜고 끄기`, `domain > 연결 사용 설정`
- Given: 연결 사용 설정이 테스트 데이터의 값으로 저장되어 있다.
- When: 사용자가 SettingMcp 화면 본문을 확인한다.
- Then: 연결 사용이 테스트 데이터의 표시 상태로 보인다.
- 테스트 데이터:

| 저장된 값 | 표시 상태 |
| --- | --- |
| 한 번도 바꾸지 않음 | 꺼짐 |
| 꺼짐 | 꺼짐 |
| 켬 | 켜짐 |

### TC-89b9a0f5-4c46-412e-b067-1fd08f8dd10c: 연결을 켜거나 끄면 바로 저장한다

- 근거: `feature > 연결 켜고 끄기`, `data > 저장 시점과 유지`
- Given: 연결 사용 설정이 테스트 데이터의 현재 값으로 저장되어 있다.
- When: 사용자가 연결 사용을 바꾼다.
- Then: 연결 사용 설정이 테스트 데이터의 저장 결과로 저장된다.
- 테스트 데이터:

| 현재 값 | 저장 결과 |
| --- | --- |
| 꺼짐 | 켬 |
| 켬 | 꺼짐 |

### TC-24a81b58-1da7-46d0-b69b-a32b19d06e94: 저장에 실패하면 이전 상태를 유지한다

- 근거: `feature > 연결 켜고 끄기`
- Given: 연결 사용 설정이 꺼짐으로 저장되어 있고, 설정 저장이 실패하도록 응답이 정해져 있다.
- When: 사용자가 연결 사용을 켠다.
- Then: 연결 사용은 꺼짐으로 표시되고 별도 오류 상태로 바뀌지 않는다.

### TC-babc55c7-b2bc-4c88-a5b6-7752ff29f25d: 저장된 설정을 확인하기 전에는 켜고 끄는 기능과 연결 상태를 제공하지 않는다

- 근거: `feature > 연결 켜고 끄기`
- Given: 저장된 연결 사용 설정을 아직 확인하지 못했거나 읽지 못했다.
- When: 사용자가 SettingMcp 화면 본문을 확인한다.
- Then: 연결 사용과 연결 상태는 제공되지 않고, AI 도구가 할 수 있는 일을 알리는 안내는 표시된다.

### TC-09ab3adb-4b9b-45c4-ad6c-6c1d35a64473: 연결 상태에 맞는 안내를 표시한다

- 근거: `feature > 연결 상태 확인`
- Given: 연결 사용 설정이 확인되었고 연결이 테스트 데이터의 상태다.
- When: 사용자가 연결 상태를 확인한다.
- Then: 테스트 데이터의 표시가 보인다.
- 테스트 데이터:

| 연결 상태 | 표시 |
| --- | --- |
| 꺼짐 | 꺼져 있다는 안내, 주소 없음 |
| 동작 중 | 동작 중이라는 안내와 연결 주소 |
| 시작 실패, 주소를 다른 프로그램이 씀 | 주소를 다른 프로그램이 써서 시작하지 못했다는 안내와 연결 주소 |
| 시작 실패, 그 밖의 이유 | 연결을 시작하지 못했다는 안내, 주소 없음 |

### TC-78bc132a-5ecc-4a32-80a3-c4433b22fd2d: 연결 상태가 바뀌면 새로고침 없이 바뀐 상태를 보여 준다

- 근거: `feature > 연결 상태 확인`
- Given: 연결이 꺼짐 상태로 SettingMcp 화면이 표시되어 있다.
- When: 연결이 동작 중 상태로 바뀐다.
- Then: 화면은 사용자 조작 없이 동작 중 안내와 연결 주소를 보여 준다.

### TC-96afd6dd-77e2-4fe8-8ded-56b705adb68d: 동작 중일 때 주소를 복사한다

- 근거: `feature > 주소 복사`
- Given: 연결이 동작 중이다.
- When: 사용자가 주소 복사를 실행한다.
- Then: 연결 주소가 복사되고 복사되었다는 안내가 한 번 표시된다.

### TC-229a7f57-7608-45fe-92ee-7d8958cb7bc2: 동작 중이 아니면 주소를 복사할 수 없다

- 근거: `feature > 주소 복사`
- Given: 연결이 꺼짐, 주소를 다른 프로그램이 써서 시작 실패, 그 밖의 이유로 시작 실패 중 하나다.
- When: 사용자가 연결 상태를 확인한다.
- Then: 주소 복사를 실행할 수 없다.

### TC-b6f6c100-f235-4fe7-9e1a-646fd628695e: 뒤로가면 이전 화면으로 돌아가고 설정은 바뀌지 않는다

- 근거: `feature > 뒤로가기`
- Given: SettingMcp 화면이 단독으로 표시되어 있다.
- When: 사용자가 뒤로간다.
- Then: 이전 화면으로 돌아가기가 한 번 요청되고 연결 사용 설정은 바뀌지 않는다.
- 작성하지 않는 이유: 설정 목록으로 돌아가는 화면 전환은 설정 목록과 세부 화면을 함께 구성해야 관찰할 수 있어 [Setting 목록·상세 배치 테스트 케이스](./setting-list-detail.md)가 다룬다. 뒤로가면 이전 화면으로 돌아가기를 한 번 요청하는 것은 자동화한다.
