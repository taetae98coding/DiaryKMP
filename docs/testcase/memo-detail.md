# MemoDetail 테스트 케이스

기준 스펙: [MemoDetail 화면 스펙](../spec/client/memo-detail.md)

이 문서에서 `feature > 진입할 때의 입력 초점`, `feature > 내용 수정`, `data > 저장 실패` 절은 [항목 상세 화면 공통 스펙](../spec/client/entity-detail.md)이 소유한다. 나머지 케이스의 절은 기준 스펙이 소유한다.

태그 입력의 공통 표시와 조작, 태그 관련 문구의 케이스는 [메모 태그 입력 컴포넌트 테스트 케이스](./memo-tag-input.md)에서, 웹 입력의 공통 표시와 조작, 웹 관련 문구의 케이스는 [메모 웹 입력 컴포넌트 테스트 케이스](./memo-web-input.md)에서, 연락처 입력의 공통 표시와 조작, 연락처 관련 문구의 케이스는 [메모 연락처 입력 컴포넌트 테스트 케이스](./memo-contact-input.md)에서, 장소 카드의 표시와 조작, 장소 관련 문구의 케이스는 [메모 장소 카드 컴포넌트 테스트 케이스](./memo-place-card.md)에서 다룬다. 이 문서에는 MemoDetail 화면에서 태그 조작과 웹 조작과 연락처 조작이 저장된 메모에 반영되는 케이스와, MemoDetail 화면에서만 다른 태그 입력·웹 입력·연락처 입력의 표시 기준 케이스를 둔다.

## feature

### TC-e56b13c0-7157-4641-b74c-7a4b0b62ab4a: 첫진입 시 조회한 메모의 제목, 설명, 컬러가 채워진다

- 근거: `feature > 첫진입 시 내용 표시`
- Given: 선택한 메모의 제목, 설명, 컬러를 조회할 수 있도록 설정되어 있다.
- When: 사용자가 해당 메모의 MemoDetail 화면에 진입한다.
- Then: 로딩 상태가 끝나고, 화면 제목과 제목 입력 칸에 조회한 제목이, 설명 입력에 조회한 설명이, 컬러 입력에 조회한 컬러가 표시된다.

### TC-90dde206-ef20-4230-b636-ebd7aa0e0a71: 화면 상단의 제목은 폭을 넘어도 한 줄에 생략 없이 담긴다

- 근거: `feature > 첫진입 시 내용 표시`
- Given: 화면 상단에서 표시할 수 있는 폭보다 긴 제목의 메모를 조회할 수 있도록 설정되어 있다.
- When: 사용자가 그 메모의 MemoDetail 화면에 진입해 화면 상단의 제목을 확인한다.
- Then: 제목이 여러 줄로 나뉘지 않고 한 줄에 표시되며, 뒷부분이 생략되지 않은 전체 제목이 담긴다.

### TC-ff8dab46-0293-4e89-808f-9fe9bb053df8: 화면 상단의 제목이 폭을 넘으면 가로로 반복해서 이동한다

- 근거: `feature > 첫진입 시 내용 표시`
- Given: 화면 상단에서 표시할 수 있는 폭보다 긴 제목의 메모로 MemoDetail 화면이 표시되어 있다.
- When: 사용자가 화면 상단의 제목을 확인한다.
- Then: 전체 제목을 확인할 수 있도록 제목이 가로로 반복해서 이동한다.
- 작성하지 않는 이유: 가로 이동은 그려지는 위치만 바뀌는 애니메이션이라 화면의 공개된 상태로 드러나지 않고, 여러 시점의 화면 프레임을 비교해야 판정할 수 있다. 한 줄에 전체 제목이 담기는 것은 TC-90dde206-ef20-4230-b636-ebd7aa0e0a71이 확인한다. 표시 폭을 제어하고 여러 시점의 화면 프레임을 비교할 수 있는 시각 회귀 테스트 환경이 갖춰지면 자동화한다.
