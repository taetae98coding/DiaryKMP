# 파일 올리기 알림 테스트 케이스

기준 스펙: [파일 올리기 알림 스펙](../spec/client/file-upload-notification.md)

결과 알림 케이스의 `근거`가 가리키는 절은 실패 이유의 구분을 [파일 보관 스펙](../spec/client/file-storage.md)의 `올리기 상태`에 위임한다.

## feature

### TC-d37fcb12-71d8-44d7-acce-dfa929458de0: Android에서 올리는 동안 파일 이름과 진행을 보여 주는 알림을 표시한다

- 근거: `feature > 진행 알림`
- Given: Android에서 사용자 언어가 한국어이고 알림 권한이 허용되어 있으며, `보고서.pdf` 파일을 올리는 중이다.
- When: 서버에 보낸 양이 테스트 데이터와 같아진다.
- Then: 제목 `파일 올리는 중`, 본문 `보고서.pdf`인 진행 알림이 진행 중 알림으로 표시되고, 진행은 테스트 데이터와 같다.
- 테스트 데이터:

| 보낸 양 | 진행 |
| --- | --- |
| 아직 보내지 않음 | 백분율 없이 진행 중 |
| 전체의 40% | 40% |

### TC-5ac880b6-b3b1-4069-a145-c2997888d56f: FileHome 화면을 보고 있어도 진행 알림을 표시한다

- 근거: `feature > 진행 알림`
- Given: Android에서 알림 권한이 허용되어 있고 사용자가 FileHome 화면을 보고 있다.
- When: 파일 올리기가 시작된다.
- Then: 진행 알림이 표시된다.

### TC-56a76dfa-a79d-4d88-9179-af1e4bc9cb6d: 올리기가 끝나거나 중단되면 진행 알림이 사라진다

- 근거: `feature > 진행 알림`
- Given: Android에서 파일을 올리는 중이라 진행 알림이 표시되어 있다.
- When: 올리기가 테스트 데이터의 결과로 끝난다.
- Then: 진행 알림이 사라진다.
- 테스트 데이터:

| 결과 |
| --- |
| 성공 |
| 크기 초과로 실패 |
| 그 밖의 이유로 실패 |
| 계정이 바뀌어 중단 |

- 작성하지 않는 이유: 진행 알림은 올리는 동안 앱을 붙잡아 두는 운영체제의 전경 실행과 함께 표시되고, 올리기가 끝나면 운영체제가 그 실행을 끝내면서 알림을 거둔다. 저장소의 테스트 환경은 이 전경 실행을 시작하거나 끝내지 않아 진행 알림이 사라지는 순간을 관찰할 수 없다. 진행 알림의 내용은 TC-d37fcb12-71d8-44d7-acce-dfa929458de0이, 끝난 뒤의 결과 알림은 TC-f27003e1-5af1-458e-8752-01093aba51f6가 확인한다. 자동화하려면 실제 기기에서 알림 표시 영역을 조회할 수 있는 기기 테스트 환경이 필요하다.

### TC-f27003e1-5af1-458e-8752-01093aba51f6: 보고 있는 화면과 관계없이 올리기가 끝나면 결과 알림을 보낸다

- When: 올리기가 테스트 데이터의 결과로 끝난다.
- Then: 테스트 데이터의 제목과 본문을 가진 결과 알림이 표시된다.
- 테스트 데이터:

| 결과 | 제목 | 본문 |

| 성공 | `파일을 올렸습니다` | `보고서.pdf` |

| 그 밖의 이유로 실패 | `파일을 올리지 못했습니다` | `보고서.pdf` |

### TC-0cfddb99-8c07-4897-a998-4682648a3f46: 파일 화면이 아닌 화면을 보는 동안 올리기가 끝나면 알림만 보내고 화면은 바뀌지 않는다

- 근거: `feature > 앱을 사용하는 중에 받은 알림`
- Given: Android에서 알림 권한이 허용되어 있고, 사용자가 FileAdd 화면에서 파일 올리기를 시작한 뒤 FileHome을 거쳐 `더보기` 화면으로 돌아갔다.
- When: 올리기가 성공으로 끝난다.
- Then: 성공 결과 알림이 표시되고, 앱 화면 안에는 따로 안내가 표시되지 않으며 보고 있던 화면도 바뀌지 않는다.

### TC-94f603f9-56ab-42a8-85b9-856f9dad8a5a: 알림 권한이 없어도 올리기는 그대로 진행된다

- 근거: `domain > 알림 권한`
- Given: 알림 권한이 허용되어 있지 않다.
- When: 파일 하나로 올리기를 시작하고 서버가 성공을 돌려준다.
- Then: 알림은 사용자에게 보이지 않고, 올리기는 성공으로 끝난다.
- 작성하지 않는 이유: 알림이 사용자에게 보이는지는 운영체제가 권한 상태로 정하는 결과라 저장소의 테스트 환경에서 관찰할 수 없다. 올리기의 성공과 실패는 알림과 관계없이 [파일 보관 테스트 케이스](./file-storage.md)가 확인한다. 자동화하려면 알림 권한을 바꾸고 알림 표시 영역을 조회할 수 있는 기기 테스트 환경이 필요하다.
