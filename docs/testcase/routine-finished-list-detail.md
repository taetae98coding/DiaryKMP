# RoutineFinishedList 목록·상세 배치 테스트 케이스

기준 스펙: [RoutineFinishedList 목록·상세 배치 스펙](../spec/client/routine-finished-list-detail.md)

함께 사용과 단독 사용, 상세 선택과 교체, 뒤로가기, 표시 비율 조절과 유지·초기화의 공통 기준은 [목록·상세 배치 공통 스펙](../spec/client/list-detail-pane.md)에, 완료 목록 배치의 공통 기준은 같은 문서의 `완료 목록의 배치`에 위임된 규칙을 이 배치에 적용한 결과를 이 문서가 확인한다.

RoutineHome에서 진입한 루틴 상세와 루틴 추가의 배치 케이스는 [Routine 목록·상세 배치 테스트 케이스](./routine-list-detail.md)에서 다룬다. 상세 화면 하나에서 완료나 다시 시작 뒤 수정 중이던 내용이 유지되는 결과와 기록 넣기·빼기, 수정의 결과는 [RoutineDetail 테스트 케이스](./routine-detail.md)가 다루고, 이 문서는 그 결과가 목록과 상세 영역에 함께 나타나는 것을 다룬다. 시스템이 앱을 정리했다가 다시 만든 뒤 상세 선택과 뒤로가기 기록을 복원하는 결과는 [테스트 케이스 문서 목록](./README.md)에 따라 [Memo 목록·상세 배치 테스트 케이스](./memo-list-detail.md)가 대표로 확인한다.

선택 전 상세의 안내 문구는 [RoutineFinishedList 목록·상세 배치 디자인](../design/routine-finished-list-detail.md)이 정한 문구를 기대 결과로 쓴다.

## feature

- 근거: [목록·상세 배치 공통 스펙의 함께 사용과 단독 사용](../spec/client/list-detail-pane.md#함께-사용과-단독-사용), `domain > 배치에 참여하는 화면`

- When: 사용자가 RoutineHome의 목록 보기에서 완료된 루틴 확인을 선택한다.
- Then: 완료된 루틴 목록을 목록·상세 배치의 목록 영역에 표시해 상세 영역과 함께 쓸 수 있고, RoutineHome의 루틴 목록은 함께 표시되지 않는다.

### TC-13bc6f6c-6544-4310-9435-df87e9ba5d04: 상세 영역에서 루틴을 다시 시작하면 목록에서 사라지고 상세는 그대로 남는다

- 근거: `feature > 상세 영역의 구성`
- Given: 목록과 상세를 함께 사용하고 있고, 완료된 루틴 목록에서 고른 루틴의 상세가 상세 영역에 놓여 있으며 다시 시작이 성공하도록 설정되어 있다.

- Then: 그 루틴은 완료된 루틴 목록에서 사라지고, 상세 영역에는 같은 루틴의 상세가 남아 완료 동작을 제공한다.

### TC-f12c1f04-b713-4fd7-a7d3-9a2798bb1693: 다시 시작한 상세에서 다시 완료하면 그 루틴이 목록에 다시 나타난다

- Given: 목록과 상세를 함께 사용하고 있고, 상세 영역에서 다시 시작해 완료된 루틴 목록에서 사라진 루틴의 상세가 상세 영역에 그대로 놓여 있으며 완료가 성공하도록 설정되어 있다.
- When: 사용자가 상세 영역의 그 루틴을 완료한다.
- Then: 그 루틴이 완료된 루틴 목록에 카드 문구 `완료`로 다시 나타나고, 상세 영역에는 같은 루틴의 상세가 남아 다시 시작 동작을 제공한다.
