# TagDetail 메모 탭 테스트 케이스

기준 스펙: [TagDetail 메모 탭 스펙](../spec/client/tag-detail-memo.md)

자리 표시 케이스의 `근거`가 가리키는 절은 공통 규칙을 [페이지 조회 목록의 자리 표시 스펙](../spec/client/paged-list-placeholder.md)에, 빈 상태 케이스의 `근거`가 가리키는 절은 [목록 빈 상태 스펙](../spec/client/list-empty-state.md)에 위임한다.

웹 탭과 장소 탭의 케이스는 [TagDetail 웹 탭 테스트 케이스](./tag-detail-web.md)와 [TagDetail 장소 탭 테스트 케이스](./tag-detail-place.md)에서 다룬다.

## feature

### TC-TAG-DETAIL-MEMO-FEATURE-003: 기간 유무와 시작 날짜에 따라 메모를 나누어 표시한다

- 근거: `feature > 목록 표시`
- Given: 상세 대상 태그에 기간이 없는 메모와 같은 시작 날짜의 기간이 있는 메모들이 연결되어 있다.
- When: 사용자가 TagDetail 화면에서 메모 탭을 연다.
- Then: 기간이 없는 메모는 날짜 그룹 없이 먼저 표시되고, 기간이 있는 메모들은 시작 날짜가 같은 것끼리 한 그룹으로 표시된다.

### TC-TAG-DETAIL-MEMO-FEATURE-004: 자리 표시 상태의 메모는 선택하거나 완료·삭제할 수 없다

- 근거: `feature > 목록 표시`
- Given: 목록의 메모가 아직 준비되지 않아 자리 표시 상태로 제공되어 있다.
- When: 사용자가 해당 메모를 선택하거나 완료·삭제하려 한다.
- Then: 메모 상세 이동, 완료, 삭제가 요청되지 않는다.

### TC-TAG-DETAIL-MEMO-FEATURE-006: 목록 조회 실패에 별도의 오류나 재시도 동작을 표시하지 않는다

- 근거: `feature > 목록 표시`, `feature > 빈 상태`
- Given: 목록 조회가 테스트 데이터의 시점에 실패하도록 설정되어 있다.
- When: 사용자가 TagDetail 화면의 메모 탭을 확인한다.
- Then: 별도 오류 안내나 재시도 동작 없이 테스트 데이터의 표시 결과가 된다.
- 테스트 데이터:

| 실패 시점 | 표시 결과 |
| --- | --- |
| 최초 조회 | 목록이 준비된 것으로 다뤄져 메모 카드 대신 빈 상태 안내가 표시된다. 안내 내용은 `TC-TAG-DETAIL-MEMO-FEATURE-021`과 같다 |
| 추가 조회 | 이미 표시된 메모가 그대로 남는다 |

### TC-TAG-DETAIL-MEMO-FEATURE-007: 메모를 선택하면 그 메모의 상세로 이동한다

- 근거: `feature > 메모 상세 확인`
- Given: 상세 대상 태그에 연결된 메모가 표시되어 있다.
- When: 사용자가 그 메모를 선택한다.
- Then: 선택한 메모의 MemoDetail 화면으로 이동한다.

### TC-TAG-DETAIL-MEMO-FEATURE-008: 메모를 완료하거나 삭제하면 목록에서 사라지고 피드백을 제공한다

- 근거: `feature > 완료·삭제와 실행 취소`
- Given: 상세 대상 태그에 연결된 미완료·미삭제 메모가 표시되어 있으며 상태 변경이 성공하도록 설정되어 있다.
- When: 사용자가 테스트 데이터의 상태 변경을 실행한다.
- Then: 메모가 목록에서 사라지고 해당 결과의 피드백과 실행 취소 동작이 제공된다.
- 테스트 데이터:

| 상태 변경 |
| --- |
| 완료 |
| 삭제 |

### TC-TAG-DETAIL-MEMO-FEATURE-009: 상태 변경을 실행 취소하면 메모가 목록에 다시 나타난다

- 근거: `feature > 완료·삭제와 실행 취소`
- Given: 상세 대상 태그의 메모가 테스트 데이터의 상태 변경으로 목록에서 사라지고 실행 취소 동작이 표시되어 있다.
- When: 사용자가 실행 취소를 선택한다.
- Then: 메모가 이전 상태로 돌아가고 목록의 정렬 기준에 맞는 위치에 다시 나타난다.
- 테스트 데이터:

| 상태 변경 | 실행 취소 결과 |
| --- | --- |
| 완료 | 미완료 상태로 복구 |
| 삭제 | 미삭제 상태로 복구 |

### TC-TAG-DETAIL-MEMO-FEATURE-010: 화면 복귀 시 오늘 날짜 그룹 표시를 갱신한다

- 근거: `feature > 오늘 갱신`
- Given: TagDetail 화면을 벗어난 사이 날짜가 바뀌어 새 오늘과 이전 오늘에 시작하는 메모가 각각 있다.
- When: 사용자가 메모 탭이 선택된 TagDetail 화면으로 복귀한다.
- Then: 새 오늘에 해당하는 날짜 그룹이 오늘로 표시되고 이전 오늘의 날짜 그룹은 더 이상 오늘로 표시되지 않는다.

### TC-TAG-DETAIL-MEMO-FEATURE-031: 메모 탭에서 이동한 MemoAdd와 MemoDetail 화면은 단독으로 표시한다

- 근거: `feature > 메모 추가`, `feature > 메모 상세 확인`
- Given: 태그 목록과 상세를 함께 표시하는 배치에서 TagDetail 화면의 메모 탭이 상세 영역에 표시되어 있다.
- When: 사용자가 메모 탭에서 테스트 데이터의 동작을 실행한다.
- Then: 이동한 화면이 TagDetail 화면과 함께 배치되지 않고 단독으로 표시되며, 그 화면에서는 주요 목적지의 공통 내비게이션을 제공하지 않는다.
- 테스트 데이터:

| 동작 | 이동한 화면 |
| --- | --- |
| 메모 추가 선택 | MemoAdd |
| 메모 선택 | MemoDetail |

### TC-TAG-DETAIL-MEMO-FEATURE-019: 대상 태그의 상태와 무관하게 메모 추가를 시작할 수 있다

- 근거: `feature > 메모 추가`, `domain > 메모 추가의 초기값`
- Given: 메모 탭의 상세 대상 태그 상태가 테스트 데이터의 상태다.
- When: 사용자가 TagDetail 화면의 메모 탭에서 가능한 동작을 확인한다.
- Then: 메모 추가를 시작할 수 있다.
- 테스트 데이터:

| 대상 태그 상태 |
| --- |
| 현재 사용자 계정과 연결되어 있고 미완료·미삭제 |
| 현재 사용자 계정과 연결되지 않음 |
| 완료 |
| 삭제 |

### TC-TAG-DETAIL-MEMO-FEATURE-014: 메모 추가를 선택하면 MemoAdd 화면으로 이동한다

- 근거: `feature > 메모 추가`
- Given: 완료되지 않고 삭제되지 않은 태그의 TagDetail 화면의 메모 탭이 표시되어 있다.
- When: 사용자가 메모 추가를 선택한다.
- Then: MemoAdd 화면으로 이동한다.

### TC-TAG-DETAIL-MEMO-FEATURE-015: 메모 추가 화면은 대상 태그를 초기 선택하고 초기 대표로 시작한다

- 근거: `feature > 메모 추가`, `domain > 메모 추가의 초기값`
- Given: 활성 상태인 태그 A의 TagDetail 화면의 메모 탭이 표시되어 있다.
- When: 사용자가 메모 추가를 선택한다.
- Then: MemoAdd 화면에서 태그 A가 최초 선택되어 있고 최초 대표 태그로 지정되어 있으며, 사용자는 저장 전까지 태그 A를 해제하거나 다른 태그를 선택하고 대표 태그를 바꿀 수 있다.

완료되었거나 삭제된 대상 태그로 메모 추가를 시작하는 결과는 MemoAdd의 태그 선택 시작 상태 규칙이므로 [MemoAdd 테스트 케이스](./memo-add.md)의 `TC-MEMO-ADD-DOMAIN-016`이 다룬다.

### TC-TAG-DETAIL-MEMO-FEATURE-021: 연결된 메모가 없으면 빈 상태 안내를 표시한다

- 근거: `feature > 빈 상태`
- Given: 상세 대상 태그와 연결되고 노출 기준을 만족하는 메모가 하나도 없고 목록의 준비가 끝났다.
- When: 사용자가 TagDetail 화면의 메모 탭을 확인한다.
- Then: 메모 카드 대신 이 태그에 연결된 메모가 없음을 알리는 안내가 표시된다.

### TC-TAG-DETAIL-MEMO-FEATURE-022: 목록을 준비하는 동안에는 빈 상태 안내를 표시하지 않는다

- 근거: `feature > 빈 상태`
- Given: 목록에 표시된 메모가 아직 하나도 없고 목록의 준비가 끝나지 않았다.
- When: 사용자가 TagDetail 화면의 메모 탭을 확인한다.
- Then: 빈 상태 안내가 표시되지 않는다.

### TC-TAG-DETAIL-MEMO-FEATURE-023: 대상 태그를 조회하지 못해도 빈 상태 안내는 같은 기준으로 표시한다

- 근거: `feature > 빈 상태`
- Given: 상세 대상 태그를 조회하지 못해 화면 제목이 표시되지 않고, 연결된 메모가 하나도 없으며 목록의 준비가 끝났다.
- When: 사용자가 TagDetail 화면의 메모 탭을 확인한다.
- Then: 이 태그에 연결된 메모가 없음을 알리는 안내가 표시된다.

### TC-TAG-DETAIL-MEMO-FEATURE-024: 빈 상태에서도 메모 추가를 실행할 수 있다

- 근거: `feature > 빈 상태`
- Given: TagDetail 화면의 메모 탭에 빈 상태 안내가 표시되어 있다.
- When: 사용자가 메모 추가를 선택한다.
- Then: 상세 대상 태그를 초기값으로 하는 메모 추가 화면으로 이동한다.

### TC-TAG-DETAIL-MEMO-FEATURE-025: 완료된 메모 확인을 선택하면 같은 태그의 완료된 메모 목록으로 이동한다

- 근거: `feature > 완료된 메모 확인`
- Given: 상세 대상 태그의 TagDetail 화면의 메모 탭이 표시되어 있다.
- When: 사용자가 완료된 메모 확인을 선택한다.
- Then: 같은 태그의 TagMemoFinishedList 화면으로 이동한다.

### TC-TAG-DETAIL-MEMO-FEATURE-026: 목록 상태와 무관하게 완료된 메모 확인을 실행할 수 있다

- 근거: `feature > 완료된 메모 확인`, `feature > 빈 상태`
- Given: TagDetail 화면의 메모 탭이 테스트 데이터의 상태다.
- When: 사용자가 완료된 메모 확인을 선택한다.
- Then: 같은 태그의 TagMemoFinishedList 화면으로 이동한다.
- 테스트 데이터:

| 화면 상태 |
| --- |
| 연결된 메모가 표시되어 있음 |
| 빈 상태 안내가 표시되어 있음 |
| 대상 태그를 조회하지 못해 화면 제목이 없음 |

### TC-TAG-DETAIL-MEMO-FEATURE-027: 메모 추가는 메모 탭에서만 제공된다

- 근거: `feature > 메모 추가`
- Given: 태그가 조회된 TagDetail 화면에서 테스트 데이터의 탭이 선택되어 있다.
- When: 사용자가 화면에서 실행할 수 있는 동작을 확인한다.
- Then: 메모 추가를 실행할 수 없고, 메모 탭으로 전환하면 메모 추가를 실행할 수 있다.
- 테스트 데이터:

| 선택한 탭 |
| --- |
| 태그 디테일 탭 |
| 웹 탭 |
| 장소 탭 |

### TC-TAG-DETAIL-MEMO-FEATURE-028: 완료된 메모 확인은 메모 탭에서만 제공된다

- 근거: `feature > 완료된 메모 확인`
- Given: 태그가 조회된 TagDetail 화면에서 테스트 데이터의 탭이 선택되어 있다.
- When: 사용자가 화면에서 실행할 수 있는 동작을 확인한다.
- Then: 완료된 메모 확인을 실행할 수 없고, 메모 탭으로 전환하면 완료된 메모 확인을 실행할 수 있다.
- 테스트 데이터:

| 선택한 탭 |
| --- |
| 태그 디테일 탭 |
| 웹 탭 |
| 장소 탭 |

### TC-TAG-DETAIL-MEMO-FEATURE-030: 완료된 메모 목록에는 표시 범위를 적용하지 않는다

- 근거: `feature > 완료된 메모 확인`
- Given: 상세 대상 태그에서 태그 B로 향하는 연결이 저장되어 있고 태그 B에만 완료된 메모가 연결되어 있으며, 사용자가 표시 범위를 `모든 하위까지`로 바꿨다.
- When: 사용자가 메모 탭에서 완료된 메모 확인을 선택한다.
- Then: 이동한 완료된 메모 목록에 태그 B의 완료된 메모가 표시되지 않는다.

### TC-TAG-DETAIL-MEMO-FEATURE-029: 대상 태그를 조회하지 못해도 메모 목록과 동작을 제공한다

- 근거: `feature > 진입`
- Given: 상세 대상 태그를 조회할 수 없고, 그 태그와 연결된 미완료·미삭제 메모가 저장되어 있다.
- When: 사용자가 TagDetail 화면에서 메모 탭을 연다.
- Then: 연결된 메모가 목록에 표시되고 메모 추가와 완료된 메모 확인을 실행할 수 있다.

### TC-TAG-DETAIL-MEMO-FEATURE-032: 다른 탭에 다녀와도 메모 목록에서 보던 위치를 유지한다

- 근거: `feature > 진입`, [TagDetail 화면 스펙의 탭 전환](../spec/client/tag-detail.md#탭-전환)
- Given: 메모 탭의 목록에 한 화면을 넘는 메모가 표시되어 있고, 사용자가 목록을 내려 맨 위가 아닌 메모를 보고 있다.
- When: 사용자가 다른 탭을 선택했다가 메모 탭으로 돌아온다.
- Then: 사용자가 보던 메모가 그대로 표시되고 목록의 맨 위 메모는 보이지 않는다.

### TC-TAG-DETAIL-MEMO-FEATURE-033: 이동한 화면이 닫히면 메모 탭이 선택된 같은 태그의 TagDetail로 돌아온다

- 근거: `feature > 메모 추가`, `feature > 메모 상세 확인`
- Given: TagDetail 화면의 메모 탭에서 테스트 데이터의 화면으로 이동했다.
- When: 테스트 데이터의 동작으로 그 화면이 닫힌다.
- Then: 같은 태그의 TagDetail 화면이 메모 탭이 선택된 채로 표시되고 메모 탭의 목록이 보인다.
- 테스트 데이터:

| 닫히는 경우 |
| --- |
| MemoAdd에서 뒤로가기 |
| MemoDetail에서 뒤로가기 |

### TC-TAG-DETAIL-MEMO-FEATURE-034: 안내가 보이는 동안 다른 탭으로 바꾸면 안내가 닫히고 되돌릴 수 없다

- 근거: `feature > 완료·삭제와 실행 취소`

### TC-TAG-DETAIL-MEMO-DATA-001: 현재 계정의 대상 태그와 활성 연결을 가진 미완료·미삭제 메모만 조회한다

- 근거: `data > 태그별 메모 조회`, `domain > 상세 대상 태그와 연결`, `domain > 메모 노출과 정렬`
- Given: 표시 범위가 `이 태그만`이고, 현재 계정과 다른 계정, 대상 태그와 다른 태그, 해제된 연결과 해제되지 않은 연결, 완료·삭제 상태가 서로 다른 메모가 함께 저장되어 있다.
- When: 현재 계정에서 대상 태그의 메모 목록을 조회한다.
- Then: 현재 계정과 연결되어 있고 대상 태그와 해제되지 않은 연결을 가지며 완료되지 않고 삭제되지 않은 메모만 조회된다.

### TC-TAG-DETAIL-MEMO-DATA-003: 메모나 연결이 바뀌면 태그별 메모 목록이 자동으로 갱신된다

- 근거: `data > 태그별 메모 조회`
- Given: 대상 태그의 메모 목록을 조회하고 있고, 변경할 메모와 연결이 준비되어 있다.
- When: 테스트 데이터의 변경을 저장한다.
- Then: 새로 목록을 요청하지 않아도 테스트 데이터의 기대 결과가 목록에 반영된다.
- 테스트 데이터:

| 변경 | 기대 결과 |
| --- | --- |
| 연결 해제 | 메모가 목록에서 사라짐 |
| 연결 복구 | 노출 기준을 만족하는 메모가 정렬 위치에 나타남 |
| 메모 완료 | 메모가 목록에서 사라짐 |
| 메모 삭제 | 메모가 목록에서 사라짐 |
| 메모 기간 변경 | 변경된 기간의 정렬 위치로 이동 |

### TC-TAG-DETAIL-MEMO-DATA-004: 메모 상태 변경은 태그 연결을 유지한다

- 근거: `data > 상태 변경의 저장`, `domain > 완료·삭제·실행 취소`
- Given: 대상 태그와 연결된 미완료·미삭제 메모가 저장되어 있다.
- When: 메모를 테스트 데이터의 상태로 바꾼다.
- Then: 메모 상태와 수정 시각은 바뀌지만 대상 태그와의 연결은 해제되지 않는다.
- 테스트 데이터:

| 상태 변경 |
| --- |
| 완료 |
| 삭제 |
| 완료 실행 취소 |
| 삭제 실행 취소 |

### TC-TAG-DETAIL-MEMO-DATA-005: 메모는 저장 시점의 태그 선택과 대표 태그로 저장된다

- 근거: `data > 메모 추가 결과`, `domain > 메모 추가의 초기값`
- Given: 태그 A의 메모 탭에서 메모 추가를 시작했고 태그 B도 선택할 수 있으며, 새 메모는 미완료·미삭제 상태다.
- When: 사용자가 테스트 데이터의 최종 선택 상태와 대표 태그로 메모를 저장한다.
- Then: 새 메모의 태그 연결과 대표 태그가 테스트 데이터의 기대 결과로 저장되고 메모 탭 노출 결과도 그 연결을 따른다.
- 테스트 데이터:

| 저장 시점의 선택 태그 | 저장 시점의 대표 태그 | 기대 연결 | 기대 대표 태그 | 태그 A의 메모 탭 결과 |
| --- | --- | --- | --- | --- |
| 태그 A | 태그 A | 태그 A와 연결 | 태그 A | 새 메모가 나타남 |
| 태그 A, 태그 B | 태그 B | 태그 A·태그 B와 연결 | 태그 B | 새 메모가 나타남 |
| 태그 B | 태그 B | 태그 B와만 연결하고 태그 A와 연결하지 않음 | 태그 B | 새 메모가 나타나지 않음 |

### TC-TAG-DETAIL-MEMO-DATA-006: 탭별 조회는 서로 독립이다

- 근거: `data > 태그별 메모 조회`
- Given: 대상 태그 조회가 실패하도록 제어되어 있고, 그 태그와 연결된 미완료·미삭제 메모가 저장되어 있다.
- When: 사용자가 메모 탭의 목록을 확인한다.
- Then: 태그 조회 실패와 무관하게 메모 목록이 노출 기준대로 조회되어 표시된다.
