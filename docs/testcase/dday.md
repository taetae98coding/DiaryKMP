# 디데이 테스트 케이스

기준 스펙: [디데이 앱 스펙](../spec/client/dday.md), [디데이 스펙](../spec/common/dday.md)

이 문서에서 `domain > 디데이의 정보`, `domain > 날짜`, `domain > 반복 간격`, `domain > 유효 범위`, `domain > 기본값` 절은 [디데이 스펙](../spec/common/dday.md)이 소유하고, 나머지 케이스의 절은 [디데이 앱 스펙](../spec/client/dday.md)이 소유한다.

카드 문구와 기념일 문구의 기대 결과는 디데이 앱 스펙이 정한 한국어 형식으로 쓴다. 그 외 기본 언어의 카드 문구 표기는 [DDayHome 테스트 케이스](./dday-home.md)가, 계산 결과를 캘린더에 놓는 결과는 캘린더 디데이 표시 테스트 케이스가 확인한다. 반복 간격을 입력 단위에서 일 수와 개월 수로 기록하는 결과는 [DDayAdd 테스트 케이스](./dday-add.md)가 확인한다.

`domain > 유효 범위`의 케이스는 이 문서에 두지 않는다. 앱의 입력이 이 범위를 벗어난 값을 만들지 않는 것은 [DDayAdd 테스트 케이스](./dday-add.md)와 [DDayDetail 테스트 케이스](./dday-detail.md)가, 서버가 동기화 요청에서 값을 확인하는 것은 [데이터 동기화 테스트 케이스](./data-sync.md)가 확인한다.

케이스의 `켬`과 `끔`은 기준일을 1일로 세기의 값이다. 따로 적지 않으면 달력에 없는 날짜 처리는 `말일로 당김`이고 종료일은 없다.
