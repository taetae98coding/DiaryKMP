# SwipeToFinishAndDelete 컴포넌트 테스트 케이스

기준 스펙: [SwipeToFinishAndDelete 컴포넌트 스펙](../spec/client/swipe-to-finish-and-delete.md)

메모 목록처럼 컴포넌트를 배치한 화면에서 시작 방향 동작이 완료인지 다시 시작인지, 그 결과와 피드백이 무엇인지는 각 화면의 테스트 케이스 문서에서 다룬다.

## feature

### TC-SWIPE-TO-FINISH-AND-DELETE-FEATURE-001: 시작 방향 상호작용은 시작 방향 동작만 한 번 실행한다

- 근거: `feature > 두 방향의 동작`, `domain > 동작 실행 기준`
- Given: 상호작용이 활성화된 카드가 표시되어 있다.
- When: 사용자가 시작 방향 상호작용을 실행 기준에 도달하도록 수행한다.
- Then: 시작 방향 동작이 한 번 실행되고 삭제 동작은 실행되지 않는다.

### TC-SWIPE-TO-FINISH-AND-DELETE-FEATURE-002: 끝 방향 상호작용은 삭제 동작만 한 번 실행한다

- 근거: `feature > 두 방향의 동작`, `domain > 동작 실행 기준`
- Given: 상호작용이 활성화된 카드가 표시되어 있다.
- When: 사용자가 끝 방향 상호작용을 실행 기준에 도달하도록 수행한다.
- Then: 삭제 동작이 한 번 실행되고 시작 방향 동작은 실행되지 않는다.

### TC-SWIPE-TO-FINISH-AND-DELETE-FEATURE-004: 실행 기준에 도달하지 않은 상호작용은 아무 동작도 실행하지 않는다

- 근거: `feature > 상호작용 취소`
- Given: 상호작용이 활성화된 카드가 표시되어 있다.
- When: 사용자가 실행 기준에 도달하지 않은 채 상호작용을 끝낸다.
- Then: 카드가 그대로 남아 있고 두 방향의 동작이 모두 실행되지 않는다.

### TC-SWIPE-TO-FINISH-AND-DELETE-FEATURE-005: 상호작용이 비활성화된 카드는 어느 방향의 동작도 실행할 수 없다

- 근거: `feature > 상호작용 비활성`
- Given: 상호작용이 비활성화된 카드가 표시되어 있다.
- When: 사용자가 카드에서 시작 방향 또는 끝 방향 상호작용을 시도한다.
- Then: 카드가 그대로 남아 있고 두 방향의 동작이 모두 실행되지 않는다.

### TC-SWIPE-TO-FINISH-AND-DELETE-FEATURE-006: 적용 대상이 아닌 목록의 카드는 상호작용을 제공하지 않는다

- 근거: `적용 대상`
- Given: SearchHome의 메모 검색 결과에 메모 카드가 표시되어 있다.
- When: 사용자가 카드를 시작 방향과 끝 방향으로 밀어 본다.
- Then: 카드가 밀리지 않고 제자리에 남으며, 진행 상태 변경과 삭제 동작이 모두 실행되지 않고 동작 아이콘도 나타나지 않는다.

### TC-SWIPE-TO-FINISH-AND-DELETE-FEATURE-007: 삭제만 제공하는 카드는 시작 방향 상호작용에 동작을 실행하지 않는다

- 근거: `적용 대상`, `feature > 방향별 동작의 의미`
- Given: 진행 상태를 바꾸는 동작이 없는 목록의 카드가 상호작용이 활성화된 채 표시되어 있다.
- When: 사용자가 카드를 시작 방향으로 실행 기준을 넘도록 민다.
- Then: 카드가 그대로 남아 있고 삭제 동작이 실행되지 않는다.

### TC-SWIPE-TO-FINISH-AND-DELETE-FEATURE-008: 삭제만 제공하는 카드는 끝 방향 상호작용으로 삭제 동작을 한 번 실행한다

- 근거: `feature > 방향별 동작의 의미`, `domain > 동작 실행 기준`
- Given: 진행 상태를 바꾸는 동작이 없는 목록의 카드가 상호작용이 활성화된 채 표시되어 있다.
- When: 사용자가 카드를 끝 방향으로 실행 기준을 넘도록 민다.
- Then: 삭제 동작이 한 번 실행된다.

### TC-SWIPE-TO-FINISH-AND-DELETE-FEATURE-009: 삭제만 제공하는 카드도 비활성화되면 삭제 동작을 실행할 수 없다

- 근거: `feature > 상호작용 비활성`
- Given: 진행 상태를 바꾸는 동작이 없는 목록의 카드가 상호작용이 비활성화된 채 표시되어 있다.
- When: 사용자가 카드를 끝 방향으로 민다.
- Then: 카드가 그대로 남아 있고 삭제 동작이 실행되지 않는다.

## domain

### TC-SWIPE-TO-FINISH-AND-DELETE-DOMAIN-001: 다른 항목을 표시하면 스와이프 상태가 초기화된다

- 근거: `domain > 카드 상태 초기화`
- Given: 카드에서 두 방향의 동작 중 하나가 실행되었다.
- When: 같은 카드 자리가 다른 항목을 표시한다.
- Then: 카드는 동작 실행 전의 원래 상태로 표시되고 동작이 다시 실행되지 않는다.

### TC-SWIPE-TO-FINISH-AND-DELETE-DOMAIN-002: 실행 취소로 다시 나타난 카드는 실행 전 상태로 표시된다

- 근거: `domain > 카드 상태 초기화`
- Given: 카드에서 두 방향의 동작 중 하나가 실행되어 카드가 목록에서 사라졌다.
- When: 사용자가 실행 취소해 같은 항목의 카드가 목록에 다시 나타난다.
- Then: 카드는 동작 실행 전의 원래 상태로 표시되고 어느 방향의 동작도 다시 실행되지 않는다.

### TC-SWIPE-TO-FINISH-AND-DELETE-DOMAIN-003: 삭제만 제공하는 카드도 다른 항목을 표시하면 스와이프 상태가 초기화된다

- 근거: `domain > 카드 상태 초기화`
- Given: 진행 상태를 바꾸는 동작이 없는 목록의 카드에서 삭제 동작이 실행되었다.
- When: 같은 카드 자리가 다른 항목을 표시한다.
- Then: 카드는 스와이프 전의 원래 모양으로 표시되고 삭제 동작이 다시 실행되지 않는다.

### TC-SWIPE-TO-FINISH-AND-DELETE-DOMAIN-004: 실행 취소로 다시 나타난 삭제 전용 카드는 스와이프 전 모양으로 표시된다

- 근거: `domain > 카드 상태 초기화`
- Given: 진행 상태를 바꾸는 동작이 없는 목록의 카드에서 삭제 동작이 실행되어 카드가 목록에서 사라졌다.
- When: 사용자가 실행 취소해 같은 항목의 카드가 목록에 다시 나타난다.
- Then: 카드는 스와이프 전의 원래 모양으로 표시되고 삭제 동작이 다시 실행되지 않는다.
