# SettingHoliday 테스트 케이스

기준 스펙: [SettingHoliday 화면 스펙](../spec/client/setting-holiday.md)

설정 화면 본문에서 `공휴일` 항목을 선택해 SettingHoliday로 이동하는 케이스는 [SettingHome 테스트 케이스](./setting-home.md)에서 다룬다. 설정 목록과 함께 표시되는 상태의 시스템 뒤로가기 결과는 [Setting 목록·상세 배치 테스트 케이스](./setting-list-detail.md)에서, 선택한 항목이 캘린더 공휴일 조회에 적용되는 결과는 [공휴일 노출 설정 테스트 케이스](./holiday-visibility.md)에서 다룬다. 국가 설정의 저장과 적용 국가 판정은 [공휴일 국가 설정 테스트 케이스](./holiday-country.md)에서 다룬다.

국가 설정과 노출 설정이 화면 재생성, 백그라운드 복귀, 화면 재진입과 앱 재실행 뒤에도 유지되는 결과는 화면이 기기에 저장된 선택 상태를 다시 표시하는 `TC-aad46f37-24f2-4c33-9979-0d8849541987`과, 저장된 설정이 유지되는 [공휴일 국가 설정 테스트 케이스](./holiday-country.md)의 `TC-a0f2ad95-90dd-430e-89d3-fee58de68b8f`, [공휴일 노출 설정 테스트 케이스](./holiday-visibility.md)의 `TC-f78d63e6-cf9e-45d2-bdc4-7cabe36dbbf5`, `TC-af66fad9-88ce-4615-968a-5008dbd5f523`로 확인한다.

## feature

### TC-1e6ede6f-955a-4221-8303-bc31c70655b2: 단독 화면에서 뒤로가면 설정 목록으로 돌아간다

- 근거: `feature > 뒤로가기`
- Given: SettingHoliday 화면이 단독으로 표시되어 뒤로가기 동작이 제공되고 있다.
- When: 사용자가 뒤로가기 동작을 선택한다.
- Then: 이전 화면으로 돌아가는 요청이 한 번 발생한다.

이 요청으로 설정 목록이 다시 표시되는 결과는 [Setting 목록·상세 배치 테스트 케이스](./setting-list-detail.md)의 TC-8cbf380d-d0b9-456a-a873-f94e35d5deea이, 그동안 공통 내비게이션을 계속 제공하지 않는 결과는 [TopLevelNavigation 테스트 케이스](./top-level-navigation.md)의 TC-e499dc91-528f-4d46-a621-c4f9867ec27a가 다룬다.

- Then: 쉬는 날인 항목만 쉬는 날로 구분되고 쉬는 날이 아닌 항목은 그렇게 구분되지 않는다.
