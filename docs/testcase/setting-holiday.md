# SettingHoliday 테스트 케이스

기준 스펙: [SettingHoliday 화면 스펙](../spec/setting-holiday.md)

설정 화면 본문에서 `공휴일` 항목을 선택해 SettingHoliday로 이동하는 케이스는 [SettingHome 테스트 케이스](./setting-home.md)에서 다룬다. 설정 목록과 함께 표시되는 상태의 시스템 뒤로가기 결과는 [Setting 목록·상세 배치 테스트 케이스](./setting-list-detail.md)에서, 선택한 항목이 캘린더 공휴일 조회에 적용되는 결과는 [공휴일 노출 설정 테스트 케이스](./holiday-visibility.md)에서 다룬다. 국가 설정의 저장과 적용 국가 판정은 [공휴일 국가 설정 테스트 케이스](./holiday-country.md)에서 다룬다.

## feature

### TC-SETTING-HOLIDAY-FEATURE-003: 단독 화면에서 뒤로가면 설정 목록으로 돌아간다

- 근거: `feature > 뒤로가기`
- Given: SettingHoliday 화면이 단독으로 표시되어 있다.
- When: 사용자가 뒤로간다.
- Then: 설정 목록으로 돌아가고 공통 내비게이션은 계속 제공되지 않는다.

### TC-SETTING-HOLIDAY-FEATURE-005: 동작 버튼을 펼치면 일괄 선택 동작을 제공한다

- 근거: `feature > 일괄 선택`
- Given: 저장된 공휴일과 노출 설정을 확인했고 검색어가 비어 있다.
- When: 사용자가 일괄 선택 동작 버튼을 선택한다.
- Then: 전체 선택, 전체 해제, 쉬는 날만 선택하는 동작이 제공된다.

### TC-SETTING-HOLIDAY-FEATURE-006: 저장된 공휴일 항목과 선택 상태를 표시한다

- 근거: `feature > 공휴일 선택`
- Given: 저장된 공휴일은 서로 다른 key 세 개로 구성되고 그중 두 key가 선택되어 있다.
- When: 사용자가 SettingHoliday 화면 본문을 확인한다.
- Then: 세 공휴일 항목이 각각의 선택 상태와 함께 표시된다.

### TC-SETTING-HOLIDAY-FEATURE-007: 쉬는 날인 항목만 쉬는 날로 표시한다

- 근거: `feature > 공휴일 선택`
- Given: 쉬는 날인 공휴일과 쉬는 날이 아닌 공휴일이 하나씩 저장되어 있다.
- When: 사용자가 두 공휴일 항목을 확인한다.
- Then: 쉬는 날인 항목만 쉬는 날로 구분되고 쉬는 날이 아닌 항목은 그렇게 구분되지 않는다.

### TC-SETTING-HOLIDAY-FEATURE-008: 공휴일 항목을 선택하면 선택 상태가 바뀐다

- 근거: `feature > 공휴일 선택`, `domain > 선택 상태`
- Given: 저장된 공휴일과 노출 설정이 확인되어 있고 설정 변경이 성공하는 상태다.
- When: 사용자가 테스트 데이터의 공휴일 항목을 선택한다.
- Then: 해당 key의 목표 상태가 한 번 저장되고, 저장된 결과가 반영되면 해당 항목이 목표 상태로 바뀐다.
- 테스트 데이터:

| 기존 상태 | 목표 상태 |
| --- | --- |
| 선택 | 선택 해제 |
| 선택 해제 | 선택 |

### TC-SETTING-HOLIDAY-FEATURE-009: 전체 선택은 모든 항목을 선택한다

- 근거: `feature > 일괄 선택`, `domain > 일괄 선택 기준`
- Given: 현재 공휴일 중 일부만 선택되어 있고, 현재 공휴일에 없는 key도 숨김으로 저장되어 있으며 설정 변경이 성공하는 상태다.
- When: 사용자가 `전체 선택`을 선택한다.
- Then: 빈 숨김 key 집합이 한 번 저장되어 현재 공휴일에 없는 기존 key도 제거되고, 저장된 결과가 반영되면 모든 공휴일 항목이 선택 상태로 표시된다.

### TC-SETTING-HOLIDAY-FEATURE-010: 전체 해제는 모든 항목을 선택 해제한다

- 근거: `feature > 일괄 선택`, `domain > 일괄 선택 기준`
- Given: 현재 공휴일 중 일부가 선택되어 있고, 현재 공휴일에 없는 key도 숨김으로 저장되어 있으며 설정 변경이 성공하는 상태다.
- When: 사용자가 `전체 해제`를 선택한다.
- Then: 현재 전체 공휴일의 모든 이름 key만 담은 숨김 집합이 한 번 저장되어 현재 공휴일에 없는 기존 key는 제거되고, 저장된 결과가 반영되면 모든 공휴일 항목이 선택 해제 상태로 표시된다.

### TC-SETTING-HOLIDAY-FEATURE-011: 쉬는 날만 선택은 쉬는 날 여부에 맞춰 선택한다

- 근거: `feature > 일괄 선택`, `domain > 일괄 선택 기준`
- Given: 쉬는 날인 key와 쉬는 날이 아닌 key가 각각 있고 현재 선택 상태가 쉬는 날 여부와 다르며, 현재 공휴일에 없는 key도 숨김으로 저장되어 있고 설정 변경이 성공하는 상태다.
- When: 사용자가 `쉬는 날만 선택`을 선택한다.
- Then: 현재 전체 공휴일 중 쉬는 날이 아닌 key만 담은 숨김 집합이 한 번 저장되어 현재 공휴일에 없는 기존 key는 제거되고, 저장된 결과가 반영되면 쉬는 날인 모든 항목은 선택되고 쉬는 날이 아닌 모든 항목은 선택 해제된다.

### TC-SETTING-HOLIDAY-FEATURE-012: 일괄 선택의 목표 상태와 같으면 새 저장값을 만들지 않는다

- 근거: `feature > 일괄 선택`, `domain > 일괄 선택 기준`
- Given: 현재 저장된 숨김 key 집합이 테스트 데이터의 전체 교체 결과와 이미 정확히 같다.
- When: 사용자가 테스트 데이터의 일괄 선택을 선택한다.
- Then: 선택 상태가 그대로 유지되고 새 저장값이나 화면 상태 갱신이 생기지 않는다.
- 테스트 데이터:

| 저장된 숨김 key 집합 | 일괄 선택 |
| --- | --- |
| 빈 집합 | `전체 선택` |
| 현재 전체 공휴일의 모든 이름 key | `전체 해제` |
| 현재 전체 공휴일 중 쉬는 날이 아닌 key | `쉬는 날만 선택` |

### TC-SETTING-HOLIDAY-FEATURE-013: 공휴일을 확인하는 동안 확인 중 상태를 제공한다

- 근거: `feature > 확인 중`
- Given: 저장된 공휴일과 노출 설정을 아직 확인하고 있다.
- When: 사용자가 SettingHoliday 화면 본문을 확인한다.
- Then: 확인 중 상태가 제공되고 선택할 수 있는 공휴일 항목이 없다.

### TC-SETTING-HOLIDAY-FEATURE-018: 원본 데이터가 바뀌면 목록을 갱신한다

- 근거: `feature > 상태 갱신과 유지`
- Given: SettingHoliday 화면에서 저장된 공휴일과 선택 상태를 확인하고 있다.
- When: 저장된 공휴일 또는 노출 설정이 바뀐다.
- Then: 사용자의 별도 조작 없이 공휴일 목록과 각 항목의 선택 상태가 최신 값으로 바뀐다.

### TC-SETTING-HOLIDAY-FEATURE-020: 목록을 스크롤해도 일괄 선택 동작을 계속 사용할 수 있다

- 근거: `feature > 일괄 선택`
- Given: 한 화면에 다 보이지 않을 만큼 많은 공휴일이 저장되어 있다.
- When: 사용자가 공휴일 목록을 마지막 항목까지 스크롤한 뒤 일괄 선택 동작 버튼을 선택한다.
- Then: 동작 버튼이 계속 표시되어 있고 전체 선택, 전체 해제, 쉬는 날만 선택하는 동작이 제공된다.

### TC-SETTING-HOLIDAY-FEATURE-021: 검색어를 입력하면 일치하는 항목만 표시한다

- 근거: `feature > 검색`
- Given: 검색어와 일치하는 공휴일과 일치하지 않는 공휴일이 함께 저장되어 있고 목록이 표시되어 있다.
- When: 사용자가 검색어를 입력한다.
- Then: 일치하는 항목만 목록에 남고, 남은 항목의 순서와 선택 상태는 전체 목록에서와 같다.

### TC-SETTING-HOLIDAY-FEATURE-022: 검색 결과가 없으면 빈 상태 안내를 표시한다

- 근거: `feature > 검색`
- Given: 공휴일 목록이 표시되어 있다.
- When: 사용자가 어떤 공휴일과도 일치하지 않는 검색어를 입력한다.
- Then: 결과가 없음을 알리는 빈 상태가 표시되고, 검색어를 계속 수정하거나 지울 수 있다.

### TC-SETTING-HOLIDAY-FEATURE-023: 검색어를 모두 지우면 전체 목록으로 돌아간다

- 근거: `feature > 검색`
- Given: 검색어로 목록이 필터링되어 있다.
- When: 사용자가 검색어를 모두 지운다.
- Then: 저장된 모든 공휴일 항목이 다시 표시된다.

### TC-SETTING-HOLIDAY-FEATURE-024: 일괄 선택은 검색어가 비어 있을 때만 제공한다

- 근거: `feature > 일괄 선택`
- Given: 공휴일 목록과 일괄 선택 동작 버튼이 표시되어 있다.
- When: 사용자가 검색어를 입력한 뒤 다시 모두 지운다.
- Then: 검색어가 있는 동안 일괄 선택 동작 버튼이 제공되지 않고, 검색어를 모두 지우면 다시 제공된다.

### TC-SETTING-HOLIDAY-FEATURE-025: 필터링된 목록에서도 선택 상태를 바꿀 수 있다

- 근거: `feature > 검색`, `domain > 선택 상태`
- Given: 검색어로 목록이 필터링되어 있고 설정 변경이 성공하는 상태다.
- When: 사용자가 필터링된 목록의 공휴일 항목을 선택한다.
- Then: 해당 key의 목표 상태가 한 번 저장되고, 저장된 결과가 반영되면 해당 항목이 목표 상태로 바뀐다.

### TC-SETTING-HOLIDAY-FEATURE-026: 화면에 진입해도 검색어 입력에 초점을 두지 않는다

- 근거: `feature > 검색`
- Given: 사용자가 설정의 `공휴일` 항목을 선택했다.
- When: SettingHoliday 화면이 표시된다.
- Then: 검색어 입력에 초점이 없다.

### TC-SETTING-HOLIDAY-FEATURE-030: 일괄 선택 동작을 고르면 펼친 동작을 접는다

- 근거: `feature > 일괄 선택`
- Given: 일괄 선택 동작 버튼을 선택해 세 동작이 펼쳐져 있고 설정 변경이 성공하는 상태다.
- When: 사용자가 펼쳐진 동작 중 하나를 고른다.
- Then: 세 동작이 더 이상 표시되지 않고 동작 버튼만 남는다.

### TC-SETTING-HOLIDAY-FEATURE-031: 동작 버튼을 다시 선택하면 아무 동작도 실행하지 않고 접는다

- 근거: `feature > 일괄 선택`
- Given: 일괄 선택 동작 버튼을 선택해 세 동작이 펼쳐져 있다.
- When: 사용자가 동작 버튼을 다시 선택한다.
- Then: 세 동작이 더 이상 표시되지 않고 선택 상태는 그대로 유지되며 새 저장값이 생기지 않는다.

### TC-SETTING-HOLIDAY-FEATURE-032: 확인 중에도 일괄 선택 동작을 펼쳐 실행할 수 있다

- 근거: `feature > 확인 중`, `domain > 일괄 선택 기준`
- Given: 저장된 공휴일과 노출 설정을 아직 확인하고 있다.
- When: 사용자가 일괄 선택 동작 버튼을 선택하고 펼쳐진 동작 중 하나를 고른다.
- Then: 세 동작이 모두 제공되고, 고른 동작이 실행된다.

### TC-SETTING-HOLIDAY-FEATURE-034: 국가 선택지를 정해진 순서로 선택 상태와 함께 표시한다

- 근거: `feature > 국가 선택`
- Given: 국가 설정에서 `기기값`과 `미국`을 고른 상태이고 확인이 끝났다.
- When: 사용자가 검색어 없이 SettingHoliday 화면 본문을 확인한다.
- Then: `기기값`, `한국`, `미국` 선택지가 이 순서로 공휴일 항목보다 먼저 표시되고, `기기값`과 `미국`만 선택 상태로 표시된다.

### TC-SETTING-HOLIDAY-FEATURE-035: 국가 선택지를 누르면 그 선택지의 변경을 요청한다

- 근거: `feature > 국가 선택`
- Given: 국가 설정이 확인되어 있다.
- When: 사용자가 테스트 데이터의 국가 선택지를 누른다.
- Then: 해당 선택지의 변경이 한 번 요청된다.
- 테스트 데이터:

  | 누르는 선택지 |
  | --- |
  | `기기값` |
  | `한국` |
  | `미국` |

### TC-SETTING-HOLIDAY-FEATURE-036: 기기값 선택지에 기기 지역에 따라 적용되는 국가를 보여 준다

- 근거: `feature > 국가 선택`
- Given: 기기 지역이 테스트 데이터의 지역이다.
- When: 사용자가 `기기값` 선택지를 확인한다.
- Then: 선택지에 테스트 데이터의 문구가 함께 표시된다.
- 테스트 데이터:

  | 기기 지역 | 함께 표시되는 문구 |
  | --- | --- |
  | 한국 | 한국 |
  | 미국 | 미국 |
  | 일본 | 지원하지 않는 지역 |

### TC-SETTING-HOLIDAY-FEATURE-037: 검색어가 있는 동안에는 국가 선택지를 제공하지 않는다

- 근거: `feature > 국가 선택`
- Given: 국가 설정과 공휴일이 확인되어 있다.
- When: 사용자가 공휴일 이름과 일치하는 검색어를 입력했다가 모두 지운다.
- Then: 검색어가 있는 동안에는 국가 선택지가 표시되지 않고 일치하는 공휴일 항목만 표시되며, 검색어를 지우면 국가 선택지가 다시 표시된다.

### TC-SETTING-HOLIDAY-FEATURE-038: 국가 설정이 바뀌면 공휴일 목록을 적용 국가로 다시 구성한다

- 근거: `feature > 국가 선택`, `feature > 상태 갱신과 유지`
- Given: 한국과 미국 공휴일이 저장되어 있고 적용 국가가 한국인 상태로 화면이 표시되어 있다.
- When: 국가 설정에 `미국`이 더해진다.
- Then: 별도 조작 없이 한국과 미국 공휴일 항목이 함께 표시되고, 국가 선택지의 선택 상태도 바뀐 설정으로 표시된다.

### 작성하지 않는 이유

- 선택 상태가 화면 재생성, 백그라운드 복귀, 화면 재진입과 앱 재실행 뒤에도 유지되는 규칙은 기기 저장 계약으로 결정되며 실제 저장 영역과 실행 경계를 다시 열어야 관찰할 수 있으므로 단위 테스트 케이스로 작성하지 않는다.
- 검색어가 화면 재생성과 백그라운드 복귀에 유지되고 재진입 시 비워지는 규칙은 실행 경계를 실제로 재현해야 관찰할 수 있으므로 단위 테스트 케이스로 작성하지 않는다.
- `TC-SETTING-HOLIDAY-FEATURE-027`, `TC-SETTING-HOLIDAY-FEATURE-028`, `TC-SETTING-HOLIDAY-FEATURE-029`, `TC-SETTING-HOLIDAY-FEATURE-033`은 검색을 시작하고 끝내는 상태가 스펙에서 사라져 검증할 행동이 없어졌다. 남은 케이스의 ID를 옮기지 않으려고 번호는 비워 둔다.

### TC-SETTING-HOLIDAY-DOMAIN-003: 같은 key는 최근 공휴일의 원래 이름으로 하나만 표시한다

- 근거: `domain > 공휴일 항목 구성`
- Given: 공백만 다른 이름을 가진 같은 key의 공휴일들이 서로 다른 시작일로 저장되어 있다.
- When: SettingHoliday에 표시할 공휴일 항목을 구성한다.
- Then: 같은 key의 항목은 하나만 제공되고 시작일이 가장 최근인 공휴일의 원래 이름이 표시된다.

### TC-SETTING-HOLIDAY-DOMAIN-004: 최근 시작일이 같으면 이름 오름차순의 첫 표기를 사용한다

- 근거: `domain > 공휴일 항목 구성`
- Given: 같은 key와 같은 최근 시작일을 가지면서 공백 표기가 다른 공휴일들이 저장되어 있다.
- When: SettingHoliday에 표시할 공휴일 항목을 구성한다.
- Then: 이름 오름차순에서 첫 번째인 원래 이름이 표시된다.

### TC-SETTING-HOLIDAY-DOMAIN-005: 같은 key 중 하나라도 쉬는 날이면 쉬는 날 항목이다

- 근거: `domain > 공휴일 항목 구성`
- Given: 같은 key의 공휴일 중 공휴일 여부가 참인 항목과 거짓인 항목이 함께 저장되어 있다.
- When: SettingHoliday에 표시할 공휴일 항목을 구성한다.
- Then: 해당 key는 쉬는 날인 항목으로 제공된다.

### TC-SETTING-HOLIDAY-DOMAIN-006: 표시 이름과 key 순으로 항목을 정렬한다

- 근거: `domain > 공휴일 항목 구성`
- Given: 표시 이름이나 key가 서로 다른 공휴일들이 순서 없이 저장되어 있다.

### TC-SETTING-HOLIDAY-DOMAIN-007: 숨긴 key만 선택 해제 상태로 제공한다

- 근거: `domain > 선택 상태`
