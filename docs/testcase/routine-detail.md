# RoutineDetail 테스트 케이스

기준 스펙: [RoutineDetail 화면 스펙](../spec/client/routine-detail.md)

진입할 때의 입력 초점, 조회 상태, 내용 수정의 반영과 성공·실패 결과, 삭제, 외부 변경, 태그 입력의 반영, 요청 제한과 저장·동기화 계약은 [항목 상세 화면 공통 스펙](../spec/client/entity-detail.md)에, 각 입력의 조작과 숫자를 입력하고 기록하는 기준은 [RoutineAdd 화면 스펙](../spec/client/routine-add.md)에, 기록 내역을 나누어 불러오는 기준은 [페이지 조회 목록의 자리 표시 스펙](../spec/client/paged-list-placeholder.md)에 위임된 규칙을 이 화면에 적용한 결과를 이 문서가 확인한다. 케이스의 `근거`는 위임한 RoutineDetail 화면 스펙의 절을 가리킨다.

태그 입력의 표시와 조작, 태그 선택 목록의 케이스는 [항목 태그 입력 컴포넌트 테스트 케이스](./entity-tag-input.md)에서 다룬다. `data > 결과의 표시`의 RoutineHome 반영(카드 문구와 자리 이동)은 같은 저장 변경으로 [RoutineHome 테스트 케이스](./routine-home.md)의 목록 갱신 케이스가, 달력 반영은 [캘린더 루틴 기록 표시 테스트 케이스](./calendar-routine.md)가, 합계와 달성률의 계산은 [루틴 테스트 케이스](./routine.md)가 확인한다. 목록과 상세 영역을 함께 표시하는 상태에서 완료, 삭제나 뒤로가기 뒤의 상세 영역은 [Routine 목록·상세 배치 테스트 케이스](./routine-list-detail.md)가, 완료된 루틴 목록과 함께 표시하는 상태의 상세 영역은 [RoutineFinishedList 목록·상세 배치 테스트 케이스](./routine-finished-list-detail.md)와 [TagRoutineFinishedList 목록·상세 배치 테스트 케이스](./tag-routine-finished-list-detail.md)가, Spotlight 검색 결과에서 들어온 화면의 진입과 뒤로가기는 [Spotlight 항목 노출 테스트 케이스](./spotlight.md)가 확인한다.

화면에 보이는 문구와 접근성 이름은 [RoutineDetail 화면 디자인](../design/routine-detail.md)과 [RoutineAdd 화면 디자인](../design/routine-add.md)이 정한 문구를 기대 결과로 쓴다.
