# WebDetail 메모 탭 테스트 케이스

기준 스펙: [WebDetail 메모 탭 스펙](../spec/web-detail-memo.md)

이 문서의 `근거`가 가리키는 절 중 `feature > 진입`, `feature > 메모 추가의 초기 선택`, `feature > 단독 표시와 돌아오기`, `domain > 상세 대상`, `domain > 웹 항목의 상태와 노출`은 기준 스펙이 소유하고, 나머지 절은 [항목 상세 메모 탭 공통 스펙](../spec/entity-detail-memo.md)이 소유한다.

자리 표시 케이스의 `근거`가 가리키는 절은 공통 규칙을 [페이지 조회 목록의 자리 표시 스펙](../spec/paged-list-placeholder.md)에, 빈 상태 케이스의 `근거`가 가리키는 절은 [목록 빈 상태 스펙](../spec/list-empty-state.md)에 위임한다.

화면 전체의 탭 전환과 선택한 탭의 유지, 웹 정보 수정과 웹 페이지 표시의 케이스는 [WebDetail 테스트 케이스](./web-detail.md)에서 다룬다. MemoAdd 화면이 초기 선택을 표시하는 케이스는 [MemoAdd 테스트 케이스](./memo-add.md)에서 다룬다.

## feature

### TC-WEB-DETAIL-MEMO-FEATURE-001: 기간 유무와 시작 날짜에 따라 메모를 나누어 표시한다

- 근거: `feature > 목록 표시`
- Given: 상세 대상 웹 항목에 기간이 없는 메모와 같은 시작 날짜의 기간이 있는 메모들이 연결되어 있다.
- When: 사용자가 WebDetail 화면에서 메모 탭을 연다.
- Then: 기간이 없는 메모는 날짜 그룹 없이 먼저 표시되고, 기간이 있는 메모들은 시작 날짜가 같은 것끼리 한 그룹으로 표시된다.

### TC-WEB-DETAIL-MEMO-FEATURE-002: 자리 표시 상태의 메모는 선택하거나 완료·삭제할 수 없다

- 근거: `feature > 목록 표시`
- Given: 목록의 메모가 아직 준비되지 않아 자리 표시 상태로 제공되어 있다.
- When: 사용자가 해당 메모를 선택하거나 완료·삭제하려 한다.
- Then: 메모 상세 이동, 완료, 삭제가 요청되지 않는다.

### TC-WEB-DETAIL-MEMO-FEATURE-003: 목록 조회 실패에 별도의 오류나 재시도 동작을 표시하지 않는다

- 근거: `feature > 목록 표시`
- Given: 목록 조회가 테스트 데이터의 시점에 실패하도록 설정되어 있다.
- When: 사용자가 WebDetail 화면의 메모 탭을 확인한다.
- Then: 별도 재시도 동작 없이 테스트 데이터의 기존 표시 결과를 유지한다.
- 테스트 데이터:

| 실패 시점 | 기존 표시 결과 |
| --- | --- |
| 최초 조회 | 표시된 메모 없음. 이때의 빈 상태 안내는 `TC-WEB-DETAIL-MEMO-FEATURE-012`가 다룬다 |
| 추가 조회 | 이미 표시된 메모 |

### TC-WEB-DETAIL-MEMO-FEATURE-004: 메모를 선택하면 그 메모의 상세로 이동한다

- 근거: `feature > 메모 상세 확인`
- Given: 상세 대상 웹 항목에 연결된 메모가 표시되어 있다.
- When: 사용자가 그 메모를 선택한다.
- Then: 선택한 메모의 MemoDetail 화면으로 이동한다.

### TC-WEB-DETAIL-MEMO-FEATURE-005: 메모를 완료하거나 삭제하면 목록에서 사라지고 피드백을 제공한다

- 근거: `feature > 완료·삭제와 실행 취소`
- Given: 상세 대상 웹 항목에 연결된 미완료·미삭제 메모가 표시되어 있으며 상태 변경이 성공하도록 설정되어 있다.
- When: 사용자가 테스트 데이터의 상태 변경을 실행한다.
- Then: 메모가 목록에서 사라지고 해당 결과의 피드백과 실행 취소 동작이 제공된다.
- 테스트 데이터:

| 상태 변경 |
| --- |
| 완료 |
| 삭제 |

### TC-WEB-DETAIL-MEMO-FEATURE-006: 상태 변경을 실행 취소하면 메모가 목록에 다시 나타난다

- 근거: `feature > 완료·삭제와 실행 취소`
- Given: 상세 대상 웹 항목의 메모가 테스트 데이터의 상태 변경으로 목록에서 사라지고 실행 취소 동작이 표시되어 있다.
- When: 사용자가 실행 취소를 선택한다.
- Then: 메모가 이전 상태로 돌아가고 목록의 정렬 기준에 맞는 위치에 다시 나타난다.
- 테스트 데이터:

| 상태 변경 | 실행 취소 결과 |
| --- | --- |
| 완료 | 미완료 상태로 복구 |
| 삭제 | 미삭제 상태로 복구 |

### TC-WEB-DETAIL-MEMO-FEATURE-007: 화면 복귀 시 오늘 날짜 그룹 표시를 갱신한다

- 근거: `feature > 오늘 갱신`
- Given: WebDetail 화면을 벗어난 사이 날짜가 바뀌어 새 오늘과 이전 오늘에 시작하는 메모가 각각 있다.
- When: 사용자가 메모 탭이 선택된 WebDetail 화면으로 복귀한다.
- Then: 새 오늘에 해당하는 날짜 그룹이 오늘로 표시되고 이전 오늘의 날짜 그룹은 더 이상 오늘로 표시되지 않는다.

### TC-WEB-DETAIL-MEMO-FEATURE-008: 대상 웹 항목의 상태와 무관하게 메모 추가를 시작할 수 있다

- 근거: `feature > 메모 추가`, `domain > 메모 추가의 초기값`
- Given: 메모 탭의 상세 대상 웹 항목 상태가 테스트 데이터의 상태다.
- When: 사용자가 WebDetail 화면의 메모 탭에서 가능한 동작을 확인한다.
- Then: 메모 추가를 시작할 수 있다.
- 테스트 데이터:

| 대상 웹 항목 상태 |
| --- |
| 현재 사용자 계정과 연결되어 있고 미삭제 |
| 현재 사용자 계정과 연결되지 않음 |
| 삭제 |

### TC-WEB-DETAIL-MEMO-FEATURE-009: 메모 추가를 선택하면 MemoAdd 화면으로 이동한다

- 근거: `feature > 메모 추가`
- Given: 삭제되지 않은 웹 항목의 WebDetail 화면의 메모 탭이 표시되어 있다.
- When: 사용자가 메모 추가를 선택한다.
- Then: MemoAdd 화면으로 이동한다.

### TC-WEB-DETAIL-MEMO-FEATURE-010: 메모 추가 화면은 대상 웹 항목를 웹 입력에 초기 선택하고 시작한다

- 근거: `feature > 메모 추가의 초기 선택`, `domain > 메모 추가의 초기값`
- Given: 삭제되지 않은 웹 항목 A의 WebDetail 화면의 메모 탭이 표시되어 있다.
- When: 사용자가 메모 추가를 선택한다.
- Then: MemoAdd 화면의 웹 입력에 웹 항목 A가 선택되어 있고 태그, 연락처, 장소은 선택되지 않은 상태이며, 사용자는 저장 전까지 웹 항목 A를 해제하거나 다른 웹 항목를 더 선택할 수 있다.

### TC-WEB-DETAIL-MEMO-FEATURE-011: 삭제된 대상 웹 항목는 선택되지 않은 상태로 메모 추가를 시작한다

- 근거: `domain > 메모 추가의 초기값`
- Given: 대상 웹 항목가 삭제 상태인 WebDetail 화면의 메모 탭이 표시되어 있다.
- When: 사용자가 메모 추가를 선택한다.
- Then: MemoAdd 화면의 웹 입력에 대상 웹 항목가 선택된 것으로 표시되지 않는다.

### TC-WEB-DETAIL-MEMO-FEATURE-012: 연결된 메모가 없으면 빈 상태 안내를 표시한다

- 근거: `feature > 빈 상태`
- Given: 상세 대상 웹 항목와 연결되고 노출 기준을 만족하는 메모가 하나도 없고 목록의 준비가 끝났다.
- When: 사용자가 WebDetail 화면의 메모 탭을 확인한다.
- Then: 메모 카드 대신 이 웹 항목에 연결된 메모가 없음을 알리는 안내가 표시된다.

### TC-WEB-DETAIL-MEMO-FEATURE-013: 목록을 준비하는 동안에는 빈 상태 안내를 표시하지 않는다

- 근거: `feature > 빈 상태`
- Given: 목록에 표시된 메모가 아직 하나도 없고 목록의 준비가 끝나지 않았다.
- When: 사용자가 WebDetail 화면의 메모 탭을 확인한다.
- Then: 빈 상태 안내가 표시되지 않는다.

### TC-WEB-DETAIL-MEMO-FEATURE-014: 대상 웹 항목를 조회하지 못해도 빈 상태 안내는 같은 기준으로 표시한다

- 근거: `feature > 빈 상태`
- Given: 상세 대상 웹 항목를 조회하지 못해 화면 제목이 표시되지 않고, 연결된 메모가 하나도 없으며 목록의 준비가 끝났다.
- When: 사용자가 WebDetail 화면의 메모 탭을 확인한다.
- Then: 이 웹 항목에 연결된 메모가 없음을 알리는 안내가 표시된다.

### TC-WEB-DETAIL-MEMO-FEATURE-015: 빈 상태에서도 메모 추가를 실행할 수 있다

- 근거: `feature > 빈 상태`
- Given: WebDetail 화면의 메모 탭에 빈 상태 안내가 표시되어 있다.
- When: 사용자가 메모 추가를 선택한다.
- Then: 상세 대상 웹 항목를 초기 선택으로 하는 메모 추가 화면으로 이동한다.

### TC-WEB-DETAIL-MEMO-FEATURE-016: 메모 추가는 메모 탭에서만 제공된다

- 근거: `feature > 메모 추가`
- Given: 웹 항목가 조회된 WebDetail 화면에서 테스트 데이터의 탭이 선택되어 있다.
- When: 사용자가 화면에서 실행할 수 있는 동작을 확인한다.
- Then: 메모 추가를 실행할 수 없고, 메모 탭으로 전환하면 메모 추가를 실행할 수 있다.
- 테스트 데이터:

| 선택한 탭 |
| --- |
| 수정 폼 탭 |
| 웹 페이지 탭 |

### TC-WEB-DETAIL-MEMO-FEATURE-017: 대상 웹 항목를 조회하지 못해도 메모 목록과 동작을 제공한다

- 근거: `feature > 진입`
- Given: 상세 대상 웹 항목를 조회할 수 없고, 그 웹 항목와 연결된 미완료·미삭제 메모가 저장되어 있다.
- When: 사용자가 WebDetail 화면에서 메모 탭을 연다.
- Then: 연결된 메모가 목록에 표시되고 메모 추가를 실행할 수 있다.

### TC-WEB-DETAIL-MEMO-FEATURE-018: 메모 탭은 완료된 메모를 표시하지 않고 완료된 메모 목록 진입을 두지 않는다

- 근거: `feature > 완료된 메모`, `domain > 메모 노출과 정렬`
- Given: 상세 대상 웹 항목에 미완료 메모와 완료된 메모가 함께 연결되어 있다.
- When: 사용자가 WebDetail 화면의 메모 탭을 확인한다.
- Then: 완료된 메모는 목록에 표시되지 않고, 완료된 메모 목록으로 이동하는 동작도 제공되지 않는다.

### TC-WEB-DETAIL-MEMO-FEATURE-019: 어느 경로로 진입한 WebDetail 화면에서도 메모 탭을 제공한다

- 근거: `feature > 진입`
- Given: 테스트 데이터의 경로로 WebDetail 화면에 진입할 수 있다.
- When: 사용자가 그 경로로 WebDetail 화면에 진입한다.
- Then: 메모 탭을 선택할 수 있고 같은 웹 항목에 연결된 메모 목록이 표시된다.
- 테스트 데이터:

| 진입 경로 |
| --- |
| WebHome의 웹 목록 |
| SearchHome의 웹 결과 |
| TagDetail 웹 탭 |
| 메모의 웹 입력 |

### TC-WEB-DETAIL-MEMO-FEATURE-020: 메모 탭에서 이동한 MemoAdd와 MemoDetail 화면은 단독으로 표시한다

- 근거: `feature > 단독 표시와 돌아오기`
- Given: WebDetail 화면의 메모 탭이 표시되어 있다.
- When: 사용자가 메모 탭에서 테스트 데이터의 동작을 실행한다.
- Then: 이동한 화면이 WebDetail 화면과 함께 배치되지 않고 단독으로 표시되며, 그 화면에서는 주요 목적지의 공통 내비게이션을 제공하지 않는다.
- 테스트 데이터:

| 동작 | 이동한 화면 |
| --- | --- |
| 메모 추가 선택 | MemoAdd |
| 메모 선택 | MemoDetail |

### TC-WEB-DETAIL-MEMO-FEATURE-021: 이동한 화면에서 뒤로가면 메모 탭이 선택된 같은 웹 항목의 상세로 돌아온다

- 근거: `feature > 단독 표시와 돌아오기`
- Given: WebDetail 화면의 메모 탭에서 테스트 데이터의 화면으로 이동했다.
- When: 사용자가 그 화면에서 뒤로간다.
- Then: 메모 탭이 선택된 같은 웹 항목의 WebDetail 화면으로 돌아온다.
- 테스트 데이터:

| 이동한 화면 |
| --- |
| MemoAdd |
| MemoDetail |

- 작성하지 않는 이유: 뒤로가기로 이동한 화면을 벗어나는 요청이 한 번 발생하는 것은 자동화한다. 돌아온 WebDetail 화면에 메모 탭이 선택되어 있는 결과는 여러 화면과 전환 이력을 함께 제어해야 판정할 수 있어 현재 테스트 환경에서는 결정적으로 검증할 수 없다. 여러 화면과 전환 이력을 함께 제어할 수 있는 테스트 환경이 갖춰지면 자동화한다.

## domain

### TC-WEB-DETAIL-MEMO-DOMAIN-001: 웹 항목의 상태 변화는 연결된 메모의 노출에 영향을 주지 않는다

- 근거: `domain > 웹 항목의 상태와 노출`, `domain > 상세 대상 항목과 연결`
- Given: 현재 계정의 웹 항목와 미완료·미삭제 메모가 해제되지 않은 연결로 저장되어 있다.
- When: 웹 항목를 테스트 데이터의 변경대로 바꾼 뒤 그 웹 항목의 메모 목록을 조회한다.
- Then: 연결된 메모가 목록에 계속 포함된다.
- 테스트 데이터:

| 웹 항목 변경 |
| --- |
| 삭제 |
| 태그 연결 변경 |
| 내용 수정 |
| 웹 페이지 표시 방식 변경 |

### TC-WEB-DETAIL-MEMO-DOMAIN-002: 메모 추가의 초기 선택은 대상 웹 항목 하나뿐이다

- 근거: `domain > 메모 추가의 초기값`
- Given: 삭제되지 않은 웹 항목의 WebDetail 화면의 메모 탭이 표시되어 있다.

## 작성하지 않는 이유

메모 목록의 스크롤 위치를 다른 탭에 다녀온 뒤에도 유지하는 결과는 실제 스크롤 오프셋을 관찰해야 판정할 수 있어 현재 테스트 환경에서는 결정적으로 검증할 수 없다. 목록의 스크롤 위치를 외부에서 읽을 수 있는 테스트 환경이 갖춰지면 자동화한다.
