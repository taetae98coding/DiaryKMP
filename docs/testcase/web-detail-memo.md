# WebDetail 메모 탭 테스트 케이스

기준 스펙: [WebDetail 메모 탭 스펙](../spec/client/web-detail-memo.md)

이 문서의 `근거`가 가리키는 절 중 `feature > 진입`, `feature > 메모 추가의 초기 선택`, `feature > 단독 표시와 돌아오기`, `domain > 상세 대상`, `domain > 웹 항목의 상태와 노출`은 기준 스펙이 소유하고, 나머지 절은 [항목 상세 메모 탭 공통 스펙](../spec/client/entity-detail-memo.md)이 소유한다.

자리 표시 케이스의 `근거`가 가리키는 절은 공통 규칙을 [페이지 조회 목록의 자리 표시 스펙](../spec/client/paged-list-placeholder.md)에, 빈 상태 케이스의 `근거`가 가리키는 절은 [목록 빈 상태 스펙](../spec/client/list-empty-state.md)에, 정렬 케이스의 `근거`가 가리키는 절은 [목록 정렬 스펙](../spec/client/list-sort.md)에 위임한다.

화면 전체의 탭 전환과 선택한 탭의 유지, 웹 정보 수정과 웹 페이지 표시의 케이스는 [WebDetail 테스트 케이스](./web-detail.md)에서 다룬다. MemoAdd 화면이 초기 선택을 표시하는 케이스는 [MemoAdd 테스트 케이스](./memo-add.md)에서 다룬다.

## feature

### TC-7749dbe9-8243-4b50-a014-84f28c2e9a66: 기간 유무와 시작 날짜에 따라 메모를 나누어 표시한다

- 근거: `feature > 목록 표시`
- Given: 상세 대상 웹 항목에 기간이 없는 메모와 같은 시작 날짜의 기간이 있는 메모들이 연결되어 있다.
- When: 사용자가 WebDetail 화면에서 메모 탭을 연다.
- Then: 기간이 없는 메모는 날짜 그룹 없이 먼저 표시되고, 기간이 있는 메모들은 시작 날짜가 같은 것끼리 한 그룹으로 표시된다.

- 근거: `data > 메모 추가 결과`, `domain > 메모 추가의 초기값`
- Given: 웹 항목 A의 메모 탭에서 메모 추가를 시작했고 웹 항목 B도 선택할 수 있으며, 새 메모는 미완료·미삭제 상태다.
- When: 사용자가 테스트 데이터의 최종 선택 상태로 메모를 저장한다.
- Then: 새 메모의 웹 항목 연결이 테스트 데이터의 기대 결과로 저장되고 메모 탭 노출 결과도 그 연결을 따른다.
- 테스트 데이터:

| 저장 시점의 선택 웹 항목 | 기대 연결 | 웹 항목 A의 메모 탭 결과 |
| --- | --- | --- |
| 웹 항목 A | 웹 항목 A와 연결 | 새 메모가 나타남 |
| 웹 항목 A, 웹 항목 B | 웹 항목 A·웹 항목 B와 연결 | 새 메모가 나타남 |
| 웹 항목 B | 웹 항목 B와만 연결하고 웹 항목 A와 연결하지 않음 | 새 메모가 나타나지 않음 |
| 없음 | 어느 웹 항목과도 연결하지 않음 | 새 메모가 나타나지 않음 |

### TC-7057f8c9-004a-4fe9-b4de-f7de13059840: 탭별 조회는 서로 독립이다

- 근거: `data > 항목별 메모 조회`
- Given: 대상 웹 항목 조회가 실패하도록 제어되어 있고, 그 웹 항목과 연결된 미완료·미삭제 메모가 저장되어 있다.
- When: 사용자가 메모 탭의 목록을 확인한다.
- Then: 웹 항목 조회 실패와 무관하게 메모 목록이 노출 기준대로 조회되어 표시된다.
