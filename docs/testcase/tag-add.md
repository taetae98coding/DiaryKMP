# TagAdd 테스트 케이스

기준 스펙: [TagAdd 화면 스펙](../spec/client/tag-add.md)

이 문서에서 `domain > 추가 요청 제한`, `domain > 항목의 계정 연결`, `feature > 뒤로가기`, `feature > 작성 상태 유지`, `feature > 저장 실패`, `data > 동기화` 절은 [항목 추가 화면 공통 스펙](../spec/client/entity-add.md)이 소유한다. 나머지 케이스의 절은 기준 스펙이 소유한다.

연결 입력의 표시와 조작, 태그 선택 목록의 케이스는 [태그 연결 입력 컴포넌트 테스트 케이스](./tag-link-input.md)에서 다룬다. 이 문서에는 TagAdd 화면에서만 다른 시작 상태와 추가 결과의 케이스만 둔다.

## feature

### TC-f0a17125-7f45-48b0-9f81-8caaff3acba2: TagHome에서 태그 추가 행동을 실행하면 TagAdd 화면으로 이동한다

- 근거: `feature > 진입과 입력`
- Given: TagHome 화면이 표시되어 있다.
- When: 사용자가 태그 추가를 선택한다.
- Then: TagAdd 화면이 표시된다.

### TC-a294018e-22e5-4d8f-9992-ba8a2a01b30e: 뒤로가면 이전 화면으로 돌아간다

- 근거: `feature > 뒤로가기`
- Given: TagAdd 화면이 표시되어 있다.
- When: 사용자가 뒤로간다.
- Then: TagAdd 화면에 진입하기 전 화면으로 돌아간다.

### TC-a54f9661-82c2-4fe5-a8b0-b48a904eac4c: 추가를 실행하지 않고 화면을 떠나면 입력한 내용은 저장되지 않고 사라진다

- 근거: `feature > 태그 추가`
- Given: TagAdd 화면에서 이모지, 제목과 설명을 입력하고 연결할 태그 하나를 골랐으며 태그 추가는 실행하지 않았다.
- When: 사용자가 뒤로가 화면을 떠난 뒤 TagAdd 화면에 다시 진입한다.
- Then: 입력하는 동안과 화면을 떠난 뒤 모두 태그가 저장되지 않고, 다시 진입한 화면은 이모지, 제목과 설명이 비어 있고 고른 연결이 하나도 없다.

### TC-5c715465-e883-49f7-aa9a-8ed95e648264: 추가에 성공하면 다음 태그를 작성할 수 있는 상태로 초기화한다

- 근거: `feature > 태그 추가`

- When: 사용자가 태그 추가를 실행한다.
- Then: TagAdd 화면이 유지되고 이모지, 제목과 설명이 비워지며 다음 태그를 위한 새 무작위 컬러가 제시된다.

- Given: 계정과 연결된 태그가 여러 개 저장되어 있다.

- Then: 연결 입력에 연결 대상으로 표시되는 태그가 없다.

### TC-e0cd2aba-795d-4a3a-9505-48c1e8f508fa: 연결을 골라도 저장된 태그의 연결은 바뀌지 않는다

- When: 사용자가 태그 추가를 실행한다.
