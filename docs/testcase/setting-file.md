# SettingFile 테스트 케이스

기준 스펙: [SettingFile 화면 스펙](../spec/client/setting-file.md)

설정 화면의 `파일` 항목을 선택해 SettingFile로 이동하는 케이스는 [SettingHome 테스트 케이스](./setting-home.md)에서, 설정 목록과 함께 표시되는 상태의 뒤로가기 결과는 [Setting 목록·상세 배치 테스트 케이스](./setting-list-detail.md)에서, 고른 위치에 실제로 저장하는 케이스는 [파일 내려받기 테스트 케이스](./file-download.md)에서 다룬다.

표시 관계, 저장된 설정을 확인하기 전의 상태, 화면에 보이는 값, 뒤로가기, 저장 시점과 기기별 보관은 [기기 설정 화면 공통 스펙](../spec/client/device-setting.md)에 위임되어 있으며, 이 문서의 케이스는 SettingFile에서 관찰하는 결과를 기준으로 한다. 각 환경의 저장 영역은 공통 스펙의 `환경별 저장 영역`을 같은 저장 영역에서 확인하는 [SettingMap 테스트 케이스](./setting-map.md)가 다룬다.

## feature

### TC-283ec755-2b37-46d3-b133-b22eb704af9a: 저장된 설정을 확인하기 전이거나 읽지 못하면 위치와 동작을 표시하지 않는다

- 근거: `feature > 다운로드 위치 확인`
- Given: 다운로드 위치 설정이 테스트 데이터의 상태다.
- When: SettingFile 화면이 표시된다.
- Then: 다운로드 위치와 `기본 위치로 되돌리기`가 표시되지 않고 별도 로딩 또는 오류 상태도 표시되지 않는다.
- 테스트 데이터:

| 설정 상태 |
| --- |
| 아직 확인하지 못함 |
| 읽지 못함 |

### TC-2e3176b1-a1f4-4217-9cb9-e7141780387f: 고른 폴더가 없으면 기본 위치를 쓴다고 표시하고 되돌리기를 제공하지 않는다

- 근거: `feature > 다운로드 위치 확인`, `feature > 기본 위치로 되돌리기`
- Given: 사용자 언어가 한국어이고, 고른 폴더가 없다.
- When: SettingFile 화면이 표시된다.
- Then: `기본 위치`와 플랫폼의 기본 위치 설명이 표시되고 `기본 위치로 되돌리기`는 표시되지 않는다.

### TC-0d5074c9-38b9-433a-aa49-7b74fe270e88: 고른 폴더가 있으면 그 폴더와 되돌리기를 표시한다

- 근거: `feature > 다운로드 위치 확인`, `feature > 기본 위치로 되돌리기`
- Given: 사용자 언어가 한국어이고, 고를 때 시스템이 `Documents`라고 알려 준 폴더를 골라 두었다.
- When: SettingFile 화면이 표시된다.
- Then: `Documents`와 `기본 위치로 되돌리기`가 표시된다.

### TC-b06cf4e1-aa8a-40f1-b29b-bd81ba582ae5: 시스템이 이름을 알려 주지 않은 폴더는 이름 없이 고른 폴더로 표시한다

- 근거: `feature > 다운로드 위치 확인`
- Given: 사용자 언어가 한국어이고, 고를 때 시스템이 이름을 알려 주지 않은 폴더를 골라 두었다.
- When: SettingFile 화면이 표시된다.
- Then: 위치 자리에 `고른 폴더`가 표시되고 `기본 위치`는 표시되지 않는다.

### TC-54007111-1d12-4faf-89ae-1c4c34ad4b10: 데스크톱 앱에서는 고른 폴더의 전체 경로도 보여 준다

- 근거: `feature > 다운로드 위치 확인`
- Given: 데스크톱 앱에서 `/Users/user/Documents` 폴더를 골라 두었다.
- When: 고른 폴더의 보조 표시를 정한다.
- Then: 보조 표시가 `/Users/user/Documents` 전체 경로다.

### TC-792f8c12-646b-4778-b076-60d8c401f617: 현재 위치를 선택하면 폴더 선택 도구를 연다

- 근거: `feature > 폴더 고르기`
- Given: 위치가 표시되어 있다.
- When: 사용자가 표시된 현재 위치를 선택한다.
- Then: 폴더 선택 도구를 여는 동작이 한 번 실행된다.

### TC-85a21962-0120-4bf2-aa08-6d061c10d516: 폴더를 고르면 곧바로 저장되고 위치가 바뀐다

- 근거: `feature > 폴더 고르기`, `data > 저장 시점과 유지`, `data > 폴더를 쓸 수 있는 허락`
- Given: 고른 폴더가 없고, 폴더를 계속 쓸 수 있도록 시스템이 허락하며 저장에 성공한다.
- When: 사용자가 폴더 선택 도구에서 `Music` 폴더를 고른다.
- Then: `Music` 폴더를 계속 쓸 수 있는 허락을 받아 다운로드 위치 설정으로 저장하고, 앞서 고른 폴더가 있었으면 그 허락을 돌려주며, 화면의 위치가 `Music`으로 바뀌고 `기본 위치로 되돌리기`가 표시된다.

### TC-5a7c116a-9f0a-4126-9c26-1624c7a91034: 폴더를 고르지 않고 선택 도구를 닫으면 설정이 바뀌지 않는다

- 근거: `feature > 폴더 고르기`
- Given: `Documents` 폴더를 골라 두었다.
- When: 사용자가 폴더 선택 도구를 열었다가 폴더를 고르지 않고 닫는다.
- Then: 설정을 저장하지 않고, 화면의 위치는 `Documents` 그대로다.

### TC-41fd402c-68d3-4b41-9366-c2f9bb19d9ca: 폴더를 쓰도록 허락받지 못하거나 저장에 실패하면 알리고 설정을 바꾸지 않는다

- 근거: `feature > 폴더 고르기`
- Given: 사용자 언어가 한국어이고, `Documents` 폴더를 골라 두었으며, 테스트 데이터의 상황이다.
- When: 사용자가 폴더 선택 도구에서 `Music` 폴더를 고른다.
- Then: `다운로드 위치를 바꾸지 못했습니다.`가 표시되고, 화면의 위치는 `Documents` 그대로다.
- 테스트 데이터:

| 상황 |
| --- |
| 고른 폴더를 계속 쓸 수 있도록 시스템이 허락하지 않는다 |
| 설정 저장에 실패한다 |

### TC-cef9e1ad-cca8-4668-b96c-e2124fbc09d7: 기본 위치로 되돌리면 고른 폴더를 지우고 기본 위치를 표시한다

- 근거: `feature > 기본 위치로 되돌리기`
- Given: `Documents` 폴더를 골라 두었고, 저장에 성공한다.
- When: 사용자가 `기본 위치로 되돌리기`를 선택한다.
- Then: 고른 폴더가 없는 설정이 저장되고, 화면에 `기본 위치`가 표시되며 `기본 위치로 되돌리기`가 사라진다.

### TC-3a05cdca-74ef-4bb0-8d41-247f33ec83d2: 되돌리기에 실패하면 알리고 고른 폴더를 그대로 둔다

- 근거: `feature > 기본 위치로 되돌리기`
- Given: 사용자 언어가 한국어이고, `Documents` 폴더를 골라 두었으며, 저장에 실패한다.
- When: 사용자가 `기본 위치로 되돌리기`를 선택한다.
- Then: `다운로드 위치를 바꾸지 못했습니다.`가 표시되고, 화면의 위치는 `Documents` 그대로다.

## domain

### TC-26317d55-0959-4669-8b2c-7aa6a2df9b2c: 저장하는 동안에는 폴더 고르기와 되돌리기를 다시 처리하지 않는다

- 근거: `domain > 요청 제한`
- Given: `Documents` 폴더를 골라 두었고, 설정 저장이 아직 끝나지 않는다.
- When: 사용자가 `기본 위치로 되돌리기`를 선택한 뒤 다시 선택한다.
- Then: 설정 저장은 한 번만 일어난다.

### TC-4a16856d-4ec7-44bf-a4bf-d11d437a63b5: 선택 도구가 열린 동안 화면이 다시 만들어지면 고른 폴더를 다시 만들어진 화면에서 저장한다

- 근거: `domain > 요청 제한`
- Given: Android에서 폴더 선택 도구가 열려 있다.
- When: 화면이 다시 만들어진 뒤 사용자가 `Music` 폴더를 고른다.
- Then: 다시 만들어진 화면이 `Music` 폴더를 받아 다운로드 위치 설정으로 저장한다.

## data

### TC-786bc68f-5f47-40d0-975b-a7463878d6d4: 저장한 설정은 앱을 다시 실행해도 유지된다

- 근거: `data > 저장 시점과 유지`
- Given: `Music` 폴더를 다운로드 위치로 저장했다.
- When: 앱을 종료하고 다시 실행한 뒤 다운로드 위치 설정을 읽는다.
- Then: `Music` 폴더를 고른 설정을 읽는다.

### TC-76624134-bce5-4b1e-83e1-e02281c9ffed: 한 번도 고르지 않았으면 고른 폴더가 없는 설정을 읽는다

- 근거: `data > 저장 시점과 유지`, `domain > 다운로드 위치 설정`
- Given: 다운로드 위치를 한 번도 저장하지 않았다.
- When: 다운로드 위치 설정을 읽는다.
- Then: 고른 폴더가 없는 설정을 읽는다.

### TC-89660e14-4b3d-4a19-bb56-7b5f27a5b744: 되돌린 뒤에는 고른 폴더가 없는 설정을 읽는다

- 근거: `data > 저장 시점과 유지`
- Given: `Music` 폴더를 저장한 뒤 기본 위치로 되돌렸다.
- When: 다운로드 위치 설정을 읽는다.
- Then: 고른 폴더가 없는 설정을 읽는다.

### TC-2f29a22e-d3a9-4e80-8e50-2b477d7e10e6: 저장된 값을 읽을 수 없으면 확인하지 못한 상태로 다룬다

- 근거: `data > 저장 시점과 유지`
- Given: 기기에 저장한 설정을 읽는 데 실패한다.
- When: 다운로드 위치 설정을 읽는다.
- Then: 고른 폴더가 없는 설정이 아니라 설정을 확인하지 못한 상태가 된다.

### TC-c0abc709-36cb-43ca-b469-ef51782ceeec: 로그인과 계정이 바뀌어도 설정은 그대로다

- 근거: `data > 기기별 보관`
- Given: `Music` 폴더를 다운로드 위치로 저장했다.
- When: 사용자가 로그아웃하거나 다른 계정으로 로그인한다.
- Then: 다운로드 위치 설정은 `Music` 폴더 그대로이고, 서버에 보내지 않는다.
- 작성하지 않는 이유: 설정은 계정과 연결되지 않은 기기 저장 영역에만 있어, 계정 전환이 설정에 아무 일도 하지 않는다는 것은 관찰할 경계가 없다. 자동화하려면 로그인부터 설정 화면까지 실제 앱을 거치는 통합 테스트 환경이 필요하다.

### TC-802762da-b246-444b-8ab9-e9e5e39f3e4f: 기본 위치로 되돌려도 고른 폴더와 그 안의 파일을 지우지 않는다

- 근거: `feature > 기본 위치로 되돌리기`, `data > 폴더를 쓸 수 있는 허락`
- Given: `Music` 폴더를 다운로드 위치로 저장했고 그 폴더에 내려받은 파일이 있다.
- When: 사용자가 기본 위치로 되돌린다.
- Then: 고른 폴더가 없는 설정을 저장하고 폴더를 쓰도록 받은 허락만 돌려주며, 폴더와 그 안의 파일을 지우는 요청은 보내지 않는다.
