# Profile 테스트 케이스

기준 스펙: [Profile 화면 스펙](../spec/client/profile.md)

탈퇴 확인, Apple 재인증, 탈퇴 처리의 케이스는 [계정 탈퇴 테스트 케이스](./account-deletion.md)가 갖는다.

## feature

### TC-9f7b2656-4323-4665-97f8-2b3338e46146: 프로필 이미지 변경과 탈퇴하기 두 동작을 표시한다

- 근거: `feature > 화면 내용`
- Given: 사용자 상태에서 Profile 화면에 진입한다.
- When: 사용자가 화면을 확인한다.
- Then: `프로필 이미지 변경`과 `탈퇴하기`가 이 순서로 표시되고 둘 다 선택할 수 있으며, 불러오는 중이나 오류 표시는 없다.

### TC-34878f0f-1805-494b-8498-6d8e3ef35e3a: 프로필 이미지 변경을 선택하면 ProfileImageEdit 화면으로 이동한다

- 근거: `feature > 프로필 이미지 변경`
- Given: Profile 화면이 표시되어 있다.
- When: 사용자가 `프로필 이미지 변경`을 선택한다.
- Then: ProfileImageEdit 화면으로 이동하는 동작이 한 번 실행된다.

### TC-7f3778a6-b045-4310-af80-c458ac781bcd: 탈퇴가 진행 중이면 두 동작을 실행할 수 없다

- 근거: `feature > 탈퇴하기`
- Given: Profile 화면에서 탈퇴가 진행 중이며, 서버 응답이 오지 않도록 제어되어 있다.
- When: 사용자가 `프로필 이미지 변경`과 `탈퇴하기`를 차례로 누른다.
- Then: ProfileImageEdit 화면으로 이동하지 않고, 탈퇴 요청은 처음 한 번만 이루어진다.

### TC-f6c0e0be-4d94-4ca3-91e1-fcce03c712c0: 뒤로가면 MoreHome 화면으로 돌아간다

- 근거: `feature > 뒤로가기`
- Given: Profile 화면이 표시되어 있다.
- When: 사용자가 뒤로가기를 실행한다.
- Then: 이전 화면으로 돌아가는 동작이 한 번 실행된다.

## domain

### TC-135005f9-705b-4f5f-9663-76b1c2abb1da: 화면을 보는 동안 계정이 게스트가 되면 화면을 닫는다

- 근거: `domain > 계정 상태가 바뀔 때`
- Given: 사용자 상태에서 Profile 화면이 표시되어 있다.
- When: 저장된 사용자 정보가 사라져 계정 상태가 게스트로 바뀐다.
- Then: Profile 화면을 닫고 이전 화면으로 돌아가는 동작이 한 번 실행된다.

### TC-39cad1b0-fe53-4dc0-b394-b2d34e99ad42: 세션 갱신 여부만 바뀌거나 계정을 잠시 확인하지 못하면 화면을 닫지 않는다

- 근거: `domain > 계정 상태가 바뀔 때`
- Given: 사용자 상태에서 Profile 화면이 표시되어 있다.
- When: 계정 정보가 테스트 데이터처럼 바뀐다.
- Then: Profile 화면을 닫는 동작이 실행되지 않고 두 동작이 그대로 표시된다.
- 테스트 데이터:

| 바뀐 계정 정보 |
| --- |
| 같은 사용자의 세션이 갱신되지 않은 상태로 바뀜 |
| 계정 정보 확인에 실패함 |

### TC-175fa603-3a0b-42ce-ada7-cfded5b754e1: 화면이 재생성되어도 Profile 화면에 머문다

- 근거: `domain > 실행 경계`
- Given: Profile 화면이 표시되어 있다.
- When: 화면이 회전하거나 시스템에 의해 재생성된다.
- Then: Profile 화면이 다시 표시되고 두 동작이 그대로 표시된다.
- 작성하지 않는 이유: 화면 이동 기록을 복원하는 것은 앱 전체의 내비게이션이 보장하는 결과라 이 화면 하나의 테스트로는 판정할 수 없다. 여러 화면의 이동 기록을 복원하는 앱 수준 화면 테스트 환경이 마련되면 작성한다.
