# 메모 웹 테스트 케이스

기준 스펙: [메모 웹 스펙](../spec/memo-web.md)

이 문서에서 `data > 공유되는 연결`, `data > 내려받기 순서와 표시`, `data > 동기화`, `data > 연결의 저장`, `domain > 연결된 항목의 조회`, `domain > 연결의 상태와 시각`, `domain > 연결의 의미`, `domain > 항목의 상태 변화와 연결` 절은 [항목 연결 공통 스펙](../spec/entity-link.md)이 소유한다. 나머지 케이스의 절은 기준 스펙이 소유한다.

사용자가 웹 항목을 고르고 해제하는 조작의 케이스는 [메모 웹 입력 컴포넌트 테스트 케이스](./memo-web-input.md)에서, 메모를 추가하면서 웹 항목을 연결하는 케이스는 [MemoAdd 테스트 케이스](./memo-add.md)에서, 저장된 메모의 웹 연결을 바꾸는 케이스는 [MemoDetail 테스트 케이스](./memo-detail.md)에서 다룬다.

## domain

### TC-MEMO-WEB-DOMAIN-001: 하나의 메모에 여러 웹 항목을 연결할 수 있다

- 근거: `domain > 메모와 웹 항목의 연결`
- Given: 계정과 연결된 웹 항목 여러 개와 새로 추가할 메모가 준비되어 있다.
- When: 그 웹 항목 전체를 연결한 메모를 저장한다.
- Then: 저장한 메모에 연결된 웹 항목을 조회하면 연결한 웹 항목 전체가 조회된다.

### TC-MEMO-WEB-DOMAIN-002: 하나의 웹 항목을 여러 메모에 연결할 수 있다

- 근거: `domain > 메모와 웹 항목의 연결`
- Given: 계정과 연결된 웹 항목 하나와 새로 추가할 메모 두 개가 준비되어 있다.
- When: 두 메모를 각각 같은 웹 항목과 연결해 저장한다.
- Then: 두 메모 모두 그 웹 항목과 연결된 상태로 조회되고, 한 메모의 연결이 다른 메모의 연결을 대체하지 않는다.

### TC-MEMO-WEB-DOMAIN-003: 같은 메모와 웹 항목의 연결은 중복되지 않는다

- 근거: `domain > 메모와 웹 항목의 연결`
- Given: 한 메모와 한 웹 항목이 이미 연결되어 저장되어 있다.
- When: 같은 메모와 같은 웹 항목의 연결을 다시 저장한다.
- Then: 그 메모와 웹 항목의 연결은 하나로 유지되고 연결이 두 건으로 늘어나지 않는다.

### TC-MEMO-WEB-DOMAIN-004: 연결된 웹 항목이 없는 메모도 저장된다

- 근거: `domain > 메모와 웹 항목의 연결`
- Given: 연결할 웹 항목을 지정하지 않은 새 메모가 준비되어 있다.
- When: 그 메모를 저장한다.
- Then: 메모가 실패 없이 저장되고, 그 메모에 연결된 웹 항목을 조회하면 아무것도 조회되지 않는다.

### TC-MEMO-WEB-DOMAIN-005: 웹 항목을 삭제해도 메모와의 연결이 유지된다

- 근거: `domain > 항목의 상태 변화와 연결`
- Given: 한 웹 항목과 한 메모가 연결되어 저장되어 있다.
- When: 그 웹 항목을 삭제된 상태로 바꾼다.
- Then: 그 메모와 웹 항목의 연결은 해제되지 않고 그대로 남는다.

### TC-MEMO-WEB-DOMAIN-006: 메모를 완료하거나 삭제해도 웹 항목과의 연결이 유지된다

- 근거: `domain > 항목의 상태 변화와 연결`
- Given: 한 메모와 한 웹 항목이 연결되어 저장되어 있다.
- When: 그 메모를 테스트 데이터의 상태로 바꾼다.
- Then: 그 메모와 웹 항목의 연결은 해제되지 않고 그대로 남는다.
- 테스트 데이터:

| 메모 상태 변경 |
| --- |
| 완료 |
| 삭제 |

### TC-MEMO-WEB-DOMAIN-007: 메모나 웹 항목의 내용 수정은 연결을 바꾸지 않는다

- 근거: `domain > 항목의 상태 변화와 연결`
- Given: 웹 항목이 연결된 메모가 저장되어 있다.
- When: 테스트 데이터의 대상을 다른 내용으로 수정한다.
- Then: 수정한 내용은 반영되고 그 메모에 연결된 웹 항목은 수정 전과 같다.
- 테스트 데이터:

| 수정 대상 |
| --- |
| 메모의 제목·설명·컬러·기간 |
| 웹 항목의 제목·설명·URL·요청 헤더 |

### TC-MEMO-WEB-DOMAIN-008: 기기에서 연결을 해제하면 해제 상태로 남는다

- 근거: `domain > 연결의 상태와 시각`
- Given: 한 메모와 한 웹 항목이 연결되어 저장되어 있다.
- When: 그 메모와 웹 항목의 연결을 해제한다.
- Then: 그 웹 항목은 메모에 연결된 웹 항목으로 조회되지 않지만, 연결은 저장소에서 사라지지 않고 해제 상태로 남으며 수정 시각이 해제 시점으로 갱신된다.

### TC-MEMO-WEB-DOMAIN-009: 해제된 연결을 다시 만들면 기존 연결이 되살아난다

- 근거: `domain > 연결의 상태와 시각`
- Given: 한 메모와 한 웹 항목의 연결이 해제 상태로 저장되어 있다.
- When: 같은 메모와 웹 항목의 연결을 다시 만든다.
- Then: 그 메모와 웹 항목의 연결이 하나로 유지된 채 연결된 상태로 조회되고, 연결의 수정 시각이 다시 만든 시점으로 갱신된다.

### TC-MEMO-WEB-DOMAIN-010: 삭제된 웹 항목은 메모의 연결된 웹 항목 조회에서 빠진다

- 근거: `domain > 연결된 항목의 조회`
- Given: 한 메모에 삭제되지 않은 웹 항목과 삭제된 웹 항목이 각각 해제되지 않은 연결로 연결되어 있다.
- When: 그 메모에 연결된 웹 항목을 조회한다.
- Then: 삭제되지 않은 웹 항목만 조회되고 삭제된 웹 항목은 조회되지 않는다.

### TC-MEMO-WEB-DOMAIN-011: 연결된 웹 항목은 제목 오름차순으로 조회된다

- 근거: `domain > 연결된 웹 항목의 정렬`
- Given: 한 메모에 제목이 서로 다른 웹 항목 여러 개가 연결되어 있다.
- When: 그 메모에 연결된 웹 항목을 조회한다.
- Then: 조회 결과가 제목 오름차순으로 놓인다.

### TC-MEMO-WEB-DOMAIN-012: 웹 연결은 메모 목록의 노출과 순서를 바꾸지 않는다

- 근거: `domain > 연결의 의미`
- Given: 같은 노출 기준을 만족하는 메모 두 개가 있고 한쪽만 웹 항목과 연결되어 있다.
- When: 메모 목록을 조회한다.
- Then: 두 메모가 모두 노출되고 순서가 웹 연결 여부로 달라지지 않는다.

### TC-MEMO-WEB-DOMAIN-013: 웹 연결은 웹 목록의 노출과 순서를 바꾸지 않는다

- 근거: `domain > 연결의 의미`
- Given: 계정과 연결된 웹 항목 두 개가 있고 한쪽만 메모와 연결되어 있다.
- When: 웹 목록을 조회한다.
- Then: 두 웹 항목이 모두 노출되고 순서가 메모 연결 여부로 달라지지 않는다.

### TC-MEMO-WEB-DOMAIN-014: 웹 연결은 태그로 조회한 결과를 바꾸지 않는다

- 근거: `domain > 연결의 의미`
- Given: 태그와 연결되지 않은 메모가 태그와 연결된 웹 항목 하나와 연결되어 있다.
- When: 그 태그로 메모를 조회한다.
- Then: 그 메모는 조회되지 않는다.

## data

### TC-MEMO-WEB-DATA-001: 연결에는 만든 시점이 생성 시각과 수정 시각으로 함께 기록된다

- 근거: `domain > 연결의 상태와 시각`, `data > 연결의 저장`
- Given: 계정과 연결된 웹 항목을 선택해 새 메모를 추가할 수 있다.
- When: 그 웹 항목을 연결한 메모를 저장한다.
- Then: 저장된 연결의 생성 시각과 수정 시각이 저장을 실행한 시점으로 서로 같게 기록되고, 연결은 해제되지 않은 상태다.

### TC-MEMO-WEB-DATA-002: 메모와 계정 연결, 태그 연결, 웹 연결, 장소 연결이 하나의 저장 작업으로 반영된다

- 근거: `data > 연결의 저장`
- Given: 계정과 연결된 태그, 웹 항목, 장소를 선택한 새 메모의 저장이 진행되는 중 저장 작업이 실패하도록 제어되어 있다.
- When: 그 메모의 저장을 실행한다.
- Then: 메모, 계정과의 연결, 태그와의 연결, 웹 항목과의 연결, 장소와의 연결 가운데 어느 것도 기기에 남지 않는다.

### TC-MEMO-WEB-DATA-003: 같은 메모와 웹 항목의 연결을 다시 저장하면 덮어쓴다

- 근거: `data > 연결의 저장`
- Given: 한 메모와 한 웹 항목의 연결이 저장되어 있다.
- When: 같은 메모와 웹 항목의 연결을 다른 수정 시각으로 다시 저장한다.
- Then: 연결은 한 건으로 유지되고 나중에 저장한 내용으로 조회된다.

### TC-MEMO-WEB-DATA-004: 해제되지 않은 연결의 웹 항목만 메모의 웹 항목으로 조회된다

- 근거: `data > 메모별 웹 항목 표시`
- Given: 한 메모가 해제되지 않은 연결의 웹 항목과 해제된 연결의 웹 항목을 함께 가지고 있다.
- When: 그 메모에 연결된 웹 항목을 조회한다.
- Then: 해제되지 않은 연결의 웹 항목만 조회되고 해제된 연결의 웹 항목은 조회되지 않는다.

### TC-MEMO-WEB-DATA-005: 저장된 연결은 업로드 대기 상태가 된다

- 근거: `data > 공유되는 연결`, `data > 동기화`
- Given: 로그인한 계정이 있고 계정과 연결된 웹 항목을 선택해 새 메모를 추가할 수 있다.
- When: 그 웹 항목을 연결한 메모를 저장한다.
- Then: 그 계정의 메모와 웹 항목 연결이 업로드 대기 항목으로 조회된다.

### TC-MEMO-WEB-DATA-006: 연결은 메모·웹 항목과 구분되는 종류로 업로드된다

- 근거: `data > 동기화`
- Given: 로그인한 계정에 업로드 대기 상태인 메모와 웹 항목의 연결이 있다.
- When: 동기화의 업로드 단계가 진행된다.
- Then: 연결은 메모 업로드 요청이나 웹 항목 업로드 요청이 아니라 메모·웹 연결 전용 업로드 요청에 담겨 전달된다.

### TC-MEMO-WEB-DATA-007: 해제된 연결도 해제 상태로 업로드된다

- 근거: `data > 동기화`
- Given: 해제 상태인 메모와 웹 항목의 연결이 업로드 대기 상태다.
- When: 동기화의 업로드 단계가 진행된다.
- Then: 서버로 보내는 연결 항목에 해제 상태가 함께 담기고, 그 항목이 업로드 대상에서 빠지지 않는다.

### TC-MEMO-WEB-DATA-008: 내려받은 연결이 기기에 반영된다

- 근거: `data > 동기화`
- Given: 서버가 메모와 웹 항목의 연결 항목을 응답하도록 제어되어 있고, 그 연결의 서버 수정 시각이 기기보다 늦다.
- When: 동기화의 메모·웹 연결 내려받기가 진행된다.
- Then: 기기에 그 연결이 응답 내용대로 저장되고, 그 종류의 내려받기 위치가 응답의 가장 큰 순번으로 갱신된다.

### TC-MEMO-WEB-DATA-009: 가리키는 메모나 웹 항목이 기기에 없는 연결은 메모별 웹 조회에 나타나지 않는다

- 근거: `data > 내려받기 순서와 표시`
- Given: 기기에 저장되어 있지 않은 메모나 웹 항목을 가리키는 연결이 준비되어 있다.
- When: 그 연결을 기기에 저장한 뒤 연결이 가리키는 메모의 웹 항목을 조회한다.
- Then: 연결은 실패 없이 저장되지만 메모별 웹 항목 조회 결과에는 나타나지 않는다.

### TC-MEMO-WEB-DATA-010: 연결을 하나씩 만들거나 해제하면 그 연결만 업로드 대기가 된다

- 근거: `data > 연결의 저장`, `data > 공유되는 연결`
- Given: 로그인한 계정의 한 메모에 여러 웹 항목이 연결되어 있고 모두 동기화 완료 상태다.
- When: 그 메모의 웹 연결 하나만 해제한다.
- Then: 해제한 연결만 업로드 대기 항목으로 조회되고 같은 메모의 다른 웹 연결은 동기화 완료 상태로 유지된다.

### TC-MEMO-WEB-DATA-011: 계정과 연결되지 않은 메모나 웹 항목의 연결 업로드는 반영되지 않는다

- 근거: `data > 동기화`
- Given: 업로드하는 계정과 연결되어 있지 않은 메모 또는 웹 항목을 가리키는 연결이 업로드 대기 상태다.
- When: 그 연결을 서버에 업로드한다.
- Then: 서버에 그 연결이 반영되지 않고 업로드 요청이 실패로 처리된다.
- 작성하지 않는 이유: 서버 저장소의 연결 검증 규칙이어서 앱의 단위 테스트 환경에서 결정적으로 판정할 수 없다. 서버 정책 테스트 환경이 마련되면 작성한다.
