# MemoFinishedList 목록·상세 배치 테스트 케이스

기준 스펙: [MemoFinishedList 목록·상세 배치 스펙](../spec/client/memo-finished-list-detail.md)

MemoHome 목록에서 진입한 메모 상세와 메모 추가의 배치 케이스는 [Memo 목록·상세 배치 테스트 케이스](./memo-list-detail.md)에서 다룬다. 목록과 함께 표시하는 동안 상세 영역의 메모 상세 화면에 목록으로 돌아가는 동작이 없다는 결과는 같은 화면을 대상으로 한 [Memo 목록·상세 배치 테스트 케이스](./memo-list-detail.md)의 TC-3176086c-a211-477a-a6c6-7bb1a3ee511b가, 상세 화면 하나에서 다시 시작 뒤 수정 중이던 내용이 유지되는 결과는 [MemoDetail 화면 테스트 케이스](./memo-detail.md)가 다루고, 이 문서는 그 결과가 목록과 상세 영역에 함께 나타나는 것을 다룬다.
