# ContactDetail 메모 탭 테스트 케이스

기준 스펙: [ContactDetail 메모 탭 스펙](../spec/client/contact-detail-memo.md)

이 문서의 `근거`가 가리키는 절 중 `feature > 진입`, `feature > 메모 추가의 초기 선택`, `feature > 단독 표시와 돌아오기`, `domain > 상세 대상`, `domain > 연락처의 상태와 노출`은 기준 스펙이 소유하고, 나머지 절은 [항목 상세 메모 탭 공통 스펙](../spec/client/entity-detail-memo.md)이 소유한다.

자리 표시 케이스의 `근거`가 가리키는 절은 공통 규칙을 [페이지 조회 목록의 자리 표시 스펙](../spec/client/paged-list-placeholder.md)에, 빈 상태 케이스의 `근거`가 가리키는 절은 [목록 빈 상태 스펙](../spec/client/list-empty-state.md)에, 정렬 케이스의 `근거`가 가리키는 절은 [목록 정렬 스펙](../spec/client/list-sort.md)에 위임한다.

`domain > 진행 상태 유지` 가운데 다른 탭에 다녀온 뒤의 목록 위치 유지는 [ContactDetail 테스트 케이스](./contact-detail.md)의 `TC-ef7f75d7-17b5-4ed2-94dc-bfd8c64c1141`가 다룬다.

화면 전체의 탭 전환과 선택한 탭의 유지, 연락처 디테일 탭의 케이스는 [ContactDetail 테스트 케이스](./contact-detail.md)에서 다룬다. MemoAdd 화면이 초기 선택을 표시하는 케이스는 [MemoAdd 테스트 케이스](./memo-add.md)에서 다룬다.

## feature

- 근거: `feature > 목록 표시`
- Given: 상세 대상 연락처에 기간이 없는 메모와 같은 시작 날짜의 기간이 있는 메모들이 연결되어 있다.
- When: 사용자가 ContactDetail 화면에서 메모 탭을 연다.
- Then: 기간이 없는 메모는 날짜 그룹 없이 먼저 표시되고, 기간이 있는 메모들은 시작 날짜가 같은 것끼리 한 그룹으로 표시된다.
