# ProfileImageViewer 테스트 케이스

기준 스펙: [ProfileImageViewer 화면 스펙](../spec/client/profile-image-viewer.md)

## feature

### TC-1feffbd6-0df1-40e2-87d6-b5fde7a246a7: 진입할 때 받은 프로필 이미지를 보여 준다

- 근거: `feature > 진입`
- Given: 프로필 이미지 `https://example.com/a.jpg`로 ProfileImageViewer 화면에 진입한다.
- When: 화면이 이미지를 불러온다.
- Then: `https://example.com/a.jpg`의 이미지를 불러오는 요청이 이루어진다.

### TC-a724a3c7-9cb9-475b-989a-04940800a478: 불러오는 동안, 성공, 실패에 따라 표시가 달라진다

- 근거: `feature > 이미지 표시`
- Given: ProfileImageViewer 화면에 진입했고, 이미지 불러오기 결과가 테스트 데이터처럼 제어되어 있다.
- When: 사용자가 화면을 확인한다.
- Then: 테스트 데이터의 표시가 보인다.
- 테스트 데이터:

| 불러오기 결과 | 표시 |
| --- | --- |
| 아직 끝나지 않음 | 불러오는 중 표시, 이미지와 실패 문구는 없음 |
| 성공 | `프로필 이미지` 이미지, 불러오는 중 표시와 실패 문구는 없음 |
| 실패 | `이미지를 불러올 수 없습니다.` 문구, 이미지와 불러오는 중 표시는 없음 |

### TC-c7dd899a-09ff-420b-8fba-ac6c152efb1d: 뒤로가면 MoreHome 화면으로 돌아간다

- 근거: `feature > 뒤로가기`
- Given: ProfileImageViewer 화면이 표시되어 있다.
- When: 사용자가 뒤로가기를 실행한다.
- Then: 이전 화면으로 돌아가는 동작이 한 번 실행된다.

## domain

### TC-78ce52be-ad6e-4fa6-bb36-908fd2b5934b: 배율은 처음 배율과 그 5배 사이로 제한된다

- 근거: `domain > 확대 범위`
- Given: 처음 배율이 1인 상태다.
- When: 테스트 데이터의 배율로 확대·축소를 요청한다.
- Then: 적용되는 배율은 테스트 데이터의 결과다.
- 테스트 데이터:

| 요청한 배율 | 적용되는 배율 |
| --- | --- |
| 0.5 | 1 |
| 1 | 1 |
| 3 | 3 |
| 5 | 5 |
| 8 | 5 |

### TC-fe533a3c-3347-477d-8c06-2f167c4887ac: 확대한 이미지는 가장자리가 화면 안쪽으로 들어오지 않는 범위에서만 움직인다

- 근거: `domain > 확대 범위`
- Given: 화면과 같은 크기로 맞춘 이미지를 2배로 확대해 가운데에 두었다.
- When: 테스트 데이터의 거리만큼 이미지를 움직인다.
- Then: 이미지는 테스트 데이터의 위치에 놓인다.
- 테스트 데이터:

| 움직인 거리 | 놓이는 위치 |
| --- | --- |
| 화면 폭의 4분의 1만큼 오른쪽 | 화면 폭의 4분의 1만큼 오른쪽 |
| 화면 폭만큼 오른쪽 | 이미지 왼쪽 가장자리가 화면 왼쪽 가장자리에 닿는 위치 |
| 화면 폭만큼 왼쪽 | 이미지 오른쪽 가장자리가 화면 오른쪽 가장자리에 닿는 위치 |

### TC-2eca51bf-4b7e-46bc-83a5-82737e668b11: 이미지가 화면보다 작은 방향으로는 움직이지 않는다

- 근거: `domain > 확대 범위`
- Given: 화면보다 세로가 짧은 가로로 긴 이미지를 처음 배율로 두었다.
- When: 이미지를 위아래로 움직인다.
- Then: 이미지는 세로 가운데에 머문다.

### TC-01f222b8-7b37-4983-8aff-712da3961761: 불러오는 중이거나 불러오지 못한 동안에는 확대할 수 없다

- 근거: `feature > 확대와 이동`
- Given: 이미지 불러오기가 테스트 데이터의 상태로 제어되어 있다.
- When: 사용자가 이미지 영역에서 확대 조작을 한다.
- Then: 화면이 확대되지 않는다.
- 테스트 데이터:

| 불러오기 상태 |
| --- |
| 아직 끝나지 않음 |
| 실패 |

- 작성하지 않는 이유: 확대 여부는 그려진 배율로만 드러나고 화면 요소의 정보로 노출되지 않아 시각 판단이 필요하다. 배율을 화면 요소의 정보로 드러내거나 화면을 캡처해 비교하는 테스트 환경이 갖춰지면 작성한다.

### TC-164b3d51-86fc-4506-bafa-041bacfe3dfe: 계정이 게스트가 되어도 화면을 닫지 않는다

- 근거: `domain > 계정 상태가 바뀔 때`
- Given: ProfileImageViewer 화면이 이미지를 표시하고 있다.
- When: 계정 상태가 게스트로 바뀐다.
- Then: 화면을 닫는 동작이 실행되지 않고 이미지가 그대로 표시된다.
- 작성하지 않는 이유: 화면 하나의 테스트로는 이 화면을 보는 동안 계정 상태가 바뀌는 상황과 그에 따른 화면 이동 여부를 함께 만들고 관찰할 수 없다. 계정 상태와 화면 이동 기록을 함께 다루는 앱 수준 화면 테스트 환경이 마련되면 작성한다.

### TC-7db52307-a554-4264-8902-45ff770f4bfe: 화면이 재생성되면 이미지는 유지하고 배율은 처음 상태로 돌아간다

- 근거: `domain > 실행 경계`
- Given: 프로필 이미지 `https://example.com/a.jpg`를 표시하는 화면에서 이미지를 확대해 두었다.
- When: 화면이 재생성된다.
- Then: `https://example.com/a.jpg`의 이미지가 처음 배율로 표시된다.
- 작성하지 않는 이유: 이미지 주소를 유지하는 것은 자동화한다. 배율이 처음 상태로 돌아갔는지는 그려진 배율로만 드러나 시각 판단이 필요하다. 배율을 화면 요소의 정보로 드러내는 테스트 환경이 갖춰지면 배율까지 판정한다.
