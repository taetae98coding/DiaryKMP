# Routine 목록·상세 배치 테스트 케이스

기준 스펙: [Routine 목록·상세 배치 스펙](../spec/client/routine-list-detail.md)

이 문서에서 `domain > 배치에 참여하는 화면`, `feature > 추가 진입 수단`, `feature > 함께 사용과 단독 사용`, `feature > 함께 사용할 때의 행동` 절은 [목록·상세 배치 공통 스펙](../spec/client/list-detail-pane.md)이 소유한다. 나머지 케이스의 절은 기준 스펙이 소유한다.

표시 비율 조절의 공통 행동과 유지 기준은 [목록·상세 배치 공통 스펙](../spec/client/list-detail-pane.md)에 위임되어 있다. 시스템이 앱을 정리했다가 다시 만든 뒤 상세 선택과 뒤로가기 기록을 복원하는 결과는 [테스트 케이스 문서 목록](./README.md)에 따라 [Memo 목록·상세 배치 테스트 케이스](./memo-list-detail.md)가 대표로 확인한다. 한 화면만 사용하는 환경에서 루틴 목록이나 달력에서 추가나 상세로 이동하는 케이스와 목록 카드의 빠른 기록 케이스는 [RoutineHome 테스트 케이스](./routine-home.md)에서, 상세 영역에서 루틴을 작성해 추가하는 케이스는 [RoutineAdd 테스트 케이스](./routine-add.md)에서, 상세 영역에서 루틴을 확인하고 수정하고 완료하거나 다시 시작하고 삭제하고 기록을 넣고 빼는 케이스는 [RoutineDetail 테스트 케이스](./routine-detail.md)에서, 완료된 루틴 목록과 상세를 함께 사용하는 배치는 [RoutineFinishedList 목록·상세 배치 테스트 케이스](./routine-finished-list-detail.md)와 [TagRoutineFinishedList 목록·상세 배치 테스트 케이스](./tag-routine-finished-list-detail.md)에서 다룬다.

이 문서에서 루틴 추가의 처음 상태는 제목과 설명이 비어 있고, 시작 날짜가 오늘, 주기 `매일`, 단위와 목표량 비어 있음, 한 번에 기록할 양 `1`이며 태그를 고르지 않은 상태를 말한다. 따로 적지 않으면 루틴의 주기는 `매일`이고, RoutineHome의 보기 범위는 처음 상태인 `오늘 할 루틴`이며 선택한 태그가 없다. 2026-07-15는 수요일이다.

- When: 사용자가 두 영역의 표시 비율을 조절한 뒤 테스트 데이터의 경계를 지난다.
- Then: 조절하는 동안 결과가 즉시 반영되고, 경계를 지난 뒤에도 조절한 비율이 그대로다.
