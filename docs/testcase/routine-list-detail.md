# Routine 목록·상세 배치 테스트 케이스

기준 스펙: [Routine 목록·상세 배치 스펙](../spec/client/routine-list-detail.md)

이 문서에서 `domain > 배치에 참여하는 화면`, `feature > 추가 진입 수단`, `feature > 함께 사용과 단독 사용`, `feature > 함께 사용할 때의 행동` 절은 [목록·상세 배치 공통 스펙](../spec/client/list-detail-pane.md)이 소유한다. 이름이 비슷한 `domain > 배치에 참여하지 않는 화면`을 비롯한 나머지 절은 기준 스펙이 소유한다.

표시 비율 조절의 공통 행동과 유지 기준은 [목록·상세 배치 공통 스펙](../spec/client/list-detail-pane.md)에 위임되어 있다.

## feature

### TC-8c88c858-2072-400f-a879-00952bb3e90e: 목록과 상세를 함께 쓰는 환경에서는 두 영역을 함께 표시한다

- 근거: `feature > 함께 사용과 단독 사용`
- Given: 목록과 상세를 함께 사용할 수 있는 환경이다.
- When: 사용자가 루틴 주요 목적지에 진입한다.
- Then: 루틴 목록을 유지한 채 상세 영역에 루틴 추가가 함께 표시된다.

### TC-8beb00fb-4162-4842-b012-03becf084f00: 한 화면만 제공하는 환경에서는 현재 화면만 단독으로 표시한다

- 근거: `feature > 함께 사용과 단독 사용`
- Given: 목록과 상세를 함께 사용할 수 없는 환경이다.
- When: 사용자가 루틴 목록 또는 루틴 추가를 사용한다.
- Then: 현재 사용하는 화면만 단독으로 표시된다.

### TC-1c7abf77-eef1-4700-9622-4b0330cc60ba: 상세 영역에 루틴 추가가 놓이면 목록에서 추가 수단을 제공하지 않는다

- 근거: `feature > 추가 진입 수단`
- Given: 상세 영역에 루틴 추가가 놓여 있다.
- When: 사용자가 루틴 목록에서 실행할 수 있는 동작을 확인한다.
- Then: 루틴 추가 동작이 제공되지 않는다. 추가 단축키를 눌러도 추가가 실행되지 않는다.

### TC-5d9a4a09-8e34-45f2-aa70-3465ee2e6786: 목록만 사용하는 환경에서는 목록에서 추가 수단을 제공한다

- 근거: `feature > 추가 진입 수단`
- Given: 상세 영역에 루틴 추가가 놓여 있지 않다.
- When: 사용자가 루틴 목록에서 실행할 수 있는 동작을 확인한다.
- Then: 루틴 추가 동작이 제공된다.

### TC-b8284f0b-8b8d-418a-aab5-be224f5a025d: 목록과 함께 표시되면 루틴 추가에서 뒤로가기 수단을 제공하지 않는다

- 근거: `feature > 함께 사용할 때의 행동`
- Given: 루틴 목록과 루틴 추가가 함께 표시되어 있다.
- When: 사용자가 루틴 추가에서 실행할 수 있는 동작을 확인한다.
- Then: 뒤로가기 동작이 제공되지 않는다.

### TC-40815f60-f4ef-47e0-b6a5-8df2a5c18365: 단독으로 표시되면 루틴 추가에서 뒤로가기 수단을 제공한다

- 근거: `feature > 함께 사용할 때의 행동`
- Given: 루틴 추가가 단독으로 표시되어 있다.
- When: 사용자가 루틴 추가에서 실행할 수 있는 동작을 확인한다.
- Then: 뒤로가기 동작이 제공된다.

## domain

### TC-60b8a575-1947-4f86-8c3f-6325a0c126ea: 루틴 목록에서 이어 진입한 루틴 추가는 목록과 함께 표시한다

- 근거: `domain > 배치에 참여하는 화면`
- Given: 목록과 상세를 함께 사용할 수 있는 환경이다.
- When: 사용자가 루틴 목록에서 루틴 추가로 이동한다.
- Then: 루틴 추가를 목록·상세 배치의 상세 영역에 표시한다.

### TC-acdca25a-a5ef-4070-972f-0c2bbcc47a45: 다른 주요 목적지에 다녀오면 상세 영역의 루틴 추가는 제목과 설명이 비어 있는 상태로 시작한다

- 근거: `domain > 유지와 초기화 기준`
- Given: 목록과 상세를 함께 사용하고 있고 상세 영역의 루틴 추가에 사용자가 제목과 설명을 입력했다.
- When: 사용자가 공통 내비게이션에서 다른 주요 목적지로 이동했다가 루틴을 다시 선택한다.
- Then: 상세 영역의 루틴 추가는 제목과 설명이 비어 있다.

### TC-c752043f-d257-44c2-a6bc-a64c0d7587f8: 표시 비율을 조절한 뒤 화면이 재생성되거나 앱이 백그라운드에 다녀오거나 시스템이 앱을 정리했다가 다시 만들어도 조절한 비율이 그대로다

- 근거: `domain > 유지와 초기화 기준`
- Given: 루틴 목록과 상세 영역이 함께 표시되어 있다.
- When: 사용자가 두 영역의 표시 비율을 조절한 뒤 테스트 데이터의 경계를 지난다.
- Then: 조절하는 동안 결과가 즉시 반영되고, 경계를 지난 뒤에도 조절한 비율이 그대로다.
- 테스트 데이터:

| 경계 |
| --- |
| 화면 재생성 |
| 백그라운드 복귀 |
| 앱이 백그라운드에 있는 동안 시스템이 앱을 정리했다가 다시 만듦 |

- 작성하지 않는 이유: 표시 비율은 실제 창 크기에서 두 영역의 경계를 끌어야 조절되고 그 비율을 화면 밖에서 읽을 수 없어 현재 테스트 환경에서는 결정적으로 검증할 수 없다. 이 배치는 상세 영역에 루틴 추가만 놓여 따로 유지할 상세 선택이 없다. 창 크기와 영역 경계 끌기를 제어·관찰할 수 있는 통합 UI 테스트 환경이 갖춰지면 자동화한다.

### TC-b6bec6a0-d8bf-4e7b-99bb-50804d2a980a: 표시 비율을 조절한 뒤 다른 주요 목적지에 다녀와 루틴으로 돌아오거나 앱을 다시 실행하면 기본 비율로 돌아간다

- 근거: `domain > 유지와 초기화 기준`
- Given: 루틴 목록과 상세 영역이 함께 표시되어 있다.
- When: 사용자가 두 영역의 표시 비율을 조절한 뒤 테스트 데이터의 경계를 지난다.
- Then: 경계를 지난 뒤 표시 비율이 기본 비율로 돌아간다.
- 테스트 데이터:

| 경계 |
| --- |
| 다른 주요 목적지에 다녀와 루틴으로 돌아옴 |
| 앱 종료 뒤 다시 실행 |

- 작성하지 않는 이유: 표시 비율은 실제 창 크기에서 두 영역의 경계를 끌어야 조절되고 그 비율을 화면 밖에서 읽을 수 없어 현재 테스트 환경에서는 결정적으로 검증할 수 없다. 이 배치는 상세 영역에 루틴 추가만 놓여 따로 초기화할 상세 선택이 없다. 창 크기와 영역 경계 끌기를 제어·관찰할 수 있는 통합 UI 테스트 환경이 갖춰지면 자동화한다.
