# Web 목록·상세 배치 테스트 케이스

기준 스펙: [Web 목록·상세 배치 스펙](../spec/client/web-list-detail.md)

이 문서에서 `domain > 배치에 참여하는 화면`, `feature > 추가 진입 수단`, `feature > 함께 사용과 단독 사용`, `feature > 함께 사용할 때의 행동` 절은 [목록·상세 배치 공통 스펙](../spec/client/list-detail-pane.md)이 소유한다. 나머지 케이스의 절은 기준 스펙이 소유한다.

표시 비율 조절의 공통 행동과 유지 기준은 [목록·상세 배치 공통 스펙](../spec/client/list-detail-pane.md)에 위임되어 있다. 한 화면만 사용하는 환경에서 웹 목록에서 웹 추가와 웹 상세로 이동하는 케이스는 [WebHome 테스트 케이스](./web-home.md)에서 다룬다.

## feature

### TC-95056249-4b0a-4482-b23f-1d2c025f4702: 목록과 상세를 함께 쓰는 환경에서는 두 영역을 함께 표시한다

- 근거: `feature > 함께 사용과 단독 사용`
- Given: 목록과 상세를 함께 사용할 수 있는 환경이다.
- When: 사용자가 WebHome 화면에 진입한다.
- Then: 웹 목록을 유지한 채 상세 영역에 웹 추가가 함께 표시된다.

### TC-d821e061-1d4a-4935-bd52-065c171ab4d4: 한 화면만 제공하는 환경에서는 현재 화면만 단독으로 표시한다

- 근거: `feature > 함께 사용과 단독 사용`
- Given: 목록과 상세를 함께 사용할 수 없는 환경이다.
- When: 사용자가 웹 목록 또는 웹 추가를 사용한다.
- Then: 현재 사용하는 화면만 단독으로 표시된다.

### TC-e26e4e26-c90d-4534-bfca-5e674bb8f4b8: 상세 영역에 웹 추가가 놓이면 목록에서 추가 수단을 제공하지 않는다

- 근거: `feature > 추가 진입 수단`
- Given: 상세 영역에 웹 추가가 놓여 있다.
- When: 사용자가 웹 목록에서 실행할 수 있는 동작을 확인한다.
- Then: 웹 추가 동작이 제공되지 않는다. 추가 단축키를 눌러도 추가가 실행되지 않는다.

### TC-ef692409-3aae-4c98-87cf-84c56e9e3d4b: 목록만 사용하는 환경에서는 목록에서 추가 수단을 제공한다

- 근거: `feature > 추가 진입 수단`
- Given: 상세 영역에 웹 추가가 놓여 있지 않다.
- When: 사용자가 웹 목록에서 실행할 수 있는 동작을 확인한다.
- Then: 웹 추가 동작이 제공된다.

### TC-3a01fd1f-f851-4443-b779-47da4cec2406: 목록과 함께 표시되면 웹 추가에서 뒤로가기 수단을 제공하지 않는다

- 근거: `feature > 함께 사용할 때의 행동`
- Given: 웹 목록과 웹 추가가 함께 표시되어 있다.
- When: 사용자가 웹 추가에서 실행할 수 있는 동작을 확인한다.
- Then: 뒤로가기 동작이 제공되지 않는다.

### TC-ef33482d-22c5-4945-b15b-bec7fc4591a6: 단독으로 표시되면 웹 추가에서 뒤로가기 수단을 제공한다

- 근거: `feature > 함께 사용과 단독 사용`, `feature > 함께 사용할 때의 행동`
- Given: 웹 추가가 단독으로 표시되어 있다.
- When: 사용자가 웹 추가에서 실행할 수 있는 동작을 확인한다.
- Then: 뒤로가기 동작이 제공된다.

### TC-c093c315-4a27-4d82-b207-cc5b40eecb87: 목록과 함께 표시되어도 목록의 검색 수단은 그대로 제공한다

- 근거: `feature > 검색으로 이동`
- Given: 웹 목록과 웹 추가가 함께 표시되어 있다.
- When: 사용자가 웹 목록에서 실행할 수 있는 동작을 확인한다.
- Then: 검색 동작이 제공된다.

### TC-0436f577-1128-4d24-8b33-c59681e04d56: 상세 영역의 웹 추가에서 추가에 성공해도 상세 영역은 웹 추가로 남고 추가한 웹 항목이 목록에 나타난다

- 근거: `feature > 상세 영역의 구성`
- Given: 목록과 상세를 함께 사용할 수 있는 환경이고, 상세 영역에 웹 추가가 놓여 있으며 웹 항목 추가가 성공하도록 설정되어 있다.
- When: 사용자가 제목과 URL을 입력하고 웹 항목 추가를 실행한다.
- Then: 목록과 함께 상세 영역에는 제목과 URL이 비워진 웹 추가가 그대로 남아 다음 웹 항목을 입력할 수 있고, 방금 추가한 웹 항목이 같은 화면의 목록에 나타난다.

### TC-18fd5320-3e21-4050-b98b-c3ee38fc6fec: 웹 상세에서 뒤로 돌아오면 목록과 웹 추가를 함께 쓰는 상태로 돌아오고 보던 목록을 그대로 본다

- 근거: `feature > 웹 항목 선택`
- Given: 목록과 상세를 함께 사용할 수 있는 환경이고, 웹 목록을 아래로 스크롤해 목록 중간의 웹 항목을 보고 있다.
- When: 사용자가 보고 있던 웹 항목을 선택해 웹 상세로 이동한 뒤 뒤로간다.
- Then: 웹 상세는 목록 없이 단독으로 표시되고, 뒤로가면 웹 목록과 상세 영역의 웹 추가가 함께 표시되며 목록은 떠나기 전에 보던 위치를 그대로 보여 준다.

### TC-89f89f68-82bb-4884-9cc1-c0c269e180d6: 목록에서 검색으로 이동하면 검색 화면을 목록 없이 단독으로 표시한다

- 근거: `feature > 검색으로 이동`
- Given: 목록과 상세를 함께 사용할 수 있는 환경이고, 웹 목록과 상세 영역의 웹 추가가 함께 표시되어 있다.
- When: 사용자가 웹 목록에서 검색을 실행한다.
- Then: 검색 화면이 웹 목록과 웹 추가 없이 단독으로 표시된다.

## domain

### TC-a88fe4ef-621f-4d01-963e-e820ac0e72ab: 웹 목록에서 진입하지 않은 웹 추가는 목록과 함께 표시하지 않는다

- 근거: `domain > 배치에 참여하는 화면`
- Given: 목록과 상세를 함께 사용할 수 있는 환경이다.
- When: 사용자가 웹 목록이 아닌 화면에서 웹 추가로 이동한다.
- Then: 웹 추가를 목록·상세 배치에 참여시키지 않아 단독으로 표시한다.

### TC-d52c92ec-edad-42d3-9e8a-9bde47f6c6a0: 웹 목록에서 이어 진입한 웹 추가는 목록과 함께 표시한다

- 근거: `domain > 배치에 참여하는 화면`
- Given: 목록과 상세를 함께 사용할 수 있는 환경이다.
- When: 사용자가 웹 목록에서 웹 추가로 이동한다.
- Then: 웹 추가를 목록·상세 배치의 상세 영역에 표시한다.

### TC-2f18ac65-c93d-4f11-a82d-f37835606153: 웹 상세는 목록과 함께 표시하지 않는다

- 근거: `domain > 배치에 참여하지 않는 화면`, `domain > 배치에 참여하는 화면`
- Given: 목록과 상세를 함께 사용할 수 있는 환경이다.
- When: 사용자가 웹 목록에서 웹 항목을 선택해 웹 상세로 이동한다.
- Then: 웹 상세를 목록·상세 배치에 참여시키지 않아 단독으로 표시한다.

### TC-f3b028ee-28a1-48d8-a1aa-135eef2a1fc9: `더보기`로 돌아갔다가 다시 진입하면 상세 영역의 웹 추가는 입력과 태그 선택이 모두 비어 있는 상태로 시작한다

- 근거: `domain > 유지와 초기화 기준`
- Given: 목록과 상세 영역이 함께 표시되어 상세 영역에 웹 추가가 놓여 있다. 사용자가 웹 추가에 제목, 설명, URL과 요청 헤더 하나를 입력하고 태그 하나를 골랐다.
- When: 사용자가 `더보기` 화면으로 돌아갔다가 웹 화면에 다시 진입한다.
- Then: 상세 영역의 웹 추가는 제목, 설명, URL이 비어 있고 요청 헤더가 하나도 없으며, 앞서 고른 태그가 선택되어 있지 않다.

### TC-5c2564d0-eeb8-4bdb-9398-9a4856846a04: 배치를 떠나기 전에는 다른 화면에 다녀와도 웹 추가의 입력과 태그 선택이 남는다

- 근거: `domain > 유지와 초기화 기준`
- Given: 목록과 상세 영역이 함께 표시되어 상세 영역에 웹 추가가 놓여 있다. 사용자가 웹 추가에 제목, 설명, URL과 요청 헤더 하나를 입력하고 태그 하나를 골랐다.
- When: 사용자가 테스트 데이터의 화면으로 이동했다가 뒤로가기를 사용해 상세 영역의 웹 추가로 돌아온다.
- Then: 웹 추가에 입력하던 제목, 설명, URL, 요청 헤더와 고른 태그가 그대로 남아 있다.
- 테스트 데이터: 목록에서 고른 웹 상세, 웹 추가의 태그 입력에서 연 태그 추가, 웹 추가의 태그 입력에서 연 태그 상세

### TC-07b8eeb9-a612-4127-b995-a64440eab179: 표시 비율을 조절한 뒤 화면이 재생성되거나 앱이 백그라운드에 다녀오거나 시스템이 앱을 정리했다가 다시 만들어도 조절한 비율이 그대로다

- 근거: `domain > 유지와 초기화 기준`
- Given: 목록과 상세 영역이 함께 표시되어 있다.
- When: 사용자가 두 영역의 표시 비율을 조절한 뒤 테스트 데이터의 경계를 지난다.
- Then: 조절하는 동안 결과가 즉시 반영되고, 경계를 지난 뒤에도 조절한 비율이 그대로다.
- 테스트 데이터:

| 경계 |
| --- |
| 화면 재생성 |
| 백그라운드 복귀 |
| 앱이 백그라운드에 있는 동안 시스템이 앱을 정리했다가 다시 만듦 |

- 작성하지 않는 이유: 표시 비율은 실제 창 크기에서 두 영역의 경계를 끌어야 조절되고 그 비율을 화면 밖에서 읽을 수 없어 현재 테스트 환경에서는 결정적으로 검증할 수 없다. 배치를 떠나기 전 다른 화면에 다녀와도 상세 영역의 웹 추가 입력이 남는 결과는 TC-5c2564d0-eeb8-4bdb-9398-9a4856846a04가 검증한다. 창 크기와 영역 경계 끌기를 제어·관찰할 수 있는 통합 UI 테스트 환경이 갖춰지면 자동화한다.

### TC-f5408195-a59e-4dce-b998-5a8e0d5d32ad: 표시 비율을 조절한 뒤 `더보기`로 돌아갔다가 다시 진입하거나 앱을 다시 실행하면 기본 비율로 돌아간다

- 근거: `domain > 유지와 초기화 기준`
- Given: 목록과 상세 영역이 함께 표시되어 있다.
- When: 사용자가 두 영역의 표시 비율을 조절한 뒤 테스트 데이터의 경계를 지난다.
- Then: 경계를 지난 뒤 표시 비율이 기본 비율로 돌아간다.
- 테스트 데이터:

| 경계 |
| --- |
| `더보기`로 돌아갔다가 다시 진입 |
| 앱 종료 뒤 다시 실행 |

- 작성하지 않는 이유: 표시 비율은 실제 창 크기에서 두 영역의 경계를 끌어야 조절되고 그 비율을 화면 밖에서 읽을 수 없어 현재 테스트 환경에서는 결정적으로 검증할 수 없다. 상세 영역의 웹 추가가 재진입하면 비어 있는 상태로 시작하는 결과는 TC-f3b028ee-28a1-48d8-a1aa-135eef2a1fc9가 검증한다. 창 크기와 영역 경계 끌기를 제어·관찰할 수 있는 통합 UI 테스트 환경이 갖춰지면 자동화한다.
