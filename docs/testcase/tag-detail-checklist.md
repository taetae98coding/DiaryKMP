# TagDetail 체크리스트 탭 테스트 케이스

기준 스펙: [TagDetail 체크리스트 탭 스펙](../spec/client/tag-detail-checklist.md)

자리 표시 케이스의 `근거`가 가리키는 절은 공통 규칙을 [페이지 조회 목록의 자리 표시 스펙](../spec/client/paged-list-placeholder.md)에, 빈 상태 케이스의 `근거`가 가리키는 절은 [목록 빈 상태 스펙](../spec/client/list-empty-state.md)에, 새로고침 케이스의 `근거`가 가리키는 절은 [새로고침 스펙](../spec/client/sync-refresh.md)에 위임한다.

## feature

### TC-d28ab57d-cc71-4cb4-9bea-c381d6657d66: 대상 태그와 연결된 체크리스트만 목록에 표시한다

- 근거: `feature > 목록 표시`
- Given: 표시 범위가 `이 태그만`이고, 상세 대상 태그와 연결된 체크리스트와 다른 태그에만 연결된 체크리스트가 저장되어 있다.
- When: 사용자가 TagDetail 화면에서 체크리스트 탭을 연다.
- Then: 대상 태그와 연결된 체크리스트만 목록에 표시된다.

### TC-f7d0f491-98c6-4b46-a9a9-764d162c736c: 목록은 제목 오름차순으로 표시한다

- 근거: `feature > 목록 표시`, `domain > 체크리스트 노출과 정렬`
- Given: 상세 대상 태그에 제목이 서로 다른 체크리스트 여러 개가 연결되어 있다.
- When: 사용자가 TagDetail 화면에서 체크리스트 탭을 연다.
- Then: 체크리스트가 제목 오름차순으로 표시된다.
