# TagMemoFinishedList 화면 테스트 케이스

기준 스펙: [TagMemoFinishedList 화면 스펙](../spec/client/tag-memo-finished-list.md)

이 문서에서 `domain > 대상 항목`, `domain > 정렬`, `feature > 빈 상태`, `feature > 추가 미제공`, `feature > 불러오기 실패`, `feature > 새로고침`, `feature > 상세 확인` 절은 [완료 목록 공통 스펙](../spec/client/finished-list.md)이 소유한다. `domain > 날짜 그룹과 오늘 기준` 절은 [MemoHome 목록 스펙](../spec/client/memo-home.md)이 소유한다. `domain > 실행 경계` 절 중 정렬 선택과 보던 자리는 [완료 목록 공통 스펙](../spec/client/finished-list.md)이 소유한다. 나머지 케이스의 절은 기준 스펙이 소유한다.

자리 표시 케이스의 `근거`가 가리키는 절은 공통 규칙을 [페이지 조회 목록의 자리 표시 스펙](../spec/client/paged-list-placeholder.md)에, 빈 상태 케이스의 `근거`가 가리키는 절은 [목록 빈 상태 스펙](../spec/client/list-empty-state.md)에 위임한다.

## feature

### TC-TAG-MEMO-FINISHED-LIST-FEATURE-001: 대상 태그와 연결된 완료·미삭제 메모만 목록에 표시한다

- 근거: `feature > 목록 표시`, `domain > 태그 연결과 노출 기준`
- Given: 대상 태그에 연결된 완료·미삭제 메모, 미완료·미삭제 메모, 완료·삭제 메모와 다른 태그에만 연결된 완료·미삭제 메모가 함께 저장되어 있다.
- When: 사용자가 TagMemoFinishedList 화면을 연다.
- Then: 대상 태그와 연결되고 완료되었으며 삭제되지 않은 메모만 표시된다.

### TC-TAG-MEMO-FINISHED-LIST-FEATURE-002: 목록에 메모 제목과 기간이 표시된다

- 근거: `feature > 목록 표시`
- Given: 대상 태그에 테스트 데이터의 완료 메모가 연결되어 있다.
- When: 사용자가 TagMemoFinishedList 화면을 연다.
- Then: 테스트 데이터의 기대 표시 결과가 나타난다.
- 테스트 데이터:

| 메모의 기간 | 기대 표시 결과 |
| --- | --- |
| 있음 | 제목과 기간이 함께 표시됨 |
| 없음 | 제목만 표시되고 기간은 표시되지 않음 |

### TC-TAG-MEMO-FINISHED-LIST-FEATURE-003: 상단 바에 대상 태그의 이모지와 제목, 완료된 메모 목록 표시를 함께 제공한다

- 근거: `feature > 화면 제목`, `domain > 대상 태그와 연결`
- Given: 대상 태그가 테스트 데이터의 이모지와 제목으로 저장되어 있다.
- When: 사용자가 TagMemoFinishedList 화면을 연다.
- Then: 상단 바에 테스트 데이터의 기대 태그 표시와 완료된 메모 목록임을 알리는 표시가 함께 나타난다.
- 테스트 데이터:

| 저장된 이모지 | 저장된 제목 | 기대 태그 표시 |
| --- | --- | --- |
| `📌` | `회사` | `📌 회사` |
| 비어 있음 | `회사` | 앞선 공백 없이 `회사` |

### TC-TAG-MEMO-FINISHED-LIST-FEATURE-004: 대상 태그를 조회하지 못하면 태그 표시 없이 완료된 메모 목록임만 알린다

- 근거: `feature > 화면 제목`, `domain > 대상 태그와 연결`
- Given: 대상 태그를 테스트 데이터와 같이 조회할 수 없다.
- When: 사용자가 TagMemoFinishedList 화면을 연다.
- Then: 상단 바에 태그의 이모지와 제목이 표시되지 않고, 완료된 메모 목록임을 알리는 표시와 뒤로가기, 목록은 그대로 표시된다.
- 테스트 데이터:

| 조회 결과 |
| --- |
| 태그를 찾을 수 없음 |
| 조회 실패 |

### TC-TAG-MEMO-FINISHED-LIST-FEATURE-005: 대상 태그의 저장 이모지나 제목이 바뀌면 상단 바 표시를 갱신한다

- 근거: `domain > 대상 태그와 연결`
- Given: TagMemoFinishedList 화면에 대상 태그의 이모지와 제목이 표시되어 있다.
- When: 같은 태그의 저장된 이모지나 제목이 다른 경로로 변경된다.
- Then: 상단 바의 태그 표시가 변경된 저장 이모지와 제목으로 갱신된다.

### TC-TAG-MEMO-FINISHED-LIST-FEATURE-006: 기간 유무와 시작 날짜에 따라 메모를 나누어 표시한다

- 근거: `feature > 목록 표시`
- Given: 대상 태그에 기간이 없는 완료 메모와 시작 날짜가 같은 기간이 있는 완료 메모들이 연결되어 있다.
- When: 사용자가 TagMemoFinishedList 화면을 연다.
- Then: 기간이 없는 메모는 날짜 그룹 없이 먼저 표시되고, 기간이 있는 메모들은 시작 날짜가 같은 것끼리 한 그룹으로 표시된다.

### TC-TAG-MEMO-FINISHED-LIST-FEATURE-007: 시작 날짜가 오늘인 메모의 날짜 그룹은 오늘임을 알린다

- 근거: `feature > 목록 표시`
- Given: 시작 날짜가 오늘인 기간을 가진 완료 메모가 대상 태그에 연결되어 있다.
- When: 사용자가 TagMemoFinishedList 화면을 연다.
- Then: 그 그룹의 날짜 표시는 날짜 대신 오늘임을 알린다.

### TC-TAG-MEMO-FINISHED-LIST-FEATURE-008: 자리 표시 상태의 메모는 선택하거나 다시 시작·삭제할 수 없다

- 근거: `feature > 목록 표시`
- Given: 목록의 메모가 아직 준비되지 않아 자리 표시 상태로 제공되어 있다.
- When: 사용자가 해당 자리를 선택하거나 다시 시작·삭제하려 한다.
- Then: 메모 상세 이동, 다시 시작, 삭제가 요청되지 않는다.

### TC-TAG-MEMO-FINISHED-LIST-FEATURE-009: 목록 조회 실패에 별도의 오류나 재시도 동작을 표시하지 않는다

- 근거: `feature > 불러오기 실패`
- Given: 목록 조회가 테스트 데이터의 시점에 실패하도록 설정되어 있다.
- When: 사용자가 TagMemoFinishedList 화면을 확인한다.
- Then: 별도 재시도 동작 없이 테스트 데이터의 기존 표시 결과를 유지한다.
- 테스트 데이터:

| 실패 시점 | 기존 표시 결과 |
| --- | --- |
| 최초 조회 | 표시된 메모 없음. 이때의 빈 상태 안내는 `TC-TAG-MEMO-FINISHED-LIST-FEATURE-013`이 다룬다 |
| 추가 조회 | 이미 표시된 메모 |

### TC-TAG-MEMO-FINISHED-LIST-FEATURE-010: 완료된 메모가 없어도 화면에 진입할 수 있다

- 근거: `feature > 진입과 이동`
- Given: 대상 태그에 연결된 완료된 메모가 하나도 없다.
- When: 사용자가 대상 태그의 TagDetail 화면 메모 탭에서 완료된 메모 확인을 선택한다.
- Then: 같은 태그의 TagMemoFinishedList 화면으로 이동한다.

### TC-TAG-MEMO-FINISHED-LIST-FEATURE-011: 뒤로가기를 사용하면 메모 탭이 선택된 같은 태그의 TagDetail 화면으로 돌아간다

- 근거: `feature > 진입과 이동`
- Given: 대상 태그의 TagDetail 화면 메모 탭에서 진입한 TagMemoFinishedList 화면이 표시되어 있다.
- When: 사용자가 뒤로간다.
- Then: TagMemoFinishedList 화면이 닫히고 메모 탭이 선택된 같은 태그의 TagDetail 화면이 표시된다.

### TC-TAG-MEMO-FINISHED-LIST-FEATURE-012: 이 화면에서는 메모를 추가할 수 없다

- 근거: `feature > 추가 미제공`
- Given: 사용자가 TagMemoFinishedList 화면을 보고 있다.
- When: 사용자가 화면에서 실행할 수 있는 동작을 확인한다.
- Then: 메모 추가 동작이 제공되지 않는다.

### TC-TAG-MEMO-FINISHED-LIST-FEATURE-013: 완료된 메모가 없으면 빈 상태 안내를 표시한다

- 근거: `feature > 빈 상태`, `feature > 빈 상태 문구`
- Given: 대상 태그와 연결되고 노출 기준을 만족하는 메모가 하나도 없고 목록의 준비가 끝났다.
- When: 사용자가 TagMemoFinishedList 화면을 확인한다.
- Then: 메모 카드 대신 이 태그에서 완료한 메모가 없음을 알리는 안내가 표시되고, 메모 추가를 권하는 안내는 표시되지 않는다.

### TC-TAG-MEMO-FINISHED-LIST-FEATURE-014: 목록을 준비하는 동안에는 빈 상태 안내를 표시하지 않는다

- 근거: `feature > 빈 상태`
- Given: 목록에 표시된 메모가 아직 하나도 없고 목록의 준비가 끝나지 않았다.
- When: 사용자가 TagMemoFinishedList 화면을 확인한다.
- Then: 빈 상태 안내가 표시되지 않는다.

### TC-TAG-MEMO-FINISHED-LIST-FEATURE-015: 대상 태그를 조회하지 못해도 빈 상태 안내는 같은 기준으로 표시한다

- 근거: `feature > 빈 상태`, `feature > 빈 상태 문구`
- Given: 대상 태그를 조회하지 못해 상단 바에 태그 표시가 없고, 노출 기준을 만족하는 메모가 하나도 없으며 목록의 준비가 끝났다.
- When: 사용자가 TagMemoFinishedList 화면을 확인한다.
- Then: 이 태그에서 완료한 메모가 없음을 알리는 안내가 표시된다.

### TC-TAG-MEMO-FINISHED-LIST-FEATURE-016: 메모를 다시 시작하면 목록에서 사라지고 실행 취소를 제공한다

- 근거: `feature > 다시 시작`
- Given: 대상 태그에 연결된 완료 메모가 목록에 표시되어 있고 상태 변경이 성공하도록 설정되어 있다.
- When: 사용자가 그 메모를 다시 시작한다.
- Then: 메모가 목록에서 사라지고 다시 시작 안내와 실행 취소 동작이 제공된다.

### TC-TAG-MEMO-FINISHED-LIST-FEATURE-017: 메모를 삭제하면 목록에서 사라지고 실행 취소를 제공한다

- 근거: `feature > 삭제`
- Given: 대상 태그에 연결된 완료·미삭제 메모가 목록에 표시되어 있고 상태 변경이 성공하도록 설정되어 있다.
- When: 사용자가 그 메모를 삭제한다.
- Then: 메모가 목록에서 사라지고 삭제 안내와 실행 취소 동작이 제공된다.

### TC-TAG-MEMO-FINISHED-LIST-FEATURE-018: 상태 변경을 실행 취소하면 메모가 목록에 다시 나타난다

- 근거: `feature > 다시 시작`, `feature > 삭제`
- Given: 대상 태그의 완료 메모가 테스트 데이터의 상태 변경으로 목록에서 사라지고 실행 취소 동작이 표시되어 있다.
- When: 사용자가 실행 취소를 선택한다.
- Then: 메모가 테스트 데이터의 실행 취소 결과로 되돌아가 목록의 정렬 기준에 맞는 위치에 다시 나타난다.
- 테스트 데이터:

| 상태 변경 | 실행 취소 결과 |
| --- | --- |
| 다시 시작 | 완료 상태로 복구 |
| 삭제 | 미삭제 상태로 복구 |

### TC-TAG-MEMO-FINISHED-LIST-FEATURE-019: 메모를 선택하면 그 메모의 상세로 이동한다

- 근거: `feature > 메모 상세 확인`
- Given: 대상 태그에 연결된 완료 메모가 목록에 표시되어 있다.
- When: 사용자가 그 메모를 선택한다.
- Then: 선택한 메모의 MemoDetail 화면으로 이동한다.

### TC-TAG-MEMO-FINISHED-LIST-FEATURE-020: 화면 복귀 시 오늘 날짜 그룹 표시를 갱신한다

- 근거: `domain > 날짜 그룹과 오늘 기준`
- Given: TagMemoFinishedList 화면을 벗어난 사이 날짜가 바뀌어 새 오늘과 이전 오늘에 시작하는 완료 메모가 각각 있다.
- When: 사용자가 TagMemoFinishedList 화면으로 복귀한다.
- Then: 새 오늘에 해당하는 날짜 그룹이 오늘로 표시되고 이전 오늘의 날짜 그룹은 더 이상 오늘로 표시되지 않는다.

### TC-TAG-MEMO-FINISHED-LIST-FEATURE-021: 다시 시작이나 삭제가 저장되지 못하면 메모가 남고 안내를 표시하지 않는다

- 근거: `feature > 안내와 실행 취소`
- Given: 목록에 완료된 메모가 표시되어 있고, 테스트 데이터의 동작을 저장하면 실패하도록 설정되어 있다.
- When: 사용자가 그 메모에 테스트 데이터의 동작을 실행한다.
- Then: 메모의 상태가 바뀌지 않아 목록에 그대로 남고, 동작을 알리는 안내와 실행 취소는 표시되지 않는다.
- 테스트 데이터:

| 동작 |
| --- |
| 다시 시작 |
| 삭제 |

### TC-TAG-MEMO-FINISHED-LIST-FEATURE-022: 화면에 들어오거나 다른 화면에서 돌아오는 것만으로는 새로고침하지 않는다

- 근거: `feature > 새로고침`
- Given: 로그인한 사용자 계정이 확인되어 있고 진행 중인 동기화가 없다.
- When: 사용자가 TagMemoFinishedList 화면에 들어오거나, 다른 화면으로 이동했다가 TagMemoFinishedList 화면으로 돌아온다.
- Then: 서버와 맞추는 새로고침이 요청되지 않는다.

### TC-TAG-MEMO-FINISHED-LIST-FEATURE-023: 메모 상세에서 돌아오면 목록에서 보던 자리가 그대로다

- 근거: `feature > 상세 확인`
- Given: 한 영역만 쓰는 환경에서 TagMemoFinishedList 화면에 한 화면에 다 들어가지 않는 수의 완료 메모가 표시되어 있고, 사용자가 목록을 내려 뒤쪽의 메모를 보고 있다.
- When: 사용자가 메모를 선택해 MemoDetail 화면으로 이동했다가 뒤로 돌아온다.
- Then: 상세로 떠나기 전에 보던 메모가 그대로 보이고 첫 메모 카드는 보이지 않는다.

### TC-TAG-MEMO-FINISHED-LIST-FEATURE-024: 대상 태그가 완료되었거나 삭제되었어도 화면으로 이동할 수 있다

- 근거: `feature > 진입과 이동`
- Given: 대상 태그가 테스트 데이터의 상태로 저장되어 있고, 그 태그의 TagDetail 화면 메모 탭이 표시되어 있다.
- When: 사용자가 완료된 메모 확인을 선택한다.
- Then: 같은 태그의 TagMemoFinishedList 화면으로 이동한다.

## 작성하지 않는 이유

시작 날짜, 종일 여부, 시작 시각, 종료 시점, 제목이 모두 같은 메모끼리의 순서는 기준 스펙이 따르는 [MemoHome 목록 스펙](../spec/client/memo-home.md)에서 정하지 않으므로 기대 결과를 판정할 수 없어 작성하지 않는다.

상단 바 태그 표시의 한 줄 배치와 폭을 넘는 제목의 무한 반복 가로 이동, 날짜 헤더의 스크롤 고정은 시각적 레이아웃과 애니메이션이므로 현재 단위 테스트 환경에서 외부 결과로 결정적으로 판정할 수 없다. 제목 폭을 제어하고 여러 시점의 화면 프레임을 비교할 수 있는 시각 회귀 테스트 환경이 갖춰지면 자동화한다.

당겨서 새로고침과 진행 표시는 [새로고침 테스트 케이스](./sync-refresh.md)에서 다루므로 이 문서에서 다시 작성하지 않는다.

메모 상세를 목록과 함께 표시하는 배치와 그 뒤로가기는 [TagMemoFinishedList 목록·상세 배치 테스트 케이스](./tag-memo-finished-list-detail.md)에서 다루므로 이 문서에서 다시 작성하지 않는다.
