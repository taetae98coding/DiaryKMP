# 캘린더 루틴 기록 표시 테스트 케이스

기준 스펙: [캘린더 루틴 기록 표시 스펙](../spec/client/calendar-routine.md)

날짜별 합계와 양의 문구를 정하는 계산 규칙은 [루틴 앱 스펙](../spec/client/routine.md)이 소유하므로 [루틴 테스트 케이스](./routine.md)에서 다룬다. 이 문서는 그 결과가 표시 대상 기간에 따라 캘린더 루틴 기록으로 전달되는 것만 다루며, 케이스에 적은 양 문구는 루틴 앱 스펙의 규칙을 따른 값이다. 캘린더를 배치하는 화면이 이 기준 위에 더하는 태그 필터와 조회 실패의 표시는 [RoutineHome 테스트 케이스](./routine-home.md)에서 다룬다.

따로 적지 않으면 루틴의 단위는 `ml`이고, 루틴과 기록은 현재 사용자 계정과 연결되어 있으며 삭제되지 않은 상태다.

## domain

### TC-407dac03-4c85-447f-b14b-bdc62414009e: 표시 대상 기간에 드는 날짜의 기록만 표시 대상이 된다

- 근거: `domain > 표시 대상 기간`, `domain > 노출 기준`
- Given: 루틴 `물 마시기`에 날짜가 테스트 데이터와 같고 양이 500인 기록이 하나씩 저장되어 있다.
- When: 2026년 6월 28일부터 8월 8일까지를 표시 대상 기간으로 캘린더 루틴 기록을 조회한다.
- Then: 날짜가 표시 대상 기간에 드는 기록만 그 날짜를 차지하는 양 문구 `500ml`의 캘린더 루틴 기록으로 결과에 포함된다.
- 테스트 데이터:

| 기록의 날짜 | 결과 포함 | 비고 |
| --- | --- | --- |
| 2026년 6월 27일 | 아님 | 표시 대상 기간보다 하루 이전 |
| 2026년 6월 28일 | 포함 | 표시 대상 기간 시작일, 표시 중인 달에 속하지 않는 이웃 달의 날짜 |
| 2026년 7월 15일 | 포함 | 표시 대상 기간 안 |
| 2026년 8월 8일 | 포함 | 표시 대상 기간 종료일, 이웃 달의 날짜 |
| 2026년 8월 9일 | 아님 | 표시 대상 기간보다 하루 이후 |

### TC-02e860c4-c7b1-43ad-aff5-abfd981cd4e7: 캘린더 루틴 기록은 식별값, 제목, 루틴 컬러, 차지하는 하루와 그 날짜 합계의 양 문구를 가진다

- 근거: `domain > 캘린더 루틴 기록`
- Given: 제목이 `물 마시기`, 컬러가 파란색, 단위가 `ml`인 루틴에 2026년 7월 10일에 양 1500인 기록이 저장되어 있다.
- When: 2026년 6월 28일부터 8월 8일까지를 표시 대상 기간으로 캘린더 루틴 기록을 조회한다.
- Then: 그 루틴의 식별값, 제목 `물 마시기`, 표시 색상 파란색, 차지하는 날짜 2026년 7월 10일 하루, 양 문구 `1500ml`를 가진 캘린더 루틴 기록 하나가 전달된다.
