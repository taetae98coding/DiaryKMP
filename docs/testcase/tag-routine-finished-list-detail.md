# TagRoutineFinishedList 목록·상세 배치 테스트 케이스

기준 스펙: [TagRoutineFinishedList 목록·상세 배치 스펙](../spec/client/tag-routine-finished-list-detail.md)

상세 영역의 구성과 상세 선택은 기준 스펙이 [RoutineFinishedList 목록·상세 배치 스펙](../spec/client/routine-finished-list-detail.md)에, 함께 사용할 때의 행동, 상세 선택과 교체, 뒤로가기, 완료 목록의 배치와 유지·초기화의 공통 규칙은 [목록·상세 배치 공통 스펙](../spec/client/list-detail-pane.md)에 위임하므로, 그 규칙을 다루는 케이스의 `근거`는 그 스펙들의 절을 가리킨다.

TagDetail 루틴 탭에서 진입한 루틴 상세와 루틴 추가는 이 배치에 참여하지 않는다. 그 동작의 케이스는 [TagDetail 루틴 탭 테스트 케이스](./tag-detail-routine.md)에서 다룬다. 계정의 완료된 루틴 전체를 모으는 화면의 배치는 [RoutineFinishedList 목록·상세 배치 테스트 케이스](./routine-finished-list-detail.md)가, 상세 화면 하나에서 완료와 다시 시작 뒤 화면과 입력이 유지되는 결과는 [RoutineDetail 화면 테스트 케이스](./routine-detail.md)가 다루고, 이 문서는 그 결과가 대상 태그의 완료된 루틴 목록과 상세 영역에 함께 나타나는 것을 다룬다.
