# CalendarBarText 테스트 케이스

기준 스펙: [CalendarBarText 컴포넌트 스펙](../spec/client/calendar-bar-text.md)

## feature

### TC-CALENDAR-BAR-TEXT-FEATURE-001: 지정한 글이 표시된다

- 근거: `feature > 글 표시`
- Given: 표시할 글로 `회의 준비`가 지정된다.
- When: CalendarBarText가 표시된다.
- Then: `회의 준비`가 표시된다.

### TC-CALENDAR-BAR-TEXT-FEATURE-002: 글이 한 번에 다 보이지 않아도 뒷부분을 생략하지 않는다

- 근거: `feature > 넘치는 글 확인`, `domain > 표시 내용`
- Given: 한 번에 담기지 않는 길이의 글이 지정되고, 그 글보다 좁은 너비가 주어진다.
- When: CalendarBarText가 표시된다.
- Then: 뒷부분이 생략되지 않은 전체 글이 표시된다.

## 작성하지 않는 이유

글 옆에 색상 바가 표시되어 사용자가 색상을 구분할 수 있는 결과는 실제 화면의 색상과 형태를 판정해야 하므로 블랙박스 유닛 테스트 케이스로 작성하지 않는다. 색상과 형태를 결정적으로 비교할 수 있는 테스트 환경이 갖춰지면 검증한다.

넘치는 글이 가로로 흐르며 지나가 사용자가 뒷부분까지 눈으로 확인하는 결과는 시간에 따라 변하는 시각 표현을 판정해야 하므로 블랙박스 유닛 테스트 케이스로 작성하지 않는다. 글이 생략 없이 표시되는 것은 TC-CALENDAR-BAR-TEXT-FEATURE-002로 확인하며, 화면의 실제 변화를 결정적으로 비교할 수 있는 테스트 환경이 갖춰지면 검증한다.

색상 바에 지정한 색이 적용되는 결과, 색을 지정하지 않았을 때 화면 기본 글자색을 사용하는 결과와 지정한 색에 관계없이 글자색이 화면 기본 글자색으로 유지되는 결과는 실제 색상을 판정해야 하므로 블랙박스 유닛 테스트 케이스로 작성하지 않는다. 색상 결과를 결정적으로 비교할 수 있는 테스트 환경이 갖춰지면 검증한다.
