# 앱 동작 제공 테스트 케이스

기준 스펙: [앱 동작 제공 스펙](../spec/client/app-action.md)

제공하는 기능의 범위, 대상 계정, 화면이 없어서 달라지는 부분과 저장·동기화는 [AI 도구 제공 공통 테스트 케이스](./ai-tool.md)에서 다룬다. 이 문서는 Android와 iOS에만 있는 동작을 다룬다. Android와 iOS에서 `MCP` 설정 항목을 두지 않는 것은 [SettingHome 테스트 케이스](./setting-home.md)에서 다룬다.

## feature

### TC-4d946ca8-91a4-4197-9802-b46e106079bd: 동작을 실행해도 앱 화면이 열리지 않는다

- 근거: `feature > 동작 실행`
- Given: 앱이 열려 있고 사용자가 보던 화면이 있다.
- When: AI 도우미나 단축어가 메모 추가 동작을 실행한다.
- Then: 앱 화면은 보던 화면을 그대로 유지하고, 결과는 동작을 실행한 AI 도우미나 단축어가 받는다.
- 작성하지 않는 이유: 동작을 실행하는 주체와 앱 화면을 여는지는 운영체제가 정한다. 자동화하려면 실제 AI 도우미나 단축어로 동작을 실행하는 기기 테스트 환경이 필요하다.

### TC-9b30e8cc-8ed7-4266-9aad-7ddd0adfaa96: iOS에서 설정 없이 Siri 바로 실행 문구로 동작을 실행한다

- 근거: `feature > Siri 바로 실행 문구`
- Given: iOS에 앱을 설치했고 따로 설정하지 않았다.
- When: 사용자가 Siri에게 테스트 데이터의 동작을 말한다.
- Then: 그 동작이 실행되고, 결과는 테스트 데이터의 기능이 정한 결과와 같다.
- 테스트 데이터:

| 동작 | 결과를 정하는 기능 |
| --- | --- |
| 메모 추가 | MemoAdd 화면 |
| 메모 검색 | SearchHome 화면의 메모 결과 |
| 날짜별 캘린더 메모 보기 | 캘린더 메모 표시 |
| 진행 중 메모 목록 보기 | MemoHome 목록 |
| 태그 추가 | TagAdd 화면 |
| 체크리스트 추가 | ChecklistAdd 화면 |
| 웹 추가 | WebAdd 화면 |
| 저장한 장소 검색 | SearchHome 화면의 장소 결과 |
| 곡 추가 | MusicAdd 화면 |
| QR 추가 | QrAdd 화면 |

- 작성하지 않는 이유: 바로 실행 문구는 iOS 앱에만 있고 Siri가 문구를 알아듣는지는 운영체제가 정한다. 테스트 소스셋에서 iOS 앱과 Siri를 실행할 수 없으므로, 자동화하려면 iOS 앱을 실행하는 기기 테스트 환경이 필요하다.
