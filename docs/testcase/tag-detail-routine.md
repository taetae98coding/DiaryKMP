# TagDetail 루틴 탭 테스트 케이스

기준 스펙: [TagDetail 루틴 탭 스펙](../spec/client/tag-detail-routine.md)

자리 표시 케이스의 `근거`가 가리키는 절은 공통 규칙을 [페이지 조회 목록의 자리 표시 스펙](../spec/client/paged-list-placeholder.md)에, 빈 상태 케이스의 `근거`가 가리키는 절은 [목록 빈 상태 스펙](../spec/client/list-empty-state.md)에, 새로고침 케이스의 `근거`가 가리키는 절은 [새로고침 스펙](../spec/client/sync-refresh.md)에, 완료·삭제와 실행 취소 케이스의 `근거`가 가리키는 절은 [RoutineHome 화면 스펙](../spec/client/routine-home.md)의 완료와 삭제 규칙에 위임한다. 진행 상태, 주기의 합계, 달성률, 카드 문구와 목록 순서의 계산 규칙은 [루틴 테스트 케이스](./routine.md)가 다루며, 이 문서는 그 문구와 순서가 목록에 표시되는 것과 오늘을 다시 정하는 시점만 다룬다. 표시 범위에 따라 목록 탭에 담기는 태그는 [TagDetail 테스트 케이스](./tag-detail.md)가, 완료된 루틴 확인으로 이동한 화면의 내용과 행동은 [TagRoutineFinishedList 화면 테스트 케이스](./tag-routine-finished-list.md)가 다룬다.

## feature

### TC-c6eef3a9-261c-4525-98f7-dcfac6e409d0: 대상 태그와 연결된 루틴만 목록에 표시한다

- 근거: `feature > 목록 표시`
- Given: 표시 범위가 `이 태그만`이고, 상세 대상 태그와 연결된 루틴과 다른 태그에만 연결된 루틴이 저장되어 있다.
- When: 사용자가 TagDetail 화면에서 루틴 탭을 연다.
- Then: 대상 태그와 연결된 루틴만 목록에 표시된다.
