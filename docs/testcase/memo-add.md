# MemoAdd 테스트 케이스

기준 스펙: [MemoAdd 화면 스펙](../spec/client/memo-add.md)

이 문서에서 `domain > 추가 요청 제한`, `domain > 항목의 계정 연결`, `feature > 뒤로가기`, `feature > 저장 실패`, `data > 동기화` 절은 [항목 추가 화면 공통 스펙](../spec/client/entity-add.md)이 소유한다. 나머지 케이스의 절은 기준 스펙이 소유한다.

태그 입력의 표시와 조작, 태그 관련 문구의 케이스는 [메모 태그 입력 컴포넌트 테스트 케이스](./memo-tag-input.md)에서, 웹 입력의 표시와 조작, 웹 관련 문구의 케이스는 [메모 웹 입력 컴포넌트 테스트 케이스](./memo-web-input.md)에서, 연락처 입력의 표시와 조작, 연락처 관련 문구의 케이스는 [메모 연락처 입력 컴포넌트 테스트 케이스](./memo-contact-input.md)에서 다룬다. 이 문서에는 MemoAdd 화면에서만 다른 초기 상태와 추가 결과의 케이스만 둔다.

## feature

### TC-MEMO-ADD-FEATURE-005: 뒤로가기를 사용하면 이전 화면으로 돌아간다

- 근거: `feature > 뒤로가기`
- Given: MemoAdd 화면이 표시되어 있다.
- When: 사용자가 뒤로가기를 실행한다.
- Then: MemoAdd 화면이 닫히고 진입하기 전 화면이 표시된다.

### TC-MEMO-ADD-FEATURE-006: 추가에 성공하면 화면을 유지하고 다음 메모 입력 상태로 바뀐다

- 근거: `feature > 메모 추가 실행`, `feature > 추가 성공`
- Given: 메모 추가가 성공하도록 설정되어 있고, 공백이 아닌 제목과 설명이 입력되어 있으며 컬러가 선택되어 있다.
- When: 사용자가 메모 추가를 실행한다.
- Then: MemoAdd 화면이 그대로 유지되고 제목과 설명은 비워지며 다음 메모를 위한 무작위 컬러가 새로 제시된다.

### TC-MEMO-ADD-FEATURE-007: 추가 성공을 안내한다

- 근거: `feature > 추가 성공`
- Given: 메모 추가가 성공하도록 설정되어 있고 공백이 아닌 제목이 입력되어 있다.
- When: 사용자가 메모 추가를 실행한다.
- Then: 메모가 추가되었음을 안내한다.

### TC-MEMO-ADD-FEATURE-008: 추가를 처리하는 동안 진행 중인 상태를 표시한다

- 근거: `feature > 메모 추가 실행`
- Given: 메모 추가 처리가 완료되지 않고 진행 중인 상태로 설정되어 있고, 공백이 아닌 제목이 입력되어 있다.
- When: 사용자가 메모 추가를 실행한 뒤 화면을 확인한다.
- Then: 추가 처리가 끝날 때까지 진행 중인 상태가 표시된다.

### TC-MEMO-ADD-FEATURE-009: 제목을 입력하지 않으면 입력 내용을 유지한다

- 근거: `feature > 제목 미입력`
- Given: MemoAdd 화면에 설명이 입력되어 있고, 제목 입력 칸이 테스트 데이터의 상태다.
- When: 사용자가 메모 추가를 실행한다.
- Then: 메모가 추가되지 않고 입력한 설명과 제목 입력 칸의 내용이 지워지지 않은 채 유지된다.
- 테스트 데이터:

| 제목 입력 칸 상태 |
| --- |
| 비어 있음 |
| 공백 문자만 입력됨 |

### TC-MEMO-ADD-FEATURE-010: 제목 미입력을 안내한다

- 근거: `feature > 제목 미입력`
- Given: 제목 입력 칸이 비어 있거나 공백 문자만 입력되어 있다.
- When: 사용자가 메모 추가를 실행한다.
- Then: 제목 입력을 요청하는 안내가 표시된다.

### TC-MEMO-ADD-FEATURE-011: 화면이 처음 나타나면 기간을 사용하지 않는 상태다

- 근거: `feature > 메모 내용 입력`, `domain > 기간 선택의 시작 상태`
- Given: MemoHome이나 TagDetail 메모 탭에서 MemoAdd 화면에 진입할 수 있다.
- When: 사용자가 MemoAdd 화면에 진입한다.
- Then: 메모 기간을 사용하지 않는 상태로 표시된다.

### TC-MEMO-ADD-FEATURE-047: 캘린더 홈 화면이나 황금연휴 화면에서 기간을 선택해 진입하면 그 기간이 종일 기간으로 입력되어 있다

- 근거: `feature > 진입`, `domain > 기간 선택의 시작 상태`
- Given: 테스트 데이터의 화면에서 2026년 7월 14일부터 7월 17일까지의 기간을 선택해 MemoAdd 화면에 진입할 수 있다.
- When: 사용자가 MemoAdd 화면에 진입한다.
- Then: 시작이 2026년 7월 14일이고 종료가 2026년 7월 17일인 종일 기간을 사용하는 상태로 표시된다.
- 테스트 데이터:

| 진입 화면 |
| --- |
| 캘린더 홈 화면 |
| 황금연휴 화면 |

### TC-MEMO-ADD-FEATURE-013: 추가에 성공해도 선택한 기간이 유지된다

- 근거: `feature > 추가 성공`
- Given: 메모 추가가 성공하도록 설정되어 있고, 공백이 아닌 제목이 입력되어 있으며 기간을 사용하도록 설정해 기간을 선택한 상태다.
- When: 사용자가 메모 추가를 실행한다.
- Then: 기간 사용 상태와 선택한 기간이 그대로 유지되어, 사용자는 같은 기간으로 다음 메모를 이어서 추가할 수 있다.

### TC-MEMO-ADD-FEATURE-016: MemoHome, 캘린더 홈 화면이나 황금연휴 화면에서 진입하면 선택한 태그가 없는 상태로 시작한다

- 근거: `feature > 태그 입력`, `domain > 태그 선택의 시작 상태`
- Given: 계정과 연결된 태그가 있고 테스트 데이터의 화면에서 MemoAdd 화면에 진입할 수 있다.
- When: 사용자가 그 화면의 메모 추가 행동으로 MemoAdd 화면에 진입한다.
- Then: 선택한 태그와 대표 태그가 없는 상태로 표시된다.
- 테스트 데이터:

| 진입 화면 |
| --- |
| MemoHome |
| 캘린더 홈 화면(기간을 선택해 진입) |
| 황금연휴 화면(기간을 선택해 진입) |

### TC-MEMO-ADD-FEATURE-042: TagDetail 메모 탭에서 진입하면 대상 태그를 대표 태그로 표시한다

- 근거: `feature > 진입`, `feature > 태그 입력`, `domain > 태그 선택의 시작 상태`
- Given: 완료되지 않고 삭제되지 않은 대상 태그의 TagDetail 메모 탭이 표시되어 있다.
- When: 사용자가 메모 추가 행동으로 MemoAdd 화면에 진입한다.
- Then: 대상 태그가 선택되고 대표 태그로 지정된 상태로 표시된다.

### TC-MEMO-ADD-FEATURE-028: 추가에 성공해도 선택한 태그와 대표 태그 지정이 유지된다

- 근거: `feature > 추가 성공`
- Given: 메모 추가가 성공하도록 설정되어 있고, 공백이 아닌 제목이 입력되어 있으며, 태그 두 개가 선택되고 그중 하나가 대표 태그로 지정되어 있다.
- When: 사용자가 메모 추가를 실행한다.
- Then: 선택한 두 태그와 대표 태그 지정이 그대로 유지되어, 사용자는 같은 태그로 다음 메모를 이어서 추가할 수 있다.

### TC-MEMO-ADD-FEATURE-045: 화면 구성이 변경되어도 선택한 태그와 대표 태그 지정을 유지한다

- 근거: `domain > 진행 상태 유지`
- Given: MemoAdd 화면에서 태그 두 개를 선택하고 그중 하나를 대표 태그로 지정한 상태다.
- When: 화면이 회전하거나 창 크기가 바뀌어 화면 구성이 변경된다.
- Then: 변경 전에 선택한 두 태그와 대표 태그 지정이 그대로 유지된다.

### TC-MEMO-ADD-FEATURE-046: 시스템이 앱을 정리한 뒤 화면을 복원하면 선택한 태그가 유지되지 않는다

- 근거: `domain > 진행 상태 유지`
- Given: MemoAdd 화면에서 태그 두 개를 선택하고 그중 하나를 대표 태그로 지정한 상태다.
- When: 시스템이 앱을 메모리에서 정리한 뒤 사용자가 같은 경로로 화면을 복원한다.
- Then: 이전에 선택한 태그와 대표 태그 지정은 복원되지 않고 진입 경로의 초기 선택 상태로 시작한다.

### TC-MEMO-ADD-FEATURE-031: 앱을 다시 실행한 뒤 MemoHome에서 새로 진입하면 선택한 태그가 없는 상태로 시작한다

- 근거: `domain > 진행 상태 유지`
- Given: MemoAdd 화면에서 태그를 선택하고 대표 태그를 지정한 뒤 앱을 종료했다.
- When: 사용자가 앱을 다시 실행하고 MemoHome에서 MemoAdd 화면에 새로 진입한다.
- Then: 선택한 태그와 대표 태그가 없는 상태로 표시된다.
- 작성하지 않는 이유: 현재 테스트 환경에서는 앱 종료와 재실행을 결정적으로 제어할 수 없다. 앱 재실행을 제어하는 테스트 환경이 갖춰지면 자동화한다.

### TC-MEMO-ADD-FEATURE-043: 앱을 다시 실행한 뒤 TagDetail 메모 탭에서 새로 진입하면 대상 태그만 대표 태그로 선택된다

- 근거: `domain > 진행 상태 유지`
- Given: TagDetail 메모 탭에서 진입한 MemoAdd 화면에서 대상 태그 외의 태그를 추가로 선택하고 대표 태그를 바꾼 뒤 앱을 종료했다.
- When: 사용자가 앱을 다시 실행하고 같은 대상 태그의 TagDetail 메모 탭에서 MemoAdd 화면에 새로 진입한다.
- Then: 이전에 바꾼 선택은 복원되지 않고 메모 탭의 상세 대상 태그만 선택되어 대표 태그로 표시된다.
- 작성하지 않는 이유: 현재 테스트 환경에서는 앱 종료와 재실행을 결정적으로 제어할 수 없다. 앱 재실행을 제어하는 테스트 환경이 갖춰지면 자동화한다.

### TC-MEMO-ADD-FEATURE-055: 진입하면 선택한 웹 항목이 없는 상태로 시작한다

- When: 사용자가 MemoAdd 화면에 진입한다.

### TC-MEMO-ADD-FEATURE-063: 상세 화면의 메모 탭에서 진입하면 그 항목만 선택된 상태로 시작한다

- 근거: `feature > 진입`, `domain > 웹 선택의 시작 상태`, `domain > 연락처 선택의 시작 상태`, `domain > 장소 선택의 시작 상태`, `domain > 태그 선택의 시작 상태`

| 진입 화면 | 선택이 표시되는 입력 |
| --- | --- |
| ContactDetail 메모 탭 | 연락처 입력 |
| PlaceDetail 메모 탭 | 장소 카드 |
| WebDetail 메모 탭 | 웹 입력 |
