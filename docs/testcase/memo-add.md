# MemoAdd 테스트 케이스

기준 스펙: [MemoAdd 화면 스펙](../spec/client/memo-add.md)

이 문서에서 `domain > 추가 요청 제한`, `domain > 항목의 계정 연결`, `feature > 뒤로가기`, `feature > 저장 실패`, `data > 동기화` 절은 [항목 추가 화면 공통 스펙](../spec/client/entity-add.md)이 소유한다. 나머지 케이스의 절은 기준 스펙이 소유한다.

태그 입력의 표시와 조작, 태그 관련 문구의 케이스는 [메모 태그 입력 컴포넌트 테스트 케이스](./memo-tag-input.md)에서, 웹 입력의 표시와 조작, 웹 관련 문구의 케이스는 [메모 웹 입력 컴포넌트 테스트 케이스](./memo-web-input.md)에서, 연락처 입력의 표시와 조작, 연락처 관련 문구의 케이스는 [메모 연락처 입력 컴포넌트 테스트 케이스](./memo-contact-input.md)에서, 장소 카드의 표시와 조작, 장소 관련 문구의 케이스는 [메모 장소 카드 컴포넌트 테스트 케이스](./memo-place-card.md)에서 다룬다. 이 문서에는 MemoAdd 화면에서만 다른 초기 상태와 추가 결과의 케이스만 둔다.
