# FileHome 테스트 케이스

기준 스펙: [FileHome 화면 스펙](../spec/client/file-home.md)

추가 단축키 케이스의 `근거`가 가리키는 절은 공통 규칙을 [목록 추가 단축키 스펙](../spec/client/list-add-shortcut.md)에 위임한다.

올리기 실패 케이스의 `근거`가 가리키는 절은 실패 이유의 구분을 [파일 보관 스펙](../spec/client/file-storage.md)의 `올리기 상태`에 위임한다.

## feature

### TC-9065f330-9fac-4a23-88e2-d747eebcb1ca: 상단 바에 화면 제목을 표시한다

- 근거: `feature > 진입`
- Given: 사용자 언어가 한국어다.
- When: 사용자가 FileHome 화면을 확인한다.
- Then: 상단 바에 제목 `파일` 문구가 표시된다.

### TC-265cd00c-e425-422d-8afc-8e7fbbd9c701: 뒤로가기를 선택하면 이전 화면으로 돌아간다

- 근거: `feature > 뒤로가기`
- Given: 사용자가 `더보기`의 `파일` 바로가기로 FileHome 화면에 들어와 있다.
- When: 사용자가 뒤로가기를 선택한다.
- Then: 이전 화면으로 돌아가는 동작이 한 번 실행된다.

### TC-2e7619f5-e91c-4918-b683-b02dd5e0f339: 게스트 상태에서는 로그인 안내만 표시한다

- 근거: `feature > 게스트 상태`, `domain > 계정 상태에 따른 화면`
- Given: 사용자 언어가 한국어이고 계정 상태가 게스트다.
- When: 사용자가 FileHome 화면을 확인한다.
- Then: 본문에 `로그인이 필요합니다` 안내가 표시되고, 로그인 화면으로 이동하는 동작, 파일 목록과 파일 추가 동작은 표시되지 않으며, 파일 목록을 서버에 요청하지 않는다.

### TC-724f16b0-07de-418f-aee5-8701186d717e: 계정 상태를 확정하지 않은 동안에는 본문을 비운다

- 근거: `domain > 계정 상태에 따른 화면`
- Given: 계정 상태가 아직 게스트나 사용자로 확정되지 않았다.
- When: 사용자가 FileHome 화면을 확인한다.
- Then: 제목과 뒤로가기만 표시되고, 로그인 안내, 파일 목록, 파일 추가 동작은 표시되지 않는다.

### TC-d1e4bdd5-6315-458c-84c6-008443de7a9b: 목록을 처음 불러오는 동안 불러오는 중임을 표시한다

- 근거: `feature > 목록 표시 조건`
- Given: 계정 상태가 사용자이고, 서버가 파일 목록 요청에 아직 응답하지 않았다.
- When: 사용자가 FileHome 화면을 확인한다.
- Then: 본문에 불러오는 중 표시가 나타나고, 빈 상태 안내와 불러오기 실패 안내는 표시되지 않는다.

### TC-d6f066a1-3ba3-4563-bb58-eb2b0b1f785f: 처음 불러오기에 실패하면 실패 안내와 다시 시도를 표시한다

- 근거: `feature > 목록 표시 조건`

### TC-1c5350e0-97bf-485b-adac-25069bde7bd8: 처음 불러오기 실패 후 다시 시도하면 목록을 다시 불러온다

- Given: 처음 불러오기가 실패해 실패 안내가 표시되어 있고, 서버가 다음 요청에는 파일 하나를 돌려준다.
- When: 사용자가 `다시 시도`를 선택한다.
- Then: 다시 요청하는 동안 본문에 불러오는 중 표시가 나타나고, 파일 목록을 처음부터 다시 요청해 돌려받은 파일이 목록에 표시된다.

### TC-945cd089-e224-49fe-8f94-8ef966c2bdbd: 올린 파일이 하나도 없으면 빈 상태 안내를 표시한다

### TC-5bc8c5b1-a167-4dc8-947e-8800be9555df: 목록의 끝으로 이동하면 다음 파일을 이어서 불러와 붙인다

### TC-a487c7b4-8ae1-40cf-8b98-84f6003dc4db: 이어서 불러오기에 실패하면 목록 끝에 실패 안내와 다시 시도를 표시한다

### TC-e1268149-3bf6-4a84-8b06-aaeaa625dfe5: 이어서 불러오기 실패 후 다시 시도하면 이어서 다시 불러온다

### TC-ccb81390-a936-4a22-8ce9-4fe3de62a730: 올리기에 성공하면 목록을 처음부터 다시 불러와 처음으로 돌아간다

- 근거: `feature > 올리기 결과`, `domain > 목록을 다시 불러오는 계기`
- Given: FileHome 화면에 파일 목록이 표시되어 있고 사용자가 목록을 아래로 내려 첫 파일이 보이지 않으며, 서버가 올리기 요청에 성공을 돌려주고 다음 목록 요청에는 테스트 데이터의 목록을 돌려준다.
- When: 파일 올리기가 끝난다.
- Then: 진행 중 표시가 사라지고, 파일 목록을 처음부터 다시 요청하며, 새 목록이 오면 목록의 처음으로 돌아가 테스트 데이터의 맨 앞 파일이 보인다. 성공을 알리는 안내는 표시되지 않는다.
- 테스트 데이터:

| 다음 목록 | 맨 앞 파일 |
| --- | --- |
| 방금 올린 파일이 맨 앞에 있다 | 방금 올린 파일 |
| 다른 기기에서 더 늦게 올린 파일이 방금 올린 파일 앞에 있다 | 다른 기기에서 올린 파일 |

### TC-f0d423c5-b463-4cef-9f6c-b17e5e1946d9: 올리기에 실패하면 실패 이유를 알리고 목록을 유지한다
