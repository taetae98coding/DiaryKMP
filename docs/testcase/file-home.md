# FileHome 테스트 케이스

기준 스펙: [FileHome 화면 스펙](../spec/client/file-home.md)

## feature

### TC-FILE-HOME-FEATURE-001: 상단 바에 화면 제목을 표시한다

- 근거: `feature > 진입`
- Given: 사용자 언어가 한국어다.
- When: 사용자가 FileHome 화면을 확인한다.
- Then: 상단 바에 제목 `파일` 문구가 표시된다.

### TC-FILE-HOME-FEATURE-003: 뒤로가기를 선택하면 이전 화면으로 돌아간다

- 근거: `feature > 뒤로가기`
- Given: 사용자가 `더보기`의 `파일` 바로가기로 FileHome 화면에 들어와 있다.
- When: 사용자가 뒤로가기를 선택한다.
- Then: 이전 화면으로 돌아가는 동작이 한 번 실행된다.

### TC-FILE-HOME-FEATURE-005: 게스트 상태에서는 로그인 안내만 표시한다

- 근거: `feature > 게스트 상태`, `domain > 계정 상태에 따른 화면`
- Given: 사용자 언어가 한국어이고 계정 상태가 게스트다.
- When: 사용자가 FileHome 화면을 확인한다.
- Then: 본문에 `로그인이 필요합니다` 안내가 표시되고, 로그인 화면으로 이동하는 동작, 파일 목록과 파일 추가 동작은 표시되지 않으며, 파일 목록을 서버에 요청하지 않는다.

### TC-FILE-HOME-FEATURE-006: 계정 상태를 확정하지 않은 동안에는 본문을 비운다

- 근거: `domain > 계정 상태에 따른 화면`
- Given: 계정 상태가 아직 게스트나 사용자로 확정되지 않았다.
- When: 사용자가 FileHome 화면을 확인한다.
- Then: 제목과 뒤로가기만 표시되고, 로그인 안내, 파일 목록, 파일 추가 동작은 표시되지 않는다.

### TC-FILE-HOME-FEATURE-008: 목록을 처음 불러오는 동안 불러오는 중임을 표시한다

- 근거: `feature > 목록 표시 조건`
- Given: 계정 상태가 사용자이고, 서버가 파일 목록 요청에 아직 응답하지 않았다.
- When: 사용자가 FileHome 화면을 확인한다.
- Then: 본문에 불러오는 중 표시가 나타나고, 빈 상태 안내와 불러오기 실패 안내는 표시되지 않는다.

### TC-FILE-HOME-FEATURE-009: 처음 불러오기에 실패하면 실패 안내와 다시 시도를 표시한다

- 근거: `feature > 목록 표시 조건`
- Given: 사용자 언어가 한국어이고 계정 상태가 사용자이며, 서버가 파일 목록 요청에 실패를 돌려준다.
- When: 사용자가 FileHome 화면을 확인한다.
- Then: 본문에 `파일을 불러오지 못했습니다` 안내와 `다시 시도` 동작이 표시되고, 빈 상태 안내는 표시되지 않는다.

### TC-FILE-HOME-FEATURE-010: 처음 불러오기 실패 후 다시 시도하면 목록을 다시 불러온다

- 근거: `feature > 목록 표시 조건`, `domain > 목록을 다시 불러오는 계기`
- Given: 처음 불러오기가 실패해 실패 안내가 표시되어 있고, 서버가 다음 요청에는 파일 하나를 돌려준다.
- When: 사용자가 `다시 시도`를 선택한다.
- Then: 다시 요청하는 동안 본문에 불러오는 중 표시가 나타나고, 파일 목록을 처음부터 다시 요청해 돌려받은 파일이 목록에 표시된다.

### TC-FILE-HOME-FEATURE-011: 올린 파일이 하나도 없으면 빈 상태 안내를 표시한다

- 근거: `feature > 목록 표시 조건`
- Given: 사용자 언어가 한국어이고 계정 상태가 사용자이며, 서버가 파일이 하나도 없는 목록을 돌려준다.
- When: 사용자가 FileHome 화면을 확인한다.
- Then: 본문에 `아직 올린 파일이 없습니다` 안내가 표시되고, 파일 추가 동작은 그대로 표시된다.

### TC-FILE-HOME-FEATURE-012: 목록의 끝으로 이동하면 다음 파일을 이어서 불러와 붙인다

- 근거: `feature > 파일 목록`
- Given: 계정 상태가 사용자이고, 서버에 올린 파일이 25개 있어 첫 요청에 20개를 돌려주었다.
- When: 사용자가 목록의 끝으로 이동한다.
- Then: 나머지 5개를 이어서 요청하고, 목록에 25개 파일이 순서대로 모두 표시된다.

### TC-FILE-HOME-FEATURE-013: 이어서 불러오기에 실패하면 목록 끝에 실패 안내와 다시 시도를 표시한다

- 근거: `feature > 목록 표시 조건`
- Given: 사용자 언어가 한국어이고, 첫 요청으로 파일 20개가 표시되어 있으며, 서버가 이어서 불러오는 요청에 실패를 돌려준다.
- When: 사용자가 목록의 끝으로 이동한다.
- Then: 목록 끝에 `더 불러오지 못했습니다` 안내와 `다시 시도` 동작이 표시되고, 이미 표시된 파일 20개는 그대로 남는다.

### TC-FILE-HOME-FEATURE-014: 이어서 불러오기 실패 후 다시 시도하면 이어서 다시 불러온다

- 근거: `feature > 목록 표시 조건`
- Given: 이어서 불러오기가 실패해 목록 끝에 실패 안내가 표시되어 있고, 서버가 다음 요청에는 남은 파일을 돌려준다.
- When: 사용자가 목록 끝의 `다시 시도`를 선택한다.
- Then: 실패했던 이어서 불러오기를 다시 요청하고, 돌려받은 파일이 기존 목록 뒤에 붙는다.

### TC-FILE-HOME-FEATURE-018: 올리기에 성공하면 목록을 처음부터 다시 불러와 처음으로 돌아간다

- 근거: `feature > 올리기 결과`, `domain > 목록을 다시 불러오는 계기`
- Given: FileHome 화면에 파일 목록이 표시되어 있고 사용자가 목록을 아래로 내려 첫 파일이 보이지 않으며, 서버가 올리기 요청에 성공을 돌려주고 다음 목록 요청에는 테스트 데이터의 목록을 돌려준다.
- When: 파일 올리기가 끝난다.
- Then: 진행 중 표시가 사라지고, 파일 목록을 처음부터 다시 요청하는 동안 본문은 불러오는 중 표시로 바뀌지 않고 이전 목록을 그대로 보여 주며, 새 목록이 오면 목록의 처음으로 돌아가 테스트 데이터의 맨 앞 파일이 보인다. 성공을 알리는 안내는 표시되지 않는다.
- 테스트 데이터:

| 다음 목록 | 맨 앞 파일 |
| --- | --- |
| 방금 올린 파일이 맨 앞에 있다 | 방금 올린 파일 |
| 다른 기기에서 더 늦게 올린 파일이 방금 올린 파일 앞에 있다 | 다른 기기에서 올린 파일 |

### TC-FILE-HOME-FEATURE-019: 올리기에 실패하면 실패 이유를 알리고 목록을 유지한다

- 근거: `feature > 올리기 결과`
- Given: 사용자 언어가 한국어이고 FileHome 화면에 파일 목록이 표시되어 있으며, 파일 올리기가 테스트 데이터의 이유로 실패한다.
- When: 파일 올리기가 끝난다.
- Then: 테스트 데이터의 안내가 표시되고, 진행 중 표시가 사라지며, 목록은 바뀌지 않고, 사용자는 파일 추가를 다시 선택할 수 있다.
- 테스트 데이터:

| 실패 이유 | 안내 |
| --- | --- |
| 고른 파일이 50MB를 넘는다 | `50MB 이하 파일만 올릴 수 있습니다.` |
| 그 밖의 이유로 올리지 못했다 | `파일을 올리지 못했습니다.` |

### TC-FILE-HOME-FEATURE-020: 이어서 불러오는 동안 목록 끝에 불러오는 중임을 표시한다

- 근거: `feature > 목록 표시 조건`
- Given: 첫 요청으로 파일 20개가 표시되어 있고, 서버가 이어서 불러오는 요청에 아직 응답하지 않았다.
- When: 사용자가 목록의 끝으로 이동한다.
- Then: 목록 끝에 불러오는 중 표시가 나타나고, 이미 표시된 파일은 그대로 남는다.

### TC-FILE-HOME-FEATURE-021: 올리는 동안에도 목록을 확인하고 이동할 수 있다

- 근거: `feature > 파일 추가`
- Given: 파일 30개가 표시되어 있고, 파일을 올리는 중이다.
- When: 사용자가 목록의 끝으로 이동한다.
- Then: 진행 중 표시가 유지된 채 목록 끝의 파일이 보인다.

### TC-FILE-HOME-FEATURE-023: 목록이 보이는 상태에서 다시 불러오기에 실패하면 이전 목록을 두고 다시 시도와 함께 알린다

- 근거: `feature > 목록이 표시된 상태의 다시 불러오기 실패`, `feature > 올리기 결과`
- Given: 사용자 언어가 한국어이고 파일 목록이 표시되어 있으며 사용자가 목록을 아래로 내려 첫 파일이 보이지 않고, 서버가 다음 목록 요청에 실패를 돌려준다.
- When: 테스트 데이터의 일로 목록을 처음부터 다시 불러온다.
- Then: 이전 파일 목록이 보던 자리 그대로 표시되고, `파일을 불러오지 못했습니다` 안내가 `다시 시도` 동작과 함께 표시된다.
- 테스트 데이터:

| 다시 불러오는 일 |
| --- |
| 파일 올리기에 성공한다 |
| 사용자가 목록을 맨 위로 올린 뒤 당겨서 새로고침한다 |

### TC-FILE-HOME-FEATURE-024: 올리는 동안 계정이 바뀌면 올리기를 중단하고 결과를 알리지 않는다

- 근거: `feature > 올리기 결과`
- Given: 계정 A로 파일을 올리는 중이다.
- When: 계정 상태가 테스트 데이터의 상태로 바뀐다.
- Then: 진행 중 표시가 사라지고, 올리기 성공이나 실패를 알리는 안내가 표시되지 않으며, 테스트 데이터의 결과가 된다.
- 테스트 데이터:

| 바뀐 계정 상태 | 결과 |
| --- | --- |
| 계정 B의 사용자 | 파일 추가를 다시 선택할 수 있다 |
| 게스트 | 파일 추가가 사라지고 로그인 안내가 표시된다 |

### TC-FILE-HOME-FEATURE-025: 올리는 동안 뒤로가면 이전 화면으로 돌아가고 올리기는 이어진다

- 근거: `feature > 뒤로가기`
- Given: 파일을 올리는 중이고, 서버가 올리기 요청에 아직 응답하지 않았다.
- When: 사용자가 뒤로가기를 선택한다.
- Then: 이전 화면으로 돌아가는 동작이 한 번 실행된다. 화면을 떠난 뒤에도 올리기가 끝까지 진행되는 것은 [파일 보관 테스트 케이스](./file-storage.md)의 TC-FILE-STORAGE-DATA-024가 확인한다.

### TC-FILE-HOME-FEATURE-026: 다시 불러오기 실패 안내의 다시 시도를 선택하면 목록을 처음부터 다시 불러온다

- 근거: `feature > 목록이 표시된 상태의 다시 불러오기 실패`, `domain > 목록을 다시 불러오는 계기`
- Given: 파일 목록이 표시된 상태에서 다시 불러오기가 실패해 `다시 시도` 동작이 있는 안내가 표시되어 있고, 서버가 다음 목록 요청에 아직 응답하지 않았다가 새 목록을 돌려준다.
- When: 사용자가 안내의 `다시 시도`를 선택한다.
- Then: 안내가 닫히고 파일 목록을 처음부터 다시 요청하며, 응답을 기다리는 동안 이전 목록이 그대로 보인 채 새로고침 진행 표시가 나타나고, 응답이 오면 새 목록이 표시된다.

### TC-FILE-HOME-FEATURE-028: 파일 목록에서 당겨서 새로고침하면 이전 목록을 둔 채 처음부터 다시 불러온다

- 근거: `feature > 당겨서 새로고침`, `domain > 목록을 다시 불러오는 계기`
- Given: 파일 목록이 맨 위부터 표시되어 있고, 서버가 다음 목록 요청에 아직 응답하지 않았다가 새 파일이 맨 앞에 더해진 목록을 돌려준다.
- When: 사용자가 목록을 아래로 당겨 놓는다.
- Then: 파일 목록을 처음부터 다시 요청하고, 응답을 기다리는 동안 이전 목록이 그대로 보인 채 새로고침 진행 표시가 나타나며, 응답이 오면 진행 표시가 사라지고 새 파일이 맨 앞에 표시된다.

### TC-FILE-HOME-FEATURE-029: 빈 상태나 처음 불러오기 실패에서 당기면 처음 불러오기와 같이 표시한다

- 근거: `feature > 당겨서 새로고침`, `feature > 목록 표시 조건`
- Given: 본문이 테스트 데이터의 상태이고, 서버가 다음 목록 요청에 아직 응답하지 않았다가 파일 하나를 돌려준다.
- When: 사용자가 본문을 아래로 당겨 놓는다.
- Then: 파일 목록을 처음부터 다시 요청하고, 응답을 기다리는 동안 본문에 불러오는 중 표시가 나타나며, 응답이 오면 돌려받은 파일이 목록에 표시된다.
- 테스트 데이터:

| 본문 상태 |
| --- |
| 빈 상태 |
| 처음 불러오기 실패 |

### TC-FILE-HOME-FEATURE-030: 목록을 처음 불러오는 중에는 당겨도 다시 요청하지 않는다

- 근거: `feature > 당겨서 새로고침`
- Given: 계정 상태가 사용자이고, 서버가 첫 목록 요청에 아직 응답하지 않았다.
- When: 사용자가 본문을 아래로 당겨 놓는다.
- Then: 목록 요청은 첫 요청 한 번뿐이고, 본문에는 불러오는 중 표시가 그대로 남는다.

### TC-FILE-HOME-FEATURE-031: 다시 불러오는 동안 다시 당겨도 불러오기는 한 번만 진행된다

- 근거: `feature > 당겨서 새로고침`
- Given: 파일 목록에서 당겨서 새로고침해 서버가 그 요청에 아직 응답하지 않았다.
- When: 사용자가 목록을 다시 아래로 당겨 놓는다.
- Then: 처음부터 다시 불러오는 요청은 한 번만 보내진다.
