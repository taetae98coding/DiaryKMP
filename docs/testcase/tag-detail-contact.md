# TagDetail 연락처 탭 테스트 케이스

기준 스펙: [TagDetail 연락처 탭 스펙](../spec/client/tag-detail-contact.md)

자리 표시 케이스의 `근거`가 가리키는 절은 공통 규칙을 [페이지 조회 목록의 자리 표시 스펙](../spec/client/paged-list-placeholder.md)에, 빈 상태 케이스의 `근거`가 가리키는 절은 [목록 빈 상태 스펙](../spec/client/list-empty-state.md)에, 새로고침 케이스의 `근거`가 가리키는 절은 [새로고침 스펙](../spec/client/sync-refresh.md)에 위임한다.

## feature

### TC-e8ba66c1-2a33-41b6-843f-3d1021b92467: 대상 태그와 연결된 연락처만 목록에 표시한다

- 근거: `feature > 목록 표시`
- Given: 표시 범위가 `이 태그만`이고, 상세 대상 태그와 연결된 연락처와 다른 태그에만 연결된 연락처가 저장되어 있다.
- When: 사용자가 TagDetail 화면에서 연락처 탭을 연다.
- Then: 대상 태그와 연결된 연락처만 목록에 표시된다.

### TC-24a8eb8a-cd1b-4ce8-8467-36157533e65d: 연락처 탭에는 유무 필터를 제공하지 않는다

- 근거: `feature > 목록 표시`
- Given: 상세 대상 태그에 연결된 연락처가 표시되어 있다.
- When: 사용자가 연락처 탭에서 실행할 수 있는 동작을 확인한다.
- Then: 생일, 태어난 연도, 전화번호의 유무 필터를 열 수 없다.

### TC-3d12c653-8a80-47ce-baba-808818c3eda1: 자리 표시 상태의 연락처는 선택할 수 없다

- 근거: `feature > 목록 표시`
- Given: 목록의 연락처가 아직 준비되지 않아 자리 표시 상태로 제공되어 있다.
- When: 사용자가 해당 자리를 선택하려 한다.
- Then: 연락처 상세 이동이 요청되지 않는다.

### TC-5ced89c9-a106-47ec-8c29-a056dbd587f3: 목록 조회 실패에 별도의 오류나 재시도 동작을 표시하지 않는다

- 근거: `feature > 목록 표시`
- Given: 목록 조회가 테스트 데이터의 시점에 실패하도록 설정되어 있다.
- When: 사용자가 TagDetail 화면의 연락처 탭을 확인한다.
- Then: 별도 재시도 동작 없이 테스트 데이터의 표시 결과가 된다.
- 테스트 데이터:

| 실패 시점 | 표시 결과 |
| --- | --- |
| 최초 조회 | 표시된 연락처 없음. 이때의 빈 상태 안내는 `TC-5bd220a7-c214-4917-a581-ca45adbe7256`이 다룬다 |
| 추가 조회 | 이미 표시된 연락처 |
| 다시 조회 | 표시된 연락처 없음. 이전 연락처를 남기지 않는다 |

### TC-3d3d1f17-09df-420f-8a4f-cb47542ec96c: 연락처를 선택하면 그 연락처의 상세로 이동한다

- When: 사용자가 TagDetail 화면의 연락처 탭에서 가능한 동작을 확인한다.
