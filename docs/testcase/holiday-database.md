# 기기에 저장한 공휴일 테스트 케이스

기준 스펙: [기기에 저장한 공휴일 스펙](../spec/client/holiday-database.md)

## data

### TC-HOLIDAY-DATABASE-DATA-001: 저장된 공휴일이 없으면 빈 목록을 반환한다

- 근거: `data > 연도별 조회`
- Given: 조회할 연도의 공휴일이 저장되어 있지 않다.
- When: 해당 연도의 공휴일을 조회한다.
- Then: 빈 목록을 반환한다.

### TC-HOLIDAY-DATABASE-DATA-002: 요청한 연도의 공휴일만 반환한다

- 근거: `data > 연도별 조회`
- Given: 서로 다른 두 연도의 공휴일이 저장되어 있다.
- When: 그중 한 연도의 공휴일을 조회한다.
- Then: 요청한 연도에 저장된 공휴일만 반환한다.

### TC-HOLIDAY-DATABASE-DATA-003: 조회 중인 연도의 저장된 공휴일이 바뀌면 새 목록을 제공한다

- 근거: `data > 연도별 조회`
- Given: 특정 연도의 공휴일을 계속 조회하고 있다.
- When: 해당 연도의 공휴일 목록을 교체한다.
- Then: 기존 조회 결과에 이어 교체된 목록을 제공한다.

### TC-HOLIDAY-DATABASE-DATA-004: 공휴일 목록을 정해진 순서로 반환한다

- 근거: `data > 연도별 조회`
- Given: 시작일, 종료일 또는 이름이 서로 다른 공휴일이 순서 없이 저장되어 있다.
- When: 해당 연도의 공휴일을 조회한다.
- Then: 시작일, 종료일, 이름의 오름차순으로 정렬된 목록을 반환한다.

### TC-HOLIDAY-DATABASE-DATA-005: 저장 시 해당 연도의 기존 목록 전체를 교체한다

- 근거: `data > 연도별 교체`
- Given: 특정 연도에 여러 공휴일이 저장되어 있다.
- When: 일부 내용이 다른 새 공휴일 목록을 해당 연도에 저장한다.
- Then: 기존 목록의 항목은 남지 않고 새 목록만 반환한다.

### TC-HOLIDAY-DATABASE-DATA-006: 빈 목록 저장 시 해당 연도의 기존 목록을 제거한다

- 근거: `data > 연도별 교체`
- Given: 특정 연도에 공휴일이 저장되어 있다.
- When: 빈 공휴일 목록을 해당 연도에 저장한다.
- Then: 해당 연도를 조회하면 빈 목록을 반환한다.

### TC-HOLIDAY-DATABASE-DATA-007: 한 연도를 교체해도 다른 연도의 목록은 유지한다

- 근거: `data > 연도별 교체`
- Given: 서로 다른 두 연도에 공휴일이 저장되어 있다.
- When: 그중 한 연도의 공휴일 목록을 교체한다.
- Then: 교체하지 않은 연도의 공휴일 목록은 이전과 동일하다.

### TC-HOLIDAY-DATABASE-DATA-008: 전체 조회는 모든 연도의 공휴일을 반환한다

- 근거: `data > 전체 조회`
- Given: 서로 다른 여러 연도에 공휴일이 저장되어 있다.
- When: 저장된 전체 공휴일을 조회한다.
- Then: 모든 연도에 저장된 공휴일이 함께 반환된다.

### TC-HOLIDAY-DATABASE-DATA-009: 전체 조회에서 저장된 공휴일이 없으면 빈 목록을 반환한다

- 근거: `data > 전체 조회`
- Given: 어느 연도에도 공휴일이 저장되어 있지 않다.
- When: 저장된 전체 공휴일을 조회한다.
- Then: 빈 목록을 반환한다.

### TC-HOLIDAY-DATABASE-DATA-010: 어느 연도의 저장된 공휴일이든 바뀌면 전체 조회 결과를 갱신한다

- 근거: `data > 전체 조회`
- Given: 여러 연도의 공휴일 전체를 계속 조회하고 있다.
- When: 그중 한 연도의 공휴일 목록을 교체한다.
- Then: 기존 조회 결과에 이어 모든 연도의 최신 공휴일을 담은 목록이 제공된다.

### TC-HOLIDAY-DATABASE-DATA-012: 전체 조회는 이름 순으로 공휴일을 반환한다

- 근거: `data > 전체 조회`
- Given: 이름이 서로 다른 공휴일들이 순서 없이 저장되어 있다.
- When: 저장된 전체 공휴일을 조회한다.
- Then: 이름의 오름차순으로 정렬된 목록을 반환한다.

### TC-HOLIDAY-DATABASE-DATA-013: 연도별 조회는 요청한 국가 집합의 공휴일만 합쳐 반환한다

- 근거: `data > 연도별 조회`
- Given: 같은 연도의 한국과 미국 공휴일이 기기에 저장되어 있다.
- When: 테스트 데이터의 국가 집합과 그 연도로 공휴일을 조회한다.
- Then: 테스트 데이터의 국가 공휴일만 반환된다.
- 테스트 데이터:

  | 국가 집합 | 반환되는 공휴일 |
  | --- | --- |
  | 한국 | 한국 |
  | 미국 | 미국 |
  | 한국, 미국 | 한국, 미국 |
  | 없음 | 없음 |

### TC-HOLIDAY-DATABASE-DATA-014: 전체 조회는 요청한 국가 집합의 공휴일만 반환한다

- 근거: `data > 전체 조회`
- Given: 서로 다른 연도의 한국과 미국 공휴일이 기기에 저장되어 있다.
- When: 한국만 담은 국가 집합으로 전체 공휴일을 조회한다.
- Then: 모든 연도의 한국 공휴일만 반환된다.

### TC-HOLIDAY-DATABASE-DATA-015: 한 국가·연도를 교체해도 같은 연도의 다른 국가 목록은 유지한다

- 근거: `data > 연도별 교체`
- Given: 같은 연도의 한국과 미국 공휴일이 기기에 저장되어 있다.
- When: 한국의 그 연도 공휴일을 새 목록으로 저장한다.
- Then: 한국의 그 연도 목록은 새 목록으로 교체되고, 미국의 그 연도 목록은 유지된다.

### TC-HOLIDAY-DATABASE-DATA-016: 시작일·종료일·이름이 같으면 국가 순으로 반환한다

- 근거: `data > 연도별 조회`
- Given: 같은 연도에 시작일, 종료일, 이름이 같은 한국 공휴일과 미국 공휴일이 저장되어 있다.
- When: 한국과 미국을 담은 국가 집합으로 그 연도의 공휴일을 조회한다.
- Then: 한국 공휴일, 미국 공휴일 순으로 반환된다.

### TC-HOLIDAY-DATABASE-DATA-017: 전체 조회에서 이름이 같으면 한국, 미국 순으로 반환한다

- 근거: `data > 전체 조회`
- Given: 이름이 같은 한국 공휴일과 미국 공휴일이 서로 다른 연도에 저장되어 있고, 미국 공휴일의 날짜가 더 이르다.
- When: 한국과 미국을 담은 국가 집합으로 전체 공휴일을 조회한다.
- Then: 날짜와 관계없이 한국 공휴일, 미국 공휴일 순으로 반환된다.

## 작성하지 않는 이유

- 교체 실패 시 기존 공휴일을 유지하는 동작은 지우기를 마친 뒤 새로 저장하는 도중에 실제 저장소의 쓰기를 실패시켜야 확인할 수 있어 작성하지 않는다. 저장 도중의 쓰기 실패를 주입할 수 있는 저장소 테스트 환경이 갖춰지면 자동화한다.
- 기기에 저장한 공휴일이 사용자 계정과 무관해 로그인, 로그아웃, 계정 전환에도 그대로 남는 결과는, 공휴일 저장과 조회에 계정 구분이 없어 이 문서의 범위에서는 계정 전환을 일으킬 수 없으므로 작성하지 않는다. 로그인 상태 전환과 기기 저장을 함께 실행하는 통합 테스트 환경이 갖춰지면 자동화한다.
- Android, iOS, 데스크톱 앱에서 저장한 공휴일이 앱을 다시 실행해도 남아 있고 웹에서는 페이지를 새로 열면 비워지는 결과는, 앱 프로세스를 다시 시작하거나 웹 페이지를 새로 열어 플랫폼별 실제 저장소를 다시 열어야 확인할 수 있어 작성하지 않는다. 플랫폼별 저장소를 닫았다가 다시 여는 실행 경계를 제어할 수 있는 테스트 환경이 갖춰지면 자동화한다.
