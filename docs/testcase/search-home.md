# SearchHome 테스트 케이스

기준 스펙: [SearchHome 화면 스펙](../spec/client/search-home.md)

자리 표시 케이스의 `근거`가 가리키는 절은 공통 규칙을 [페이지 조회 목록의 자리 표시 스펙](../spec/client/paged-list-placeholder.md)에, 결과 없음 안내 케이스의 `근거`가 가리키는 절은 [목록 빈 상태 스펙](../spec/client/list-empty-state.md)에 위임한다.

`더보기`에서 `검색` 항목을 선택하는 케이스는 [MoreHome 테스트 케이스](./more-home.md)에서, 목록 화면에서 검색을 선택하는 케이스는 [MemoHome 목록 테스트 케이스](./memo-home.md), [TagHome 목록 테스트 케이스](./tag-home.md), [PlaceHome 테스트 케이스](./place-home.md), [WebHome 테스트 케이스](./web-home.md)에서 다룬다. 이동한 상세 화면의 내용과 수정·삭제 케이스는 [MemoDetail 테스트 케이스](./memo-detail.md), [TagDetail 테스트 케이스](./tag-detail.md), [PlaceDetail 테스트 케이스](./place-detail.md)에서 다룬다.

결과 카드를 미는 상호작용 자체의 케이스는 [SwipeToFinishAndDelete 테스트 케이스](./swipe-to-finish-and-delete.md)에서, 결과에서 실행한 완료·다시 시작·삭제와 실행 취소의 상태 전이와 저장 케이스는 그 기준을 소유한 [MemoHome 목록 테스트 케이스](./memo-home.md), [MemoFinishedList 테스트 케이스](./memo-finished-list.md), [TagHome 목록 테스트 케이스](./tag-home.md), [TagFinishedList 테스트 케이스](./tag-finished-list.md), [PlaceHome 테스트 케이스](./place-home.md), [WebHome 테스트 케이스](./web-home.md)에서 다룬다.

## feature

- 근거: `feature > 진입과 검색`
- Given: 저장된 메모, 태그, 장소, 웹 항목이 있다.
