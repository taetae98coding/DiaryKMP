# TagDetail 곡 탭 테스트 케이스

기준 스펙: [TagDetail 곡 탭 스펙](../spec/client/tag-detail-music.md)

자리 표시 케이스의 `근거`가 가리키는 절은 공통 규칙을 [페이지 조회 목록의 자리 표시 스펙](../spec/client/paged-list-placeholder.md)에, 빈 상태 케이스의 `근거`가 가리키는 절은 [목록 빈 상태 스펙](../spec/client/list-empty-state.md)에, 새로고침 케이스의 `근거`가 가리키는 절은 [새로고침 스펙](../spec/client/sync-refresh.md)에 위임한다.

## feature

### TC-1b53a403-fc5f-4cfb-a5d2-e5c71210b8bf: 대상 태그와 연결된 곡만 목록에 표시한다

- 근거: `feature > 목록 표시`
- Given: 표시 범위가 `이 태그만`이고, 상세 대상 태그와 연결된 곡과 다른 태그에만 연결된 곡이 저장되어 있다.
- When: 사용자가 TagDetail 화면에서 곡 탭을 연다.
- Then: 대상 태그와 연결된 곡만 목록에 표시된다.

### TC-e0b49707-d7ca-4003-a7bd-b216b33256f9: 목록은 제목 오름차순으로 표시한다

- 근거: `feature > 목록 표시`, `domain > 곡 노출과 정렬`
- Given: 상세 대상 태그에 제목이 서로 다른 곡 여러 개가 연결되어 있다.
- When: 사용자가 TagDetail 화면에서 곡 탭을 연다.
- Then: 곡이 제목 오름차순으로 표시된다.

### TC-1c38254f-bd63-41fd-be30-038cd06c92ba: 자리 표시 상태의 곡은 선택할 수 없다

- 근거: `feature > 목록 표시`
- Given: 목록의 곡이 아직 준비되지 않아 자리 표시 상태로 제공되어 있다.
- When: 사용자가 해당 자리를 선택하려 한다.
- Then: 곡 상세 이동이 요청되지 않는다.

### TC-452fda2a-9823-41b0-9bb4-a49e0920b026: 목록 조회 실패에 별도의 오류나 재시도 동작을 표시하지 않는다

- 근거: `feature > 목록 표시`
- Given: 목록 조회가 테스트 데이터의 시점에 실패하도록 설정되어 있다.
- When: 사용자가 TagDetail 화면의 곡 탭을 확인한다.
- Then: 별도 재시도 동작 없이 테스트 데이터의 표시 결과가 된다.
- 테스트 데이터:

| 실패 시점 | 표시 결과 |
| --- | --- |
| 최초 조회 | 표시된 곡 없음. 이때의 빈 상태 안내는 `TC-7b4bd46a-bc10-419c-8094-5c9ef50096ce`이 다룬다 |
| 추가 조회 | 이미 표시된 곡 |
| 다시 조회 | 표시된 곡 없음. 이전 곡을 남기지 않는다 |

### TC-13d845f3-f943-4de0-8c00-700b51190013: 곡을 선택하면 그 곡의 상세로 이동한다

- 근거: `feature > 곡 상세 확인`
- Given: 상세 대상 태그에 연결된 곡이 표시되어 있다.
- When: 사용자가 그 곡을 선택한다.
- Then: 선택한 곡의 MusicDetail 화면으로 이동한다.
