# MusicAdd 테스트 케이스

기준 스펙: [MusicAdd 화면 스펙](../spec/client/music-add.md)

이 문서에서 `data > 동기화`, `domain > 추가 요청 제한`, `domain > 항목의 계정 연결`, `feature > 뒤로가기`, `feature > 작성 상태 유지`, `feature > 저장 실패` 절은 [항목 추가 화면 공통 스펙](../spec/client/entity-add.md)이 소유한다. 나머지 케이스의 절은 기준 스펙이 소유한다.

PlaylistHome에서 곡 추가를 선택해 MusicAdd로 이동하는 케이스는 [PlaylistHome 테스트 케이스](./playlist-home.md)에서, 곡 목록과 함께 표시할 때의 케이스는 [Playlist 목록·상세 배치 테스트 케이스](./playlist-list-detail.md)에서 다룬다. 추가한 곡을 서버와 맞추는 흐름의 케이스는 [데이터 동기화 테스트 케이스](./data-sync.md)에서 다룬다. 이 화면에는 태그 입력이 없으므로 태그 연결 케이스는 두지 않는다.

## feature

### TC-MUSIC-ADD-FEATURE-001: 화면에 처음 진입하면 입력이 모두 비어 있다

- 근거: `feature > 진입과 입력`
- Given: 사용자가 곡 추가를 선택했다.
- When: MusicAdd 화면이 처음 표시된다.
- Then: 제목, 가수와 링크가 비어 있고 썸네일 미리보기가 표시되지 않는다.

### TC-MUSIC-ADD-FEATURE-002: 제목, 가수와 링크를 입력할 수 있다

- 근거: `feature > 진입과 입력`
- Given: MusicAdd 화면이 표시되어 있다.
- When: 사용자가 제목, 가수와 링크를 입력한다.
- Then: 입력한 제목, 가수와 링크가 화면에 그대로 표시된다.

### TC-MUSIC-ADD-FEATURE-026: 화면에 처음 진입하면 제목 입력에 초점이 있다

- 근거: `feature > 진입과 입력`
- Given: 사용자가 곡 추가를 선택했다.
- When: MusicAdd 화면이 처음 표시된다.
- Then: 입력 초점이 제목 입력에 있다.

### TC-MUSIC-ADD-FEATURE-028: 링크를 입력하면 그 링크의 썸네일 미리보기가 즉시 표시된다

- 근거: `feature > 썸네일 확인`
- Given: MusicAdd 화면이 표시되어 있고 불러오기를 실행하지 않았다.
- When: 사용자가 테스트 데이터의 링크를 입력한다.
- Then: 테스트 데이터의 결과대로 썸네일 미리보기가 표시되거나 표시되지 않는다.
- 테스트 데이터:

| 링크 | 썸네일 미리보기 |
| --- | --- |
| `www.youtube.com`의 영상 주소 | 표시된다 |
| `youtu.be`의 짧은 주소 | 표시된다 |
| 비어 있음 | 표시되지 않는다 |
| YouTube 채널 주소 | 표시되지 않는다 |
| YouTube 주소가 아닌 주소 | 표시되지 않는다 |

### TC-MUSIC-ADD-FEATURE-030: 링크를 지우거나 바꾸면 썸네일 미리보기가 따라 바뀐다

- 근거: `feature > 썸네일 확인`
- Given: YouTube 영상 링크가 입력되어 썸네일 미리보기가 표시된 MusicAdd 화면이 표시되어 있다.
- When: 사용자가 테스트 데이터의 조작을 한다.
- Then: 테스트 데이터의 결과대로 미리보기가 바뀐다.
- 테스트 데이터:

| 조작 | 결과 |
| --- | --- |
| 링크를 모두 지운다 | 미리보기가 사라진다 |
| 다른 영상의 링크로 바꾼다 | 미리보기가 바꾼 링크의 썸네일로 바뀐다 |
| YouTube 채널 주소로 바꾼다 | 미리보기가 사라진다 |

### TC-MUSIC-ADD-FEATURE-004: 추가에 성공하면 다음 곡을 작성할 수 있는 상태로 초기화한다

- 근거: `feature > 곡 추가`
- Given: 곡 추가가 성공하도록 설정되어 있고, 제목과 가수와 YouTube 영상 링크를 입력해 썸네일 미리보기가 표시된 상태다.
- When: 사용자가 곡 추가를 실행한다.
- Then: MusicAdd 화면이 유지되고 제목, 가수와 링크가 비워지며 썸네일 미리보기가 사라진다.

### TC-MUSIC-ADD-FEATURE-005: 추가에 성공하면 성공 피드백을 제공한다

- 근거: `feature > 곡 추가`
- Given: 곡 추가가 성공하도록 설정되어 있고, 공백이 아닌 제목이 입력되어 있다.
- When: 사용자가 곡 추가를 실행한다.
- Then: 곡이 추가되었다는 성공 피드백이 제공된다.

### TC-MUSIC-ADD-FEATURE-027: 추가에 성공하면 제목 입력으로 초점을 옮긴다

- 근거: `feature > 곡 추가`
- Given: 곡 추가가 성공하도록 설정되어 있고, 공백이 아닌 제목이 입력되어 있으며 입력 초점이 링크 입력에 있다.
- When: 사용자가 곡 추가를 실행한다.
- Then: 입력 초점이 제목 입력으로 옮겨진다.

### TC-MUSIC-ADD-FEATURE-029: 가수나 링크가 비어 있어도 곡을 추가한다

- 근거: `feature > 곡 추가`
- Given: 곡 추가가 성공하도록 설정되어 있고, 공백이 아닌 제목과 테스트 데이터의 입력 상태가 만들어져 있다.
- When: 사용자가 곡 추가를 실행한다.
- Then: 곡이 추가되었다는 성공 피드백이 제공된다.
- 테스트 데이터:

| 입력 상태 |
| --- |
| 가수가 비어 있고 링크는 있음 |
| 링크가 비어 있고 가수는 있음 |
| 가수와 링크가 모두 비어 있음 |

### TC-MUSIC-ADD-FEATURE-007: 추가를 처리하는 동안 진행 상태를 표시한다

- 근거: `feature > 곡 추가`
- Given: 곡 추가 처리가 완료되지 않고 진행 중인 상태로 설정되어 있고, 공백이 아닌 제목이 입력되어 있다.
- When: 사용자가 곡 추가를 실행한 뒤 화면을 확인한다.
- Then: 추가 처리가 끝날 때까지 진행 상태가 표시된다.

### TC-MUSIC-ADD-FEATURE-031: 저장에 실패하면 안내 없이 작성 내용을 유지하고 진행 상태만 해제한다

- 근거: `feature > 저장 실패`
- Given: 기기 저장이 실패하도록 설정되어 있고, 공백이 아닌 제목과 가수, YouTube 영상 링크가 입력되어 있다.
- When: 사용자가 곡 추가를 실행한다.
- Then: 곡이 추가되지 않고 성공 피드백과 저장 실패 안내가 모두 제공되지 않는다. 입력한 제목, 가수와 링크가 그대로 남고 진행 상태가 해제되어, 사용자는 같은 내용으로 추가를 다시 실행할 수 있다.

### TC-MUSIC-ADD-FEATURE-008: 성립하지 않는 입력으로 추가하면 필요한 입력을 알린다

- 근거: `feature > 제목 미입력`, `feature > 링크 형식 불만족`
- Given: MusicAdd 화면에 테스트 데이터의 입력 상태가 만들어져 있다.
- When: 사용자가 곡 추가를 실행한다.
- Then: 곡이 추가되지 않고 테스트 데이터의 피드백이 제공된다.
- 테스트 데이터:

| 입력 상태 | 피드백 |
| --- | --- |
| 제목이 비어 있음 | 제목 입력이 필요함 |
| 제목이 공백 문자뿐임 | 제목 입력이 필요함 |
| 제목은 있고 링크가 YouTube 주소가 아님 | YouTube 영상 링크가 필요함 |

### TC-MUSIC-ADD-FEATURE-009: 성립하지 않는 입력으로 추가해도 작성 내용은 유지된다

- 근거: `feature > 제목 미입력`, `feature > 링크 형식 불만족`
- Given: 테스트 데이터의 성립하지 않는 입력 상태이고 나머지 입력이 채워진 MusicAdd 화면이 표시되어 있다.
- When: 사용자가 곡 추가를 실행한다.
- Then: 제목, 가수와 링크가 지워지거나 바뀌지 않는다.
- 테스트 데이터:

| 성립하지 않는 입력 |
| --- |
| 제목이 공백 |
| 링크가 YouTube 주소가 아님 |

### TC-MUSIC-ADD-FEATURE-010: 성립하지 않는 입력으로 추가하면 고쳐야 할 입력으로 초점을 옮긴다

- 근거: `feature > 제목 미입력`, `feature > 링크 형식 불만족`
- Given: MusicAdd 화면에 테스트 데이터의 입력 상태가 만들어져 있다.
- When: 사용자가 곡 추가를 실행한다.
- Then: 입력 초점이 테스트 데이터의 자리에 있다.
- 테스트 데이터:

| 입력 상태 | 초점 |
| --- | --- |
| 제목이 비어 있음 | 제목 입력 |
| 제목은 있고 링크가 YouTube 주소가 아님 | 링크 입력 |

### TC-MUSIC-ADD-FEATURE-013: 화면이 재생성되어도 작성 중이던 내용을 유지한다

- 근거: `feature > 작성 상태 유지`
- Given: 제목과 가수와 YouTube 영상 링크를 입력한 MusicAdd 화면이 표시되어 있다.
- When: 화면이 회전하거나 시스템에 의해 재생성된다.
- Then: 재생성 전의 제목, 가수, 링크가 그대로 표시되고 그 링크의 썸네일 미리보기도 그대로 표시된다.

### TC-MUSIC-ADD-FEATURE-014: 앱을 다시 실행해 진입하면 새 입력 상태로 시작한다

- 근거: `feature > 작성 상태 유지`
- Given: 이전 실행에서 MusicAdd 화면에 제목, 가수와 링크를 입력한 뒤 앱을 종료했다.
- When: 앱을 다시 실행해 MusicAdd 화면에 진입한다.
- Then: 제목, 가수와 링크가 비어 있다.
- 작성하지 않는 이유: 앱 프로세스를 종료하고 다시 시작해야 확인할 수 있어 앱의 단위 테스트 환경에서 결정적으로 판정할 수 없다. 프로세스 재시작을 제어할 수 있는 테스트 환경이 마련되면 작성한다.

### TC-MUSIC-ADD-FEATURE-015: 뒤로가면 이전 화면으로 돌아간다

- 근거: `feature > 뒤로가기`
- Given: MusicAdd 화면이 단독으로 표시되어 있다.
- When: 사용자가 뒤로가기를 실행한다.
- Then: MusicAdd 화면에 진입하기 전 화면으로 돌아간다.

### TC-MUSIC-ADD-FEATURE-016: 불러오기에 성공하면 제목과 가수를 채운다

- 근거: `feature > 링크로 곡 정보 불러오기`
- Given: YouTube 영상 링크가 입력되어 있고 제목과 가수가 비어 있으며, 영상 정보 조회가 영상 제목과 채널 이름을 돌려주도록 설정되어 있다.
- When: 사용자가 불러오기를 실행한다.
- Then: 제목에 영상 제목이, 가수에 채널 이름이 표시되고 링크 입력과 썸네일 미리보기는 바뀌지 않는다.

### TC-MUSIC-ADD-FEATURE-024: 불러오기에 성공하면 이미 채워진 제목과 가수도 덮어쓴다

- 근거: `domain > 불러온 값을 채우는 기준`
- Given: YouTube 영상 링크와 테스트 데이터의 제목·가수 상태가 만들어져 있고, 영상 정보 조회가 영상 제목과 채널 이름을 돌려주도록 설정되어 있다.
- When: 사용자가 불러오기를 실행한다.
- Then: 제목이 영상 제목으로, 가수가 채널 이름으로 바뀐다.
- 테스트 데이터:

| 제목 | 가수 |
| --- | --- |
| 비어 있음 | 사용자가 입력한 값 |
| 사용자가 입력한 값 | 비어 있음 |
| 사용자가 입력한 값 | 사용자가 입력한 값 |
| 공백 문자뿐임 | 공백 문자뿐임 |

### TC-MUSIC-ADD-FEATURE-018: 불러오기를 처리하는 동안 진행 상태를 표시한다

- 근거: `feature > 링크로 곡 정보 불러오기`
- Given: YouTube 영상 링크가 입력되어 있고 영상 정보 조회가 완료되지 않고 진행 중인 상태로 설정되어 있다.
- When: 사용자가 불러오기를 실행한 뒤 화면을 확인한다.
- Then: 조회가 끝날 때까지 불러오기의 진행 상태가 표시된다.

### TC-MUSIC-ADD-FEATURE-019: 링크가 성립하지 않으면 불러오지 않고 링크 입력을 알린다

- 근거: `feature > 불러오기 실패`
- Given: MusicAdd 화면에 테스트 데이터의 링크 상태가 만들어져 있다.
- When: 사용자가 불러오기를 실행한다.
- Then: 테스트 데이터의 피드백이 제공되고 입력 초점이 링크 입력으로 옮겨지며, 제목과 가수가 바뀌지 않는다.
- 테스트 데이터:

| 링크 상태 | 피드백 |
| --- | --- |
| 비어 있음 | 링크 입력이 필요함 |
| 공백 문자뿐임 | 링크 입력이 필요함 |
| YouTube 주소가 아님 | YouTube 영상 링크가 필요함 |

### TC-MUSIC-ADD-FEATURE-020: 영상 정보를 가져오지 못하면 실패를 알리고 입력을 유지한다

- 근거: `feature > 불러오기 실패`
- Given: YouTube 영상 링크가 입력되어 있고 영상 정보 조회가 실패하도록 설정되어 있다.
- When: 사용자가 불러오기를 실행한다.
- Then: 불러오지 못했다는 피드백이 제공되고 제목, 가수와 링크가 지워지거나 바뀌지 않는다.

### TC-MUSIC-ADD-FEATURE-021: 곡 추가로 입력을 비운 뒤에는 앞선 불러오기 결과를 채우지 않는다

- 근거: `domain > 불러온 값을 채우는 기준`
- Given: YouTube 영상 링크와 공백이 아닌 제목과 가수가 입력되어 있고, 영상 정보 조회가 완료되지 않고 진행 중이다.
- When: 사용자가 불러오기를 실행한 뒤 곡 추가를 실행해 성공하고, 그 다음에 영상 정보 조회가 성공으로 끝난다.
- Then: 제목, 가수와 링크가 비어 있는 상태로 유지되고 조회 결과가 채워지지 않는다.

### TC-MUSIC-ADD-FEATURE-023: 썸네일만 바꾸거나 지우는 조작을 두지 않는다

- 근거: `feature > 썸네일 확인`
- Given: YouTube 영상 링크가 입력되어 썸네일 미리보기가 표시된 MusicAdd 화면이 표시되어 있다.
- When: 사용자가 썸네일 미리보기를 확인한다.
- Then: 썸네일 미리보기에 선택할 수 있는 동작이 없다.

## domain

### TC-MUSIC-ADD-DOMAIN-001: 성립하지 않는 입력은 곡을 추가하지 않는다

- 근거: `domain > 추가 성립 조건`
- Given: 로그인한 사용자 계정이 있다.
- When: 테스트 데이터의 입력으로 곡 추가를 실행한다.
