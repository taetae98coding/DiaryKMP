- Given: 종일이 아닌 초기 기간이 제공된 컴포넌트에서 사용자가 종일 기간으로 바꿔 두었다.
- When: 사용자가 앱을 새로 실행해 같은 초기 기간으로 컴포넌트가 다시 표시된다.
- Then: 사용자가 바꾼 종일 여부는 이어지지 않고, 제공된 초기 기간의 종일 아님, 시작·종료 날짜와 시간이 표시된다.

### TC-6f351d2a-32ef-4c38-a105-403cc0b1e90e: 사용을 끄면 기간을 조작할 수 없다

- When: 사용자가 날짜·시간 입력을 사용하지 않도록 전환한다.
- Then: 기간을 조작할 수 없다.

| 사용 중, 종일 아님, 오늘 20:00 ~ 21:00 | 종일 아님, 2일 뒤 09:00 ~ 3일 뒤 08:00 (이전 기간보다 뒤) |
