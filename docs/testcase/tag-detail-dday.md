# TagDetail 디데이 탭 테스트 케이스

기준 스펙: [TagDetail 디데이 탭 스펙](../spec/client/tag-detail-dday.md)

자리 표시 케이스의 `근거`가 가리키는 절은 공통 규칙을 [페이지 조회 목록의 자리 표시 스펙](../spec/client/paged-list-placeholder.md)에, 빈 상태 케이스의 `근거`가 가리키는 절은 [목록 빈 상태 스펙](../spec/client/list-empty-state.md)에, 새로고침 케이스의 `근거`가 가리키는 절은 [새로고침 스펙](../spec/client/sync-refresh.md)에, 삭제와 실행 취소 케이스의 `근거`가 가리키는 절은 [DDayHome 화면 스펙](../spec/client/dday-home.md)의 삭제 규칙에 위임한다. 카드 문구의 계산 규칙은 [디데이 앱 스펙](../spec/client/dday.md)의 테스트 케이스가 다루며, 이 문서는 그 문구가 목록에 표시되는 것과 오늘을 다시 정하는 시점만 다룬다. 표시 범위에 따라 목록 탭에 담기는 태그는 [TagDetail 테스트 케이스](./tag-detail.md)가 다룬다.

## feature

### TC-08893b99-d83c-4ef2-8400-eb88e6695b68: 대상 태그와 연결된 디데이만 목록에 표시한다

- 근거: `feature > 목록 표시`
- Given: 표시 범위가 `이 태그만`이고, 상세 대상 태그와 연결된 디데이와 다른 태그에만 연결된 디데이가 저장되어 있다.
- When: 사용자가 TagDetail 화면에서 디데이 탭을 연다.
- Then: 대상 태그와 연결된 디데이만 목록에 표시된다.

### TC-4b70ffce-8100-48bd-9e5e-d9dc5017875b: 각 디데이의 제목과 카드 문구를 표시한다

- 근거: `feature > 목록 표시`
- Given: 오늘이 2026년 3월 20일이고, 상세 대상 태그에 제목이 `우리`, 기준일이 2025년 1월 15일이고 기준일을 1일로 세기가 켜진 디데이가 연결되어 있다.
- When: 사용자가 TagDetail 화면에서 디데이 탭을 연다.
- Then: 그 디데이 항목에 제목 `우리`와 카드 문구 `430일(1년 2개월)`이 표시된다.
