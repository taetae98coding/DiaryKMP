# 메모 웹 입력 컴포넌트 테스트 케이스

기준 스펙: [메모 웹 입력 컴포넌트 스펙](../spec/client/memo-web-input.md)

이 문서의 케이스는 MemoAdd 화면과 MemoDetail 화면에서 같은 결과로 판정된다. 사용자가 반영한 선택이 어디에 반영되는지는 [MemoAdd 테스트 케이스](./memo-add.md)와 [MemoDetail 테스트 케이스](./memo-detail.md)에서 다룬다.

검색어의 정규화와 일치 판정, 검색 결과 없음 판정은 [검색어 일치 판정 스펙](../spec/client/search-match.md)에 위임되어 있으며, 웹 선택 목록에서의 결과를 이 문서의 케이스로 덮는다. 아직 준비되지 않은 자리의 표시는 [페이지 조회 목록의 자리 표시 스펙](../spec/client/paged-list-placeholder.md)에 위임되어 있다.

케이스의 근거는 기준 스펙의 절이며, 그 규칙은 기준 스펙이 따르는 [메모 항목 선택 입력 공통 스펙](../spec/client/memo-entity-input.md)이 소유한다.

## feature

### TC-7d49b3ab-3e88-4679-b310-c578b24f36c9: 웹 선택 목록을 열면 목록에 나타나는 웹 항목이 표시된다

- 근거: `feature > 웹 선택 목록`
- Given: 선택할 수 있는 웹 항목이 있고 웹 선택 목록이 닫혀 있다.
- When: 사용자가 웹 입력의 추가 항목을 눌러 웹 선택 목록을 연다.
- Then: 목록에 나타나는 웹 항목과 각 웹 항목의 선택 여부가 표시된다.

### TC-eecef363-624e-475c-8e0b-7d02e5d3c91d: 웹 추가 항목이 웹 입력에 항상 표시된다

- 근거: `feature > 웹 선택 목록`
- Given: 선택한 웹 항목이 테스트 데이터와 같다.
- When: 사용자가 웹 입력을 확인한다.
- Then: 웹 입력에 추가 항목이 표시된다.
- 테스트 데이터:

| 선택한 웹 항목 |
| --- |
| 없음 |
| 웹 항목 여러 개 |

추가 항목을 눌렀을 때의 동작 판정은 다음 케이스가 나누어 덮는다.

```mermaid
flowchart TD
    Click["추가 항목 누름"] --> Ready{"목록의 대상을<br/>확인했는가"}
    Ready -- "아니오 · TC-b2244317-117b-4155-b9d9-b878e91f13e0 · TC-bafc6159-4597-4eb4-a68d-dcfb894022d0" --> Open["웹 선택 목록 열기"]
    Ready -- 예 --> Any{"선택할 수 있는 웹 항목이<br/>하나라도 있는가"}
    Any -- "예 · TC-7d49b3ab-3e88-4679-b310-c578b24f36c9" --> Open
    Any -- "아니오 · TC-5590412d-9887-4f1c-b2ca-36577da63ad6" --> Move["WebAdd 화면으로 이동"]
```

- Given: 검색어를 만족하는 웹 항목과 만족하지 않는 웹 항목이 함께 저장되어 있다.
- When: 웹 선택 목록에 그 검색어를 입력한다.
- Then: 검색어를 만족하는 웹 항목만 조회 결과로 나타난다.

### TC-027e9d6f-0e02-4be7-9ec2-cf03b407ddc0: 검색어가 바뀌면 첫 페이지부터 다시 조회한다

- 근거: `data > 웹 목록 조회`
- Given: 웹 선택 목록에서 뒷부분까지 확인한 상태다.
- When: 사용자가 검색어를 바꾼다.
- Then: 새 검색어 기준으로 첫 페이지부터 다시 조회되어 목록이 정렬 순서의 앞부분부터 나타난다.

### TC-4c802fe3-ab30-4d77-85f9-ca5c61f79ecd: 저장된 웹 항목이 바뀌면 웹 입력과 웹 선택 목록에 함께 반영된다

- 근거: `data > 내용 갱신`
- Given: 선택한 웹 항목이 웹 입력에 표시되어 있고 웹 선택 목록이 열려 있다.
- When: 그 웹 항목의 제목이 바뀌거나 새 웹 항목이 추가된다.
- Then: 바뀐 내용이 웹 입력의 칩과 웹 선택 목록에 함께 나타난다.
