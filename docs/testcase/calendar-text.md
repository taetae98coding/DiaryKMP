# CalendarText 테스트 케이스

기준 스펙: [CalendarText 컴포넌트 스펙](../spec/client/calendar-text.md)

## feature

### TC-CALENDAR-TEXT-FEATURE-001: 지정한 글이 표시된다

- 근거: `feature > 글 표시`
- Given: 표시할 글로 `제헌절`이 지정된다.
- When: CalendarText가 표시된다.
- Then: `제헌절`이 표시된다.

## domain

### TC-CALENDAR-TEXT-DOMAIN-001: 글이 한 번에 다 들어가지 않아도 줄이지 않고 전체 글을 담는다

- 근거: `domain > 표시 내용`, `feature > 넘치는 글 확인`
- Given: 표시할 글로 CalendarText의 너비에 한 번에 다 들어가지 않는 긴 글이 지정된다.
- When: CalendarText가 표시된다.
- Then: 표시된 글은 뒷부분이 생략되지 않고 지정한 글 전체를 담는다.

## 작성하지 않는 이유

글이 한 번에 다 보이지 않을 때 넘치는 부분이 시간에 따라 흘러 지나가며 드러나는지는 시간에 따라 변하는 시각 표현을 판정해야 하므로 블랙박스 유닛 테스트 케이스로 작성하지 않는다. 화면의 실제 변화를 결정적으로 비교할 수 있는 테스트 환경이 갖춰지면 검증한다. 넘치는 글이 생략되지 않고 전체로 담기는 것은 TC-CALENDAR-TEXT-DOMAIN-001이 확인한다.

배치하는 화면이 지정한 배경색의 적용, 배경색을 지정하지 않았을 때 화면 기본 글자색을 사용하는 결과와 글자색의 가독성은 실제 색상을 판정해야 하므로 블랙박스 유닛 테스트 케이스로 작성하지 않는다. 색상 결과를 결정적으로 비교할 수 있는 테스트 환경이 갖춰지면 검증한다.
