# CalendarText 테스트 케이스

기준 스펙: [CalendarText 컴포넌트 스펙](../spec/client/calendar-text.md)

## feature

### TC-57f3c28c-32b4-46c0-a809-3ec05a8ee224: 지정한 글이 표시된다

- 근거: `feature > 글 표시`
- Given: 표시할 글로 `제헌절`이 지정된다.
- When: CalendarText가 표시된다.
- Then: `제헌절`이 표시된다.

## domain

### TC-1b7aa080-34ea-4ca9-adb2-fe9abdd0e32f: 글이 한 번에 다 들어가지 않아도 줄이지 않고 전체 글을 담는다

- 근거: `domain > 표시 내용`, `feature > 넘치는 글 확인`
- Given: 표시할 글로 CalendarText의 너비에 한 번에 다 들어가지 않는 긴 글이 지정된다.
- When: CalendarText가 표시된다.
- Then: 표시된 글은 뒷부분이 생략되지 않고 지정한 글 전체를 담는다.

### TC-132b85f0-9035-40bd-94bf-32cb5a47c6e9: 지정한 배경색 위에 글이 표시된다

- 근거: `domain > 색상 결정`
- Given: 표시할 글로 `제헌절`, 배경색으로 빨간색이 지정된다.
- When: CalendarText가 표시된다.
- Then: `제헌절`이 빨간색 배경 위에 표시된다.
- 작성하지 않는 이유: 배경색은 실제 화면에 칠해진 색을 판정해야 해 반복해서 같은 결과로 판정할 수 없다. 화면에 칠해진 색을 결정적으로 비교할 수 있는 환경이 갖춰지면 자동화한다.

### TC-e2aa7c60-900d-4973-8734-d2b844a43479: 배경색을 지정하지 않으면 화면 기본 글자색을 배경색으로 사용한다

- 근거: `domain > 색상 결정`
- Given: CalendarText를 배치한 화면의 기본 글자색이 파란색이고, 표시할 글로 `제헌절`이 지정되며 배경색은 지정되지 않는다.
- When: CalendarText가 표시된다.
- Then: `제헌절`이 파란색 배경 위에 표시된다.
- 작성하지 않는 이유: 배경색은 실제 화면에 칠해진 색을 판정해야 해 반복해서 같은 결과로 판정할 수 없다. 화면에 칠해진 색을 결정적으로 비교할 수 있는 환경이 갖춰지면 자동화한다.

### TC-f72def00-66a7-4eef-89e5-9d995fa8be6e: 글자색은 흰색과 검은색 중 배경색과의 명암 대비가 더 큰 색이다

- 근거: `domain > 색상 결정`
- Given: 표시할 글로 `제헌절`, 배경색으로 테스트 데이터의 배경색이 지정된다.
- When: CalendarText가 표시된다.
- Then: `제헌절`의 글자색이 테스트 데이터의 글자색이다.
- 테스트 데이터:

| 배경색 | 글자색 |
| --- | --- |
| 밝은 노란색 `#FFEB3B` | 검은색 |
| 짙은 남색 `#1A237E` | 흰색 |

### TC-9e3c465f-4e20-4dc0-99e5-6acd1753d579: 두 색과의 명암비가 같으면 글자색은 검은색이다

- 근거: `domain > 색상 결정`
- Given: 표시할 글로 `제헌절`, 배경색으로 흰색과의 명암비와 검은색과의 명암비가 같은 색이 지정된다.
- When: CalendarText가 표시된다.
- Then: `제헌절`의 글자색이 검은색이다.
- 작성하지 않는 이유: 검증에 쓸 수 있는 배경색 가운데 두 명암비가 정확히 같아지는 색이 없어, 같은 Given을 재현할 수 없다. 명암비를 직접 지정하거나 같은 명암비를 갖는 색을 정확히 표현할 수 있는 수단이 갖춰지면 자동화한다.
