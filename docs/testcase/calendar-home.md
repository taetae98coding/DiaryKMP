# CalendarHome 테스트 케이스

기준 스펙: [CalendarHome 스펙](../spec/client/calendar-home.md)

태그 필터 케이스의 `근거`가 가리키는 CalendarHome 스펙의 태그 필터 관련 절은 공통 규칙을 [태그 필터 스펙](../spec/client/tag-filter.md)에 위임하고, 필터가 적용되어 있는지 알리는 기준은 [목록 필터 반영 스펙](../spec/client/list-filter.md)에 위임한다.

캘린더에 표시할 메모, 생일, 날씨를 정하는 조회 규칙과 숨김 공휴일, 위치 권한 요청, 날짜 선택 자체의 행동은 각각 [캘린더 메모 표시](./calendar-memo.md), [캘린더 연락처 생일 표시](./calendar-contact-birthday.md), [현재 날씨 동기화](./weather-fetch.md), [공휴일 노출 설정](./holiday-visibility.md), [위치 권한 요청](./location-permission.md), [Calendar 날짜 선택](./calendar-select.md) 테스트 케이스가 다룬다. 이 문서는 캘린더 홈 화면이 정하는 조회 기간, 동기화 계기와 화면 노출 결과만 다루며, 공휴일 케이스는 노출 설정을 한 번도 고르지 않은 상태를 전제한다.
