# Memo 목록·상세 배치 테스트 케이스

기준 스펙: [Memo 목록·상세 배치 스펙](../spec/client/memo-list-detail.md)

이 문서에서 `feature > 함께 사용할 때의 행동` 절은 [목록·상세 배치 공통 스펙](../spec/client/list-detail-pane.md)이 소유한다. 나머지 케이스의 절은 기준 스펙이 소유한다.

## feature

### TC-MEMO-LIST-DETAIL-FEATURE-001: 함께 표시하는 환경에서는 목록과 상세 영역이 모두 표시된다

- 근거: `feature > 상세 영역의 구성`
- Given: 목록과 상세 영역을 함께 표시하는 환경이다.
- When: 사용자가 메모 주요 목적지에 진입한다.
- Then: 메모 목록과 상세 영역이 함께 표시된다.
- 작성하지 않는 이유: 목록과 상세 배치는 여러 화면과 전환 상태를 함께 구동해야 관찰할 수 있어 현재 테스트 환경에서는 결정적으로 검증할 수 없다. 여러 화면과 전환 상태를 제어할 수 있는 테스트 환경이 갖춰지면 자동화한다.

### TC-MEMO-LIST-DETAIL-FEATURE-002: 선택한 메모가 없으면 상세 영역에 메모 추가 화면이 표시된다

- 근거: `feature > 상세 영역의 구성`
- Given: 목록과 상세 영역이 함께 표시되고 사용자가 선택한 메모가 없다.
- When: 사용자가 메모 주요 목적지에 진입한다.
- Then: 상세 영역에 메모 추가 화면이 표시된다.
- 작성하지 않는 이유: TC-MEMO-LIST-DETAIL-FEATURE-001과 같은 이유로 통합 UI 테스트 환경이 갖춰지면 자동화한다.

### TC-MEMO-LIST-DETAIL-FEATURE-003: 메모를 선택하면 상세 영역에 해당 메모의 상세 화면이 표시된다

- 근거: `feature > 상세 영역의 구성`
- Given: 목록과 상세 영역이 함께 표시되고 메모 목록에 메모가 있다.
- When: 사용자가 목록에서 메모 하나를 선택한다.
- Then: 상세 영역에 선택한 메모의 상세 화면이 표시된다.
- 작성하지 않는 이유: TC-MEMO-LIST-DETAIL-FEATURE-001과 같은 이유로 통합 UI 테스트 환경이 갖춰지면 자동화한다.

### TC-MEMO-LIST-DETAIL-FEATURE-004: 한 영역만 표시하는 환경에서는 현재 영역만 표시된다

- 근거: `feature > 상세 영역의 구성`
- Given: 한 영역만 표시하는 환경이다.
- When: 사용자가 메모 주요 목적지에 진입한다.
- Then: 현재 목록 또는 상세 영역 하나만 표시된다.
- 작성하지 않는 이유: TC-MEMO-LIST-DETAIL-FEATURE-001과 같은 이유로 통합 UI 테스트 환경이 갖춰지면 자동화한다.

### TC-MEMO-LIST-DETAIL-FEATURE-009: 목록과 함께 표시된 메모 추가 화면에는 목록으로 돌아가는 별도 동작이 없다

### TC-MEMO-LIST-DETAIL-FEATURE-011: 한 영역만 표시되면 목록에서 메모 추가를 실행할 수 있다

- 근거: `feature > 함께 사용할 때의 행동`

### TC-MEMO-LIST-DETAIL-FEATURE-012: 목록과 함께 표시된 메모 상세 화면에는 목록으로 돌아가는 별도 동작이 없다

### TC-MEMO-LIST-DETAIL-FEATURE-013: 상세 영역에 메모 추가 화면이 표시되면 목록에서 추가를 다시 실행할 수 없다

### TC-MEMO-LIST-DETAIL-FEATURE-014: 상세 영역에 메모 상세 화면이 표시되면 목록에서 메모 추가를 실행할 수 있다

- 근거: `feature > 함께 사용할 때의 행동`

- When: 사용자가 목록 화면을 확인한다.
- Then: 목록에서 메모 추가를 실행할 수 있다.

### TC-MEMO-LIST-DETAIL-FEATURE-015: 상세 화면과 함께 표시된 목록에서 추가를 실행하면 상세 영역에 메모 추가 화면이 표시된다

- 근거: `feature > 함께 사용할 때의 행동`
- Given: 목록과 상세 영역이 함께 표시되고 상세 영역에 메모 상세 화면이 표시되어 있다.
- When: 사용자가 목록에서 메모 추가를 실행한다.
- Then: 상세 영역에 메모 추가 화면이 표시된다.
- 작성하지 않는 이유: TC-MEMO-LIST-DETAIL-FEATURE-001과 같은 이유로 목록과 상세 배치를 함께 구동해야 관찰할 수 있어, 통합 UI 테스트 환경이 갖춰지면 자동화한다.

### TC-MEMO-LIST-DETAIL-FEATURE-016: 메모 목록에서 진입하지 않은 상세 화면은 목록과 함께 표시하지 않는다

- 근거: `feature > 상세 영역의 구성`

- When: 사용자가 메모 목록이 아닌 화면에서 테스트 데이터의 화면으로 이동한다.
- Then: 해당 화면을 목록·상세 배치에 참여시키지 않아 단독으로 표시한다.
- 테스트 데이터: 캘린더 홈에서 진입한 메모 상세, 캘린더 홈에서 진입한 메모 추가, 완료된 메모 목록에서 진입한 메모 상세

### TC-MEMO-LIST-DETAIL-FEATURE-017: 메모 목록에서 이어 진입한 상세 화면은 목록과 함께 표시한다

- 근거: `feature > 상세 영역의 구성`
- Given: 목록과 상세 영역을 함께 표시하는 환경이다.
- When: 사용자가 메모 목록에서 테스트 데이터의 순서로 상세 영역의 화면을 연다.
- Then: 각 화면을 목록·상세 배치의 상세 영역에 표시한다.
- 테스트 데이터: 메모 상세, 메모 추가, 메모 추가에 이어 선택한 메모 상세

### TC-MEMO-LIST-DETAIL-FEATURE-018: 메모 상세가 놓인 동안 다른 메모를 선택하면 앞 메모로 돌아가는 기록을 남기지 않는다

- 근거: `feature > 상세 영역의 구성`
- Given: 목록과 상세 영역이 함께 표시되고 테스트 데이터의 화면이 상세 영역에 놓여 있다.
- When: 사용자가 목록에서 다른 메모를 선택한다.
- Then: 상세 영역에 새로 선택한 메모의 상세가 놓인다. 앞서 보던 메모 상세로 돌아가는 기록은 남지 않고, 그보다 먼저 놓였던 화면의 기록은 그대로 남는다.
- 테스트 데이터:

| 상세 영역에 놓인 화면 | 선택 뒤 되돌아갈 화면 |
| --- | --- |
| 선택한 메모 없음 | 메모 추가 |
| 메모 상세 | 메모 추가 |
| 메모 추가에 이어 연 메모 상세 | 메모 추가 |

### TC-MEMO-LIST-DETAIL-FEATURE-019: 상세 영역에서 메모를 복사하면 복사한 메모의 상세로 바뀐다

- 근거: `feature > 상세 영역의 구성`
- Given: 목록과 상세 영역이 함께 표시되고, 메모 추가에 이어 연 메모 상세가 상세 영역에 놓여 있다.
- When: 사용자가 상세 영역의 메모를 복사한다.
- Then: 상세 영역에 복사한 메모의 상세가 놓이고, 원본 메모 상세로 돌아가는 기록은 남지 않으며 메모 추가의 기록은 그대로 남는다.

### TC-MEMO-LIST-DETAIL-FEATURE-020: 상세 영역에서 메모를 삭제하면 그 전에 놓였던 화면으로 되돌아간다

- 근거: `feature > 상세 영역의 구성`
- Given: 목록과 상세 영역이 함께 표시되고, 메모 추가에 이어 연 메모 상세가 상세 영역에 놓여 있다.
- When: 사용자가 상세 영역의 메모를 삭제한다.
- Then: 목록은 그대로 유지되고 상세 영역에는 메모 추가가 놓인다.
- 작성하지 않는 이유: 삭제 뒤 상세 영역에 놓이는 화면은 메모 상세 화면의 삭제 결과와 목록·상세 배치를 함께 구동해야 관찰할 수 있어 현재 테스트 환경에서는 결정적으로 검증할 수 없다. 여러 화면과 전환 상태를 제어할 수 있는 통합 UI 테스트 환경이 갖춰지면 자동화한다.

### TC-MEMO-LIST-DETAIL-FEATURE-021: 상세 영역에서 뒤로가기를 사용하면 상세 영역만 그 전 화면으로 되돌아간다

- 근거: `feature > 뒤로가기`
- Given: 목록과 상세 영역이 함께 표시되고 테스트 데이터의 화면이 상세 영역에 놓여 있다.
- When: 사용자가 시스템 뒤로가기를 사용한다.
- Then: 목록은 그대로 유지되고 상세 영역에는 테스트 데이터의 결과 화면이 놓인다.
- 테스트 데이터:

| 상세 영역에 놓인 화면 | 결과 화면 |
| --- | --- |
| 메모 추가에 이어 연 메모 상세 | 메모 추가 |
| 선택한 메모 없이 목록에서 연 메모 상세 | 선택한 메모가 없을 때의 메모 추가 |

- 작성하지 않는 이유: TC-MEMO-LIST-DETAIL-FEATURE-001과 같은 이유로, 여러 화면의 실제 표시와 시스템 뒤로가기를 함께 구동해야 관찰할 수 있어 통합 UI 테스트 환경이 갖춰지면 자동화한다.

### TC-MEMO-LIST-DETAIL-FEATURE-022: 상세 영역에 메모 추가만 놓여 있으면 뒤로가기는 목록의 뒤로가기와 같은 결과를 낸다

- 근거: `feature > 뒤로가기`
- Given: 목록과 상세 영역이 함께 표시되고 선택한 메모가 없어 상세 영역에 메모 추가만 놓여 있다.
- When: 사용자가 시스템 뒤로가기를 사용한다.
- Then: 상세 영역은 바뀌지 않고, 메모 목록에서 뒤로가기를 사용한 것과 같은 결과가 나타난다.
- 작성하지 않는 이유: 결과가 주요 목적지 사이의 뒤로가기에 따라 정해져 메모 배치와 주요 목적지 전환을 함께 구동해야 관찰할 수 있다. 주요 목적지 전환과 시스템 뒤로가기를 함께 제어할 수 있는 통합 UI 테스트 환경이 갖춰지면 자동화한다.

### TC-MEMO-LIST-DETAIL-FEATURE-023: 상세 영역의 메모에서 연 연결 항목 화면은 단독으로 표시하고, 돌아오면 떠나기 전의 메모가 놓인다

- 근거: `feature > 상세 영역의 구성`
- Given: 목록과 상세 영역이 함께 표시되고 상세 영역에 메모 상세가 놓여 있다.
- When: 사용자가 그 메모에서 테스트 데이터의 화면으로 이동했다가 뒤로가기를 사용한다.
- Then: 이동한 화면은 목록과 함께 표시되지 않고 단독으로 표시되며, 돌아오면 목록과 함께 상세 영역에 떠나기 전의 메모 상세가 놓인다.
- 테스트 데이터: 태그 상세, 태그 추가, 웹 항목 상세, 웹 항목 추가, 연락처 상세, 연락처 추가, 장소 상세, 장소 추가
- 작성하지 않는 이유: 연결 항목 화면은 다른 기능이 제공하는 화면이라 그 화면과 메모 배치를 함께 구동해야 단독 표시와 복귀 결과를 관찰할 수 있다. 여러 기능의 화면을 함께 띄우고 전환 상태를 제어할 수 있는 통합 UI 테스트 환경이 갖춰지면 자동화한다.

### TC-MEMO-LIST-DETAIL-FEATURE-024: 필터를 열어도 상세 영역에 놓인 화면은 바뀌지 않는다

- 근거: `feature > 정렬과 필터`
- Given: 목록과 상세 영역이 함께 표시되고 테스트 데이터의 화면이 상세 영역에 놓여 있다.
- When: 사용자가 목록에서 필터를 연다.
- Then: 필터가 열린 동안에도 상세 영역에는 같은 화면이 목록과 함께 놓여 있다.
- 테스트 데이터: 메모 상세, 메모 추가

## domain

### TC-MEMO-LIST-DETAIL-DOMAIN-001: 다른 주요 목적지에 다녀오면 상세 영역이 선택 전 상태로 돌아간다

- 근거: `domain > 유지와 초기화 기준`
- Given: 목록과 상세 영역이 함께 표시되고 상세 영역에 테스트 데이터의 화면이 놓여 있다.
- When: 사용자가 공통 내비게이션에서 다른 주요 목적지로 이동했다가 메모를 다시 선택한다.
- Then: 메모 목록만 열린 상태로 돌아와 상세 영역에는 선택 전 화면인 메모 추가가 놓이고, 떠나기 전에 놓였던 화면은 남아 있지 않아 뒤로가면 `캘린더`로 돌아간다.
- 테스트 데이터:

| 상세 영역에 놓인 화면 | 다녀온 주요 목적지 |
| --- | --- |
| 메모 상세 | `태그`, `캘린더`, `루틴`, `더보기` |
| 메모 상세 위에 목록에서 연 메모 추가 | `태그`, `캘린더`, `루틴`, `더보기` |

### TC-MEMO-LIST-DETAIL-DOMAIN-002: 다른 주요 목적지에 다녀오면 상세 영역의 메모 추가는 입력과 선택이 모두 비어 있는 상태로 시작한다

- 근거: `domain > 유지와 초기화 기준`
- Given: 목록과 상세 영역이 함께 표시되고 선택한 메모가 없어 상세 영역에 메모 추가가 놓여 있다. 사용자가 메모 추가에 제목과 설명을 입력하고 기간을 켰으며 태그, 웹 항목, 연락처, 장소를 하나씩 골랐다.
- When: 사용자가 공통 내비게이션에서 다른 주요 목적지로 이동했다가 메모를 다시 선택한다.
- Then: 상세 영역의 메모 추가는 제목과 설명이 비어 있고 기간이 꺼져 있으며, 앞서 고른 태그, 웹 항목, 연락처, 장소가 하나도 선택되어 있지 않다.

### TC-MEMO-LIST-DETAIL-DOMAIN-003: 배치를 떠나기 전에는 상세 영역에서 다른 화면에 다녀와도 메모 추가의 입력과 선택이 남는다

- 근거: `domain > 유지와 초기화 기준`
- Given: 목록과 상세 영역이 함께 표시되고 선택한 메모가 없어 상세 영역에 메모 추가가 놓여 있다. 사용자가 메모 추가에 제목과 설명을 입력하고 기간을 켰으며 태그, 웹 항목, 연락처, 장소를 하나씩 골랐다.
- When: 사용자가 테스트 데이터의 화면으로 이동했다가 뒤로가기를 사용해 상세 영역의 메모 추가로 돌아온다.
- Then: 메모 추가에 입력하던 제목과 설명, 켜 둔 기간, 고른 태그, 웹 항목, 연락처, 장소가 그대로 남아 있다.
- 테스트 데이터: 목록에서 고른 메모 상세, 메모 추가의 태그 입력에서 연 태그 추가

## 작성하지 않는 이유

두 영역의 너비 비율 조절과 조절 중 즉시 반영, 화면 재생성 후 비율 유지, 다른 주요 목적지에 다녀온 뒤와 앱 재실행 후 기본 비율 초기화는 실제 화면 크기와 실행 경계를 함께 판정해야 한다. 현재 테스트 환경에서는 결정적으로 자동화할 수 없으며, 화면 크기와 실행 경계를 제어·관찰할 수 있는 통합 UI 테스트 환경이 갖춰지면 자동화한다.
