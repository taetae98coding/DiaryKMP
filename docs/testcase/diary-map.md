# DiaryMap 테스트 케이스

기준 스펙: [DiaryMap 컴포넌트 스펙](../spec/diary-map.md)

## feature

### TC-DIARY-MAP-FEATURE-001: 초기 제공자를 지정하지 않으면 네이버 지도가 표시된다

- 근거: `feature > 지도 표시`, `domain > 지도 제공자`
- Given: 초기 지도 제공자를 지정하지 않았고 네이버 지도 인증과 준비가 성공하도록 정해져 있다.
- When: 지도가 준비된다.
- Then: 네이버 지도가 선택된 제공자의 지도로 표시된다.

### TC-DIARY-MAP-FEATURE-002: 지정된 초기 제공자의 지도가 표시된다

- 근거: `feature > 지도 표시`, `domain > 지도 제공자`
- Given: 초기 지도 제공자가 테스트 데이터의 제공자로 지정되고 해당 지도의 인증과 준비가 성공하도록 정해져 있다.
- When: 지도가 준비된다.
- Then: 테스트 데이터의 제공자가 선택되고 그 제공자의 지도만 표시된다.
- 테스트 데이터:

| 초기 제공자 |
| --- |
| 네이버 지도 |
| Google 지도 |

### TC-DIARY-MAP-FEATURE-003: 다른 제공자를 선택하면 해당 제공자의 지도로 전환된다

- 근거: `feature > 지도 제공자 전환`, `domain > 지도 제공자`
- Given: 테스트 데이터의 선택 전 제공자 지도가 표시되어 있고 선택할 제공자의 인증과 준비가 성공하도록 정해져 있다.
- When: 사용자가 테스트 데이터의 다른 제공자를 선택한다.
- Then: 기존 지도는 사라지고 선택한 제공자의 지도만 표시된다.
- 테스트 데이터:

| 선택 전 제공자 | 선택할 제공자 |
| --- | --- |
| 네이버 지도 | Google 지도 |
| Google 지도 | 네이버 지도 |

### TC-DIARY-MAP-FEATURE-004: 이미 선택된 제공자를 다시 선택하면 보고 있던 지도가 유지된다

- 근거: `feature > 지도 제공자 전환`
- Given: 테스트 데이터의 제공자 지도를 보고 있다.
- When: 사용자가 이미 선택된 제공자를 다시 선택한다.
- Then: 선택된 제공자와 보고 있던 지도가 그대로 유지된다.
- 테스트 데이터:

| 선택된 제공자 |
| --- |
| 네이버 지도 |
| Google 지도 |

### TC-DIARY-MAP-FEATURE-007: 지도가 준비되는 동안 지도 내용이 표시되지 않는다

- 근거: `feature > 지도 표시`
- Given: DiaryMap이 표시되었고 선택한 제공자의 지도 불러오기가 아직 완료되지 않았다.
- When: 사용자가 DiaryMap을 확인한다.
- Then: 지도 내용은 표시되지 않으며, 준비가 끝나면 선택된 제공자의 지도가 표시된다.
- 작성하지 않는 이유: 현재 테스트 환경에서는 지도 제공자의 준비 상태를 제어할 수 없다. 준비 상태를 제어할 수 있는 지도 렌더링 대체 환경이 제공되면 자동화한다.

### TC-DIARY-MAP-FEATURE-008: 지도를 불러오지 못해도 다른 제공자를 선택할 수 있다

- 근거: `feature > 지도 표시`
- Given: 선택한 제공자의 지도 불러오기가 실패했고, 다른 제공자의 인증과 지도 준비는 성공하도록 정해져 있다.
- When: 사용자가 다른 제공자를 선택한다.
- Then: 실패한 제공자의 지도는 표시되지 않고 새로 선택한 제공자의 지도가 표시된다.
- 작성하지 않는 이유: 현재 테스트 환경에서는 실제 지도 제공자의 불러오기 실패와 다른 제공자의 인증·준비 성공을 결정적으로 제어할 수 없다. 두 제공자의 결과를 제어할 수 있는 지도 렌더링 대체 환경이 제공되면 자동화한다.

### TC-DIARY-MAP-FEATURE-009: 지도 기본 조작으로 지도를 이동하고 확대·축소한다

- 근거: `feature > 지도 조작`
- Given: 선택한 제공자와 현재 환경이 지도 이동과 확대·축소를 지원하며 지도가 표시되어 있다.
- When: 사용자가 제공되는 기본 지도 조작으로 지도를 이동하거나 확대·축소한다.
- Then: 지도 중심이나 확대 수준이 사용자의 조작에 맞게 바뀐다.

- 작성하지 않는 이유: 현재 테스트 환경은 실제 지도 렌더링과 플랫폼 지도 입력 처리를 제공하지 않는다. 지도 입력과 카메라 결과를 제어·관찰할 수 있는 환경이 제공되면 자동화한다.

### TC-DIARY-MAP-FEATURE-010: 영역 크기가 바뀌어도 보고 있던 지도 위치를 유지한다

- 근거: `feature > 지도 조작`
- Given: 사용자가 DiaryMap의 지도를 기본 위치와 다른 위치 및 확대 수준으로 조작했다.
- When: DiaryMap이 배치된 영역의 크기가 바뀐다.
- Then: 사용자가 보고 있던 지도 위치와 확대 수준이 유지된다.
- 작성하지 않는 이유: 현재 테스트 환경은 실제 지도 렌더링의 영역 변경과 카메라 상태를 함께 관찰할 수 없다. 지도 영역과 카메라 결과를 제어·관찰할 수 있는 환경이 제공되면 자동화한다.

### TC-DIARY-MAP-FEATURE-011: 회전과 기울이기 조작으로 지도 시점을 바꾼다

- 근거: `feature > 지도 조작`
- Given: 선택한 제공자와 현재 환경이 지도 회전 또는 기울이기를 지원하며 지도가 표시되어 있다.
- When: 사용자가 제공되는 기본 지도 조작으로 지도를 회전하거나 기울인다.
- Then: 지도의 방향이나 기울기가 사용자의 조작에 맞게 바뀐다.

- 작성하지 않는 이유: 현재 테스트 환경은 실제 지도 렌더링과 플랫폼의 여러 손가락 입력 처리를 제공하지 않는다. 지도 입력과 카메라 결과를 제어·관찰할 수 있는 환경이 제공되면 자동화한다.

### TC-DIARY-MAP-FEATURE-036: 위치 권한이 허용되어 있으면 현 위치 점과 현 위치 컨트롤이 표시된다

- 근거: `feature > 현 위치 표시`
- Given: 위치 권한이 허용된 Android 또는 iOS에서 테스트 데이터의 제공자 지도가 표시되어 있다.
- When: 사용자가 지도를 확인한다.
- Then: 지도 위에 현 위치 점이 표시되고 현 위치 컨트롤을 사용할 수 있다.
- 테스트 데이터:

| 제공자 |
| --- |
| 네이버 지도 |
| Google 지도 |

- 작성하지 않는 이유: 현재 테스트 환경은 실제 지도 렌더링과 플랫폼의 위치 권한 상태를 제공하지 않아 현 위치 점과 컨트롤의 표시를 관찰할 수 없다. 권한 상태와 지도 렌더링 결과를 제어·관찰할 수 있는 환경이 제공되면 자동화한다.

### TC-DIARY-MAP-FEATURE-037: 현 위치 컨트롤을 선택하면 지도가 현 위치로 옮겨진다

- 근거: `feature > 현 위치 표시`
- Given: 위치 권한이 허용된 Android 또는 iOS에서 테스트 데이터의 제공자 지도가 현 위치와 다른 곳을 보고 있고, 디바이스가 테스트 데이터의 위도와 경도를 현 위치로 제공하도록 정해져 있다.
- When: 사용자가 현 위치 컨트롤을 선택한다.
- Then: 지도가 현 위치를 가운데에 두도록 옮겨지고, 컴포넌트를 배치한 화면이 확인하는 지도 위치와 보이는 영역도 옮겨진 위치로 바뀐다.
- 테스트 데이터:

| 제공자 |
| --- |
| 네이버 지도 |
| Google 지도 |

- 작성하지 않는 이유: 현재 테스트 환경은 실제 지도 제공자의 컨트롤 입력과 디바이스 위치, 카메라 상태를 제공하지 않는다. 컨트롤 입력과 현 위치, 카메라 결과를 제어·관찰할 수 있는 환경이 제공되면 자동화한다.

### TC-DIARY-MAP-FEATURE-038: 위치 권한이 허용되어 있지 않으면 현 위치 점과 현 위치 컨트롤이 표시되지 않는다

- 근거: `feature > 현 위치 표시`
- Given: 위치 권한이 허용되지 않은 Android 또는 iOS에서 테스트 데이터의 제공자 지도가 표시되어 있다.
- When: 사용자가 지도를 확인한다.
- Then: 현 위치 점과 현 위치 컨트롤이 모두 표시되지 않고, 사용자는 지도의 나머지 조작을 그대로 사용할 수 있다.
- 테스트 데이터:

| 제공자 |
| --- |
| 네이버 지도 |
| Google 지도 |

- 작성하지 않는 이유: 현재 테스트 환경은 실제 지도 렌더링과 플랫폼의 위치 권한 상태를 제공하지 않아 컨트롤의 미표시를 관찰할 수 없다. 권한 상태와 지도 렌더링 결과를 제어·관찰할 수 있는 환경이 제공되면 자동화한다.

### TC-DIARY-MAP-FEATURE-039: 현 위치를 확인하지 못하면 현 위치 컨트롤을 선택해도 지도가 옮겨지지 않는다

- 근거: `feature > 현 위치 표시`
- Given: 위치 권한이 허용된 Android 또는 iOS에서 지도가 표시되어 있고, 디바이스가 아직 위치를 알려 주지 않도록 정해져 있다.
- When: 사용자가 현 위치 컨트롤을 선택한다.
- Then: 현 위치 점이 표시되지 않고 지도 중심과 확대 수준도 바뀌지 않으며, 앱은 별도의 안내를 표시하지 않는다.
- 작성하지 않는 이유: 현재 테스트 환경은 디바이스 위치의 미제공 상태와 실제 지도 카메라 상태를 함께 제어·관찰할 수 없다. 현 위치와 카메라 결과를 제어·관찰할 수 있는 환경이 제공되면 자동화한다.

### TC-DIARY-MAP-FEATURE-015: 제공자가 지원하면 지도 위 장소 정보를 확인한다

- 근거: `feature > 지도 조작`
- Given: 선택한 제공자와 현재 환경이 지도 위 장소 정보 확인을 지원하며 지도가 표시되어 있다.
- When: 사용자가 지도 위 장소를 선택한다.
- Then: 선택한 장소의 정보가 지도 위에 표시된다.

- 작성하지 않는 이유: 현재 테스트 환경은 실제 지도 제공자의 장소 데이터와 렌더링 결과를 제공하지 않는다. 장소와 정보 표시를 제어·관찰할 수 있는 환경이 제공되면 자동화한다.

### TC-DIARY-MAP-FEATURE-016: Android의 Google 지도 도구 모음으로 기기의 Google 지도로 이동한다

- 근거: `feature > 지도 조작`
- Given: Google 지도가 표시된 DiaryMap이 Android에 표시되어 있다.
- When: 사용자가 지도 도구 모음을 선택한다.
- Then: 기기의 Google 지도로 이동한다.
- 작성하지 않는 이유: 다른 앱으로의 이동은 실제 기기와 설치된 앱에 따라 결과가 달라져 현재 테스트 환경에서 결정적으로 재현할 수 없다. 외부 앱 이동을 제어·관찰할 수 있는 환경이 제공되면 자동화한다.

### TC-DIARY-MAP-FEATURE-017: 네이버 지도 로고를 선택하면 법적 공지를 확인할 수 있다

- 근거: `domain > 지도 컨트롤 제공 기준`
- Given: 네이버 지도가 표시되어 있고 제공자 로고가 제공된다.
- When: 사용자가 네이버 지도 로고를 선택한다.
- Then: 네이버 지도가 정한 법적 공지를 확인할 수 있다.
- 작성하지 않는 이유: 실제 지도 제공자의 로고와 법적 공지 연결 결과를 현재 테스트 환경에서 제어할 수 없다. 제공자 로고 선택 결과를 제어·관찰할 수 있는 환경이 제공되면 자동화한다.

### TC-DIARY-MAP-FEATURE-018: 전환 컨트롤 배치와 무관하게 제공자를 선택할 수 있다

- 근거: `feature > 지도 제공자 전환`, `domain > 전환 컨트롤 배치`
- Given: 테스트 데이터의 전환 컨트롤 배치로 DiaryMap이 표시되어 있고 네이버 지도가 선택되어 있다.
- When: 사용자가 전환 컨트롤에서 Google 지도를 선택한다.
- Then: Google 지도가 선택된 상태가 되고 네이버 지도는 선택되지 않은 상태가 된다.
- 테스트 데이터:

| 전환 컨트롤 배치 |
| --- |
| 지도와 겹쳐 표시 |
| 지도와 겹치지 않는 자리에 표시 |

### TC-DIARY-MAP-FEATURE-019: 겹치지 않는 배치에서는 전환 컨트롤이 지도에 가려지지 않는다

- 근거: `domain > 전환 컨트롤 배치`
- Given: 전환 컨트롤을 지도와 겹치지 않는 자리에 표시하는 환경에서 DiaryMap이 표시되어 있다.
- When: 사용자가 DiaryMap을 확인한다.
- Then: 전환 컨트롤이 차지하는 영역과 지도가 차지하는 영역이 겹치지 않고, 지도가 컴포넌트 영역에서 전환 컨트롤을 뺀 나머지를 채운다.

### TC-DIARY-MAP-FEATURE-020: 전환 컨트롤 배치와 무관하게 같은 문구를 표시한다

- 근거: `domain > 전환 컨트롤 배치`

| 지도와 겹쳐 표시 | 그 외 기본 |
| 지도와 겹치지 않는 자리에 표시 | 한국어 |
| 지도와 겹치지 않는 자리에 표시 | 그 외 기본 |

### TC-DIARY-MAP-FEATURE-021: 배치하는 화면이 지정한 전환 컨트롤 배치로 표시한다

- 근거: `domain > 전환 컨트롤 배치`
