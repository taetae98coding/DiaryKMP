# DDayHome 테스트 케이스

기준 스펙: [DDayHome 화면 스펙](../spec/client/dday-home.md)

목록 표시, 갱신과 조회, 추가·상세로 이동, 삭제와 실행 취소, 화면 유지는 [항목 목록 화면 공통 스펙](../spec/client/entity-home.md)에, 태그 필터의 선택 방식과 판정은 [태그 필터 스펙](../spec/client/tag-filter.md)에, 필터를 열고 바꾼 결과와 선택 유지는 [목록 필터 반영 스펙](../spec/client/list-filter.md)에, 빈 상태는 [목록 빈 상태 스펙](../spec/client/list-empty-state.md)에, 자리 표시는 [페이지 조회 목록의 자리 표시 스펙](../spec/client/paged-list-placeholder.md)에, 새로고침은 [새로고침 스펙](../spec/client/sync-refresh.md)에, 추가 단축키는 [목록 추가 단축키 스펙](../spec/client/list-add-shortcut.md)에, 카드 삭제와 안내는 [SwipeToFinishAndDelete 컴포넌트 스펙](../spec/client/swipe-to-finish-and-delete.md)에 위임된 규칙을 이 화면에 적용한 결과를 이 문서가 확인한다. 케이스의 `근거`는 위임한 DDayHome 화면 스펙의 절을 가리키고, 공통 스펙의 절을 직접 가리킬 때만 그 문서를 링크한다.

시스템이 앱을 정리했다가 다시 만든 뒤 보던 목록 위치가 복원되는 결과는 [MemoHome 테스트 케이스](./memo-home.md)가, 삭제 안내가 보이는 동안 화면이 재생성되거나 앱이 백그라운드에 다녀오는 결과는 같은 문서가 대표로 확인한다. 카드 문구의 계산 규칙은 [디데이 테스트 케이스](./dday.md)가, 목록과 상세를 함께 사용하는 배치는 [DDay 목록·상세 배치 테스트 케이스](./dday-list-detail.md)가 확인한다.

화면에 보이는 문구와 접근성 이름은 [DDayHome 화면 디자인](../design/dday-home.md)이 정한 문구를 기대 결과로 쓴다.

## feature

### TC-6bdbd5aa-9cd9-443d-b6cf-15569cd8af16: 상단 바에 화면 제목을 표시한다

- 근거: `feature > 화면 내용`
- Given: 사용자 언어가 한국어다.
- When: 사용자가 DDayHome 화면을 확인한다.
- Then: 상단 바에 제목 `디데이` 문구가 표시된다.

### TC-dbfa3393-be4d-44ed-911f-494552f3182a: 제목, 뒤로가기, 필터 열기, 디데이 목록과 디데이 추가 외의 정보와 동작을 두지 않는다

- 근거: `feature > 화면 내용`
- Given: 사용자 언어가 한국어이고, 현재 계정에 디데이가 하나 있다.
- When: 사용자가 DDayHome 화면을 확인한다.
- Then: 화면에는 제목 `디데이`, 뒤로가기, 필터 열기, 디데이 목록과 디데이 추가만 있고, 정렬 선택이나 검색 같은 그 밖의 정보나 동작은 없다.

### TC-04b394e3-662a-45a9-a0ae-6a147b37611c: 계정에 저장된 디데이를 제목과 카드 문구로 표시한다

- 근거: `feature > 디데이 목록`, `domain > 오늘 기준`
- Given: 사용자 언어가 한국어이고 오늘이 2026-03-20이다. 현재 계정에 제목 `결혼`, 기준일 2025-01-15, 기준일을 1일로 세기 켬인 디데이와 제목 `시험`, 기준일 2026-03-20인 디데이가 있다.
- When: DDayHome 화면이 표시된다.
- Then: 두 디데이가 모두 목록에 나타나고, `결혼` 카드에는 `430일(1년 2개월)`이, `시험` 카드에는 `D-Day`가 함께 표시된다.

### TC-363e235e-e7cb-49fc-82b1-b4ec76fdfa5c: 디데이 카드에는 제목과 카드 문구 외의 글을 표시하지 않는다

- 근거: `feature > 디데이 목록`
- Given: 현재 계정에 설명, 반복 간격, 종료일이 있고 태그 하나와 연결된 디데이가 있다.
- When: DDayHome 화면이 표시된다.
- Then: 그 카드에 보이는 글은 제목과 카드 문구뿐이며, 설명, 기준일, 기준일을 1일로 세기, 반복 간격, 종료일, 달력에 없는 날짜 처리와 연결한 태그는 표시되지 않는다.

### TC-7e906050-2851-4551-84fc-d1c96cfd5c2b: 그 외 기본 언어에서는 디자인이 정한 형식으로 카드 문구를 표시한다

- When: DDayHome 화면이 표시된다.
- Then: 그 카드의 카드 문구가 테스트 데이터의 그 외 기본 표기로 표시된다.
- 테스트 데이터:

  | 한국어 카드 문구 | 그 외 기본 표기 |
  | --- | --- |
  | `D-400(1년 1개월)` | `D-400 (1 year 1 month)` |
  | `D-20` | `D-20` |
  | `D-Day` | `D-Day` |
  | `430일(1년 2개월)` | `430 days (1 year 2 months)` |
  | `366일(1년)` | `366 days (1 year)` |
  | `1일` | `1 day` |

### TC-e31981f0-9535-4872-9904-b642ed87f370: 선택한 태그가 없으면 선택 전체 해제를 실행할 수 없다
