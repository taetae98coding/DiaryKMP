# Checklist 목록·상세 배치 테스트 케이스

기준 스펙: [Checklist 목록·상세 배치 스펙](../spec/client/checklist-list-detail.md)

이 문서에서 `domain > 배치에 참여하는 화면`, `feature > 추가 진입 수단`, `feature > 함께 사용과 단독 사용`, `feature > 함께 사용할 때의 행동` 절은 [목록·상세 배치 공통 스펙](../spec/client/list-detail-pane.md)이 소유한다. 나머지 케이스의 절은 기준 스펙이 소유한다.

표시 비율 조절의 공통 행동과 유지 기준은 [목록·상세 배치 공통 스펙](../spec/client/list-detail-pane.md)에 위임되어 있다. 한 화면만 사용하는 환경에서 체크리스트 목록에서 체크리스트 추가나 체크리스트 상세로 이동하는 케이스는 [ChecklistHome 테스트 케이스](./checklist-home.md)에서, 상세 영역에서 체크리스트를 작성해 추가하는 케이스는 [ChecklistAdd 테스트 케이스](./checklist-add.md)에서, 상세 영역에서 체크리스트를 확인하고 체크하고 수정하고 삭제하는 케이스는 [ChecklistDetail 테스트 케이스](./checklist-detail.md)에서 다룬다.

## feature

### TC-CHECKLIST-LIST-DETAIL-FEATURE-001: 목록과 상세를 함께 쓰는 환경에서는 두 영역을 함께 표시한다

- 근거: `feature > 함께 사용과 단독 사용`
- Given: 목록과 상세를 함께 사용할 수 있는 환경이다.
- When: 사용자가 ChecklistHome 화면에 진입한다.
- Then: 체크리스트 목록을 유지한 채 상세 영역에 체크리스트 추가가 함께 표시된다.

### TC-CHECKLIST-LIST-DETAIL-FEATURE-002: 한 화면만 제공하는 환경에서는 현재 화면만 단독으로 표시한다

- 근거: `feature > 함께 사용과 단독 사용`
- Given: 목록과 상세를 함께 사용할 수 없는 환경이다.
- When: 사용자가 체크리스트 목록 또는 체크리스트 추가를 사용한다.
- Then: 현재 사용하는 화면만 단독으로 표시된다.

### TC-CHECKLIST-LIST-DETAIL-FEATURE-003: 상세 영역에 체크리스트 추가가 놓이면 목록에서 추가 수단을 제공하지 않는다

- 근거: `feature > 추가 진입 수단`
- Given: 상세 영역에 체크리스트 추가가 놓여 있다.
- When: 사용자가 체크리스트 목록에서 실행할 수 있는 동작을 확인한다.
- Then: 체크리스트 추가 동작이 제공되지 않는다. 추가 단축키를 눌러도 추가가 실행되지 않는다.

### TC-CHECKLIST-LIST-DETAIL-FEATURE-004: 상세 영역에 체크리스트 추가가 놓여 있지 않으면 목록에서 추가 수단을 제공한다

- 근거: `feature > 추가 진입 수단`
- Given: 상세 영역이 테스트 데이터의 상태다.
- When: 사용자가 체크리스트 목록에서 실행할 수 있는 동작을 확인한다.
- Then: 체크리스트 추가 동작이 제공된다.
- 테스트 데이터:

| 상세 영역 |
| --- |
| 상세 영역을 함께 표시하지 않음 |
| 체크리스트 상세가 놓여 있음 |

### TC-CHECKLIST-LIST-DETAIL-FEATURE-005: 목록과 함께 표시되면 상세 영역의 화면에서 뒤로가기 수단을 제공하지 않는다

- 근거: `feature > 함께 사용할 때의 행동`
- Given: 체크리스트 목록과 테스트 데이터의 화면이 함께 표시되어 있다.
- When: 사용자가 상세 영역의 화면에서 실행할 수 있는 동작을 확인한다.
- Then: 뒤로가기 동작이 제공되지 않는다.
- 테스트 데이터:

| 상세 영역의 화면 |
| --- |
| 체크리스트 추가 |
| 체크리스트 상세 |

### TC-CHECKLIST-LIST-DETAIL-FEATURE-006: 단독으로 표시되면 그 화면에서 뒤로가기 수단을 제공한다

- 근거: `feature > 함께 사용할 때의 행동`
- Given: 테스트 데이터의 화면이 단독으로 표시되어 있다.
- When: 사용자가 그 화면에서 실행할 수 있는 동작을 확인한다.
- Then: 뒤로가기 동작이 제공된다.
- 테스트 데이터:

| 화면 |
| --- |
| 체크리스트 추가 |
| 체크리스트 상세 |

### TC-CHECKLIST-LIST-DETAIL-FEATURE-007: 목록에서 체크리스트를 선택하면 상세 영역이 그 체크리스트의 상세로 바뀐다

- 근거: `feature > 상세 영역의 구성`
- Given: 체크리스트 목록과 체크리스트 추가가 함께 표시되어 있다.
- When: 사용자가 목록에서 체크리스트 하나를 선택한다.
- Then: 목록은 그대로 유지되고 상세 영역이 그 체크리스트의 ChecklistDetail로 바뀐다.

### TC-CHECKLIST-LIST-DETAIL-FEATURE-008: 상세 영역에서 뒤로가면 체크리스트 추가로 되돌아간다

- 근거: `feature > 뒤로가기`
- Given: 체크리스트 목록과 선택한 체크리스트의 상세가 함께 표시되어 있다.
- When: 사용자가 상세 영역에서 시스템 뒤로가기를 실행한다.
- Then: 목록은 그대로 유지되고 상세 영역이 체크리스트 추가로 되돌아간다.

### TC-CHECKLIST-LIST-DETAIL-FEATURE-009: 상세에서 체크리스트를 삭제하면 상세 영역이 체크리스트 추가로 되돌아간다

- 근거: `feature > 상세 영역의 구성`
- Given: 체크리스트 목록과 선택한 체크리스트의 상세가 함께 표시되어 있고 삭제가 성공하도록 설정되어 있다.
- When: 사용자가 상세 영역에서 그 체크리스트를 삭제한다.
- Then: 목록은 그대로 유지되고 상세 영역이 체크리스트 추가로 되돌아간다.

### TC-CHECKLIST-LIST-DETAIL-FEATURE-010: 체크리스트 상세가 놓인 동안 체크리스트 추가를 실행하면 상세 영역이 체크리스트 추가로 바뀐다

- 근거: `feature > 상세 영역의 구성`
- Given: 체크리스트 목록과 선택한 체크리스트의 상세가 함께 표시되어 있다.
- When: 사용자가 목록에서 체크리스트 추가를 실행한다.
- Then: 상세 영역이 체크리스트 추가로 바뀌고 선택한 체크리스트가 없는 상태가 된다.

### TC-CHECKLIST-LIST-DETAIL-FEATURE-011: 체크리스트 상세 위에서 연 체크리스트 추가에서 뒤로가면 이전 체크리스트 상세로 돌아간다

- 근거: `feature > 상세 영역의 구성`
- Given: 체크리스트 목록과 선택한 체크리스트의 상세가 함께 표시된 상태에서 사용자가 목록의 체크리스트 추가를 실행해 상세 영역에 체크리스트 추가가 놓여 있다.
- When: 사용자가 상세 영역에서 뒤로가기를 실행한다.
- Then: 목록은 그대로 유지되고 상세 영역이 체크리스트 추가를 열기 전에 보던 체크리스트의 상세로 돌아간다.

### TC-CHECKLIST-LIST-DETAIL-FEATURE-012: 체크리스트 상세 위에서 연 체크리스트 추가는 빈 입력으로 시작한다

- 근거: `feature > 상세 영역의 구성`
- Given: 체크리스트 목록과 상세 영역이 함께 표시되고, 선택한 체크리스트가 없을 때의 체크리스트 추가에 제목, 설명과 항목 입력을 적은 뒤 목록에서 체크리스트를 골라 상세 영역에 체크리스트 상세가 놓여 있다.
- When: 사용자가 목록에서 체크리스트 추가를 실행한다.
- Then: 목록은 그대로 유지되고, 상세 영역에 놓인 체크리스트 추가의 제목, 설명과 항목 입력이 모두 비어 있고 넣어 둔 체크 항목이 없다.

### TC-CHECKLIST-LIST-DETAIL-FEATURE-013: 체크리스트 상세가 놓인 동안 다른 체크리스트를 고르면 앞 체크리스트의 상세를 쌓지 않고 교체한다

- 근거: `feature > 상세 영역의 구성`
- Given: 체크리스트 목록과 체크리스트 추가가 함께 표시되어 있고 목록에 체크리스트 A와 체크리스트 B가 있다.
- When: 사용자가 목록에서 체크리스트 A를 고른 뒤 체크리스트 B를 고르고, 시스템 뒤로가기를 사용한다.
- Then: 체크리스트 B를 고르면 상세 영역이 체크리스트 B의 상세로 바뀌고, 뒤로가기를 사용하면 체크리스트 A의 상세가 아니라 체크리스트 추가로 되돌아가며 목록은 그대로 유지된다.

### TC-CHECKLIST-LIST-DETAIL-FEATURE-014: 목록에서 연 체크리스트 추가가 놓인 동안 다른 체크리스트를 고르면 추가를 걷어내고 그 상세로 바꾼다

- 근거: `feature > 상세 영역의 구성`
- Given: 목록과 상세를 함께 사용할 수 있는 환경이고, 테스트 데이터의 상태에서 목록의 체크리스트 추가로 연 체크리스트 추가가 상세 영역에 놓여 있으며 그 화면에 제목을 적어 두었다.
- When: 사용자가 목록에서 체크리스트 B를 고른 뒤 뒤로가기를 실행한다.
- Then: 상세 영역이 체크리스트 B의 상세로 바뀌고, 뒤로가기를 실행하면 그 전에 보던 체크리스트의 상세나 걷어낸 체크리스트 추가가 아니라 선택한 체크리스트가 없을 때의 체크리스트 추가로 되돌아가며 적어 두었던 제목은 보이지 않는다.
- 테스트 데이터:

| 체크리스트 추가를 열기 전의 상태 |
| --- |
| 상세 영역에 체크리스트 A의 상세가 놓여 있었음 |
| 한 영역만 표시되던 동안 목록에서 체크리스트 추가를 열었고, 그 뒤 창이 넓어짐 |

### TC-CHECKLIST-LIST-DETAIL-FEATURE-015: 체크리스트를 고르지 않은 상태에서 뒤로가면 `더보기`로 돌아간다

- 근거: `feature > 뒤로가기`
- Given: 체크리스트 목록과 선택한 체크리스트가 없을 때의 체크리스트 추가가 함께 표시되어 있다.
- When: 사용자가 시스템 뒤로가기를 사용한다.
- Then: 체크리스트 목록과 체크리스트 추가가 함께 사라지고 `더보기` 화면으로 돌아간다.

### TC-CHECKLIST-LIST-DETAIL-FEATURE-016: 선택 전 체크리스트 추가에서 추가에 성공해도 상세 영역은 체크리스트 추가로 남고 추가한 체크리스트가 목록에 나타난다

- 근거: `feature > 상세 영역의 구성`
- Given: 목록과 상세를 함께 사용할 수 있는 환경이고, 선택한 체크리스트가 없어 상세 영역에 체크리스트 추가가 놓여 있으며 체크리스트 추가가 성공하도록 설정되어 있다.
- When: 사용자가 제목을 입력하고 체크리스트 추가를 실행한다.
- Then: 상세 영역에는 입력이 비워진 체크리스트 추가가 그대로 남아 다음 체크리스트를 입력할 수 있고, 방금 추가한 체크리스트가 같은 화면의 목록에 나타난다.

### TC-CHECKLIST-LIST-DETAIL-FEATURE-017: 상세 영역에서 체크 항목을 바꾸면 목록의 진행 정도가 같은 화면에서 바뀐다

- 근거: `feature > 상세 영역의 구성`
- Given: 목록과 상세 영역이 함께 표시되고, 목록에서 고른 체크리스트의 상세가 상세 영역에 놓여 있다. 그 체크리스트에는 체크한 항목과 체크하지 않은 항목이 있고, 바뀐 체크 항목은 저장되도록 설정되어 있다.
- When: 사용자가 상세 영역에서 테스트 데이터의 동작을 실행한다.
- Then: 상세 영역은 그 체크리스트의 상세로 남고, 목록에 놓인 그 체크리스트의 진행 정도가 테스트 데이터의 결과로 바뀐다.
- 테스트 데이터:

| 동작 | 진행 정도 |
| --- | --- |
| 체크하지 않은 항목을 체크 | 체크한 항목 수가 하나 늘어남 |
| 새 항목을 넣음 | 전체 항목 수가 하나 늘어남 |
| 체크하지 않은 항목을 뺌 | 전체 항목 수가 하나 줄어듦 |
| 리셋을 확인 | 체크한 항목 수가 0이 됨 |

## domain

### TC-CHECKLIST-LIST-DETAIL-DOMAIN-001: 체크리스트 목록에서 진입하지 않은 체크리스트 추가는 목록과 함께 표시하지 않는다

- 근거: `domain > 배치에 참여하는 화면`
- Given: 목록과 상세를 함께 사용할 수 있는 환경이다.
- When: 사용자가 체크리스트 목록이 아닌 화면에서 체크리스트 추가로 이동한다.
- Then: 체크리스트 추가를 목록·상세 배치에 참여시키지 않아 단독으로 표시한다.

### TC-CHECKLIST-LIST-DETAIL-DOMAIN-002: 체크리스트 목록에서 이어 진입한 체크리스트 추가는 목록과 함께 표시한다

- 근거: `domain > 배치에 참여하는 화면`
- Given: 목록과 상세를 함께 사용할 수 있는 환경이다.
- When: 사용자가 체크리스트 목록에서 체크리스트 추가로 이동한다.
- Then: 체크리스트 추가를 목록·상세 배치의 상세 영역에 표시한다.

### TC-CHECKLIST-LIST-DETAIL-DOMAIN-003: 체크리스트 목록에서 이어 진입한 체크리스트 상세는 목록과 함께 표시한다

- 근거: `domain > 배치에 참여하는 화면`
- Given: 목록과 상세를 함께 사용할 수 있는 환경이다.
- When: 사용자가 체크리스트 목록에서 체크리스트 상세로 이동한다.
- Then: 체크리스트 상세를 목록·상세 배치의 상세 영역에 표시한다.

### TC-CHECKLIST-LIST-DETAIL-DOMAIN-004: `더보기`로 돌아갔다가 다시 진입하면 상세 선택이 초기화된다

- 근거: `domain > 유지와 초기화 기준`
- Given: 목록과 상세 영역이 함께 표시되고 상세 영역에 선택한 체크리스트의 상세가 놓여 있다.
- When: 사용자가 체크리스트 목록의 뒤로가기 동작으로 `더보기` 화면으로 돌아갔다가 체크리스트 화면에 다시 진입한다.
- Then: 상세 영역에는 체크리스트 상세가 아니라 선택한 체크리스트가 없을 때의 체크리스트 추가가 놓인다.

### TC-CHECKLIST-LIST-DETAIL-DOMAIN-005: `더보기`로 돌아갔다가 다시 진입하면 상세 영역의 체크리스트 추가는 입력이 모두 비어 있는 상태로 시작한다

- 근거: `domain > 유지와 초기화 기준`
- Given: 목록과 상세 영역이 함께 표시되고 선택한 체크리스트가 없어 상세 영역에 체크리스트 추가가 놓여 있다. 사용자가 체크리스트 추가에 제목과 설명을 적고 체크 항목 하나를 넣었다.
- When: 사용자가 `더보기` 화면으로 돌아갔다가 체크리스트 화면에 다시 진입한다.
- Then: 상세 영역의 체크리스트 추가는 제목, 설명과 항목 입력이 비어 있고 넣어 둔 체크 항목이 없다.

### TC-CHECKLIST-LIST-DETAIL-DOMAIN-006: 배치를 떠나기 전에는 상세 영역에서 체크리스트 상세를 보고 돌아와도 체크리스트 추가의 입력이 남는다

- 근거: `domain > 유지와 초기화 기준`
- Given: 목록과 상세 영역이 함께 표시되고 선택한 체크리스트가 없어 상세 영역에 체크리스트 추가가 놓여 있다. 사용자가 체크리스트 추가에 제목과 설명을 적고 체크 항목 하나를 넣었다.
- When: 사용자가 목록에서 체크리스트를 골라 상세 영역에서 체크리스트 상세를 본 뒤 뒤로가기를 사용해 체크리스트 추가로 돌아온다.
- Then: 체크리스트 추가에 적어 두던 제목과 설명, 넣어 둔 체크 항목이 그대로 남아 있다.

### TC-CHECKLIST-LIST-DETAIL-DOMAIN-007: 화면이 재생성되어도 상세 선택을 유지한다

- 근거: `domain > 유지와 초기화 기준`
- Given: 목록과 상세 영역이 함께 표시되고 목록에서 고른 체크리스트의 상세가 상세 영역에 놓여 있다.
- When: 화면이 재생성된다.
- Then: 목록과 함께 상세 영역에 같은 체크리스트의 상세가 놓여 있고, 상세 영역에서 뒤로가면 체크리스트 추가로 되돌아간다.

### TC-CHECKLIST-LIST-DETAIL-DOMAIN-008: 시스템이 앱을 정리했다가 다시 만들어도 상세 선택과 뒤로가기 기록을 유지한다

- 근거: `domain > 유지와 초기화 기준`
- Given: 목록과 상세 영역이 함께 표시되고, 목록에서 체크리스트 A를 고른 뒤 목록의 체크리스트 추가를 실행해 상세 영역에 체크리스트 추가가 놓여 있다.
- When: 앱이 백그라운드에 있는 동안 시스템이 앱을 정리했다가 다시 만든다.
- Then: 목록과 함께 상세 영역에 체크리스트 추가가 놓여 있고, 상세 영역에서 뒤로가면 체크리스트 A의 상세로, 한 번 더 뒤로가면 선택한 체크리스트가 없을 때의 체크리스트 추가로 되돌아간다.

### TC-CHECKLIST-LIST-DETAIL-DOMAIN-009: 앱이 백그라운드에 다녀와도 상세 선택을 유지한다

- 근거: `domain > 유지와 초기화 기준`
- Given: 목록과 상세 영역이 함께 표시되고 목록에서 고른 체크리스트의 상세가 상세 영역에 놓여 있다.
- When: 앱이 백그라운드에 갔다가 같은 화면으로 돌아온다.
- Then: 목록과 함께 상세 영역에 같은 체크리스트의 상세가 놓여 있고, 상세 영역에서 뒤로가면 체크리스트 추가로 되돌아간다.

### TC-CHECKLIST-LIST-DETAIL-DOMAIN-010: 목록에서 연 체크리스트 추가를 닫거나 걷어내도 선택 전 체크리스트 추가의 작성 내용이 남는다

- 근거: `domain > 유지와 초기화 기준`
- Given: 목록과 상세 영역이 함께 표시되고, 사용자가 선택한 체크리스트가 없을 때의 체크리스트 추가에 제목과 설명을 적고 체크 항목 하나를 넣은 뒤 목록에서 체크리스트 A를 골라 상세 영역에 그 상세가 놓여 있다. 그 상태에서 목록의 체크리스트 추가를 실행해 상세 영역에 빈 체크리스트 추가가 놓여 있다.
- When: 사용자가 테스트 데이터의 동작으로 목록에서 연 체크리스트 추가를 닫은 뒤, 상세 영역에서 뒤로가기를 실행해 선택한 체크리스트가 없을 때의 체크리스트 추가로 돌아온다.
- Then: 선택한 체크리스트가 없을 때의 체크리스트 추가에 적어 두던 제목과 설명, 넣어 둔 체크 항목이 그대로 남아 있다.

| 목록에서 연 체크리스트 추가를 닫는 동작 |
| --- |

## 작성하지 않는 이유

체크리스트 목록의 뒤로가기 동작으로 상세 영역에 놓인 화면과 관계없이 `더보기` 화면으로 돌아가는 결과는 [ChecklistHome 테스트 케이스](./checklist-home.md)의 TC-CHECKLIST-HOME-FEATURE-027에서 다룬다.

앱을 다시 실행했을 때의 상세 선택 초기화는 앱 프로세스를 끝내고 다시 띄워야 관찰할 수 있어 자동화하지 않으며, 프로세스 재시작을 제어할 수 있는 테스트 환경이 갖춰지면 자동화한다.

두 영역의 표시 비율 조절과 조절 중 즉시 반영, 화면 재생성·백그라운드 복귀·시스템 정리 뒤 다시 만들기 후 비율 유지, `더보기`로 돌아갔다가 다시 진입하거나 앱을 다시 실행한 뒤의 기본 비율 초기화는 실제 창 크기에서 두 영역의 경계를 끌어야 조절되고 실행 경계를 함께 판정해야 한다. 현재 테스트 환경에서는 결정적으로 자동화할 수 없으며, 창 크기, 영역 경계 끌기와 실행 경계를 제어·관찰할 수 있는 통합 UI 테스트 환경이 갖춰지면 자동화한다. 상세 선택의 유지는 같은 경계에서 TC-CHECKLIST-LIST-DETAIL-DOMAIN-007, TC-CHECKLIST-LIST-DETAIL-DOMAIN-008, TC-CHECKLIST-LIST-DETAIL-DOMAIN-009가 따로 검증한다.
