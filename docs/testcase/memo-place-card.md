# 메모 장소 카드 테스트 케이스

기준 스펙: [메모 장소 카드 컴포넌트 스펙](../spec/client/memo-place-card.md)

지도의 표시·조작·제공자 전환과 핀 표시·핀 선택 자체의 케이스는 [DiaryMap 테스트 케이스](./diary-map.md)에서 다룬다. 핀을 눌러 이동한 상세 화면의 내용과 수정·삭제 케이스는 [PlaceDetail 테스트 케이스](./place-detail.md)에서 다룬다. 현재 위치를 확인하는 규칙 자체의 케이스는 [현재 위치 확인 테스트 케이스](./current-location.md)에서 다룬다. 기본 지도를 고르고 저장하는 케이스는 [SettingMap 테스트 케이스](./setting-map.md)에서 다룬다. 메모와 장소 연결 규칙 자체의 케이스는 [메모 장소 테스트 케이스](./memo-place.md)에서, 선택이 반영되는 화면별 케이스는 [MemoAdd 테스트 케이스](./memo-add.md)와 [MemoDetail 테스트 케이스](./memo-detail.md)에서 다룬다. 자리 표시 케이스의 `근거`가 가리키는 절은 공통 규칙을 [페이지 조회 목록의 자리 표시 스펙](../spec/client/paged-list-placeholder.md)에 위임한다. 검색어의 정규화와 일치 판정, 검색 결과 없음 판정도 [검색어 일치 판정 스펙](../spec/client/search-match.md)에 위임되어 있으며, 장소 선택 목록에서의 결과를 이 문서의 케이스로 덮는다.

## feature

### TC-649e3b47-a249-4368-837b-e9dd21aecd2a: MemoAdd 화면 본문에 장소 카드가 표시된다

- 근거: `feature > 카드 표시`
- Given: MemoAdd 화면이 표시되어 있다.
- When: 사용자가 본문을 확인한다.
- Then: 메모의 장소를 보여 주는 장소 카드가 표시된다.

### TC-2f2161b0-8611-4832-9213-5fa348e0f5e0: MemoDetail 화면 본문에 장소 카드가 표시된다

- 근거: `feature > 카드 표시`
- Given: 메모 조회가 완료된 MemoDetail 화면이 표시되어 있다.
- When: 사용자가 본문을 확인한다.
- Then: 메모의 장소를 보여 주는 장소 카드가 표시된다.

### TC-a2329351-5d96-4a5d-b6c2-465d26366250: 기본 지도를 확인하지 못하면 지도를 표시하지 않는다

- 근거: `feature > 지도 표시`
- Given: 사용자가 고른 기본 지도를 아직 확인하지 못했거나 읽지 못한 상태로 장소 카드가 표시되어 있다.
- When: 사용자가 장소 카드를 확인한다.
- Then: 지도가 표시되지 않고 별도의 로딩 안내나 오류 안내도 표시되지 않으며, 카드와 장소 목록은 그대로 표시된다.

### TC-40088a6c-af25-478e-a361-f4d4f1091e59: 연결된 장소가 컬러와 제목으로 표시된다

- Then: 각 장소가 저장된 컬러와 제목으로 구분되어 모두 표시된다.

- 근거: `feature > 장소 위치 보기`, `domain > 장소 위치 보기와 지도 이동`
- Given: 기본 지도가 확인되어 지도가 표시되어 있고, 카드가 서로 다른 좌표의 장소 여러 개를 노출하고 있으며, 지도는 그 장소들과 다른 위치를 가운데에 두고 있다.

- Then: 지도가 그 장소의 좌표를 가운데에 두도록 이동하고 장소 상세 이동은 요청되지 않는다. 이때 확대 수준이 유지되는 것은 [DiaryMap 테스트 케이스](./diary-map.md)의 TC-5e16f287-92f8-4a1f-ae15-0559952c7d38가 다룬다.

- Then: 지도가 다시 그 장소의 좌표를 가운데에 두도록 이동하고 장소 상세 이동은 요청되지 않는다.

### TC-ee257126-2dd0-48fd-8c3b-99cfc84577cd: 지도를 눌러도 지점이 만들어지지 않는다

- 근거: `feature > 지도 표시`
- Given: 기본 지도가 확인되어 카드의 지도가 표시되어 있다.
- When: 사용자가 지도의 한 곳을 누른다.
- Then: 지점이 만들어지지 않고 지점 표시도 나타나지 않는다.
- 작성하지 않는 이유: 지도 누르기는 지도 제공자의 실제 표시 요소가 필요하고, 현재 호스트 테스트 환경은 이를 제공하지 않는다. 지도 표시를 대체할 수 있는 테스트 환경이 제공되면 자동화한다.
