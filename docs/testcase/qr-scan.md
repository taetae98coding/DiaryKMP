# QrScan 테스트 케이스

기준 스펙: [QrScan 화면 스펙](../spec/client/qr-scan.md)

카메라가 QR을 읽는 동작은 플랫폼이 제공하는 카메라 기능이 소유하므로, 이 문서의 QR 읽기 케이스는 카메라가 읽어 낸 값을 테스트 조건으로 정하고 그 값에 따라 이 화면에서 관찰되는 결과를 확인한다.

## feature

### TC-QR-SCAN-FEATURE-001: 상단 바에 화면 제목을 표시한다

- 근거: `feature > 화면 내용`
- Given: 사용자 언어가 테스트 데이터의 언어다.
- When: 사용자가 QrScan 화면을 확인한다.
- Then: 상단 바에 테스트 데이터의 제목이 표시된다.
- 테스트 데이터:

  | 언어 | 제목 |
  | --- | --- |
  | 한국어 | `QR 스캔` |
  | 그 외 기본 | `Scan QR code` |

### TC-QR-SCAN-FEATURE-002: 제목 외의 정보와 뒤로가기 외의 동작을 두지 않는다

- 근거: `feature > 화면 내용`
- Given: 사용자 언어가 한국어이고 QrScan 화면이 표시되어 있다.
- When: 사용자가 화면에서 보이는 글과 할 수 있는 동작을 확인한다.
- Then: 화면에 보이는 글은 제목 `QR 스캔` 하나뿐이고, 선택할 수 있는 동작은 뒤로가기 하나뿐이다.

### TC-QR-SCAN-FEATURE-006: 뒤로가기를 선택하면 값을 넘기지 않고 이전 화면으로 돌아간다

- 근거: `feature > 뒤로가기`
- Given: 사용자가 QrAdd 화면에서 QrScan 화면으로 들어와 있다.
- When: 사용자가 뒤로가기를 선택한다.
- Then: 이전 화면으로 돌아가는 동작이 한 번 실행되고, QrAdd 화면에 넘기는 값은 없다.

### TC-QR-SCAN-FEATURE-004: 화면이 보이는 동안 후면 카메라 모습을 실시간으로 보여 준다

- 근거: `feature > 화면 내용`
- Given: 카메라 권한이 허용되어 있고 후면 카메라를 사용할 수 있다.
- When: 사용자가 QrScan 화면을 확인한다.
- Then: 후면 카메라가 비추는 모습이 실시간으로 보인다.
- 작성하지 않는 이유: 카메라 모습은 실제 기기의 카메라와 플랫폼이 제공하는 카메라 기능으로만 관찰할 수 있고, 현재 테스트 환경은 카메라를 실행하지 않는다. 카메라 입력을 대신 공급할 수 있는 테스트 환경이 제공되면 자동화한다.

### TC-QR-SCAN-FEATURE-005: 카메라를 시작할 수 없어도 뒤로가기로 돌아갈 수 있다

- 근거: `feature > 화면 내용`
- Given: 카메라를 시작할 수 없는 상태에서 QrScan 화면이 표시되어 있다.
- When: 사용자가 화면을 확인하고 뒤로가기를 선택한다.
- Then: 별도 안내가 표시되지 않고, 이전 화면으로 돌아가는 동작이 한 번 실행된다.

### TC-QR-SCAN-FEATURE-007: QR을 읽으면 읽은 값을 넘기고 이전 화면으로 돌아간다

- 근거: `feature > QR 읽기`
- Given: QrScan 화면이 표시되어 있다.
- When: 카메라가 값 `https://example.com`을 담은 QR을 읽는다.
- Then: QrAdd 화면에 `https://example.com`을 넘기는 동작과 이전 화면으로 돌아가는 동작이 각각 한 번 실행된다.

### TC-QR-SCAN-FEATURE-008: QR을 읽기 전에는 화면에 머무른다

- 근거: `feature > QR 읽기`
- Given: QrScan 화면이 표시되어 있다.
- When: 카메라가 아무 QR도 읽지 않은 채 시간이 지난다.
- Then: 값을 넘기는 동작과 이전 화면으로 돌아가는 동작이 실행되지 않는다.

## domain

### TC-QR-SCAN-DOMAIN-002: 담긴 값을 받을 수 없는 QR은 읽지 않은 것으로 보고 계속 스캔한다

- 근거: `domain > 읽을 QR`
- Given: QrScan 화면이 표시되어 있다.
- When: 카메라가 테스트 데이터의 값을 담은 QR을 읽은 뒤 값 `abc`를 담은 QR을 읽는다.
- Then: 테스트 데이터의 값은 넘기지 않고, `abc`를 넘기는 동작과 이전 화면으로 돌아가는 동작이 각각 한 번 실행된다.
- 테스트 데이터:

  | 값 |
  | --- |
  | 빈 값 |
  | QR 하나에 담을 수 있는 가장 긴 숫자 값보다 한 자 긴 숫자 값 |

### TC-QR-SCAN-DOMAIN-003: QR을 하나 읽으면 그 뒤에 읽은 QR은 쓰지 않는다

- 근거: `domain > 읽을 QR`
- Given: QrScan 화면이 표시되어 있다.
- When: 카메라가 값 `first`를 담은 QR을 읽고, 이어서 값 `second`를 담은 QR을 읽는다.
- Then: `first`를 넘기는 동작과 이전 화면으로 돌아가는 동작이 각각 한 번만 실행되고, `second`는 넘기지 않는다.

### TC-QR-SCAN-DOMAIN-004: QR이 아닌 코드는 읽지 않는다

- 근거: `domain > 읽을 QR`
- Given: QrScan 화면이 표시되어 있다.
- When: 카메라에 막대 바코드를 비춘다.
- Then: 값을 넘기지 않고 화면에 머무른다.
- 작성하지 않는 이유: 어떤 종류의 코드를 읽을지는 플랫폼이 제공하는 카메라 인식 기능이 판정하고, 현재 테스트 환경은 카메라와 그 인식 기능을 실행하지 않는다. 카메라 입력을 대신 공급할 수 있는 테스트 환경이 제공되면 자동화한다.

### TC-QR-SCAN-DOMAIN-001: 화면이 보이는 동안에만 카메라를 사용한다

- 근거: `domain > 카메라 사용 구간`
- Given: 카메라 권한이 허용되어 있고 QrScan 화면에 카메라 모습이 보인다.
- When: 테스트 데이터의 실행 상태 변화가 일어난다.
- Then: 테스트 데이터의 카메라 사용 결과가 나타난다.
- 테스트 데이터:

  | 실행 상태 변화 | 카메라 사용 결과 |
  | --- | --- |
  | 앱이 백그라운드로 감 | 카메라 사용을 멈춘다 |
  | 앱이 다시 앞에 나옴 | 카메라 모습을 다시 보여 준다 |
  | 화면을 떠남 | 카메라 사용을 멈춘다 |
  | 화면이 재생성됨 | 카메라 모습을 다시 보여 준다 |

- 작성하지 않는 이유: 카메라 사용 여부는 실제 기기의 카메라와 플랫폼이 제공하는 카메라 기능으로만 관찰할 수 있고, 현재 테스트 환경은 카메라를 실행하지 않는다. 카메라 사용 상태를 관찰할 수 있는 테스트 환경이 제공되면 자동화한다.

## 작성하지 않는 케이스

- 뒤로가기를 다루던 TC-QR-SCAN-FEATURE-003은 값을 넘기지 않는다는 결과가 더해져 TC-QR-SCAN-FEATURE-006으로 대체하고 폐기했다.
- 카메라 모습에 QR이 여러 개 있을 때 먼저 읽은 하나만 쓰는 결과는 TC-QR-SCAN-DOMAIN-003과 같은 관찰 결과다. 카메라가 여러 QR을 차례로 읽어 내므로, 먼저 읽은 값만 넘기는지로 확인한다.
