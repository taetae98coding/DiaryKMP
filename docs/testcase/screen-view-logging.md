# 화면 조회 로깅 테스트 케이스

기준 스펙: [화면 조회 로깅 스펙](../spec/client/screen-view-logging.md)

## domain

### TC-c175092c-a776-4cb0-997b-00bf151a20f0: 화면을 표시하면 그 화면의 화면 조회가 남는다

- 근거: `domain > 화면 조회`
- Given: 화면 조회를 담당하는 기록 수단이 등록되어 있고, 아직 어떤 화면도 표시되지 않았다.
- When: 앱이 어떤 화면을 표시한다.
- Then: 그 화면의 이름을 담은 화면 조회가 한 번 남는다.

- Given: 화면 조회를 담당하는 기록 수단이 등록되어 있고 어떤 화면이 표시되어 있다.
- When: 사용자가 다른 화면으로 이동한다.

## 작성하지 않는 이유

- `domain > 화면 조회가 남는 시점`의 앱 재실행 후 복원: 앱 프로세스 종료와 재시작이 필요해 유닛 테스트로 결정적으로 검증할 수 없다. 화면 재생성 경계는 TC-77ed6712-737b-4d2b-828f-b08e20b97c36이 덮는다. 앱 프로세스를 끝냈다가 이전 화면으로 되살릴 수 있는 테스트 환경이 갖춰지면 자동화한다.
- `domain > 화면 조회가 남는 시점`의 화면을 본 시간 파악: 화면을 본 시간은 남은 화면 조회들을 모아 Google Analytics 4가 집계하므로 앱에서 관찰할 결과가 없다. 집계 결과를 조회할 수 있는 테스트용 Google Analytics 4 속성이 갖춰지면 자동화한다.
- `domain > 화면 이름`의 이름을 바꾸지 않음: 한 시점의 실행에서 관찰할 결과가 없고, 이름을 바꾸지 않는 것은 문서와 리뷰로 지킬 약속이다. 이전 버전의 화면 이름 목록과 비교하는 검사가 갖춰지면 자동화한다.
- `domain > 화면 이름 목록`의 이름 없는 화면을 둘 수 없음: 이름 없는 화면은 만들 수 없으므로 실행 시점에 넣을 입력이 없다. 화면 이름을 실행 중에 정하게 되어 이름이 빠질 수 있는 입력이 생기면 자동화한다.
- `domain > 기록 수단`의 콘솔 기록: 콘솔 기록 수단이 모든 종류의 로그를 남기는 것은 [앱 로깅 테스트 케이스](./app-logging.md)의 TC-a67642d9-cecb-41fc-ac49-94487ca64af5이 덮는다.
- `domain > 기록 수단`의 Android·iOS에서 Google Analytics 4에 남는지: 해당 플랫폼 실행 환경과 실제 Google Analytics 4 속성이 필요해 현재 유닛 테스트 환경에서는 검증할 수 없다. Android·iOS 실행 환경과 결과를 조회할 수 있는 테스트용 Google Analytics 4 속성이 갖춰지면 자동화한다.
