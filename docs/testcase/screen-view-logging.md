# 화면 조회 로깅 테스트 케이스

기준 스펙: [화면 조회 로깅 스펙](../spec/client/screen-view-logging.md)

콘솔 기록 수단이 화면 조회를 포함한 모든 종류의 로그를 남기는 것은 [앱 로깅 테스트 케이스](./app-logging.md)의 TC-a67642d9-cecb-41fc-ac49-94487ca64af5가 다룬다.

## domain

### TC-c175092c-a776-4cb0-997b-00bf151a20f0: 화면을 표시하면 그 화면의 화면 조회가 남는다

- 근거: `domain > 화면 조회`
- Given: 화면 조회를 담당하는 기록 수단이 등록되어 있고, 아직 어떤 화면도 표시되지 않았다.
- When: 앱이 어떤 화면을 표시한다.
- Then: 그 화면의 이름을 담은 화면 조회가 한 번 남는다.

### TC-6ff1e76d-1d6a-4b2f-9930-dfc929d20f95: 다른 화면으로 이동하면 이동한 화면의 화면 조회가 남는다

- 근거: `domain > 화면 조회가 남는 시점`
- Given: 화면 조회를 담당하는 기록 수단이 등록되어 있고 어떤 화면이 표시되어 있다.
- When: 사용자가 다른 화면으로 이동한다.
- Then: 이동한 화면의 이름을 담은 화면 조회가 남는다.

### TC-0fd2aa7e-724c-4acc-9910-e8063e45219c: 두 화면을 함께 표시해도 가장 나중에 진입한 화면만 남는다

- 근거: `domain > 화면 조회`
- Given: 화면 조회를 담당하는 기록 수단이 등록되어 있고 목록 화면이 표시되어 있다.
- When: 목록을 유지한 채 그 목록에서 상세 화면으로 진입한다.
- Then: 상세 화면의 이름을 담은 화면 조회만 남고, 함께 표시되고 있는 목록 화면의 화면 조회는 새로 남지 않는다.

### TC-1cbbab70-4991-4025-866a-06f957913cbe: 겹쳐 표시하는 화면도 화면 조회로 남는다

- 근거: `domain > 화면 조회`

- When: 그 화면을 닫지 않고, 화면 이동 기록에 쌓이며 위에 겹쳐 표시하는 화면을 연다.
- Then: 겹쳐 표시한 화면의 이름을 담은 화면 조회가 남는다.

### TC-e41ebef2-9037-4cf7-ab7c-4abf4694364b: 화면 안에서 연 다이얼로그는 화면 조회로 남지 않는다

- When: 그 화면 안에서 다이얼로그를 열었다가 닫는다.

### TC-58209d4e-67f5-473c-9ed0-4d735894bcac: 겹쳐 표시한 화면을 닫으면 아래 화면의 화면 조회가 다시 남는다

### TC-dee14294-e838-4a4d-95b2-4ccbf91fc8a6: 백그라운드에서 돌아오면 같은 화면의 화면 조회가 다시 남는다

- Given: 화면 조회를 담당하는 기록 수단이 등록되어 있고, 어떤 화면이 표시된 채 앱이 백그라운드로 갔다.
- When: 앱이 다시 앞으로 돌아온다.

### TC-77ed6712-737b-4d2b-828f-b08e20b97c36: 화면이 재생성되어 복원되면 화면 조회가 남는다

- 근거: `domain > 화면 조회가 남는 시점`
- Given: 화면 조회를 담당하는 기록 수단이 등록되어 있고 어떤 화면이 표시되어 있다.

- Then: 복원된 화면의 이름을 담은 화면 조회가 남는다.

### TC-fd5e53b3-3cc2-450e-b18b-89d98275929e: 앱을 다시 실행하면 처음 보이는 화면의 화면 조회가 남는다

- Given: 화면 조회를 담당하는 기록 수단이 등록되어 있고, 사용자가 어떤 화면을 보다가 앱을 종료했다.

### TC-d741d32e-60b9-4492-903c-9c04ef19a18a: 화면을 떠난 사건은 따로 남기지 않는다

- 근거: `domain > 화면 조회가 남는 시점`
- Given: 화면 조회를 담당하는 기록 수단이 등록되어 있고 어떤 화면이 표시되어 있다.
- When: 사용자가 다른 화면으로 이동한다.
- Then: 처음 화면과 이동한 화면의 화면 조회만 차례로 남고, 처음 화면을 떠난 사건은 남지 않는다.

### TC-bdb0f73c-85ca-460f-a797-2c658b67250d: 한 화면을 본 시간은 연속한 두 화면 조회 사이의 간격으로 파악한다

- 근거: `domain > 화면 조회가 남는 시점`
- Given: 원격 분석 기록 수단이 등록되어 있고 사용자가 한 화면을 보다가 다른 화면으로 이동했다.
- When: 원격 분석 결과에서 처음 화면을 본 시간을 확인한다.
- Then: 두 화면 조회 사이의 간격이 처음 화면을 본 시간으로 집계된다.
- 작성하지 않는 이유: 본 시간은 남은 화면 조회를 모아 Google Analytics 4가 집계하므로 앱에서 관찰할 결과가 없다. 앱이 남기는 화면 조회의 순서는 TC-d741d32e-60b9-4492-903c-9c04ef19a18a가 다룬다. 집계 결과를 조회할 수 있는 테스트용 Google Analytics 4 속성이 갖춰지면 자동화한다.

### TC-5aaffc7f-b4ed-45b0-82a4-6ea04e4f4f60: 현재 화면이 바뀌지 않으면 화면 조회가 더 남지 않는다

### TC-04f91a23-c86c-4dfe-a44e-118fbefa14f4: 항목이 달라도 같은 종류의 화면은 같은 이름으로 남는다

### TC-16c187ba-3651-4483-b320-64e260bc6fbe: 화면 이름에 그 화면에 전달된 값이 담기지 않는다

- 근거: `domain > 화면 이름`

### TC-32e6ad32-004b-47c6-a25a-144794ac03aa: 각 화면은 목록에 정의된 이름으로 남는다

- 근거: `domain > 화면 이름 목록`

- When: 화면 이름 목록에 있는 화면을 표시한다.

- 테스트 데이터: [화면 조회 로깅 스펙](../spec/client/screen-view-logging.md)의 `화면 이름 목록`

### TC-2267537e-3af3-492a-a7bf-7ed245bceeb4: 앱에 등록된 모든 화면은 화면 이름 목록에 자기 이름을 가진다

- 근거: `domain > 화면 이름`, `domain > 화면 이름 목록`
- Given: 앱이 이동할 수 있는 화면이 등록되어 있다.
- When: 등록된 화면과 화면 이름 목록을 맞대어 본다.
- Then: 등록된 모든 화면이 목록에 한 번씩 이름을 가지며, 이름 없이 남는 화면이 없다.

### TC-bea1efec-9edc-4201-9356-166d6ed79ca8: 한 번 정한 화면 이름은 바꾸지 않는다

- 근거: `domain > 화면 이름`
- Given: 이전에 배포한 앱이 남긴 화면 이름이 있다.
- When: 새 버전의 앱이 같은 화면의 화면 조회를 남긴다.
- Then: 이전 버전과 같은 이름으로 남는다.
- 작성하지 않는 이유: 한 버전의 실행에서는 이전 버전과 비교할 결과가 없고, 이름을 바꾸지 않는 것은 문서와 리뷰로 지키는 약속이다. TC-32e6ad32-004b-47c6-a25a-144794ac03aa는 목록과 다른 이름을 막지만 목록 자체를 고치는 것은 막지 못한다. 이전에 배포한 버전의 화면 이름 목록을 기준으로 비교하는 검사가 갖춰지면 자동화한다.

### TC-bb3a7d32-a89e-4aee-9c2c-d8ca4545a065: 화면 조회는 오류 보고로 남지 않는다

- 근거: `domain > 기록 수단`

### TC-93c21a25-8e9c-4873-bc82-f6dde6365764: 기록에 실패해도 화면은 그대로 표시된다

### TC-49a95b65-2e1d-4e81-b823-b22f46e3a17e: Android와 iOS에서는 화면 조회가 Google Analytics 4에 남는다

- 근거: `domain > 기록 수단`
- Given: Android 또는 iOS 앱에 원격 분석 기록 수단이 등록되어 있다.
- When: 사용자가 어떤 화면을 본다.
- Then: 그 화면의 이름을 담은 화면 조회가 Google Analytics 4에 남는다.
- 작성하지 않는 이유: 해당 플랫폼 실행 환경과 실제 Google Analytics 4 속성이 필요해 현재 유닛 테스트 환경에서는 검증할 수 없다. Android·iOS 실행 환경과 결과를 조회할 수 있는 테스트용 Google Analytics 4 속성이 갖춰지면 자동화한다.
