# 현재 위치 확인 테스트 케이스

기준 스펙: [현재 위치 확인 스펙](../spec/client/current-location.md)

확인한 위치와 확인 실패를 각 기능이 어떻게 쓰는지는 [현재 날씨 동기화 테스트 케이스](./weather-fetch.md)와 [PlaceHome 테스트 케이스](./place-home.md)에서 다룬다.

## domain

### TC-CURRENT-LOCATION-DOMAIN-001: 디바이스 위치를 우선 사용한다

- 근거: `domain > 확인 순서`
- Given: 디바이스 위치 확인이 특정 위도와 경도로 성공하도록 제어되어 있고, 공인 IP 기준 위치 확인은 다른 위도와 경도로 성공하도록 제어되어 있다.
- When: 현재 위치 확인을 요청한다.
- Then: 디바이스 위치의 위도와 경도가 현재 위치로 확인되고, 공인 IP 기준 위치 조회는 요청되지 않는다.

### TC-CURRENT-LOCATION-DOMAIN-002: 디바이스에서 위치를 확인하지 못하면 공인 IP 기준 위치를 사용한다

- 근거: `domain > 확인 순서`, `domain > 디바이스 위치`
- Given: 디바이스에서 위치를 확인할 수 없는 테스트 데이터의 조건이 제어되어 있고, 공인 IP 기준 위치 확인은 특정 위도와 경도로 성공하도록 제어되어 있다.
- When: 현재 위치 확인을 요청한다.
- Then: 확인은 디바이스 위치 조건 때문에 실패로 끝나지 않고, 공인 IP 기준 위도와 경도가 현재 위치로 확인된다.
- 테스트 데이터:

  | 디바이스 위치 조건 |
  | --- |
  | 디바이스가 위치 확인을 지원하지 않음 |
  | 위치 권한이 허용되어 있지 않음 |
  | 위치 권한이 허용되어 있는지 확인할 수 없음 |
  | 디바이스에서 위치를 확인하지 못함 |

### TC-CURRENT-LOCATION-DOMAIN-003: 공인 IP 기준 위치 조회에 실패하면 현재 위치를 확인하지 못한다

- 근거: `domain > 공인 IP 기준 위치`
- Given: 디바이스에서 위치를 확인할 수 없는 조건이 제어되어 있고, 공인 IP 기준 위치 조회가 실패하도록 제어되어 있다.
- When: 현재 위치 확인을 요청한다.
- Then: 현재 위치를 확인하지 못한 결과가 전달되고, 임의의 기본 위도와 경도가 확인 결과로 제공되지 않는다.

### TC-CURRENT-LOCATION-DOMAIN-005: 위치를 확인하는 과정에서 위치 권한을 요청하지 않는다

- 근거: `domain > 디바이스 위치`
- Given: 위치 권한이 허용되어 있지 않다.
- When: 현재 위치 확인을 요청한다.
- Then: 위치 권한 요청이 시작되지 않는다.
- 작성하지 않는 이유: 현재 테스트 환경은 플랫폼의 위치 권한 요청 창이 열렸는지를 관찰할 수 없고, 권한 요청이 없다는 것은 어떤 관찰 대상도 만들지 않아 결정적으로 판정할 수 없다. 권한 요청 발생 여부를 관찰할 수 있는 테스트 환경이 제공되면 자동화한다.

### TC-CURRENT-LOCATION-DOMAIN-006: 디바이스가 최근에 확인해 둔 위치가 있으면 새로 확인하지 않는다

- 근거: `domain > 디바이스 위치`
- Given: 디바이스에 최근에 확인해 둔 위치가 있고, 새로 확인하면 다른 위도와 경도가 나오도록 제어되어 있다.
- When: 현재 위치 확인을 요청한다.
- Then: 최근에 확인해 둔 위도와 경도가 현재 위치로 확인된다.
- 작성하지 않는 이유: 최근에 확인해 둔 위치와 새로 확인한 위치를 구분해 제공하는 것은 플랫폼 위치 서비스의 동작이고, 현재 호스트 테스트 환경은 그 두 위치를 각각 다른 값으로 제어할 수 없어 우선순위를 결정적으로 판정할 수 없다. 플랫폼 위치 서비스의 최근 위치와 신규 확인 결과를 각각 제어할 수 있는 테스트 환경이 제공되면 자동화한다.

### TC-CURRENT-LOCATION-DOMAIN-007: 웹에서 디바이스 위치 확인이 5초를 넘기면 확인하지 못한 것으로 다룬다

- 근거: `domain > 디바이스 위치`, `domain > 확인 순서`
- Given: 웹 환경에서 위치 권한이 허용되어 있고 브라우저가 위치를 5초 안에 알려 주지 않도록 제어되어 있으며, 공인 IP 기준 위치 확인은 특정 위도와 경도로 성공하도록 제어되어 있다.
- When: 현재 위치 확인을 요청한다.
- Then: 디바이스 위치 결과를 계속 기다리지 않고, 공인 IP 기준 위도와 경도가 현재 위치로 확인된다.
- 작성하지 않는 이유: 브라우저가 위치를 알려 주는 시점은 실제 브라우저의 동작이고, 현재 테스트 환경은 브라우저의 위치 응답 지연을 제어할 수 없다. 브라우저의 위치 응답 시점을 제어할 수 있는 테스트 환경이 제공되면 자동화한다.

## data

### TC-CURRENT-LOCATION-DATA-001: 공인 IP 기준 위치를 외부 서비스에 한 번 조회한다

- 근거: `domain > 공인 IP 기준 위치`
- Given: 디바이스에서 위치를 확인할 수 없는 조건이 제어되어 있고, 공인 IP 기준 위치 조회가 성공하도록 제어되어 있다.
- When: 현재 위치 확인을 요청한다.
- Then: 공인 IP로 위치를 알려 주는 외부 서비스로 나가는 조회 요청이 한 번 발생한다.

### TC-CURRENT-LOCATION-DATA-002: 공인 IP 기준 위치 응답의 위도와 경도를 현재 위치로 제공한다

- 근거: `domain > 공인 IP 기준 위치`
- Given: 디바이스에서 위치를 확인할 수 없는 조건이 제어되어 있고, 공인 IP 기준 위치 조회가 특정 위도와 경도를 담은 응답으로 성공하도록 제어되어 있다.
- When: 현재 위치 확인을 요청한다.
- Then: 응답에 담긴 위도와 경도가 그대로 현재 위치로 제공된다.
