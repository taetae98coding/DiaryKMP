# MoreHome 테스트 케이스

기준 스펙: [MoreHome 화면 스펙](../spec/client/more-home.md)

## feature

### TC-MORE-HOME-FEATURE-003: 확인 중 상태에서는 라벨과 계정 동작을 표시하지 않는다

- 근거: `feature > 계정 상태와 행동`
- Given: 계정 정보가 확인 중이다.
- When: 사용자가 계정 상태를 확인한다.
- Then: 게스트 라벨과 이메일이 표시되지 않고, 로그인 동작과 로그아웃 동작도 선택할 수 없다.

### TC-MORE-HOME-FEATURE-004: 게스트 상태에서 게스트 라벨과 로그인 동작을 표시한다

- 근거: `feature > 계정 상태와 행동`
- Given: 로그인한 사용자 정보가 없어 계정 상태가 게스트다.
- When: 사용자가 계정 상태를 확인한다.
- Then: 게스트 상태가 표시되고 로그인 동작을 선택할 수 있다.

### TC-MORE-HOME-FEATURE-005: 사용자 상태에서 이메일과 로그아웃 동작을 표시한다

- 근거: `feature > 계정 상태와 행동`
- Given: 이메일 `diary@example.com`을 가진 로그인 사용자 정보가 있다.
- When: 사용자가 계정 상태를 확인한다.
- Then: `diary@example.com`이 표시되고 게스트 상태는 표시되지 않으며 로그아웃 동작을 선택할 수 있다.

### TC-MORE-HOME-FEATURE-036: 표시할 프로필 이미지가 없으면 기본 프로필 이미지를 표시한다

- 근거: `feature > 계정 상태와 행동`
- Given: 계정 상태가 테스트 데이터의 상태다.
- When: 사용자가 프로필 자리를 확인한다.
- Then: 기본 프로필 이미지가 표시된다.
- 테스트 데이터:

| 계정 상태 |
| --- |
| 프로필 이미지가 없는 사용자 |
| 게스트 |
| 확인 중 |

- 작성하지 않는 이유: 기본 프로필 이미지와 사용자의 프로필 이미지는 그려진 그림으로만 구분되고 화면 요소의 정보로는 구분되지 않아, 어느 이미지가 표시되었는지 판정하려면 시각 판단이 필요하다. 표시 중인 이미지의 종류를 화면 요소의 정보로 드러내거나, 화면을 캡처해 기준 이미지와 비교하는 테스트 환경이 갖춰지면 작성한다.

### TC-MORE-HOME-FEATURE-037: 확인 다이얼로그가 열려 있는 동안에는 화면의 다른 조작을 할 수 없다

- 근거: `feature > 로그아웃 확인`
- Given: 로그아웃 확인 다이얼로그가 표시되어 있다.
- When: 사용자가 다이얼로그 뒤의 설정 이동이나 기능 바로가기를 누른다.
- Then: 설정이나 기능 바로가기 화면으로 이동하지 않고 다이얼로그가 그대로 표시된다.
- 작성하지 않는 이유: 다이얼로그가 뒤 화면의 입력을 막는 것은 플랫폼 창이 하는 일인데, 현재 화면 테스트 환경은 창마다 입력을 직접 보내 다이얼로그 뒤 화면에도 입력이 전달되므로 결과를 판정할 수 없다. 실제 Activity 창 위에서 화면 좌표로 입력을 보내는 기기 테스트 환경이 갖춰지면 작성한다.

### TC-MORE-HOME-FEATURE-038: 계정 상태나 표시 정보가 바뀌면 별도 조작 없이 바뀐 내용을 표시한다

- 근거: `feature > 내용 갱신과 새로고침`
- Given: 계정 상태가 테스트 데이터의 `이전`으로 표시되어 있다.
- When: 로그인, 로그아웃이나 사용자 정보 다시 확인으로 계정 정보가 테스트 데이터의 `이후`로 바뀐다.
- Then: 사용자가 아무것도 하지 않아도 테스트 데이터의 `이후`가 표시된다.
- 테스트 데이터:

| 이전 | 이후 |
| --- | --- |
| 게스트 | 사용자 |
| 사용자 | 게스트 |
| 사용자 | 이메일과 프로필 이미지가 바뀐 사용자 |
