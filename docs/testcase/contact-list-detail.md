# Contact 목록·상세 배치 테스트 케이스

기준 스펙: [Contact 목록·상세 배치 스펙](../spec/client/contact-list-detail.md)

이 문서에서 `domain > 배치에 참여하는 화면`, `feature > 추가 진입 수단`, `feature > 함께 사용과 단독 사용`, `feature > 함께 사용할 때의 행동` 절은 [목록·상세 배치 공통 스펙](../spec/client/list-detail-pane.md)이 소유한다. 나머지 케이스의 절은 기준 스펙이 소유한다.

선택한 연락처의 상세에서 확인하고 수정하고 삭제하는 케이스는 [ContactDetail 테스트 케이스](./contact-detail.md)에서 다룬다.

표시 비율 조절의 공통 행동과 유지 기준은 [목록·상세 배치 공통 스펙](../spec/client/list-detail-pane.md)에 위임되어 있다. 연락처 목록의 뒤로가기 동작으로 상세 영역에 놓인 화면과 관계없이 `더보기` 화면으로 돌아가는 케이스는 [ContactHome 테스트 케이스](./contact-home.md)의 TC-3c7dd4ea-e23f-4f08-abb3-ce38a1b4b2b4에서 다룬다. 한 화면만 사용하는 환경에서 연락처 목록에서 연락처 추가로 이동하는 케이스는 [ContactHome 테스트 케이스](./contact-home.md)에서 다룬다.

## feature

### TC-43da9f5e-8117-46fb-97a2-b6ca84b6646f: 목록과 상세를 함께 쓰는 환경에서는 두 영역을 함께 표시한다

- 근거: `feature > 함께 사용과 단독 사용`
- Given: 목록과 상세를 함께 사용할 수 있는 환경이다.
- When: 사용자가 ContactHome 화면에 진입한다.
- Then: 연락처 목록을 유지한 채 상세 영역에 연락처 추가가 함께 표시된다.

- 근거: `feature > 함께 사용과 단독 사용`
- Given: 목록과 상세를 함께 사용할 수 없는 환경이다.
- When: 사용자가 연락처 목록 또는 연락처 추가를 사용한다.
- Then: 현재 사용하는 화면만 단독으로 표시된다.

### TC-603058fa-cf2e-414c-bac9-ad734a1d8dc3: 상세 영역에 연락처 추가가 놓이면 목록에서 추가 수단을 제공하지 않는다

- 근거: `feature > 추가 진입 수단`
- Given: 상세 영역에 연락처 추가가 놓여 있다.
- When: 사용자가 연락처 목록에서 실행할 수 있는 동작을 확인한다.
- Then: 연락처 추가 동작이 제공되지 않는다. 추가 단축키를 눌러도 추가가 실행되지 않는다.

### TC-ab7166d7-90ca-4f2a-9f12-7f000a7e83ff: 상세 영역에 연락처 추가가 놓여 있지 않으면 목록에서 추가 수단을 제공한다

| --- |

### TC-547f4263-10de-4c07-900a-b9161c081798: 표시 비율을 조절하고 실행 경계를 지나도 공통 기준대로 유지하거나 초기화한다

- 근거: `domain > 유지와 초기화 기준`
- Given: 목록과 상세 영역이 함께 표시되어 있다.
- When: 사용자가 두 영역의 표시 비율을 조절한 뒤 테스트 데이터의 경계를 지난다.
- Then: 조절하는 동안 결과가 즉시 반영되고, 경계를 지난 뒤 표시 비율과 상세 선택이 테스트 데이터의 결과가 된다.
- 테스트 데이터:

| 경계 | 결과 |
| --- | --- |
| 화면 재생성 | 조절한 비율과 상세 선택 유지 |
| 백그라운드 복귀 | 조절한 비율과 상세 선택 유지 |
| 앱이 백그라운드에 있는 동안 시스템이 앱을 정리했다가 다시 만듦 | 조절한 비율과 상세 선택 유지 |
| `더보기`로 돌아갔다가 다시 진입 | 기본 비율과 선택 전 상태 |
| 앱 종료 뒤 다시 실행 | 기본 비율과 선택 전 상태 |

- 작성하지 않는 이유: 표시 비율은 실제 창 크기에서 두 영역의 경계를 끌어야 조절되고 앱 재실행은 앱 프로세스의 실행 경계를 지나야 판정할 수 있어, 표시 비율의 유지와 초기화는 현재 테스트 환경에서 결정적으로 검증할 수 없다. 상세 선택의 재생성 유지와 재진입 초기화는 TC-0c98d16c-241e-4b8e-a459-6dd782ce11d4과 TC-94e26d85-149b-4e23-88af-e7e81afde43d이, 시스템 정리 뒤 다시 만들기와 백그라운드 복귀의 상세 선택 유지는 TC-3702fa15-098d-46a9-a36e-ec1d5b5aa318과 TC-99c06fa7-892e-4ac3-ab5c-f159e79473c6이 따로 검증한다. 창 크기, 영역 경계 끌기와 실행 경계를 제어·관찰할 수 있는 통합 UI 테스트 환경이 갖춰지면 자동화한다.
