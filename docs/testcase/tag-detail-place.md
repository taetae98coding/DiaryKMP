# TagDetail 장소 탭 테스트 케이스

기준 스펙: [TagDetail 장소 탭 스펙](../spec/tag-detail-place.md)

보기 모드 전환, 지도 표시, 두 보기 모드의 목록과 지도 핀, 장소 추가와 상세로 넘기는 것, 정렬과 새로고침을 다루는 케이스의 `근거`가 가리키는 절은 [장소 보기 모드 스펙](../spec/place-view-mode.md)이 소유하고, 나머지 케이스의 절은 기준 스펙이 소유한다. 자리 표시 케이스의 절은 공통 규칙을 [페이지 조회 목록의 자리 표시 스펙](../spec/paged-list-placeholder.md)에, 빈 상태 케이스의 절은 [목록 빈 상태 스펙](../spec/list-empty-state.md)에, 새로고침 케이스의 절은 [새로고침 스펙](../spec/sync-refresh.md)에 위임한다.

## feature

### TC-TAG-DETAIL-PLACE-FEATURE-001: 대상 태그와 연결된 장소만 목록에 표시한다

- 근거: `feature > 목록 모드의 장소 목록`, `domain > 노출 대상 장소`
- Given: 표시 범위가 `이 태그만`이고, 상세 대상 태그와 연결된 장소와 다른 태그에만 연결된 장소가 저장되어 있다.
- When: 사용자가 TagDetail 화면에서 장소 탭을 연다.
- Then: 대상 태그와 연결된 장소만 목록에 표시된다.

### TC-TAG-DETAIL-PLACE-FEATURE-002: 목록은 제목 오름차순으로 표시한다

- 근거: `domain > 목록 정렬`
- Given: 상세 대상 태그에 제목이 서로 다른 장소 여러 개가 연결되어 있다.
- When: 사용자가 TagDetail 화면에서 장소 탭을 연다.
- Then: 장소가 제목 오름차순으로 표시된다.

### TC-TAG-DETAIL-PLACE-FEATURE-003: 자리 표시 상태의 장소는 선택할 수 없다

- 근거: `domain > 상세로 이동하는 대상`
- Given: 목록 모드에서 목록의 장소가 아직 준비되지 않아 자리 표시 상태로 제공되어 있다.
- When: 사용자가 해당 자리를 선택하려 한다.
- Then: 장소 상세 이동이 요청되지 않는다.

### TC-TAG-DETAIL-PLACE-FEATURE-004: 목록 조회 실패에 별도의 오류나 재시도 동작을 표시하지 않는다

- 근거: `feature > 목록 모드의 장소 목록`
- Given: 목록 조회가 테스트 데이터의 시점에 실패하도록 설정되어 있다.
- When: 사용자가 TagDetail 화면의 장소 탭을 확인한다.
- Then: 별도 재시도 동작 없이 테스트 데이터의 기존 표시 결과를 유지한다.
- 테스트 데이터:

| 실패 시점 | 기존 표시 결과 |
| --- | --- |
| 최초 조회 | 표시된 장소 없음. 이때의 빈 상태 안내는 `TC-TAG-DETAIL-PLACE-FEATURE-010`이 다룬다 |
| 추가 조회 | 이미 표시된 장소 |

### TC-TAG-DETAIL-PLACE-FEATURE-005: 장소를 선택하면 그 장소의 상세로 이동한다

- 근거: `feature > 장소 상세 확인`
- Given: 상세 대상 태그에 연결된 장소가 테스트 데이터의 보기 모드에서 표시되어 있다.
- When: 사용자가 그 장소를 선택한다.
- Then: 선택한 장소의 PlaceDetail 화면으로 이동한다.
- 테스트 데이터:

| 보기 모드 |
| --- |
| 목록 모드 |
| 지도 모드 |

### TC-TAG-DETAIL-PLACE-FEATURE-006: 대상 태그의 상태와 무관하게 장소 추가를 시작할 수 있다

- 근거: `feature > 장소 추가`, `domain > 장소 추가의 초기값`
- Given: 장소 탭의 상세 대상 태그 상태가 테스트 데이터의 상태다.
- When: 사용자가 TagDetail 화면의 장소 탭에서 가능한 동작을 확인한다.
- Then: 장소 추가를 시작할 수 있다.
- 테스트 데이터:

| 대상 태그 상태 |
| --- |
| 현재 사용자 계정과 연결되어 있고 미완료·미삭제 |
| 현재 사용자 계정과 연결되지 않음 |
| 완료 |
| 삭제 |

### TC-TAG-DETAIL-PLACE-FEATURE-007: 장소 추가를 선택하면 PlaceAdd 화면으로 이동한다

- 근거: `feature > 장소 추가`
- Given: 완료되지 않고 삭제되지 않은 태그의 TagDetail 화면의 장소 탭이 표시되어 있다.
- When: 사용자가 장소 추가를 선택한다.
- Then: PlaceAdd 화면으로 이동한다.

### TC-TAG-DETAIL-PLACE-FEATURE-008: 장소 추가 화면은 대상 태그를 초기 선택한 상태로 시작한다

- 근거: `feature > 장소 추가`, `domain > 장소 추가의 초기값`
- Given: 미완료·미삭제 상태인 태그 A의 TagDetail 화면의 장소 탭이 표시되어 있다.
- When: 사용자가 장소 추가를 선택한다.
- Then: PlaceAdd 화면에서 태그 A가 최초 선택되어 있고, 사용자는 저장 전까지 태그 A를 해제하거나 다른 태그를 선택할 수 있다.

### TC-TAG-DETAIL-PLACE-FEATURE-009: 완료되었거나 삭제된 대상 태그는 선택되지 않은 상태로 장소 추가를 시작한다

- 근거: `domain > 장소 추가의 초기값`
- Given: 대상 태그가 테스트 데이터의 상태인 TagDetail 화면의 장소 탭이 표시되어 있다.
- When: 사용자가 장소 추가를 선택한다.
- Then: PlaceAdd 화면에서 대상 태그가 선택된 것으로 표시되지 않는다.
- 테스트 데이터:

| 대상 태그 상태 |
| --- |
| 완료 |
| 삭제 |

### TC-TAG-DETAIL-PLACE-FEATURE-010: 목록 모드에서 연결된 장소가 없으면 빈 상태 안내를 표시한다

- 근거: `feature > 빈 상태`
- Given: 장소 탭이 목록 모드이고, 상세 대상 태그와 연결되고 노출 기준을 만족하는 장소가 하나도 없으며 목록의 준비가 끝났다.
- When: 사용자가 TagDetail 화면의 장소 탭을 확인한다.
- Then: 장소 카드 대신 이 태그에 연결된 장소가 없음을 알리는 안내가 표시된다.

### TC-TAG-DETAIL-PLACE-FEATURE-011: 목록을 준비하는 동안에는 빈 상태 안내를 표시하지 않는다

- 근거: `feature > 빈 상태`
- Given: 목록에 표시된 장소가 아직 하나도 없고 목록의 준비가 끝나지 않았다.
- When: 사용자가 TagDetail 화면의 장소 탭을 확인한다.
- Then: 빈 상태 안내가 표시되지 않는다.

### TC-TAG-DETAIL-PLACE-FEATURE-012: 대상 태그를 조회하지 못해도 빈 상태 안내는 같은 기준으로 표시한다

- 근거: `feature > 빈 상태`
- Given: 상세 대상 태그를 조회하지 못해 화면 제목이 표시되지 않고, 연결된 장소가 하나도 없으며 목록의 준비가 끝났다.
- When: 사용자가 TagDetail 화면의 장소 탭을 확인한다.
- Then: 이 태그에 연결된 장소가 없음을 알리는 안내가 표시된다.

### TC-TAG-DETAIL-PLACE-FEATURE-013: 빈 상태에서도 장소 추가와 보기 모드 전환을 실행할 수 있다

- 근거: `feature > 빈 상태`
- Given: TagDetail 화면의 장소 탭에 빈 상태 안내가 표시되어 있다.
- When: 사용자가 장소 추가와 보기 모드 전환을 각각 실행한다.
- Then: 상세 대상 태그를 초기값으로 하는 장소 추가 화면으로 이동하고, 보기 모드 전환도 실행된다.

### TC-TAG-DETAIL-PLACE-FEATURE-014: 장소 추가는 장소 탭에서만 제공된다

- 근거: `feature > 장소 추가`
- Given: 태그가 조회된 TagDetail 화면에서 테스트 데이터의 탭이 선택되어 있다.
- When: 사용자가 화면에서 실행할 수 있는 동작을 확인한다.
- Then: 장소 추가를 실행할 수 없고, 장소 탭으로 전환하면 장소 추가를 실행할 수 있다.
- 테스트 데이터:

| 선택한 탭 |
| --- |
| 태그 디테일 탭 |
| 메모 탭 |
| 웹 탭 |

### TC-TAG-DETAIL-PLACE-FEATURE-015: 대상 태그를 조회하지 못해도 장소 목록과 동작을 제공한다

- 근거: `feature > 진입`
- Given: 상세 대상 태그를 조회할 수 없고, 그 태그와 연결된 미삭제 장소가 저장되어 있다.
- When: 사용자가 TagDetail 화면에서 장소 탭을 연다.
- Then: 연결된 장소가 목록에 표시되고 장소 추가와 보기 모드 전환을 실행할 수 있다.

### TC-TAG-DETAIL-PLACE-FEATURE-016: 목록을 당기면 계정 데이터 동기화를 요청한다

- 근거: `feature > 장소 목록 새로고침`
- Given: 로그인한 계정의 TagDetail 화면에서 장소 탭이 선택되어 있고, 테스트 데이터의 보기 모드와 목록 상태다.
- When: 사용자가 장소 목록 영역을 아래로 당긴다.
- Then: 계정 데이터의 서버 동기화가 한 번 요청되고 진행 중임이 표시된다.
- 테스트 데이터:

| 보기 모드 | 목록 상태 |
| --- | --- |
| 목록 모드 | 연결된 장소가 표시되어 있음 |
| 목록 모드 | 빈 상태 안내가 표시되어 있음 |
| 지도 모드 | 보이는 영역 안의 장소가 표시되어 있음 |

### TC-TAG-DETAIL-PLACE-FEATURE-017: 목록에는 밀어서 상태를 바꾸는 제스처를 제공하지 않는다

- 근거: `domain > 태그 연결의 변경과 목록`
- Given: 상세 대상 태그에 연결된 장소가 표시되어 있다.
- When: 사용자가 그 장소를 좌우로 밀어 본다.
- Then: 어떤 상태 변경도 요청되지 않고 장소가 목록에 그대로 남는다.

### TC-TAG-DETAIL-PLACE-FEATURE-019: 목록 모드에서 장소 추가 화면에 지도 위치를 넘기지 않는다

- 근거: `domain > 장소 추가로 넘기는 지도 위치`
- Given: 미완료·미삭제 상태인 태그의 TagDetail 화면에서 장소 탭이 목록 모드로 표시되어 있다.
- When: 사용자가 장소 추가를 선택한다.
- Then: PlaceAdd 화면이 이 탭에서 넘겨받은 지도 위치 없이 자신의 기준으로 정한 위치에서 시작한다.

### TC-TAG-DETAIL-PLACE-FEATURE-020: 장소 탭을 선택하면 목록 모드로 시작한다

- 근거: `feature > 진입`, `domain > 기본 보기 모드`
- Given: 상세 대상 태그에 연결된 장소가 저장되어 있다.
- When: 사용자가 TagDetail 화면에서 장소 탭을 연다.
- Then: 지도와 지도 핀 없이 장소 목록만 표시되고, 전환 컨트롤은 지도로 보기를 가리킨다.

### TC-TAG-DETAIL-PLACE-FEATURE-021: 보기 모드를 바꾸면 지도와 보이는 영역 안의 장소 목록을 함께 표시한다

- 근거: `feature > 보기 모드 전환`, `feature > 지도 모드의 장소 목록`
- Given: 기본 지도와 현재 위치를 확인한 장소 탭이 목록 모드로 표시되어 있고, 대상 태그에 연결된 장소가 지도의 보이는 영역 안과 밖에 각각 저장되어 있다.
- When: 사용자가 보기 모드 전환을 실행한다.
- Then: 지도가 표시되고 목록에는 보이는 영역 안의 장소만 남는다.

### TC-TAG-DETAIL-PLACE-FEATURE-022: 지도 모드에서 다시 전환하면 목록 모드로 돌아온다

- 근거: `feature > 보기 모드 전환`
- Given: 장소 탭이 지도 모드로 표시되어 있다.
- When: 사용자가 보기 모드 전환을 한 번 더 실행한다.
- Then: 지도와 지도 핀이 사라지고 대상 태그에 연결된 장소 전체가 목록에 표시된다.

### TC-TAG-DETAIL-PLACE-FEATURE-023: 지도가 표시되지 않아도 보기 모드를 바꿀 수 있다

- 근거: `feature > 보기 모드 전환`, `feature > 지도 표시`
- Given: 기본 지도를 확인하지 못해 지도가 표시되지 않는 장소 탭이 테스트 데이터의 보기 모드로 표시되어 있다.
- When: 사용자가 보기 모드 전환을 실행한다.
- Then: 전환 컨트롤이 비활성으로 표시되지 않고 테스트 데이터의 기대 결과가 표시된다.
- 테스트 데이터:

| 보기 모드 | 기대 결과 |
| --- | --- |
| 목록 모드 | 지도 모드로 바뀌고 지도와 장소 목록 영역이 모두 표시되지 않음 |
| 지도 모드 | 목록 모드로 바뀌고 대상 태그에 연결된 장소 전체가 목록에 표시됨 |

### TC-TAG-DETAIL-PLACE-FEATURE-024: 기본 지도나 현재 위치를 확인하기 전에는 지도와 지도 모드 목록을 표시하지 않는다

- 근거: `feature > 지도 표시`
- Given: 장소 탭이 지도 모드이고 테스트 데이터의 확인 상태다.
- When: 사용자가 장소 탭을 확인한다.
- Then: 지도, 지도 제공자 전환과 장소 목록 영역이 모두 표시되지 않고 로딩이나 오류 안내도 표시되지 않는다.
- 테스트 데이터:

| 확인 상태 |
| --- |
| 기본 지도를 확인하기 전 |
| 기본 지도를 읽지 못함 |
| 현재 위치 확인이 끝나기 전 |

### TC-TAG-DETAIL-PLACE-FEATURE-025: 지도 모드에서 보이는 영역이 바뀌면 목록과 핀이 갱신된다

- 근거: `feature > 지도 모드의 장소 목록`, `domain > 목록 갱신`
- Given: 장소 탭이 지도 모드이고 대상 태그에 연결된 장소가 서로 다른 좌표에 저장되어 있다.
- When: 사용자가 지도를 옮겨 보이는 영역을 바꾼다.
- Then: 새 영역 안의 장소만 목록과 지도 핀에 남고, 영역 밖으로 나간 장소는 목록과 핀에서 사라진다.

### TC-TAG-DETAIL-PLACE-FEATURE-026: 지도 모드의 목록에 표시되는 장소가 지도 핀으로 지정된다

- 근거: `feature > 지도 핀`, `domain > 핀 표현`
- Given: 장소 탭이 지도 모드이고 대상 태그에 연결된 장소가 보이는 영역 안에 저장되어 있다.
- When: 사용자가 장소 탭을 확인한다.

| 태그 B | 태그 B와만 연결하고 태그 A와 연결하지 않음 | 새 장소가 나타나지 않음 |

### TC-TAG-DETAIL-PLACE-DATA-005: 탭별 조회는 서로 독립이다

- 근거: `data > 탭별 조회`
- Given: 대상 태그 조회가 실패하도록 제어되어 있고, 그 태그와 연결된 미삭제 장소가 저장되어 있다.
- When: 사용자가 장소 탭의 목록을 확인한다.
- Then: 태그 조회 실패와 무관하게 장소 목록이 노출 기준대로 조회되어 표시된다.

### TC-TAG-DETAIL-PLACE-DATA-006: 지도 모드의 목록은 태그 연결과 보이는 영역을 기준으로 조회한다

- 근거: `data > 태그별 장소 조회`, `data > 목록 조회`
- Given: 현재 계정과 다른 계정, 대상 태그와 다른 태그, 해제된 연결과 해제되지 않은 연결, 삭제 여부와 좌표가 서로 다른 장소가 함께 저장되어 있다.
- When: 현재 계정에서 대상 태그와 특정 보이는 영역을 기준으로 장소 목록을 조회한다.
- Then: 현재 계정과 연결되어 있고 대상 태그와 해제되지 않은 연결을 가지며 삭제되지 않았고 좌표가 그 영역 안에 있는 장소만 제목 오름차순으로 조회된다.

### TC-TAG-DETAIL-PLACE-DATA-007: 지도 모드의 조회는 날짜변경선을 걸친 영역의 양쪽 범위를 모두 포함한다

- 근거: `data > 태그별 장소 조회`, `domain > 지도 모드에 노출하는 장소`
- Given: 대상 태그와 연결된 미삭제 장소가 서쪽 경도가 동쪽 경도보다 큰 영역의 양쪽 범위에 각각 저장되어 있다.
- When: 그 영역을 기준으로 대상 태그의 장소 목록을 조회한다.
- Then: 양쪽 범위의 장소가 모두 조회되고, 영역 밖 경도의 장소는 조회되지 않는다.

### TC-TAG-DETAIL-PLACE-DATA-008: 지도 모드의 목록은 페이지로 나누지 않는다

- 근거: `domain > 지도 모드에 노출하는 장소`, `data > 태그별 장소 조회`
- Given: 장소 탭이 지도 모드이고 보이는 영역 안에 대상 태그와 연결된 장소가 목록 모드의 한 페이지 크기보다 많이 있다.
- When: 사용자가 목록을 확인한다.
- Then: 사용자가 목록을 내리지 않아도 영역 안의 장소가 모두 조회되어 자리 표시 카드 없이 표시된다.

### TC-TAG-DETAIL-PLACE-DATA-009: 보기 모드를 바꾸는 것은 서버 조회를 일으키지 않는다

- 근거: `data > 목록 조회`
- Given: 장소 탭이 표시되어 있고 서버 동기화 요청을 관찰할 수 있다.
- When: 사용자가 보기 모드를 여러 번 바꾼다.
- Then: 서버 동기화가 요청되지 않고 로컬 조회 결과만 바뀐다.

## 작성하지 않는 이유

장소 목록의 스크롤 위치를 탭 전환 후에도 유지하는 결과는 실제 스크롤 오프셋을 관찰해야 판정할 수 있어 현재 테스트 환경에서는 결정적으로 검증할 수 없다. 목록의 스크롤 위치를 외부에서 읽을 수 있는 테스트 환경이 갖춰지면 자동화한다.

지도 모드에서 지도 영역과 장소 목록 영역이 창 너비에 따라 위아래 또는 좌우로 나뉘는 결과는 실제 화면의 크기와 위치를 판정해야 하므로 작성하지 않는다.

`TC-TAG-DETAIL-PLACE-FEATURE-027`의 핀 누르기와 `TC-TAG-DETAIL-PLACE-FEATURE-032`의 지도 끌기는 지도 제공자의 지도가 실제로 표시되어야 조작할 수 있고, 호스트 테스트 환경에서는 지도 제공자의 화면 요소를 만들 수 없어 자동화하지 않는다. 지도 없이 판정할 수 있는 부분은 나누어 다룬다. 핀이 어떤 장소를 가리키는지는 목록과 같은 장소가 핀으로 지정되는 것으로, 당기는 자리가 목록 영역에 한정되는 것은 목록 영역에서 당겼을 때 새로고침이 요청되는 것으로 검증한다. 지도 제공자의 화면 요소를 구성할 수 있는 테스트 환경이 갖춰지면 자동화한다.

`TC-TAG-DETAIL-PLACE-DOMAIN-008`의 상세 대상 전환은 상세 대상 태그를 바꾸는 동안 같은 보기 모드 상태와 지도 상태가 유지되는지를 판정해야 하고, 대상 전환은 화면 밖의 전환 이력이 만들므로 이 문서의 범위에서 자동화하지 않는다. 보기 모드와 지도 위치가 대상과 무관하게 유지되는 부분은 `TC-TAG-DETAIL-PLACE-DOMAIN-006`이 다룬다.
