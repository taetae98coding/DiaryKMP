# AI 도구 제공 공통 테스트 케이스

기준 스펙: [AI 도구 제공 공통 스펙](../spec/client/ai-tool.md)

각 기능이 무엇을 보여 주고 바꾸는지와 어떤 조건에서 실패하는지는 그 기능의 스펙이 소유하므로 그 기능의 테스트 케이스가 다룬다. 이 문서는 제공하는 기능의 범위, 대상 계정, 화면이 없어서 달라지는 부분, 디데이의 요청과 결과와 저장·동기화를 다룬다. 데스크톱 연결에만 있는 동작은 [AI 도구 연결 테스트 케이스](./mcp-server.md)에서, Android와 iOS에만 있는 동작은 [앱 동작 제공 테스트 케이스](./app-action.md)에서 다룬다.
