# AI 도구 제공 공통 테스트 케이스

기준 스펙: [AI 도구 제공 공통 스펙](../spec/client/ai-tool.md)

각 기능이 무엇을 보여 주고 바꾸는지와 어떤 조건에서 실패하는지는 그 기능의 스펙이 소유하므로 그 기능의 테스트 케이스가 다룬다. 이 문서는 제공하는 기능의 범위, 대상 계정, 화면이 없어서 달라지는 부분, 항목과 태그의 연결, 디데이의 요청과 결과, 루틴과 루틴 기록의 요청과 결과와 저장·동기화를 다룬다. 데스크톱 연결에만 있는 동작은 [AI 도구 연결 테스트 케이스](./mcp-server.md)에서, Android와 iOS에만 있는 동작은 [앱 동작 제공 테스트 케이스](./app-action.md)에서 다룬다.

## domain

### TC-c3ac3b36-0621-4123-838a-1cb57a17ccf8: 제공하는 기능만 목록에 둔다

- 근거: `domain > 제공하는 기능`, `domain > 항목과 태그의 연결`
- Given: AI 도구가 앱의 기능을 사용할 수 있다.
- When: AI 도구가 제공하는 기능 목록을 확인한다.
- Then: 목록에는 `제공하는 기능` 표의 대상마다 조회 기능이 있고, 바꾸기가 있는 대상에는 추가, 수정, 삭제, 되돌리기 기능이 있다. 메모, 장소, 웹, 연락처, 체크리스트, QR, 곡, 디데이, 루틴에는 태그를 연결하는 기능과 해제하는 기능이 있다. 기기 설정 변경, 로그인·로그아웃·계정 탈퇴·프로필 이미지 변경, 파일, 앱 밖 서비스 조회, 링크 열기, 기기 장치가 필요한 기능은 목록에 없다.
