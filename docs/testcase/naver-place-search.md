# 네이버 장소 검색 테스트 케이스

기준 스펙: [네이버 장소 검색 스펙](../spec/naver-place-search.md)

이 문서에서 `data > 원격 조회`, `domain > 검색어`, `domain > 인증` 절은 [장소 검색 공통 스펙](../spec/place-search.md)이 소유한다. 나머지 케이스의 절은 기준 스펙이 소유한다.

## domain

### TC-NAVER-PLACE-SEARCH-DOMAIN-001: 검색은 최대 개수인 5개를 요청한다

- 근거: `domain > 검색어`
- Given: 네이버 인증 정보가 준비되어 있다.
- When: 검색어로 장소 검색을 요청한다.
- Then: 외부 경계로 나가는 요청에 결과 개수 5개가 포함된다.

## data

### TC-NAVER-PLACE-SEARCH-DATA-001: 검색어와 인증 정보를 담아 기본 정렬로 요청한다

- 근거: `domain > 검색어`, `domain > 인증`, `data > 원격 조회`
- Given: 네이버 인증 정보가 준비되어 있다.
- When: 검색어로 장소 검색을 요청한다.
- Then: 외부 경계로 나가는 요청에 검색어와 네이버 인증 정보가 포함되고, 정렬은 지정하지 않아 네이버 기본 정렬인 정확도순을 그대로 사용한다.

### TC-NAVER-PLACE-SEARCH-DATA-002: 성공 응답의 장소 목록을 그대로 전달한다

- 근거: `domain > 장소 정보`, `data > 원격 조회`
- Given: 외부 응답이 장소 목록을 담은 성공으로 제어되어 있다.
- When: 검색어로 장소 검색을 요청한다.
- Then: 응답에 담긴 장소 개수와 각 장소의 이름(강조 표식 포함), 분류, 지번 주소, 도로명 주소, 좌표, 링크, 설명이 받은 값 그대로 전달된다.

### TC-NAVER-PLACE-SEARCH-DATA-003: 결과가 없으면 빈 목록을 성공으로 전달한다

- 근거: `data > 원격 조회`
- Given: 외부 응답이 빈 장소 목록을 담은 성공으로 제어되어 있다.
- When: 검색어로 장소 검색을 요청한다.
- Then: 빈 목록이 실패가 아닌 정상 결과로 전달된다.

### TC-NAVER-PLACE-SEARCH-DATA-004: 원격 조회 실패를 그대로 알린다

- 근거: `domain > 인증`, `data > 실패 처리`
- Given: 외부 응답이 실패로 제어되어 있다.
- When: 검색어로 장소 검색을 요청한다.
- Then: 검색은 실패로 끝나며, 실패가 빈 목록 같은 정상 결과로 바뀌지 않는다.
- 테스트 데이터:

  | 외부 응답 | 기대 결과 |
  | --- | --- |
  | 인증 실패 | 실패 |
  | 잘못된 요청 | 실패 |
  | 서버 오류 | 실패 |

### TC-NAVER-PLACE-SEARCH-DATA-005: 검색 결과를 저장하지 않고 검색할 때마다 새로 조회한다

- 근거: `data > 원격 조회`
- Given: 같은 검색어로 두 번 검색할 수 있다.
- When: 같은 검색어로 검색을 두 번 요청한다.
- Then: 원격 조회가 두 번 모두 수행되고, 앞선 결과를 저장해 두었다가 그대로 돌려주지 않는다.
