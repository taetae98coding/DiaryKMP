# CalendarTimetable 테스트 케이스

기준 스펙: [CalendarTimetable 화면 스펙](../spec/client/calendar-timetable.md)

시간표에 표시할 메모의 노출 기준, 표시 색상, 조회 결과 정렬, 로그인이나 로그아웃으로 계정이 바뀌었을 때 다시 조회하는 것은 [캘린더 메모 표시 테스트 케이스](calendar-memo.md)에서 다루므로 여기서 중복 작성하지 않는다. 날짜 구성, 좌우로 넘기는 이동과 이동 범위, 아이템의 시간대와 배치, 화면 재생성 때 시간대 유지, 기간 선택의 칸과 기간은 [Timetable 컴포넌트 스펙](../spec/client/timetable.md)에 위임되어 [Timetable 테스트 케이스](timetable.md)가 갖는다. 각 연도의 공휴일 동기화와 이미 성공한 연도의 재조회 생략, 노출 설정과 국가 설정을 반영한 조회는 [공휴일 동기화 테스트 케이스](holiday-fetch.md)와 [공휴일 노출 설정 테스트 케이스](holiday-visibility.md)가 갖는다. 이 문서는 시간표 화면이 정하는 형식과 시작 날짜, 방향키로 날짜 이동, 년도와 월 안내, 공휴일 표시와 선택, 메모 자리, 메모 선택, 기간 선택 후 이동, 현재 시각 지정, 조회 기간과 공휴일 동기화 대상만 다룬다.
