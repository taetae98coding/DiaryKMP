# 제목 입력 테스트 케이스

기준 스펙: [제목 입력 스펙](../spec/client/title-input.md)

## feature

### TC-2db1e950-9dda-4d43-9a57-320e104fa91d: 엔터를 눌러도 줄이 나뉘지 않는다

- 근거: `feature > 제목 입력`
- Given: 제목 입력에 제목이 입력되어 있고 입력 초점이 제목 입력에 있다.
- When: 사용자가 엔터를 누른다.
- Then: 제목에 줄바꿈이 더해지지 않고 입력한 제목이 한 줄 그대로 유지된다.

### TC-6ebff0ef-7ef6-484f-9320-797193da9091: 입력 칸의 폭보다 긴 제목을 입력해도 입력 칸이 여러 줄로 늘어나지 않는다

- 근거: `feature > 제목 입력`
- Given: 짧은 제목이 입력된 제목 입력이 표시되어 있다.
- When: 사용자가 제목을 입력 칸의 폭보다 긴 제목으로 바꾼다.
- Then: 긴 제목이 한 줄로 놓이고, 입력 칸의 높이는 짧은 제목일 때와 같다.

### TC-b3d443d2-5551-4922-9e73-aae585e8d9d6: 입력 칸의 폭보다 긴 제목은 입력 칸 안에서 가로로 옮겨 가며 확인한다

- 근거: `feature > 제목 입력`
- Given: 입력 칸의 폭보다 긴 제목이 입력되어 있다.
- When: 사용자가 입력 칸 안에서 제목의 앞이나 뒤로 입력 위치를 옮긴다.
- Then: 입력 칸에 보이는 부분이 가로로 옮겨 가며 입력 위치 주변의 제목이 보인다.
- 작성하지 않는 이유: 입력 칸 안에서 보이는 글자 범위는 그려지는 위치로만 드러나고 화면의 공개된 상태로 노출되지 않아 실제 화면을 비교해야 판정할 수 있다. 입력 칸이 보이는 범위를 공개된 상태로 알리거나, 입력 위치를 옮긴 전후의 화면 프레임을 비교할 수 있는 시각 회귀 테스트 환경이 갖춰지면 자동화한다.

### TC-2b021010-a337-4c45-9992-0d5829d9011a: 입력 칸에 제목 입력임을 알리는 이름이 표시된다

- 근거: `feature > 제목 입력`
- Given: 테스트 데이터의 언어 환경에서 비어 있는 제목 입력이 표시되어 있다.
- When: 사용자가 제목 입력을 확인한다.
- Then: 테스트 데이터의 이름이 표시된다.
- 테스트 데이터:

| 언어 환경 | 이름 |
| --- | --- |
| 한국어 | `제목` |
| 그 외 기본 | `Title` |

### TC-0669514d-68cd-47d0-840c-c01e3ac05c18: 제목을 지우면 제목이 비워지고 입력 초점이 제목 입력에 남는다

- 근거: `feature > 제목 지우기`
- Given: 제목 입력에 제목이 입력되어 있다.
- When: 사용자가 제목 지우기를 선택한다.
- Then: 제목이 비워지고 입력 초점이 제목 입력에 있다.

### TC-48afecbd-f64f-495f-87a8-885a6bbd09fc: 제목이 비어 있으면 지우는 동작을 제공하지 않는다

- 근거: `feature > 제목 지우기`
- Given: 제목 입력이 비어 있다.
- When: 사용자가 제목 입력을 확인한다.
- Then: 제목 지우기가 제공되지 않는다.

### TC-eade93ed-5de8-4a91-8b56-229784e11052: 제목이 채워져 있어도 입력 칸 이름이 보이고 필수 표시는 없다

- 근거: `feature > 제목 입력`
- Given: 테스트 데이터의 언어 환경에서 제목이 채워진 제목 입력이 표시되어 있다.
- When: 사용자가 제목 입력을 확인한다.
- Then: 채워진 제목과 함께 테스트 데이터의 이름이 표시되고, 필수임을 알리는 표시는 없다.
- 테스트 데이터:

| 언어 환경 | 이름 |
| --- | --- |
| 한국어 | `제목` |
| 그 외 기본 | `Title` |

## domain

### TC-ad3aeb0c-4197-4f62-af49-a813f32dba0f: 진입할 때 초점을 두도록 정한 화면이 보이면 제목 입력에 초점이 한 번 놓인다

- 근거: `domain > 처음 입력 초점`
- Given: 진입할 때 입력 초점을 제목에 두도록 정한 화면에 제목 입력과 다른 입력이 함께 있다.
- When: 화면이 사용자에게 보이게 된다.
- Then: 입력 초점이 제목 입력에 놓인다.

### TC-5e874719-7686-4891-b321-a035de15bc6e: 화면이 회전해도 제목 입력으로 초점을 다시 옮기지 않는다

- 근거: `domain > 처음 입력 초점`
- Given: 진입할 때 제목 입력에 초점이 놓인 뒤 사용자가 초점을 다른 입력으로 옮겼다.
- When: 화면이 회전해 다시 그려진다.
- Then: 입력 초점이 제목 입력으로 되돌아가지 않는다.

### TC-22de3370-9d10-4feb-88db-0f677df4afbd: 화면이 회전해도 입력 중이던 제목이 유지된다

- 근거: `domain > 진행 상태 유지`
- Given: 제목 입력에 제목을 입력하고 있다.
- When: 화면이 회전해 다시 그려진다.
- Then: 입력 중이던 제목이 그대로 유지된다.

### TC-f8b8e282-11fe-40b8-ae77-3c1e3767cf42: 설명 입력 상태이면 제목 다음 초점은 제목 지우기를 건너뛰고 설명 입력으로 옮겨 간다

- 근거: `domain > 제목 다음 초점`
- Given: 제목 입력 바로 뒤에 설명 입력이 있고, 제목이 채워져 제목 지우기가 제공되며, 설명 입력이 설명 입력 상태이고, 입력 초점이 제목 입력에 있다.
- When: 사용자가 키보드로 다음 입력으로 초점을 옮긴다.
- Then: 입력 초점이 설명 입력에 놓인다.

### TC-acbbc8d9-8cde-490b-99f8-8ce8b4bba246: 마크다운 미리보기 상태이면 제목 다음 초점은 제목 지우기로 옮겨 간다

- 근거: `domain > 제목 다음 초점`
- Given: 제목 입력 바로 뒤에 설명 입력이 있고, 제목이 채워져 제목 지우기가 제공되며, 설명 입력이 마크다운 미리보기 상태이고, 입력 초점이 제목 입력에 있다.
- When: 사용자가 키보드로 다음 입력으로 초점을 옮긴다.
- Then: 입력 초점이 제목 지우기에 놓인다.

### TC-06582590-cccb-406b-af8d-bb503dce1236: 뒤에 설명 입력이 없으면 제목 다음 초점은 제목 지우기로 옮겨 간다

- 근거: `domain > 제목 다음 초점`
- Given: 제목 입력 바로 뒤에 설명 입력이 없고, 제목이 채워져 제목 지우기가 제공되며, 입력 초점이 제목 입력에 있다.
- When: 사용자가 키보드로 다음 입력으로 초점을 옮긴다.
- Then: 입력 초점이 제목 지우기에 놓인다.
