# 제목 입력 테스트 케이스

기준 스펙: [제목 입력 스펙](../spec/client/title-input.md)

## feature

### TC-TITLE-INPUT-FEATURE-001: 엔터를 눌러도 줄이 나뉘지 않는다

- 근거: `feature > 제목 입력`
- Given: 제목 입력에 제목이 입력되어 있고 입력 초점이 제목 입력에 있다.
- When: 사용자가 엔터를 누른다.
- Then: 제목에 줄바꿈이 더해지지 않고 입력한 제목이 한 줄 그대로 유지된다.

### TC-TITLE-INPUT-FEATURE-002: 입력 칸에 제목 입력임을 알리는 이름이 표시된다

- 근거: `feature > 제목 입력`
- Given: 테스트 데이터의 언어 환경에서 비어 있는 제목 입력이 표시되어 있다.
- When: 사용자가 제목 입력을 확인한다.
- Then: 테스트 데이터의 이름이 표시된다.
- 테스트 데이터:

| 언어 환경 | 이름 |
| --- | --- |
| 한국어 | `제목` |
| 그 외 기본 | `Title` |

### TC-TITLE-INPUT-FEATURE-003: 제목을 지우면 제목이 비워지고 입력 초점이 제목 입력에 남는다

- 근거: `feature > 제목 지우기`
- Given: 제목 입력에 제목이 입력되어 있다.
- When: 사용자가 제목 지우기를 선택한다.
- Then: 제목이 비워지고 입력 초점이 제목 입력에 있다.

### TC-TITLE-INPUT-FEATURE-004: 제목이 비어 있으면 지우는 동작을 제공하지 않는다

- 근거: `feature > 제목 지우기`
- Given: 제목 입력이 비어 있다.
- When: 사용자가 제목 입력을 확인한다.
- Then: 제목 지우기가 제공되지 않는다.

## domain

### TC-TITLE-INPUT-DOMAIN-001: 진입할 때 초점을 두도록 정한 화면이 보이면 제목 입력에 초점이 한 번 놓인다

- 근거: `domain > 처음 입력 초점`
- Given: 진입할 때 입력 초점을 제목에 두도록 정한 화면에 제목 입력과 다른 입력이 함께 있다.
- When: 화면이 사용자에게 보이게 된다.
- Then: 입력 초점이 제목 입력에 놓인다.

### TC-TITLE-INPUT-DOMAIN-002: 화면이 회전해도 제목 입력으로 초점을 다시 옮기지 않는다

- 근거: `domain > 처음 입력 초점`
- Given: 진입할 때 제목 입력에 초점이 놓인 뒤 사용자가 초점을 다른 입력으로 옮겼다.
- When: 화면이 회전해 다시 그려진다.
- Then: 입력 초점이 제목 입력으로 되돌아가지 않는다.

### TC-TITLE-INPUT-DOMAIN-003: 화면이 회전해도 입력 중이던 제목이 유지된다

- 근거: `domain > 진행 상태 유지`
- Given: 제목 입력에 제목을 입력하고 있다.
- When: 화면이 회전해 다시 그려진다.
- Then: 입력 중이던 제목이 그대로 유지된다.
