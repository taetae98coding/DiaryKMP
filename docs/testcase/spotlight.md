# Spotlight 항목 노출 테스트 케이스

기준 스펙: [Spotlight 항목 노출 스펙](../spec/client/spotlight.md)

Spotlight에 담긴 항목은 앱이 운영체제에 맡긴 항목과 각 항목의 정보로 관찰한다. 검색어와 항목을 맞춰 보는 방법, 결과 순서, 반영 지연과 iOS 설정의 노출 끄기는 운영체제가 정하므로 다루지 않는다. 열린 상세 화면의 내용과 고른 항목을 조회할 수 없을 때의 결과는 각 상세 화면의 테스트 케이스가 다룬다.

## feature

### TC-308f8a17-0dd3-4e86-9640-3411623074ff: 앱을 새로 시작하면 목록 화면 위에 고른 항목의 상세 화면을 연다

- 근거: `feature > 고른 항목 열기`
- Given: 앱이 실행 중이 아니다.
- When: 사용자가 Spotlight 결과에서 테스트 데이터의 항목을 고른다.
- Then: 앱이 시작되어 그 항목의 상세 화면이 보이고, 상세에서 뒤로 가면 테스트 데이터의 아래 화면이 보인다.
- 테스트 데이터:

| 항목 | 상세 화면 | 아래 화면 |
| --- | --- | --- |
| 메모 | MemoDetail | MemoHome 목록 |
| 태그 | TagDetail | TagHome 목록 |
| 장소 | PlaceDetail | PlaceHome |
| 웹 | WebDetail | WebHome |
| 연락처 | ContactDetail | ContactHome |
| 체크리스트 | ChecklistDetail | ChecklistHome |
| QR | QrDetail | QrHome |
| 곡 | MusicDetail | PlaylistHome |
| 디데이 | DDayDetail | DDayHome |

### TC-623b7d4f-6590-44ee-87c7-2984e6d1af57: 보던 화면이 남아 있으면 그 위에 상세 화면을 연다

- 근거: `feature > 고른 항목 열기`
- Given: 앱이 보던 화면이 남아 있고, 그 화면은 고를 항목의 상세 화면이 아니다.
- When: 사용자가 Spotlight 결과에서 메모를 고른다.
- Then: 보던 화면 위에 그 메모의 MemoDetail 화면이 열리고, 상세에서 뒤로 가면 고르기 전에 보던 화면이 그대로 보인다.
- 테스트 데이터:

| 보던 화면 |
| --- |
| CalendarHome |
| 다른 메모의 MemoDetail |
| TagDetail |

### TC-78950452-bd6c-4403-bee9-33266b6eef48: 보던 화면이 고른 항목의 상세 화면이면 상세 화면을 더 쌓지 않는다

- 근거: `feature > 고른 항목 열기`
- Given: 앱이 메모 A의 MemoDetail 화면을 보던 상태로 남아 있다.
- When: 사용자가 Spotlight 결과에서 메모 A를 고른다.
- Then: 메모 A의 MemoDetail 화면이 그대로 보이고, 상세에서 뒤로 가면 메모 A의 상세를 보기 전 화면이 보인다.

## domain

### TC-75a4449a-4607-4404-bee9-cdfb3d735a29: 현재 계정의 삭제되지 않은 항목을 완료 여부와 관계없이 노출한다

- 근거: `domain > 노출 대상`
- Given: 현재 계정과 연결된 테스트 데이터의 항목과, 기기에 남아 있는 다른 계정의 메모가 저장되어 있다. 사용자가 앱에서 목록 필터를 골라 두었다.
- When: 앱이 시작되어 현재 계정이 확인된다.
- Then: 각 항목이 테스트 데이터의 노출 여부대로 Spotlight에 담기고, 다른 계정의 메모는 담기지 않는다.
- 테스트 데이터:

| 항목 | 노출 |
| --- | --- |
| 진행 중 메모 | 노출 |
| 완료된 메모 | 노출 |
| 삭제된 메모 | 노출하지 않음 |
| 진행 중 태그 | 노출 |
| 완료된 태그 | 노출 |
| 장소, 웹, 연락처, 체크리스트, QR, 곡 각 1개 | 노출 |
| 종료일이 지난 디데이 | 노출 |
| 삭제된 디데이 | 노출하지 않음 |
| 고른 목록 필터에서 보이지 않는 메모 | 노출 |

### TC-ffa2902e-19f4-4595-a5ba-f0d96e826b91: 현재 계정을 확인할 수 없으면 어떤 항목도 노출하지 않는다

- 근거: `domain > 노출 대상`
- Given: Spotlight에 항목이 담겨 있고, 계정 조회가 실패하도록 응답이 정해져 있다.
- When: 앱이 시작된다.
- Then: Spotlight에 어떤 항목도 담기지 않는다.

### TC-4feb13cd-47f2-4919-86ca-6e316bab251d: 항목마다 정해진 정보만 담는다

- 근거: `domain > 담는 정보`
- Given: 현재 계정에 테스트 데이터의 항목이 저장되어 있다.
- When: 그 항목이 Spotlight에 담긴다.
- Then: 항목에는 테스트 데이터의 정보와 아이콘 색만 담기고, 이 밖의 값과 항목 사이의 연결은 담기지 않는다.
- 테스트 데이터:

| 항목 | 담는 정보 | 아이콘 색 | 담지 않는 값의 예 |
| --- | --- | --- | --- |
| 메모 | 제목, 설명 | 메모의 컬러 | 기간, 연결한 태그 |
| 태그 | 이모지, 제목, 설명 | 태그의 컬러 | 연결한 태그 |
| 장소 | 제목, 설명, 주소 | 장소의 컬러 | 좌표 |
| 웹 | 제목, 설명, URL | 없음 | 연결한 태그 |
| 연락처 | 이름, 설명 | 없음 | 번호, 생일 |
| 체크리스트 | 제목, 설명 | 없음 | 체크 항목 |
| QR | 제목, 설명 | 없음 | QR에 담긴 내용 |
| 곡 | 제목, 아티스트 | 없음 | 링크 |
| 디데이 | 제목, 설명 | 디데이의 컬러 | 기준일, 반복 간격, 연결한 태그 |

## data

### TC-585b6caf-41ba-4f5b-9ff0-eec55d5a3beb: 기기에 저장된 항목이 바뀌면 Spotlight에 반영한다

- 근거: `data > 반영 시점`
- Given: 앱이 실행 중이고 현재 계정이 확인되어 있다.
- When: 기기에 저장된 메모가 테스트 데이터대로 바뀐다.
- Then: 사용자가 아무것도 하지 않아도 Spotlight가 테스트 데이터의 결과가 된다.
- 테스트 데이터:

| 바뀐 내용 | 결과 |
| --- | --- |
| 메모 추가 | 추가한 메모가 담긴다 |
| 메모 제목 수정 | 그 메모의 제목이 바뀐 제목으로 담긴다 |
| 메모 완료 | 그 메모가 그대로 담겨 있다 |
| 메모 삭제 | 그 메모가 빠진다 |
| 삭제한 메모 되돌리기 | 그 메모가 다시 담긴다 |
| 동기화로 내려받은 메모 추가 | 내려받은 메모가 담긴다 |

### TC-29e44189-cc2f-43d5-9a38-b738e75f615d: 계정이 바뀌면 이전 계정의 항목을 빼고 바뀐 계정의 항목을 담는다

- 근거: `data > 반영 시점`
- Given: 테스트 데이터의 이전 계정의 메모가 Spotlight에 담겨 있고, 바뀔 계정의 메모가 기기에 저장되어 있다.
- When: 테스트 데이터대로 계정이 바뀐다.
- Then: 이전 계정의 메모는 Spotlight에서 빠지고, 바뀐 계정의 메모가 담긴다.
- 테스트 데이터:

| 이전 계정 | 계정 변경 | 바뀐 계정 |
| --- | --- | --- |
| 게스트 | 로그인 | 사용자 |
| 사용자 | 로그아웃 | 게스트 |
| 사용자 | 계정 탈퇴 | 게스트 |

### TC-446731f1-5cf7-4659-b880-1715fbd0ac76: 앱이 시작되어 계정이 확인되면 Spotlight를 노출 대상과 맞춘다

- 근거: `data > 반영 시점`
- Given: Spotlight에 지금은 삭제된 메모와 다른 계정의 메모가 담겨 있고, 현재 계정의 메모 하나가 담겨 있지 않다.
- When: 앱이 시작되어 현재 계정이 확인된다.
- Then: Spotlight에는 현재 계정의 삭제되지 않은 메모만 담기며, 빠져 있던 메모가 담기고 삭제된 메모와 다른 계정의 메모는 빠진다.
