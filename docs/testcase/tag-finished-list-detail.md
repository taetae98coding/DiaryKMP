# TagFinishedList 목록·상세 배치 테스트 케이스

기준 스펙: [TagFinishedList 목록·상세 배치 스펙](../spec/client/tag-finished-list-detail.md)

TagHome 목록에서 진입한 태그 상세와 태그 추가의 배치 케이스는 [Tag 목록·상세 배치 테스트 케이스](./tag-list-detail.md)에서 다룬다. 상세 화면 하나에서 다시 시작 뒤 수정 중이던 내용이 유지되는 결과는 [TagDetail 화면 테스트 케이스](./tag-detail.md)가 다루고, 이 문서는 그 결과가 목록과 상세 영역에 함께 나타나는 것을 다룬다.

## feature

### TC-TAG-FINISHED-LIST-DETAIL-FEATURE-001: 목록과 상세를 함께 쓰는 환경에서는 두 영역을 함께 표시한다

- 근거: `feature > 상세 영역의 구성`
- Given: 목록과 상세를 함께 사용할 수 있는 환경이다.
- When: 사용자가 TagHome 목록에서 완료된 태그 확인을 선택한다.
- Then: 완료된 태그 목록을 목록·상세 배치의 목록 영역에 표시해 상세 영역과 함께 쓸 수 있고, TagHome 목록은 함께 표시되지 않는다.

### TC-TAG-FINISHED-LIST-DETAIL-FEATURE-002: 선택 전 상세에는 태그를 선택하라는 안내만 표시한다

- 근거: `feature > 상세 영역의 구성`
- Given: 목록과 상세를 함께 사용할 수 있는 환경이고 아직 태그를 선택하지 않았다.
- When: 사용자가 상세 영역을 확인한다.
- Then: 테스트 데이터의 언어 환경에 해당하는 안내가 표시되고, 선택 전 상세에는 사용자가 실행할 수 있는 동작이 없다.
- 테스트 데이터:

| 언어 환경 | 기대 안내 |
| --- | --- |
| 한국어 | `태그를 선택하세요` |
| 그 외 기본 | `Choose a tag` |

### TC-TAG-FINISHED-LIST-DETAIL-FEATURE-003: 태그를 선택하면 상세 영역에 그 태그의 상세 화면이 표시된다

- 근거: `feature > 상세 영역의 구성`
- Given: 목록과 상세를 함께 사용하고 있고 완료된 태그 목록에 태그가 있다.
- When: 사용자가 목록에서 태그 하나를 선택한다.
- Then: 완료된 태그 목록은 유지되고 상세 영역에 선택한 태그의 상세 화면이 표시된다.

### TC-TAG-FINISHED-LIST-DETAIL-FEATURE-004: 다른 태그를 선택하면 상세 영역에 쌓인 화면을 정리하고 교체한다

- 근거: `feature > 상세 영역의 구성`
- Given: 목록과 상세를 함께 사용하고 있고 상세 영역에 테스트 데이터의 순서로 화면이 놓여 있다.
- When: 사용자가 목록에서 다른 태그를 선택한다.
- Then: 앞서 놓인 화면을 쌓아 두지 않고 상세 영역이 새로 선택한 태그의 상세 화면 하나로 교체된다.
- 테스트 데이터:

| 상세 영역에 놓인 순서 |
| --- |
| 태그 상세 |
| 태그 상세에 이어 연결한 태그의 상세 |
| 태그 상세에 이어 연결 입력으로 연 태그 추가 |

### TC-TAG-FINISHED-LIST-DETAIL-FEATURE-005: 상세 영역의 태그 상세에서 연결 입력으로 연 화면도 상세 영역에 놓인다

- 근거: `feature > 상세 영역의 구성`, `domain > 배치에 참여하는 화면`
- Given: 목록과 상세를 함께 사용하고 있고, 목록에서 선택한 태그의 상세 화면이 상세 영역에 표시되어 있다.
- When: 사용자가 상세 영역의 태그 상세에서 테스트 데이터의 화면을 연다.
- Then: 완료된 태그 목록은 유지되고 연 화면이 상세 영역에 표시된다.
- 테스트 데이터: 연결한 태그의 상세, 연결 입력으로 연 태그 추가

### TC-TAG-FINISHED-LIST-DETAIL-FEATURE-006: 한 영역만 쓰는 환경에서는 현재 영역만 표시한다

- 근거: `feature > 상세 영역의 구성`
- Given: 한 영역만 사용하는 환경이다.
- When: 사용자가 완료된 태그 목록 또는 태그 상세를 사용한다.
- Then: 현재 사용하는 화면만 단독으로 표시된다.

### TC-TAG-FINISHED-LIST-DETAIL-FEATURE-007: 목록과 상세를 함께 표시하는 동안에도 공통 내비게이션을 제공하지 않는다

- 근거: `feature > 함께 사용할 때의 행동`
- Given: 목록과 상세를 함께 사용할 수 있는 환경에서 TagHome 목록을 거쳐 TagFinishedList 화면에 진입했다.
- When: 사용자가 목록에서 테스트 데이터의 화면을 상세 영역에 연다.
- Then: 주요 목적지의 공통 내비게이션이 제공되지 않는다.
- 테스트 데이터:

| 상세 영역 화면 |
| --- |
| 열지 않음 |
| 태그 상세 |

### TC-TAG-FINISHED-LIST-DETAIL-FEATURE-008: 상세가 선택된 상태에서 뒤로가면 목록을 유지하고 상세만 되돌린다

- 근거: `feature > 뒤로가기`
- Given: 목록과 상세를 함께 사용하고 있고 상세 영역에 테스트 데이터의 순서로 화면을 열었다.
- When: 사용자가 뒤로간다.
- Then: 완료된 태그 목록은 유지되고 상세 영역이 테스트 데이터의 기대 상태가 된다.
- 테스트 데이터:

| 상세 영역에 연 순서 | 기대 상태 |
| --- | --- |
| 목록에서 고른 태그 상세 | 선택 전 상태 |
| 목록에서 고른 태그 상세에 이어 목록에서 고른 다른 태그 상세 | 선택 전 상태 |
| 목록에서 고른 태그 상세에 이어 연결한 태그의 상세 | 목록에서 고른 태그 상세 |

### TC-TAG-FINISHED-LIST-DETAIL-FEATURE-009: 상세 영역의 태그 상세에서 탭으로 연 화면은 이 배치에 참여하지 않는다

- 근거: `feature > 상세 영역의 구성`, `domain > 배치에 참여하는 화면`
- Given: 목록과 상세를 함께 사용하고 있고, 목록에서 선택한 태그의 상세 화면이 상세 영역에 표시되어 있다.
- When: 사용자가 상세 영역의 태그 상세에서 테스트 데이터의 화면을 연다.
- Then: 그 화면은 TagFinishedList의 목록·상세 배치의 상세 영역에 놓이지 않는다.
- 테스트 데이터: 메모 탭의 메모 상세, 메모 탭의 메모 추가, 웹 탭의 웹 항목 상세, 장소 탭의 장소 상세, 완료된 메모 목록

### TC-TAG-FINISHED-LIST-DETAIL-FEATURE-010: TagFinishedList에서 진입하지 않은 화면은 이 배치에 참여하지 않는다

- 근거: `domain > 배치에 참여하는 화면`
- Given: 목록과 상세를 함께 사용할 수 있는 환경이다.
- When: 사용자가 TagFinishedList가 아닌 화면에서 테스트 데이터의 화면으로 이동한다.
- Then: 해당 화면을 TagFinishedList의 목록·상세 배치에 참여시키지 않는다.
- 테스트 데이터: TagHome 목록에서 진입한 태그 상세, TagHome 목록에서 진입한 태그 추가, 메모 상세의 태그 입력에서 진입한 태그 상세

### TC-TAG-FINISHED-LIST-DETAIL-FEATURE-011: 완료된 태그 목록의 선택 전 상세에는 태그 추가가 나타나지 않는다

- 근거: `feature > 상세 영역의 구성`, `domain > 상세 선택`
- Given: 목록과 상세를 함께 사용할 수 있는 환경에서 TagFinishedList 화면이 목록 영역에 표시되어 있고 아직 태그를 선택하지 않았다.
- When: 사용자가 목록과 상세 영역에서 실행할 수 있는 동작을 확인한다.
- Then: 태그 추가 동작이 제공되지 않고 상세 영역에 태그 추가 화면이 표시되지 않는다.

### TC-TAG-FINISHED-LIST-DETAIL-FEATURE-012: 목록 화면의 뒤로가기 동작은 상세 선택 여부와 관계없이 TagHome 목록으로 돌아간다

- 근거: `feature > 뒤로가기`
- Given: TagHome 목록을 거쳐 TagFinishedList 화면에 진입했고 상세 영역이 테스트 데이터의 상태다.
- When: 사용자가 완료된 태그 목록 화면이 제공하는 뒤로가기 동작을 사용한다.
- Then: 완료된 태그 목록과 상세 영역이 함께 닫히고 TagHome 목록으로 돌아간다.
- 테스트 데이터:

| 상세 영역 상태 |
| --- |
| 선택 전 상태 |
| 태그 상세 화면 |
| 태그 상세에 이어 연결한 태그의 상세 |

### TC-TAG-FINISHED-LIST-DETAIL-FEATURE-013: 상세가 선택 전 상태일 때 뒤로가면 목록 화면 전체를 떠나 TagHome 목록으로 돌아간다

- 근거: `feature > 뒤로가기`
- Given: 목록과 상세를 함께 사용하고 있고, TagHome 목록을 거쳐 진입한 TagFinishedList 화면의 상세 영역이 선택 전 상태다.
- When: 사용자가 뒤로간다.
- Then: 완료된 태그 목록과 상세 영역이 함께 닫히고 TagHome 목록이 표시된다.

### TC-TAG-FINISHED-LIST-DETAIL-FEATURE-014: 상세 영역의 태그 상세에서 탭으로 연 화면에서 돌아오면 떠나기 전의 태그 상세가 놓인다

- 근거: `feature > 상세 영역의 구성`, `domain > 유지와 초기화 기준`
- Given: 목록과 상세를 함께 사용하고 있고 상세 영역에 완료된 태그 목록에서 고른 태그 상세가 놓여 있다.
- When: 사용자가 그 태그 상세에서 테스트 데이터의 화면으로 이동했다가 뒤로간다.
- Then: 완료된 태그 목록과 함께 상세 영역에 떠나기 전의 태그 상세가 놓인다.
- 테스트 데이터: 메모 탭의 메모 상세, 메모 탭의 메모 추가, 웹 탭의 웹 항목 상세, 장소 탭의 장소 상세, 완료된 메모 목록

### TC-TAG-FINISHED-LIST-DETAIL-FEATURE-015: 상세 영역에서 태그를 삭제하면 뒤로가기와 같이 그 전 상태로 돌아간다

- 근거: `feature > 상세 영역의 구성`
- Given: 목록과 상세를 함께 사용하고 있고 상세 영역에 테스트 데이터의 순서로 태그 상세를 열었다.
- When: 사용자가 마지막에 연 태그 상세에서 태그 삭제에 성공한다.
- Then: 완료된 태그 목록은 유지되고 상세 영역이 테스트 데이터의 기대 상태가 된다.
- 테스트 데이터:

| 상세 영역에 연 순서 | 기대 상태 |
| --- | --- |
| 목록에서 고른 태그 상세 | 선택 전 상태 |
| 목록에서 고른 태그 상세에 이어 목록에서 고른 다른 태그 상세 | 선택 전 상태 |
| 목록에서 고른 태그 상세에 이어 연결한 태그의 상세 | 목록에서 고른 태그 상세 |

### TC-TAG-FINISHED-LIST-DETAIL-FEATURE-016: 상세 영역의 태그 상세는 연결한 태그를 눌러 이어 연 경우에만 뒤로가기 동작을 제공한다

- 근거: `feature > 상세 영역의 구성`
- Given: 목록과 상세를 함께 사용하고 있고 상세 영역에 테스트 데이터의 경로로 태그 상세가 놓여 있다.
- When: 사용자가 그 태그 상세 화면을 확인한다.
- Then: 뒤로가기 동작의 제공 여부가 테스트 데이터의 기대 결과와 같다.
- 테스트 데이터:

| 경로 | 뒤로가기 동작 |
| --- | --- |
| 목록에서 고른 태그 상세 | 제공하지 않음 |
| 목록에서 고른 태그 상세에 이어 다른 태그를 고른 태그 상세 | 제공하지 않음 |
| 목록에서 고른 태그 상세의 연결 입력에서 연결한 태그를 눌러 연 태그 상세 | 제공함 |

### TC-TAG-FINISHED-LIST-DETAIL-FEATURE-017: 상세 영역에서 태그를 다시 시작하면 목록에서 사라지고 상세는 그대로 남는다

- 근거: `feature > 상세 영역의 구성`
- Given: 목록과 상세를 함께 사용하고 있고, 완료된 태그 목록에서 고른 태그의 상세가 상세 영역에 놓여 있으며 다시 시작이 성공하도록 설정되어 있다.
- When: 사용자가 상세 영역의 태그를 다시 시작한다.
- Then: 그 태그는 완료된 태그 목록에서 사라지고, 상세 영역에는 같은 태그의 상세가 남아 완료 동작을 제공한다.

## domain

### TC-TAG-FINISHED-LIST-DETAIL-DOMAIN-001: 목록 화면을 떠났다가 다시 진입하면 상세가 선택 전 상태로 돌아간다

- 근거: `domain > 유지와 초기화 기준`
- Given: TagHome 목록을 거쳐 진입한 TagFinishedList 화면의 상세 영역에 테스트 데이터의 화면이 놓여 있다.
- When: 사용자가 완료된 태그 목록 화면이 제공하는 뒤로가기로 TagHome 목록에 돌아간 뒤, 다시 완료된 태그 확인을 선택한다.
- Then: 완료된 태그 목록만 열린 상태로 돌아와 상세는 선택 전 상태이며, 떠나기 전에 열었던 태그 상세는 남아 있지 않다.
- 테스트 데이터:

| 상세 영역에 연 화면 |
| --- |
| 태그 상세 |
| 태그 상세에 이어 연결한 태그의 상세 |

### TC-TAG-FINISHED-LIST-DETAIL-DOMAIN-002: 다른 주요 목적지로 이동하면 이 배치를 떠난 것으로 본다

- 근거: `domain > 유지와 초기화 기준`
- Given: TagFinishedList 화면의 상세 영역에 태그 상세가 놓여 있다.
- When: 사용자가 파일 올리기 알림을 선택해 `더보기` 위에 FileHome 화면이 열린 뒤, 태그 주요 목적지로 돌아온다.
- Then: 완료된 태그 목록과 상세가 남아 있지 않고 TagHome 목록이 표시된다.

## 작성하지 않는 이유

- 두 영역의 표시 비율 조절과 조절 중 즉시 반영, 화면 재생성·백그라운드 복귀·시스템 정리 후 다시 만들기의 비율 유지, 재진입 후 비율 초기화와 앱 재실행 후 기본 상태 초기화는 실제 화면 너비와 실행 경계를 함께 제어하고 관찰해야 한다. 같은 실행 경계의 상세 선택 유지는 [테스트 케이스 목록](./README.md)의 `목록·상세 배치 공통 스펙` 항목에 따라 `TC-MEMO-LIST-DETAIL-DOMAIN-004`가 대표로 갖는다. 재진입 후 상세 선택 초기화는 `TC-TAG-FINISHED-LIST-DETAIL-DOMAIN-001`이 다룬다. 현재 테스트 환경에서는 결정적으로 자동화할 수 없으며, 화면 크기와 실행 경계를 제어하는 통합 UI 테스트 환경이 갖춰지면 자동화한다.
