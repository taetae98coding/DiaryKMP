# CalendarMonth 테스트 케이스

기준 스펙: [CalendarMonth 컴포넌트 스펙](../spec/calendar-month.md)

## feature

### TC-CALENDAR-MONTH-FEATURE-001: 지정한 달의 여섯 주를 표시한다

- 근거: `feature > 여섯 주 표시`, `domain > 여섯 주 고정`
- Given: 2026년 7월이 지정된다.
- When: CalendarMonth가 표시된다.
- Then: 첫 주의 일요일인 6월 28일부터 여섯 번째 주의 토요일인 8월 8일까지 42개의 날짜 숫자가 순서대로 표시된다.

### TC-CALENDAR-MONTH-FEATURE-002: 지정한 아이템이 겹치는 주에만 표시된다

- 근거: `feature > 아이템 표시`
- Given: 2026년 7월이 지정되고, 첫 주(6월 28일부터 7월 4일까지)에만 겹치는 7월 1일부터 3일까지의 아이템 하나가 지정된다.
- When: CalendarMonth가 표시된다.
- Then: 해당 아이템의 내용이 한 번만 표시된다.

### TC-CALENDAR-MONTH-FEATURE-003: 되돌리기를 요청하면 여섯 주가 모두 첫 아이템 줄부터 다시 보인다

- 근거: `feature > 아이템 스크롤 되돌리기`
- Given: 2026년 7월이 지정되고, 서로 다른 두 주에 각각 아이템 영역에 한 번에 들어가지 않을 만큼 많은 아이템이 지정되어 있다. 사용자가 두 주의 아이템 영역을 각각 아래로 스크롤해 두 주의 첫 아이템이 모두 보이지 않는 상태다.
- When: 배치하는 화면이 아이템 영역의 스크롤을 맨 위로 되돌리도록 요청한다.
- Then: 두 주의 첫 아이템 내용이 모두 다시 보인다.

## domain

### TC-CALENDAR-MONTH-DOMAIN-001: 주 수가 여섯보다 적은 달은 남는 주가 다음 달 날짜로만 표시된다

- 근거: `domain > 여섯 주 고정`
- Given: 네 주로 끝나는 2026년 2월이 지정된다.
- When: CalendarMonth가 표시된다.
- Then: 2월 1일부터 28일까지에 이어 다음 달인 3월 1일부터 14일까지의 숫자가 순서대로 표시되어, 남는 두 주가 다음 달 날짜로만 구성된다.

### TC-CALENDAR-MONTH-DOMAIN-002: 여러 주에 걸친 아이템은 겹치는 각 주에 나뉘어 표시된다

- 근거: `domain > 여러 주에 걸친 아이템`
- Given: 2026년 7월이 지정되고, 첫 주와 두 번째 주에 걸치는 7월 4일부터 5일까지의 아이템 하나가 지정된다.
- When: CalendarMonth가 표시된다.
- Then: 해당 아이템의 내용이 두 번 표시된다.

### TC-CALENDAR-MONTH-DOMAIN-003: 여섯 주와 겹치지 않는 아이템은 어느 주에도 표시되지 않는다

- 근거: `domain > 여러 주에 걸친 아이템`
- Given: 2026년 7월이 지정되고, 여섯 주 범위인 6월 28일부터 8월 8일까지와 하루도 겹치지 않는 8월 9일부터 11일까지의 아이템이 지정된다.
- When: CalendarMonth가 표시된다.
- Then: 해당 아이템의 내용이 표시되지 않는다.
