# Tag 목록·상세 배치 테스트 케이스

기준 스펙: [Tag 목록·상세 배치 스펙](../spec/client/tag-list-detail.md)

추가 진입 수단 케이스의 `근거`가 가리키는 절은 공통 규칙을 [목록·상세 배치 공통 스펙](../spec/client/list-detail-pane.md)의 `추가 진입 수단`에 위임한다.

## feature

| 태그 상세에 이어 연결한 태그의 상세 | 앞선 태그 상세 |

## 작성하지 않는 이유

두 영역의 표시 비율 조절과 조절 중 즉시 반영, 화면 재생성과 시스템 정리 후 다시 만들기와 완료된 태그 목록에 다녀온 뒤의 비율 유지, 다른 주요 목적지에 다녀온 뒤와 앱 재실행 후 기본 비율 초기화는 실제 화면 크기와 실행 경계를 함께 판정해야 한다. 현재 테스트 환경에서는 결정적으로 자동화할 수 없으며, 화면 크기와 실행 경계를 제어·관찰할 수 있는 통합 UI 테스트 환경이 갖춰지면 자동화한다.

다른 주요 목적지에 다녀온 뒤 상세 영역의 태그 추가에 새 무작위 컬러가 제시되는 것과, 배치를 떠나기 전 컬러가 그대로 남는 것은 화면에 칠해진 색으로만 드러나므로 픽셀 판정이 필요해 작성하지 않는다. 입력 칸의 컬러 값을 외부에서 관찰할 수 있는 수단이 갖춰지면 `TC-16865921-607f-467c-baee-6249fc6fd85a`와 `TC-98758bf8-de13-45c5-839b-312f29457d71`에 더한다.
