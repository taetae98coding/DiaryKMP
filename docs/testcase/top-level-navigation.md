# TopLevelNavigation 테스트 케이스

기준 스펙: [TopLevelNavigation 스펙](../spec/client/top-level-navigation.md)

## feature

### TC-e0513532-718e-4a9d-ba26-3a5637327cfb: 현재 목적지를 선택 상태로 표시한다

- 근거: `feature > 주요 목적지 이동`
- Given: 테스트 데이터의 주요 목적지 화면이 표시되어 있다.
- When: 사용자가 공통 내비게이션을 확인한다.
- Then: 현재 목적지만 선택 상태로 표시된다.
- 테스트 데이터: `메모`, `태그`, `캘린더`, `루틴`, `더보기`

### TC-e499dc91-528f-4d46-a621-c4f9867ec27a: 세부 화면이 단독으로 표시되면 내비게이션 영역을 숨긴다

- 근거: `feature > 공통 내비게이션 노출`
- Given: 주요 목적지 화면과 공통 내비게이션이 표시되어 있다.
- When: 사용자가 해당 목적지의 세부 화면이나 별도 흐름으로 이동해 해당 화면이 단독으로 표시된다.
- Then: 공통 내비게이션이 제공되지 않는다.

### TC-713b65da-f06b-4d3a-8cd4-4fe3d4ceacb3: 주요 목적지 복귀 후 내비게이션 영역을 다시 표시한다

- 근거: `feature > 공통 내비게이션 노출`
- Given: 주요 목적지에서 이어진 세부 화면이나 별도 흐름이 단독으로 표시되어 공통 내비게이션이 제공되지 않고 있다.
- When: 사용자가 이전 주요 목적지로 돌아온다.
- Then: 공통 내비게이션이 다시 제공되고 해당 주요 목적지가 선택 상태가 된다.

### TC-af129482-c473-4ec8-a9df-79c72a9de480: 주요 목적지 화면이 세부 화면과 함께 표시되면 내비게이션 영역을 계속 표시한다

- 근거: `feature > 공통 내비게이션 노출`, `domain > 내비게이션 노출 기준`
- Given: 주요 목적지 화면과 공통 내비게이션이 표시되어 있다.
- When: 사용자가 해당 목적지의 세부 화면을 주요 목적지 화면과 함께 사용한다.
- Then: 공통 내비게이션이 계속 제공된다.

### TC-ba5937cc-b46a-4b4a-91c7-be1019aba587: 주요 목적지 화면 위에 겹쳐 표시하는 화면을 열어도 내비게이션 영역을 계속 표시한다

- 근거: `feature > 공통 내비게이션 노출`, `domain > 내비게이션 노출 기준`
- Given: 테스트 데이터의 주요 목적지 화면과 공통 내비게이션이 표시되어 있다.
- When: 사용자가 그 화면을 유지한 채 위에 겹쳐 표시하는 화면을 연다.
- Then: 공통 내비게이션이 계속 제공되고 해당 주요 목적지가 선택 상태를 유지한다.
- 테스트 데이터: `메모`의 태그 필터, `캘린더`의 태그 필터

### TC-6d6ea720-76ed-46dc-bc47-d20dcc847db7: 목록 목적지를 다시 선택하면 목록의 첫 항목으로 돌아간다

- 근거: `feature > 현재 목적지 다시 선택`, `domain > 다시 선택으로 돌아가는 자리`
- Given: 테스트 데이터의 주요 목적지 화면만 표시되어 있고, 사용자가 목록을 아래로 이동해 첫 항목이 보이지 않는다.
- When: 사용자가 현재 목적지를 다시 선택한다.
- Then: 목록의 첫 항목이 다시 보이고, 목록에 놓인 항목과 그 순서는 바뀌지 않는다.
- 테스트 데이터: `메모`, `태그`, `루틴`
- 작성하지 않는 이유: `루틴`은 [RoutineHome 화면 스펙](../spec/client/routine-home.md)의 이번 범위에서 목록에 노출할 항목이 없어 되돌아갈 자리를 만들 수 없다. 루틴 목록이 항목을 노출하면 함께 작성한다. `메모`와 `태그`는 작성한다.

### TC-7c88772e-21af-439d-a716-0c9ff1c84cc9: `캘린더`를 다시 선택하면 오늘이 속한 달로 돌아간다

- 근거: `feature > 현재 목적지 다시 선택`, `domain > 다시 선택으로 돌아가는 자리`
- Given: `캘린더` 화면만 표시되어 있고 오늘이 속하지 않은 달을 보고 있다.
- When: 사용자가 `캘린더` 목적지를 다시 선택한다.
- Then: 오늘이 속한 달이 표시된다.

### TC-a90e5eda-5d5e-4516-be40-57c0db856883: `더보기`를 다시 선택해도 보던 자리를 유지한다

- 근거: `domain > 다시 선택으로 돌아가는 자리`
- Given: `더보기` 화면만 표시되어 있고, 사용자가 화면을 아래로 이동해 두었다.
- When: 사용자가 `더보기` 목적지를 다시 선택한다.
- Then: 사용자가 보던 자리가 그대로 유지된다.
- 작성하지 않는 이유: 보던 자리가 그대로인지는 공통 내비게이션의 다시 선택과 실제 `더보기` 화면을 한 화면에 함께 띄워야 판정할 수 있다. `더보기` 화면은 다시 선택을 전달받는 입력이 없어 기능 모듈의 화면 테스트에서는 다시 선택을 일으킬 수 없고, 앱 모듈에서는 `더보기` 화면이 쓰는 화면 상태를 대역으로 바꿀 수 없어 실제 화면을 띄우지 못한다. 다시 선택해도 목적지와 전환 이력이 유지되는 것은 TC-aeaa51e5-0fb1-4174-8c7e-d63a5d15cb3a가 확인한다. 앱 모듈에서 실제 `더보기` 화면을 제어한 자료로 띄울 수 있는 테스트 구성이 갖춰지면 작성한다.

### TC-da0880d8-c8a2-464e-9647-2892a77fcc97: 이어진 화면이 열려 있으면 닫고 돌아오기만 한다

- 근거: `feature > 현재 목적지 다시 선택`, `domain > 이어진 화면 판정`
- Given: `메모` 화면에서 사용자가 목록을 아래로 이동해 첫 항목이 보이지 않게 한 뒤 테스트 데이터의 화면을 열어 두었다.
- When: 사용자가 `메모` 목적지를 다시 선택한다.
- Then: 열어 둔 화면이 닫히고 `메모` 화면이 표시되며, 목록은 떠나기 전에 보던 자리를 유지한다.
- 테스트 데이터: `메모` 화면을 덮는 세부 화면, 사용자가 항목을 열어 표시한 상세, `메모` 화면 위에 겹쳐 표시하는 화면

### TC-68db6c25-ae6e-4f49-a1a3-bea2ee56c335: 이어진 화면을 닫은 뒤 다시 선택하면 첫 항목으로 돌아간다

- 근거: `feature > 현재 목적지 다시 선택`
- Given: `메모` 화면에서 목록을 아래로 이동한 뒤 세부 화면을 열었고, 한 번 다시 선택해 그 세부 화면이 닫힌 상태다.
- When: 사용자가 `메모` 목적지를 한 번 더 선택한다.
- Then: 목록의 첫 항목이 다시 보인다.

## domain

### TC-ff5a0d79-ad63-400e-9f38-1d0028dddd3b: 주요 목적지를 정해진 순서로 제공한다

- 근거: `domain > 주요 목적지와 순서`
- Given: 주요 목적지 화면이 표시되어 있다.
- When: 사용자가 공통 내비게이션의 목적지를 순서대로 확인한다.
- Then: `메모`, `태그`, `캘린더`, `루틴`, `더보기` 다섯 목적지만 해당 순서로 제공된다.

### TC-a1456939-ef2d-44a8-b187-db9eccce49e9: 앱을 기본 목적지에서 시작한다

- 근거: `domain > 기본 목적지와 전환 이력`
- Given: 저장된 화면 전환 상태가 없는 상태에서 앱을 실행한다.
- When: 첫 화면 표시가 완료된다.
- Then: `캘린더` 화면과 공통 내비게이션이 표시되고 `캘린더`가 선택 상태다.

### TC-03c304af-90f4-4d6e-98d3-9a7af49b28bf: 선택한 주요 목적지로 전환한다

- 근거: `feature > 주요 목적지 이동`
- Given: 테스트 데이터의 현재 목적지 화면이 표시되어 있다.
- When: 사용자가 다른 주요 목적지를 선택한다.
- Then: 선택한 목적지 화면이 표시되고 해당 목적지가 선택 상태가 된다.
- 테스트 데이터: 현재 목적지와 선택할 목적지가 서로 다른 모든 조합

### TC-aeaa51e5-0fb1-4174-8c7e-d63a5d15cb3a: 현재 목적지를 다시 선택해도 목적지와 전환 이력을 유지한다

- 근거: `feature > 주요 목적지 이동`, `domain > 기본 목적지와 전환 이력`
- Given: 테스트 데이터의 주요 목적지 화면만 표시되어 있다.
- When: 사용자가 현재 목적지를 다시 선택한다.
- Then: 같은 목적지 화면이 계속 표시되고 선택 상태와 주요 목적지 전환 이력이 변경되지 않는다.
- 테스트 데이터: `메모`, `태그`, `캘린더`, `루틴`, `더보기`

### TC-f6d1cbd9-d1de-4408-85d5-6fa8bab19721: 다른 주요 목적지로 전환해도 이전 목적지 이력을 누적하지 않는다

- 근거: `domain > 기본 목적지와 전환 이력`
- Given: 사용자가 기본 목적지에서 하나 이상의 다른 주요 목적지로 전환했다.
- When: 기본 목적지가 아닌 현재 목적지에서 뒤로가기를 사용한다.
- Then: 직전에 거쳤던 다른 목적지가 아니라 `캘린더` 화면으로 돌아간다.

### TC-f7946f1c-35ac-4069-a912-3fdd1b65f240: 기본 목적지를 선택하면 이전 주요 목적지 이력을 제거한다

- Given: `캘린더`가 아닌 주요 목적지 화면이 표시되어 있고 이전에 다른 주요 목적지를 거쳤다.
- When: 사용자가 `캘린더` 목적지를 선택한다.
- Then: `캘린더` 화면이 표시되고 뒤로가기를 사용해도 이전에 거친 주요 목적지가 다시 표시되지 않는다.

### TC-7e17dbec-9193-4e60-b99a-5db2f754b712: 화면 재생성 후 현재 목적지와 전환 이력을 복원한다

### TC-c7cf0275-7d03-4a99-ad22-fafc877cc5a8: 화면 재생성 후 목적지 위에 열려 있던 화면을 복원한다

### TC-e8c22e00-ba72-44a3-af1b-6bae10c5d492: 이미 돌아갈 자리를 보고 있으면 자리를 바꾸지 않는다

- 근거: `domain > 다시 선택으로 돌아가는 자리`

### TC-58d3fd49-552c-4ed0-9ba4-a9b8b6c061a3: 상세 자리에 기본으로 놓인 화면은 이어진 화면으로 보지 않는다

- Then: 상세 자리의 기본 화면이 그대로 남고 목록의 첫 항목이 다시 보인다.

### TC-348f39c9-be15-41d2-a3ca-c0647c788fe8: 이어진 화면을 닫은 뒤 뒤로가면 기본 목적지로 돌아간다

### TC-8c50c1af-cd06-4f6e-a670-f91971d0d918: 다시 선택해도 목록의 조회 조건을 바꾸지 않는다

### TC-94e59c44-53d0-477b-9aa8-e25a33419603: 다른 주요 목적지로 이동하면 떠난 목적지 위에 열어 둔 화면이 닫힌다
