# TopLevelNavigation 테스트 케이스

기준 스펙: [TopLevelNavigation 스펙](../spec/top-level-navigation.md)

## feature

### TC-TOP-LEVEL-NAVIGATION-FEATURE-002: 현재 목적지를 선택 상태로 표시한다

- 근거: `feature > 주요 목적지 이동`
- Given: 테스트 데이터의 주요 목적지 화면이 표시되어 있다.
- When: 사용자가 공통 내비게이션을 확인한다.
- Then: 현재 목적지만 선택 상태로 표시된다.
- 테스트 데이터: `메모`, `태그`, `캘린더`, `루틴`, `더보기`

### TC-TOP-LEVEL-NAVIGATION-FEATURE-004: 세부 화면이 단독으로 표시되면 내비게이션 영역을 숨긴다

- 근거: `feature > 공통 내비게이션 노출`
- Given: 주요 목적지 화면과 공통 내비게이션이 표시되어 있다.
- When: 사용자가 해당 목적지의 세부 화면이나 별도 흐름으로 이동해 해당 화면이 단독으로 표시된다.
- Then: 공통 내비게이션이 제공되지 않는다.

### TC-TOP-LEVEL-NAVIGATION-FEATURE-005: 주요 목적지 복귀 후 내비게이션 영역을 다시 표시한다

- 근거: `feature > 공통 내비게이션 노출`
- Given: 주요 목적지에서 이어진 세부 화면이나 별도 흐름이 단독으로 표시되어 공통 내비게이션이 제공되지 않고 있다.
- When: 사용자가 이전 주요 목적지로 돌아온다.
- Then: 공통 내비게이션이 다시 제공되고 해당 주요 목적지가 선택 상태가 된다.

### TC-TOP-LEVEL-NAVIGATION-FEATURE-007: 주요 목적지 화면이 세부 화면과 함께 표시되면 내비게이션 영역을 계속 표시한다

- 근거: `feature > 공통 내비게이션 노출`, `domain > 내비게이션 노출 기준`
- Given: 주요 목적지 화면과 공통 내비게이션이 표시되어 있다.
- When: 사용자가 해당 목적지의 세부 화면을 주요 목적지 화면과 함께 사용한다.
- Then: 공통 내비게이션이 계속 제공된다.

### TC-TOP-LEVEL-NAVIGATION-FEATURE-008: 주요 목적지 화면 위에 겹쳐 표시하는 화면을 열어도 내비게이션 영역을 계속 표시한다

- 근거: `feature > 공통 내비게이션 노출`, `domain > 내비게이션 노출 기준`
- Given: 테스트 데이터의 주요 목적지 화면과 공통 내비게이션이 표시되어 있다.
- When: 사용자가 그 화면을 유지한 채 위에 겹쳐 표시하는 화면을 연다.
- Then: 공통 내비게이션이 계속 제공되고 해당 주요 목적지가 선택 상태를 유지한다.
- 테스트 데이터: `메모`의 태그 필터, `캘린더`의 태그 필터

## domain

### TC-TOP-LEVEL-NAVIGATION-DOMAIN-001: 주요 목적지를 정해진 순서로 제공한다

- 근거: `domain > 주요 목적지와 순서`
- Given: 주요 목적지 화면이 표시되어 있다.
- When: 사용자가 공통 내비게이션의 목적지를 순서대로 확인한다.
- Then: `메모`, `태그`, `캘린더`, `루틴`, `더보기` 다섯 목적지만 해당 순서로 제공된다.

### TC-TOP-LEVEL-NAVIGATION-DOMAIN-002: 앱을 기본 목적지에서 시작한다

- 근거: `domain > 기본 목적지와 전환 이력`
- Given: 저장된 화면 전환 상태가 없는 상태에서 앱을 실행한다.
- When: 첫 화면 표시가 완료된다.
- Then: `캘린더` 화면과 공통 내비게이션이 표시되고 `캘린더`가 선택 상태다.

### TC-TOP-LEVEL-NAVIGATION-DOMAIN-003: 선택한 주요 목적지로 전환한다

- 근거: `feature > 주요 목적지 이동`
- Given: 테스트 데이터의 현재 목적지 화면이 표시되어 있다.
- When: 사용자가 다른 주요 목적지를 선택한다.
- Then: 선택한 목적지 화면이 표시되고 해당 목적지가 선택 상태가 된다.
- 테스트 데이터: 현재 목적지와 선택할 목적지가 서로 다른 모든 조합

### TC-TOP-LEVEL-NAVIGATION-DOMAIN-004: 현재 목적지를 다시 선택해도 화면을 유지한다

- 근거: `feature > 주요 목적지 이동`, `domain > 기본 목적지와 전환 이력`
- Given: 테스트 데이터의 주요 목적지 화면이 표시되어 있다.
- When: 사용자가 현재 목적지를 다시 선택한다.
- Then: 현재 화면과 전환 이력이 변경되지 않는다.
- 테스트 데이터: `메모`, `태그`, `캘린더`, `루틴`, `더보기`

### TC-TOP-LEVEL-NAVIGATION-DOMAIN-005: 다른 주요 목적지로 전환해도 이전 목적지 이력을 누적하지 않는다

- 근거: `domain > 기본 목적지와 전환 이력`
- Given: 사용자가 기본 목적지에서 하나 이상의 다른 주요 목적지로 전환했다.
- When: 기본 목적지가 아닌 현재 목적지에서 뒤로가기를 사용한다.
- Then: 직전에 거쳤던 다른 목적지가 아니라 `캘린더` 화면으로 돌아간다.

### TC-TOP-LEVEL-NAVIGATION-DOMAIN-008: 기본 목적지를 선택하면 이전 주요 목적지 이력을 제거한다

- 근거: `domain > 기본 목적지와 전환 이력`
- Given: `캘린더`가 아닌 주요 목적지 화면이 표시되어 있고 이전에 다른 주요 목적지를 거쳤다.
- When: 사용자가 `캘린더` 목적지를 선택한다.
- Then: `캘린더` 화면이 표시되고 뒤로가기를 사용해도 이전에 거친 주요 목적지가 다시 표시되지 않는다.

### TC-TOP-LEVEL-NAVIGATION-DOMAIN-009: 화면 재생성 후 현재 목적지와 전환 이력을 복원한다

- 근거: `domain > 기본 목적지와 전환 이력`
- Given: 사용자가 `캘린더`에서 다른 주요 목적지로 이동한 상태다.
- When: 시스템이 화면을 재생성한다.
- Then: 재생성 전의 주요 목적지가 계속 표시되고, 뒤로가기를 사용하면 `캘린더` 화면으로 돌아간다.
