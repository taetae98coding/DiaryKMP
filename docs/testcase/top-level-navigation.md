# TopLevelNavigation 테스트 케이스

기준 스펙: [TopLevelNavigation 스펙](../spec/client/top-level-navigation.md)

## feature

### TC-TOP-LEVEL-NAVIGATION-FEATURE-002: 현재 목적지를 선택 상태로 표시한다

- 근거: `feature > 주요 목적지 이동`
- Given: 테스트 데이터의 주요 목적지 화면이 표시되어 있다.
- When: 사용자가 공통 내비게이션을 확인한다.
- Then: 현재 목적지만 선택 상태로 표시된다.
- 테스트 데이터: `메모`, `태그`, `캘린더`, `루틴`, `더보기`

### TC-TOP-LEVEL-NAVIGATION-FEATURE-004: 세부 화면이 단독으로 표시되면 내비게이션 영역을 숨긴다

- 근거: `feature > 공통 내비게이션 노출`
- Given: 주요 목적지 화면과 공통 내비게이션이 표시되어 있다.
- When: 사용자가 해당 목적지의 세부 화면이나 별도 흐름으로 이동해 해당 화면이 단독으로 표시된다.
- Then: 공통 내비게이션이 제공되지 않는다.

### TC-TOP-LEVEL-NAVIGATION-FEATURE-005: 주요 목적지 복귀 후 내비게이션 영역을 다시 표시한다

- 근거: `feature > 공통 내비게이션 노출`
- Given: 주요 목적지에서 이어진 세부 화면이나 별도 흐름이 단독으로 표시되어 공통 내비게이션이 제공되지 않고 있다.
- When: 사용자가 이전 주요 목적지로 돌아온다.
- Then: 공통 내비게이션이 다시 제공되고 해당 주요 목적지가 선택 상태가 된다.

### TC-TOP-LEVEL-NAVIGATION-FEATURE-007: 주요 목적지 화면이 세부 화면과 함께 표시되면 내비게이션 영역을 계속 표시한다

- 근거: `feature > 공통 내비게이션 노출`, `domain > 내비게이션 노출 기준`
- Given: 주요 목적지 화면과 공통 내비게이션이 표시되어 있다.
- When: 사용자가 해당 목적지의 세부 화면을 주요 목적지 화면과 함께 사용한다.
- Then: 공통 내비게이션이 계속 제공된다.

### TC-TOP-LEVEL-NAVIGATION-FEATURE-008: 주요 목적지 화면 위에 겹쳐 표시하는 화면을 열어도 내비게이션 영역을 계속 표시한다

- 근거: `feature > 공통 내비게이션 노출`, `domain > 내비게이션 노출 기준`
- Given: 테스트 데이터의 주요 목적지 화면과 공통 내비게이션이 표시되어 있다.
- When: 사용자가 그 화면을 유지한 채 위에 겹쳐 표시하는 화면을 연다.
- Then: 공통 내비게이션이 계속 제공되고 해당 주요 목적지가 선택 상태를 유지한다.
- 테스트 데이터: `메모`의 태그 필터, `캘린더`의 태그 필터

### TC-TOP-LEVEL-NAVIGATION-FEATURE-009: 목록 목적지를 다시 선택하면 목록의 첫 항목으로 돌아간다

- 근거: `feature > 현재 목적지 다시 선택`, `domain > 다시 선택으로 돌아가는 자리`
- Given: 테스트 데이터의 주요 목적지 화면만 표시되어 있고, 사용자가 목록을 아래로 이동해 첫 항목이 보이지 않는다.
- When: 사용자가 현재 목적지를 다시 선택한다.
- Then: 목록의 첫 항목이 다시 보이고, 목록에 놓인 항목과 그 순서는 바뀌지 않는다.
- 테스트 데이터: `메모`, `태그`, `루틴`
- 작성하지 않는 이유: `루틴`은 [RoutineHome 화면 스펙](../spec/client/routine-home.md)의 이번 범위에서 목록에 노출할 항목이 없어 되돌아갈 자리를 만들 수 없다. 루틴 목록이 항목을 노출하면 함께 작성한다. `메모`와 `태그`는 작성한다.

### TC-TOP-LEVEL-NAVIGATION-FEATURE-010: `캘린더`를 다시 선택하면 오늘이 속한 달로 돌아간다

- 근거: `feature > 현재 목적지 다시 선택`, `domain > 다시 선택으로 돌아가는 자리`
- Given: `캘린더` 화면만 표시되어 있고 오늘이 속하지 않은 달을 보고 있다.
- When: 사용자가 `캘린더` 목적지를 다시 선택한다.
- Then: 오늘이 속한 달이 표시된다.

### TC-TOP-LEVEL-NAVIGATION-FEATURE-011: `더보기`를 다시 선택해도 보던 자리를 유지한다

- 근거: `domain > 다시 선택으로 돌아가는 자리`
- Given: `더보기` 화면만 표시되어 있고, 사용자가 화면을 아래로 이동해 두었다.
- When: 사용자가 `더보기` 목적지를 다시 선택한다.
- Then: 사용자가 보던 자리가 그대로 유지된다.
- 작성하지 않는 이유: 보던 자리가 그대로인지는 공통 내비게이션과 `더보기` 화면을 한 화면에 함께 띄우고, 다시 선택하기 전과 후에 `더보기` 화면이 보여 주는 자리를 비교해야 판정할 수 있다. 현재 자동화 환경은 공통 내비게이션의 목적지 전환과 `더보기` 화면을 따로 띄울 뿐 둘을 함께 띄워 조작하지 못한다. 다시 선택해도 목적지와 전환 이력이 유지되는 것은 TC-TOP-LEVEL-NAVIGATION-DOMAIN-004가 확인한다. 공통 내비게이션과 각 목적지 화면을 실제 구성 그대로 함께 띄워 조작할 수 있는 앱 수준 화면 자동화 환경이 갖춰지면 작성한다.

### TC-TOP-LEVEL-NAVIGATION-FEATURE-012: 이어진 화면이 열려 있으면 닫고 돌아오기만 한다

- 근거: `feature > 현재 목적지 다시 선택`, `domain > 이어진 화면 판정`
- Given: `메모` 화면에서 사용자가 목록을 아래로 이동해 첫 항목이 보이지 않게 한 뒤 테스트 데이터의 화면을 열어 두었다.
- When: 사용자가 `메모` 목적지를 다시 선택한다.
- Then: 열어 둔 화면이 닫히고 `메모` 화면이 표시되며, 목록은 떠나기 전에 보던 자리를 유지한다.
- 테스트 데이터: `메모` 화면을 덮는 세부 화면, 사용자가 항목을 열어 표시한 상세, `메모` 화면 위에 겹쳐 표시하는 화면

### TC-TOP-LEVEL-NAVIGATION-FEATURE-013: 이어진 화면을 닫은 뒤 다시 선택하면 첫 항목으로 돌아간다

- 근거: `feature > 현재 목적지 다시 선택`
- Given: `메모` 화면에서 목록을 아래로 이동한 뒤 세부 화면을 열었고, 한 번 다시 선택해 그 세부 화면이 닫힌 상태다.
- When: 사용자가 `메모` 목적지를 한 번 더 선택한다.
- Then: 목록의 첫 항목이 다시 보인다.

## domain

### TC-TOP-LEVEL-NAVIGATION-DOMAIN-001: 주요 목적지를 정해진 순서로 제공한다

- 근거: `domain > 주요 목적지와 순서`
- Given: 주요 목적지 화면이 표시되어 있다.
- When: 사용자가 공통 내비게이션의 목적지를 순서대로 확인한다.
- Then: `메모`, `태그`, `캘린더`, `루틴`, `더보기` 다섯 목적지만 해당 순서로 제공된다.

### TC-TOP-LEVEL-NAVIGATION-DOMAIN-002: 앱을 기본 목적지에서 시작한다

- 근거: `domain > 기본 목적지와 전환 이력`
- Given: 저장된 화면 전환 상태가 없는 상태에서 앱을 실행한다.
- When: 첫 화면 표시가 완료된다.
- Then: `캘린더` 화면과 공통 내비게이션이 표시되고 `캘린더`가 선택 상태다.

### TC-TOP-LEVEL-NAVIGATION-DOMAIN-003: 선택한 주요 목적지로 전환한다

- 근거: `feature > 주요 목적지 이동`
- Given: 테스트 데이터의 현재 목적지 화면이 표시되어 있다.
- When: 사용자가 다른 주요 목적지를 선택한다.
- Then: 선택한 목적지 화면이 표시되고 해당 목적지가 선택 상태가 된다.
- 테스트 데이터: 현재 목적지와 선택할 목적지가 서로 다른 모든 조합

### TC-TOP-LEVEL-NAVIGATION-DOMAIN-004: 현재 목적지를 다시 선택해도 목적지와 전환 이력을 유지한다

- 근거: `feature > 주요 목적지 이동`, `domain > 기본 목적지와 전환 이력`
- Given: 테스트 데이터의 주요 목적지 화면만 표시되어 있다.
- When: 사용자가 현재 목적지를 다시 선택한다.
- Then: 같은 목적지 화면이 계속 표시되고 선택 상태와 주요 목적지 전환 이력이 변경되지 않는다.
- 테스트 데이터: `메모`, `태그`, `캘린더`, `루틴`, `더보기`

### TC-TOP-LEVEL-NAVIGATION-DOMAIN-005: 다른 주요 목적지로 전환해도 이전 목적지 이력을 누적하지 않는다

- 근거: `domain > 기본 목적지와 전환 이력`
- Given: 사용자가 기본 목적지에서 하나 이상의 다른 주요 목적지로 전환했다.
- When: 기본 목적지가 아닌 현재 목적지에서 뒤로가기를 사용한다.
- Then: 직전에 거쳤던 다른 목적지가 아니라 `캘린더` 화면으로 돌아간다.

### TC-TOP-LEVEL-NAVIGATION-DOMAIN-008: 기본 목적지를 선택하면 이전 주요 목적지 이력을 제거한다

- 근거: `domain > 기본 목적지와 전환 이력`
- Given: `캘린더`가 아닌 주요 목적지 화면이 표시되어 있고 이전에 다른 주요 목적지를 거쳤다.
- When: 사용자가 `캘린더` 목적지를 선택한다.
- Then: `캘린더` 화면이 표시되고 뒤로가기를 사용해도 이전에 거친 주요 목적지가 다시 표시되지 않는다.

### TC-TOP-LEVEL-NAVIGATION-DOMAIN-009: 화면 재생성 후 현재 목적지와 전환 이력을 복원한다

- 근거: `domain > 기본 목적지와 전환 이력`
- Given: 사용자가 `캘린더`에서 다른 주요 목적지로 이동한 상태다.
- When: 시스템이 화면을 재생성한다.
- Then: 재생성 전의 주요 목적지가 계속 표시되고, 뒤로가기를 사용하면 `캘린더` 화면으로 돌아간다.

### TC-TOP-LEVEL-NAVIGATION-DOMAIN-010: 이미 돌아갈 자리를 보고 있으면 자리를 바꾸지 않는다

- 근거: `domain > 다시 선택으로 돌아가는 자리`
- Given: 테스트 데이터의 주요 목적지 화면만 표시되어 있고 이미 돌아갈 자리를 보고 있다.
- When: 사용자가 현재 목적지를 다시 선택한다.
- Then: 보던 자리가 그대로 유지된다.
- 테스트 데이터: 첫 항목이 보이는 `메모`·`태그`·`루틴` 목록, 오늘이 속한 달을 보고 있는 `캘린더`

### TC-TOP-LEVEL-NAVIGATION-DOMAIN-011: 상세 자리에 기본으로 놓인 화면은 이어진 화면으로 보지 않는다

- 근거: `domain > 이어진 화면 판정`
- Given: `메모` 목록과 상세를 함께 표시하는 배치에서 사용자가 아직 아무 항목도 열지 않아 상세 자리에 기본 화면이 놓여 있고, 목록은 첫 항목이 보이지 않는 자리에 있다.
- When: 사용자가 `메모` 목적지를 다시 선택한다.
- Then: 상세 자리의 기본 화면이 그대로 남고 목록의 첫 항목이 다시 보인다.

### TC-TOP-LEVEL-NAVIGATION-DOMAIN-012: 이어진 화면을 닫은 뒤 뒤로가면 기본 목적지로 돌아간다

- 근거: `domain > 기본 목적지와 전환 이력`
- Given: `캘린더`가 아닌 주요 목적지에서 세부 화면을 열어 둔 상태다.
- When: 사용자가 그 목적지를 다시 선택해 세부 화면을 닫은 뒤 뒤로가기를 사용한다.
- Then: `캘린더` 화면으로 돌아간다.

### TC-TOP-LEVEL-NAVIGATION-DOMAIN-013: 다시 선택해도 목록의 조회 조건을 바꾸지 않는다

- 근거: `feature > 현재 목적지 다시 선택`, `domain > 다시 선택으로 돌아가는 자리`
- Given: `메모` 화면만 표시되어 있고, 사용자가 정렬과 필터를 바꿔 둔 뒤 목록을 아래로 이동해 첫 항목이 보이지 않는다.
- When: 사용자가 `메모` 목적지를 다시 선택한다.
- Then: 선택해 둔 정렬과 필터가 그대로 유지되고 목록에 놓인 항목과 그 순서도 그대로이며, 목록의 첫 항목이 다시 보인다.

### TC-TOP-LEVEL-NAVIGATION-DOMAIN-014: 다른 주요 목적지로 이동하면 떠난 목적지 위에 열어 둔 화면이 닫힌다

- 근거: `domain > 목적지 이동과 화면 상태`, `domain > 기본 목적지와 전환 이력`
- Given: 테스트 데이터의 목적지 위에 테스트 데이터의 화면이 열려 있다.
- When: 사용자가 공통 내비게이션에서 다른 주요 목적지로 이동했다가 떠났던 목적지를 다시 선택한다.
- Then: 떠났던 목적지 화면만 표시되고 열어 두었던 화면은 다시 나타나지 않는다. 그 목적지에서 뒤로가면 `캘린더`로 돌아가고, `캘린더`에서는 더 돌아갈 화면이 없다.
- 테스트 데이터:

| 떠난 목적지 | 열어 둔 화면 |
| --- | --- |
| `메모` | 메모 상세, 메모 추가, 메모 필터 |
| `태그` | 태그 상세, 태그 추가, 태그 필터 |
| `캘린더` | 메모 상세, 캘린더 필터 |
| `루틴` | 루틴 추가 |
| `더보기` | 로그인, 설정 |

### TC-TOP-LEVEL-NAVIGATION-DOMAIN-015: 캘린더가 아닌 목적지에 다녀오면 처음 들어온 것처럼 시작한다

- 근거: `domain > 목적지 이동과 화면 상태`
- Given: 테스트 데이터의 목적지에서 사용자가 정렬과 필터를 바꿔 두고 목록을 아래로 이동해 첫 항목이 보이지 않는다.
- When: 사용자가 공통 내비게이션에서 다른 주요 목적지로 이동했다가 그 목적지를 다시 선택한다.
- Then: 목록의 첫 항목부터 보이고, 정렬은 그 목록의 처음 정렬로 돌아가며, 필터는 바꿔 둔 선택이 그대로 적용되어 있다.
