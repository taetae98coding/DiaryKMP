# MusicDetail 테스트 케이스

기준 스펙: [MusicDetail 화면 스펙](../spec/music-detail.md)

이 문서에서 `feature > 진입할 때의 입력 초점`, `domain > 요청 제한`, `data > 대상 조회` 절은 [항목 상세 화면 공통 스펙](../spec/entity-detail.md)이 소유한다. 나머지 케이스의 절은 기준 스펙이 소유한다.

PlaylistHome에서 곡을 선택해 MusicDetail로 이동하는 케이스는 [PlaylistHome 테스트 케이스](./playlist-home.md)에서, 곡 목록과 함께 표시할 때의 케이스는 [Playlist 목록·상세 배치 테스트 케이스](./playlist-list-detail.md)에서, 링크로 영상 정보를 조회하는 공통 규칙의 케이스는 [MusicAdd 테스트 케이스](./music-add.md)에서, 수정하거나 삭제한 곡을 서버와 맞추는 흐름의 케이스는 [데이터 동기화 테스트 케이스](./data-sync.md)에서 다룬다. 이 화면에는 태그 입력이 없으므로 태그 연결 케이스는 두지 않는다.

## feature

### TC-MUSIC-DETAIL-FEATURE-001: 조회에 성공하면 저장된 내용을 채운다

- 근거: `feature > 진입과 내용`
- Given: 제목, 가수와 YouTube 영상 링크가 저장된 곡이 조회되도록 설정되어 있다.
- When: MusicDetail 화면이 표시된다.
- Then: 제목, 가수, 링크 입력에 저장된 값이 채워지고 상단 바 제목에 저장된 제목이 표시된다.

### TC-MUSIC-DETAIL-FEATURE-002: 조회가 끝나기 전에는 조회 중 상태를 유지한다

- 근거: `feature > 조회 상태`
- Given: 곡 조회가 완료되지 않고 진행 중인 상태로 설정되어 있다.
- When: MusicDetail 화면을 확인한다.
- Then: 조회 중 상태가 표시되고 내용 수정, 다시 불러오기, 외부로 열기, 삭제를 실행할 수 없다.

### TC-MUSIC-DETAIL-FEATURE-003: 곡을 조회할 수 없으면 조회 중 상태를 유지한다

- 근거: `feature > 조회 상태`
- Given: 대상 곡 조회가 결과를 돌려주지 않거나 실패하도록 설정되어 있다.
- When: MusicDetail 화면을 확인한다.
- Then: 조회 중 상태가 유지되고 오류 안내가 표시되지 않는다.

### TC-MUSIC-DETAIL-FEATURE-004: 화면에 처음 진입하면 어느 입력에도 초점을 두지 않는다

- 근거: `feature > 진입할 때의 입력 초점`
- Given: 곡 조회에 성공한다.
- When: MusicDetail 화면이 처음 표시된다.
- Then: 제목, 가수, 링크 어느 입력에도 입력 초점이 없다.

### TC-MUSIC-DETAIL-FEATURE-005: 제목, 가수와 링크를 바꿀 수 있다

- 근거: `feature > 내용 수정`
- Given: 저장된 곡이 표시된 MusicDetail 화면이 표시되어 있다.
- When: 사용자가 제목, 가수와 링크를 바꾼다.
- Then: 바꾼 제목, 가수와 링크가 화면에 그대로 표시된다.

### TC-MUSIC-DETAIL-FEATURE-006: 입력이 저장 내용과 다를 때만 수정 동작을 제공한다

- 근거: `feature > 내용 수정`
- Given: 저장된 곡이 표시된 MusicDetail 화면이 테스트 데이터의 입력 상태다.
- When: 사용자가 화면에서 실행할 수 있는 동작을 확인한다.
- Then: 테스트 데이터의 결과대로 수정 동작이 제공되거나 제공되지 않는다.
- 테스트 데이터:

| 입력 상태 | 수정 동작 |
| --- | --- |
| 저장된 내용 그대로임 | 제공되지 않음 |
| 제목을 바꿈 | 제공됨 |
| 가수를 바꿈 | 제공됨 |
| 링크를 바꿈 | 제공됨 |
| 제목을 비움 | 제공됨 |
| 가수를 비움 | 제공됨 |
| 링크를 비움 | 제공됨 |

### TC-MUSIC-DETAIL-FEATURE-007: 수정에 성공하면 화면과 입력을 유지하고 성공 피드백을 제공한다

- 근거: `feature > 내용 수정`
- Given: 수정이 성공하도록 설정되어 있고 입력을 저장 내용과 다르게 바꾼 상태다.
- When: 사용자가 수정을 실행한다.
- Then: MusicDetail 화면이 유지되고 입력 내용이 비워지지 않으며 곡이 수정되었다는 성공 피드백이 제공된다.

### TC-MUSIC-DETAIL-FEATURE-008: 수정을 처리하는 동안 진행 상태를 표시한다

- 근거: `feature > 내용 수정`
- Given: 수정 처리가 완료되지 않고 진행 중인 상태로 설정되어 있고 입력을 저장 내용과 다르게 바꾼 상태다.
- When: 사용자가 수정을 실행한 뒤 화면을 확인한다.
- Then: 수정 처리가 끝날 때까지 진행 상태가 표시된다.

### TC-MUSIC-DETAIL-FEATURE-009: 수정에 실패하면 화면과 입력을 유지한다

- 근거: `feature > 내용 수정`
- Given: 수정이 실패하도록 설정되어 있고 입력을 저장 내용과 다르게 바꾼 상태다.
- When: 사용자가 수정을 실행한다.
- Then: MusicDetail 화면과 입력 내용이 그대로 유지되고 진행 상태만 해제되어 다시 수정할 수 있다.

### TC-MUSIC-DETAIL-FEATURE-010: 링크가 YouTube 영상 링크가 아니면 수정하지 않고 알린다

- 근거: `feature > 링크 형식 불만족`
- Given: 저장된 곡이 표시된 MusicDetail 화면에 YouTube 주소가 아닌 링크가 입력되어 있다.
- When: 사용자가 수정을 실행한다.
- Then: 곡이 수정되지 않고 YouTube 영상 링크가 필요하다는 피드백이 제공된다.

### TC-MUSIC-DETAIL-FEATURE-011: 링크 형식이 맞지 않아도 입력은 유지하고 링크로 초점을 옮긴다

- 근거: `feature > 링크 형식 불만족`
- Given: 저장된 곡이 표시된 MusicDetail 화면에 YouTube 주소가 아닌 링크와 바꾼 제목과 가수가 입력되어 있다.
- When: 사용자가 수정을 실행한다.
- Then: 제목, 가수와 링크가 바뀌지 않고 입력 초점이 링크 입력으로 옮겨진다.

### TC-MUSIC-DETAIL-FEATURE-012: 다시 불러오기에 성공하면 제목과 가수를 덮어쓴다

- 근거: `feature > 다시 불러오기`
- Given: 저장된 제목과 가수와 YouTube 영상 링크가 채워진 MusicDetail 화면이 표시되어 있고, 영상 정보 조회가 다른 영상 제목과 채널 이름을 돌려주도록 설정되어 있다.
- When: 사용자가 불러오기를 실행한다.
- Then: 제목이 영상 제목으로, 가수가 채널 이름으로 바뀌고 링크 입력과 썸네일 미리보기는 바뀌지 않는다.

### TC-MUSIC-DETAIL-FEATURE-013: 다시 불러오기만으로는 저장된 곡이 바뀌지 않는다

- 근거: `feature > 다시 불러오기`
- Given: 저장된 곡이 표시된 MusicDetail 화면이 표시되어 있고 영상 정보 조회가 성공하도록 설정되어 있다.
- When: 사용자가 불러오기를 실행하고 수정을 실행하지 않는다.
- Then: 저장된 곡의 제목, 가수와 링크가 바뀌지 않는다.

### TC-MUSIC-DETAIL-FEATURE-028: 진입하면 저장된 링크에서 정해진 썸네일을 표시한다

- 근거: `feature > 썸네일 확인`
- Given: 테스트 데이터의 링크가 저장된 곡이 조회되도록 설정되어 있다.
- When: MusicDetail 화면이 표시된다.
- Then: 테스트 데이터의 결과대로 표시된다.
- 테스트 데이터:

| 저장된 링크 | 결과 |
| --- | --- |
| YouTube 영상 링크 | 썸네일 미리보기가 표시된다 |
| 비어 있음 | 썸네일 미리보기가 표시되지 않는다 |
| YouTube 채널 주소 | 썸네일 미리보기가 표시되지 않는다 |

### TC-MUSIC-DETAIL-FEATURE-029: 링크 입력을 바꾸면 수정을 반영하지 않아도 썸네일 미리보기가 바뀐다

- 근거: `feature > 썸네일 확인`
- Given: 테스트 데이터의 저장 상태인 곡이 표시된 MusicDetail 화면이 표시되어 있다.
- When: 사용자가 테스트 데이터의 조작을 하고 수정을 실행하지 않는다.
- Then: 테스트 데이터의 결과대로 미리보기가 바뀐다.
- 테스트 데이터:

| 저장 상태 | 조작 | 결과 |
| --- | --- | --- |
| YouTube 영상 링크가 저장됨 | 링크를 모두 지운다 | 미리보기가 사라진다 |
| YouTube 영상 링크가 저장됨 | 다른 영상의 링크로 바꾼다 | 미리보기가 바꾼 링크의 썸네일로 바뀐다 |
| 링크가 비어 있음 | YouTube 영상 링크를 입력한다 | 미리보기가 나타난다 |

### TC-MUSIC-DETAIL-FEATURE-015: 썸네일만 바꾸거나 지우는 조작을 두지 않는다

- 근거: `feature > 썸네일 확인`
- Given: YouTube 영상 링크가 저장되어 썸네일 미리보기가 표시된 MusicDetail 화면이 표시되어 있다.
- When: 사용자가 썸네일 미리보기를 확인한다.
- Then: 썸네일 미리보기에 선택할 수 있는 동작이 없다.

### TC-MUSIC-DETAIL-FEATURE-016: 외부로 열기를 실행하면 저장된 링크를 앱 밖에서 연다

- 근거: `feature > 외부로 열기`
- Given: 링크가 저장된 곡이 표시된 MusicDetail 화면이 표시되어 있다.
- When: 사용자가 외부로 열기를 실행한다.
- Then: 저장된 링크를 앱 밖에서 여는 동작이 한 번 실행된다.

### TC-MUSIC-DETAIL-FEATURE-017: 외부로 열어도 화면 상태를 유지한다

- 근거: `feature > 외부로 열기`
- Given: 제목, 가수와 링크를 바꾼 MusicDetail 화면이 표시되어 있다.
- When: 사용자가 외부로 열기를 실행한다.
- Then: 입력 중이던 제목, 가수와 링크가 그대로 유지된다.

### TC-MUSIC-DETAIL-FEATURE-018: 저장된 링크가 비어 있으면 외부로 열기를 제공하지 않는다

- 근거: `feature > 외부로 열기`
- Given: 링크가 비어 있는 곡이 조회되도록 설정되어 있다.
- When: 사용자가 MusicDetail 화면에서 실행할 수 있는 동작을 확인한다.
- Then: 외부로 열기 동작이 제공되지 않는다.

### TC-MUSIC-DETAIL-FEATURE-019: 삭제를 실행하면 되묻지 않고 곡을 삭제한다

- 근거: `feature > 삭제`
- Given: 삭제가 성공하도록 설정되어 있고 저장된 곡이 표시된 MusicDetail 화면이 표시되어 있다.
- When: 사용자가 삭제를 실행한다.
- Then: 확인을 되묻지 않고 그 곡의 삭제가 한 번 요청된다.

### TC-MUSIC-DETAIL-FEATURE-020: 삭제를 처리하는 동안 진행 상태를 표시한다

- 근거: `feature > 삭제`
- Given: 삭제 처리가 완료되지 않고 진행 중인 상태로 설정되어 있다.
- When: 사용자가 삭제를 실행한 뒤 화면을 확인한다.
- Then: 삭제 처리가 끝날 때까지 진행 상태가 표시되고, 그동안에도 입력과 다시 불러오기와 외부로 열기와 수정을 실행할 수 있다.

### TC-MUSIC-DETAIL-FEATURE-021: 삭제에 성공하면 화면을 떠난다

- 근거: `feature > 삭제`
- Given: 삭제가 성공하도록 설정되어 있고 MusicDetail 화면이 단독으로 표시되어 있다.
- When: 사용자가 삭제를 실행한다.
- Then: MusicDetail 화면에 진입하기 전 화면으로 돌아간다.

### TC-MUSIC-DETAIL-FEATURE-022: 삭제에 실패하면 화면에 머무른다

- 근거: `feature > 삭제`
- Given: 삭제가 실패하도록 설정되어 있다.
- When: 사용자가 삭제를 실행한다.
- Then: MusicDetail 화면에 머무르고 진행 상태만 해제되어 다시 삭제할 수 있다.

### TC-MUSIC-DETAIL-FEATURE-023: 저장 내용이 바뀌면 화면 제목만 갱신한다

- 근거: `feature > 외부 변경`
- Given: 제목, 가수와 링크를 바꾼 MusicDetail 화면이 표시되어 있다.
- When: 같은 곡의 저장된 제목이 다른 경로에서 바뀐다.
- Then: 상단 바 제목이 최신 저장 제목으로 바뀌고 입력 중이던 제목, 가수, 링크는 바뀌지 않는다.

### TC-MUSIC-DETAIL-FEATURE-024: 대상 곡이 삭제 상태가 되어도 내용 표시 상태를 유지한다

- 근거: `feature > 외부 변경`
- Given: 제목, 가수와 링크를 바꾼 MusicDetail 화면이 표시되어 있다.
- When: 같은 곡이 다른 경로에서 삭제 상태가 된다.
- Then: 내용 표시 상태와 입력 내용이 유지되고 수정과 다시 불러오기와 외부로 열기와 삭제를 그대로 실행할 수 있다.

### TC-MUSIC-DETAIL-FEATURE-025: 화면이 재생성되어도 입력 중이던 내용을 유지한다

- 근거: `feature > 진행 상태 유지`
- Given: 제목과 가수를 바꾸고 링크를 다른 YouTube 영상 링크로 바꾼 MusicDetail 화면이 표시되어 있다.
- When: 화면이 회전하거나 시스템에 의해 재생성된다.
- Then: 재생성 전의 제목, 가수, 링크가 그대로 표시되고 바꾼 링크의 썸네일 미리보기가 표시되며 불러오기를 다시 실행하지 않는다.

### TC-MUSIC-DETAIL-FEATURE-026: 다시 진입하면 저장된 내용으로 시작한다

- 근거: `feature > 진행 상태 유지`
- Given: MusicDetail 화면에서 제목, 가수와 링크를 바꾼 뒤 수정을 실행하지 않고 화면을 떠났다.
- When: 사용자가 같은 곡의 MusicDetail 화면에 다시 진입한다.
- Then: 입력에 저장된 제목, 가수, 링크가 채워지고 바꾸던 내용이 복원되지 않는다.

### TC-MUSIC-DETAIL-FEATURE-027: 뒤로가면 이전 화면으로 돌아가고 수정 내용은 저장되지 않는다

- 근거: `feature > 뒤로가기`
- Given: 제목, 가수와 링크를 바꾼 MusicDetail 화면이 단독으로 표시되어 있다.
- When: 사용자가 뒤로가기를 실행한다.
- Then: MusicDetail 화면에 진입하기 전 화면으로 돌아가고 저장된 곡의 내용이 바뀌지 않는다.

## domain

### TC-MUSIC-DETAIL-DOMAIN-001: 삭제 상태인 곡도 상세 대상으로 조회한다

- 근거: `domain > 상세 대상과 내용 표시`
