# SettingHoliday 화면 스펙

이 문서는 사용자가 설정 화면의 `공휴일` 항목에서 진입해 공휴일을 다룰 국가와 캘린더에 표시할 공휴일을 고르는 SettingHoliday 화면의 내용과 행동을 다룬다. 설정 항목의 표시와 선택은 [SettingHome 화면 스펙](./setting-home.md)에서, 설정 목록과 함께 사용할 때의 선택·뒤로가기 정책은 [Setting 목록·상세 배치 스펙](./setting-list-detail.md)에서, 세부 화면에서의 공통 내비게이션 노출 규칙은 [TopLevelNavigation 스펙](./top-level-navigation.md)에서 다룬다. 공휴일 자체의 동기화와 저장 규칙은 [공휴일 동기화 스펙](./holiday-fetch.md)과 [공휴일 로컬 캐시 스펙](./holiday-database.md)을, 선택한 국가 설정의 적용과 저장 규칙은 [공휴일 국가 설정 스펙](./holiday-country.md)을, 노출 설정의 적용과 저장 규칙은 [공휴일 노출 설정 스펙](./holiday-visibility.md)을 따른다.

디자인: [SettingHoliday 화면 디자인](../design/setting-holiday.md)

기기에 저장된 전체 공휴일과 변경한 국가 설정·노출 설정은 기기의 로컬 저장 영역에서 불러오고 보관한다.

## feature

### 진입과 이동

사용자는 설정 화면의 `공휴일` 항목을 선택해 SettingHoliday 화면으로 이동한다.

SettingHoliday 화면은 설정 목록과 함께 표시되거나 단독으로 표시될 수 있다. 두 상태 모두 공통 내비게이션을 제공하지 않으며, 표시 관계는 [Setting 목록·상세 배치 스펙](./setting-list-detail.md)을 따른다.

### 국가 선택

목록 맨 위에는 `기기값`, `한국`, `미국` 세 국가 선택지를 이 순서로 제공한다. 사용자는 각 선택지의 선택 상태를 확인하고 하나씩 고르거나 해제할 수 있으며, 여러 선택지를 함께 고를 수도 있다. 선택지의 의미와 기본값은 [공휴일 국가 설정 스펙](./holiday-country.md)을 따른다.

`기기값` 선택지에는 기기 지역에 따라 적용되는 국가를 함께 보여 준다. 기기 지역이 한국·미국이 아니면 지원하지 않는 지역이라 적용되는 국가가 없음을 보여 준다.

변경 내용은 별도 확인 없이 바로 저장하며, 바뀐 적용 국가에 맞게 아래 공휴일 목록이 바로 다시 구성된다.

국가 선택지는 검색어가 비어 있을 때만 제공한다. 검색은 공휴일을 찾는 수단이므로 검색어가 있는 동안에는 공휴일 항목만 목록에 남긴다.

### 공휴일 선택

적용 국가의 기기에 저장된 모든 연도의 공휴일은 이름 key별로 하나의 선택 항목이 된다. 공백만 다른 이름은 같은 key로 합치며, 항목 구성과 순서는 `domain > 공휴일 항목 구성`을 따른다.

사용자는 각 항목의 선택 상태와 쉬는 날 여부를 확인하고 선택 상태를 바꿀 수 있다.

선택한 항목은 캘린더에 표시하고 선택 해제한 항목은 숨긴다. 변경 내용은 별도 확인 없이 바로 저장한다.

### 검색

화면 상단에는 검색어 입력이 항상 있다. 사용자는 검색어를 입력해 공휴일 목록을 필터링할 수 있고, 검색어를 입력하면 일치하는 항목만 목록에 남는다. 일치 기준은 `domain > 검색 일치`를 따른다.

사용자는 검색어 입력과 필터링된 목록을 언제나 함께 확인한다. 검색을 시작하거나 끝내는 별도의 상태 전이는 없으며, 목록의 필터링 여부는 검색어가 비어 있는지로만 정해진다.

이 화면의 기본 흐름은 목록에서 항목을 고르는 것이고 검색은 보조 수단이므로, 진입할 때는 검색어 입력에 입력 초점을 두지 않는다.

필터링된 목록에서도 각 항목의 선택 상태를 그대로 확인하고 바꿀 수 있으며, 변경 결과는 `공휴일 선택`과 동일하게 바로 저장된다.

일치하는 항목이 없으면 결과가 없음을 알리는 빈 상태를 표시한다. 사용자는 빈 상태에서도 검색어를 수정하거나 지울 수 있다.

사용자가 검색어를 모두 지우면 전체 목록으로 돌아간다. 검색어의 유지 범위는 `domain > 검색어 유지`를 따른다.

### 일괄 선택

사용자는 현재 목록의 모든 항목을 선택하거나 모두 선택 해제할 수 있고, 쉬는 날인 항목만 선택할 수도 있다.

세 동작은 목록과 겹쳐 떠 있는 하나의 동작 버튼에 모아 둔다. 사용자가 동작 버튼을 선택하면 세 동작이 펼쳐지고, 그중 하나를 고르면 그 동작을 실행하고 다시 접는다. 사용자는 아무 동작도 고르지 않고 동작 버튼을 다시 선택해 접을 수도 있다. 펼침 여부는 화면 표시 상태일 뿐이므로 기기에 저장하지 않는다.

동작 버튼은 목록을 스크롤하는 동안에도 같은 자리에 남아 계속 사용할 수 있다.

일괄 선택은 검색어가 비어 있을 때만 제공한다. 검색어가 있는 동안에는 동작 버튼을 제공하지 않으며, 검색어를 모두 지우면 다시 제공한다. 검색어가 있는 동안 동작 버튼이 사라지면 펼쳐져 있던 동작도 함께 사라진다.

일괄 선택 결과는 실행 시점의 적용 국가에 대해 기기에 저장된 전체 공휴일을 기준으로 계산하고 기존 숨김 key 집합 전체를 교체한다. 따라서 현재 공휴일에 없는 기존 숨김 key도 제거된다. 적용 국가에서 빠진 국가에만 있는 공휴일의 숨김 key도 여기에 포함된다.

저장된 숨김 key 집합이 계산 결과와 같으면 새 저장값을 만들거나 화면 상태를 갱신하지 않는다.

일괄 선택은 실행 시점의 목록에 한 번 적용되며 선택 모드로 남지 않는다. 이후 처음 등장하는 key는 [공휴일 노출 설정 스펙](./holiday-visibility.md)의 기본 노출 규칙에 따라 선택 상태로 추가된다.

### 확인 중

저장된 공휴일과 국가 설정·노출 설정을 확인하는 동안에는 확인 중 상태를 제공한다. 국가 선택지도 확인이 끝난 뒤 목록과 함께 제공한다.

확인 중에도 일괄 선택 동작 버튼은 같은 자리에 있고 사용자는 세 동작을 펼쳐 고를 수 있다. 고른 동작은 확인이 끝났는지와 관계없이 그대로 실행한다.

### 상태 갱신과 유지

화면이 표시된 동안 공휴일 캐시, 국가 설정이나 노출 설정이 바뀌면 목록을 자동으로 최신 상태로 갱신한다.

선택한 국가 설정과 노출 설정은 화면 재생성, 백그라운드 복귀, 화면 재진입과 앱 재실행 뒤에도 유지된다. 구체적인 유지 범위는 [공휴일 국가 설정 스펙](./holiday-country.md)과 [공휴일 노출 설정 스펙](./holiday-visibility.md)을 따른다.

국가 설정과 노출 설정은 로컬 저장 영역에 즉시 반영하며 별도 저장 중 상태를 두지 않는다. 화면에는 저장 영역에서 확인된 최신 선택 상태를 반영한다.

### 뒤로가기

단독으로 표시될 때와 설정 목록과 함께 표시될 때의 뒤로가기 결과는 모두 [Setting 목록·상세 배치 스펙](./setting-list-detail.md)의 `뒤로가기`를 따른다.

## domain

### 공휴일 항목 구성

항목은 실행 시점의 적용 국가에 대해 기기에 저장된 공휴일로만 구성한다. 적용 국가가 비어 있으면 공휴일 항목이 없다. 적용 국가의 공휴일을 아직 한 번도 받아오지 않았다면 그 국가의 공휴일은 캘린더나 황금연휴 화면에서 공휴일을 동기화한 뒤에 항목으로 나타난다.

공휴일 이름 key는 [공휴일 노출 설정 스펙](./holiday-visibility.md)의 기준을 따른다.

같은 key를 가진 공휴일은 연도와 적용 기간이 달라도 하나의 항목으로 묶는다. 표시 이름은 그 묶음에서 시작일이 가장 최근인 공휴일의 원래 이름을 사용한다. 같은 시작일에 표기가 여러 개면 이름 오름차순에서 첫 번째 이름을 사용한다.

같은 key의 공휴일 중 공휴일 여부가 참인 것이 하나라도 있으면 쉬는 날로 본다. 모두 거짓일 때만 쉬는 날이 아닌 항목으로 본다.

항목은 표시 이름 오름차순으로 정렬한다. 표시 이름이 같으면 key 오름차순으로 정렬한다.

### 선택 상태

각 key는 선택과 선택 해제 중 하나의 상태를 가진다. 한 번도 설정하지 않은 key는 선택 상태로 시작한다.

같은 key의 공휴일은 하나의 선택 상태를 공유한다. 특정 key의 상태를 바꾸면 저장된 모든 연도와 이후 저장될 같은 key의 공휴일에 동일하게 적용된다.

개별 선택과 일괄 선택 결과는 로컬 저장 영역에 즉시 보관하고, 저장 영역에서 확인된 최신 상태를 화면에 반영한다.

### 검색 일치

검색 일치는 항목의 표시 이름을 기준으로 판정한다.

검색어와 표시 이름 양쪽에서 모든 공백 문자를 제거한 뒤, 검색어가 표시 이름에 부분 문자열로 포함되면 일치로 본다. 영문은 대소문자를 구분하지 않는다.

공백 문자만으로 구성된 검색어는 공백 제거 뒤 비어 있으므로 검색어가 없는 것으로 보고 전체 목록을 표시한다.

필터링은 항목의 노출 여부만 바꾼다. 항목의 구성, 정렬, 선택 상태는 `공휴일 항목 구성`과 `선택 상태`를 그대로 따른다.

### 검색어 유지

검색어는 화면 재생성과 백그라운드 복귀에는 유지된다. 화면을 떠났다가 다시 진입하거나 앱을 다시 시작하면 빈 검색어로 시작한다.

검색어는 기기에 저장하지 않으며 노출 설정 저장값에 영향을 주지 않는다.

### 일괄 선택 기준

`전체 선택`은 숨김 key를 남기지 않는다.

`전체 해제`는 실행 시점의 적용 국가에 대해 기기에 저장된 전체 공휴일의 모든 이름 key를 숨김 key로 정한다.

`쉬는 날만 선택`은 실행 시점의 적용 국가에 대해 저장된 전체 공휴일을 이름 key별로 묶고 쉬는 날이 아닌 key만 숨김 key로 정한다.

세 동작은 계산한 숨김 key 집합으로 기존 저장값 전체를 교체한다.

세 동작의 계산 기준은 실행 시점의 적용 국가에 대해 저장된 전체 공휴일이며, 화면이 그 공휴일을 확인했는지와 무관하다.
