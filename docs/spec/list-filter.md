# 목록 필터 반영 스펙

이 문서는 화면 본문을 차지하는 목록에서 사용자가 필터를 바꿨을 때 목록을 어디서부터 보게 되는지를 다룬다. 각 목록이 어떤 필터를 제공하고 그 필터가 무엇을 걸러 내는지는 각 화면 스펙이 다루고, 표시할 항목이 하나도 없을 때의 안내는 [목록 빈 상태 스펙](./list-empty-state.md)이 다룬다.

디자인: [필터 Bottom Sheet 디자인](../design/filter-bottom-sheet.md)

## 적용 대상

| 스펙 | 목록 | 이 문서를 따르는 필터 |
| --- | --- | --- |
| [TagHome 목록](./tag-home.md) | 태그 목록 | 최상위 태그 필터 |
| [MemoHome 목록](./memo-home.md) | 메모 목록 | 유무 필터, 태그 필터 |

[CalendarHome 화면 스펙](./calendar-home.md)의 태그 필터에는 적용하지 않는다. 캘린더는 처음부터 순서대로 읽는 목록이 아니라 날짜로 자리가 정해진 화면이며, 아이템 영역의 스크롤을 언제 되돌리는지는 [CalendarHome 화면 스펙](./calendar-home.md)과 [CalendarWeekOfMonth 컴포넌트 스펙](./calendar-week-of-month.md)이 소유한다.

[SearchHome 화면 스펙](./search-home.md)의 질의와 [장소 보기 모드 스펙](./place-view-mode.md)의 지도 보이는 영역도 목록의 범위를 좁히지만 사용자가 필터로 조작하는 것이 아니므로 이 문서가 정하지 않는다.

## feature

### 필터 반영

필터를 바꾸면 그 목록은 좁힌 범위의 항목으로 다시 놓인다. 사용자는 목록의 처음부터 좁힌 결과를 확인한다. 이는 [목록 정렬 스펙](./list-sort.md)의 `정렬 반영`에서 정렬을 바꾼 뒤 목록의 처음부터 새 순서를 확인하는 것과 같은 기준이다.

사용자가 목록을 아래로 이동해 둔 상태에서 필터를 바꿔도 마찬가지다. 이전 위치에 있던 항목이 좁힌 결과에 그대로 남아 있어도 그 자리를 따라가지 않는다. 좁힌 범위에서 무엇이 첫 항목이 되었는지는 필터를 바꾸기 전 위치에서 알 수 없으므로, 사용자가 결과를 처음부터 확인하게 한다.

필터를 바꿔도 필터는 열린 채로 남는다. 사용자는 필터 아래에 보이는 목록이 처음부터 다시 놓인 것을 확인하고 이어서 다른 필터를 바꿀 수 있으며, 필터를 닫은 뒤에도 목록은 처음부터 놓인 그대로다.

되돌린 뒤에도 목록에서 할 수 있는 행동은 그대로다. 항목을 열고, 완료하고, 삭제하고, 실행 취소하고, 당겨서 새로고침하고, 목록을 이어서 이동하는 것이 달라지지 않는다.

좁힌 결과에 표시할 항목이 하나도 없으면 목록 자리에 빈 상태를 표시하며, 그 기준은 [목록 빈 상태 스펙](./list-empty-state.md)을 따른다.

## domain

### 되돌리는 시점

되돌림은 좁힌 결과가 목록에 놓이는 시점에 한 번 적용한다.

필터를 바꾼 직후에는 아직 이전 필터로 조회한 목록이 놓여 있다. 그 시점에 되돌리면 좁힌 결과가 도착하면서 사용자가 보던 항목을 따라 목록이 다시 내려가므로, 사용자는 목록이 위로 올라갔다가 되돌아오는 움직임을 보게 된다. 따라서 이전 결과가 남아 있는 동안에는 위치를 그대로 두고, 좁힌 결과가 놓일 때 되돌린다.

좁힌 결과를 준비하는 동안의 표시는 [페이지 조회 목록의 자리 표시 스펙](./paged-list-placeholder.md)을 따른다.

### 되돌리는 조건

되돌림은 그 목록에 적용되는 필터의 값이 실제로 달라졌을 때만 적용한다.

| 사용자 행동 | 되돌림 |
| --- | --- |
| 최상위 태그만 보기를 켜거나 끈다 | 되돌린다 |
| 유무 필터의 한 축을 다른 값으로 바꾼다 | 되돌린다 |
| 유무 필터의 한 축에서 이미 고른 값을 다시 고른다 | 되돌리지 않는다 |
| 태그 필터에서 태그를 선택하거나 선택을 해제한다 | 되돌린다 |
| 태그 필터에서 선택을 전체 해제한다 | 되돌린다 |

메모 목록에서 태그 축이 `없음`이어서 태그 필터가 목록에 적용되지 않는 동안에는 사용자가 태그 선택을 바꿀 수 없으므로 되돌릴 일도 없다. 적용 여부의 기준은 [MemoHome 목록 스펙](./memo-home.md)의 `필터 조합 기준`을 따른다.

### 되돌리지 않는 경우

필터를 바꾸지 않았는데 목록의 내용이 바뀌는 경우에는 되돌리지 않는다. 항목이 추가되거나 수정되거나 완료·삭제되거나 실행 취소로 돌아온 경우, 당겨서 새로고침하거나 서버에서 내려받은 내용이 기기에 반영된 경우가 모두 그렇다. 사용자는 보고 있던 위치에서 바뀐 내용을 확인한다.

필터가 그대로인 채 화면이 회전하거나 시스템에 의해 화면이 재생성되어도, 앱이 백그라운드에 갔다가 같은 화면으로 돌아와도 되돌리지 않는다. 상세나 검색으로 이동한 뒤 뒤로 돌아온 경우도 같다.

정렬을 바꿨을 때의 결과는 [목록 정렬 스펙](./list-sort.md)의 `정렬 반영`이 소유한다.

### 되돌림 범위

되돌림은 필터를 바꾼 그 목록에만 적용한다. 같은 종류의 항목을 보여 주는 다른 목록이나 다른 화면의 목록 위치는 바꾸지 않는다.

필터 선택은 화면별로 독립이므로, 한 화면에서 필터를 바꾼 것이 다른 화면의 목록 위치를 되돌리지 않는다. 화면별 독립의 기준은 [태그 필터 스펙](./tag-filter.md)의 `필터 선택 유지`와 [TagHome 목록 스펙](./tag-home.md)의 `필터 선택 유지`를 따른다.

목록과 상세를 함께 표시하는 배치에서는 목록 영역만 되돌리고 상세 영역은 그대로 둔다. 사용자가 상세에서 보고 있던 항목은 필터를 바꿔도 계속 상세 영역에 남는다.
