# TagMemoFinishedList 목록·상세 배치 스펙

이 문서는 TagMemoFinishedList 화면에서 완료된 메모 목록과 상세를 함께 사용할 때 이 배치에만 해당하는 상세 선택 상태, 뒤로가기와 초기화 경계를 다룬다. 함께 사용과 단독 사용, 표시 비율 조절, 배치에 참여하는 화면과 유지·초기화의 공통 기준은 [목록·상세 배치 공통 스펙](./list-detail-pane.md)을 따른다. 목록 화면 자체의 내용과 행동은 [TagMemoFinishedList 화면 스펙](./tag-memo-finished-list.md)을, 상세 영역에 표시되는 화면의 내용과 행동은 [MemoDetail 화면 스펙](./memo-detail.md)을 따른다.

TagDetail 메모 탭에서 진입한 메모 상세와 메모 추가는 이 배치에 참여하지 않고 단독으로 표시한다. 그 기준은 [TagDetail 메모 탭 스펙](./tag-detail-memo.md)의 `메모 상세 확인`과 `메모 추가`를 따른다. MemoHome에서 사용하는 목록·상세 배치는 [Memo 목록·상세 배치 스펙](./memo-list-detail.md)에서 다룬다.

디자인: [TagMemoFinishedList 목록·상세 배치 디자인](../design/tag-memo-finished-list-detail.md)

선택 상태와 표시 비율은 화면 표시 상태일 뿐 사용자 데이터를 만들거나 저장하지 않으므로 `data` 영역은 생략한다.

## feature

### 상세 영역의 구성

아직 메모를 선택하지 않았으면 상세는 선택 전 상태다. 선택 전 상태에서는 목록에서 메모를 선택하라는 안내만 제공하고 사용자가 실행할 수 있는 동작은 제공하지 않는다.

사용자가 목록에서 메모를 선택하면 그 메모의 상세 화면이 현재 상세가 된다. 상세가 이미 다른 메모의 상세 화면이면 이전 상세를 쌓아 두지 않고 새로 선택한 메모의 상세 화면으로 교체한다.

이 화면에서는 메모를 추가할 수 없으므로 상세 영역에 메모 추가 화면이 표시되지 않고, 목록에서 추가를 실행하는 수단도 두지 않는다. 그 기준은 [완료 목록 공통 스펙](./finished-list.md)의 `추가 미제공`을 따른다.

### 함께 사용할 때의 행동

목록과 상세를 함께 사용하는 동안에도 주요 목적지의 공통 내비게이션은 제공하지 않는다.

### 뒤로가기

상세가 선택된 상태에서 뒤로가면 목록은 유지되고 상세는 직전 상태로 돌아간다.

메모 상세 화면을 다른 메모의 상세 화면으로 교체한 뒤 뒤로가면 이전에 선택했던 메모의 상세 화면으로 돌아가지 않고 선택 전 상태가 된다.

상세가 선택 전 상태일 때 뒤로가면 목록 화면 전체를 떠나 메모 탭이 선택된 같은 태그의 TagDetail 화면으로 돌아간다.

목록 화면이 제공하는 뒤로가기 동작을 사용하면 상세 선택 여부와 관계없이 같은 곳으로 돌아간다.

## domain

### 상세 선택

상세 영역이 가질 수 있는 상태는 선택 전 상태와 선택한 메모의 상세뿐이다.

### 유지와 초기화 기준

사용자가 목록 화면을 떠나는 것을 이 배치를 떠난 것으로 본다. 그 뒤 목록 화면에 다시 진입하거나 앱을 종료하고 다시 실행하면 [목록·상세 배치 공통 스펙](./list-detail-pane.md)의 `유지와 초기화 기준`에 따라 상세 선택은 선택 전 상태로, 표시 비율은 기본 상태로 초기화한다.
