# TagDetail 메모 탭 스펙

이 문서는 사용자가 TagDetail 화면의 메모 탭에서 표시 범위 안 태그에 연결된 메모를 확인하고 조작하며, 상세 대상 태그를 초기값으로 사용해 메모를 추가하는 행동을 다룬다. 화면 전체의 구성, 탭 전환과 유지, 화면 제목, 태그 디테일 탭의 행동과 세 목록 탭이 함께 쓰는 표시 범위는 [TagDetail 화면 스펙](./tag-detail.md)이 소유한다.

목록의 메모 표시·기간·날짜 그룹과 완료·삭제 규칙은 [MemoHome 목록 스펙](./memo-home.md)을, 메모 추가 행동은 [MemoAdd 화면 스펙](./memo-add.md)을, 메모와 태그 연결의 의미는 [메모 태그 스펙](./memo-tag.md)을 따른다. 목록을 당겨 새로고침하는 행동과 동기화 진행 표시는 [새로고침 스펙](./sync-refresh.md)에서 다룬다. 이 태그의 완료된 메모를 모아 확인하는 화면은 [TagMemoFinishedList 화면 스펙](./tag-memo-finished-list.md)에서 다룬다.

디자인: [TagDetail 메모 탭 디자인](../design/tag-detail-memo.md)

## feature

### 진입

사용자는 TagDetail 화면에서 메모 탭을 선택해 표시 범위 안 태그에 연결된 메모 목록을 확인한다. 탭을 선택하는 방법과 선택한 탭의 유지 기준은 [TagDetail 화면 스펙](./tag-detail.md)의 `탭 전환`과 `선택한 탭`을 따른다.

상세 대상 태그를 아직 조회하지 못했거나 조회에 실패해도 메모 탭의 목록과 동작은 그대로 제공한다.

### 메모 추가

사용자는 메모 탭에서 언제든 메모 추가를 시작할 수 있다. 상세 대상 태그의 완료 여부, 삭제 여부와 조회 결과는 메모 추가 시작을 막지 않는다.

사용자가 메모 추가를 선택하면 MemoAdd 화면으로 이동한다. MemoAdd 화면은 창 너비와 관계없이 단독으로 표시하고, 그 화면에서는 주요 목적지의 공통 내비게이션을 제공하지 않는다.

메모 탭에서 진입한 메모 추가 화면은 상세 대상 태그를 최초 선택하고 대표 태그로 지정한 상태로 시작한다. 사용자는 저장 전까지 태그 선택을 추가하거나 해제하고 대표 태그를 바꿀 수 있다.

사용자가 메모 추가 화면에서 뒤로가면 메모 탭이 선택된 같은 태그의 TagDetail 화면으로 돌아간다.

메모 추가는 메모 탭을 선택한 동안에만 제공한다. 다른 탭에서는 메모 추가를 실행할 수 없다.

### 목록 표시

목록에는 현재 사용자 계정과 연결된 메모 중 표시 범위 안 태그 하나 이상과 해제되지 않은 연결을 가지며 완료되지도 삭제되지도 않은 메모만 표시한다. 표시 범위가 무엇을 정하는지는 [TagDetail 화면 스펙](./tag-detail.md)의 `표시 범위`를 따른다.

한 메모가 표시 범위 안 여러 태그와 연결되어 있어도 목록에는 한 번만 나타난다.

사용자가 표시 범위를 바꾸면 목록을 새 범위 기준으로 다시 표시하고, 범위를 넓혀 새로 들어온 메모는 지금 정렬 기준에 맞는 위치에 나타난다.

기간이 없는 메모는 날짜 그룹 없이 먼저 표시한다. 기간이 있는 메모는 시작 날짜별로 묶어 표시한다. 정렬과 날짜 그룹은 [MemoHome 목록 스펙](./memo-home.md)을 따른다.

아직 준비되지 않은 자리의 처리는 [페이지 조회 목록의 자리 표시 스펙](./paged-list-placeholder.md)을 따른다.

최초 조회나 추가 조회에 실패하면 이미 표시된 메모를 유지하며 별도 재시도 동작은 제공하지 않는다.

### 빈 상태

표시 범위 안 태그에 연결된 메모가 하나도 없으면 목록 자리에 표시할 메모가 아직 없음을 알린다. 판정 시점, 빈 상태에서 할 수 있는 행동, 목록과의 전환은 [목록 빈 상태 스펙](./list-empty-state.md)을 따른다.

빈 상태에서도 사용자는 메모 추가와 완료된 메모 확인을 그대로 실행할 수 있으며, 추가한 메모가 이 목록의 노출 기준을 만족하면 빈 상태가 사라지고 목록에 나타난다.

대상 태그를 조회하지 못해 화면 제목을 표시하지 못하는 것은 빈 상태 판정에 영향을 주지 않는다.

### 완료된 메모 확인

사용자는 메모 탭에서 완료된 메모 확인을 선택해 같은 태그의 TagMemoFinishedList 화면으로 이동한다.

이 태그에 완료된 메모가 하나도 없어도 이 동작은 제공된다. 목록이 비어 있는지, 대상 태그를 조회했는지, 지금 표시 범위가 무엇인지는 이 동작을 막지 않는다.

이동한 화면에는 표시 범위를 적용하지 않는다. 표시 범위를 넓혀 두었어도 그 화면은 상세 대상 태그에 연결된 완료된 메모만 표시한다.

완료된 메모 확인은 메모 탭을 선택한 동안에만 제공한다. 다른 탭에서는 실행할 수 없다.

이동한 화면의 내용과 행동은 [TagMemoFinishedList 화면 스펙](./tag-memo-finished-list.md)을 따른다. 사용자가 그 화면에서 뒤로 가면 메모 탭이 선택된 같은 태그의 TagDetail 화면으로 돌아온다.

### 메모 상세 확인

사용자가 메모를 선택하면 선택한 메모의 MemoDetail 화면으로 이동한다. MemoDetail 화면은 창 너비와 관계없이 단독으로 표시하고, 그 화면에서는 주요 목적지의 공통 내비게이션을 제공하지 않는다.

MemoDetail 화면에서 뒤로가면 메모 탭이 선택된 같은 태그의 TagDetail 화면으로 돌아간다.

사용자가 MemoDetail 화면에서 메모를 완료하거나 삭제하거나 이 태그와의 연결을 해제한 뒤 돌아오면, 그 메모는 이 목록의 노출 기준에 따라 목록에서 사라진다.

### 완료·삭제와 실행 취소

사용자는 목록에서 메모를 완료하거나 삭제할 수 있다.

완료되거나 삭제된 메모는 목록에서 사라지고 해당 결과의 피드백과 실행 취소 동작을 제공한다. 완료한 메모는 [TagMemoFinishedList 화면 스펙](./tag-memo-finished-list.md)의 노출 기준을 만족해 그 화면의 목록에 나타난다.

사용자가 실행 취소하면 메모는 이전 상태로 돌아가 목록의 정렬 기준에 맞는 위치에 다시 나타난다.

### 오늘 갱신

화면이 다시 활성화될 때마다 사용자의 현재 시간대를 기준으로 오늘을 다시 정하고, 오늘에 해당하는 날짜 그룹 표시를 갱신한다.

### 정렬 선택

사용자는 목록 위에서 현재 정렬을 확인하고 다른 기준으로 바꿀 수 있다. 고를 수 있는 기준과 정렬 선택·반영·유지의 결과는 [목록 정렬 스펙](./list-sort.md)을 따른다.

## domain

### 상세 대상 태그와 연결

메모 탭의 상세 대상은 TagDetail 화면의 상세 대상 태그와 같은 태그다. 대상이 결정되는 기준은 [TagDetail 화면 스펙](./tag-detail.md)의 `상세 대상과 내용 표시`를 따른다.

목록에는 표시 범위가 정한 태그 집합 중 하나 이상과 해제되지 않은 연결을 가진 메모만 포함한다. 집합을 만드는 기준은 [TagDetail 화면 스펙](./tag-detail.md)의 `표시 범위`가 소유한다.

집합 안 태그가 완료되거나 삭제되어도 기존 메모 연결은 유지되므로 메모 탭의 노출 기준은 바뀌지 않는다. 다만 삭제된 태그는 집합에 들어가지 않으므로, 상세 대상 태그가 아닌 하위 태그가 삭제되면 그 태그로만 연결된 메모는 목록에서 사라진다.

상세 대상이 다른 태그로 바뀌면 목록을 새 대상 태그를 기준으로 만든 집합의 메모로 바꾼다.

### 메모 추가의 초기값

메모 추가 시작은 상세 대상 태그의 상태와 무관하게 항상 허용한다.

대상 태그는 메모 추가 화면의 최초 선택 태그이자 최초 대표 태그일 뿐, 저장해야 하는 필수 관계나 고정된 대표 태그가 아니다. 대상 태그를 선택한 것으로 표시할 수 있는지는 [MemoAdd 화면 스펙](./memo-add.md)의 `태그 선택과 메모 추가 성립 조건`을 따르므로, 완료되었거나 삭제된 대상 태그는 선택되지 않은 상태로 시작한다.

최종 메모-태그 관계와 대표 태그는 저장 시점에 사용자가 선택한 상태로 확정한다. 따라서 대상 태그를 해제하면 새 메모와 연결하지 않고, 다른 태그를 대표 태그로 선택하면 대상 태그를 대표 태그로 저장하지 않는다. 그 밖의 저장 규칙은 [MemoAdd 화면 스펙](./memo-add.md)을 따른다.

### 메모 노출과 정렬

표시 범위 안 태그와 연결된 메모 중 미완료·미삭제 메모만 노출한다. 표시 범위는 담을 태그만 정하고 이 노출 기준을 대체하지 않는다.

정렬, 날짜 그룹과 오늘의 기준은 [MemoHome 목록 스펙](./memo-home.md)을 따른다.

위 순서는 사용자가 정렬을 고르지 않았을 때의 순서이며, 사용자가 고를 수 있는 다른 기준과 그 순서는 [목록 정렬 스펙](./list-sort.md)이 정한다.

### 완료·삭제·실행 취소

상태 전이와 수정 시각 갱신은 [MemoHome 목록 스펙](./memo-home.md)을 따른다.

완료, 삭제와 실행 취소는 메모와 태그의 연결을 바꾸지 않는다. 따라서 완료한 메모는 대상 태그와의 연결을 유지한 채 [TagMemoFinishedList 화면 스펙](./tag-memo-finished-list.md)의 노출 기준을 만족하고, 그 화면에서 다시 시작하면 이 목록에 다시 나타난다.

메모 탭에서 실행하는 완료, 삭제와 실행 취소는 대상 태그의 이모지, 제목, 설명, 컬러와 완료 여부, 삭제 여부를 바꾸지 않는다. 태그 디테일 탭에서 수정 중이던 입력 내용도 바꾸지 않는다.

## data

### 태그별 메모 조회

현재 사용자 계정과 연결된 메모 및 메모-태그 연결 중 표시 범위 안 태그 하나 이상과 해제되지 않은 연결을 가진 항목만 페이지 단위로 조회한다. 표시 범위 안 여러 태그와 연결된 메모도 조회 결과에 한 번만 담는다. 이 조회는 태그 디테일 탭의 태그 조회, 웹 탭의 웹 항목 조회, 장소 탭의 장소 조회와 서로 독립이다.

메모의 완료 여부, 삭제 여부, 기간 또는 태그 연결 상태가 바뀌면 목록을 노출 기준과 정렬 기준에 따라 자동 갱신한다. 표시 범위 안 태그를 정하는 태그와 태그의 연결이 바뀐 것도 같은 기준으로 갱신한다.

연결이 해제된 메모는 목록에서 사라지고, 연결이 복구되면 노출 기준을 만족할 때 정렬 기준에 맞는 위치에 다시 나타난다.

### 상태 변경의 저장

완료, 삭제와 실행 취소의 저장 흐름은 [MemoHome 목록 스펙](./memo-home.md)을 따른다.

메모 상태를 바꿔도 메모와 태그의 연결은 유지한다.

### 메모 추가 결과

메모 탭에서 시작한 메모 추가 화면은 `domain > 메모 추가의 초기값`에서 확정한 관계와 대표 태그를 새 메모와 함께 저장한다.

추가된 메모가 상세 대상 태그와 연결되고 메모 탭의 노출 기준을 만족하면 현재 목록의 정렬 기준에 맞는 위치에 나타난다.
