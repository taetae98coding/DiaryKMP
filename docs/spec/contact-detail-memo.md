# ContactDetail 메모 탭 스펙

이 문서는 사용자가 ContactDetail 화면의 메모 탭에서 상세 대상 연락처에 연결된 메모를 확인하고 조작하며, 그 연락처를 초기 선택으로 사용해 메모를 추가하는 행동 가운데 ContactDetail 화면에만 해당하는 부분을 다룬다. 목록 표시, 빈 상태, 메모 추가와 메모 상세 확인, 완료·삭제와 실행 취소, 새로고침, 정렬, 조회와 저장 계약은 [항목 상세 메모 탭 공통 스펙](./entity-detail-memo.md)이 소유한다. 화면 전체의 구성, 탭 전환과 유지, 화면 제목, 연락처 디테일 탭의 행동은 [ContactDetail 화면 스펙](./contact-detail.md)이 소유한다.

메모와 연락처 연결의 의미는 [메모 연락처 스펙](./memo-contact.md)을 따른다.

조회와 저장은 공통 스펙의 `data`를 그대로 따르므로 이 문서에는 `data` 영역을 두지 않는다.

디자인: [항목 상세 메모 탭 공통 디자인](../design/entity-detail-memo.md), [ContactDetail 화면 디자인](../design/contact-detail.md)

## feature

### 진입

사용자는 ContactDetail 화면에서 메모 탭을 선택해 상세 대상 연락처에 연결된 메모 목록을 확인한다. 연락처 목록과 상세를 함께 표시하는 배치에서는 상세 영역 안의 메모 탭에서 같은 목록을 확인한다. 탭을 선택하는 방법과 선택한 탭의 유지 기준은 [ContactDetail 화면 스펙](./contact-detail.md)의 `탭 전환`과 `선택한 탭`을 따른다.

캘린더 홈 화면의 생일에서 진입한 ContactDetail 화면에서도 같은 메모 탭을 제공한다.

### 메모 추가의 초기 선택

메모 탭에서 진입한 MemoAdd 화면은 상세 대상 연락처가 연락처 입력에 선택된 상태로 시작한다. 태그, 웹 항목, 장소는 선택되지 않은 상태로 시작한다.

### 단독 표시와 돌아오기

메모 탭에서 이동한 MemoAdd 화면과 MemoDetail 화면은 [Contact 목록·상세 배치 스펙](./contact-list-detail.md)의 배치에 참여하지 않고 창 너비와 관계없이 단독으로 표시한다.

두 화면에서 뒤로가면 메모 탭이 선택된 같은 연락처의 ContactDetail 화면으로 돌아간다. 연락처 목록과 함께 표시하던 배치에서 이동했으면 그 배치로 돌아가고, 상세 영역에는 메모 탭이 선택된 같은 연락처의 상세가 남아 있다.

## domain

### 상세 대상

메모 탭의 상세 대상은 ContactDetail 화면의 상세 대상 연락처와 같다. 대상이 결정되는 기준은 [ContactDetail 화면 스펙](./contact-detail.md)의 `상세 대상과 내용 표시`를 따른다.

목록에 담을 연결은 메모와 연락처의 연결이며, 그 규칙은 [메모 연락처 스펙](./memo-contact.md)을 따른다.

연락처 목록에서 다른 연락처를 선택해 상세 대상이 바뀌면 목록을 새 연락처의 메모로 바꾼다.

### 연락처의 상태와 노출

즐겨찾기 변경과 연락처 삭제는 메모와 연락처의 연결을 바꾸지 않으므로 메모 탭의 노출 기준도 바꾸지 않는다.
