# Play Integrity 판정 기록 스펙

이 문서는 서버가 앱이 보낸 Google Play 무결성 확인 정보를 Google에 보내 판정 결과를 받아 앱에 돌려주는 처리를 다룬다.

주고받는 정보와 판정 결과의 의미는 [Play Integrity 판정 기록 스펙(common)](../common/play-integrity-logging.md)을, 앱이 언제 확인하고 판정 결과를 어떻게 기록하는지는 [Play Integrity 판정 기록 스펙(client)](../client/play-integrity-logging.md)을 따른다.

## data

### 판정 결과 요청 처리

무결성 확인 정보는 Google의 키로 암호화되어 있어 앱이 스스로 풀 수 없으므로, 서버가 Google에 보내 판정 결과로 바꾼다.

서버는 로그인 세션이 없어도 요청을 받는다. 게스트도 확인하기 때문이다. 무결성 확인 정보나 앱 패키지 이름이 비어 있는 요청은 거절한다.

서버는 받은 앱 패키지 이름으로 Google에 판정 결과를 요청한다. Google은 서버의 프로젝트에 Play Console에서 연결된 앱이 발급받은 무결성 확인 정보만 풀어 주므로, 다른 앱의 정보나 위조한 정보를 보내면 서버는 판정 결과를 돌려주지 못한다. 서버가 요청의 앱 패키지 이름을 따로 확인하지 않아도 되는 것은 이 때문이다.

서버는 Google이 돌려준 판정 결과를 필드를 고르거나 서버가 판단한 값을 더하지 않고 구조 그대로 돌려준다. Google이 새 필드를 추가하면 별도 변경 없이 그 필드도 함께 전달된다.

Google이 판정 결과를 돌려주지 않거나 Google에 연결하지 못하면 서버는 판정 결과 없이 실패를 돌려주고 서버 오류 기록으로 남긴다. 다시 시도하지 않는다.

### 저장하지 않음

서버는 무결성 확인 정보와 판정 결과를 저장하지 않고 돌려주기만 한다. 판정 결과는 계정 데이터가 아니므로 [데이터 동기화 스펙](../common/data-sync.md)의 동기화 대상이 아니다.
