# 메모 태그 입력 컴포넌트 스펙

이 문서는 MemoAdd 화면과 MemoDetail 화면에서 함께 사용하는 태그 입력 가운데 이 입력에만 해당하는 부분을 다룬다. 태그를 고르는 행동과 판정 기준은 [태그 선택 입력 공통 스펙](./tag-select-input.md)을 따르고, 구체적인 구성과 조작 수단은 [메모 태그 입력 컴포넌트 디자인](../design/memo-tag-input.md)에서 다룬다.

태그 입력에서 사용자가 반영한 선택과 대표 태그 지정이 어디에 반영되는지는 화면마다 다르므로 이 문서에서 다루지 않는다. MemoAdd 화면에서는 추가할 메모의 선택으로 반영되고, MemoDetail 화면에서는 상세 대상 메모의 저장된 연결과 대표 태그로 반영되며, 각각 [MemoAdd 화면 스펙](./memo-add.md)과 [MemoDetail 화면 스펙](./memo-detail.md)을 따른다.

메모와 태그의 연결 규칙은 [메모 태그 스펙](./memo-tag.md)을, 메모가 태그 하나를 대표 태그로 가지는 규칙은 [메모 대표 태그 스펙](./memo-primary-tag.md)을 따른다.

디자인: [메모 태그 입력 컴포넌트 디자인](../design/memo-tag-input.md)

## 공통 스펙과의 용어 대응

[태그 선택 입력 공통 스펙](./tag-select-input.md)의 용어는 이 입력에서 다음을 뜻한다.

| 공통 스펙 용어 | 이 입력에서의 뜻 |
| --- | --- |
| 선택 | 메모의 태그 선택, 선택 해제는 그 선택의 해제 |
| 표시 대상 태그 | 선택한 것으로 표시하는 태그 |
| 추가 항목 | 태그 입력의 추가 항목 |

이 입력은 공통 스펙에 없는 대표 태그 지정을 함께 제공하므로, 아래 절은 공통 스펙의 같은 이름 절을 대체하지 않고 더한다.

## feature

### 선택 상태 표시에 더하는 것

태그 입력에는 현재 선택한 태그와 함께 그중 대표 태그로 지정한 태그가 표시된다.

대표 태그로 지정한 칩도 다른 칩과 같은 방식으로 태그 상세로 이동하며, 이동해도 선택과 대표 태그 지정은 바뀌지 않는다.

### 태그 선택 목록에 더하는 것

사용자는 태그 선택 목록에서 각 태그의 선택 여부와 함께 대표 태그 지정 여부를 확인할 수 있다.

다음 태그를 이어서 불러오는 동안에도 사용자는 이미 나타난 태그의 대표 태그 지정을 바꿀 수 있고, 목록을 닫아도 목록에서 반영한 대표 태그 지정은 그대로 유지된다.

### 태그 검색에 더하는 것

태그 선택 목록이 열리면 입력 초점이 검색어 입력에 놓여, 사용자는 입력을 따로 누르지 않고 바로 검색어를 입력할 수 있다.

검색어로 좁힌 목록에서도 사용자는 대표 태그 지정을 그대로 바꿀 수 있다. 대표 태그로 지정해도 그 태그는 검색 결과에서 빠지지 않는다.

검색어는 태그 입력에 선택한 것으로 표시하는 태그와 그 대표 태그 지정을 바꾸지 않는다.

### 태그 추가 이동에 더하는 것

이동과 돌아왔을 때의 자동 선택은 [태그 선택 입력 공통 스펙](./tag-select-input.md)의 `태그 추가 이동`을 따른다.

어느 경로로 이동하든 이동 자체는 대표 태그 지정을 바꾸지 않고, 태그를 하나도 추가하지 않고 돌아와도 대표 태그 지정은 그대로다.

### 대표 태그 지정

사용자는 선택 목록의 태그를 메모의 대표 태그로 지정하거나 지정을 해제할 수 있다.

선택하지 않은 태그를 대표 태그로 지정하면 그 태그는 함께 선택된다.

이미 대표 태그로 지정한 태그의 대표 태그 지정을 다시 실행하면 대표 태그 지정만 해제되고 태그 선택은 유지된다.

다른 태그를 대표 태그로 지정하면 이전에 지정한 태그의 대표 태그 지정은 해제되고 선택은 유지된다.

대표 태그로 지정한 태그의 선택을 해제하면 대표 태그 지정도 함께 해제된다.

대표 태그 지정과 지정 해제도 즉시 반영되며 별도의 확정 동작은 필요하지 않다.

## domain

### 선택한 것으로 표시하는 태그

기준은 [태그 선택 입력 공통 스펙](./tag-select-input.md)의 `표시 대상 태그`를 따른다.

완료된 태그를 선택한 것으로 표시하는지는 화면마다 다르다. MemoAdd 화면은 [MemoAdd 화면 스펙](./memo-add.md)의 `태그 선택과 메모 추가 성립 조건`을, MemoDetail 화면은 [MemoDetail 화면 스펙](./memo-detail.md)의 `태그 입력에 표시하는 태그`를 따른다.

선택되어 있던 태그가 그 기준에 없으면 그 태그는 선택에서 제외된 것으로 보고, 대표 태그로 지정되어 있었으면 대표 태그 지정도 함께 해제된 것으로 본다. 그 태그가 복구되거나 다시 시작되어 표시 기준을 다시 만족하면 유지되어 있던 선택과 대표 태그 지정이 태그 입력에 다시 나타난다.

저장된 연결이 유지되는 규칙은 [항목 연결 공통 스펙](./entity-link.md)의 `항목의 상태 변화와 연결`을 따른다.

### 선택할 수 있는 태그

기준은 [태그 선택 입력 공통 스펙](./tag-select-input.md)의 `선택할 수 있는 태그`를 따른다. 완료되거나 삭제된 태그는 새로 선택하거나 대표 태그로 지정할 수 없다.

메모는 태그가 아니므로 자기 자신을 제외하는 규칙은 없다.

### 태그 선택 목록에 나타나는 태그

기준은 [태그 선택 입력 공통 스펙](./tag-select-input.md)의 `태그 선택 목록에 나타나는 태그`를 따른다. 목록에 나타난 태그는 완료 여부와 관계없이 선택을 해제하거나 대표 태그 지정을 바꿀 수 있다.

MemoAdd 화면은 선택한 것으로 표시하는 태그가 선택할 수 있는 태그와 같으므로 목록에도 선택할 수 있는 태그만 나타나고, MemoDetail 화면은 [MemoDetail 화면 스펙](./memo-detail.md)의 `태그 입력에 표시하는 태그`에 따라 연결된 완료된 태그가 함께 나타난다.

### 추가한 태그의 자동 선택에 더하는 것

판정은 [태그 선택 입력 공통 스펙](./tag-select-input.md)의 `추가한 태그의 자동 선택`을 따른다.

자동 선택은 선택만 바꾸고 대표 태그 지정은 바꾸지 않는다. 대표 태그를 지정하지 않은 상태에서 태그가 자동 선택되어도 대표 태그는 지정되지 않는다.

### 대표 태그 지정 기준

메모의 대표 태그는 최대 하나이며, 항상 선택한 태그 중 하나다.

대표 태그를 지정하지 않은 상태도 허용된다.

## data

### 태그 목록 조회

조회 흐름은 [태그 선택 입력 공통 스펙](./tag-select-input.md)의 `태그 목록 조회`를 따른다.

MemoAdd 화면은 선택할 수 있는 태그만 조회하고, MemoDetail 화면은 [MemoDetail 화면 스펙](./memo-detail.md)의 `태그 입력의 조회`를 따른다.
