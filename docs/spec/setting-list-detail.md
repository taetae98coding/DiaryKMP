# Setting 목록·상세 배치 스펙

이 문서는 설정 목록과 상세를 함께 사용할 때 이 배치에만 해당하는 상세 선택 상태, 뒤로가기와 초기화 경계를 다룬다. 함께 사용과 단독 사용, 표시 비율 조절, 배치에 참여하는 화면과 유지·초기화의 공통 기준은 [목록·상세 배치 공통 스펙](./list-detail-pane.md)을 따른다. 설정 목록과 각 세부 설정 화면의 내용과 행동은 [SettingHome 화면 스펙](./setting-home.md), [SettingHoliday 화면 스펙](./setting-holiday.md), [SettingMap 화면 스펙](./setting-map.md), [SettingGemini 화면 스펙](./setting-gemini.md)에서 다룬다.

디자인: [Setting 목록·상세 배치 디자인](../design/setting-list-detail.md)

선택 상태와 표시 비율은 화면 표시 상태일 뿐 사용자 데이터를 만들거나 저장하지 않으므로 `data` 영역은 생략한다.

## feature

### 상세 영역의 구성

아직 설정 항목을 선택하지 않았으면 상세는 선택 전 상태이며, 선택 전 상태에서는 사용자가 실행할 수 있는 동작을 제공하지 않는다.

사용자가 설정 항목을 선택하면 해당 설정 화면이 현재 상세가 된다. 다른 설정 항목을 선택하면 이전 상세를 쌓아 두지 않고 현재 상세를 새로 선택한 설정 화면으로 교체한다.

이 배치에는 추가 화면이 없으므로 목록에서 추가를 실행하는 수단도 두지 않는다.

### 뒤로가기

목록과 상세를 함께 사용하는 중 상세가 선택된 상태에서 시스템 뒤로가기를 사용하면 목록은 유지되고 상세는 선택 전 상태로 돌아간다. 이전에 선택했던 다른 상세로 이동하지 않는다.

설정 목록의 뒤로가기 동작을 사용하면 상세 선택 여부와 관계없이 설정 화면 전체를 떠나 `더보기` 화면으로 돌아간다.

세부 설정 화면이 단독으로 표시될 때 사용자가 뒤로가면 설정 목록으로 돌아간다. 설정 목록도 세부 화면이므로 공통 내비게이션은 계속 제공하지 않는다.

## domain

### 상세 선택

상세 영역은 선택 전 상태, 공휴일 설정 선택, 지도 설정 선택, Gemini 설정 선택 중 하나의 상태를 가진다.

### 유지와 초기화 기준

사용자가 `더보기` 화면으로 돌아가는 것을 이 배치를 떠난 것으로 본다. 그 뒤 설정 화면에 다시 진입하거나 앱을 종료하고 다시 실행하면 [목록·상세 배치 공통 스펙](./list-detail-pane.md)의 `유지와 초기화 기준`에 따라 상세 선택은 선택 전 상태로, 표시 비율은 기본 상태로 초기화한다.
