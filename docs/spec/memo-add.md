# MemoAdd 화면 스펙

이 문서는 사용자가 새 메모를 작성해 추가하는 MemoAdd 화면의 내용과 행동을 다룬다. MemoAdd 화면으로 이동하는 메모 목록 화면의 구성과 추가한 메모가 목록에 표시되는 방식은 이 문서의 범위가 아니다. 화면 본문에 배치되는 설명 입력, 컬러 입력, 날짜·시간 입력 컴포넌트 자체의 동작은 [설명 입력 컴포넌트 스펙](./description-input.md), [DiaryColorInput 컴포넌트 스펙](./diary-color-input.md), [DiaryDateTimeInput 컴포넌트 스펙](./diary-date-time-input.md)을 따른다.

태그 선택·해제와 대표 태그 지정의 행동과 정책은 [메모 태그 입력 컴포넌트 스펙](./memo-tag-input.md)을 따르고, 구체적인 구성·선택 목록 표현·문구는 [메모 태그 입력 컴포넌트 디자인](../design/memo-tag-input.md)을 따른다. 본문에 배치되는 웹 입력의 행동과 정책은 [메모 웹 입력 컴포넌트 스펙](./memo-web-input.md)을, 연락처 입력의 행동과 정책은 [메모 연락처 입력 컴포넌트 스펙](./memo-contact-input.md)을, 장소 카드의 행동과 정책은 [메모 장소 카드 컴포넌트 스펙](./memo-place-card.md)을 따른다. 이 문서에서는 MemoAdd 화면에서만 다른 초기 상태와 추가 결과를 다룬다. 메모와 태그의 연결 규칙은 [메모 태그 스펙](./memo-tag.md)을, 메모가 태그 하나를 대표 태그로 가지는 규칙은 [메모 대표 태그 스펙](./memo-primary-tag.md)을, 메모와 웹 항목의 연결 규칙은 [메모 웹 스펙](./memo-web.md)을, 메모와 연락처의 연결 규칙은 [메모 연락처 스펙](./memo-contact.md)을, 메모와 장소의 연결 규칙은 [메모 장소 스펙](./memo-place.md)을 따른다.

작성 상태 유지, 뒤로가기, 추가 요청 제한, 계정 연결과 저장 계약은 [항목 추가 화면 공통 스펙](./entity-add.md)을 따른다. Gemini로 제목, 설명, 기간을 생성해 반영하는 작성 도우미의 행동과 정책은 [메모 Gemini 작성 도우미 스펙](./memo-gemini.md)을 따른다.

디자인: [MemoAdd 화면 디자인](../design/memo-add.md)

## feature

### 진입

사용자는 메모 목록 화면에서 메모 추가 행동을 선택해 MemoAdd 화면으로 이동한다. TagDetail 메모 탭에서 이동한 경우에는 그 탭의 상세 대상 태그를 선택하고 대표 태그로 지정한 상태로 진입한다. ContactDetail, PlaceDetail 또는 WebDetail 화면의 메모 탭에서 이동한 경우에는 그 탭의 상세 대상 연락처, 장소 또는 웹 항목이 선택된 상태로 진입한다. 캘린더 홈 화면이나 황금연휴 화면에서 기간을 선택해 이동한 경우에는 선택한 기간이 날짜·시간 입력에 입력된 상태로 진입한다.

MemoHome에서 이동한 MemoAdd 화면의 목록 동시 표시와 단독 표시 상태는 [Memo 목록·상세 배치 스펙](./memo-list-detail.md)을, TagDetail 메모 탭에서 이동한 MemoAdd 화면은 [TagDetail 메모 탭 스펙](./tag-detail-memo.md)의 `메모 추가`에 따라, ContactDetail·PlaceDetail·WebDetail 메모 탭에서 이동한 MemoAdd 화면은 [항목 상세 메모 탭 공통 스펙](./entity-detail-memo.md)의 `메모 추가`에 따라 단독으로 표시한다.

캘린더 홈이나 황금연휴 화면에서 이동한 MemoAdd 화면은 메모 목록과 함께 표시하지 않는다.

### 메모 내용 입력

사용자는 메모의 제목과 설명을 입력하고, 컬러와 기간을 선택할 수 있다.

MemoAdd 화면이 처음 나타나면 컬러 입력에는 무작위로 정해진 컬러가 초기값으로 제시되며, 사용자가 바꾸지 않으면 그 컬러가 그대로 쓰인다. 사용자가 제목부터 바로 입력할 수 있도록 입력 초점을 제목 입력에 한 번 둔다.

기간 선택의 시작 상태는 `domain`의 기간 선택 시작 상태를 따른다.

### Gemini 작성 도우미

사용자는 Gemini 작성 도우미를 시작해 제목, 설명, 기간을 생성하고 각각 따로 반영할 수 있다. 도우미의 행동과 정책은 [메모 Gemini 작성 도우미 스펙](./memo-gemini.md)을 따른다.

반영한 내용은 추가할 메모의 입력으로만 들어가며, 메모에 기록되는 시점은 사용자가 메모 추가를 실행할 때다.

작성 도우미는 메모 추가 성립 조건에 영향을 주지 않는다.

### 태그 입력

태그 선택 목록에서의 태그 선택·해제와 대표 태그 지정은 [메모 태그 입력 컴포넌트 스펙](./memo-tag-input.md)을 따르고, 태그 입력의 구성과 표현은 [메모 태그 입력 컴포넌트 디자인](../design/memo-tag-input.md)을 따른다.

MemoAdd 화면에서 사용자가 반영한 태그 선택과 대표 태그 지정은 추가할 메모의 선택으로만 반영되며, 저장된 메모를 바꾸지 않는다. 선택한 태그가 메모에 연결되는 시점은 사용자가 메모 추가를 실행할 때다.

TagDetail 메모 탭에서 이동한 MemoAdd 화면이 처음 나타나면 해당 탭의 상세 대상 태그가 선택되고 대표 태그로 지정된 상태로 표시된다.

### 웹 입력

본문에는 메모에 연결할 웹 항목을 고르는 웹 입력이 표시된다. 웹 선택 목록에서의 웹 선택·해제, 웹 항목을 눌러 웹 상세로 이동하는 흐름과 웹 추가 이동의 행동과 정책은 [메모 웹 입력 컴포넌트 스펙](./memo-web-input.md)을 따른다.

MemoAdd 화면에서 사용자가 반영한 웹 선택은 추가할 메모의 선택으로만 반영되며, 저장된 메모를 바꾸지 않는다. 선택한 웹 항목이 메모에 연결되는 시점은 사용자가 메모 추가를 실행할 때다.

WebDetail 메모 탭에서 이동한 MemoAdd 화면이 처음 나타나면 그 탭의 상세 대상 웹 항목이 선택된 상태로 표시된다.

웹 입력은 메모 추가 성립 조건에 영향을 주지 않는다.

### 연락처 입력

본문에는 메모에 연결할 연락처를 고르는 연락처 입력이 표시된다. 연락처 선택 목록에서의 연락처 선택·해제, 연락처를 눌러 연락처 상세로 이동하는 흐름과 연락처 추가 이동의 행동과 정책은 [메모 연락처 입력 컴포넌트 스펙](./memo-contact-input.md)을 따른다.

MemoAdd 화면에서 사용자가 반영한 연락처 선택은 추가할 메모의 선택으로만 반영되며, 저장된 메모를 바꾸지 않는다. 선택한 연락처가 메모에 연결되는 시점은 사용자가 메모 추가를 실행할 때다.

ContactDetail 메모 탭에서 이동한 MemoAdd 화면이 처음 나타나면 그 탭의 상세 대상 연락처가 선택된 상태로 표시된다.

연락처 입력은 메모 추가 성립 조건에 영향을 주지 않는다.

### 장소 표시와 선택

본문에는 메모의 장소를 보여 주는 장소 카드가 표시된다. 카드의 지도 표시, 장소 표시, 장소 위치 보기, 지도 위 핀에서 장소 상세로 이동하는 흐름과 장소 선택·해제의 행동과 정책은 [메모 장소 카드 컴포넌트 스펙](./memo-place-card.md)을 따른다.

MemoAdd 화면에서 사용자가 반영한 장소 선택은 추가할 메모의 선택으로만 반영되며, 저장된 메모를 바꾸지 않는다. 선택한 장소가 메모에 연결되는 시점은 사용자가 메모 추가를 실행할 때다.

PlaceDetail 메모 탭에서 이동한 MemoAdd 화면이 처음 나타나면 그 탭의 상세 대상 장소가 선택된 상태로 표시된다.

장소 카드는 메모 추가 성립 조건에 영향을 주지 않는다.

### 메모 추가 실행

사용자는 입력한 제목으로 메모 추가를 실행할 수 있다.

메모 추가를 처리하는 동안에는 진행 중인 상태를 표시하며 새 추가 요청을 받을 수 없다.

### 추가 성공

메모 추가에 성공하면 화면은 그대로 유지되고 제목과 설명을 비운다. 컬러에는 다음 메모를 위한 무작위 값이 새로 제시되며, 기간, 태그 선택, 웹 선택과 장소 선택은 그대로 유지한다. 입력 초점은 제목 입력으로 옮긴다.

이어서 메모가 추가되었음을 안내한다.

사용자는 화면을 떠나지 않고 다음 메모를 이어서 추가할 수 있으며, 같은 기간, 같은 태그, 같은 웹 항목과 같은 장소의 메모를 여러 번 이어서 추가할 수 있다.

### 제목 미입력

사용자가 제목을 입력하지 않았거나 공백만 입력한 상태에서 메모 추가를 실행하면 메모가 추가되지 않는다.

이때 제목 입력을 요청하는 안내를 표시한다.

입력 중이던 내용은 지워지지 않고 입력 초점은 제목 입력으로 옮겨지므로, 사용자는 제목을 바로 입력한 뒤 다시 시도할 수 있다.

## domain

### 메모 추가 성립 조건

메모는 제목을 가져야 추가할 수 있다.

제목이 비어 있거나 공백 문자로만 이루어져 있으면 제목이 없는 것으로 보고 메모를 추가하지 않는다.

### 추가되는 메모의 초기 상태

추가되는 메모는 다른 메모와 겹치지 않는 고유 식별자를 새로 부여받는다.

추가 시점의 메모는 완료되지 않은 상태이며, 삭제되지 않은 상태다.

메모에는 추가된 시점이 생성 시각과 수정 시각으로 함께 기록된다.

메모에는 사용자가 입력한 설명과 컬러가 함께 기록된다. 설명을 입력하지 않으면 빈 설명으로 기록되고, 컬러를 바꾸지 않으면 화면이 처음 제시한 무작위 컬러가 기록된다.

### 메모의 기간

메모는 기간을 가질 수 있으며, 기간이 없는 메모도 허용된다.

기간은 날짜 단위의 종일 기간이거나, 날짜와 시각(시·분) 단위의 날짜·시간 기간이다. 두 형태 모두 시작과 종료로 이루어지며, 시작은 종료보다 늦지 않다.

기간을 사용하고 선택한 상태로 메모를 추가하면 선택한 기간이 종일 여부와 함께 메모에 기록된다. 기간을 사용하지 않는 상태로 추가하면 메모는 기간 없이 기록된다.

### 기간 선택의 시작 상태

MemoHome, TagDetail 메모 탭과 ContactDetail·PlaceDetail·WebDetail 메모 탭에서 MemoAdd 화면에 진입하면 기간이 선택되지 않은 상태로 시작한다.

캘린더 홈 화면이나 황금연휴 화면에서 기간을 선택해 진입하면 선택한 기간을 종일 기간의 초기값으로 사용한다. 사용자는 제시된 기간을 자유롭게 바꾸거나 기간 사용을 해제해 기간 없는 메모로 추가할 수 있다.

### 태그 선택과 메모 추가 성립 조건

선택할 수 있는 태그의 기준과 선택 여부의 판정, 대표 태그 지정 기준은 [메모 태그 입력 컴포넌트 스펙](./memo-tag-input.md)의 `domain`을 따른다.

MemoAdd 화면에서 선택한 것으로 표시하는 태그는 선택할 수 있는 태그와 같다. 아직 저장되지 않은 메모의 선택이므로 사용자가 지금 선택할 수 있는 태그만 표시하며, 완료되거나 삭제된 태그는 선택한 것으로 표시하지 않는다.

태그를 선택하지 않아도 메모를 추가할 수 있다. 태그 선택과 대표 태그 지정은 메모 추가 성립 조건이 아니다.

### 태그 선택의 시작 상태

MemoHome과 ContactDetail·PlaceDetail·WebDetail 메모 탭에서 MemoAdd 화면에 진입하면 선택한 태그와 대표 태그가 없는 상태로 시작한다.

TagDetail 메모 탭에서 MemoAdd 화면으로 이동할 때는 상세 대상 태그를 선택 태그와 대표 태그의 초기값으로 사용한다.

자동으로 선택된 대상 태그도 다른 선택 태그와 동일하게 선택할 수 있는 태그를 기준으로 표시하고 선택 가능 여부를 판정한다.

### 추가되는 메모의 태그

메모를 추가하면 추가 시점에 선택한 태그가 그 메모와 연결되고, 대표 태그로 지정한 태그가 그 메모의 대표 태그로 기록된다.

연결되는 태그와 대표 태그는 사용자가 선택한 그대로다. 선택한 뒤 태그가 완료되거나 삭제되어 태그 입력이 선택에서 제외된 것으로 표시하고 있어도, 추가 시점에 그 선택을 다시 판정하지 않고 그대로 연결한다.

선택한 태그가 없으면 연결된 태그 없이 메모가 추가되고, 대표 태그를 지정하지 않았으면 대표 태그 없이 메모가 추가된다.

메모와 태그의 연결 규칙은 [메모 태그 스펙](./memo-tag.md)을, 대표 태그 규칙은 [메모 대표 태그 스펙](./memo-primary-tag.md)을 따른다.

### 웹 선택과 메모 추가 성립 조건

선택할 수 있는 웹 항목의 기준과 선택 여부의 판정은 [메모 웹 입력 컴포넌트 스펙](./memo-web-input.md)의 `domain`을 따른다.

MemoAdd 화면에서 선택한 것으로 표시하는 웹 항목은 사용자가 선택한 웹 항목 중 선택할 수 있는 웹 항목 기준을 만족하는 웹 항목이다. 아직 저장되지 않은 메모의 선택이므로 사용자가 지금 선택할 수 있는 웹 항목만 표시하며, 삭제된 웹 항목은 선택한 것으로 표시하지 않는다.

선택한 것으로 표시하는 웹 항목은 사용자가 웹 선택 목록을 얼마나 확인했는지와 관계없이 정해진다.

웹 항목을 선택하지 않아도 메모를 추가할 수 있다. 웹 선택은 메모 추가 성립 조건이 아니다.

### 웹 선택의 시작 상태

MemoAdd 화면에 진입하면 선택한 웹 항목이 없는 상태로 시작한다.

WebDetail 메모 탭에서 MemoAdd 화면으로 이동할 때는 그 탭의 상세 대상 웹 항목을 선택 웹 항목의 초기값으로 사용한다. 자동으로 선택된 대상 웹 항목도 다른 선택 웹 항목과 동일하게 선택할 수 있는 웹 항목을 기준으로 표시하고 선택 가능 여부를 판정하므로, 삭제된 대상 웹 항목은 선택되지 않은 상태로 시작한다.

### 추가되는 메모의 웹 항목

메모를 추가하면 추가 시점에 선택한 웹 항목이 그 메모와 연결된다.

연결되는 웹 항목은 사용자가 선택한 그대로다. 선택한 뒤 웹 항목이 삭제되어 웹 입력이 선택에서 제외된 것으로 표시하고 있어도, 추가 시점에 그 선택을 다시 판정하지 않고 그대로 연결한다.

선택한 웹 항목이 없으면 연결된 웹 항목 없이 메모가 추가된다.

메모와 웹 항목의 연결 규칙은 [메모 웹 스펙](./memo-web.md)을 따른다.

### 진행 상태 유지

화면이 회전하거나 창 크기가 바뀌어 화면 구성이 변경되어도 선택한 태그와 대표 태그 지정, 선택한 웹 항목, 선택한 연락처, 선택한 장소는 유지된다.

시스템이 앱을 메모리에서 정리한 뒤 화면을 복원하거나, 앱을 종료한 뒤 MemoAdd 화면에 새로 진입하면 이전에 선택했던 태그와 대표 태그 지정, 웹 선택, 연락처 선택, 장소 선택은 복원하지 않는다. MemoHome에서 새로 진입하면 선택이 없는 상태로 시작하고, TagDetail 메모 탭에서 새로 진입하면 해당 탭의 상세 대상 태그를 선택하고 대표 태그로 지정한 상태로 시작하며, ContactDetail·PlaceDetail·WebDetail 메모 탭에서 새로 진입하면 해당 탭의 상세 대상 연락처, 장소 또는 웹 항목만 선택된 상태로 시작한다.

캘린더 홈 화면이나 황금연휴 화면에서 MemoAdd 화면에 진입하거나 같은 경로를 복원하면 그 진입에 전달된 기간을 종일 기간의 초기값으로 사용한다.

## data

### 메모 생성과 저장

사용자가 유효한 제목으로 메모 추가를 실행하면 새 메모와 현재 사용자 계정의 연결이 함께 저장된다. 기간을 선택했으면 기간도 함께 저장된다.

선택한 태그가 있으면 메모와 그 태그의 연결도 함께 저장된다. 대표 태그로 지정한 태그는 메모의 값으로 함께 저장된다. 선택한 웹 항목이 있으면 메모와 그 웹 항목의 연결도, 선택한 연락처가 있으면 메모와 그 연락처의 연결도, 선택한 장소가 있으면 메모와 그 장소의 연결도 함께 저장된다.

메모, 계정과의 연결, 태그와의 연결, 웹 항목과의 연결, 연락처와의 연결, 장소와의 연결을 하나의 저장 작업으로 함께 반영하고 이미 같은 식별자의 메모가 있으면 덮어쓰는 흐름은 [항목 추가 화면 공통 스펙](./entity-add.md)의 `생성과 저장`을 따른다.

### 태그 목록 조회

태그 입력에 표시할 태그를 조회하는 흐름은 [메모 태그 입력 컴포넌트 스펙](./memo-tag-input.md)의 `태그 목록 조회`를 따른다.

메모를 추가할 때 함께 연결할 태그는 조회 결과가 아니라 사용자가 선택한 태그를 기준으로 정한다. 사용자가 태그 선택 목록을 얼마나 확인했는지도 연결되는 태그에 영향을 주지 않는다.

### 웹 목록 조회

웹 입력에 표시할 웹 항목을 조회하는 흐름은 [메모 웹 입력 컴포넌트 스펙](./memo-web-input.md)의 `웹 목록 조회`를 따른다. MemoAdd 화면은 현재 선택 상태를 사용자가 선택한 웹 항목의 식별자로 조회해 표시하며, 선택한 웹 항목이 없으면 이 조회를 하지 않는다.

메모 추가를 실행할 때 함께 저장할 웹 항목은 조회 결과가 아니라 사용자가 선택한 웹 항목을 기준으로 정한다. 이 조회는 선택 상태의 표시에만 사용한다.

### 연락처 목록 조회

연락처 입력에 표시할 연락처를 조회하는 흐름은 [메모 연락처 입력 컴포넌트 스펙](./memo-contact-input.md)의 `연락처 목록 조회`를 따른다. MemoAdd 화면은 현재 선택 상태를 사용자가 선택한 연락처의 식별자로 조회해 표시하며, 선택한 연락처가 없으면 이 조회를 하지 않는다.

### 장소 목록 조회

장소 카드에 표시할 장소를 조회하는 흐름은 [메모 장소 카드 컴포넌트 스펙](./memo-place-card.md)의 `장소 목록 조회`를 따른다. MemoAdd 화면은 현재 선택 상태를 사용자가 선택한 장소의 식별자로 조회해 표시하며, 선택한 장소가 없으면 이 조회를 하지 않는다.

### 저장 결과의 표시

MemoAdd 화면은 저장된 메모 자체를 화면에 나열하지 않는다.

추가된 메모는 메모 목록 화면에서 조회되어 표시된다.
