# 공휴일 로컬 캐시 스펙

이 문서는 국가·연도별 공휴일 데이터의 로컬 저장과 조회를 다룬다. 사용자에게 직접 노출되는 화면이나 사용자 행동은 없으므로 `feature` 영역은 생략한다.

## domain

### 국가·연도별 공휴일

공휴일 데이터는 국가와 조회 기준 연도가 같은 것끼리 하나의 묶음으로 관리한다. 국가는 [공휴일 국가 설정 스펙](./holiday-country.md)의 한국과 미국이다.

각 공휴일은 국가, 이름, 공휴일 여부, 시작일부터 종료일까지의 적용 기간을 가진다. 하루만 해당하는 공휴일은 시작일과 종료일이 같은 기간으로 다룬다.

공휴일 여부는 해당 날짜를 공휴일로 강조할 대상인지 구분하는 값이다. 이름은 있으나 공휴일 여부가 거짓인 날은 공휴일로 강조하지 않는다.

## data

### 연도별 캐시 조회

국가 집합과 연도를 정해 공휴일을 조회하면 그 국가들의 해당 연도에 로컬로 저장된 공휴일을 합친 목록을 반환한다.

국가 집합이 비어 있거나 저장된 공휴일이 없으면 빈 목록을 반환한다. 조회 중인 국가·연도의 캐시가 변경되면 변경된 목록을 이어서 제공한다.

목록은 시작일, 종료일, 이름 순으로 정렬한다. 이 셋이 모두 같으면 국가 순으로 정렬한다.

### 전체 캐시 조회

공휴일 설정을 위해 국가 집합을 정해 전체 공휴일을 조회하면 그 국가들의 기기에 저장된 모든 연도의 공휴일 목록을 반환한다.

국가 집합이 비어 있거나 저장된 공휴일이 없으면 빈 목록을 반환한다. 조회 중인 국가의 어느 연도 캐시든 변경되면 최신 목록을 이어서 제공한다.

목록은 이름 순으로 정렬한다.

### 연도별 캐시 교체

특정 국가·연도의 공휴일을 저장하면 기존에 저장된 해당 국가·연도의 공휴일을 모두 제거하고 새 목록으로 교체한다.

빈 목록을 저장하면 해당 국가·연도의 기존 공휴일을 모두 제거한다.

한 국가·연도의 캐시를 교체해도 다른 국가나 다른 연도의 캐시는 유지한다.

교체 작업이 완료되지 못하면 해당 국가·연도의 기존 캐시를 유지한다.
