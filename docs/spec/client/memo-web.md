# 메모 웹 앱 스펙

이 문서는 메모와 웹 항목의 연결 가운데 앱이 기기에 저장된 연결로 메모의 웹 항목과 웹 항목의 메모를 조회하는 규칙과, 이 연결이 앱의 목록과 검색 결과에 주는 영향을 다룬다. 메모와 웹 항목의 연결이 공통으로 지키는 규칙은 [메모 웹 스펙](../common/memo-web.md)을, 연결의 성질과 동기화 계약은 [항목 연결 공통 스펙](../common/entity-link.md)을, 연결을 기기에 저장하는 규칙은 [항목 연결 앱 스펙](./entity-link.md)을 따른다.

사용자가 웹 항목을 고르고 해제하는 조작과 조회 결과를 보여 주는 화면은 각 입력 컴포넌트 스펙과 화면 스펙이 소유하므로 이 문서에는 `feature` 영역을 두지 않는다.

## domain

### 연결된 웹 항목의 정렬

메모를 기준으로 조회한 웹 항목은 제목 오름차순으로 놓인다. 제목이 같은 웹 항목끼리의 순서는 정하지 않는다.

조회에 포함되는 연결과 웹 항목의 기준은 [항목 연결 공통 스펙](../common/entity-link.md)의 `연결된 항목의 조회`를 따른다.

### 연결의 의미

[항목 연결 공통 스펙](../common/entity-link.md)의 `연결의 의미`는 메모와 웹 항목의 연결에서 다음 목록에 적용된다.

- [MemoHome 목록 스펙](./memo-home.md)의 목록 노출 기준과 정렬. 웹 연결 여부는 [태그 필터 스펙](./tag-filter.md)과 MemoHome의 유무 필터 대상도 아니다.
- [WebHome 화면 스펙](./web-home.md)의 목록 노출 기준과 정렬
- [SearchHome 화면 스펙](./search-home.md)의 메모 검색 결과와 웹 검색 결과
- 태그로 메모나 웹 항목을 조회한 결과

웹 항목으로 메모를 조회하는 [WebDetail 메모 탭 스펙](./web-detail-memo.md)의 목록은 이 연결을 노출 기준으로 쓴다.

메모와 웹 항목이 같은 태그와 연결되어 있어도 그것만으로 메모와 웹 항목이 연결되지는 않는다.

## data

### 메모별 웹 항목 표시

메모로 웹 항목을 조회할 때는 현재 사용자 계정과 연결된 웹 항목과 메모-웹 연결만 사용한다. 조회에 포함되는 연결과 웹 항목의 기준은 [항목 연결 공통 스펙](../common/entity-link.md)의 `연결된 항목의 조회`를 따른다.

연결이 만들어지거나 해제되거나 복구되면 그 메모의 웹 항목을 표시하는 화면과 그 웹 항목의 메모를 표시하는 화면은 변경된 연결 상태를 반영한다.

### 웹 항목별 메모 표시

웹 항목으로 메모를 조회할 때는 현재 사용자 계정과 연결된 메모와 메모-웹 연결만 사용한다. 조회에 포함되는 연결과 메모의 기준은 [항목 연결 공통 스펙](../common/entity-link.md)의 `연결된 항목의 조회`를 따르며, 그 위에 더하는 노출 기준과 정렬은 [항목 상세 메모 탭 공통 스펙](./entity-detail-memo.md)이 정한다.
