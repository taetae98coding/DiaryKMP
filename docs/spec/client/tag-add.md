# TagAdd 화면 스펙

이 문서는 사용자가 새 태그를 작성해 추가하는 TagAdd 화면의 내용과 행동을 다룬다. 목록의 노출 기준은 [TagHome 목록 스펙](./tag-home.md)에서, 설명과 컬러 입력의 행동은 [설명 입력 컴포넌트 스펙](./description-input.md)과 [컬러 입력 컴포넌트 스펙](./diary-color-input.md)에서 다룬다. 제목 입력 자체의 동작은 [제목 입력 스펙](./title-input.md)을 따른다.

작성 상태 유지, 뒤로가기, 추가 요청 제한, 계정 연결과 저장 계약은 [항목 추가 화면 공통 스펙](./entity-add.md)을 따른다. 연결할 태그의 선택과 해제, 선택 목록의 행동과 정책은 [태그 연결 입력 컴포넌트 스펙](./tag-link-input.md)을 따르고, 태그와 태그의 연결 규칙은 [태그 연결 스펙](../common/tag-link.md)을 따른다. 이 문서에서는 TagAdd 화면에서만 다른 시작 상태와 추가 결과를 다룬다.

디자인: [TagAdd 화면 디자인](../../design/tag-add.md)

## feature

### 진입과 입력

사용자는 TagHome 화면에서 태그 추가를 선택해 TagAdd 화면으로 이동한다.

메모나 캘린더의 태그 필터에서 태그 추가를 선택해서도 TagAdd 화면으로 이동한다. 태그 입력과 태그 선택 목록에서 태그 추가로 이동하는 경우에도 TagAdd 화면으로 이동하며, 그 진입 경로와 돌아왔을 때의 결과는 [태그 선택 입력 공통 스펙](./tag-select-input.md)의 `태그 추가 이동`을 따른다. 태그 목록에서 진입하지 않은 TagAdd 화면은 태그 목록과 함께 표시하지 않는다.

TagAdd 화면의 연결 입력에서 다시 태그 추가로 이동하면 TagAdd 화면이 하나 더 열린다. 두 화면은 각각 자기 입력 내용, 고른 연결과 추가 결과를 따로 가지며, 뒤에 연 화면에서 돌아오면 먼저 있던 화면의 입력 내용은 이동하기 전 그대로다.

사용자는 태그 이모지, 제목, 설명과 컬러를 입력하거나 바꿀 수 있다. 제목은 한 줄 분량을 입력할 수 있고, 이모지는 문자 하나만 입력할 수 있다.

화면에 처음 진입하면 무작위 컬러가 초기값으로 제시된다. 사용자가 바꾸지 않으면 제시된 컬러를 사용한다. 사용자가 제목부터 바로 입력할 수 있도록 입력 초점을 제목 입력에 한 번 두고, 이모지 입력에는 두지 않는다.

사용자는 추가할 태그가 연결할 태그를 함께 고를 수 있다.

### 태그 연결 입력

태그 선택 목록에서의 연결과 해제는 [태그 연결 입력 컴포넌트 스펙](./tag-link-input.md)을 따르고, 연결 입력의 구성과 표현은 [태그 연결 입력 컴포넌트 디자인](../../design/tag-link-input.md)을 따른다.

TagAdd 화면에서 사용자가 반영한 연결은 추가할 태그의 연결 대상으로만 반영되며, 저장된 태그의 연결을 바꾸지 않는다. 선택한 태그가 실제로 연결되는 시점은 사용자가 태그 추가를 실행할 때다.

TagAdd 화면에 진입하면 연결할 태그를 하나도 고르지 않은 상태로 시작한다.

### 연결 입력의 태그 추가 이동

TagAdd 화면의 연결 입력에서 태그 추가로 이동해 열린 TagAdd 화면에서 태그를 추가하고 돌아오면, 추가한 태그가 이 화면의 연결 대상으로 선택된다. 이 자동 선택은 [태그 선택 입력 공통 스펙](./tag-select-input.md)의 `추가한 태그의 자동 선택`을 따른다.

이 화면에서 실행한 태그 추가로 만들어진 태그는 이 화면의 연결 대상으로 선택되지 않는다. 추가에 성공하면 이 화면은 다음 태그를 위해 고른 연결까지 비우므로, 방금 추가한 태그를 다음 태그의 연결 대상으로 삼지 않는다.

### 태그 추가 결과를 돌려줄 곳

태그를 추가하면 이 화면을 연 태그 입력에만 그 결과를 돌려준다. 한 화면에서 태그를 여러 개 추가하면 추가한 태그를 모두 돌려준다.

태그 목록이나 태그 필터처럼 태그 입력이 아닌 곳에서 연 TagAdd 화면은 결과를 돌려줄 곳이 없으므로 아무 곳에도 돌려주지 않는다. 이때 추가한 태그는 나중에 여는 다른 화면의 태그 입력에도 선택된 것으로 나타나지 않는다.

### 태그 추가

사용자는 입력한 내용으로 태그 추가를 실행할 수 있다.

입력한 이모지, 제목, 설명, 컬러와 고른 연결은 태그 추가를 실행할 때만 저장된다. 입력하는 동안에는 저장하지 않으며, 추가하지 않고 화면을 떠나면 입력한 내용은 저장되지 않고 사라진다.

태그 추가를 처리하는 동안에는 진행 상태를 표시한다.

추가에 성공하면 화면을 유지한 채 이모지, 제목과 설명을 비우고 고른 연결도 함께 비우며, 다음 태그를 위한 무작위 컬러를 새로 제시한다. 사용자가 다음 태그 입력을 바로 이어갈 수 있도록 입력 초점을 제목 입력으로 옮기고 성공 피드백을 제공한다.

### 제목 미입력

제목이 비어 있거나 공백만 있는 상태에서 추가를 실행하면 태그를 추가하지 않고 제목 입력이 필요하다는 피드백을 제공한다.

입력 중이던 이모지, 설명, 컬러와 고른 연결은 유지하고 입력 초점을 제목 입력으로 옮기므로, 사용자는 제목을 바로 입력한 뒤 다시 시도할 수 있다.

### 작성 상태 유지 대상

[항목 추가 화면 공통 스펙](./entity-add.md)의 `작성 상태 유지`가 유지하는 대상은 입력 중이던 이모지, 제목, 설명, 선택한 컬러와 고른 연결이다.

시스템이 앱을 메모리에서 정리한 뒤 화면을 복원하면 고른 연결은 복원하지 않고 연결을 하나도 고르지 않은 상태로 시작한다.

## domain

### 태그 추가 성립 조건

태그는 제목을 가져야 추가할 수 있다. 제목이 비어 있거나 공백 문자로만 이루어져 있으면 추가하지 않는다.

이모지와 설명은 비어 있어도 태그를 추가할 수 있다.

### 태그 이모지

태그 이모지는 태그를 한눈에 알아보게 하는 문자 하나다.

이모지는 사용자에게 보이는 문자 하나까지만 가진다. 여러 문자를 입력하면 마지막 문자 하나만 남기고 나머지는 버리므로, 이미 문자가 있는 상태에서 새로 입력하면 새로 입력한 문자가 기존 문자를 대체한다. 여러 코드가 모여 하나로 보이는 이모지는 그 전체를 문자 하나로 본다.

입력할 수 있는 문자를 이모지로 제한하지 않는다. 사용자가 이모지가 아닌 문자를 입력하면 그 문자를 그대로 사용한다.

### 연결 대상 선택과 태그 추가 성립 조건

선택할 수 있는 태그의 기준과 연결 여부의 판정은 [태그 연결 입력 컴포넌트 스펙](./tag-link-input.md)의 `domain`을 따른다.

TagAdd 화면에서 연결 대상으로 표시하는 태그는 선택할 수 있는 태그와 같다. 아직 저장되지 않은 태그의 연결이므로 사용자가 지금 선택할 수 있는 태그만 표시하며, 완료되거나 삭제된 태그는 연결 대상으로 표시하지 않는다.

추가할 태그는 아직 저장되지 않아 출발 태그가 정해지지 않았으므로, 선택할 수 있는 태그에서 제외하는 태그도 없다.

태그를 하나도 연결하지 않아도 태그를 추가할 수 있다. 연결 대상 선택은 태그 추가 성립 조건이 아니다.

### 추가되는 태그의 연결

태그를 추가하면 추가 시점에 고른 태그를 도착 태그로 하고 새 태그를 출발 태그로 하는 단방향 연결이 함께 만들어진다. 연결의 규칙과 기록되는 내용은 [태그 연결 스펙](../common/tag-link.md)을 따른다.

연결되는 태그는 사용자가 고른 그대로다. 고른 뒤 태그가 완료되거나 삭제되어 연결 입력이 제외된 것으로 표시하고 있어도, 추가 시점에 그 선택을 다시 판정하지 않고 그대로 연결한다.

태그를 하나도 고르지 않았으면 연결 없이 태그가 추가된다.

### 추가되는 태그의 내용

기록되는 공통 값은 [항목 추가 화면 공통 스펙](./entity-add.md)의 `추가되는 항목의 내용`을 따른다.

태그에는 사용자가 입력한 이모지, 제목, 설명과 컬러를 기록한다. 이모지나 설명을 입력하지 않으면 빈 값으로 기록하고, 컬러를 바꾸지 않으면 처음 제시한 무작위 컬러를 기록한다.

## data

### 태그 생성과 저장

저장 흐름은 [항목 추가 화면 공통 스펙](./entity-add.md)의 `생성과 저장`을 따른다. 이때 함께 반영되는 것은 새 태그, 현재 사용자 계정의 연결, 그리고 새 태그에서 고른 태그로 향하는 연결이다.

### 저장 결과의 표시

저장된 태그는 [TagHome 목록 스펙](./tag-home.md)의 노출 기준과 정렬 기준에 따라 목록에 반영된다.

저장된 연결은 그 태그의 [TagDetail 화면](./tag-detail.md) 연결 입력에 반영된다.

### 태그 목록 조회

연결 입력에 표시할 태그를 조회하는 흐름은 [태그 연결 입력 컴포넌트 스펙](./tag-link-input.md)의 `태그 목록 조회`를 따른다.

태그를 추가할 때 함께 연결할 태그는 조회 결과가 아니라 사용자가 고른 태그를 기준으로 정한다. 사용자가 태그 선택 목록을 얼마나 확인했는지도 연결되는 태그에 영향을 주지 않는다.
