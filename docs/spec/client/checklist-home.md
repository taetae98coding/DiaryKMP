# ChecklistHome 화면 스펙

이 문서는 `더보기`의 `체크리스트` 바로가기로 진입하는 ChecklistHome 화면의 내용과 행동을 다룬다. 항목 목록 화면이 공통으로 따르는 노출 기준, 목록 갱신과 조회, 추가·상세로 이동, 목록에서의 삭제와 실행 취소, 화면 유지는 [항목 목록 화면 공통 스펙](./entity-home.md)를 따르며, 이 문서에는 체크리스트 목록에만 있는 내용을 둔다. 바로가기 항목의 표시와 선택은 [MoreHome 화면 스펙](./more-home.md)에서, 체크리스트를 작성해 추가하는 흐름과 체크리스트·체크 항목이 갖는 정보는 [ChecklistAdd 화면 스펙](./checklist-add.md)에서, 저장한 체크리스트의 항목을 체크하고 관리하는 흐름은 [ChecklistDetail 화면 스펙](./checklist-detail.md)에서, 체크리스트 목록과 상세를 함께 사용하는 배치는 [Checklist 목록·상세 배치 스펙](./checklist-list-detail.md)에서, 목록 카드에서 삭제를 실행하는 상호작용의 공통 규칙은 [SwipeToFinishAndDelete 컴포넌트 스펙](./swipe-to-finish-and-delete.md)에서, 나누어 불러오는 목록이 나타나는 순서와 아직 준비되지 않은 자리의 처리는 [페이지 조회 목록의 자리 표시 스펙](./paged-list-placeholder.md)에서, 목록이 비어 있을 때의 안내는 [목록 빈 상태 스펙](./list-empty-state.md)에서, 목록을 당겨 새로고침하는 행동과 동기화 진행 표시는 [새로고침 스펙](./sync-refresh.md)에서, 체크리스트를 서버와 맞추는 규칙은 [데이터 동기화 스펙](../common/data-sync.md)에서 다룬다.

디자인: [ChecklistHome 화면 디자인](../../design/checklist-home.md)

이번 범위는 `더보기`에서 ChecklistHome으로 이동하고, 계정에 저장된 체크리스트를 기기에서 불러와 목록으로 표시하고, 목록을 당겨 새로고침하고, ChecklistHome에서 체크리스트 추가로 이동하고, 목록에서 체크리스트를 선택해 상세로 이동하고, 목록에서 체크리스트를 삭제하고 되돌리는 것까지다. 목록의 정렬 선택은 이번 범위에서 다루지 않는다.

## feature

### 진입

사용자는 `더보기` 화면의 `체크리스트` 바로가기를 선택해 이 화면으로 이동한다.

### 화면 내용

사용자는 화면에서 자신이 `체크리스트` 기능으로 들어왔음을 알 수 있는 제목을 확인한다. 제목은 `더보기`에서 고른 바로가기 항목과 같은 이름을 쓴다.

화면에는 제목, 뒤로가기, 체크리스트 목록과 체크리스트 추가만 둔다.

### 체크리스트 목록

사용자는 ChecklistHome에서 계정에 저장된 체크리스트 전체를 목록으로 볼 수 있다. 사용자는 각 항목에서 그 체크리스트의 제목과 진행 정도를 확인한다. 진행 정도는 `domain > 진행 정도`가 정한 체크한 항목 수와 전체 항목 수다.

체크리스트의 설명과 체크 항목의 내용은 목록에 표시하지 않는다. 목록에서는 어떤 체크리스트인지 알아보는 데 필요한 제목과, 얼마나 끝냈는지 한눈에 볼 수 있는 진행 정도만 보여 준다.

목록이 나타나는 순서, 아직 준비되지 않은 자리와 추가한 체크리스트가 목록에 나타나는 조건은 [항목 목록 화면 공통 스펙](./entity-home.md)의 `목록 표시`를 따른다.

사용자는 목록의 체크리스트를 선택해 그 체크리스트의 [ChecklistDetail 화면](./checklist-detail.md)으로 이동한다. 준비되지 않은 자리와 돌아왔을 때의 목록은 [항목 목록 화면 공통 스펙](./entity-home.md)의 `상세로 이동`을 따르며, 상세에서 체크한 결과도 반영된 목록을 본다.

목록과 상세를 함께 사용하는 환경에서는 이동하지 않고 상세 영역이 그 체크리스트의 상세로 바뀌며, 그 기준은 [Checklist 목록·상세 배치 스펙](./checklist-list-detail.md)의 `상세 영역의 구성`을 따른다.

### 빈 상태

목록 불러오기가 끝났고 `domain`의 `목록에 노출하는 체크리스트`에 맞는 체크리스트가 하나도 없으면 목록 자리에 아직 체크리스트가 없으며 새로 추가할 수 있음을 알린다. 불러오는 중에는 빈 상태 대신 [페이지 조회 목록의 자리 표시 스펙](./paged-list-placeholder.md)의 자리 표시를 보여 준다. 판정 시점, 빈 상태에서 할 수 있는 행동, 목록과의 전환은 [목록 빈 상태 스펙](./list-empty-state.md)을 따른다.

빈 상태에서도 사용자는 체크리스트 추가와 당겨서 새로고침을 그대로 실행할 수 있다.

### 새로고침

목록을 당겨 새로고침하는 행동과 결과는 [항목 목록 화면 공통 스펙](./entity-home.md)의 `새로고침`을 따른다. 새로고침으로 내려받은 체크 항목도 별도 조작 없이 진행 정도에 반영된다.

### 체크리스트 추가로 이동

사용자는 체크리스트 추가를 선택해 [ChecklistAdd 화면](./checklist-add.md)으로 이동한다. 체크리스트 추가는 모든 플랫폼에서 제공한다. 언제 제공하는지, 추가 단축키, 목록과 상세를 함께 사용하는 동안의 추가 수단과 돌아왔을 때의 결과는 [항목 목록 화면 공통 스펙](./entity-home.md)의 `추가로 이동`을 따른다.

### 삭제

사용자는 목록의 체크리스트를 삭제할 수 있다. 체크리스트에는 완료 여부가 없으므로 삭제 방향만 제공하며, 삭제와 실행 취소의 결과는 [항목 목록 화면 공통 스펙](./entity-home.md)의 `삭제`를 따른다. 실행 취소로 돌아온 체크리스트는 삭제하기 전의 체크 항목과 체크 상태를 그대로 가진다.

### 안내와 실행 취소

삭제의 안내와 실행 취소는 [항목 목록 화면 공통 스펙](./entity-home.md)의 `안내와 실행 취소`를 따른다. [ChecklistDetail 화면 스펙](./checklist-detail.md)의 삭제가 여기에 해당하는 상세 화면의 삭제다.

### 뒤로가기

뒤로가기의 결과는 [항목 목록 화면 공통 스펙](./entity-home.md)의 `뒤로가기`를 따르며, 상세 영역과 함께 표시되는 상태에서의 결과는 [Checklist 목록·상세 배치 스펙](./checklist-list-detail.md)의 `뒤로가기`를 따른다.

## domain

### 목록에 노출하는 체크리스트

노출 기준은 [항목 목록 화면 공통 스펙](./entity-home.md)의 `목록에 노출하는 항목`을 따른다. 체크리스트에는 더하는 상태 조건이 없다.

### 진행 정도

진행 정도의 전체 항목 수는 그 체크리스트에 속하고 현재 사용자 계정과 연결되어 있으며 삭제되지 않은 체크 항목의 수이고, 체크한 항목 수는 그중 체크된 항목의 수다. 삭제된 체크 항목은 어느 쪽에도 세지 않는다.

체크 항목이 하나도 없으면 진행 정도는 0개 중 0개로 보인다.

### 목록 정렬

목록은 제목 오름차순으로 정렬한다. 제목이 같은 체크리스트끼리의 순서는 정하지 않는다. 사용자가 고를 수 있는 다른 정렬은 없다. 진행 정도는 정렬에 영향을 주지 않는다.

### 목록 갱신

목록의 자동 갱신은 [항목 목록 화면 공통 스펙](./entity-home.md)의 `목록 갱신`을 따른다. 체크 항목이 추가되거나 삭제되거나 체크 상태가 바뀌면 그 체크리스트의 진행 정도도 자동 갱신하며, 서버에서 내려받은 체크 항목이 기기에 반영된 것도 같다.

### 삭제와 실행 취소의 상태 전이

목록의 삭제와 실행 취소는 [항목 목록 화면 공통 스펙](./entity-home.md)의 `삭제와 실행 취소의 상태 전이`를 따른다. 제목, 설명과 체크 항목은 바꾸지 않으며, 체크 항목의 삭제 여부, 체크 여부와 수정 시각도 바꾸지 않는다.

### 화면 유지

목록 위치의 유지는 [항목 목록 화면 공통 스펙](./entity-home.md)의 `화면 유지`를 따른다.

## data

### 삭제와 실행 취소의 저장

삭제와 실행 취소의 저장과 동기화는 [항목 목록 화면 공통 스펙](./entity-home.md)의 `삭제와 실행 취소의 저장`을 따른다. 체크 항목은 기기에서 지우지 않는다.

### 목록 조회

목록의 조회, 조회 실패와 서버에서 다시 가져오는 계기는 [항목 목록 화면 공통 스펙](./entity-home.md)의 `목록 조회`를 따른다. 각 체크리스트의 진행 정도는 기기에 저장된 그 체크리스트의 체크 항목으로 함께 세며, 체크 항목이 바뀌어도 조회 결과가 갱신된다.
