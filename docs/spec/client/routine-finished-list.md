# RoutineFinishedList 화면 스펙

이 문서는 사용자가 RoutineHome의 목록 보기에서 완료된 루틴을 모아 확인하는 RoutineFinishedList 화면 가운데 이 화면에만 해당하는 부분을 다룬다. 진입과 이동, 내용 갱신, 새로고침, 불러오기 실패, 빈 상태, 추가 미제공, 상세 확인, 다시 시작과 삭제, 노출 기준과 실행 경계의 공통 규칙은 [완료 목록 공통 스펙](./finished-list.md)을 따른다. 이 화면의 짝이 되는 목록은 [RoutineHome 화면](./routine-home.md)의 목록 보기에 놓인 루틴 목록이다.

루틴 카드의 내용은 [RoutineHome 화면 스펙](./routine-home.md)의 `루틴 목록`을, 카드 문구와 목록 순서의 계산은 [루틴 앱 스펙](./routine.md)을 따르고, 다시 시작과 삭제의 상태 전이는 이 문서의 `domain > 다시 시작과 삭제의 상태 전이`가 정한다. 다시 시작·삭제 상호작용의 공통 규칙은 [SwipeToFinishAndDelete 컴포넌트 스펙](./swipe-to-finish-and-delete.md)을, 상세 확인은 [RoutineDetail 화면 스펙](./routine-detail.md)을 따른다. 태그 하나에 연결된 완료된 루틴만 모아 확인하는 화면은 [TagRoutineFinishedList 화면 스펙](./tag-routine-finished-list.md)에서 다룬다. 목록과 루틴 상세를 함께 사용할 때의 선택 상태와 뒤로가기는 [RoutineFinishedList 목록·상세 배치 스펙](./routine-finished-list-detail.md)에서 다룬다.

디자인: [RoutineFinishedList 화면 디자인](../../design/routine-finished-list.md)

## feature

### 진입과 이동

사용자는 RoutineHome의 목록 보기에서 완료된 루틴 확인을 선택해 이 화면으로 이동한다. 진입 동작의 제공 조건은 [RoutineHome 화면 스펙](./routine-home.md)의 `완료된 루틴 확인`을 따른다.

사용자가 뒤로가면 RoutineHome의 목록 보기로 돌아간다.

### 목록 표시

사용자는 각 카드에서 루틴의 제목과 카드 문구를 확인하고, 카드는 루틴의 컬러로 서로 구분해 보여 준다. 이 목록의 루틴은 모두 완료된 루틴이므로 카드 문구는 [루틴 앱 스펙](./routine.md)의 `카드 문구`에 따라 `완료`이며, 이번 주기의 합계와 달성률은 보여 주지 않는다.

카드에는 [RoutineHome 화면 스펙](./routine-home.md)의 `빠른 기록`을 제공하지 않는다. 완료된 루틴의 기록은 루틴을 선택해 이동한 [RoutineDetail 화면](./routine-detail.md)의 `기록 넣기`로 넣는다.

루틴의 설명, 시작 날짜, 주기, 단위, 목표량, 한 번에 기록할 양과 연결한 태그는 목록에 표시하지 않는다.

### 빈 상태 문구

완료된 루틴이 하나도 없을 때 알리는 내용은 [목록 빈 상태 스펙](./list-empty-state.md)의 `빈 상태에서 알리는 내용`을 따른다.

### 태그 필터 미적용

이 화면에는 태그 필터를 제공하지 않는다.

사용자가 RoutineHome에서 선택한 태그 필터와 보기 범위는 이 목록의 루틴 노출에 영향을 주지 않는다. 따라서 사용자는 필터를 어떻게 선택해 두었는지와 관계없이 완료된 루틴 전체를 확인한다.

### 보기 전환 미제공

이 화면에는 목록만 두며, RoutineHome의 달력 보기와 보기 전환을 제공하지 않는다. 완료된 루틴의 기록은 [RoutineHome 화면 스펙](./routine-home.md)의 `달력의 루틴 기록`에 따라 RoutineHome의 달력 보기에서 확인한다.

### 정렬 선택 미제공

이 화면에는 [완료 목록 공통 스펙](./finished-list.md)의 `정렬 선택`을 제공하지 않는다. 짝이 되는 RoutineHome의 루틴 목록에 사용자가 고르는 정렬이 없기 때문이며, 순서는 `domain > 순서`를 따른다.

### 다시 시작

목록에서 루틴을 다시 시작하거나 삭제한 결과와 안내, 실행 취소는 [완료 목록 공통 스펙](./finished-list.md)의 `다시 시작과 삭제`를 따르고, 바뀌는 상태는 `domain > 다시 시작과 삭제의 상태 전이`가 정한다.

다시 시작한 루틴은 RoutineHome의 루틴 목록에 [루틴 앱 스펙](./routine.md)의 `목록 순서`에 맞는 자리로 다시 나타난다. 그 목록에 실제로 보이는지는 [RoutineHome 화면 스펙](./routine-home.md)의 `보기 범위 기준`과 `태그 필터 기준`을 따른다. 다시 시작과 삭제는 그 루틴의 기록을 바꾸지 않는다. 삭제한 루틴의 기록은 [캘린더 루틴 기록 표시 스펙](./calendar-routine.md)의 `노출 기준`에 따라 달력에 보이지 않는다.

### 내용 갱신과 새로고침

목록의 갱신 방식, 당겨서 새로고침과 불러오기 실패의 결과는 [완료 목록 공통 스펙](./finished-list.md)의 `내용 갱신`, `새로고침`, `불러오기 실패`를 따른다.

## domain

### 태그 필터와 노출 기준

태그 필터 선택과 보기 범위 선택은 [완료 목록 공통 스펙](./finished-list.md)의 `노출 기준`에 넣지 않는다. 완료된 루틴은 되돌아보기 위한 목록이므로 사용자가 RoutineHome에서 좁혀 둔 범위를 그대로 적용하지 않고 전체를 보여 준다.

진행 상태, 오늘의 요일이 하는 요일에 드는지, 목표량이 있는지, 목표를 채웠는지, 기록이 있는지는 노출 기준에 쓰지 않는다. 시작 전인 루틴도 완료되었으면 이 목록에 나타난다.

### 순서

목록은 [루틴 앱 스펙](./routine.md)의 `목록 순서`에 따라 진행 중, 시작 전 순으로 놓고, 진행 상태가 같은 루틴끼리는 제목 오름차순으로 놓는다. RoutineHome의 루틴 목록과 같은 순서이며, 완료한 시점은 순서에 쓰지 않는다. 사용자가 고를 수 있는 다른 정렬은 없다.

따라서 [완료 목록 공통 스펙](./finished-list.md)의 `정렬`과 `실행 경계`가 정렬 선택에 대해 정한 내용은 이 화면에 해당하지 않는다. 보던 자리의 유지는 그 문서의 `실행 경계`를 그대로 따른다.

### 오늘

진행 상태를 정해 순서에 쓰는 오늘은 [루틴 앱 스펙](./routine.md)의 `오늘`이다. 오늘은 이 화면에 들어오거나 다른 화면이나 다른 앱에서 이 화면으로 돌아올 때마다 다시 정하고, 화면을 보는 동안 자정이 지나도 다시 정하지 않는다. 기준은 [RoutineHome 화면 스펙](./routine-home.md)의 `오늘 기준`과 같다.

오늘이 바뀌어 진행 상태가 달라진 루틴은 바뀐 상태의 자리로 옮겨진다. 카드 문구는 오늘과 관계없이 `완료`다.

### 다시 시작과 삭제의 상태 전이

다시 시작은 루틴의 완료 여부를 미완료 상태로 바꾸는 것이고, 삭제는 삭제 여부를 삭제 상태로 바꾸는 것이다. 두 동작 모두 루틴 자체를 지우지 않는다.

실행 취소는 직전에 바꾼 상태를 원래 상태로 되돌린다. 다시 시작의 실행 취소는 완료 여부를 완료로, 삭제의 실행 취소는 삭제 여부를 미삭제로 되돌린다.

다시 시작, 삭제와 실행 취소는 모두 루틴의 수정 시각을 동작 시점으로 갱신한다.

다시 시작과 삭제는 루틴의 제목, 설명, 컬러, 시작 날짜, 주기, 단위, 목표량과 한 번에 기록할 양을 바꾸지 않고, 루틴 기록과 태그 연결도 바꾸지 않는다. 그 밖의 기준은 [RoutineHome 화면 스펙](./routine-home.md)의 `완료와 실행 취소의 상태 전이`와 `삭제와 실행 취소의 상태 전이`와 같다.

## data

### 목록 조회

조회 흐름은 [완료 목록 공통 스펙](./finished-list.md)의 `목록 조회`를 따른다. 태그 필터 선택은 조회 조건에 넣지 않으며, 루틴의 제목이나 시작 날짜가 바뀔 때도 목록을 갱신한다.

### 상태 변경의 저장

목록에서 루틴을 다시 시작하거나 삭제하면 현재 사용자 계정과 연결된 해당 루틴의 완료 여부나 삭제 여부가 기기에 즉시 저장되고, 서버에는 [데이터 동기화 스펙](../common/data-sync.md)에 따라 반영된다. 루틴에 속한 기록과 태그 연결은 기기에서 지우지 않고 바꾸지도 않는다.

실행 취소를 선택하면 되돌린 상태가 같은 방식으로 즉시 저장된다.
