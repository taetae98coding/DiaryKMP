# 목록·상세 배치 공통 스펙

이 문서는 목록과 상세를 함께 사용하는 화면들이 공통으로 보장하는 표시 비율 조절 행동, 배치에 참여하는 화면의 기준, 추가 진입 수단의 제공 기준과 유지·초기화 정책을 다룬다. 상세 영역에 어떤 화면을 두는지와 뒤로가기가 어디로 가는지는 화면마다 다르므로 각 배치 스펙에서 다룬다.

이 문서를 따르는 배치 스펙은 다음과 같다.

- [Contact 목록·상세 배치 스펙](./contact-list-detail.md)
- [Memo 목록·상세 배치 스펙](./memo-list-detail.md)
- [Playlist 목록·상세 배치 스펙](./playlist-list-detail.md)
- [Routine 목록·상세 배치 스펙](./routine-list-detail.md)
- [Setting 목록·상세 배치 스펙](./setting-list-detail.md)
- [Tag 목록·상세 배치 스펙](./tag-list-detail.md)
- [TagMemoFinishedList 목록·상세 배치 스펙](./tag-memo-finished-list-detail.md)
- [Web 목록·상세 배치 스펙](./web-list-detail.md)

디자인: [목록·상세 배치 공통 디자인](../../design/list-detail-pane.md)

표시 비율과 상세 선택은 화면 표시 상태일 뿐 사용자 데이터를 만들거나 저장하지 않으므로 `data` 영역은 생략한다.

## feature

### 함께 사용과 단독 사용

목록과 상세를 함께 사용할 수 있는 환경에서는 목록을 유지한 채 상세를 확인한다.

한 영역만 사용하는 환경에서는 목록과 각 상세 화면을 단독으로 사용하며, 화면 사이의 이동은 각 화면 스펙을 따른다.

### 함께 사용할 때의 행동

목록과 상세를 함께 사용하는 동안에는 상세 영역에서 목록으로 돌아가는 별도 동작을 제공하지 않는다.

상세 영역의 화면에서 다른 상세로 이어 이동한 경우 이전 상세로 돌아가는 동작을 제공하는지는 각 화면 스펙이 정한다. 이 동작은 목록으로 돌아가지 않고 상세 영역 안에서만 이동한다.

### 추가 진입 수단

상세 영역에 추가 화면이 이미 놓여 있으면 목록에서 그 추가를 실행하는 수단을 제공하지 않는다. 사용자가 지금 입력할 수 있는 화면을 다시 열도록 안내할 필요가 없기 때문이다.

상세 영역에 추가가 아닌 화면이 놓여 있으면 목록에서 추가를 실행할 수 있고, 실행하면 상세 영역이 추가 화면으로 바뀐다.

한 화면만 사용하는 환경에서는 목록에서 추가를 실행해 그 추가 화면으로 이동한다.

### 표시 비율 조절

목록과 상세를 함께 사용하는 동안 사용자는 두 영역의 표시 비율을 자유롭게 조절할 수 있다.

조절하는 동안 결과를 즉시 확인할 수 있고, 조절을 마치면 해당 비율을 유지한다.

## domain

### 조절 규칙

표시 비율 조절은 목록과 상세를 함께 사용하는 동안에만 가능하다.

사용자는 표시 범위 안에서 자유롭게 비율을 정하며, 정해진 단계나 고정 비율로 제한하지 않는다.

### 배치에 참여하는 화면

상세 영역에는 그 목록에서 이어 진입한 화면만 표시한다. 같은 화면이라도 그 목록이 아닌 곳에서 진입했으면 배치에 참여하지 않고 단독으로 표시한다.

배치에 참여하지 않는 화면은 각 배치 스펙에서 밝힌다.

### 유지와 초기화 기준

상세 선택과 조절한 비율은 사용자가 그 배치를 사용하는 동안 화면 재생성과 백그라운드 복귀 후에도 유지한다.

앱이 백그라운드에 있는 동안 시스템이 앱을 정리했다가 다시 만들어도 상세 선택과 조절한 비율은 떠나기 전 그대로 다시 보인다. 상세 영역에서 그 전에 놓였던 화면으로 되돌아가는 뒤로가기 기록도 함께 남는다.

사용자가 그 배치를 떠났다가 다시 진입하거나 앱을 종료하고 다시 실행하면 상세 선택은 선택 전 상태로, 표시 비율은 기본 비율로 초기화한다.

무엇을 `배치를 떠난 것`으로 보는지는 배치마다 다르므로 각 배치 스펙의 `유지와 초기화 기준`에서 정한다. 다만 어느 배치든 공통 내비게이션에서 다른 주요 목적지로 이동하는 것은 떠난 것으로 본다. 따라서 주요 목적지에 놓인 배치는 다른 주요 목적지에 다녀와 그 목적지로 돌아오면 상세 선택과 표시 비율이 처음 상태로 시작하고, `더보기`의 메뉴에서 진입하는 배치는 여기에 더해 `더보기`로 돌아가는 것도 떠난 것으로 본다. 목적지를 옮길 때 배치 밖의 화면 상태가 어떻게 되는지는 [TopLevelNavigation 스펙](./top-level-navigation.md)의 `목적지 이동과 화면 상태`를 따른다.
