# FileHome 화면 스펙

이 문서는 `더보기`의 `파일` 바로가기로 진입하는 FileHome 화면에서 사용자가 올린 파일을 확인하고 새 파일을 올리는 내용과 행동을 다룬다. 바로가기 항목의 표시와 선택은 [MoreHome 화면 스펙](./more-home.md)에서, 올릴 수 있는 파일과 목록을 서버에서 불러오는 규칙은 [파일 보관 스펙](./file-storage.md)에서, 계정 상태를 결정하는 규칙은 [계정 조회 스펙](./account.md)에서, 세부 화면에서의 공통 내비게이션 노출과 뒤로가기는 [TopLevelNavigation 스펙](./top-level-navigation.md)에서 다룬다.

디자인: [FileHome 화면 디자인](../../design/file-home.md)

이번 범위는 파일을 하나씩 골라 서버에 올리고, 올린 파일을 목록으로 확인하는 것까지다. 목록의 파일을 선택해 열거나 내려받는 것, 파일의 이름을 바꾸거나 지우는 것, 여러 파일을 한 번에 올리는 것은 이번 범위에서 다루지 않는다. 목록의 파일은 아직 선택할 수 없다.

## feature

### 진입

사용자는 `더보기` 화면의 `파일` 바로가기를 선택해 FileHome 화면으로 이동한다. 화면 상단에는 `파일` 제목과 뒤로가기가 있다.

화면에서 보이는 내용은 `domain > 계정 상태에 따른 화면`에 따라 계정 상태마다 다르다.

### 게스트 상태

로그인하지 않은 상태에서는 파일 목록과 파일 추가를 제공하지 않고, 로그인하면 파일을 올리고 확인할 수 있다는 안내만 본문에 표시한다. 안내는 로그인 화면으로 이동하는 동작을 제공하지 않는다. 사용자는 `더보기` 화면으로 돌아가 로그인할 수 있다.

### 파일 목록

로그인한 상태에서는 사용자가 올린 파일을 목록으로 확인한다. 목록의 각 파일에서 사용자는 파일 이름, 파일 크기, 올린 날짜와 시각을 확인한다. 목록의 순서와 노출 기준은 [파일 보관 스펙](./file-storage.md)의 `domain > 목록에 노출하는 파일`을 따른다.

목록은 화면에 들어올 때 서버에서 불러온다. 목록은 앞부분부터 나타나고, 사용자가 목록의 끝으로 이동하면 그다음 파일을 이어서 불러와 붙인다. 사용자는 목록을 계속 이동해 올린 파일을 모두 확인할 수 있다.

목록을 당겨서 새로고침하지 않는다. 다른 기기에서 올린 파일은 이 화면에 다시 들어올 때 보인다. 목록을 다시 불러오는 계기는 `domain > 목록을 다시 불러오는 계기`를 따른다.

### 목록 표시 조건

로그인한 상태의 본문은 다음 중 하나를 표시한다.

| 조건 | 표시 |
| --- | --- |
| 목록을 처음 불러오는 중이다 | 불러오는 중임을 표시한다 |
| 처음 불러오기에 실패했다 | 목록을 불러오지 못했다는 안내와 다시 시도 동작을 표시한다 |
| 처음 불러오기가 끝났고 올린 파일이 하나도 없다 | 아직 올린 파일이 없으며 새로 추가할 수 있다는 빈 상태 안내를 표시한다 |
| 처음 불러오기가 끝났고 올린 파일이 있다 | 파일 목록을 표시한다 |

파일 목록이 표시된 상태에서 이어서 불러오는 동안에는 목록 끝에 불러오는 중임을 표시하고, 이미 나타난 파일은 그대로 확인할 수 있다. 이어서 불러오기에 실패하면 목록 끝에 불러오지 못했다는 안내와 다시 시도 동작을 표시하고, 이미 나타난 파일은 그대로 남는다.

다시 시도를 실행하면 실패한 불러오기를 다시 진행한다. 처음 불러오기를 다시 시도하는 동안에는 불러오는 중임을 표시한다.

표의 처음 불러오기는 화면에 들어와 처음 불러오는 경우뿐 아니라, 파일이 하나도 표시되지 않은 상태(빈 상태나 처음 불러오기 실패)에서 올리기에 성공해 목록을 다시 불러오는 경우도 포함한다.

파일 목록이 표시된 상태에서 올리기에 성공해 목록을 처음부터 다시 불러오는 동안에는 이전 목록을 그대로 보여 주고, 새 결과가 오면 목록을 바꾼다. 다시 불러오기에 실패하면 이전 목록을 그대로 두고 목록을 불러오지 못했음을 알린다.

목록의 계정이 바뀌어 처음부터 다시 불러올 때는 이전 계정의 파일을 보여 주지 않는다. 새 계정의 목록은 처음 불러오기와 같은 표시 조건을 따른다.

이 목록은 [목록 빈 상태 스펙](./list-empty-state.md)과 [페이지 조회 목록의 자리 표시 스펙](./paged-list-placeholder.md)을 따르지 않는다. 두 문서는 기기에 저장된 자료를 불러오는 목록을 다루지만, 이 목록은 서버에서 불러오므로 불러오지 못한 것과 올린 파일이 없는 것을 구분해 알리고, 아직 불러오지 않은 파일의 자리를 미리 두지 않는다.

### 파일 추가

로그인한 상태에서 사용자는 파일 추가를 실행해 기기가 제공하는 파일 선택 도구를 열고 파일 하나를 고를 수 있다. 목록을 불러오는 중이거나, 불러오기에 실패했거나, 빈 상태일 때도 파일 추가를 실행할 수 있다.

파일을 고르지 않고 취소하면 아무것도 올리지 않고 화면은 그대로 유지된다.

파일을 고르면 곧바로 서버에 올린다. 별도의 확인 단계는 없다. 올릴 수 있는 파일의 기준은 [파일 보관 스펙](./file-storage.md)의 `domain > 올릴 수 있는 파일`을 따른다.

올리는 동안에는 진행 중임을 표시하고 파일 추가를 다시 실행할 수 없다. 올리는 동안에도 목록은 그대로 확인하고 이동할 수 있다.

올리기에 성공하면 목록을 처음부터 다시 불러오고, 목록의 처음으로 돌아가 방금 올린 파일을 맨 앞에서 확인한다. 성공을 따로 알리지 않는다.

올리는 동안 계정이 게스트가 되거나 다른 계정으로 바뀌면 올리기를 중단하고 결과를 기다리지 않는다. 진행 중 표시는 사라지고 결과를 알리지 않는다. 그 파일이 보관되는지는 [파일 보관 스펙](./file-storage.md)의 `data > 올리기 중단`을 따른다.

올리기에 실패하면 화면을 유지하고 실패 이유를 알린다. 목록은 바뀌지 않으며 사용자는 파일 추가를 다시 실행할 수 있다. 알리는 실패 이유는 다음 둘로 구분한다.

| 실패 | 알리는 내용 |
| --- | --- |
| 고른 파일이 올릴 수 있는 크기를 넘는다 | 올릴 수 있는 최대 크기와 함께, 그 크기를 넘는 파일은 올릴 수 없다 |
| 그 밖의 이유로 올리지 못했다 | 파일을 올리지 못했다 |

### 뒤로가기

사용자가 뒤로가면 `더보기` 화면으로 돌아간다. 이는 [TopLevelNavigation 스펙](./top-level-navigation.md)의 `더보기 하위 화면의 뒤로가기`를 따른다.

올리는 동안 뒤로가면 결과를 기다리지 않고 돌아간다. 그 파일이 보관되는지는 [파일 보관 스펙](./file-storage.md)의 `data > 올리기 중단`을 따른다.

## domain

### 계정 상태에 따른 화면

화면의 내용은 [계정 조회 스펙](./account.md)이 결정한 계정 상태를 따른다.

| 계정 상태 | 화면 |
| --- | --- |
| 게스트·사용자로 확정하지 않음 | 제목과 뒤로가기만 표시하고 본문을 비운다. 파일 추가를 제공하지 않는다. |
| 게스트 | `feature > 게스트 상태`의 안내를 표시한다. |
| 사용자 | `feature > 파일 목록`과 `feature > 파일 추가`를 제공한다. |

사용자 상태에서는 세션 갱신 여부와 관계없이 목록을 불러오고 파일 추가를 제공한다. 세션이 갱신되지 않아 서버 요청이 실패하면 불러오기 실패나 올리기 실패로 알린다.

계정 상태가 바뀌면 사용자가 아무것도 하지 않아도 화면이 바로 바뀐 상태를 따른다. 다른 계정으로 바뀌면 목록을 그 계정의 파일로 처음부터 다시 불러온다.

### 목록을 다시 불러오는 계기

목록은 다음 경우에만 처음부터 다시 불러온다.

- 사용자가 FileHome 화면에 들어온다.
- 파일 올리기에 성공한다.
- 목록의 계정이 바뀐다.
- 처음 불러오기에 실패한 뒤 사용자가 다시 시도를 실행한다.

그 밖의 경우에는 이미 불러온 목록을 그대로 보여 준다.

### 유지할 사용자 진행 상태

화면이 회전하거나 앱이 백그라운드에 갔다가 같은 화면으로 돌아오면 불러온 목록, 보던 자리, 진행 중인 올리기를 그대로 유지하며 목록을 다시 불러오지 않는다.

파일 선택 도구가 열려 있는 동안 화면이 회전 등으로 다시 만들어져도, 사용자가 선택 도구에서 고른 파일은 그대로 올린다.

화면을 떠났다가 다시 들어오거나 앱을 다시 실행하면 목록을 처음부터 다시 불러오고 목록의 처음부터 보인다. 떠나기 전에 진행 중이던 올리기의 진행 표시는 남지 않는다.
