# 기기 설정 화면 공통 스펙

이 문서는 설정 목록에서 진입해 값을 이 기기에만 보관하는 설정 화면들이 공통으로 보장하는 표시 관계, 저장된 값을 확인하기 전의 상태, 고르면 바로 저장하는 설정과 입력한 뒤 저장하는 설정의 행동, 저장한 값의 유지와 보관 위치를 다룬다. 설정 값의 정의와 기본값, 어느 환경에서 진입할 수 있는지, 화면에만 있는 동작은 각 화면 스펙에서 다룬다. 설정 항목의 표시와 선택은 [SettingHome 화면 스펙](./setting-home.md)에서, 설정 목록과 함께 사용할 때의 선택·뒤로가기 정책은 [Setting 목록·상세 배치 스펙](./setting-list-detail.md)에서 다룬다.

디자인: [기기 설정 화면 공통 디자인](../../design/device-setting.md)

이 문서를 참조하는 문서는 다음과 같다.

- [SettingMap 화면 스펙](./setting-map.md): 고르면 바로 저장하는 설정
- [SettingFile 화면 스펙](./setting-file.md): 고르면 바로 저장하지만 실패를 알리는 설정
- [SettingGemini 화면 스펙](./setting-gemini.md): 입력한 뒤 저장하는 설정
- [공휴일 노출 설정 스펙](./holiday-visibility.md): 환경별 저장 영역

## feature

### 표시 관계

기기 설정 화면은 설정 목록과 함께 표시되거나 단독으로 표시될 수 있다. 두 상태 모두 공통 내비게이션을 제공하지 않으며, 표시 관계는 [Setting 목록·상세 배치 스펙](./setting-list-detail.md)을 따른다.

### 저장된 값을 확인하기 전

저장된 값을 확인하기 전이거나 읽지 못했으면 그 설정을 바꾸는 기능을 제공하지 않으며 별도 로딩 또는 오류 상태로 전환하지 않는다. 이 동안 화면에서 무엇을 표시하지 않는지는 각 화면 스펙이 정한다.

### 고르면 바로 저장하는 설정

이 절은 SettingMap에 적용한다.

사용자가 선택하지 않은 항목을 고르면 즉시 저장되고 선택 상태가 바뀐다. 이미 선택한 항목을 다시 고르면 아무것도 바뀌지 않는다.

화면의 선택 상태는 저장된 값을 따른다. 저장에 실패하면 이전 선택을 유지하며 별도 오류 상태로 전환하지 않는다.

바꾼 선택을 되돌리기 위한 별도 동작은 제공하지 않는다.

### 화면에 보이는 값

이 절은 SettingMap과 SettingFile에 적용한다.

화면의 현재 값은 저장된 값을 따르므로 사용자가 값을 바꾸면 새로고침 없이 바로 바뀐 값을 보여 준다. 이 화면들에는 저장된 값을 당겨서 새로고침하는 수단이 없다.

### 입력한 뒤 저장하는 설정

이 절은 SettingGemini에 적용한다.

화면에 진입하면 저장해 둔 값이 입력된 상태로 시작한다. 한 번도 저장하지 않았으면 비어 있는 상태로 시작한다. 입력란은 화면에 들어와 저장된 값을 처음 확인했을 때 한 번만 채우며, 그 뒤 저장된 값이 바뀌어도 입력 중인 내용을 덮어쓰지 않는다.

사용자는 입력한 값을 저장할 수 있다. 저장할 수 있는 때는 `domain > 저장 가능 상태`를 따른다. 저장을 실행하기 전까지 입력한 내용은 저장되지 않는다.

저장하는 동안에는 저장 동작에 진행 상태를 표시하며, 저장이 끝나기 전에는 같은 화면에서 전달된 저장 요청을 처리하지 않는다. 저장 중 저장 동작이 사라지는 경우는 `domain > 저장 가능 상태`를 따른다.

저장에 성공하면 화면을 유지한 채 저장되었다는 피드백을 제공하고, 입력한 내용은 비우지 않고 그대로 둔다. 입력한 내용이 곧 저장된 값이 되므로 사용자가 값을 다시 바꾸기 전까지는 저장 동작을 제공하지 않는다.

저장에 실패하면 입력 중이던 값을 그대로 유지하고 저장에 실패했다는 피드백을 제공하므로, 사용자는 그대로 다시 시도할 수 있다.

저장하지 않고 화면을 떠나면 입력 중이던 내용은 버려지고 저장된 값은 바뀌지 않는다. 화면을 떠나기 전에 저장하지 않은 내용이 있다고 따로 확인하지 않는다.

화면이 회전하거나 시스템에 의해 재생성되어도 입력 중이던 값을 유지한다. 사용자가 화면을 떠났다가 다시 들어오거나 앱을 종료한 뒤 새로 시작하면 저장된 값으로 다시 시작한다. 유지와 초기화의 기준은 `domain > 유지와 초기화 기준`을 따른다.

### 뒤로가기

단독으로 표시될 때와 설정 목록과 함께 표시될 때의 뒤로가기 결과는 모두 [Setting 목록·상세 배치 스펙](./setting-list-detail.md)의 `뒤로가기`를 따른다.

저장된 값은 뒤로가기로 화면을 떠나도 그대로 유지된다. 입력한 뒤 저장하는 설정에서 저장하지 않은 입력은 `입력한 뒤 저장하는 설정`에 따라 버려진다.

## domain

### 저장 가능 상태

이 절은 입력한 뒤 저장하는 설정에 적용한다.

편집 중인 값이 저장된 값과 다를 때만 저장 동작을 제공한다. 같으면 저장 동작을 제공하지 않는다. 한 화면이 여러 값을 함께 저장하면 그중 하나라도 다를 때 다른 것으로 본다.

비교는 사용자가 넣은 그대로 본다. 앞뒤 공백을 지우거나 대소문자를 맞추지 않으므로 공백만 더해도 다른 값으로 본다.

한 번도 저장하지 않아 저장된 값이 없으면 비어 있는 값과 비교한다. 그래서 화면에 처음 들어와 아무것도 입력하지 않은 상태에서는 저장 동작을 제공하지 않는다.

저장을 처리하는 동안에도 같은 기준을 적용한다. 저장이 끝나기 전이라도 저장된 값이 편집 중인 값과 같아지거나 사용자가 입력을 저장된 값으로 되돌리면 저장 동작은 사라지고, 저장 동작에 함께 보이던 진행 상태도 같이 사라진다. 저장이 끝나 저장된 값이 편집 중인 값과 같아졌을 때도 마찬가지다.

### 편집 상태와 저장된 값

이 절은 입력한 뒤 저장하는 설정에 적용한다.

화면에서 입력 중인 값은 저장된 값과 별개의 편집 상태이며, 저장을 실행할 때만 저장된 값에 반영된다. 저장된 값이 바뀌어도 편집 중인 값을 덮어쓰지 않는다.

### 유지와 초기화 기준

이 절은 입력한 뒤 저장하는 설정에 적용한다.

편집 상태는 화면이 전환 이력에 남아 있는 동안 화면 재생성과 백그라운드 복귀 후에도 유지한다.

사용자가 화면을 떠나 전환 이력에서 사라지거나 앱을 종료하고 다시 실행하면 편집 상태는 저장된 값으로 초기화한다.

## data

### 저장 시점과 유지

설정은 각 화면 스펙이 정한 시점에 기기에 저장된다. 사용자가 한 번도 저장하지 않았으면 저장된 값이 없고, 이때 어떤 값으로 다루는지는 각 화면 스펙이 정한다.

저장된 값은 화면을 떠나거나 화면이 재생성되어도, 앱이 백그라운드에 다녀와도, 앱을 종료하고 다시 시작해도 유지된다.

저장된 값을 읽을 수 없으면 설정을 아직 확인하지 못한 상태로 다룬다. 이는 저장된 값이 없어 기본값으로 다루는 것과 구분된다.

### 기기별 보관

기기 설정은 사용자 계정이 아니라 기기에 보관하며 서버와 동기화하지 않는다. 로그인, 로그아웃, 계정 전환으로 바뀌지 않으며 다른 기기에도 반영되지 않는다.

기기 설정은 [데이터 동기화 스펙](../common/data-sync.md)의 동기화 대상이 아니다.

### 환경별 저장 영역

각 환경에서 기기 설정을 보관하는 영역은 다음과 같다. 어느 환경에서 설정을 저장하는지는 각 화면 스펙이 정한다.

| 환경 | 저장 영역 | 사라지는 경우 |
| --- | --- | --- |
| Android | 앱 저장 영역 | 앱을 삭제하거나 앱 데이터를 지우면 |
| iOS | 앱 저장 영역 | 앱을 삭제하면 |
| 데스크톱 앱 | 기기에 저장한 자료와 같은, 개발용 앱과 운영용 앱을 나눈 저장 영역 | 저장 영역을 지우면 |
| 웹 | 브라우저의 사이트 저장 영역 | 브라우저의 사이트 저장 영역을 지우면 |

데스크톱 앱은 [데스크톱 앱 데이터 저장 위치 스펙](./jvm-database-storage.md)이 정한, 개발용 앱과 운영용 앱을 나눈 저장 위치를 사용하므로 두 앱은 같은 설정을 서로 다른 값으로 가진다.

웹에서는 같은 브라우저의 페이지 새로 고침이나 탭 재진입을 넘어 설정이 유지된다. 다른 브라우저나 시크릿 모드처럼 사이트 저장 영역이 분리된 환경에서는 설정을 따로 가진다.
