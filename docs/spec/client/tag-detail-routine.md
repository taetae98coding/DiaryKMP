# TagDetail 루틴 탭 스펙

이 문서는 사용자가 TagDetail 화면의 루틴 탭에서 표시 범위 안 태그에 연결된 루틴을 확인하고 조작하며, 상세 대상 태그를 초기값으로 사용해 루틴을 추가하는 행동을 다룬다. 화면 전체의 구성, 탭 전환과 유지, 화면 제목, 태그 디테일 탭의 행동과 목록 탭이 함께 쓰는 표시 범위와 공통 규칙(`목록 탭 공통`, `목록 탭의 대상과 추가의 초기값`, `탭별 조회`)은 [TagDetail 화면 스펙](./tag-detail.md)이 소유한다. 이 문서에는 루틴 탭에만 있는 차이를 둔다.

목록의 루틴 표시와 완료·삭제 규칙은 [RoutineHome 화면 스펙](./routine-home.md)을, 카드 문구와 목록 순서의 계산은 [루틴 앱 스펙](./routine.md)을, 루틴 추가 행동은 [RoutineAdd 화면 스펙](./routine-add.md)을, 루틴과 태그 연결의 의미는 [루틴 태그 앱 스펙](./routine-tag.md)과 [루틴 태그 스펙](../common/routine-tag.md)을, 선택한 루틴의 상세는 [RoutineDetail 화면 스펙](./routine-detail.md)을 따른다. 아직 준비되지 않은 자리의 처리는 [페이지 조회 목록의 자리 표시 스펙](./paged-list-placeholder.md)을, 목록이 비어 있을 때의 안내는 [목록 빈 상태 스펙](./list-empty-state.md)을, 목록을 당겨 새로고침하는 행동과 동기화 진행 표시는 [새로고침 스펙](./sync-refresh.md)을 따른다. 이 태그의 완료된 루틴을 모아 확인하는 화면은 [TagRoutineFinishedList 화면 스펙](./tag-routine-finished-list.md)에서 다룬다.

디자인: [TagDetail 루틴 탭 디자인](../../design/tag-detail-routine.md)

## feature

### 진입

사용자는 TagDetail 화면에서 루틴 탭을 선택해 표시 범위 안 태그에 연결된 루틴 목록을 확인한다. 탭을 선택하는 방법과 선택한 탭의 유지 기준은 [TagDetail 화면 스펙](./tag-detail.md)의 `탭 전환`과 `선택한 탭`을 따른다.

상세 대상 태그의 조회 결과와 관계없이 목록과 동작을 제공하는 기준은 [TagDetail 화면 스펙](./tag-detail.md)의 `목록 탭 공통`을 따른다.

### 루틴 추가

사용자가 루틴 추가를 선택하면 RoutineAdd 화면으로 이동한다. 추가를 시작할 수 있는 조건, 화면의 표시와 돌아오기, 최초 선택은 [TagDetail 화면 스펙](./tag-detail.md)의 `목록 탭 공통`을 따른다. 루틴 목록과 루틴 추가를 함께 쓰는 배치는 RoutineHome에서 진입한 경우에만 적용하며 그 기준은 [Routine 목록·상세 배치 스펙](./routine-list-detail.md)을 따른다.

### 목록 표시

목록에는 현재 사용자 계정과 연결된 루틴 중 표시 범위 안 태그 하나 이상과 해제되지 않은 연결을 가지며 완료되지도 삭제되지도 않은 루틴만 표시한다. 표시 범위가 무엇을 정하는지는 [TagDetail 화면 스펙](./tag-detail.md)의 `표시 범위`를 따른다.

사용자는 각 항목에서 루틴의 제목과 [루틴 앱 스펙](./routine.md)의 `카드 문구`를 확인한다. 그 밖의 항목 표시는 [RoutineHome 화면 스펙](./routine-home.md)의 루틴 목록과 같다. 다만 루틴 탭의 항목에는 빠른 기록을 두지 않는다. 사용자는 RoutineHome의 목록이나 루틴을 선택해 이동한 RoutineDetail 화면에서 기록을 넣는다.

여러 태그와 연결된 루틴을 한 번만 보여 주는 기준과 표시 범위를 바꿨을 때의 결과는 [TagDetail 화면 스펙](./tag-detail.md)의 `목록 탭 공통`을 따른다.

순서는 `domain > 루틴 노출과 순서`를 따른다.

아직 준비되지 않은 자리의 처리는 [페이지 조회 목록의 자리 표시 스펙](./paged-list-placeholder.md)을 따른다.

조회에 실패했을 때의 목록은 [페이지 조회 목록의 자리 표시 스펙](./paged-list-placeholder.md)의 `조회 실패`를 따르며, 별도 재시도 동작은 제공하지 않는다.

### 빈 상태

`목록 표시`의 노출 기준을 만족하는 루틴이 하나도 없을 때의 빈 상태는 [TagDetail 화면 스펙](./tag-detail.md)의 `목록 탭 공통`을 따르며, 이 태그에 연결된 루틴이 아직 없음을 알린다. 불러오는 중에는 빈 상태를 표시하지 않는다. 판정 시점, 빈 상태에서 할 수 있는 행동, 목록과의 전환은 [목록 빈 상태 스펙](./list-empty-state.md)을 따른다.

빈 상태에서도 사용자는 루틴 추가와 완료된 루틴 확인을 그대로 실행할 수 있으며, 추가한 루틴이 이 목록의 노출 기준을 만족하면 빈 상태가 사라지고 목록에 나타난다.

### 완료된 루틴 확인

사용자는 루틴 탭에서 완료된 루틴 확인을 선택해 같은 태그의 TagRoutineFinishedList 화면으로 이동한다.

이 태그에 완료된 루틴이 하나도 없어도 이 동작은 제공된다. 목록이 비어 있는지, 대상 태그를 조회했는지, 지금 표시 범위가 무엇인지는 이 동작을 막지 않는다.

이동한 화면에는 표시 범위를 적용하지 않는다. 표시 범위를 넓혀 두었어도 그 화면은 상세 대상 태그에 연결된 완료된 루틴만 표시한다.

완료된 루틴 확인은 루틴 탭을 선택한 동안에만 제공한다. 다른 탭에서는 실행할 수 없다.

이동한 화면의 내용과 행동은 [TagRoutineFinishedList 화면 스펙](./tag-routine-finished-list.md)을 따른다. 사용자가 그 화면에서 뒤로 가면 루틴 탭이 선택된 같은 태그의 TagDetail 화면으로 돌아온다.

### 루틴 상세 확인

사용자가 루틴을 선택하면 선택한 루틴의 RoutineDetail 화면으로 이동한다. 화면의 표시, 돌아오기와 돌아온 뒤의 목록은 [TagDetail 화면 스펙](./tag-detail.md)의 `목록 탭 공통`을 따른다. RoutineDetail 화면에서 기록을 넣거나 뺀 뒤 돌아오면 그 루틴의 카드 문구는 바뀐 합계와 달성률을 보여 준다. RoutineDetail 화면에서 루틴을 완료한 뒤 돌아와도 그 루틴은 이 목록의 노출 기준에 따라 목록에서 사라진다.

### 완료·삭제와 실행 취소

사용자는 목록에서 루틴을 완료하거나 삭제할 수 있다. 완료와 삭제의 상호작용, 저장과 동기화는 [RoutineHome 화면 스펙](./routine-home.md)의 `완료`와 `삭제`, 그 상태 전이와 저장 규칙을 따른다.

완료되거나 삭제된 루틴은 목록에서 사라지고 해당 결과의 피드백과 실행 취소 동작을 제공한다. 완료한 루틴은 [TagRoutineFinishedList 화면 스펙](./tag-routine-finished-list.md)의 노출 기준을 만족해 그 화면의 목록에 나타난다.

사용자가 실행 취소하면 루틴은 이전 상태로 돌아가 목록의 순서 기준에 맞는 위치에 다시 나타난다.

안내를 표시하는 곳과 안내가 닫히는 결과는 [TagDetail 화면 스펙](./tag-detail.md)의 `목록 탭 공통`을 따른다.

삭제는 루틴 자체를 삭제 상태로 바꾸는 것이며, 루틴과 이 태그의 연결만 해제하지 않는다. 따라서 삭제한 루틴은 이 목록뿐 아니라 그 루틴을 보여 주는 모든 목록에서 사라지고, 그 루틴의 기록도 RoutineHome의 달력 보기에서 사라진다. 삭제는 루틴의 기록과 태그 연결을 지우지 않는다. 실행 취소하면 루틴은 기록과 태그 연결을 그대로 가진 채 돌아오므로 이 목록의 노출 기준을 만족해 순서 기준에 맞는 위치에 다시 나타난다.

### 새로고침

사용자는 루틴 목록을 당겨 새로고침할 수 있다. 새로고침 대상과 진행 표시 기준은 [새로고침 스펙](./sync-refresh.md)을 따른다.

목록이 비어 있을 때도 당길 수 있다. 새로고침 중에 다시 당겼을 때의 결과도 같은 스펙을 따른다.

새로 받은 루틴이 지금 노출 기준을 만족하면 사용자가 별도 조작을 하지 않아도 목록에 나타난다. 다른 화면에서 바뀐 루틴, 루틴 기록과 연결도 당기지 않아도 목록에 바로 반영된다.

## domain

### 상세 대상 태그와 연결

루틴 탭의 상세 대상 태그와 목록에 담을 연결은 [TagDetail 화면 스펙](./tag-detail.md)의 `목록 탭의 대상과 추가의 초기값`을 따르며, 목록에 담는 연결은 루틴과 태그의 연결이다.

### 루틴 추가의 초기값

루틴 추가의 초기값은 [TagDetail 화면 스펙](./tag-detail.md)의 `목록 탭의 대상과 추가의 초기값`을 따르므로, 완료되었거나 삭제된 대상 태그는 태그 입력에서 선택한 것으로 보이지 않지만 선택은 남아 추가할 때 그대로 연결된다. 그 밖의 초기값과 저장 규칙은 [RoutineAdd 화면 스펙](./routine-add.md)을 따른다.

### 루틴 노출과 순서

표시 범위 안 태그와 연결된 루틴 중 미완료·미삭제 루틴만 노출한다. 표시 범위는 담을 태그만 정하고 이 노출 기준을 대체하지 않는다.

진행 상태가 시작 전인 루틴도 노출한다. 기록이 있는지와 목표를 채웠는지도 노출 기준에 쓰지 않는다. [RoutineHome 화면 스펙](./routine-home.md)의 `보기 범위 기준`은 이 목록에 적용하지 않으므로, 오늘의 요일이 하는 요일에 들지 않는 루틴도 노출한다.

순서는 [루틴 앱 스펙](./routine.md)의 `목록 순서`에 따라 진행 중, 시작 전 순이며 진행 상태가 같은 루틴끼리는 제목 오름차순이다. 사용자가 고를 수 있는 다른 정렬은 없다.

### 오늘

진행 상태와 카드 문구를 정하는 오늘은 TagDetail 화면에 들어오거나, 다른 화면이나 다른 앱에서 TagDetail 화면으로 돌아올 때마다 다시 정한다. 화면을 보는 동안 자정이 지나도 오늘은 다시 정하지 않는다.

오늘이 바뀌어 다시 정하면 진행 상태와 카드 문구도 바뀐 오늘을 기준으로 다시 정한다. 진행 상태가 달라진 루틴은 [루틴 앱 스펙](./routine.md)의 `목록 순서`에 따라 바뀐 상태의 자리로 옮겨진다.

### 완료·삭제·실행 취소

상태 전이와 수정 시각 갱신은 [RoutineHome 화면 스펙](./routine-home.md)의 `완료와 실행 취소의 상태 전이`와 `삭제와 실행 취소의 상태 전이`를 따른다.

완료, 삭제와 실행 취소는 루틴과 태그의 연결을 바꾸지 않는다. 따라서 완료한 루틴은 대상 태그와의 연결을 유지한 채 [TagRoutineFinishedList 화면 스펙](./tag-routine-finished-list.md)의 노출 기준을 만족하고, 그 화면에서 다시 시작하면 이 목록에 다시 나타난다.

### 태그 연결의 변경과 목록

루틴 탭은 목록에서 루틴의 태그 연결을 바꾸는 동작을 제공하지 않는다. 목록의 완료와 삭제는 `feature > 완료·삭제와 실행 취소`에 따라 루틴의 완료 여부나 삭제 여부만 바꾸고 태그 연결은 바꾸지 않는다.

루틴 탭 목록에서 실행하는 완료, 삭제와 실행 취소가 대상 태그와 태그 디테일 탭에 주는 영향은 [TagDetail 화면 스펙](./tag-detail.md)의 `목록 탭의 대상과 추가의 초기값`을 따른다. 사용자는 루틴을 선택해 [RoutineDetail 화면](./routine-detail.md)에서 연결을 바꾼다.

루틴 탭이 목록에 담을 루틴을 고를 때 사용하는 연결은 루틴과 태그의 연결이며, 태그와 태그의 연결이 이 목록에 주는 영향은 [TagDetail 화면 스펙](./tag-detail.md)의 `연결의 반영`을 따른다.

## data

### 태그별 루틴 조회

루틴과 루틴-태그 연결은 사용자가 목록을 내리는 만큼 나누어 불러오며, 페이지를 이어서 조회하는 기준은 [페이지 조회 목록의 자리 표시 스펙](./paged-list-placeholder.md)의 `페이지 조회`를 따른다. 조회 대상과 자동 갱신은 [TagDetail 화면 스펙](./tag-detail.md)의 `탭별 조회`를 따르며, 바뀐 루틴이 놓이는 자리는 `domain > 루틴 노출과 순서`를 따른다. 시작 날짜, 주기, 단위나 목표량이 바뀌면 바뀐 값으로 다시 정한 카드 문구와 순서가 반영된다. 루틴의 완료 여부가 바뀐 것도 갱신 계기다.

카드 문구에 쓰는 주기의 합계와 달성률은 기기에 따로 기록해 두지 않고 그 루틴의 삭제되지 않은 기록으로 그때그때 정한다. 이 기기나 다른 기기에서 루틴 기록이 추가되거나 삭제되면 사용자가 별도 조작을 하지 않아도 그 루틴의 카드 문구에 반영된다.

### 상태 변경의 저장

완료, 삭제와 실행 취소의 저장 흐름은 [RoutineHome 화면 스펙](./routine-home.md)의 `완료와 실행 취소의 저장`과 `삭제와 실행 취소의 저장`을 따른다.

루틴 상태를 바꿔도 루틴과 태그의 연결은 유지한다.

### 탭별 조회

루틴 탭의 목록 조회와 다른 탭 조회의 관계는 [TagDetail 화면 스펙](./tag-detail.md)의 `탭별 조회`를 따른다.

### 루틴 추가 결과

루틴 추가 결과의 저장과 표시는 [TagDetail 화면 스펙](./tag-detail.md)의 `탭별 조회`를 따른다.
