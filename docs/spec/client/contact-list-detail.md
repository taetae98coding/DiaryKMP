# Contact 목록·상세 배치 스펙

이 문서는 연락처 목록과 상세 영역을 함께 사용할 때 이 배치에만 해당하는 상세 영역 구성, 뒤로가기와 초기화 경계를 다룬다. 함께 사용과 단독 사용, 상세 선택과 교체, 선택이 없을 때의 추가, 추가 진입 수단, 뒤로가기, 표시 비율 조절, 배치에 참여하는 화면과 유지·초기화의 공통 기준은 [목록·상세 배치 공통 스펙](./list-detail-pane.md)을 따른다. 각 화면의 내용과 행동은 [ContactHome 화면 스펙](./contact-home.md), [ContactAdd 화면 스펙](./contact-add.md), [ContactDetail 화면 스펙](./contact-detail.md)에서 다룬다.

디자인: [Contact 목록·상세 배치 디자인](../../design/contact-list-detail.md)

표시 비율은 화면 표시 상태일 뿐 사용자 데이터를 만들거나 저장하지 않으므로 `data` 영역은 생략한다.

## feature

### 상세 영역의 구성

목록과 상세 영역을 함께 표시하는 상태에서 상세 영역에는 사용자가 선택한 연락처의 상세가 표시되고, 선택한 연락처가 없으면 연락처 추가가 표시된다. 선택, 교체, 삭제 뒤의 상세 영역과 선택이 없을 때의 추가는 [목록·상세 배치 공통 스펙](./list-detail-pane.md)의 `상세 선택과 교체`와 `선택이 없을 때의 추가`를 따른다.

선택한 연락처가 없는 동안 사용자는 연락처 추가에서 [ContactAdd 화면 스펙](./contact-add.md)의 `진입과 입력`이 정한 내용을 곧바로 입력한다.

선택한 연락처의 상세가 놓여 있는 동안 목록에서 연 연락처 추가는 [목록·상세 배치 공통 스펙](./list-detail-pane.md)의 `추가 진입 수단`을 따르며, [ContactAdd 화면 스펙](./contact-add.md)의 `진입과 입력`이 정한 처음 상태로 시작한다.

한 영역만 표시되는 상태에서는 해당 화면 스펙의 행동을 그대로 제공하며, 화면 사이의 이동은 [ContactHome 화면 스펙](./contact-home.md)의 `연락처 추가로 이동`과 `연락처 상세로 이동`을 따른다.

캘린더 홈 화면에서 생일을 선택해 진입한 ContactDetail 화면은 이 배치에 참여하지 않고 단독으로 표시한다. 진입 흐름은 [CalendarHome 스펙](./calendar-home.md)의 `생일 선택`을 따른다.

메모의 연락처 입력에서 진입한 ContactAdd 화면과 ContactDetail 화면도 이 배치에 참여하지 않고 단독으로 표시한다. 진입 흐름은 [메모 연락처 입력 컴포넌트 스펙](./memo-contact-input.md)의 `연락처 추가 이동`과 `연락처 상세 이동`을 따른다.

상세 영역의 ContactDetail 메모 탭에서 진입한 MemoAdd 화면과 MemoDetail 화면도 이 배치에 참여하지 않고 단독으로 표시한다. 같은 메모 탭에서 진입한 ContactMemoFinishedList 화면도 이 배치에 참여하지 않으며, 그 화면의 배치는 [항목 완료 메모 목록·상세 배치 스펙](./entity-memo-finished-list-detail.md)을 따른다. 세 화면에서 뒤로가면 상세 영역에는 메모 탭이 선택된 같은 연락처의 상세가 남아 있으며, 그 기준은 [ContactDetail 메모 탭 스펙](./contact-detail-memo.md)의 `단독 표시와 돌아오기`를 따른다.

### 뒤로가기

뒤로가기의 결과는 [목록·상세 배치 공통 스펙](./list-detail-pane.md)의 `뒤로가기`를 따르며, 이 배치를 떠나면 `더보기` 화면으로 돌아간다. 연락처 목록의 뒤로가기 동작의 결과는 [ContactHome 화면 스펙](./contact-home.md)의 `뒤로가기`를 따른다.

### 정렬과 필터

목록에서 정렬 기준을 고르는 행동과 유무 필터는 배치와 관계없이 [ContactHome 화면 스펙](./contact-home.md)의 `정렬 선택`과 `유무 필터`를 따른다. 상세 영역에 연락처 추가나 연락처 상세가 함께 놓여 있어도 목록의 정렬 줄과 필터를 그대로 사용할 수 있고, 필터를 여는 동안에도 상세 영역에 놓인 화면은 바뀌지 않는다.

## domain

### 유지와 초기화 기준

사용자가 `더보기` 화면으로 돌아가는 것을 이 배치를 떠난 것으로 본다. 그 뒤 연락처 화면에 다시 진입하거나 앱을 종료하고 다시 실행하면 [목록·상세 배치 공통 스펙](./list-detail-pane.md)의 `유지와 초기화 기준`에 따라 초기화한다.

선택한 연락처가 없을 때 상세 영역에 놓이는 연락처 추가의 작성 내용은 같은 절에 따라 [ContactAdd 화면 스펙](./contact-add.md)의 `작성 상태 유지 대상`이 남는다. 연락처 상세의 메모 탭에서 연 메모 추가나 메모 상세, 완료된 메모 목록에 다녀와도 남는다. 다시 진입하면 같은 문서의 `진입과 입력`이 정한 처음 상태로 시작하며, 화면 재생성에서 무엇이 남는지는 [항목 추가 화면 공통 스펙](./entity-add.md)의 `작성 상태 유지`를 따른다.
