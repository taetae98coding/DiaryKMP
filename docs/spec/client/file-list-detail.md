# File 목록·상세 배치 스펙

이 문서는 파일 목록과 상세 영역을 함께 사용할 때 이 배치에만 해당하는 상세 영역 구성, 올리기 결과를 알리는 화면, 뒤로가기와 초기화 경계를 다룬다. 함께 사용과 단독 사용, 상세 선택과 교체, 선택이 없을 때의 추가, 추가 진입 수단, 뒤로가기, 표시 비율 조절, 배치에 참여하는 화면과 유지·초기화의 공통 기준은 [목록·상세 배치 공통 스펙](./list-detail-pane.md)을 따른다. 각 화면의 내용과 행동은 [FileHome 화면 스펙](./file-home.md), [FileAdd 화면 스펙](./file-add.md), [FileDetail 화면 스펙](./file-detail.md)에서 다룬다.

디자인: [File 목록·상세 배치 디자인](../../design/file-list-detail.md)

표시 비율과 상세 선택은 화면 표시 상태일 뿐 사용자 데이터를 만들거나 저장하지 않으므로 `data` 영역은 생략한다.

## feature

### 상세 영역의 구성

목록과 상세 영역을 함께 표시하는 상태에서 상세 영역에는 사용자가 선택한 파일의 FileDetail이 표시되고, 선택한 파일이 없으면 FileAdd가 표시된다. 다만 게스트 상태에서는 FileHome이 파일 목록과 파일 추가를 제공하지 않으므로 선택한 파일이 없을 때의 상세 영역을 비워 둔다. 그 기준은 `domain > 계정 상태에 따른 상세 영역`을 따른다.

선택, 교체와 선택이 없을 때의 추가는 [목록·상세 배치 공통 스펙](./list-detail-pane.md)의 `상세 선택과 교체`와 `선택이 없을 때의 추가`를 따른다. 선택한 파일이 없는 동안 사용자는 FileAdd에서 곧바로 제목과 설명을 적고 파일을 골라 올린다. 이 배치에서는 추가에 성공할 때가 아니라 올리기를 시작할 때부터 상세 영역이 FileAdd로 남아 다음 파일을 이어서 작성하며, 올리기에 성공하면 방금 올린 파일이 목록에 나타난다. 올리기를 시작한 뒤의 입력 상태는 [FileAdd 화면 스펙](./file-add.md)의 `올리기 실행`을 따른다.

올리는 중에도 목록에서 파일을 선택할 수 있다. 상세 영역의 FileDetail에서 저장하지 않은 입력은 [FileDetail 화면 스펙](./file-detail.md)의 `뒤로가기`와 같이 남지 않는다.

상세 영역에 FileDetail이 놓여 있는 동안 목록에서 연 FileAdd는 [목록·상세 배치 공통 스펙](./list-detail-pane.md)의 `추가 진입 수단`을 따르며, 제목과 설명이 비어 있고 고른 파일이 없는 상태로 시작한다. 올리는 중에는 [FileHome 화면 스펙](./file-home.md)의 `파일 추가`에 따라 실행할 수 없다.

상세 영역의 FileDetail이나 목록에서 연 FileAdd가 계정 상태가 바뀌어 닫히면, 뒤로가기를 실행한 것과 같이 상세 영역이 되돌아간다. 닫히는 기준은 [FileDetail 화면 스펙](./file-detail.md)과 [FileAdd 화면 스펙](./file-add.md)의 `계정 상태`를 따른다. FileDetail을 보다가 목록에서 연 FileAdd가 상세 영역에 놓인 동안 다른 사용자로 바뀌면, FileAdd는 [FileAdd 화면 스펙](./file-add.md)의 `계정 상태`에 따라 적어 둔 내용과 함께 그대로 남는다. 그 FileAdd에서 뒤로가기를 실행해 가려져 있던 FileDetail이 다시 보이게 되면, 그 FileDetail은 [FileDetail 화면 스펙](./file-detail.md)의 `계정 상태`에 따라 닫히고 상세 영역은 선택한 파일이 없을 때의 FileAdd로 돌아간다. 같은 상태에서 게스트가 되면 FileAdd와 그 아래의 FileDetail이 모두 닫히고, 상세 영역은 `domain > 계정 상태에 따른 상세 영역`에 따라 비어 있게 된다.

한 영역만 표시되는 상태에서는 해당 화면 스펙의 행동을 그대로 제공하며, 화면 사이의 이동은 [FileHome 화면 스펙](./file-home.md)의 `파일 목록`과 `파일 추가`를 따른다.

### 올리기 결과를 알리는 화면

목록과 상세 영역을 함께 표시하는 동안 올리기가 끝나면, 상세 영역에 FileAdd가 놓여 있으면 [FileAdd 화면 스펙](./file-add.md)의 `올리기 결과`에 따라 FileAdd만 화면에서 결과를 알린다. 상세 영역에 FileDetail이 놓여 있으면 [FileHome 화면 스펙](./file-home.md)의 `올리기 결과`에 따라 FileHome이 알린다. 어느 경우에도 올리기에 성공하면 목록은 FileHome 화면 스펙의 `올리기 결과`에 따라 다시 불러온다. 결과 알림은 [파일 올리기 알림 스펙](./file-upload-notification.md)의 `결과 알림`에 따라 이와 관계없이 보낸다.

### 뒤로가기

뒤로가기의 결과는 [목록·상세 배치 공통 스펙](./list-detail-pane.md)의 `뒤로가기`를 따르며, 이 배치를 떠나면 `더보기` 화면으로 돌아간다. 게스트 상태에서 상세 영역이 비어 있을 때도 되돌아갈 상세가 없으므로 이 배치를 떠난다. 파일 목록의 뒤로가기 동작의 결과는 [FileHome 화면 스펙](./file-home.md)의 `뒤로가기`를 따른다.

올리는 동안 이 배치를 떠나도 올리기는 멈추지 않고 이어진다. 상세 영역의 FileDetail에서 진행 중이던 다운로드는 FileDetail이 상세 영역에서 빠질 때 [FileDetail 화면 스펙](./file-detail.md)의 `화면을 떠날 때`를 따른다.

## domain

### 계정 상태에 따른 상세 영역

선택한 파일이 없을 때의 상세 영역은 계정 상태에 따라 다음과 같다.

| 계정 상태 | 상세 영역 |
| --- | --- |
| 사용자 | FileAdd를 표시한다 |
| 게스트 | 비워 둔다. 그동안 FileAdd에 적어 두던 제목, 설명과 고른 파일은 남기지 않는다 |
| 게스트·사용자로 확정하지 않음 | FileAdd를 표시한다. 적어 둔 내용과 이때 올리기를 실행한 결과는 [FileAdd 화면 스펙](./file-add.md)의 `계정 상태`를 따른다 |

게스트에서 다시 사용자가 되면 상세 영역에 FileAdd가 제목과 설명이 비어 있고 고른 파일이 없는 상태로 다시 표시된다.

### 유지와 초기화 기준

사용자가 `더보기` 화면으로 돌아가는 것을 이 배치를 떠난 것으로 본다. 그 뒤 파일 화면에 다시 진입하거나 앱을 종료하고 다시 실행하면 [목록·상세 배치 공통 스펙](./list-detail-pane.md)의 `유지와 초기화 기준`에 따라 초기화한다.

선택한 파일이 없을 때 상세 영역에 놓이는 FileAdd의 작성 내용은 같은 절에 따라 적어 두던 제목, 설명과 고른 파일이 남고, 다시 진입하면 제목과 설명이 비어 있고 고른 파일이 없는 상태로 시작한다.

그 밖에 상세 영역에서 작성 중이던 내용을 어디까지 유지하는지는 [FileAdd 화면 스펙](./file-add.md)과 [FileDetail 화면 스펙](./file-detail.md)의 `유지할 사용자 진행 상태`를 따른다. 목록의 불러온 내용과 보던 자리는 [FileHome 화면 스펙](./file-home.md)의 `유지할 사용자 진행 상태`를 따르며, 상세 영역의 화면이 바뀌는 것은 FileHome을 떠나는 것이 아니므로 목록을 다시 불러오지 않는다.
