# 날짜·시간 입력 컴포넌트 스펙

이 문서는 여러 화면에서 재사용하는 날짜·시간 입력 컴포넌트의 사용자 관점 동작과 정책을 다룬다. 이 컴포넌트를 사용하는 화면이 선택된 기간을 어디에 저장하고 어떻게 활용하는지는 각 화면 스펙의 범위이며, 이 문서는 다루지 않는다. 컴포넌트 자체는 사용자 데이터를 저장하지 않으므로 `data` 영역은 생략한다.

디자인: [DiaryDateTimeInput 컴포넌트 디자인](../../design/diary-date-time-input.md)

## feature

### 사용 여부 전환

사용자는 날짜·시간 입력의 사용 여부를 켜거나 끌 수 있다.

처음 켜면 기본 기간이 선택되고, 껐다가 다시 켜면 끄기 직전의 선택값이 복원된다. 꺼진 상태에서는 기간을 조작할 수 없고 기간이 선택되지 않은 것으로 취급된다.

### 종일 여부 전환

기간을 사용하는 동안 사용자는 종일 기간과 시각이 있는 기간 사이를 전환할 수 있다.

종일 기간은 시작일과 종료일을, 종일이 아닌 기간은 시작 날짜·시간과 종료 날짜·시간을 확인하고 바꿀 수 있다.

### 날짜와 시간 선택

사용자는 시작과 종료의 날짜를 각각 선택할 수 있다. 종일이 아닌 기간에서는 시작과 종료의 시간도 각각 선택할 수 있다.

선택을 확인하면 해당 값이 반영되고, 취소하면 기존 값이 유지된다.

### 기간 자동 보정

사용자가 시작을 종료보다 뒤로 선택하면 종료가 시작과 같은 값으로 맞춰진다.

사용자가 종료를 시작보다 앞으로 선택하면 시작이 종료와 같은 값으로 맞춰진다.

## domain

### 기간의 개념

기간은 시작과 종료로 이루어지며, 시작은 항상 종료보다 늦지 않다. 이 관계는 기간 자동 보정으로 항상 유지된다.

종일 기간은 날짜 단위로 표현되고, 종일이 아닌 기간은 날짜와 시각(시·분) 단위로 표현된다.

종일이 아닌 기간의 자동 보정은 날짜와 시각을 합친 값을 기준으로 판단한다.

### 기본값

사용처가 초기 기간을 제공하지 않으면 날짜·시간 입력을 사용하지 않는 상태로 시작하고, 사용처가 초기 기간을 제공하면 사용하는 상태로 그 기간이 선택된다.

사용처가 제공하는 초기 기간이 바뀌면 컴포넌트는 바뀐 초기 기간으로 처음부터 다시 시작하며, 그 전까지 사용자가 고른 값은 이어지지 않는다.

처음 사용하도록 전환했을 때의 기본 기간은 오늘부터 오늘까지의 종일 기간이다.

### 사용처가 채우는 기간

사용처는 표시 중인 컴포넌트에 기간 하나를 통째로 채울 수 있다. 채우면 컴포넌트는 사용하는 상태가 되고, 종일 여부와 시작·종료가 채운 기간과 같아진다. 채우기 전에 사용하지 않는 상태였거나 종일 여부가 달랐어도 마찬가지다.

### 기본 시각

기본 시각은 현재 시각을 30분 단위로 올린 시각이다. 오후 1시 43분이면 오후 2시, 오후 2시 13분이면 오후 2시 30분이 되고, 이미 정각이거나 30분이면 그 시각을 그대로 쓴다.

올림한 결과가 하루를 넘으면 자정으로 한다. 이때 날짜는 넘기지 않는다.

기본 시각은 시각을 채워야 하는 시점의 현재 시각으로 그때마다 정한다. 컴포넌트를 표시한 뒤 시간이 흐르면 그만큼 늦은 시각이 된다.

사용처가 초기 기간을 제공하지 않으면 아직 보이지 않는 시작과 종료의 시각도 컴포넌트를 표시하기 시작한 시각의 기본 시각으로 둔다.

### 종일 전환 시 시간 처리

종일에서 종일 아님으로 전환하면 시작일과 종료일은 그대로 두고 시작 시각이 기본 시각이 된다. 종료 시각은 시작일과 종료일이 같으면 시작보다 1시간 뒤가 되고, 시작일과 종료일이 다르면 시작 시각과 같아진다.

시작보다 1시간 뒤가 하루를 넘으면 종료는 다음 날의 시각이 된다. 예를 들어 시작이 오후 11시 30분이면 종료는 다음 날 오전 12시 30분이 된다.

종일 아님에서 종일로 전환하면 시간 정보는 버려지고 날짜만 유지된다. 다시 종일 아님으로 전환하면 시간은 다시 위 규칙을 따른다.

### 상태 유지

사용하지 않도록 전환해도 선택했던 기간 값은 버려지지 않으며, 다시 사용하도록 전환하면 그대로 복원된다.

화면 재생성(기기 회전, 화면 크기 변경 등)이 일어나도 사용 여부, 종일 여부, 선택한 기간은 유지된다.

다른 앱에 다녀와도 사용 여부, 종일 여부, 선택한 기간은 그대로 유지된다. 다른 앱에 다녀온 사이 시스템이 앱을 종료했다가 사용자가 돌아와 다시 열리는 경우에도 떠나기 직전의 사용 여부, 종일 여부, 선택한 기간이 복원된다.

사용자가 앱을 새로 실행하면 이전에 고른 값은 이어지지 않고, `기본값`에 따라 사용처가 제공하는 초기 기간으로 처음부터 시작한다.

날짜나 시간을 고르는 중에 화면 재생성이 일어나도 고르기는 열린 상태를 유지하며, 시작과 종료 중 어느 쪽의 날짜를 고르던 중이었는지 또는 시간을 고르던 중이었는지도 유지된다. 재생성 전에 선택을 확인하지 않았다면 선택한 기간은 아직 바뀌지 않은 상태다.
