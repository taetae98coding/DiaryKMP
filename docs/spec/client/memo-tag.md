# 메모 태그 앱 스펙

이 문서는 메모와 태그의 연결 가운데 사용자가 기기에서 연결과 대표 태그를 함께 바꿀 때 앱이 지키는 규칙을 다룬다. 메모와 태그의 연결이 공통으로 지키는 규칙은 [메모 태그 스펙](../common/memo-tag.md)을, 대표 태그 자체의 규칙은 [메모 대표 태그 스펙](../common/memo-primary-tag.md)을, 연결을 기기에 저장하는 규칙은 [항목 연결 앱 스펙](./entity-link.md)을 따른다.

사용자가 태그와 대표 태그를 고르는 조작은 [메모 태그 입력 컴포넌트 스펙](./memo-tag-input.md)이, 메모를 추가하거나 수정하면서 연결을 바꾸는 행동은 [MemoAdd 화면 스펙](./memo-add.md)과 [MemoDetail 화면 스펙](./memo-detail.md)이 소유하므로 이 문서에는 `feature` 영역을 두지 않는다.

## domain

### 대표 태그와의 관계

메모는 [항목 태그 연결 공통 스펙](../common/entity-tag.md)의 `대표 태그`에서 대표 태그를 갖는 유일한 예외이며, 사용자가 기기에서 지정하는 메모의 대표 태그는 그 메모와 연결된 태그 중 하나다.

사용자가 기기에서 대표 태그로 지정한 태그는 같은 저장 작업에서 그 메모의 연결된 태그에도 포함된다. 사용자 행동의 기기 저장 결과로 연결되지 않은 태그만 대표 태그로 지정된 상태는 허용하지 않는다.

사용자가 기기에서 태그와 메모의 연결을 해제하면 같은 저장 작업에서 그 태그의 대표 태그 지정도 함께 해제된다.

이 관계는 기기에서의 사용자 행동에만 적용된다. 서버 동기화로 받은 내용에서 이 관계가 성립하지 않을 수 있는 범위는 [메모 태그 스펙](../common/memo-tag.md)의 `동기화에서의 대표 태그와 연결`을 따른다.

### 연결의 의미

[항목 태그 연결 공통 스펙](../common/entity-tag.md)의 `연결의 의미`는 메모와 태그의 연결에서 다음 목록에 적용된다.

- [MemoHome 목록 스펙](./memo-home.md)의 목록 노출 기준과 정렬. 사용자가 고른 태그 필터와 유무 필터의 태그 축만 예외로 이 연결이 판정에 쓰이며, 그 기준은 MemoHome 목록 스펙의 `유무 필터 기준`과 [태그 필터 스펙](./tag-filter.md)을 따른다.
- [캘린더 메모 표시 스펙](./calendar-memo.md)의 노출 기준. [CalendarHome 스펙](./calendar-home.md)에서 사용자가 고른 태그 필터만 예외이며, 그 기준은 CalendarHome 스펙의 `태그 필터 기준`을 따른다.
- [SearchHome 화면 스펙](./search-home.md)의 메모 검색 결과. 연결된 태그의 제목은 메모의 검색 일치 판정에 쓰이지 않는다.

태그로 메모를 조회하는 [TagDetail 메모 탭 스펙](./tag-detail-memo.md)의 목록은 이 연결을 노출 기준으로 쓴다.

## data

### 대표 태그를 함께 바꾸는 저장

연결 해제와 대표 태그 지정 해제, 대표 태그 지정과 연결 생성처럼 연결과 메모를 함께 바꿔야 하는 경우에도 기기의 하나의 저장 작업으로 함께 반영해 한쪽만 반영된 기기 상태가 남지 않게 한다. 저장이 실패하면 연결과 대표 태그 지정 모두 바꾸기 전 상태로 남는다.
