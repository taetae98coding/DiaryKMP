# SettingFile 화면 스펙

이 문서는 사용자가 설정 화면의 `파일` 항목에서 진입하는 SettingFile 화면의 내용과 행동을 다룬다. 설정 항목의 표시와 선택은 [SettingHome 화면 스펙](./setting-home.md)에서, 설정 목록과 함께 사용할 때의 선택·뒤로가기 정책은 [Setting 목록·상세 배치 스펙](./setting-list-detail.md)에서, 세부 화면에서의 공통 내비게이션 노출 규칙은 [TopLevelNavigation 스펙](./top-level-navigation.md)에서 다룬다. 고른 위치에 파일을 내려받는 흐름과 플랫폼별 기본 위치는 [파일 내려받기 스펙](./file-download.md)에서 다룬다.

디자인: [SettingFile 화면 디자인](../../design/setting-file.md)

이번 범위는 사용자가 파일을 내려받을 폴더를 고르거나 기본 위치로 되돌리고, 그 설정이 기기에 유지되는 것까지다.

## feature

### 진입과 이동

사용자는 설정 화면의 `파일` 항목을 선택해 SettingFile 화면으로 이동한다.

SettingFile 화면은 설정 목록과 함께 표시되거나 단독으로 표시될 수 있다. 두 상태 모두 공통 내비게이션을 제공하지 않으며, 표시 관계는 [Setting 목록·상세 배치 스펙](./setting-list-detail.md)을 따른다.

이 화면은 Android, iOS와 데스크톱 앱에서만 진입할 수 있다. 웹은 브라우저가 다운로드 위치를 정하므로 SettingHome이 `파일` 항목을 제공하지 않는다.

### 다운로드 위치 확인

사용자는 지금 파일을 내려받는 위치를 확인한다.

| 설정 | 표시 |
| --- | --- |
| 고른 폴더가 없다 | 기본 위치를 쓴다는 것과 그 기본 위치. 기본 위치는 [파일 내려받기 스펙](./file-download.md)의 `feature > 제공 범위`를 따른다 |
| 고른 폴더가 있다 | 고른 폴더 |

고른 폴더는 고를 때 시스템이 알려 준 이름으로 보여 주고, 시스템이 이름을 알려 주지 않았으면 이름 없이 고른 폴더가 있다는 것만 보여 준다. 데스크톱 앱에서는 폴더의 전체 경로도 함께 보여 준다. 고른 폴더가 지금도 있는지, 아직 쓸 수 있는지는 화면에서 확인하지 않는다. 쓸 수 없게 되었는지는 내려받을 때 [파일 내려받기 스펙](./file-download.md)의 `feature > 내려받기 결과`로 알게 된다.

저장된 설정을 확인하기 전이거나 읽지 못했으면 위치와 동작을 표시하지 않으며 별도 로딩 또는 오류 상태로 전환하지 않는다.

### 폴더 고르기

사용자는 폴더 고르기를 실행해 기기가 제공하는 폴더 선택 도구를 열고 폴더 하나를 고를 수 있다. 폴더를 고르면 곧바로 저장되고, 화면의 위치가 고른 폴더로 바뀐다. 저장 동작을 따로 실행하지 않는다.

폴더를 고르지 않고 선택 도구를 닫으면 설정은 바뀌지 않는다.

고른 폴더를 앱이 계속 쓸 수 있도록 시스템이 허락하지 않거나 저장에 실패하면 설정을 바꾸지 않고 다운로드 위치를 바꾸지 못했다고 알린다.

이미 고른 폴더가 있어도 다시 고를 수 있으며, 새로 고른 폴더로 바뀐다.

### 기본 위치로 되돌리기

고른 폴더가 있을 때 사용자는 기본 위치로 되돌릴 수 있다. 실행하면 고른 폴더를 지우고 기본 위치를 쓴다. 고른 폴더가 없으면 이 동작을 제공하지 않는다.

되돌리기에 실패하면 고른 폴더를 그대로 두고 다운로드 위치를 바꾸지 못했다고 알린다.

되돌려도 고른 폴더와 그 안에 내려받은 파일은 지우지 않는다.

### 뒤로가기

단독으로 표시될 때와 설정 목록과 함께 표시될 때의 뒤로가기 결과는 모두 [Setting 목록·상세 배치 스펙](./setting-list-detail.md)의 `뒤로가기`를 따른다.

바꾼 설정은 뒤로가기로 화면을 떠나도 그대로 유지된다.

## domain

### 다운로드 위치 설정

다운로드 위치 설정은 Android, iOS와 데스크톱 앱에서 파일을 내려받을 폴더다. 사용자가 고른 폴더 하나이거나, 고른 폴더가 없는 상태 중 하나다. 고른 폴더가 없으면 [파일 내려받기 스펙](./file-download.md)이 정한 플랫폼별 기본 위치를 쓴다.

사용자가 한 번도 고르지 않았으면 고른 폴더가 없다.

Android와 iOS에서는 시스템의 폴더 선택 도구에서 고른 폴더만 쓸 수 있다. 앱은 고를 때 그 폴더를 계속 쓸 수 있게 해 달라고 시스템에 요청하고, 허락받은 경우에만 설정으로 저장한다.

### 화면에 보이는 값

화면의 위치는 저장된 설정을 따르므로 사용자가 고르거나 되돌리면 새로고침 없이 바로 바뀐 위치를 보여 준다. 이 화면에는 당겨서 새로고침하는 수단이 없다.

### 요청 제한

폴더를 고른 결과를 저장하거나 되돌리는 동안에는 폴더 고르기와 되돌리기를 다시 처리하지 않는다. 폴더 선택 도구가 열려 있는 동안 화면이 다시 만들어지면 선택 도구에서 고른 폴더는 다시 만들어진 화면에서 저장한다.

## data

### 저장 시점과 유지

사용자가 폴더를 고르거나 기본 위치로 되돌리면 그 시점에 기기에 저장된다. 저장된 설정은 화면을 떠나거나 화면이 재생성되어도, 앱이 백그라운드에 다녀와도, 앱을 종료하고 다시 시작해도 유지된다.

저장된 값을 읽을 수 없으면 설정을 아직 확인하지 못한 상태로 다룬다. 이는 고른 폴더가 없어 기본 위치를 쓰는 것과 구분된다.

### 폴더를 쓸 수 있는 허락

폴더를 고르면 앱은 그 폴더를 계속 쓸 수 있는 허락을 시스템에 받아 둔다. 다른 폴더로 바꾸거나 기본 위치로 되돌리면 앞서 받아 둔 허락을 시스템에 돌려준다. 시스템이 앱에 허락하는 폴더 수에는 한도가 있기 때문이다. 허락을 돌려주어도 폴더와 그 안의 파일은 그대로 남는다.

### 기기별 보관

다운로드 위치 설정은 사용자 계정이 아니라 기기에 보관하며 서버와 동기화하지 않는다. 로그인, 로그아웃, 계정 전환으로 바뀌지 않으며 다른 기기에도 반영되지 않는다. 폴더는 기기마다 다르기 때문이다.

다운로드 위치 설정은 [데이터 동기화 스펙](../common/data-sync.md)의 동기화 대상이 아니다.

### 환경별 저장 영역

Android, iOS와 데스크톱 앱은 [SettingMap 화면 스펙](./setting-map.md)의 `환경별 저장 영역`이 정한 각 환경의 저장 영역을 그대로 쓴다. 웹은 이 설정을 저장하지 않는다.
