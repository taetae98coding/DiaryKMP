# Tag 목록·상세 배치 스펙

이 문서는 태그 주요 목적지에서 목록과 상세를 함께 사용할 때 이 배치에만 해당하는 상세 선택 상태와 초기화 경계를 다룬다. 함께 사용과 단독 사용, 상세 선택과 교체, 선택이 없을 때의 추가, 추가 진입 수단, 뒤로가기, 표시 비율 조절, 배치에 참여하는 화면과 유지·초기화의 공통 기준은 [목록·상세 배치 공통 스펙](./list-detail-pane.md)을 따른다. 각 화면의 내용과 행동은 [TagAdd 화면 스펙](./tag-add.md), [TagDetail 화면 스펙](./tag-detail.md) 등 해당 화면 스펙에서 다룬다. TagFinishedList에서 사용하는 목록·상세 배치는 [TagFinishedList 목록·상세 배치 스펙](./tag-finished-list-detail.md)에서 다룬다.

디자인: [Tag 목록·상세 배치 디자인](../../design/tag-list-detail.md)

크기 조절 결과는 화면 표시 상태일 뿐 사용자 데이터가 아니므로 `data` 영역은 생략한다.

## feature

### 상세 영역의 구성

선택한 태그가 없으면 상세 영역에서 새 태그를 추가할 수 있으며, 그 결과는 [목록·상세 배치 공통 스펙](./list-detail-pane.md)의 `선택이 없을 때의 추가`를 따른다. 이 자리에서 추가한 태그는 목록에 나타날 뿐 다른 태그 입력에 선택된 것으로 돌려주지 않는다.

목록에서 태그를 선택하거나 교체한 결과는 [목록·상세 배치 공통 스펙](./list-detail-pane.md)의 `상세 선택과 교체`를 따르며, 연결한 태그를 눌러 이어 본 태그 상세들도 함께 정리된다.

태그 상세가 놓인 동안 목록에서 태그 추가를 실행한 결과는 [목록·상세 배치 공통 스펙](./list-detail-pane.md)의 `추가 진입 수단`을 따른다.

상세 영역의 태그 상세와 태그 추가에서 이어 연 화면, 즉 연결 입력으로 연 태그 추가와 연결한 태그의 상세도 상세 영역에 놓인다. 이 중 이전 상세로 돌아가는 동작을 제공하는 화면은 [TagDetail 화면 스펙](./tag-detail.md)의 `뒤로가기`가 정한다.

선택한 태그가 없어 상세 영역에 놓인 새 태그 추가에서 연결한 태그를 누르면 목록에서 그 태그를 선택한 것과 같이 상세 영역이 그 태그의 상세로 바뀐다.

메모 태그 입력, 태그 필터, 다른 항목의 태그 입력처럼 태그 목록이 아닌 곳에서 연 태그 추가와 태그 상세는 이 배치에 참여하지 않고 단독으로 표시한다. TagFinishedList에서 연 태그 상세는 이 배치 대신 [TagFinishedList 목록·상세 배치 스펙](./tag-finished-list-detail.md)을 따른다.

한 화면만 제공하는 환경에서는 목록, 태그 추가 또는 태그 상세를 각각 단독 화면으로 사용한다.

### 뒤로가기

뒤로가기의 결과는 [목록·상세 배치 공통 스펙](./list-detail-pane.md)의 `뒤로가기`를 따른다. 이 배치를 떠나는 결과, 즉 태그 목록에서 뒤로가기를 사용한 결과는 [TopLevelNavigation 스펙](./top-level-navigation.md)을 따른다.

### 정렬과 필터

목록의 정렬 선택과 필터는 배치와 관계없이 [TagHome 목록 스펙](./tag-home.md)을 따른다. 상세 영역에 태그 추가나 태그 상세가 놓여 있어도 목록의 정렬과 필터를 그대로 사용할 수 있고, 필터를 여는 동안에도 상세 영역에 놓인 화면은 바뀌지 않는다. 따라서 필터를 여는 동안에도 목록에서 태그 추가를 실행할 수 있는지는 필터를 열기 전과 같다.

## domain

### 유지와 초기화 기준

태그는 주요 목적지이므로 공통 내비게이션에서 다른 주요 목적지로 이동하는 것을 이 배치를 떠난 것으로 본다. 다른 주요 목적지에 다녀와 태그로 돌아오거나 앱을 종료하고 다시 실행하면 [목록·상세 배치 공통 스펙](./list-detail-pane.md)의 `유지와 초기화 기준`에 따라 초기화하며, 떠나기 전에 상세 영역에 놓였던 화면으로 돌아가는 뒤로가기 기록도 남지 않는다.

선택한 태그가 없을 때 상세 영역에 놓이는 태그 추가의 작성 내용은 같은 절을 따른다. 이 배치를 떠나기 전까지는 연결 입력으로 연 태그 추가나 TagFinishedList 화면에 다녀와도, 입력하던 이모지, 제목, 설명, 컬러와 고른 연결이 그대로 남는다. 다른 주요 목적지에 다녀와 태그로 돌아오면 상세 영역의 태그 추가는 이모지, 제목과 설명이 비어 있고 고른 연결이 하나도 없는 상태로 시작하며, 컬러에는 새 무작위 값이 제시된다. 화면 재생성에서 무엇이 남는지는 [TagAdd 화면 스펙](./tag-add.md)의 `작성 상태 유지 대상`을 따른다.

태그 목록에서 완료된 태그 확인을 선택해 TagFinishedList 화면에 다녀오는 것은 이 배치를 떠난 것으로 보지 않는다. TagFinishedList 화면에서 태그 목록으로 돌아오면 이 배치의 상세 선택과 표시 비율, 상세 영역에서 그 전에 놓였던 화면으로 돌아가는 뒤로가기 기록은 TagFinishedList로 떠나기 전 그대로다. TagFinishedList 화면 자체의 배치는 [TagFinishedList 목록·상세 배치 스펙](./tag-finished-list-detail.md)을 따른다.
