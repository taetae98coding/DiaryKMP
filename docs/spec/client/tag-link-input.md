# 태그 연결 입력 컴포넌트 스펙

이 문서는 TagAdd 화면과 TagDetail 화면에서 함께 사용하는 태그 연결 입력 가운데 이 입력에만 해당하는 부분을 다룬다. 태그를 고르는 행동과 판정 기준은 [태그 선택 입력 공통 스펙](./tag-select-input.md)을 따르고, 구체적인 구성과 조작 수단은 [태그 연결 입력 컴포넌트 디자인](../../design/tag-link-input.md)에서 다룬다.

태그와 태그의 연결 규칙은 [태그 연결 스펙](../common/tag-link.md)을 따른다.

사용자가 반영한 선택이 언제 저장된 연결이 되는지는 화면마다 다르므로 이 문서에서 다루지 않는다. TagAdd 화면에서는 추가할 태그의 연결 대상으로만 반영되고, TagDetail 화면에서는 상세 대상 태그의 저장된 연결로 즉시 반영되며, 각각 [TagAdd 화면 스펙](./tag-add.md)과 [TagDetail 화면 스펙](./tag-detail.md)을 따른다.

디자인: [태그 연결 입력 컴포넌트 디자인](../../design/tag-link-input.md)

## 공통 스펙과의 용어 대응

[태그 선택 입력 공통 스펙](./tag-select-input.md)의 용어는 이 입력에서 다음을 뜻한다.

| 공통 스펙 용어 | 이 입력에서의 뜻 |
| --- | --- |
| 선택 | 출발 태그에서 고른 태그로 향하는 연결, 선택 해제는 그 연결의 해제 |
| 표시 대상 태그 | 연결 대상으로 표시하는 태그 |
| 추가 항목 | 연결 추가 항목 |

이 문서에서 `출발 태그`는 연결 입력이 있는 화면이 다루는 태그를 가리킨다.

## feature

### 태그 추가 이동으로 더해지는 연결

이동과 돌아왔을 때의 자동 선택은 [태그 선택 입력 공통 스펙](./tag-select-input.md)의 `태그 추가 이동`을 따른다.

자동 선택된 태그는 사용자가 태그 선택 목록에서 고른 태그와 같게 출발 태그의 연결 대상이 된다. 이 입력에는 자동 선택이 함께 바꾸는 다른 상태가 없다.

TagAdd 화면의 연결 입력에서 태그 추가로 이동하면 또 다른 TagAdd 화면이 열린다. 두 화면은 각각 자기 입력 내용과 고른 연결을 따로 가지며, 이때의 자동 선택은 [TagAdd 화면 스펙](./tag-add.md)의 `연결 입력의 태그 추가 이동`을 따른다.

### 검색어 입력의 초점

태그 선택 목록을 열어도 입력 초점은 검색어 입력에 두지 않는다. 사용자는 검색어 입력을 눌러 검색을 시작한다. 초점을 두지 않을 때의 결과는 [태그 선택 입력 공통 스펙](./tag-select-input.md)의 `태그 검색`을 따른다.

### 연결의 방향

연결 입력에서 만드는 연결은 언제나 그 화면이 다루는 태그를 출발 태그로 하고 사용자가 선택한 태그를 도착 태그로 한다. 반대 방향의 연결은 이 입력에서 만들지 않으며, 향해 오는 연결도 이 입력에 표시하지 않는다.

태그를 눌러 태그 상세로 이동해도 그 태그의 연결은 바뀌지 않는다.

## domain

### 연결 대상으로 표시하는 태그

기준은 [태그 선택 입력 공통 스펙](./tag-select-input.md)의 `표시 대상 태그`를 따른다.

완료된 태그를 연결 대상으로 표시하는지는 화면마다 다르다. TagAdd 화면은 [TagAdd 화면 스펙](./tag-add.md)의 `연결 대상 선택과 태그 추가 성립 조건`을, TagDetail 화면은 [TagDetail 화면 스펙](./tag-detail.md)의 `연결 입력에 표시하는 태그`를 따른다.

저장된 연결이 유지되는 규칙은 [태그 연결 앱 스펙](./tag-link.md)의 `태그의 상태 변화와 연결`을 따른다.

### 선택할 수 있는 태그

기준은 [태그 선택 입력 공통 스펙](./tag-select-input.md)의 `선택할 수 있는 태그`를 따른다.

출발 태그가 정해진 화면에서는 출발 태그 자신을 선택할 수 있는 태그에서 제외한다. 태그를 자기 자신과 연결할 수 없다는 규칙은 [태그 연결 스펙](../common/tag-link.md)의 `태그와 태그의 연결`을 따른다.

### 태그 선택 목록에 나타나는 태그

기준은 [태그 선택 입력 공통 스펙](./tag-select-input.md)의 `태그 선택 목록에 나타나는 태그`를 따르며, 이 입력에서는 선택할 수 있는 태그에서 출발 태그가 빠진다.

TagAdd 화면은 연결 대상으로 표시하는 태그가 선택할 수 있는 태그와 같으므로 목록에도 선택할 수 있는 태그만 나타나고, TagDetail 화면은 [TagDetail 화면 스펙](./tag-detail.md)의 `연결 입력에 표시하는 태그`에 따라 연결된 완료된 태그가 함께 나타난다.

## data

### 태그 목록 조회

조회 흐름은 [태그 선택 입력 공통 스펙](./tag-select-input.md)의 `태그 목록 조회`를 따른다.

TagAdd 화면은 선택할 수 있는 태그만 조회하고, TagDetail 화면은 [TagDetail 화면 스펙](./tag-detail.md)의 `연결 입력의 조회`를 따른다.
