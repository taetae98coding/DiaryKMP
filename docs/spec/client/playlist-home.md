# PlaylistHome 화면 스펙

이 문서는 사용자가 `더보기`의 `플레이리스트` 바로가기로 진입하는 PlaylistHome 화면의 내용과 행동을 다룬다. 항목 목록 화면이 공통으로 따르는 노출 기준, 목록 갱신과 조회, 추가·상세로 이동, 목록에서의 삭제와 실행 취소, 화면 유지는 [항목 목록 화면 공통 스펙](./entity-home.md)를 따르며, 이 문서에는 곡 목록에만 있는 내용을 둔다. 바로가기 항목의 표시와 선택은 [MoreHome 화면 스펙](./more-home.md)에서, 세부 화면에서의 공통 내비게이션 노출 규칙은 [TopLevelNavigation 스펙](./top-level-navigation.md)에서, 곡을 작성해 추가하는 흐름과 곡이 갖는 정보는 [MusicAdd 화면 스펙](./music-add.md)에서, 선택한 곡을 확인하고 수정하고 상세에서 삭제하는 흐름은 [MusicDetail 화면 스펙](./music-detail.md)에서, 목록 카드에서 삭제를 실행하는 상호작용의 공통 규칙은 [SwipeToFinishAndDelete 컴포넌트 스펙](./swipe-to-finish-and-delete.md)에서, 곡 목록과 곡 추가를 함께 사용하는 배치는 [Playlist 목록·상세 배치 스펙](./playlist-list-detail.md)에서, 나누어 불러오는 목록이 나타나는 순서와 아직 준비되지 않은 자리의 처리는 [페이지 조회 목록의 자리 표시 스펙](./paged-list-placeholder.md)에서, 목록이 비어 있을 때의 안내는 [목록 빈 상태 스펙](./list-empty-state.md)에서, 목록을 당겨 새로고침하는 행동과 동기화 진행 표시는 [새로고침 스펙](./sync-refresh.md)에서, 곡을 서버와 맞추는 규칙은 [데이터 동기화 스펙](../common/data-sync.md)에서 다룬다.

디자인: [PlaylistHome 화면 디자인](../../design/playlist-home.md)

이번 범위는 `더보기`에서 PlaylistHome으로 이동하고, 계정에 저장된 곡을 기기에서 불러와 목록으로 표시하고, 목록을 당겨 새로고침하고, PlaylistHome에서 곡 추가와 곡 상세로 이동하고, 목록에서 곡을 삭제하고 되돌리는 것까지다. 곡을 앱 안에서 재생하거나 기기에 내려받는 것은 이번 범위에서 다루지 않는다.

## feature

### 진입

사용자는 `더보기` 화면의 기능 바로가기에서 `플레이리스트` 항목을 선택해 PlaylistHome 화면으로 이동한다.

### 곡 목록

사용자는 PlaylistHome에서 계정에 저장된 곡 전체를 목록으로 볼 수 있다. 사용자는 각 항목의 썸네일과 제목과 가수를 확인한다.

썸네일은 그 곡의 링크에서 정해진다. 링크에서 영상을 가리키는 곡은 그 영상의 썸네일을 함께 보여 주고, 링크가 없거나 링크가 영상을 가리키지 않거나 썸네일 주소를 열 수 없는 곡은 이미지 자리를 비워 둔 채 같은 크기로 보여 준다. 어떤 링크에서 썸네일이 정해지는지는 [MusicAdd 화면 스펙](./music-add.md)의 `썸네일의 판정`을 따른다.

가수가 없는 곡은 가수 자리를 비운 채 제목으로 확인한다. 가수가 없는 곡도 목록에서 빠지지 않는다.

목록이 나타나는 순서, 아직 준비되지 않은 자리와 추가한 곡이 목록에 나타나는 조건은 [항목 목록 화면 공통 스펙](./entity-home.md)의 `목록 표시`를 따른다.

### 곡 상세로 이동

사용자는 목록에서 곡을 선택해 그 곡의 [MusicDetail 화면](./music-detail.md)으로 이동한다. 준비되지 않은 자리와 돌아왔을 때의 목록은 [항목 목록 화면 공통 스펙](./entity-home.md)의 `상세로 이동`을 따른다.

목록과 상세를 함께 사용하는 환경에서는 이동하지 않고 상세 영역이 그 곡의 상세로 바뀌며, 그 기준은 [Playlist 목록·상세 배치 스펙](./playlist-list-detail.md)의 `상세 영역의 구성`을 따른다.

### 삭제

사용자는 목록의 곡을 삭제할 수 있다. 곡에는 완료 여부가 없으므로 삭제 방향만 제공하며, 삭제와 실행 취소의 결과는 [항목 목록 화면 공통 스펙](./entity-home.md)의 `삭제`를 따른다.

### 안내와 실행 취소

삭제의 안내와 실행 취소는 [항목 목록 화면 공통 스펙](./entity-home.md)의 `안내와 실행 취소`를 따른다.

### 빈 상태

표시할 곡이 하나도 없으면 목록 자리에 아직 곡이 없으며 새로 추가할 수 있음을 알린다. 판정 시점, 빈 상태에서 할 수 있는 행동, 목록과의 전환은 [목록 빈 상태 스펙](./list-empty-state.md)을 따른다.

빈 상태에서도 사용자는 곡 추가와 당겨서 새로고침을 그대로 실행할 수 있다.

### 새로고침

목록을 당겨 새로고침하는 행동과 결과는 [항목 목록 화면 공통 스펙](./entity-home.md)의 `새로고침`을 따른다.

### 곡 추가로 이동

사용자는 PlaylistHome에서 곡 추가를 선택해 [MusicAdd 화면](./music-add.md)으로 이동한다. 언제 제공하는지, 추가 단축키, 목록과 상세를 함께 사용하는 동안의 추가 수단과 돌아왔을 때의 결과는 [항목 목록 화면 공통 스펙](./entity-home.md)의 `추가로 이동`을 따른다.

### 뒤로가기

뒤로가기의 결과는 [항목 목록 화면 공통 스펙](./entity-home.md)의 `뒤로가기`를 따르며, 상세 영역과 함께 표시되는 상태에서의 결과는 [Playlist 목록·상세 배치 스펙](./playlist-list-detail.md)의 `뒤로가기`를 따른다.

### 정렬 선택

사용자는 목록 위에서 현재 정렬을 확인하고 다른 기준으로 바꿀 수 있다. 고를 수 있는 기준과 정렬 선택·반영·유지의 결과는 [목록 정렬 스펙](./list-sort.md)을 따른다.

## domain

### 상세로 이동할 수 있는 곡

목록에 노출된 곡은 모두 상세로 이동할 수 있다. 아직 준비되지 않은 자리는 어떤 곡도 가리키지 않으므로 상세로 이동하는 대상이 아니며, 그 자리의 처리는 [페이지 조회 목록의 자리 표시 스펙](./paged-list-placeholder.md)을 따른다.

상세로 이동한 뒤 대상 곡을 어떤 기준으로 조회하는지는 [MusicDetail 화면 스펙](./music-detail.md)의 `상세 대상과 내용 표시`를 따르므로, 목록에 노출되지 않는 삭제된 곡도 상세에서는 계속 표시된다.

### 목록에 노출하는 곡

노출 기준은 [항목 목록 화면 공통 스펙](./entity-home.md)의 `목록에 노출하는 항목`을 따른다. 곡에는 더하는 상태 조건이 없다.

### 목록 정렬

목록은 제목 오름차순으로 정렬한다. 제목이 같은 곡끼리의 순서는 정하지 않는다. 가수는 정렬 기준으로 쓰지 않는다.

위 순서는 사용자가 정렬을 고르지 않았을 때의 순서이며, 사용자가 고를 수 있는 다른 기준과 그 순서는 [목록 정렬 스펙](./list-sort.md)이 정한다.

### 목록 갱신

목록의 자동 갱신은 [항목 목록 화면 공통 스펙](./entity-home.md)의 `목록 갱신`을 따른다.

### 삭제와 실행 취소의 상태 전이

목록의 삭제와 실행 취소는 [항목 목록 화면 공통 스펙](./entity-home.md)의 `삭제와 실행 취소의 상태 전이`를 따른다.

## data

### 삭제와 실행 취소의 저장

삭제와 실행 취소의 저장과 동기화는 [항목 목록 화면 공통 스펙](./entity-home.md)의 `삭제와 실행 취소의 저장`을 따른다.

### 목록 조회

목록의 조회, 조회 실패와 서버에서 다시 가져오는 계기는 [항목 목록 화면 공통 스펙](./entity-home.md)의 `목록 조회`를 따른다.
