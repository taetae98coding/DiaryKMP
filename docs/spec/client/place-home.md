# PlaceHome 화면 스펙

이 문서는 사용자가 `더보기`의 `장소` 메뉴에서 진입하는 PlaceHome 화면의 내용과 행동을 다룬다. `더보기` 메뉴 영역의 표시와 선택은 [MoreHome 화면 스펙](./more-home.md)에서, 세부 화면에서의 공통 내비게이션 노출 규칙은 [TopLevelNavigation 스펙](./top-level-navigation.md)에서 다룬다.

보기 모드 전환, 지도와 지도 위 핀의 표시, 두 모드의 목록과 빈 상태, 장소 추가와 장소 상세로 이동할 때 넘기는 것, 목록 정렬과 새로고침의 공통 기준은 [장소 보기 모드 스펙](./place-view-mode.md)이 소유한다. 이 문서에는 PlaceHome이 정하는 기본 보기 모드, 노출 대상 장소, 현재 위치 확인 시점, 두 보기 모드의 목록에서 장소를 삭제하고 되돌리는 행동과 보기 모드 밖에서 함께 제공하는 행동만 둔다.

본문에 표시되는 지도의 표시와 지도 제공자 전환은 [DiaryMap 컴포넌트 스펙](./diary-map.md)에서, 기본 지도를 고르고 저장하는 흐름은 [SettingMap 화면 스펙](./setting-map.md)에서, 장소를 작성해 추가하는 흐름은 [PlaceAdd 화면 스펙](./place-add.md)에서, 선택한 장소의 상세를 확인하고 수정하고 삭제하는 흐름은 [PlaceDetail 화면 스펙](./place-detail.md)에서, 화면에서 검색으로 이동한 뒤의 내용과 행동은 [SearchHome 화면 스펙](./search-home.md)에서, 현재 위치를 확인하는 규칙은 [현재 위치 확인 스펙](./current-location.md)에서, 당겨서 새로고침하는 조작과 진행 표시의 공통 기준은 [새로고침 스펙](./sync-refresh.md)에서, 나누어 불러오는 목록이 나타나는 순서와 아직 준비되지 않은 자리의 처리는 [페이지 조회 목록의 자리 표시 스펙](./paged-list-placeholder.md)에서, 장소를 서버와 맞추는 규칙은 [데이터 동기화 스펙](../common/data-sync.md)에서 다룬다.

이번 범위는 `더보기`에서 PlaceHome으로 이동하고, PlaceHome 화면 본문에 장소 보기 모드를 배치해 계정의 장소를 목록과 지도로 확인하고, 목록에서 장소를 삭제하고 되돌리고, 장소 추가와 장소 상세, 검색으로 이동하는 것까지다. 위치 권한 요청, 지도에서 장소를 찾는 검색과 경로 안내 같은 부가 기능은 이번 범위에 포함하지 않는다. 지도 위 현 위치 표시는 [DiaryMap 컴포넌트 스펙](./diary-map.md)의 현 위치 표시를 따른다. 저장된 항목을 찾는 검색으로 이동하는 것은 이번 범위에 포함하며, 이동한 뒤의 행동은 [SearchHome 화면 스펙](./search-home.md)이 다룬다.

디자인: [PlaceHome 화면 디자인](../../design/place-home.md)

## feature

### 진입

사용자는 `더보기` 화면의 메뉴 영역에서 `장소` 항목을 선택해 PlaceHome 화면으로 이동한다.

화면에 진입하면 지도 모드로 시작한다. 진입한 뒤 사용자가 보기 모드를 바꾸고 지도와 목록을 다루는 행동은 [장소 보기 모드 스펙](./place-view-mode.md)을 따른다.

### 삭제

사용자는 두 보기 모드의 목록에서 장소를 삭제할 수 있다. 목록 카드에서 삭제를 실행하는 상호작용은 [SwipeToFinishAndDelete 컴포넌트 스펙](./swipe-to-finish-and-delete.md)을 따르며, 장소에는 완료 여부가 없으므로 삭제 방향만 제공한다. 삭제를 실행하기 전에 확인을 되묻지 않는다.

삭제하면 장소가 목록에서 사라지고 삭제되었음을 안내하며, 실행 취소 동작을 제공한다. 지도 모드에서는 그 장소의 지도 핀도 함께 사라진다.

사용자가 실행 취소를 선택하면 장소는 삭제되지 않은 상태로 되돌아가, 지금 보기 모드의 노출 기준을 만족하면 목록의 정렬 기준에 맞는 위치에 다시 나타나고 지도 모드에서는 지도 핀에도 다시 나타난다.

지도 핀에서는 삭제를 실행할 수 없다. 핀을 누르는 결과는 [장소 보기 모드 스펙](./place-view-mode.md)의 `장소 상세로 이동`을 따른다.

아직 준비되지 않은 자리는 삭제할 수 없다.

### 안내와 실행 취소

삭제의 안내는 사용자가 실행 취소를 선택하지 않으면 잠시 뒤 저절로 사라지며, 사라진 뒤에는 그 삭제를 목록에서 되돌릴 수 없다.

안내가 보이는 동안 다른 장소를 이어서 삭제하면 앞의 안내는 바로 사라지고 새 삭제의 안내만 보인다. 이때 실행 취소는 마지막 삭제에만 적용되며, 앞의 삭제는 되돌려지지 않는다.

삭제가 저장되지 못하면 장소의 상태는 바뀌지 않고 안내도 보이지 않는다.

안내가 보이는 동안 보기 모드를 바꿔도 같은 화면에 머무르는 것이므로 안내는 그대로 남고, 사용자는 바꾼 보기 모드에서 실행 취소를 선택할 수 있다.

기준은 [MemoHome 목록 스펙](./memo-home.md)의 `삭제`와 `안내와 실행 취소`와 같으며, 안내가 보이는 동안 화면을 떠났을 때의 결과도 그 절을 따른다. [PlaceDetail 화면 스펙](./place-detail.md)의 `삭제`는 화면을 떠나는 동작이므로 실행 취소를 제공하지 않으며, 이 절은 그 규칙을 바꾸지 않는다.

### 검색으로 이동

사용자는 PlaceHome에서 검색을 선택해 [SearchHome 화면](./search-home.md)으로 이동한다.

이동한 화면은 장소 검색 결과부터 보여 준다. 시작 유형의 기준은 [SearchHome 화면 스펙](./search-home.md)의 `진입 경로와 시작 유형`을 따른다.

검색은 지도 기능의 표시 여부와 보기 모드에 무관하게 언제나 실행할 수 있다. 지도가 보고 있는 영역은 검색 결과를 좁히지 않으므로, 사용자는 지도 밖에 있는 장소도 검색으로 찾는다.

사용자가 검색 화면에서 뒤로 가면 PlaceHome으로 돌아오며, 검색으로 떠나기 전의 보기 모드와 지도가 보고 있던 위치, 확대 수준, 고른 지도 제공자를 그대로 본다.

### 뒤로가기

사용자가 뒤로가기를 실행하면 [TopLevelNavigation 스펙](./top-level-navigation.md)의 `더보기 하위 화면의 뒤로가기`에 따라 `더보기`로 돌아간다.

## domain

### 기본 보기 모드

PlaceHome의 기본 보기 모드는 지도 모드다. 화면에 진입하면 지도 모드에서 시작하고, 화면을 떠난 뒤 다시 들어와도 지도 모드에서 다시 시작한다.

보기 모드가 무엇을 노출하는지와 어떤 경계에서 유지되고 초기화되는지는 [장소 보기 모드 스펙](./place-view-mode.md)의 `보기 모드`와 `보기 모드의 유지`를 따른다.

### 노출 대상 장소

PlaceHome의 노출 대상 장소는 현재 사용자 계정과 연결되어 있고 삭제되지 않은 장소다. 두 보기 모드가 이 집합을 함께 사용하며, 지도 모드는 여기에 보이는 영역 기준을 더한다.

두 모드가 이 집합을 어떻게 쓰는지는 [장소 보기 모드 스펙](./place-view-mode.md)의 `목록 모드에 노출하는 장소`와 `지도 모드에 노출하는 장소`를 따른다.

### 현재 위치 확인 시점

PlaceHome은 화면에 진입할 때 보기 모드와 관계없이 현재 위치를 한 번 확인한다. 화면에 진입하면 지도 모드로 시작하므로 진입 시점이 곧 지도가 필요한 시점이다.

앱이 백그라운드에 있는 동안 시스템이 앱을 종료했다가 같은 PlaceHome 화면으로 되살리면, 되살아난 보기 모드와 관계없이 되살아나는 즉시 현재 위치를 다시 확인한다. 목록 모드로 되살아났으면 지도 모드로 바꾸었을 때 이렇게 새로 확인한 위치에서 지도를 시작하며, 지도 모드로 바꿀 때 다시 확인하지 않는다.

확인 방법과 확인하지 못했을 때의 표시, 재확인하지 않는 경계는 [장소 보기 모드 스펙](./place-view-mode.md)의 `초기 지도 위치`를 따른다.

### 검색 결과의 범위

검색으로 이동하는 것은 보기 모드와 지도가 보고 있는 영역에 영향을 받지 않는다. 검색이 어떤 항목을 찾는지는 [SearchHome 화면 스펙](./search-home.md)이 정한다.

### 새로고침 대상

PlaceHome의 새로고침 대상은 계정 데이터의 서버 동기화 하나다. 대상과 진행 표시 기준, 중복 요청 처리는 [새로고침 스펙](./sync-refresh.md)을 따르고, 두 보기 모드에서 당길 수 있는 자리는 [장소 보기 모드 스펙](./place-view-mode.md)의 `장소 목록 새로고침`을 따른다.

새로고침 대상 자체는 지도 표시 여부와 보기 모드로 달라지지 않는다.

로그인하지 않은 상태에서 당기면 서버 동기화가 시작되지 않고 진행 표시도 나타나지 않는다. 이때 목록에 노출하는 장소가 없는 것은 `노출 대상 장소`가 따르는 계정 기준의 결과이며 새로고침이 만드는 결과가 아니다.

### 삭제와 실행 취소의 상태 전이

삭제는 장소의 삭제 여부를 삭제 상태로 바꾸는 것이며 장소 자체를 지우지 않는다. 제목, 설명, 컬러, 좌표, 주소와 메모·태그와의 연결은 바꾸지 않는다. 기준은 [PlaceDetail 화면 스펙](./place-detail.md)의 `domain > 삭제`와 같다.

실행 취소는 삭제 여부를 미삭제로 되돌린다. 연결을 바꾸지 않았으므로 실행 취소한 장소는 삭제 전의 메모·태그 연결을 그대로 가진다.

삭제와 실행 취소는 모두 장소의 수정 시각을 동작 시점으로 갱신한다. 따라서 실행 취소로 돌아온 장소는 최근 수정순에서 앞쪽에 놓인다.

목록에서 실행하는 삭제와 실행 취소는 현재 사용자 계정과 연결된 장소에만 적용된다.

## data

### 삭제와 실행 취소의 저장

목록에서 장소를 삭제하거나 실행 취소하면 현재 사용자 계정과 연결된 그 장소의 삭제 여부와 수정 시각이 기기에 즉시 저장된다. 장소 자체와 계정 연결, 메모와의 연결, 태그와의 연결은 기기에서 지우지 않는다.

저장하면 그 장소가 업로드 대기로 기록되고 화면 뒤에서 동기화가 시작되어, 같은 계정의 다른 기기에도 같은 상태로 보인다. 성공 여부는 기기에 저장한 결과로만 판단하며, 업로드 단위와 실패 시 재시도는 [데이터 동기화 스펙](../common/data-sync.md)을 따른다. 로그인하지 않은 상태에서 삭제하거나 되돌린 장소는 서버에 반영되지 않고 기기 안에만 유지된다.

실행 취소를 저장하지 못하면, 현재 계정을 확인할 수 없는 경우를 포함해 장소는 삭제된 채로 남아 목록과 지도 핀에 다시 나타나지 않으며 별도의 안내는 제공하지 않는다. 기준은 [MemoHome 목록 스펙](./memo-home.md)의 메모 삭제와 같다.

### 목록 조회

두 보기 모드의 목록과 지도 핀에 표시할 장소는 `노출 대상 장소`를 기준으로 기기에 저장된 장소에서 찾는다. 조회 방식과 갱신 기준은 [장소 보기 모드 스펙](./place-view-mode.md)의 `목록 조회`를 따른다.
