# 기기에 저장한 공휴일 스펙

이 문서는 원격에서 받아 온 국가·연도별 공휴일을 기기에 저장해 두고 꺼내 보는 규칙을 다룬다. 사용자에게 직접 노출되는 화면이나 사용자 행동은 없으므로 `feature` 영역은 생략한다.

## domain

### 국가·연도별 공휴일

공휴일은 국가와 조회 기준 연도가 같은 것끼리 하나의 묶음으로 저장한다. 국가는 [공휴일 국가 설정 스펙](./holiday-country.md)의 한국과 미국이다.

각 공휴일은 국가, 이름, 공휴일 여부, 시작일부터 종료일까지의 적용 기간을 가진다. 하루만 해당하는 공휴일은 시작일과 종료일이 같은 기간으로 다룬다.

공휴일 여부는 해당 날짜를 공휴일로 강조할 대상인지 구분하는 값이다. 이름은 있으나 공휴일 여부가 거짓인 날은 공휴일로 강조하지 않는다.

### 보관 기간

기기에 저장한 공휴일의 보관은 [연도별 자료 동기화 스펙](./yearly-data-sync.md)의 `기기 보관`을 따른다. 그 문서가 정한 경우 외에, 앱을 업데이트해 [공휴일 동기화 스펙](./holiday-fetch.md)의 `원격 제공처`에 따라 이전 제공처에서 받아 둔 공휴일을 더 이상 쓰지 않을 때도 저장된 공휴일이 바뀐다.

## data

### 연도별 조회

국가 집합과 연도를 정해 공휴일을 조회하면 그 국가들의 해당 연도에 기기에 저장된 공휴일을 합친 목록을 제공한다.

국가 집합이 비어 있거나 저장된 공휴일이 없으면 공휴일이 하나도 없는 목록을 제공한다. 조회 중인 국가·연도의 저장된 공휴일이 바뀌면 바뀐 목록을 별도 요청 없이 다시 제공한다.

목록은 시작일, 종료일, 이름 순으로 정렬한다. 이 셋이 모두 같으면 국가 순으로 정렬한다. 국가 순은 한국, 미국 순이다.

### 전체 조회

공휴일 설정을 위해 국가 집합을 정해 전체 공휴일을 조회하면 그 국가들의 기기에 저장된 모든 연도의 공휴일 목록을 제공한다.

국가 집합이 비어 있거나 저장된 공휴일이 없으면 공휴일이 하나도 없는 목록을 제공한다. 조회 중인 국가의 어느 연도든 저장된 공휴일이 바뀌면 최신 목록을 별도 요청 없이 다시 제공한다.

목록은 이름 순으로 정렬하고, 이름이 같으면 `연도별 조회`와 같은 국가 순으로 정렬한다.

### 연도별 교체

특정 국가·연도의 공휴일을 저장하면 기존에 저장된 해당 국가·연도의 공휴일을 모두 지우고 새 목록으로 바꾼다.

공휴일이 하나도 없는 목록을 저장하면 해당 국가·연도의 기존 공휴일을 모두 지운다.

한 국가·연도의 공휴일을 바꿔도 다른 국가나 다른 연도의 저장된 공휴일은 그대로 둔다.

지우기와 새로 저장하기는 한 번에 이루어진다. 교체가 끝까지 완료되지 못하면 해당 국가·연도의 기존 공휴일을 그대로 유지하며, 일부만 지워지거나 일부만 저장된 상태가 사용자에게 보이지 않는다.
