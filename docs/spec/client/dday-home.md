# DDayHome 화면 스펙

이 문서는 `더보기`의 `디데이` 바로가기로 진입하는 DDayHome 화면을 다룬다. 바로가기 항목의 표시와 선택은 [MoreHome 화면 스펙](./more-home.md)에서 다룬다.

디자인: [DDayHome 화면 디자인](../../design/dday-home.md)

## feature

### 화면 내용과 행동

DDayHome 화면의 진입, 화면 내용, 뒤로가기는 [더보기 준비 중 화면 공통 스펙](./more-menu-placeholder.md)을 따른다.

디데이로 제공할 사용자 행위는 아직 정하지 않았다. 이번 범위에서는 사용자가 `디데이` 바로가기로 이 화면에 들어오고 `더보기`로 돌아가는 것까지만 제공한다.
