# 데스크톱 앱 데이터 저장 위치 스펙

이 문서는 macOS 데스크톱 앱이 개발 환경과 운영 환경마다 기기에 데이터를 저장하는 위치를 다룬다. 화면에 표시되는 기능이나 사용자가 직접 수행하는 행동은 없으므로 `feature`와 `domain` 영역은 생략한다.

## data

### 환경별 저장 위치

데스크톱 앱의 개발 환경과 운영 환경은 서로 다른 저장 위치를 쓴다. 저장 위치는 사용자 홈 폴더의 `Library/Application Support` 아래에 둔다.

| 환경 | 저장 위치 |
| --- | --- |
| 개발 | `Library/Application Support/DiaryDev` |
| 운영 | `Library/Application Support/Diary` |

이 기기에 저장하는 메모와 항목 같은 사용자 데이터, 캘린더에 쓰는 자료, 앱 설정, 앱이 내려받아 보관하는 파일은 모두 그 환경의 저장 위치 한곳에 둔다.

한 환경에서 만들거나 바꾼 데이터는 다른 환경에서 보이지 않고 바뀌지도 않는다.

### 저장 위치 생성과 이전

앱은 그 환경의 저장 위치가 없으면 처음 사용할 때 만든다.

이미 있는 저장 위치의 데이터를 다른 환경의 저장 위치로 자동으로 옮기거나 복사하지 않는다.
