# 네이버 장소 검색 스펙

이 문서는 검색어로 장소를 네이버에서 찾아오는 조회 가운데 네이버에만 해당하는 부분을 다룬다. 제공자와 무관한 검색 계약은 [장소 검색 공통 스펙](./place-search.md)을 따른다.

같은 목적을 Google에서 수행하는 규칙은 [Google 장소 검색 스펙](./google-place-search.md)에서 다룬다. 어떤 제공자로 검색할지 고르는 규칙은 [장소 검색 다이얼로그 컴포넌트 스펙](./place-search-dialog.md)의 `검색 제공자`에서 다룬다.

사용자에게 직접 노출되는 화면이나 사용자 행동은 없으므로 `feature` 영역은 생략한다.

## domain

### 결과 개수와 정렬

한 번의 검색으로 받을 수 있는 장소는 네이버 정책에 따라 최대 5개다.

정렬은 따로 지정하지 않고 네이버 지역 검색 기본 정렬인 정확도순 결과를 사용한다.

### 장소 정보

검색된 장소 하나는 다음 정보를 갖는다.

- 장소 이름: 검색어와 일치하는 부분에 강조 표식이 포함될 수 있다.
- 분류: 장소의 업종이나 종류.
- 지번 주소와 도로명 주소: 한쪽이 비어 있을 수 있다.
- 좌표: 장소의 위도와 경도.
- 링크: 장소의 상세 정보 페이지 주소로, 없을 수 있다.
- 설명: 장소에 대한 부가 설명으로, 없을 수 있다.
