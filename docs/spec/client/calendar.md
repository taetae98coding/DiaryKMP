# Calendar 컴포넌트 스펙

이 문서는 달 단위로 넘겨 볼 수 있는 캘린더를 표시하는 공용 컴포넌트 Calendar의 사용자 관점 동작과 정책을 다룬다. 이 컴포넌트를 어느 화면에 배치할지와 날짜 누름·주 누름 뒤의 다음 행동은 이 문서의 범위가 아니며, 날짜 선택의 세부 행동과 정책은 [Calendar 날짜 선택 스펙](./calendar-select.md)에서 다룬다. 사용자 데이터의 생성이나 저장이 없어 `data` 영역은 생략한다.

디자인: [Calendar 컴포넌트 디자인](../../design/calendar.md)

## feature

### 달 표시

Calendar는 한 번에 한 달의 캘린더를 여섯 주로 표시한다.

여섯 주에 포함되는 날짜와 아이템은 [CalendarMonth 컴포넌트 스펙](./calendar-month.md)을 따른다.

### 요일 표시

캘린더에는 일요일부터 토요일까지의 요일이 표시되며, 달을 이동해도 요일 순서는 변하지 않는다.

### 주요 날짜 표시

배치하는 화면은 캘린더에서 강조할 주요 날짜를 여러 개 지정할 수 있다.

배치하는 화면이 주요 날짜를 지정하지 않으면 어떤 날짜도 강조되지 않는다.

### 공휴일 표시

배치하는 화면은 캘린더에 공휴일 기간을 여러 개 지정할 수 있다. 지정한 기간에 드는 날짜는 공휴일로 구분해 표시되며, 주요 날짜·공휴일·요일 사이의 우선순위는 [CalendarWeekOfMonth 컴포넌트 스펙](./calendar-week-of-month.md)의 날짜 의미 우선순위를 따른다.

배치하는 화면이 공휴일을 지정하지 않으면 어떤 날짜도 공휴일로 구분되지 않는다.

### 아이템 표시

배치하는 화면은 캘린더에 기간을 가진 아이템을 여러 개 지정할 수 있다.

지정한 아이템 중 표시 중인 달의 여섯 주와 겹치는 아이템이 각 주에 표시된다. 배치하는 화면이 아이템을 지정하지 않으면 아이템 없이 날짜만 표시된다.

### 아이템 스크롤 되돌리기

배치하는 화면은 각 주의 아이템 영역 스크롤을 맨 위로 되돌리도록 요청할 수 있다.

요청하면 사용자는 보고 있는 달의 각 주에서 첫 아이템 줄부터 다시 본다. 되돌림 결과는 [CalendarWeekOfMonth 컴포넌트 스펙](./calendar-week-of-month.md)의 아이템 스크롤 되돌리기를 따른다.

### 날짜 선택

배치하는 화면은 캘린더의 날짜 기간 선택을 사용할 수 있다. 선택할 수 있는 날짜와 선택 결과는 [Calendar 날짜 선택 스펙](./calendar-select.md)을 따른다.

배치하는 화면이 날짜 선택을 사용하지 않으면 사용자는 캘린더에서 날짜 기간을 선택할 수 없다.

### 날짜 누름

배치하는 화면은 사용자가 날짜 하나를 누르는 행동을 사용할 수 있다. 사용하면 사용자가 캘린더에 보이는 날짜를 눌렀을 때 그 날짜가 배치하는 화면에 전달된다. 이웃 달에 속한 날짜도 실제 날짜 그대로 전달된다.

배치하는 화면이 날짜 누름을 사용하지 않으면 날짜 칸은 누를 수 있는 대상으로 제공되지 않고, 날짜를 눌러도 아무 일도 일어나지 않는다.

### 주 누름

배치하는 화면은 사용자가 한 주를 누르는 행동을 사용할 수 있다. 사용하면 사용자가 캘린더에 보이는 주를 눌렀을 때 그 주를 가리키는 일요일의 날짜가 배치하는 화면에 전달된다. 주는 일요일부터 토요일까지이므로 일요일의 날짜로 그 주의 일곱 날짜가 정해진다.

배치하는 화면이 주 누름을 사용하지 않으면 주는 누를 수 있는 대상으로 제공되지 않고, 주를 눌러도 아무 일도 일어나지 않는다.

날짜 누름과 주 누름은 배치하는 화면이 아이템에 지정한 선택보다 우선하지 않는다. 아이템을 누르면 아이템의 선택만 실행된다. 길게 누르는 행동은 날짜 누름이나 주 누름으로 다루지 않는다.

### 달 이동

사용자는 이전 달과 다음 달로 이동할 수 있다. 구체적인 조작은 [Calendar 컴포넌트 디자인](../../design/calendar.md)의 달 이동을 따른다.

### 달 이동 요청

배치하는 화면은 캘린더가 지정한 달, 이전 달 또는 다음 달로 이동하도록 요청할 수 있다. 요청하면 사용자가 별도 조작을 하지 않아도 그 달의 캘린더가 표시된다. 이동할 수 있는 달은 `domain`의 이동 범위를 따르며, 1년 1월에서 이전 달을 요청하면 1년 1월이 그대로 표시된다.

배치하는 화면은 캘린더가 지금 표시 중인 달을 알 수 있다.

### 시작 달

배치하는 화면이 시작 달을 지정하지 않으면 오늘이 속한 달의 캘린더가 먼저 표시된다.

## domain

### 주요 날짜 지정

주요 날짜는 배치하는 화면이 매번 다시 지정할 수 있고, 지정이 바뀌면 사용자가 별도 조작을 하지 않아도 강조가 갱신된다.

같은 날짜를 여러 번 지정해도 결과는 한 번 지정한 것과 같다. 표시 중인 달에 없는 날짜를 지정해도 오류로 보지 않고 강조 대상이 없는 것으로 처리한다.

### 공휴일 지정

공휴일은 배치하는 화면이 매번 다시 지정할 수 있고, 지정이 바뀌면 사용자가 별도 조작을 하지 않아도 공휴일 구분이 갱신된다. 공휴일 기간은 여러 개를 지정할 수 있고, 하루짜리 기간과 여러 날짜의 기간을 함께 지정할 수 있다.

### 아이템 지정

아이템은 배치하는 화면이 매번 다시 지정할 수 있고, 지정이 바뀌면 사용자가 별도 조작을 하지 않아도 표시가 갱신된다.

달을 이동하면 이동한 달의 각 주와 겹치는 아이템만 표시된다.

### 오늘 기준

오늘은 사용자의 현재 시간대를 기준으로 정한다.

### 이동 범위

사용자는 1년 1월보다 이전 달로 이동할 수 없다. 다음 달 방향으로는 사실상 제한 없이 이동할 수 있다.

### 보던 달 유지

화면 회전처럼 화면이 재생성되어도 사용자가 보던 달은 유지된다.
