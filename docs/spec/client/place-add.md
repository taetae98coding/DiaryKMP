# PlaceAdd 화면 스펙

이 문서는 사용자가 새 장소를 작성해 추가하는 PlaceAdd 화면의 내용과 행동, 그리고 추가되는 장소가 갖는 정보와 정책을 다룬다. PlaceAdd로 진입하는 흐름은 [PlaceHome 화면 스펙](./place-home.md), [메모 장소 카드 컴포넌트 스펙](./memo-place-card.md)과 [TagDetail 장소 탭 스펙](./tag-detail-place.md)에서, 지도의 표시·조작·지점 선택 자체의 동작은 [DiaryMap 컴포넌트 스펙](./diary-map.md)에서, 검색으로 장소를 찾아 제목과 좌표를 가져오는 행동은 [장소 검색 다이얼로그 컴포넌트 스펙](./place-search-dialog.md)에서, 설명과 컬러 입력의 행동은 [설명 입력 컴포넌트 스펙](./description-input.md)과 [컬러 입력 컴포넌트 스펙](./diary-color-input.md)에서 다룬다. 제목 입력 자체의 동작은 [제목 입력 스펙](./title-input.md)을 따른다.

작성 상태 유지, 뒤로가기, 태그 입력의 반영 시점, 추가 요청 제한, 계정 연결과 저장·동기화 계약은 [항목 추가 화면 공통 스펙](./entity-add.md)을 따른다. 연결할 태그의 선택과 해제, 선택 목록의 행동과 정책은 [항목 태그 입력 컴포넌트 스펙](./entity-tag-input.md)을 따르고, 장소와 태그의 연결 규칙은 [장소 태그 스펙](../common/place-tag.md)을 따른다. 이 문서에서는 PlaceAdd 화면에서만 다른 시작 상태와 추가 결과를 다룬다.

이번 범위는 사용자가 제목, 설명, 컬러, 주소를 입력하고, 지도에서 위치를 눌러 좌표를 고르거나 좌표를 직접 입력하거나 장소 검색으로 가져와 태그를 연결해 장소를 추가하는 것까지다. 저장한 장소의 목록 표시는 [PlaceHome 화면 스펙](./place-home.md)에서, 저장한 장소의 상세 확인·수정·삭제는 [PlaceDetail 화면 스펙](./place-detail.md)에서 다루며, 이 문서에서는 다루지 않는다.

디자인: [PlaceAdd 화면 디자인](../../design/place-add.md)

## feature

### 진입과 입력

사용자는 PlaceHome 화면에서 장소 추가를 선택해 PlaceAdd 화면으로 이동한다.

메모 장소 카드와 장소 선택 목록에서 장소 추가로 이동하는 경우에도 PlaceAdd 화면으로 이동하며, 그 진입 경로와 돌아왔을 때의 결과는 [메모 장소 카드 컴포넌트 스펙](./memo-place-card.md)의 `장소 추가 이동`을 따른다. 이 경우에도 이동하던 시점에 카드의 지도가 보고 있던 위치를 초기 지도 위치로 넘겨받는다.

사용자는 장소 제목, 설명, 컬러, 주소, 좌표와 연결할 태그를 입력하거나 바꿀 수 있다. 제목과 주소는 각각 한 줄 분량을 입력할 수 있다.

좌표는 지도에서 위치를 눌러 고르거나, 위도와 경도를 각각 십진수로 입력해 정한다. 두 방법 중 무엇을 쓰든 결과로 정해지는 좌표는 같게 다룬다. 직접 입력할 때 사용자는 음수와 소수점을 포함한 값을 입력할 수 있다.

좌표는 장소를 추가하기 위해 반드시 필요하다. 지도에서 위치를 고르거나 위도와 경도를 모두 십진수로 입력해야 장소를 추가할 수 있다.

화면에 처음 진입하면 무작위 컬러가 초기값으로 제시되고, 주소와 위도와 경도는 비어 있는 상태로 시작한다. 사용자가 컬러를 바꾸지 않으면 제시된 컬러를 사용한다. 사용자가 제목부터 바로 입력할 수 있도록 입력 초점을 제목 입력에 한 번 둔다.

PlaceHome이나 메모 장소 카드에서 진입하면 태그를 하나도 고르지 않은 상태로 시작한다. [TagDetail 장소 탭](./tag-detail-place.md)에서 진입하면 그 태그를 최초 선택한 상태로 시작하며, 기준은 그 문서의 `장소 추가의 초기값`을 따른다.

### 지도에서 좌표 선택

사용자는 화면에 함께 표시되는 지도에서 위치를 눌러 좌표를 고를 수 있다.

지도를 누르면 누른 곳에 지점 표시가 나타나고, 그 곳의 위도와 경도가 위도 입력과 경도 입력에 함께 채워진다. 사용자는 채워진 값을 그대로 두거나 이어서 고칠 수 있다.

이미 고른 곳이 있는 상태에서 지도의 다른 곳을 누르면 지점 표시가 새로 누른 곳으로 옮겨지고 위도와 경도도 그 곳의 값으로 바뀐다. 지점 표시는 항상 하나만 있다.

지도를 눌러 좌표를 고른 뒤 사용자가 지도를 옮기거나 확대·축소해도 고른 좌표는 바뀌지 않는다.

지도를 눌러 좌표를 고를 때는 입력 초점을 옮기지 않고 사용자가 보고 있던 입력에 그대로 둔다.

지도는 PlaceAdd로 이동한 화면에서 보고 있던 위치에서 시작하며, 사용자가 고른 곳이 없는 동안에는 지점 표시가 없다.

사용자는 지도 없이 위도와 경도를 직접 입력해서도 장소를 추가할 수 있다. 지도가 표시되지 않는 상태에서도 좌표 입력과 장소 추가는 그대로 사용할 수 있다.

### 장소 검색으로 채우기

사용자는 화면에서 장소 검색을 열어 검색어로 장소를 찾고, 찾은 장소의 좌표와 주소를 위도 입력과 경도 입력과 주소 입력에 가져올 수 있다. 제목이 비어 있으면 찾은 장소의 이름도 함께 가져온다. 검색의 동작과 반영 규칙은 [장소 검색 다이얼로그 컴포넌트 스펙](./place-search-dialog.md)을 따른다.

가져온 좌표는 지도에서 고르거나 직접 입력한 좌표와 같게 다루므로, 사용자는 이어서 값을 고치거나 지도에서 다른 곳을 다시 고를 수 있다.

### 좌표 직접 입력과 지도의 반영

사용자가 위도나 경도를 직접 입력하면 값을 완성한 뒤에 지도가 그 좌표를 반영한다. 입력하는 동안에는 지도가 글자마다 따라 움직이지 않으므로 사용자는 지도가 오가는 것을 보지 않고 값을 입력할 수 있다.

값을 완성하면 지점 표시가 입력한 곳으로 옮겨지고 지도도 그 곳을 가운데에 두도록 이동한다.

입력한 값으로 좌표가 성립하지 않으면 지점 표시가 사라지고, 지도가 보고 있는 위치는 바뀌지 않는다.

### 장소 추가

사용자는 입력한 내용으로 장소 추가를 실행할 수 있다.

장소 추가를 처리하는 동안에는 진행 상태를 표시한다.

추가에 성공하면 화면을 유지한 채 제목, 설명, 주소, 위도와 경도를 비우고, 다음 장소를 위한 무작위 컬러를 새로 제시한다. 사용자가 다음 장소 입력을 바로 이어갈 수 있도록 입력 초점을 제목 입력으로 옮기고 성공 피드백을 제공한다.

태그 선택은 비우지 않고 그대로 유지한다. 사용자가 같은 태그의 장소를 이어서 추가할 수 있게 하기 위한 것이며, 기준은 [MemoAdd 화면 스펙](./memo-add.md)의 `메모 추가`에서 태그 선택을 유지하는 것과 같다.

좌표를 비우므로 지점 표시도 사라진다. 지도가 보고 있는 위치는 방금 추가한 장소 근처에 그대로 두어, 사용자가 같은 동네의 다음 장소를 이어서 고를 수 있게 한다.

### 제목 미입력

제목이 비어 있거나 공백만 있는 상태에서 추가를 실행하면 장소를 추가하지 않고 제목 입력이 필요하다는 피드백을 제공한다.

입력 중이던 설명, 컬러, 주소와 좌표는 유지하고 입력 초점을 제목 입력으로 옮기므로, 사용자는 제목을 바로 입력한 뒤 다시 시도할 수 있다.

### 좌표 오류

좌표가 성립하지 않는 상태에서 추가를 실행하면 장소를 추가하지 않고 좌표를 어떻게 입력해야 하는지 알리는 피드백을 제공한다. 다음은 모두 좌표가 성립하지 않는 상태이며, 하나의 피드백으로 같게 안내한다.

- 위도나 경도가 비어 있다.
- 입력한 값을 십진수로 읽을 수 없다.
- 십진수로 읽을 수 있으나 좌표가 표현할 수 있는 범위를 벗어난다.

피드백은 위도와 경도가 각각 어떤 범위의 숫자여야 하는지 함께 알려 사용자가 무엇을 고쳐야 하는지 알 수 있게 한다.

피드백은 좌표를 고치는 방법으로 지도에서 위치를 고르는 것도 함께 알린다.

입력 중이던 제목, 설명, 컬러, 주소와 좌표는 유지하므로 사용자는 좌표를 고친 뒤 다시 시도할 수 있다. 지도가 보고 있는 위치도 바뀌지 않는다.

고쳐야 할 자리가 위도 입력, 경도 입력과 지도로 나뉘어 하나로 정해지지 않으므로, 입력 초점은 옮기지 않고 사용자가 보고 있던 입력에 그대로 둔다.

### 작성 상태 유지 대상

[항목 추가 화면 공통 스펙](./entity-add.md)의 `작성 상태 유지`가 유지하는 대상은 입력 중이던 제목, 설명, 주소, 위도, 경도와 선택한 컬러, 그리고 고른 태그다. 유지한 좌표가 성립하면 지점 표시도 같은 곳에 유지되며, 사용자가 보고 있던 지도 위치와 확대 수준, 지도 제공자도 유지한다.

시스템이 앱을 메모리에서 정리한 뒤 화면을 복원하면 입력 내용과 컬러, 지도 상태는 복원하지만 고른 태그는 복원하지 않는다. 이때 태그 선택은 `진입과 입력`의 시작 상태로 돌아가므로, TagDetail 장소 탭에서 진입했으면 그 태그만 선택된 상태가 되고 다른 경로로 진입했으면 태그를 하나도 고르지 않은 상태가 된다.

앱을 종료한 뒤 PlaceAdd 화면에 새로 진입하면 지점 표시가 없는 상태에서 시작하고, 지도는 그때 PlaceAdd로 이동한 화면에서 보고 있던 위치에서 시작한다.

## domain

### 장소의 정보

장소 하나는 다음 정보를 갖는다.

- 제목: 장소를 가리키는 이름.
- 설명: 장소에 대한 부가 설명으로, 비어 있을 수 있다.
- 컬러: 장소를 구분해 보여줄 때 사용하는 색.
- 좌표: 장소의 위도와 경도.
- 주소: 장소가 어디인지 알려 주는 주소 문구로, 없을 수 있다.

좌표의 위도와 경도는 항상 함께 존재한다. 한쪽만 있는 좌표는 장소의 좌표로 다루지 않는다.

장소와 태그의 연결은 장소가 가지는 값이 아니라 장소와 태그 사이의 별개 항목이다. 그 규칙은 [장소 태그 스펙](../common/place-tag.md)을 따른다.

### 좌표의 유효 범위

위도는 `-90` 이상 `90` 이하, 경도는 `-180` 이상 `180` 이하의 숫자다.

이 범위 안의 숫자가 아닌 값은 좌표로 다루지 않는다. 숫자로 성립하지 않는 값과 범위를 벗어난 값을 구분하지 않고, 둘 다 성립하지 않는 좌표로 함께 다룬다.

좌표가 성립하는지는 좌표를 만든 화면이 아니라 장소를 추가하는 규칙이 판단한다. 이렇게 하면 좌표를 어디에서 만들어 오더라도 같은 기준으로 걸러진다.

### 좌표를 정하는 방법

PlaceAdd에서 좌표를 정하는 방법은 지도에서 지점을 고르는 것, 위도·경도를 직접 입력하는 것, 장소 검색에서 찾은 장소를 고르는 것 세 가지다. 세 방법은 서로 다른 좌표를 각각 갖지 않고 하나의 좌표를 함께 다루며, 가장 나중에 정한 값이 현재 좌표다.

지도에서 고른 지점과 검색으로 찾은 장소의 좌표는 항상 유효 범위 안의 좌표이므로, 이 두 방법으로는 성립하지 않는 좌표가 만들어지지 않는다. 성립하지 않는 좌표는 직접 입력으로만 만들어진다.

지점 표시는 현재 좌표가 성립할 때만 있다. 좌표가 성립하지 않으면 지점 표시는 없으며, 이때 빈 값과 읽을 수 없는 값과 범위를 벗어난 값을 구분하지 않는다.

지도가 표시되지 않는 것은 장소 추가 성립 조건에 영향을 주지 않는다.

### 좌표와 지도가 서로 반영되는 시점

지도에서 지점을 고른 결과는 곧바로 좌표에 반영한다.

직접 입력한 값은 사용자가 입력을 멈춘 뒤에 지도에 한 번 반영한다. 입력이 멈췄다고 보는 기준과 기다리는 시간은 [입력 정지 대기 시간 스펙](./input-idle-delay.md)을 따른다. 값을 완성하는 도중의 중간 값을 반영하지 않기 위한 기다림이다.

지도가 보고 있는 위치를 옮기는 것은 좌표를 바꾸지 않는다. 사용자가 지도를 옮기거나 확대·축소해도, 직접 입력을 반영해 지도가 옮겨져도 현재 좌표는 그대로다.

### PlaceAdd의 지도

PlaceAdd는 [DiaryMap 컴포넌트](./diary-map.md)를 지점 선택을 사용하는 상태로 배치한다.

초기 지도 제공자는 사용자가 [SettingMap 화면](./setting-map.md)에서 고른 기본 지도다. PlaceHome에서 사용자가 잠시 바꿔 보던 제공자는 이어받지 않는다.

PlaceAdd가 표시되어 있는 동안 기본 지도가 바뀌면 바뀐 기본 지도로 지도를 새로 시작한다. 이때 입력 중이던 제목, 설명, 주소, 좌표와 컬러, 고른 태그는 유지한다. 새로 시작한 지도는 초기 지도 위치에서 시작하고, 입력 중인 좌표가 성립하면 `좌표와 지도가 서로 반영되는 시점`의 직접 입력과 같이 사용자가 입력을 멈춘 것으로 보는 시간이 지난 뒤 그 곳에 지점 표시를 두고 그 곳을 가운데로 옮긴다.

초기 지도 위치는 PlaceAdd로 이동한 화면이 넘긴, 장소 추가로 이동하던 시점에 사용자가 보고 있던 지도 위치다. PlaceHome과 TagDetail 장소 탭이 무엇을 넘기는지는 [장소 보기 모드 스펙](./place-view-mode.md)의 `장소 추가로 넘기는 지도 위치`를, 메모 장소 카드가 무엇을 넘기는지는 [메모 장소 카드 컴포넌트 스펙](./memo-place-card.md)의 `장소 추가로 넘기는 지도 위치`를 따른다.

넘겨받은 위치가 없으면 초기 위치를 지정하지 않은 것으로 다루며, 이때의 표시는 [DiaryMap 컴포넌트 스펙](./diary-map.md)의 초기 지도 위치를 따른다. PlaceAdd는 현재 위치를 따로 확인하지 않는다.

기본 지도를 확인하기 전이거나 읽지 못했으면 지도를 표시하지 않으며, 별도의 로딩 안내나 오류 안내도 제공하지 않는다. 이는 PlaceHome이 지도를 표시하는 조건과 같다.

### 장소 추가 성립 조건

장소는 제목을 가져야 추가할 수 있다. 제목이 비어 있거나 공백 문자로만 이루어져 있으면 추가하지 않는다.

장소는 성립하는 좌표를 가져야 추가할 수 있다. 위도나 경도가 유효 범위 안의 숫자가 아니면 추가하지 않는다.

설명과 주소는 비어 있어도 장소를 추가할 수 있다.

제목과 좌표 조건이 함께 성립하지 않으면 제목을 먼저 판단하고 그 결과를 알린다.

### 추가되는 장소의 내용

기록되는 공통 값은 [항목 추가 화면 공통 스펙](./entity-add.md)의 `추가되는 항목의 내용`을 따른다.

장소에는 사용자가 입력한 제목, 설명, 컬러, 주소와 좌표를 기록한다. 설명이나 주소를 입력하지 않으면 각각 빈 설명과 빈 주소로 기록하고, 컬러를 바꾸지 않으면 처음 제시한 무작위 컬러를 기록한다.

### 장소 생성과 저장

저장 흐름은 [항목 추가 화면 공통 스펙](./entity-add.md)의 `생성과 저장`을 따른다. 이때 함께 반영되는 것은 새 장소, 현재 사용자 계정의 연결, 그리고 고른 태그와의 연결이다.
