# 항목 완료 메모 목록 화면 스펙

이 문서는 사용자가 TagDetail, ContactDetail, PlaceDetail, WebDetail 화면의 메모 탭에서 상세 대상 항목의 완료된 메모를 모아 확인하는 네 화면 가운데 이 화면들에만 해당하는 부분을 다룬다. 진입과 이동, 빈 상태, 추가 미제공, 상세 확인, 다시 시작과 삭제, 정렬 선택, 노출 기준과 실행 경계의 공통 규칙은 [완료 목록 공통 스펙](./finished-list.md)을 따른다.

| 화면 | 상세 대상 항목 | 짝이 되는 목록 |
| --- | --- | --- |
| TagMemoFinishedList | 태그 | [TagDetail 메모 탭](./tag-detail-memo.md) |
| ContactMemoFinishedList | 연락처 | [ContactDetail 메모 탭](./contact-detail-memo.md) |
| PlaceMemoFinishedList | 장소 | [PlaceDetail 메모 탭](./place-detail-memo.md) |
| WebMemoFinishedList | 웹 항목 | [WebDetail 메모 탭](./web-detail-memo.md) |

이 문서에서 `상세 대상 항목`은 진입한 상세 화면이 보여 주는 태그, 연락처, 장소 또는 웹 항목을 가리킨다. [완료 목록 공통 스펙](./finished-list.md)의 `대상 항목`은 이 목록이 모으는 메모를 가리킨다. TagMemoFinishedList에만 해당하는 차이는 [TagMemoFinishedList 화면 스펙](./tag-memo-finished-list.md)이 정한다.

메모 카드의 내용, 기간 표시, 정렬과 날짜 그룹은 [MemoHome 목록 스펙](./memo-home.md)을 따르고, 다시 시작·삭제의 상태 전이는 [MemoFinishedList 화면 스펙](./memo-finished-list.md)을 따른다. 메모와 항목 연결의 성질은 [항목 연결 공통 스펙](../common/entity-link.md)을, 태그는 [메모 태그 스펙](../common/memo-tag.md)을 따르고, 상세 확인은 [MemoDetail 화면 스펙](./memo-detail.md)을 따른다. 목록과 메모 상세를 함께 사용할 때의 선택 상태와 뒤로가기는 [항목 완료 메모 목록·상세 배치 스펙](./entity-memo-finished-list-detail.md)에서 다룬다.

계정의 완료된 메모 전체를 확인하는 화면은 [MemoFinishedList 화면 스펙](./memo-finished-list.md)에서 다룬다.

디자인: [항목 완료 메모 목록 화면 디자인](../../design/entity-memo-finished-list.md)

## feature

### 진입과 이동

사용자는 상세 화면의 메모 탭에서 완료된 메모 확인을 선택해 같은 항목의 완료 메모 목록 화면으로 이동한다. 진입 동작의 제공 조건은 [항목 상세 메모 탭 공통 스펙](./entity-detail-memo.md)의 `완료된 메모 확인`을, 태그는 [TagDetail 메모 탭 스펙](./tag-detail-memo.md)의 `완료된 메모 확인`을 따른다.

완료된 메모 목록만 사용하는 동안 사용자가 뒤로가면 메모 탭이 선택된 같은 항목의 상세 화면으로 돌아간다. 상세 화면이 항목 목록과 함께 표시되던 배치에서 이동했으면 그 배치로 돌아가고, 상세 영역에는 메모 탭이 선택된 같은 항목의 상세가 남아 있다.

### 화면 제목

화면 제목에는 상세 대상 항목의 최신 저장 이름을 표시하고, 완료된 메모를 모아 보여 주는 목록임을 함께 알린다. 연락처는 이름을, 장소와 웹 항목은 제목을 이름으로 쓴다. 태그의 이름은 [TagMemoFinishedList 화면 스펙](./tag-memo-finished-list.md)의 `화면 제목`이 정한다.

상세 대상 항목을 아직 조회하지 못한 동안에는 항목의 이름을 표시하지 않고, 완료된 메모 목록이라는 사실만 알린다.

항목의 이름은 한 줄로 표시한다. 표시할 수 있는 폭보다 길면 전체를 확인할 수 있도록 가로로 반복해서 이동한다.

### 목록 표시

각 메모에는 제목이 표시되고, 기간이 있으면 기간도 함께 표시된다. 카드의 표시 방식은 [MemoHome 목록 스펙](./memo-home.md)의 `목록 표시`를 따른다.

정렬과 날짜 그룹은 [MemoHome 목록 스펙](./memo-home.md)을 따른다.

### 빈 상태 문구

상세 대상 항목에 연결된 완료된 메모가 하나도 없으면 목록 자리에 이 항목에서 완료한 메모가 아직 없음을 알린다.

상세 대상 항목을 조회하지 못해 항목의 이름을 표시하지 못하는 것은 빈 상태 판정에 영향을 주지 않는다.

### 메모 상세 확인

사용자가 상세 화면에서 상세 대상 항목과의 연결을 해제한 뒤 돌아온 메모도 이 목록의 노출 기준에 따라 목록에서 사라진다.

### 다시 시작과 삭제

목록에서 메모를 다시 시작하거나 삭제한 결과와 안내, 실행 취소는 [완료 목록 공통 스펙](./finished-list.md)의 `다시 시작과 삭제`를 따르고, 바뀌는 상태는 `domain > 다시 시작·삭제·실행 취소`가 정한다.

## domain

### 상세 대상 항목

이 화면의 상세 대상 항목은 진입한 상세 화면의 상세 대상과 같은 항목이다. 대상이 결정되는 기준은 [항목 상세 메모 탭 공통 스펙](./entity-detail-memo.md)의 `상세 대상 항목과 연결`을 따르며, TagMemoFinishedList는 [TagDetail 메모 탭 스펙](./tag-detail-memo.md)의 `상세 대상 태그와 연결`을 따른다.

화면이 열려 있는 동안 상세 대상 항목의 저장 이름이 다른 경로에서 바뀌면 화면 제목을 최신 저장 이름으로 갱신한다.

상세 대상 항목을 조회할 수 없거나 조회에 실패하면 항목의 이름을 표시하지 않고, 그 밖의 화면 행동은 바뀌지 않는다.

상세 대상 항목이 삭제되어도 기존 메모 연결은 유지되므로 이미 열린 완료 메모 목록의 노출 기준은 바뀌지 않는다. 태그가 완료되는 것과 연락처의 즐겨찾기 변경도 노출 기준을 바꾸지 않는다.

### 항목 연결과 노출 기준

[완료 목록 공통 스펙](./finished-list.md)의 `노출 기준`에 상세 대상 항목과 해제되지 않은 연결을 가진 메모라는 조건을 더한다. 연결을 판정하는 규칙과 담을 연결의 종류는 짝이 되는 메모 탭 스펙과 같다.

MemoHome의 필터 선택은 이 목록에 적용하지 않는다.

### 정렬과 날짜 그룹

정렬, 날짜 그룹과 오늘의 기준은 [MemoHome 목록 스펙](./memo-home.md)을 따른다.

### 다시 시작·삭제·실행 취소

상태 전이와 수정 시각 갱신은 [MemoFinishedList 화면 스펙](./memo-finished-list.md)의 `다시 시작과 삭제의 상태 전이`를 따른다.

다시 시작, 삭제와 실행 취소는 메모와 항목의 연결을 바꾸지 않는다. 상세 대상 항목의 저장 내용과 삭제 여부도 바꾸지 않는다.

다시 시작한 메모는 상세 대상 항목과의 연결을 그대로 유지하므로 짝이 되는 메모 탭의 노출 기준을 만족해 그 탭의 목록에 나타난다. 삭제한 메모는 두 목록 모두에 나타나지 않는다.

### 실행 경계

메모 상세 선택의 유지와 초기화는 [항목 완료 메모 목록·상세 배치 스펙](./entity-memo-finished-list-detail.md)의 `유지와 초기화 기준`을 따른다.

## data

### 항목별 완료 메모 조회

조회 흐름은 [완료 목록 공통 스펙](./finished-list.md)의 `목록 조회`를 따르며, 현재 사용자 계정과 연결된 메모 및 메모-항목 연결 중 `항목 연결과 노출 기준`을 만족하는 항목만 조회한다. 이 조회는 상세 대상 항목 자체의 조회와 서로 독립이다.

메모의 기간이나 항목 연결 상태가 바뀔 때도 목록을 노출 기준과 정렬 기준에 따라 자동 갱신한다.

연결이 해제된 메모는 목록에서 사라지고, 연결이 복구되면 노출 기준을 만족할 때 정렬 기준에 맞는 위치에 다시 나타난다.

### 상태 변경의 저장

다시 시작, 삭제와 실행 취소의 저장 흐름은 [MemoFinishedList 화면 스펙](./memo-finished-list.md)의 `상태 변경의 저장`을 따른다.

메모 상태를 바꿔도 메모와 항목의 연결은 유지한다.
