# DDay 목록·상세 배치 스펙

이 문서는 디데이 목록과 상세 영역을 함께 사용할 때 이 배치에만 해당하는 상세 영역 구성, 뒤로가기와 초기화 경계를 다룬다. 함께 사용과 단독 사용, 상세 선택과 교체, 선택이 없을 때의 추가, 추가 진입 수단, 뒤로가기, 표시 비율 조절, 배치에 참여하는 화면과 유지·초기화의 공통 기준은 [목록·상세 배치 공통 스펙](./list-detail-pane.md)을 따른다. 각 화면의 내용과 행동은 [DDayHome 화면 스펙](./dday-home.md), [DDayAdd 화면 스펙](./dday-add.md), [DDayDetail 화면 스펙](./dday-detail.md)에서 다룬다.

디자인: [DDay 목록·상세 배치 디자인](../../design/dday-list-detail.md)

표시 비율은 화면 표시 상태일 뿐 사용자 데이터를 만들거나 저장하지 않으므로 `data` 영역은 생략한다.

## feature

### 상세 영역의 구성

목록과 상세 영역을 함께 표시하는 상태에서 상세 영역에는 사용자가 선택한 디데이의 상세가 표시되고, 선택한 디데이가 없으면 디데이 추가가 표시된다. 선택, 교체, 삭제 뒤의 상세 영역과 선택이 없을 때의 추가는 [목록·상세 배치 공통 스펙](./list-detail-pane.md)의 `상세 선택과 교체`와 `선택이 없을 때의 추가`를 따른다.

선택한 디데이가 없는 동안 사용자는 디데이 추가에서 [DDayAdd 화면 스펙](./dday-add.md)의 `진입`이 정한 처음 상태로 곧바로 입력한다. 추가 성공 후의 입력 상태는 같은 문서의 `디데이 추가`를 따른다.

상세 영역에서 디데이를 수정하면 목록에 놓인 그 디데이의 카드 문구와 자리가 같은 화면에서 바뀐다. 갱신 기준은 [DDayHome 화면 스펙](./dday-home.md)의 `목록 갱신`을 따른다.

상세 영역에 디데이 상세가 놓여 있는 동안 목록에서 연 디데이 추가는 [목록·상세 배치 공통 스펙](./list-detail-pane.md)의 `추가 진입 수단`을 따르며, [DDayAdd 화면 스펙](./dday-add.md)의 `진입`이 정한 처음 상태로 시작한다.

한 영역만 표시되는 상태에서는 해당 화면 스펙의 행동을 그대로 제공하며, 화면 사이의 이동은 [DDayHome 화면 스펙](./dday-home.md)의 `디데이 추가로 이동`과 `디데이 목록`을 따른다.

캘린더 홈 화면, 시간표, TagDetail 디데이 탭과 SearchHome에서 진입한 DDayDetail 화면과 TagDetail 디데이 탭에서 진입한 DDayAdd 화면은 이 배치에 참여하지 않고 단독으로 표시한다. 진입 흐름은 [DDayDetail 화면 스펙](./dday-detail.md)의 `진입과 내용`과 [DDayAdd 화면 스펙](./dday-add.md)의 `진입`을 따른다.

### 태그 필터

목록의 태그 필터는 배치와 관계없이 [DDayHome 화면 스펙](./dday-home.md)의 `태그 필터`를 따른다. 상세 영역에 디데이 추가나 디데이 상세가 함께 놓여 있어도 필터를 그대로 사용할 수 있고, 필터를 바꿔도 상세 영역에 놓인 화면은 바뀌지 않는다. 상세 영역의 디데이가 고른 필터에 맞지 않아 목록에서 사라져도 상세 영역에는 그 디데이의 상세가 그대로 남는다.

### 뒤로가기

뒤로가기의 결과는 [목록·상세 배치 공통 스펙](./list-detail-pane.md)의 `뒤로가기`를 따르며, 이 배치를 떠나면 `더보기` 화면으로 돌아간다. 디데이 목록의 뒤로가기 동작의 결과는 [DDayHome 화면 스펙](./dday-home.md)의 `뒤로가기`를 따른다.

## domain

### 유지와 초기화 기준

사용자가 `더보기` 화면으로 돌아가는 것을 이 배치를 떠난 것으로 본다. 그 뒤 디데이 화면에 다시 진입하거나 앱을 종료하고 다시 실행하면 [목록·상세 배치 공통 스펙](./list-detail-pane.md)의 `유지와 초기화 기준`에 따라 초기화한다.

선택한 디데이가 없을 때 상세 영역에 놓이는 디데이 추가의 작성 내용은 같은 절에 따라 [DDayAdd 화면 스펙](./dday-add.md)의 `작성 상태 유지 대상`이 남고, 다시 진입하면 같은 문서의 `진입`이 정한 처음 상태로 시작한다.

그 밖에 상세 영역에서 작성 중이던 내용을 어디까지 유지하는지는 [DDayAdd 화면 스펙](./dday-add.md)의 `작성 상태 유지 대상`과 [DDayDetail 화면 스펙](./dday-detail.md)의 `진행 상태 유지`를 따른다.
