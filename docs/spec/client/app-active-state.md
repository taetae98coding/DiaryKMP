# 앱 활성 상태 스펙

이 문서는 앱이 활성 상태인지를 플랫폼마다 어떻게 판정하는지 다룬다. 판정 결과로 무엇을 하는지는 그 판정을 쓰는 각 스펙이 소유한다.

이 판정은 화면 없이 앱 내부에서 쓰이고 사용자가 직접 조작하는 수단이 없으므로 `feature`와 `data` 영역을 생략한다.

## domain

### 활성 상태

활성 상태는 사용자가 지금 앱을 쓰고 있는 상태다.

| 플랫폼 | 활성 상태 |
| --- | --- |
| Android, iOS | 앱이 화면에 보이는 동안 |
| 데스크톱 앱 | 앱 창이 최소화되지 않고 포커스를 가진 동안 |
| 웹 | 브라우저 탭이 보이고 페이지가 포커스를 가진 동안 |

Android와 iOS에서는 앱이 화면에 다시 보이게 되는 것이 다시 활성 상태가 되는 것이다. 데스크톱 앱과 웹에서는 앱 창이나 브라우저 탭이 보이기만 하는 것은 다시 활성 상태가 되는 것이 아니며, 사용자가 다른 창이나 탭에서 앱으로 돌아와 포커스를 얻었을 때 다시 활성 상태가 된다. 데스크톱과 웹에서는 앱이 보이는 채로 다른 창을 함께 쓰는 일이 흔하므로, 사용자가 실제로 앱으로 돌아온 시점을 기준으로 삼는다.
