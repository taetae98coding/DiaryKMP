# 설명 입력 컴포넌트 스펙

이 문서는 사용자가 설명을 여러 줄로 입력하고 마크다운으로 미리 볼 수 있는 설명 입력 컴포넌트의 사용자 관점 동작과 정책을 다룬다. 이 컴포넌트를 어느 화면에 배치하는지와 입력한 설명의 저장은 이 문서의 범위가 아니며, 컴포넌트를 사용하는 화면 스펙에서 다룬다. 컴포넌트 자체는 사용자 데이터를 저장하지 않으므로 `data` 영역은 생략한다.

디자인: [설명 입력 컴포넌트 디자인](../../design/description-input.md)

## feature

### 설명 입력

사용자는 여러 줄의 설명을 입력하고 수정하거나 전체 내용을 지울 수 있다.

컴포넌트가 처음 표시될 때 채워진 설명이 없으면 설명을 입력할 수 있는 상태로 시작한다.

### 마크다운 미리보기

사용자는 입력한 설명을 마크다운으로 해석한 결과를 확인하고 다시 입력으로 돌아갈 수 있다.

컴포넌트가 처음 표시될 때 이미 채워진 설명이 있으면 그 설명을 마크다운으로 해석한 결과를 먼저 보여 준다. 사용자는 여기에서 설명 입력으로 옮겨 내용을 수정할 수 있다.

입력 내용을 수정한 뒤 미리보기를 확인하면 수정된 내용이 반영된다. 입력한 내용이 없으면 미리보기에도 내용이 표시되지 않는다.

엔터로 줄을 나눠 입력하면 미리보기에서도 같은 위치에서 줄이 나뉘어 표시된다.

## domain

### 설명 내용의 단일성

입력과 미리보기는 하나의 같은 설명 내용을 다룬다. 미리보기는 입력된 내용을 마크다운으로 해석해 보여 줄 뿐, 설명 내용 자체를 바꾸지 않는다.

### 첫 표시 상태

컴포넌트는 처음 표시될 때 채워진 설명에 따라 시작 상태를 정한다. 이미 적힌 설명이 있으면 사용자가 먼저 읽는다고 보고, 아직 내용이 없으면 바로 쓴다고 본다.

| 처음 채워진 설명 | 시작 상태 |
| --- | --- |
| 없거나 공백뿐임 | 설명 입력 |
| 공백이 아닌 내용이 있음 | 마크다운 미리보기 |

첫 표시 이후에는 설명 내용이 어떻게 바뀌어도 보고 있는 상태를 스스로 바꾸지 않는다. 입력과 미리보기 사이의 전환은 사용자의 조작으로만 일어난다.

컴포넌트를 사용하는 화면이 다른 대상의 설명으로 컴포넌트를 새로 채우면 그 시점을 첫 표시로 본다.

### 줄바꿈 해석

마크다운 표준(CommonMark)은 엔터 한 번을 줄바꿈이 아닌 공백으로 해석하지만, 이 컴포넌트의 미리보기는 사용자가 엔터로 나눈 줄을 그대로 줄바꿈으로 해석해 표시한다. 사용자가 마크다운의 줄바꿈 규칙(줄 끝 공백 두 개 등)을 모르더라도 입력한 줄 나눔이 미리보기에 그대로 보이는 것을 우선한다.

빈 줄로 나눈 문단 구분과 코드 블록 내부의 줄바꿈은 표준 해석 그대로 표시한다.

### 진행 상태 유지

화면이 회전하거나 시스템에 의해 화면이 재생성되어도 입력 중이던 설명 내용과 입력·미리보기 중 보고 있던 상태는 유지된다. 이때는 첫 표시가 아니므로 시작 상태를 다시 정하지 않는다.
