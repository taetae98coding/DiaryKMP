# TagDetail 화면 스펙

이 문서는 사용자가 선택한 태그의 상세를 확인하고 수정하고, 완료하거나 삭제하며, 그 태그에 연결된 메모·웹 항목·장소를 함께 다루는 TagDetail 화면의 내용과 행동을 다룬다. 화면은 태그 디테일, 메모, 웹, 장소 네 탭으로 나뉘며, 이 문서는 화면 전체와 태그 디테일 탭, 그리고 세 목록 탭이 함께 쓰는 `표시 범위`를 소유하고 나머지 세 탭의 내용과 행동은 [TagDetail 메모 탭 스펙](./tag-detail-memo.md), [TagDetail 웹 탭 스펙](./tag-detail-web.md), [TagDetail 장소 탭 스펙](./tag-detail-place.md)이 각각 소유한다.

설명과 컬러 입력의 행동은 [설명 입력 컴포넌트 스펙](./description-input.md), [컬러 입력 컴포넌트 스펙](./diary-color-input.md)을 따른다. 제목 입력 자체의 동작은 [제목 입력 스펙](./title-input.md)을 따른다.

연결할 태그의 선택과 해제, 선택 목록의 행동과 정책은 [태그 연결 입력 컴포넌트 스펙](./tag-link-input.md)을 따르고, 태그와 태그의 연결 규칙은 [태그 연결 스펙](../common/tag-link.md)을 따른다. 이 문서에서는 TagDetail 화면에서만 다른 표시 기준과 반영 시점을 다룬다.

내용 수정의 반영과 성공 결과, 연결 입력의 반영, 요청 제한과 저장 계약은 [항목 상세 화면 공통 스펙](./entity-detail.md)을 따른다.

디자인: [TagDetail 화면 디자인](../../design/tag-detail.md)

## feature

### 진입과 내용

사용자는 태그 목록에서 태그를 선택해 그 태그의 TagDetail 화면으로 이동한다.

메모 태그 입력에 표시된 태그 칩을 눌러서도 같은 태그의 TagDetail 화면으로 이동하며, 이때의 이동은 [태그 선택 입력 공통 스펙](./tag-select-input.md)의 `태그 상세 이동`을 따른다. 태그 목록에서 진입하지 않은 TagDetail 화면은 태그 목록과 함께 표시하지 않는다.

태그 조회에 성공하면 저장된 이모지, 제목, 설명과 컬러를 확인하고 수정할 수 있으며, 이 태그가 연결한 태그를 확인하고 바꿀 수 있다. 화면 제목에는 선택한 태그의 최신 저장 이모지와 제목을 표시한다.

화면 상단의 제목은 한 줄로 표시한다. 제목이 표시할 수 있는 폭보다 길면 전체 제목을 확인할 수 있도록 가로로 반복해서 이동한다.

### 탭 전환

화면은 태그 디테일, 메모, 웹, 장소 네 탭으로 나뉘고 이 순서로 놓인다. 태그 디테일 탭에서는 이 문서의 `내용 수정`과 `태그 연결 입력`을, 나머지 탭에서는 각 탭 스펙의 행동을 실행한다.

| 탭 | 소유 문서 |
| --- | --- |
| 태그 디테일 | 이 문서 |
| 메모 | [TagDetail 메모 탭 스펙](./tag-detail-memo.md) |
| 웹 | [TagDetail 웹 탭 스펙](./tag-detail-web.md) |
| 장소 | [TagDetail 장소 탭 스펙](./tag-detail-place.md) |

화면에 처음 진입하면 태그 디테일 탭이 선택된 상태로 시작한다.

사용자는 탭을 직접 선택해 전환할 수 있고, 본문을 좌우로 밀어서도 전환할 수 있다. 본문을 밀면 지금 탭의 바로 옆 탭으로 전환한다. 전환 방법과 관계없이 선택한 탭과 표시하는 내용은 항상 일치한다.

다만 메모 탭과 웹 탭의 목록 카드 위에서 좌우로 미는 조작은 탭 전환보다 그 카드의 완료·삭제가 우선한다. 카드 위에서 밀면 탭은 바뀌지 않고 각 탭 스펙이 정한 카드 동작이 실행된다. 이때 탭을 바꾸려면 탭을 직접 선택하거나 카드 밖 여백에서 민다.

태그 조회 중에도 사용자는 탭을 전환할 수 있다. 조회 결과가 탭 전환을 막지 않는다.

탭을 전환해도 다른 탭에서 하던 일은 사라지지 않는다. 태그 디테일 탭에서 수정 중이던 이모지, 제목, 설명과 컬러는 다른 탭에 다녀와도 그대로 남아 있고, 메모·웹·장소 탭에서 보던 목록 위치도 다른 탭에 다녀오면 그대로 유지된다.

완료·다시 시작과 삭제는 선택한 탭과 관계없이 항상 실행할 수 있다.

### 표시 범위

사용자는 선택한 탭과 관계없이 화면에서 표시 범위를 열어 지금 범위를 확인하고 바꿀 수 있다. 표시 범위는 `이 태그만`, `직속 하위까지`, `모든 하위까지` 중 하나이며 처음에는 `이 태그만`이다.

범위를 고르면 즉시 반영되며 별도의 확정 동작은 필요하지 않다. 범위 선택을 닫아도 고른 범위는 유지되고, 사용자는 다시 열어 지금 범위를 확인하고 바꿀 수 있다.

표시 범위는 메모·웹·장소 탭의 목록에만 적용한다. 범위를 넓히면 세 목록에 하위 태그와 연결된 메모, 웹 항목과 장소가 함께 나타나고, 좁히면 다시 사라진다. 세 탭은 하나의 표시 범위를 함께 사용하므로 어느 탭에서 바꾸어도 세 목록에 같이 적용된다.

화면 제목, 태그 디테일 탭의 내용과 태그 연결 입력, 완료·다시 시작과 삭제는 표시 범위를 바꿔도 달라지지 않는다.

태그 조회 중에도 사용자는 표시 범위를 확인하고 바꿀 수 있다. 조회 결과가 표시 범위 선택을 막지 않는다.

### 태그 연결 입력

태그 연결 입력은 태그 디테일 탭에서 제공한다.

태그 선택 목록에서의 연결과 해제는 [태그 연결 입력 컴포넌트 스펙](./tag-link-input.md)을 따르고, 연결 입력의 구성과 표현은 [태그 연결 입력 컴포넌트 디자인](../../design/tag-link-input.md)을 따른다.

반영 시점과 다른 동작과의 관계는 [항목 상세 화면 공통 스펙](./entity-detail.md)의 `태그 입력`을 따르며, 이 화면에서 연결한 태그를 누르면 그 태그의 TagDetail 화면으로 이동하고 뒤로가면 이 태그의 상세로 돌아온다.

### 조회 상태

처음에는 태그 조회 중 상태를 제공하며 상세 내용의 수정, 태그 연결과 해제, 완료·다시 시작과 삭제를 실행할 수 없다.

조회에 성공하면 내용 표시 상태로 바뀐다. 태그를 조회할 수 없거나 조회에 실패하면 조회 중 상태를 유지한다.

조회 상태는 태그 디테일 탭의 내용과 화면 제목, 완료·다시 시작과 삭제에만 적용한다. 메모·웹·장소 탭의 표시 기준은 각 탭 스펙을 따르므로 태그를 아직 조회하지 못했어도 세 목록은 그대로 표시한다.

### 내용 수정

사용자가 입력한 이모지, 제목, 설명 또는 컬러가 저장된 내용과 하나라도 다를 때만 수정 반영 동작을 제공한다.

수정 반영 동작은 태그 디테일 탭을 선택한 동안에만 제공한다. 메모·웹·장소 탭에서는 수정 반영을 실행할 수 없고, 태그 디테일 탭으로 돌아오면 다시 실행할 수 있다.

수정에 성공하면 화면과 입력 내용을 유지하고 성공 피드백을 제공한다. 화면 제목은 새로 저장된 이모지와 제목으로 갱신된다.

수정 시점에 제목이 비어 있거나 공백만 있으면 저장된 기존 제목을 유지하고 이모지, 설명과 컬러만 반영한다.

이모지를 비운 채 수정하면 태그의 이모지를 비운 것으로 반영한다.

### 완료와 다시 시작

완료되지 않은 태그에서는 완료 동작을, 완료된 태그에서는 다시 시작 동작을 제공한다.

완료에 성공하면 태그는 완료 상태가 되고 다시 시작할 수 있다. 다시 시작에 성공하면 미완료 상태가 되고 다시 완료할 수 있다. 화면과 수정 중인 내용, 선택한 탭은 유지한다.

처리 중에는 진행 상태를 표시한다.

### 삭제

사용자는 태그를 삭제할 수 있다. 삭제는 다시 묻지 않고 바로 실행하며, 삭제한 뒤 되돌리는 동작은 제공하지 않는다. 처리 중에는 진행 상태를 표시한다.

삭제에 성공하면 뒤로가기와 같은 결과로 TagDetail 화면에서 빠져나가 진입하기 전 화면으로 돌아간다. 선택한 탭은 삭제 결과를 바꾸지 않는다.

삭제된 태그에서 수정 중이던 내용은 유지하지 않는다.

### 외부 변경과 대상 전환

화면이 열려 있는 동안 같은 태그의 저장 이모지나 제목이 다른 경로에서 바뀌면 화면 제목을 최신 저장 내용으로 갱신한다. 입력 중인 이모지, 제목, 설명과 컬러는 덮어쓰지 않는다.

화면이 열려 있는 동안 같은 태그의 연결이 다른 경로에서 바뀌면 연결 입력에 최신 연결을 반영한다.

태그 목록과 함께 표시하는 동안 사용자가 목록에서 다른 태그를 선택하면 상세 대상이 그 태그로 바뀌며, 화면 제목, 입력 내용, 연결 입력과 메모·웹·장소 목록을 새 태그의 값으로 바꾼다. 이전 태그에서 수정 중이던 내용과 고른 표시 범위는 이어지지 않고, 선택한 탭은 태그 디테일 탭으로 돌아가며, 메모·웹·장소 탭의 정렬 선택과 목록 위치도 각 목록의 처음 상태로 돌아간다. 장소 탭의 보기 모드와 지도가 보고 있던 위치만 이어지며, 그 기준은 [TagDetail 장소 탭 스펙](./tag-detail-place.md)의 `기본 보기 모드`를 따른다.

연결한 태그를 눌러 연 태그의 상세는 상세 대상이 바뀌는 것이 아니라 그 태그의 TagDetail 화면이 새로 열리는 것이며, 뒤로가면 이전 태그의 상세로 돌아간다.

뒤로가서 돌아온 이전 태그의 상세는 떠나기 전 그대로이며, 수정 중이던 내용과 선택한 탭, 고른 표시 범위가 남아 있다. 연결이 순환해 연결을 따라가다 이미 열어 둔 태그의 상세에 다시 닿아도 그 상세는 새로 열리는 화면이며, 앞서 열어 둔 같은 태그의 상세와 내용을 나누지 않는다. 뒤로가면 거쳐 온 상세들을 연 순서의 반대로 하나씩 돌아가고, 각 상세는 떠나기 전 그대로 보인다.

### 갱신과 새로고침

태그 디테일 탭의 화면 제목과 연결 입력은 다른 화면이나 다른 기기에서 바뀐 내용이 이 기기에 반영되면 사용자가 아무것도 하지 않아도 바로 최신 내용으로 바뀐다. 입력 중인 내용을 덮어쓰지 않는 기준은 `외부 변경과 대상 전환`을 따른다.

태그 디테일 탭에서는 당겨서 새로고침을 제공하지 않는다. 메모·웹·장소 탭은 각 탭 스펙에 따라 목록을 당겨 새로고침할 수 있으며, 어느 탭에서 당겨도 같은 한 번의 새로고침이 실행된다. 기준은 [새로고침 스펙](./sync-refresh.md)을 따른다.

### 진행 상태 유지

같은 태그를 대상으로 화면이 회전하거나 시스템에 의해 재생성되면 수정 중인 이모지, 제목, 설명과 컬러, 선택한 탭, 그리고 고른 표시 범위를 유지한다.

상세 대상이 다른 태그로 바뀌면 이전 태그의 수정 내용을 유지하지 않는다.

### 뒤로가기

사용자가 뒤로가면 선택한 탭과 관계없이 TagDetail 화면에 진입하기 전 화면으로 돌아간다. 태그 디테일 탭이 아닌 탭을 선택한 상태에서 뒤로간다고 태그 디테일 탭으로 먼저 돌아가지 않는다.

태그 목록과 함께 표시하는 동안 목록에서 선택해 진입한 TagDetail 화면은 [목록·상세 배치 공통 스펙](./list-detail-pane.md)의 `함께 사용할 때의 행동`에 따라 목록으로 돌아가는 별도 동작을 제공하지 않는다.

다른 태그의 TagDetail 화면에서 연결한 태그를 눌러 이동해 온 TagDetail 화면은 태그 목록과 함께 표시하는 동안에도 뒤로가기 동작을 제공한다. 사용하면 이전 태그의 상세로 돌아가고, 목록은 그대로 유지된다.

상세 영역에 놓인 태그 추가의 연결 입력에서 연결한 태그를 눌러 연 TagDetail 화면은 바로 앞 화면이 태그 상세가 아니므로, 태그 목록과 함께 표시하는 동안에는 목록에서 선택해 진입한 화면과 같이 뒤로가기 동작을 제공하지 않는다. 한 화면만 제공하는 환경에서는 다른 TagDetail 화면과 같이 뒤로가기 동작을 제공한다.

## domain

### 상세 대상과 내용 표시

상세 대상은 현재 사용자 계정과 연결된 태그 하나다. 네 탭은 같은 상세 대상 태그를 공유한다.

화면 제목에는 대상 태그의 최신 저장 이모지와 제목을 표시한다. 이모지 표시 규칙은 [TagHome 목록 스펙](./tag-home.md)의 `태그 이모지 표시`를 따른다.

입력 내용은 대상 태그를 처음 조회한 값으로 한 번만 채운다. 같은 태그의 저장 내용이 바뀌어도 다시 채우지 않지만 상세 대상이 바뀌면 새 대상의 값을 채운다.

### 선택한 탭

선택한 탭은 화면 표시 상태이며 저장되는 사용자 데이터가 아니다.

화면 재생성과 백그라운드 복귀 후에도 선택한 탭을 유지한다.

사용자가 화면을 떠났다가 다시 진입하거나 앱을 종료하고 다시 실행하면 태그 디테일 탭으로 초기화한다. 상세 대상이 다른 태그로 바뀔 때도 태그 디테일 탭으로 초기화한다.

태그의 완료 여부와 삭제 여부는 선택할 수 있는 탭을 바꾸지 않는다. 완료된 태그의 TagDetail 화면에서도 네 탭을 모두 사용할 수 있다.

### 표시 범위

표시 범위는 메모·웹·장소 탭이 목록에 담을 태그의 집합을 정하며 세 값 중 하나를 가진다. 어느 값에서도 상세 대상 태그 자신은 항상 집합에 포함한다.

| 표시 범위 | 집합에 포함하는 태그 |
| --- | --- |
| 이 태그만 | 상세 대상 태그 |
| 직속 하위까지 | 상세 대상 태그와 그 하위 태그 |
| 모든 하위까지 | 상세 대상 태그와 그 후손 태그 |

하위 태그와 후손 태그가 무엇인지, 순환하는 연결과 삭제된 태그를 어떻게 다루는지는 [태그 연결 앱 스펙](./tag-link.md)의 `하위 태그의 조회`를 따른다. 집합에는 같은 태그가 두 번 들어가지 않는다.

집합을 만드는 기준은 상세 대상 태그의 완료 여부와 삭제 여부에 따라 달라지지 않는다. 상세 대상 태그는 조회할 수 없어도 집합에 포함하므로, 태그를 아직 조회하지 못한 동안에도 세 목록은 지금 표시 범위를 그대로 적용한다.

화면이 열려 있는 동안 태그 연결이 다른 경로에서 바뀌면 집합을 다시 만들어 세 목록에 반영한다. 이때 사용자가 고른 표시 범위는 바뀌지 않는다.

표시 범위는 세 목록에 담을 태그만 정하고 각 탭의 나머지 노출 기준을 대체하지 않는다. 집합 안 태그와 연결되어 있어도 그 탭의 노출 기준을 만족하지 않는 항목은 표시하지 않는다.

### 표시 범위의 유지

표시 범위는 선택한 탭과 마찬가지로 화면 표시 상태이며 저장되는 사용자 데이터가 아니다.

화면 재생성과 백그라운드 복귀 후에도 고른 표시 범위를 유지한다.

사용자가 화면을 떠났다가 다시 진입하거나 앱을 종료하고 다시 실행하면 `이 태그만`으로 초기화한다. 상세 대상이 다른 태그로 바뀔 때도 `이 태그만`으로 초기화한다.

### 수정되는 내용

수정은 대상 태그의 이모지, 제목, 설명과 컬러를 바꾸고 수정 시각을 수정 시점으로 기록한다.

수정 시 제목이 비어 있거나 공백만 있으면 기존 제목을 사용한다. 이모지는 비어 있어도 기존 값으로 되돌리지 않고 빈 값으로 반영한다.

이모지가 가질 수 있는 값은 [TagAdd 화면 스펙](./tag-add.md)의 `태그 이모지`를 따른다.

완료 여부, 삭제 여부, 생성 시각과 계정·그룹 연결은 내용 수정으로 바뀌지 않는다.

### 완료·다시 시작·삭제

완료 동작은 완료 여부를 완료로, 다시 시작은 미완료로, 삭제는 삭제 여부를 삭제로 바꾸며 모두 수정 시각을 동작 시점으로 갱신한다. 세 동작 모두 태그 자체를 지우지 않고 상태만 바꾼다.

완료, 다시 시작과 삭제는 이모지, 제목, 설명과 컬러를 바꾸지 않는다.

완료와 삭제는 현재 사용자 계정과 연결된 태그에만 적용한다.

태그를 완료하거나 삭제해도 그 태그와 메모·웹 항목·장소의 연결은 바뀌지 않으므로 메모·웹·장소 탭의 노출 기준도 바뀌지 않는다.

### 연결 입력에 표시하는 태그

기준은 [항목 상세 화면 공통 스펙](./entity-detail.md)의 `태그 입력에 표시하는 태그`를 따르며, 이 화면에서 표시 대상은 대상 태그를 출발 태그로 하는 저장된 연결의 도착 태그다. 어떤 태그가 조회되는지는 [태그 연결 앱 스펙](./tag-link.md)의 `연결된 태그의 조회`를 따른다.

대상 태그를 향해 오는 연결은 이 화면에 표시하지 않는다.

새로 연결할 수 있는 태그는 [태그 연결 입력 컴포넌트 스펙](./tag-link-input.md)의 `선택할 수 있는 태그`를 따르며, 대상 태그 자신은 여기에서 제외한다.

### 연결의 반영

기준은 [항목 상세 화면 공통 스펙](./entity-detail.md)의 `태그 연결의 반영`을 따르며, 이 화면에서 만드는 연결은 대상 태그를 출발 태그로, 고른 태그를 도착 태그로 한다.

세 탭이 목록에 담을 항목을 고를 때 사용하는 연결은 각각 메모와 태그, 웹 항목과 태그, 장소와 태그의 연결이며 그 기준은 [항목 태그 연결 공통 스펙](../common/entity-tag.md)을 따른다. 태그와 태그의 연결은 그 항목들에 연결된 태그를 늘리지 않고, `표시 범위`가 정하는 집합에만 쓰인다. 따라서 표시 범위가 `이 태그만`이면 태그와 태그의 연결을 바꿔도 세 목록은 달라지지 않는다.

### 다시 시작과 메모 연결

태그를 다시 시작해도 그 태그와 메모의 연결은 바뀌지 않는다.

다시 시작한 태그는 미완료 상태가 되어 MemoHome 목록의 태그 필터에서 다시 선택할 수 있는 태그로 나타난다. 이때 적용되는 선택 유지 규칙은 [MemoHome 목록 스펙](./memo-home.md)의 `태그 필터 기준`을 따른다.

### 요청 제한

[항목 상세 화면 공통 스펙](./entity-detail.md)의 `요청 제한`에서 같은 종류로 보는 것은 수정, 완료·다시 시작, 삭제이며, 완료와 다시 시작은 같은 종류로 본다.

메모·웹·장소 탭에서 실행하는 동작은 이 제한에 포함하지 않는다.

### 완료·삭제와 태그 연결

대상 태그를 완료하거나 삭제해도 그 태그가 가진 연결은 해제되지 않는다. 기준은 [태그 연결 앱 스펙](./tag-link.md)의 `태그의 상태 변화와 연결`을 따른다.

완료된 태그의 TagDetail 화면에서도 사용자는 연결을 확인하고 바꿀 수 있다.

## data

### 태그 수정과 저장

수정을 반영하면 대상 태그의 이모지, 제목, 설명, 컬러와 수정 시각을 태그에 저장해 기존 값을 덮어쓴다.

### 상태 변경의 저장

완료, 다시 시작 또는 삭제를 실행하면 바뀐 상태를 즉시 저장한다. 태그 자체나 계정·그룹 연결은 지우지 않는다.

### 연결 입력의 조회

조회 흐름은 [항목 상세 화면 공통 스펙](./entity-detail.md)의 `태그 입력의 조회`를 따르며, 태그 선택 목록의 대상에서 대상 태그 자신을 제외한다.

### 연결의 저장

저장 흐름은 [항목 상세 화면 공통 스펙](./entity-detail.md)의 `태그 연결의 저장`을 따른다.

### 탭별 조회

태그 디테일 탭의 조회와 메모·웹·장소 탭의 목록 조회는 서로 독립이다. 어느 하나가 실패해도 다른 탭의 표시 기준은 바뀌지 않는다.

세 목록 조회는 지금 표시 범위가 정한 태그 집합을 기준으로 하며, 집합 안 여러 태그와 연결된 항목도 목록에 한 번만 나타난다. 사용자가 표시 범위를 바꾸면 세 목록을 새 집합으로 다시 조회한다.

표시 범위 자체는 기기에 저장하지 않고 서버와 동기화하지도 않는다.

세 목록 조회는 각각 [TagDetail 메모 탭 스펙](./tag-detail-memo.md), [TagDetail 웹 탭 스펙](./tag-detail-web.md), [TagDetail 장소 탭 스펙](./tag-detail-place.md)의 `data`를 따른다.

### 결과의 표시

수정 내용은 태그 목록과 TagDetail 화면 제목 등 해당 태그를 조회하는 곳에 반영된다.

제목이 바뀌면 [TagHome 목록 스펙](./tag-home.md)의 정렬 기준에 따라 목록에서 이동한다. 제목이 바뀌지 않으면 수정 시각 갱신만으로 목록 순서가 바뀌지 않는다.

완료하거나 삭제한 태그는 목록의 노출 기준에 따라 사라진다. 완료된 태그의 TagDetail 화면은 유지되므로 사용자는 계속 확인하거나 다시 시작할 수 있다.
