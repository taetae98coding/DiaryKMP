# Profile 화면 스펙

이 문서는 로그인한 사용자가 자기 계정을 관리하는 Profile 화면의 내용과 행동을 다룬다. 이 화면으로 진입하는 계정 카드 선택은 [MoreHome 화면 스펙](./more-home.md)에서, 사진을 고르고 영역을 정해 프로필 이미지로 반영하는 화면은 [ProfileImageEdit 화면 스펙](./profile-image-edit.md)에서, 탈퇴를 확인하고 실행하는 흐름과 그 결과는 [계정 탈퇴 스펙](./account-deletion.md)에서, 세부 화면에서의 공통 내비게이션 노출 규칙은 [TopLevelNavigation 스펙](./top-level-navigation.md)에서 다룬다.

디자인: [Profile 화면 디자인](../../design/profile.md)

## feature

### 진입

사용자는 MoreHome 화면에서 계정 카드를 선택해 Profile 화면으로 이동한다. 진입 조건은 [MoreHome 화면 스펙](./more-home.md)의 `domain > Profile 진입 조건`을 따른다.

### 화면 내용

Profile 화면에서는 다음 두 동작을 제공한다.

1. `프로필 이미지 변경`
2. `탈퇴하기`

이 화면은 계정 정보를 따로 불러오지 않으므로 불러오는 중, 빈 상태, 불러오기 오류가 없다. 두 동작은 항상 보인다. 사용자가 직접 실행하는 새로고침도 없다.

### 프로필 이미지 변경

사용자가 `프로필 이미지 변경`을 선택하면 ProfileImageEdit 화면으로 이동한다. 사진을 고르고 영역을 정해 반영하는 행동은 [ProfileImageEdit 화면 스펙](./profile-image-edit.md)이 소유한다.

반영에 성공하면 Profile 화면으로 돌아온다. 바뀐 프로필 이미지는 사용자가 MoreHome 화면으로 돌아갔을 때 보이며, 그 시점은 [프로필 이미지 변경 스펙](./profile-image.md)의 `data > 반영 결과의 전달`을 따른다.

### 탈퇴하기

사용자가 `탈퇴하기`를 선택하면 탈퇴를 한 번 더 확인하는 다이얼로그가 열린다. 확인, Apple 재인증, 탈퇴 처리와 그 결과는 [계정 탈퇴 스펙](./account-deletion.md)의 `feature`를 따른다.

탈퇴가 진행 중인 동안에는 두 동작을 실행할 수 없다.

### 뒤로가기

사용자가 뒤로가면 MoreHome 화면으로 돌아간다. 탈퇴 확인 다이얼로그가 열려 있을 때의 뒤로가기는 [계정 탈퇴 스펙](./account-deletion.md)의 `feature > 탈퇴 확인`을 따른다.

## domain

### 계정 상태가 바뀔 때

Profile 화면은 사용자 상태에서만 의미가 있다. 이 화면을 보는 동안 계정이 게스트가 되면 화면을 닫고 MoreHome 화면으로 돌아간다. 다른 기기에서 탈퇴해 이 기기의 로그인 세션이 폐기되거나, 이 화면에서 탈퇴에 성공한 경우가 여기에 해당한다. 계정 상태의 결정 기준은 [계정 조회 스펙](./account.md)을 따른다.

계정을 잠시 확인하지 못하거나 세션 갱신 여부만 바뀌는 것은 계정이 바뀐 것으로 보지 않으며 화면을 닫지 않는다.

### 실행 경계

화면이 회전하거나 시스템에 의해 재생성되어도 Profile 화면에 머문다. 탈퇴 확인 다이얼로그와 진행 상태의 유지 기준은 [계정 탈퇴 스펙](./account-deletion.md)의 `domain > 실행 경계`를 따른다.
