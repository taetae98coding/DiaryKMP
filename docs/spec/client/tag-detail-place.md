# TagDetail 장소 탭 스펙

이 문서는 사용자가 TagDetail 화면의 장소 탭에서 표시 범위 안 태그에 연결된 장소를 목록이나 지도로 확인하고, 상세 대상 태그를 초기값으로 사용해 장소를 추가하는 행동을 다룬다. 화면 전체의 구성, 탭 전환과 유지, 화면 제목, 태그 디테일 탭의 행동과 세 목록 탭이 함께 쓰는 표시 범위와 공통 규칙(`목록 탭 공통`, `목록 탭의 대상과 추가의 초기값`, `탭별 조회`)은 [TagDetail 화면 스펙](./tag-detail.md)이 소유한다.

보기 모드 전환, 장소 탭의 기본 보기 모드, 지도와 지도 위 핀의 표시, 두 모드의 목록과 빈 상태, 장소 추가와 장소 상세로 이동할 때 넘기는 것, 목록 정렬과 새로고침의 공통 기준은 [장소 보기 모드 스펙](./place-view-mode.md)이 소유한다. 이 문서에는 장소 탭에서 보기 모드가 유지되는 경계, 노출 대상 장소, 현재 위치 확인 시점, 장소 추가의 초기값과 목록에서 장소를 삭제하고 되돌리는 행동 가운데 장소 탭에만 있는 차이를 둔다.

목록의 장소 표시는 [PlaceHome 화면 스펙](./place-home.md)을, 장소 추가 행동은 [PlaceAdd 화면 스펙](./place-add.md)을, 장소와 태그 연결의 의미는 [장소 태그 앱 스펙](./place-tag.md)을, 선택한 장소의 상세는 [PlaceDetail 화면 스펙](./place-detail.md)을 따른다. 지도의 표시와 지도 제공자 전환, 핀 표시와 핀 선택은 [DiaryMap 컴포넌트 스펙](./diary-map.md)을, 기본 지도를 고르고 저장하는 흐름은 [SettingMap 화면 스펙](./setting-map.md)을, 현재 위치를 확인하는 규칙은 [현재 위치 확인 스펙](./current-location.md)을 따른다. 아직 준비되지 않은 자리의 처리는 [페이지 조회 목록의 자리 표시 스펙](./paged-list-placeholder.md)을, 목록이 비어 있을 때의 안내는 [목록 빈 상태 스펙](./list-empty-state.md)을, 목록을 당겨 새로고침하는 행동과 동기화 진행 표시는 [새로고침 스펙](./sync-refresh.md)을 따른다.

장소 탭의 지도 모드는 이 태그에 연결된 장소를 지도와 지도 위 핀으로 확인하는 것까지 제공한다. 위치 권한 요청, 지도에서 장소를 찾는 검색과 경로 안내, 저장된 항목을 찾는 검색 진입은 이 탭에서 제공하지 않는다.

디자인: [TagDetail 장소 탭 디자인](../../design/tag-detail-place.md)

## feature

### 진입

사용자는 TagDetail 화면에서 장소 탭을 선택해 표시 범위 안 태그에 연결된 장소를 확인한다. 탭을 선택하는 방법과 선택한 탭의 유지 기준은 [TagDetail 화면 스펙](./tag-detail.md)의 `탭 전환`과 `선택한 탭`을 따른다.

장소 탭을 선택하면 `기본 보기 모드`로 시작한다. 선택한 뒤 사용자가 보기 모드를 바꾸고 지도와 목록을 다루는 행동은 [장소 보기 모드 스펙](./place-view-mode.md)을 따른다.

상세 대상 태그의 조회 결과와 관계없이 목록, 지도와 동작을 제공하는 기준은 [TagDetail 화면 스펙](./tag-detail.md)의 `목록 탭 공통`을 따른다.

### 보기 모드와 탭 전환

보기 모드는 장소 탭에만 적용한다. 다른 탭에 다녀와도 바꿔 둔 보기 모드와 지도가 보고 있던 위치, 확대 수준, 고른 지도 제공자는 그대로 남아 있다.

다른 탭을 선택한 동안에는 지도와 지도 제공자를 바꾸는 기능을 사용할 수 없다.

### 장소 추가

사용자는 어느 보기 모드에서든 장소 추가를 시작할 수 있다. 사용자가 장소 추가를 선택하면 PlaceAdd 화면으로 이동한다. 추가를 시작할 수 있는 조건, 화면의 표시와 돌아오기, 최초 선택은 [TagDetail 화면 스펙](./tag-detail.md)의 `목록 탭 공통`을 따른다. PlaceAdd로 넘기는 지도 위치는 [장소 보기 모드 스펙](./place-view-mode.md)의 `장소 추가로 이동`을 따른다.

### 장소 상세 확인

사용자가 목록 모드에서 목록의 장소를 선택하거나 지도 모드에서 지도 위 핀을 누르면 그 장소의 PlaceDetail 화면으로 이동하며, 그 기준은 [장소 보기 모드 스펙](./place-view-mode.md)의 `장소 상세로 이동`을 따른다. 지도 모드의 목록에서 장소를 누르면 [장소 보기 모드 스펙](./place-view-mode.md)의 `장소 위치 보기`에 따라 지도가 그 장소로 이동하거나, 이미 지도 가운데에 있는 장소면 PlaceDetail 화면으로 이동한다. PlaceDetail 화면의 표시, 돌아오기와 돌아온 뒤의 목록은 [TagDetail 화면 스펙](./tag-detail.md)의 `목록 탭 공통`을 따르며, 돌아온 뒤 사라지는 장소는 두 보기 모드의 목록과 핀에서 함께 사라진다.

### 삭제와 실행 취소

사용자는 두 보기 모드의 목록에서 장소를 삭제할 수 있다. 삭제의 상호작용, 안내와 실행 취소, 저장과 동기화는 [PlaceHome 화면 스펙](./place-home.md)의 `삭제`, `안내와 실행 취소`, `domain > 삭제와 실행 취소의 상태 전이`, `data > 삭제와 실행 취소의 저장`을 따른다.

삭제는 장소 자체를 삭제 상태로 바꾸는 것이며, 장소와 이 태그의 연결만 해제하지 않는다. 따라서 삭제한 장소는 이 탭의 목록과 지도 핀뿐 아니라 그 장소를 보여 주는 모든 목록에서 사라진다. 실행 취소하면 태그 연결은 그대로이므로 지금 보기 모드의 노출 기준을 만족하면 정렬 기준에 맞는 위치와 지도 핀에 다시 나타난다.

안내를 표시하는 곳과 다른 탭으로 바꿀 때 안내가 닫히는 결과는 [TagDetail 화면 스펙](./tag-detail.md)의 `목록 탭 공통`을 따른다. 장소 탭 안에서 보기 모드를 바꾸는 것은 탭을 바꾸는 것이 아니므로 안내는 그대로 남는다.

### 빈 상태

대상 태그의 조회 결과가 빈 상태 판정에 주는 영향은 [TagDetail 화면 스펙](./tag-detail.md)의 `목록 탭 공통`을 따른다. 두 보기 모드가 각각 무엇을 알리는지는 [장소 보기 모드 스펙](./place-view-mode.md)의 `빈 상태`를 따른다.

### 새로고침

사용자는 두 보기 모드에서 장소 목록을 당겨 새로고침할 수 있다. 당길 수 있는 자리는 [장소 보기 모드 스펙](./place-view-mode.md)의 `장소 목록 새로고침`을, 새로고침 대상과 진행 표시는 [새로고침 스펙](./sync-refresh.md)을 따른다. 메모·웹 탭에서 당긴 것과 같은 한 번의 새로고침이다.

다른 화면이나 다른 기기에서 바뀐 장소와 연결이 이 기기에 반영되면 사용자가 당기지 않아도 목록과 핀에 바로 반영된다.

## domain

### 상세 대상 태그와 연결

장소 탭의 상세 대상 태그와 목록에 담을 연결은 [TagDetail 화면 스펙](./tag-detail.md)의 `목록 탭의 대상과 추가의 초기값`을 따르며, 목록에 담는 연결은 장소와 태그의 연결이다. 그 기준으로 목록에서 빠지거나 바뀌는 장소는 지도 핀에서도 함께 빠지거나 바뀐다.

### 기본 보기 모드

장소 탭의 기본 보기 모드는 [장소 보기 모드 스펙](./place-view-mode.md)의 `적용 대상` 표가 정한다.

보기 모드가 무엇을 노출하는지와 어떤 경계에서 유지되고 초기화되는지는 [장소 보기 모드 스펙](./place-view-mode.md)의 `보기 모드`와 `보기 모드의 유지`를 따른다. 사용자가 TagDetail 화면을 떠난 뒤 다시 진입하면 기본 보기 모드로 초기화한다.

상세 대상이 다른 태그로 바뀌어도 보기 모드는 유지하고 목록과 핀만 새 대상 태그의 장소로 바꾼다. 지도가 보고 있던 위치와 확대 수준, 고른 지도 제공자도 그대로 이어지고 현재 위치를 다시 확인하지 않는다. 사용자는 지도 모드를 유지한 채 대상을 바꿔 같은 지역에서 태그별 장소를 이어서 확인한다. 대상이 바뀌면 화면은 태그 디테일 탭에서 다시 시작하므로, 장소 탭을 다시 선택하면 이어진 보기 모드와 지도를 본다.

### 노출 대상 장소

장소 탭의 노출 대상 장소는 현재 사용자 계정과 연결된 장소 중 표시 범위 안 태그 하나 이상과 해제되지 않은 연결을 가지며 삭제되지 않은 장소다. 표시 범위가 무엇을 정하는지는 [TagDetail 화면 스펙](./tag-detail.md)의 `표시 범위`를 따르며, 표시 범위는 담을 태그만 정하고 이 노출 기준을 대체하지 않는다.

여러 태그와 연결된 장소를 목록에 한 번만 보여 주는 기준은 [TagDetail 화면 스펙](./tag-detail.md)의 `목록 탭 공통`을 따르며, 지도에도 핀 하나로만 나타난다.

두 보기 모드가 이 집합을 함께 사용하며, 지도 모드는 여기에 보이는 영역 기준을 더한다. 사용자가 표시 범위를 바꾸면 두 보기 모드의 목록과 핀을 새 범위 기준으로 다시 표시하고, 보기 모드와 지도가 보고 있던 위치와 확대 수준은 바꾸지 않는다.

두 모드가 이 집합을 어떻게 쓰는지는 [장소 보기 모드 스펙](./place-view-mode.md)의 `목록 모드에 노출하는 장소`와 `지도 모드에 노출하는 장소`를 따른다.

장소에는 완료 여부가 없으므로 완료된 장소를 모아 보는 목록도 두지 않는다.

### 현재 위치 확인 시점

장소 탭은 사용자가 처음 지도 모드로 바꿀 때 현재 위치를 한 번 확인한다. 목록 모드에 머무르는 동안에는 확인하지 않으므로, 지도를 한 번도 보지 않은 사용자에게는 위치 확인이 일어나지 않는다. 이 기준은 화면에 진입할 때 확인하는 [PlaceHome 화면 스펙](./place-home.md)의 `현재 위치 확인 시점`과 다르다.

목록 모드로 되돌린 뒤 다시 지도 모드로 바꿀 때는 다시 확인하지 않고 그때까지 보고 있던 지도를 이어서 본다. 사용자가 TagDetail 화면을 떠난 뒤 다시 들어오면 목록 모드에서 시작하므로, 그 뒤 처음 지도 모드로 바꿀 때 현재 위치를 새로 확인한다.

앱이 백그라운드에 있는 동안 시스템이 앱을 종료했다가 같은 화면으로 되살리면, 되살아난 뒤 장소 탭이 지도 모드로 처음 보일 때 현재 위치를 다시 확인한다. 지도 모드로 되살아났으면 장소 탭이 보이는 즉시, 목록 모드로 되살아났으면 그 뒤 처음 지도 모드로 바꿀 때다.

확인 방법과 확인하지 못했을 때의 표시, 재확인하지 않는 경계와 되살아난 뒤 지도가 시작하는 위치는 [장소 보기 모드 스펙](./place-view-mode.md)의 `초기 지도 위치`를 따른다.

### 장소 추가의 초기값

장소 추가의 초기값은 [TagDetail 화면 스펙](./tag-detail.md)의 `목록 탭의 대상과 추가의 초기값`을 따르므로, 완료되었거나 삭제된 대상 태그는 태그 입력에서 선택한 것으로 보이지 않지만 선택은 남아 추가할 때 그대로 연결된다. 보기 모드도 추가 시작을 막지 않는다. 그 밖의 저장 규칙은 [PlaceAdd 화면 스펙](./place-add.md)을 따른다.

### 태그 연결의 변경과 목록

장소 탭은 목록에서 장소의 태그 연결을 바꾸는 동작을 제공하지 않는다. 목록의 삭제는 `feature > 삭제와 실행 취소`에 따라 장소의 삭제 여부만 바꾸고 태그 연결은 바꾸지 않는다.

장소 탭 목록에서 실행하는 삭제와 실행 취소가 대상 태그와 태그 디테일 탭에 주는 영향은 [TagDetail 화면 스펙](./tag-detail.md)의 `목록 탭의 대상과 추가의 초기값`을 따른다. 사용자는 장소를 선택해 [PlaceDetail 화면](./place-detail.md)에서 연결을 바꾼다.

장소 탭이 목록과 핀에 담을 장소를 고를 때 사용하는 연결은 장소와 태그의 연결이며, 태그와 태그의 연결이 이 목록에 주는 영향은 [TagDetail 화면 스펙](./tag-detail.md)의 `연결의 반영`을 따른다.

## data

### 태그별 장소 조회

두 보기 모드의 목록과 지도 핀에 표시할 장소는 `노출 대상 장소`를 기준으로 기기에 저장된 장소에서 조회한다. 조회 방식과 갱신 기준은 [장소 보기 모드 스펙](./place-view-mode.md)의 `목록 조회`를 따른다.

자동 갱신과 연결이 해제되거나 복구된 장소의 결과는 [TagDetail 화면 스펙](./tag-detail.md)의 `탭별 조회`를 따르며, 두 모드의 목록과 핀에 함께 적용한다.

### 탭별 조회

장소 탭의 목록 조회와 다른 탭 조회의 관계는 [TagDetail 화면 스펙](./tag-detail.md)의 `탭별 조회`를 따른다.

### 장소 추가 결과

장소 추가 결과의 저장과 표시는 [TagDetail 화면 스펙](./tag-detail.md)의 `탭별 조회`를 따르며, 노출 기준은 지금 보기 모드의 기준이다.
