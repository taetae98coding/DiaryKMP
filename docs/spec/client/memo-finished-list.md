# MemoFinishedList 화면 스펙

이 문서는 사용자가 MemoHome 목록에서 완료된 메모를 모아 확인하는 MemoFinishedList 화면 가운데 이 화면에만 해당하는 부분을 다룬다. 진입과 이동, 빈 상태, 추가 미제공, 상세 확인, 정렬 선택, 노출 기준과 실행 경계의 공통 규칙은 [완료 목록 공통 스펙](./finished-list.md)을 따른다. 이 화면의 짝이 되는 목록은 [MemoHome 목록](./memo-home.md)이다.

메모 카드의 내용, 기간 표시, 정렬과 날짜 그룹은 [MemoHome 목록 스펙](./memo-home.md)을 따르고, 완료·다시 시작·삭제의 상태 전이도 같은 문서를 따른다. 완료·삭제 상호작용의 공통 규칙은 [SwipeToFinishAndDelete 컴포넌트 스펙](./swipe-to-finish-and-delete.md)을, 상세 확인은 [MemoDetail 화면 스펙](./memo-detail.md)을 따른다. 태그 하나에 연결된 완료된 메모만 모아 확인하는 화면은 [TagMemoFinishedList 화면 스펙](./tag-memo-finished-list.md)에서 다룬다.

디자인: [MemoFinishedList 화면 디자인](../../design/memo-finished-list.md)

## feature

### 목록 표시

각 메모에는 제목이 표시되고, 기간이 있으면 기간도 함께 표시된다. 카드의 표시 방식은 [MemoHome 목록 스펙](./memo-home.md)의 `목록 표시`를 따른다.

### 빈 상태 문구

완료된 메모가 하나도 없으면 목록 자리에 완료한 메모가 아직 없음을 알린다.

### 태그 필터 미적용

이 화면에는 태그 필터를 제공하지 않는다.

사용자가 MemoHome 목록에서 선택한 태그 필터는 이 목록의 메모 노출에 영향을 주지 않는다. 따라서 사용자는 태그 필터를 어떻게 선택해 두었는지와 관계없이 완료된 메모 전체를 확인한다.

### 날짜 헤더

날짜 헤더의 구성과 오늘 표시는 [MemoHome 목록 스펙](./memo-home.md)의 `날짜 헤더`를 따른다.

### 다시 시작

사용자는 목록의 메모를 다시 시작할 수 있다.

다시 시작하면 메모가 이 목록에서 사라지고 다시 시작되었음을 안내하며, 실행 취소 동작을 제공한다.

사용자가 실행 취소를 선택하면 메모는 완료된 상태로 되돌아가 이 목록에 다시 나타난다.

### 삭제

사용자는 목록의 메모를 삭제할 수 있다.

삭제하면 메모가 목록에서 사라지고 삭제되었음을 안내하며, 실행 취소 동작을 제공한다.

사용자가 실행 취소를 선택하면 메모는 삭제되지 않은 상태로 되돌아가 이 목록에 다시 나타난다.

### 안내와 실행 취소

다시 시작과 삭제의 안내가 사라지는 때, 이어서 다른 메모를 다시 시작하거나 삭제했을 때 실행 취소가 적용되는 동작, 저장되지 못했을 때의 결과는 [MemoHome 목록 스펙](./memo-home.md)의 `안내와 실행 취소`에서 완료를 다시 시작으로 바꿔 그대로 따른다.

### 내용 갱신과 새로고침

목록의 갱신 방식은 [MemoHome 목록 스펙](./memo-home.md)의 `내용 갱신`을 따른다. 다른 화면에서 메모를 완료하거나 다시 시작하면 이 목록은 새로고침하지 않아도 바로 그 메모를 보여 주거나 감춘다.

사용자는 목록을 당겨 새로고침할 수 있고, 그 결과는 [새로고침 스펙](./sync-refresh.md)을 따른다. 이 화면에 들어오는 것만으로는 새로고침하지 않는다.

## domain

### 태그 필터와 노출 기준

태그 필터 선택은 [완료 목록 공통 스펙](./finished-list.md)의 `노출 기준`에 넣지 않는다. 완료된 메모는 되돌아보기 위한 목록이므로 사용자가 MemoHome에서 좁혀 둔 범위를 그대로 적용하지 않고 전체를 보여 준다.

### 정렬과 날짜 그룹

정렬, 날짜 그룹과 오늘의 기준은 [MemoHome 목록 스펙](./memo-home.md)의 `정렬`과 `날짜 그룹과 오늘 기준`을 따른다.

### 다시 시작과 삭제의 상태 전이

다시 시작은 메모의 완료 여부를 미완료 상태로 바꾸는 것이고, 삭제는 삭제 여부를 삭제 상태로 바꾸는 것이다. 두 동작 모두 메모 자체를 지우지 않는다.

실행 취소는 직전에 바꾼 상태를 원래 상태로 되돌린다. 다시 시작의 실행 취소는 완료 여부를 완료로, 삭제의 실행 취소는 삭제 여부를 미삭제로 되돌린다.

다시 시작, 삭제와 실행 취소는 모두 메모의 수정 시각을 동작 시점으로 갱신한다.

다시 시작과 삭제는 메모의 제목, 설명, 컬러, 기간, 태그 연결과 대표 태그를 바꾸지 않는다.

## data

### 목록 조회

조회 흐름은 [완료 목록 공통 스펙](./finished-list.md)의 `목록 조회`를 따른다. 태그 필터 선택은 조회 조건에 넣지 않으며, 메모의 기간이 바뀔 때도 목록을 갱신한다.

날짜 헤더는 조회된 순서에서 시작 날짜가 바뀌는 자리마다 만들어진다. 따라서 화면에 아직 내용이 준비되지 않은 구간의 날짜 헤더는 그 구간의 메모가 준비된 뒤에 나타난다.

### 상태 변경의 저장

목록에서 메모를 다시 시작하거나 삭제하면 현재 사용자 계정과 연결된 해당 메모의 완료 여부나 삭제 여부가 기기에 즉시 저장되고, 서버에는 [데이터 동기화 스펙](../common/data-sync.md)에 따라 반영된다.

실행 취소를 선택하면 되돌린 상태가 같은 방식으로 즉시 저장된다.
