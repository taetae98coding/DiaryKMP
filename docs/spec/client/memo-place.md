# 메모 장소 앱 스펙

이 문서는 메모와 장소의 연결 가운데 앱이 기기에 저장된 연결로 메모의 장소와 장소의 메모를 조회하는 규칙과, 이 연결이 앱의 목록과 검색 결과에 주는 영향을 다룬다. 메모와 장소의 연결이 공통으로 지키는 규칙은 [메모 장소 스펙](../common/memo-place.md)을, 연결의 성질과 동기화 계약은 [항목 연결 공통 스펙](../common/entity-link.md)을, 연결을 기기에 저장하는 규칙은 [항목 연결 앱 스펙](./entity-link.md)을 따른다.

사용자가 장소를 고르고 해제하는 조작과 조회 결과를 보여 주는 화면은 각 입력 컴포넌트 스펙과 화면 스펙이 소유하므로 이 문서에는 `feature` 영역을 두지 않는다.

## domain

### 연결된 장소의 정렬

메모를 기준으로 조회한 장소는 제목 오름차순으로 놓인다. 제목이 같은 장소끼리의 순서는 정하지 않는다.

조회에 포함되는 연결과 장소의 기준은 [항목 연결 공통 스펙](../common/entity-link.md)의 `연결된 항목의 조회`를 따른다.

### 연결의 의미

[항목 연결 공통 스펙](../common/entity-link.md)의 `연결의 의미`는 메모와 장소의 연결에서 다음 목록에 적용된다.

- [MemoHome 목록 스펙](./memo-home.md)의 목록 노출 기준과 정렬. 사용자가 유무 필터의 장소 축을 `있음`이나 `없음`으로 고른 동안만 예외로 이 연결이 판정에 쓰이며, 그 기준은 MemoHome 목록 스펙의 `유무 필터 기준`을 따른다. 장소 연결 여부는 [태그 필터 스펙](./tag-filter.md)의 대상이 아니다.
- [캘린더 메모 표시 스펙](./calendar-memo.md)의 노출 기준
- [PlaceHome 화면 스펙](./place-home.md)의 목록·지도 핀 노출 기준과 정렬
- [SearchHome 화면 스펙](./search-home.md)의 메모 검색 결과와 장소 검색 결과. 연결된 장소의 제목은 메모의 검색 일치 판정에 쓰이지 않고, 연결된 메모의 제목도 장소의 검색 일치 판정에 쓰이지 않는다.
- 태그로 메모나 장소를 조회한 결과

장소로 메모를 조회하는 [PlaceDetail 메모 탭 스펙](./place-detail-memo.md)의 목록은 이 연결을 노출 기준으로 쓴다.

메모와 장소가 같은 태그와 연결되어 있어도 그것만으로 메모와 장소가 연결되지는 않는다.

## data

### 메모별 장소 표시

메모로 장소를 조회할 때는 현재 사용자 계정과 연결된 장소와 메모-장소 연결만 사용한다. 조회에 포함되는 연결과 장소의 기준은 [항목 연결 공통 스펙](../common/entity-link.md)의 `연결된 항목의 조회`를 따른다.

연결이 만들어지거나 해제되거나 복구되면 그 메모의 장소를 표시하는 화면과 그 장소의 메모를 표시하는 화면은 변경된 연결 상태를 반영한다.

### 장소별 메모 표시

장소로 메모를 조회할 때는 현재 사용자 계정과 연결된 메모와 메모-장소 연결만 사용한다. 조회에 포함되는 연결과 메모의 기준은 [항목 연결 공통 스펙](../common/entity-link.md)의 `연결된 항목의 조회`를 따르며, 그 위에 더하는 노출 기준과 정렬은 [항목 상세 메모 탭 공통 스펙](./entity-detail-memo.md)이 정한다.
