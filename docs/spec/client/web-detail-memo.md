# WebDetail 메모 탭 스펙

이 문서는 사용자가 WebDetail 화면의 메모 탭에서 상세 대상 웹 항목에 연결된 메모를 확인하고 조작하며, 그 웹 항목을 초기 선택으로 사용해 메모를 추가하는 행동 가운데 WebDetail 화면에만 해당하는 부분을 다룬다. 목록 표시, 빈 상태, 메모 추가와 메모 상세 확인, 완료·삭제와 실행 취소, 새로고침, 정렬, 조회와 저장 계약은 [항목 상세 메모 탭 공통 스펙](./entity-detail-memo.md)이 소유한다. 화면 전체의 구성, 메모 탭의 선택과 유지, 화면 제목, 웹 정보 수정과 웹 페이지 표시의 행동은 [WebDetail 화면 스펙](./web-detail.md)이 소유한다.

메모와 웹 항목 연결의 의미는 [메모 웹 앱 스펙](./memo-web.md)의 `연결의 의미`를 따른다.

조회와 저장은 공통 스펙의 `data`를 그대로 따르므로 이 문서에는 `data` 영역을 두지 않는다.

디자인: [항목 상세 메모 탭 공통 디자인](../../design/entity-detail-memo.md), [WebDetail 화면 디자인](../../design/web-detail.md)

## feature

### 진입

사용자는 WebDetail 화면에서 메모 탭을 선택해 상세 대상 웹 항목에 연결된 메모 목록을 확인한다. 탭을 선택하는 방법과 선택한 탭의 유지 기준은 [WebDetail 화면 스펙](./web-detail.md)의 `메모 탭`과 `선택한 탭`을 따른다.

WebHome, SearchHome, TagDetail 웹 탭, 메모의 웹 입력 어느 경로로 진입한 WebDetail 화면에서도 같은 메모 탭을 제공한다.

### 메모 추가의 초기 선택

메모 탭에서 진입한 MemoAdd 화면은 상세 대상 웹 항목이 웹 입력에 선택된 상태로 시작한다. 태그, 연락처, 장소는 선택되지 않은 상태로 시작한다.

### 단독 표시와 돌아오기

메모 탭에서 이동한 MemoAdd 화면과 MemoDetail 화면은 창 너비와 관계없이 단독으로 표시한다.

두 화면에서 뒤로가면 메모 탭이 선택된 같은 웹 항목의 WebDetail 화면으로 돌아간다. 그 WebDetail 화면에서 다시 뒤로가면 [WebDetail 화면 스펙](./web-detail.md)의 `뒤로가기`에 따라 WebDetail에 진입하기 전 화면으로 돌아간다.

## domain

### 상세 대상

메모 탭의 상세 대상은 WebDetail 화면의 상세 대상 웹 항목과 같다. 대상이 결정되는 기준은 [WebDetail 화면 스펙](./web-detail.md)의 `상세 대상`을 따른다.

목록에 담을 연결은 메모와 웹 항목의 연결이며, 그 규칙은 [메모 웹 스펙](../common/memo-web.md)을 따른다.

### 웹 항목의 상태와 노출

웹 항목의 태그 연결 변경, 내용 수정, 웹 페이지 표시 방식 변경과 웹 항목 삭제는 메모와 웹 항목의 연결을 바꾸지 않으므로 메모 탭의 노출 기준도 바꾸지 않는다. 웹 항목에 연결된 태그와 메모에 연결된 태그는 서로 무관하며, 같은 태그를 가졌다는 것만으로 메모가 이 목록에 나타나지 않는다.
