# Setting 목록·상세 배치 스펙

이 문서는 설정 목록과 상세를 함께 사용할 때 이 배치에만 해당하는 상세 선택 상태, 뒤로가기와 초기화 경계를 다룬다. 함께 사용과 단독 사용, 표시 비율 조절, 배치에 참여하는 화면과 유지·초기화의 공통 기준은 [목록·상세 배치 공통 스펙](./list-detail-pane.md)을 따른다. 설정 목록과 각 세부 설정 화면의 내용과 행동은 [SettingHome 화면 스펙](./setting-home.md), [SettingHoliday 화면 스펙](./setting-holiday.md), [SettingMap 화면 스펙](./setting-map.md), [SettingGemini 화면 스펙](./setting-gemini.md), [SettingBrowser 화면 스펙](./setting-browser.md), [SettingPlaylist 화면 스펙](./setting-playlist.md), [SettingFile 화면 스펙](./setting-file.md)에서 다룬다.

디자인: [Setting 목록·상세 배치 디자인](../../design/setting-list-detail.md)

선택 상태와 표시 비율은 화면 표시 상태일 뿐 사용자 데이터를 만들거나 저장하지 않으므로 `data` 영역은 생략한다.

## feature

### 상세 영역의 구성

이 배치는 추가를 제공하지 않으며, 아직 설정 항목을 선택하지 않았으면 상세를 선택 전 상태로 둔다. 선택 전 상태와 추가를 실행하는 수단이 없는 것은 [목록·상세 배치 공통 스펙](./list-detail-pane.md)의 `선택이 없을 때의 추가`와 `추가 진입 수단`을 따른다.

사용자가 설정 항목을 선택하면 해당 설정 화면이 현재 상세가 되며, 다른 설정 항목을 선택했을 때의 교체는 [목록·상세 배치 공통 스펙](./list-detail-pane.md)의 `상세 선택과 교체`를 따른다. 이미 현재 상세인 설정 항목을 다시 선택하면 아무것도 바뀌지 않고, 그 화면에서 입력 중이던 내용도 그대로 남는다.

### 뒤로가기

뒤로가기의 결과는 [목록·상세 배치 공통 스펙](./list-detail-pane.md)의 `뒤로가기`를 따르며, 이 배치를 떠나면 설정 화면 전체를 떠나 `더보기` 화면으로 돌아간다. 설정 목록의 뒤로가기 동작을 사용하면 설정 목록이 단독으로 표시되는지 상세와 함께 표시되는지, 상세 선택 여부와 관계없이 이 배치를 떠난다.

세부 설정 화면이 단독으로 표시될 때 사용자가 뒤로가면 설정 목록으로 돌아간다. 설정 목록도 세부 화면이므로 공통 내비게이션은 계속 제공하지 않는다.

## domain

### 상세 선택

상세 영역은 선택 전 상태, 공휴일 설정 선택, 지도 설정 선택, Gemini 설정 선택, 브라우저 설정 선택, 플레이리스트 설정 선택, 파일 설정 선택 중 하나의 상태를 가진다. 브라우저 설정 선택, 플레이리스트 설정 선택과 파일 설정 선택은 [SettingHome 화면 스펙](./setting-home.md)이 각 항목을 제공하는 환경에서만 있다.

### 유지와 초기화 기준

사용자가 `더보기` 화면으로 돌아가는 것을 이 배치를 떠난 것으로 본다. 그 뒤 설정 화면에 다시 진입하거나 앱을 종료하고 다시 실행하면 [목록·상세 배치 공통 스펙](./list-detail-pane.md)의 `유지와 초기화 기준`에 따라 상세 선택은 선택 전 상태로, 표시 비율은 기본 상태로 초기화한다.
