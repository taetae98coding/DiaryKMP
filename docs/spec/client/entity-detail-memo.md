# 항목 상세 메모 탭 공통 스펙

이 문서는 메모가 연결할 수 있는 연락처, 장소, 웹 항목의 상세 화면에 있는 메모 탭이 공통으로 보장하는 행동을 다룬다. 사용자는 이 탭에서 상세 대상 항목에 연결된 메모를 확인하고 조작하며, 상세 대상 항목을 초기 선택으로 사용해 메모를 추가한다. 어느 화면에 탭이 있고 어떻게 진입하는지, 상세 대상이 어떤 항목인지, 메모 추가 화면의 어느 입력에 초기 선택이 놓이는지, 뒤로갈 때 어디로 돌아가는지는 각 탭 스펙이 다룬다.

이 문서를 따르는 탭 스펙은 다음과 같다.

- [ContactDetail 메모 탭 스펙](./contact-detail-memo.md)
- [PlaceDetail 메모 탭 스펙](./place-detail-memo.md)
- [WebDetail 메모 탭 스펙](./web-detail-memo.md)

태그로 메모를 찾아보는 [TagDetail 메모 탭 스펙](./tag-detail-memo.md)은 표시 범위와 완료된 메모 확인을 가지므로 이 문서를 따르지 않고 자기 규칙을 갖는다.

목록의 메모 표시·기간·날짜 그룹과 완료·삭제 규칙은 [MemoHome 목록 스펙](./memo-home.md)을, 메모 추가 행동은 [MemoAdd 화면 스펙](./memo-add.md)을, 메모 상세의 행동은 [MemoDetail 화면 스펙](./memo-detail.md)을 따른다. 메모와 항목 연결의 성질과 해제 상태는 [항목 연결 공통 스펙](../common/entity-link.md)을, 연결 종류마다 다른 규칙은 [메모 연락처 스펙](../common/memo-contact.md), [메모 장소 스펙](../common/memo-place.md), [메모 웹 스펙](../common/memo-web.md)을 따른다. 목록을 당겨 새로고침하는 행동과 동기화 진행 표시는 [새로고침 스펙](./sync-refresh.md)에서 다룬다.

디자인: [항목 상세 메모 탭 공통 디자인](../../design/entity-detail-memo.md)

## feature

### 진입

사용자는 상세 화면에서 메모 탭을 선택해 상세 대상 항목에 연결된 메모 목록을 확인한다. 탭을 선택하는 방법과 선택한 탭의 유지 기준은 각 상세 화면 스펙의 `탭 전환`과 `선택한 탭`을 따른다.

상세 대상 항목을 아직 조회하지 못했거나 조회에 실패해도 메모 탭의 목록과 동작은 그대로 제공한다.

### 메모 추가

사용자는 메모 탭에서 언제든 메모 추가를 시작할 수 있다. 상세 대상 항목의 삭제 여부와 조회 결과는 메모 추가 시작을 막지 않는다.

사용자가 메모 추가를 선택하면 MemoAdd 화면으로 이동한다. MemoAdd 화면은 창 너비와 관계없이 단독으로 표시하고, 그 화면에서는 주요 목적지의 공통 내비게이션을 제공하지 않는다. 상세 화면이 목록과 함께 배치되어 있어도 MemoAdd 화면은 그 배치에 참여하지 않는다.

메모 탭에서 진입한 메모 추가 화면은 상세 대상 항목을 최초 선택한 상태로 시작한다. 어느 입력에 선택되는지는 각 탭 스펙의 `메모 추가의 초기 선택`이 정한다. 사용자는 저장 전까지 그 선택을 해제하거나 다른 항목을 더 선택할 수 있다.

사용자가 메모 추가 화면에서 뒤로가면 메모 탭이 선택된 같은 항목의 상세 화면으로 돌아간다.

메모 추가는 메모 탭을 선택한 동안에만 제공한다. 다른 탭에서는 메모 추가를 실행할 수 없다.

### 목록 표시

목록에는 현재 사용자 계정과 연결된 메모 중 상세 대상 항목과 해제되지 않은 연결을 가지며 완료되지도 삭제되지도 않은 메모만 표시한다.

기간이 없는 메모는 날짜 그룹 없이 먼저 표시한다. 기간이 있는 메모는 시작 날짜별로 묶어 표시한다. 정렬과 날짜 그룹은 [MemoHome 목록 스펙](./memo-home.md)을 따른다.

아직 준비되지 않은 자리의 처리는 [페이지 조회 목록의 자리 표시 스펙](./paged-list-placeholder.md)을 따른다.

최초 조회나 추가 조회에 실패하면 이미 표시된 메모를 유지하며 별도 오류 안내나 재시도 동작은 제공하지 않는다. 최초 조회에 실패하면 [페이지 조회 목록의 자리 표시 스펙](./paged-list-placeholder.md)의 `빈 상태 판정`에 따라 목록이 준비된 것으로 보고 메모가 없는 목록으로 다루므로, 목록 자리에는 `빈 상태`의 안내가 표시된다.

다른 화면이나 다른 기기에서 메모를 추가·수정·완료·삭제하거나 연결을 바꾸면, 그 결과가 기기에 반영되는 대로 목록은 사용자가 아무것도 하지 않아도 바뀐 내용을 보여 준다. 메모 탭에 들어오는 것만으로는 서버에서 다시 가져오지 않는다.

### 빈 상태

상세 대상 항목에 연결된 메모가 하나도 없으면 목록 자리에 표시할 메모가 아직 없음을 알린다. 판정 시점, 빈 상태에서 할 수 있는 행동, 목록과의 전환은 [목록 빈 상태 스펙](./list-empty-state.md)을 따른다.

빈 상태에서도 사용자는 메모 추가를 그대로 실행할 수 있으며, 추가한 메모가 이 목록의 노출 기준을 만족하면 빈 상태가 사라지고 목록에 나타난다.

대상 항목을 조회하지 못해 화면 제목을 표시하지 못하는 것은 빈 상태 판정에 영향을 주지 않는다.

### 완료된 메모

메모 탭은 완료된 메모를 표시하지 않으며, 상세 대상 항목의 완료된 메모만 모아 보는 화면도 제공하지 않는다. 완료한 메모는 [MemoFinishedList 화면 스펙](./memo-finished-list.md)의 목록에서 다른 완료된 메모와 함께 확인한다.

### 메모 상세 확인

사용자가 메모를 선택하면 선택한 메모의 MemoDetail 화면으로 이동한다. MemoDetail 화면은 창 너비와 관계없이 단독으로 표시하고, 그 화면에서는 주요 목적지의 공통 내비게이션을 제공하지 않는다. 상세 화면이 목록과 함께 배치되어 있어도 MemoDetail 화면은 그 배치에 참여하지 않는다.

MemoDetail 화면에서 뒤로가면 메모 탭이 선택된 같은 항목의 상세 화면으로 돌아간다.

사용자가 MemoDetail 화면에서 메모를 완료하거나 삭제하거나 상세 대상 항목과의 연결을 해제한 뒤 돌아오면, 그 메모는 이 목록의 노출 기준에 따라 목록에서 사라진다.

### 완료·삭제와 실행 취소

사용자는 목록에서 메모를 완료하거나 삭제할 수 있다.

완료되거나 삭제된 메모는 목록에서 사라지고 해당 결과의 피드백과 실행 취소 동작을 제공한다.

사용자가 실행 취소하면 메모는 이전 상태로 돌아가 목록의 정렬 기준에 맞는 위치에 다시 나타난다.

### 새로고침

사용자는 목록을 아래로 당겨 새로고침할 수 있다. 새로고침의 결과와 진행 표시는 [새로고침 스펙](./sync-refresh.md)을 따른다.

### 오늘 갱신

화면이 다시 활성화될 때마다 사용자의 현재 시간대를 기준으로 오늘을 다시 정하고, 오늘에 해당하는 날짜 그룹 표시를 갱신한다.

### 정렬 선택

사용자는 목록 위에서 현재 정렬을 확인하고 다른 기준으로 바꿀 수 있다. 고를 수 있는 기준과 정렬 선택·반영·유지의 결과는 [목록 정렬 스펙](./list-sort.md)을 따른다.

## domain

### 상세 대상 항목과 연결

메모 탭의 상세 대상은 그 상세 화면의 상세 대상 항목과 같다. 어느 종류의 항목이며 어떤 기준으로 결정되는지는 각 탭 스펙의 `상세 대상`이 정한다.

목록에는 상세 대상 항목과 해제되지 않은 연결을 가진 메모만 포함한다. 연결과 해제의 성질은 [항목 연결 공통 스펙](../common/entity-link.md)을 따르고, 목록에 담을 연결의 종류는 각 탭 스펙이 정한다.

상세 대상 항목이 삭제되어도 기존 메모 연결은 유지되므로 메모 탭의 노출 기준은 바뀌지 않는다. 삭제 상태인 항목의 상세 화면에서도 연결된 메모를 확인할 수 있다.

상세 대상이 다른 항목으로 바뀌면 목록을 새 대상 항목의 메모로 바꾼다.

### 메모 추가의 초기값

메모 추가 시작은 상세 대상 항목의 상태와 무관하게 항상 허용한다.

대상 항목은 메모 추가 화면의 최초 선택일 뿐, 저장해야 하는 필수 관계가 아니다. 대상 항목을 선택한 것으로 표시할 수 있는지는 [MemoAdd 화면 스펙](./memo-add.md)의 각 선택과 메모 추가 성립 조건을 따르므로, 삭제된 대상 항목은 선택되지 않은 상태로 시작한다.

메모와 연락처·장소·웹 항목의 연결에는 대표가 없으므로 대상 항목을 대표로 지정하지 않는다. 태그 선택과 대표 태그, 그리고 대상 항목이 아닌 다른 종류의 선택은 MemoHome에서 진입할 때와 같이 비어 있는 상태로 시작한다.

최종 메모와 항목의 연결은 저장 시점에 사용자가 선택한 상태로 확정한다. 따라서 대상 항목을 해제하면 새 메모와 연결하지 않는다. 그 밖의 저장 규칙은 [MemoAdd 화면 스펙](./memo-add.md)을 따른다.

### 메모 노출과 정렬

상세 대상 항목과 연결된 메모 중 미완료·미삭제 메모만 노출한다.

정렬, 날짜 그룹과 오늘의 기준은 [MemoHome 목록 스펙](./memo-home.md)을 따른다.

위 순서는 사용자가 정렬을 고르지 않았을 때의 순서이며, 사용자가 고를 수 있는 다른 기준과 그 순서는 [목록 정렬 스펙](./list-sort.md)이 정한다.

### 완료·삭제·실행 취소

상태 전이와 수정 시각 갱신은 [MemoHome 목록 스펙](./memo-home.md)을 따른다.

완료, 삭제와 실행 취소는 메모와 항목의 연결을 바꾸지 않는다. 따라서 완료한 메모는 대상 항목과의 연결을 유지한 채 [MemoFinishedList 화면 스펙](./memo-finished-list.md)의 노출 기준을 만족하고, 그 화면에서 다시 시작하면 이 목록에 다시 나타난다.

메모 탭에서 실행하는 완료, 삭제와 실행 취소는 상세 대상 항목의 저장 내용과 삭제 여부를 바꾸지 않는다. 다른 탭에서 수정 중이던 입력 내용도 바꾸지 않는다.

## data

### 항목별 메모 조회

현재 사용자 계정과 연결된 메모 및 메모-항목 연결 중 상세 대상 항목과 해제되지 않은 연결을 가진 메모만 사용자가 목록을 내리는 만큼 나누어 불러온다. 이 조회는 상세 대상 항목 자체의 조회와 서로 독립이다.

메모의 완료 여부, 삭제 여부, 기간 또는 항목 연결 상태가 바뀌면 목록을 노출 기준과 정렬 기준에 따라 자동 갱신한다.

연결이 해제된 메모는 목록에서 사라지고, 연결이 복구되면 노출 기준을 만족할 때 정렬 기준에 맞는 위치에 다시 나타난다.

### 상태 변경의 저장

완료, 삭제와 실행 취소의 저장 흐름은 [MemoHome 목록 스펙](./memo-home.md)을 따른다.

메모 상태를 바꿔도 메모와 항목의 연결은 유지한다.

### 메모 추가 결과

메모 탭에서 시작한 메모 추가 화면은 `domain > 메모 추가의 초기값`에서 확정한 연결을 새 메모와 함께 저장한다.

추가된 메모가 상세 대상 항목과 연결되고 메모 탭의 노출 기준을 만족하면 현재 목록의 정렬 기준에 맞는 위치에 나타난다.
