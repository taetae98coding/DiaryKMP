# 앱 밖 브라우저 열기 스펙

이 문서는 화면이 정한 웹 주소를 기기가 웹 주소를 여는 방법으로 앱 밖에서 열 때, 열지 못한 경우의 공통 결과를 다룬다. 어떤 주소를 여는지, 열고 난 뒤 화면이 무엇을 유지하는지, 안내가 무엇을 열지 못했다고 알리는지는 각 화면의 스펙이 정한다. 사용자 데이터의 조회나 저장이 없어 `data` 영역은 생략한다.

## feature

### 열지 못했을 때

앱 밖에서 주소를 열지 못하면 화면은 그대로 유지하고, 열지 못했다는 안내를 짧게 표시한다. 그 주소를 받을 앱이 기기에 없는 경우도 열지 못한 것으로 본다. 화면을 떠나지 않으므로 사용자가 보고 있던 내용과 입력 중이던 내용은 그대로 남는다.

열지 못한 것을 실행 환경이 알려 주지 않으면(웹 등) 안내하지 않는다.
