# 페이지 조회 목록의 자리 표시 스펙

이 문서는 기기에 저장된 자료를 나누어 이어서 불러오는 목록에서, 아직 준비되지 않은 자리를 사용자에게 어떻게 제공하는지를 다룬다. 목록에 무엇을 노출하고 어떤 순서로 정렬하는지는 각 화면과 컴포넌트의 스펙이 다룬다.

디자인: [페이지 조회 목록의 자리 표시 디자인](../../design/paged-list-placeholder.md)

## feature

### 목록이 나타나는 순서

목록은 정렬 순서의 앞부분부터 나타나고, 사용자가 목록의 끝으로 이동하면 그다음 항목이 이어서 나타난다. 사용자는 목록을 계속 이동해 노출 기준을 만족하는 항목을 모두 확인할 수 있다.

### 자리 표시

아직 준비되지 않은 자리는 자리 표시 상태로 제공한다. 사용자는 자리 표시 상태의 자리를 선택할 수 없고, 그 자리에서 항목의 상태를 바꾸거나 선택 여부를 바꿀 수 없다.

준비를 기다리는 동안에도 이미 나타난 항목은 그대로 선택하고 조작할 수 있다.

내용이 준비되면 같은 자리에 항목이 나타난다.

### 준비 중 표시

목록을 준비하는 동안에는 별도의 진행 안내를 표시하지 않는다. 목록을 처음 열어 첫 결과가 오기 전에는 목록 자리가 잠깐 비어 있고 자리 표시도 나타나지 않는다. 첫 결과가 온 뒤 아직 준비되지 않은 자리는 `자리 표시`에 따라 자리 표시 상태로 나타난다.

이미 항목이 나타난 목록을 다시 준비하는 동안, 예를 들어 정렬이나 필터를 바꾸거나 목록의 내용이 바뀌어 다시 조회하는 동안에는 새 결과가 준비될 때까지 이전 항목을 그대로 보여 준다. 다시 준비하는 동안 목록이 비었다가 다시 채워지지 않는다.

목록을 당겨 새로고침할 때의 진행 표시는 [새로고침 스펙](./sync-refresh.md)을 따르며, 자리 표시와 함께 나타날 수 있다.

### 빈 상태 판정

빈 상태는 목록이 준비된 뒤에 판정한다. 준비하는 동안에는 항목이 하나도 나타나지 않아도 빈 상태를 표시하지 않는다.

목록의 첫 조회가 끝나면 준비된 것으로 본다. 첫 조회에 실패한 경우도 조회가 끝난 것으로 보며, 이때 목록은 항목이 없는 목록으로 다룬다. 이어서 조회하는 페이지가 남아 있는지는 판정에 영향을 주지 않는다. 첫 조회에서 항목이 하나도 없으면 뒤에 이어질 페이지도 없기 때문이다.

화면 본문을 차지하는 목록이 빈 상태에서 무엇을 표시하고 어떤 동작을 제공하는지는 [목록 빈 상태 스펙](./list-empty-state.md)을 따른다. 그 문서의 적용 대상이 아닌 목록은 각 화면과 컴포넌트의 스펙이 정한다.

## data

### 페이지 조회

목록은 기기에 저장된 자료에서 각 스펙의 노출 기준과 정렬 순서로 한 페이지씩 조회한다. 사용자가 목록의 끝에 다가가면 다음 페이지를 이어서 조회한다.

한 페이지는 20개 항목이다. 모든 적용 대상 목록이 같은 크기를 쓴다.

사용자가 목록을 얼마나 확인했는지는 조회 범위에만 영향을 주며, 항목의 노출 기준이나 정렬 순서를 바꾸지 않는다.

목록은 기기에 저장된 자료에서 조회하며, 조회할 때 서버에 따로 요청하지 않는다.

### 자동 갱신

저장된 항목이 추가되거나 노출 기준과 정렬에 영향을 주는 값이 바뀌면 조회 결과를 자동으로 갱신한다. 같은 기기의 다른 화면에서 항목을 추가하거나 고치거나 완료하거나 삭제하면, 사용자가 새로고침하지 않아도 목록에 바로 반영된다.

다른 기기에서 바뀐 내용은 동기화로 기기에 내려받아진 뒤에 같은 기준으로 반영된다. 언제 내려받는지는 [새로고침 스펙](./sync-refresh.md)과 [데이터 동기화 스펙](../common/data-sync.md)을 따른다.

자동 갱신은 사용자가 보던 자리를 옮기지 않는다. 보던 항목이 순서가 바뀌어 다른 자리로 옮겨 가더라도 목록은 그 항목을 따라가며, 필터나 정렬처럼 사용자가 조회 조건을 바꾼 경우에만 목록의 처음으로 돌아간다. 조회 조건을 바꿀 때 처음으로 돌아가는 기준은 [목록 정렬 스펙](./list-sort.md)의 `정렬 반영`과 [목록 필터 스펙](./list-filter.md)이 정한다.

### 보던 자리 유지

사용자가 목록에서 보던 자리는 화면이 회전해도, 앱이 백그라운드에 갔다가 같은 화면으로 돌아와도, 상세로 이동한 뒤 뒤로 돌아와도 유지한다. 앱을 다시 실행하면 목록은 처음부터 보인다.

앱이 백그라운드에 있는 동안 시스템이 앱을 정리했다가 다시 만들면, 목록은 떠나기 전에 내려가 있던 위치를 다시 보여 준다. 이때 정렬은 [목록 정렬 스펙](./list-sort.md)의 `정렬 선택 유지`에 따라 처음 정렬로 돌아가므로, 다시 보여 주는 위치는 처음 정렬로 놓인 목록에서 떠나기 전과 같은 위치다.
