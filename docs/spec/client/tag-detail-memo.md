# TagDetail 메모 탭 스펙

이 문서는 사용자가 TagDetail 화면의 메모 탭에서 표시 범위 안 태그에 연결된 메모를 확인하고 조작하며, 상세 대상 태그를 초기값으로 사용해 메모를 추가하는 행동을 다룬다. 화면 전체의 구성, 탭 전환과 유지, 화면 제목, 태그 디테일 탭의 행동과 세 목록 탭이 함께 쓰는 표시 범위와 공통 규칙(`목록 탭 공통`, `목록 탭의 대상과 추가의 초기값`, `탭별 조회`)은 [TagDetail 화면 스펙](./tag-detail.md)이 소유한다. 이 문서에는 메모 탭에만 있는 차이를 둔다.

목록의 메모 표시·기간·날짜 그룹과 완료·삭제 규칙은 [MemoHome 목록 스펙](./memo-home.md)을, 메모 추가 행동은 [MemoAdd 화면 스펙](./memo-add.md)을, 메모와 태그 연결의 의미는 [메모 태그 스펙](../common/memo-tag.md)을 따른다. 목록을 당겨 새로고침하는 행동과 동기화 진행 표시는 [새로고침 스펙](./sync-refresh.md)에서 다룬다. 이 태그의 완료된 메모를 모아 확인하는 화면은 [TagMemoFinishedList 화면 스펙](./tag-memo-finished-list.md)에서 다룬다.

디자인: [TagDetail 메모 탭 디자인](../../design/tag-detail-memo.md)

## feature

### 진입

사용자는 TagDetail 화면에서 메모 탭을 선택해 표시 범위 안 태그에 연결된 메모 목록을 확인한다. 탭을 선택하는 방법과 선택한 탭의 유지 기준은 [TagDetail 화면 스펙](./tag-detail.md)의 `탭 전환`과 `선택한 탭`을 따른다.

상세 대상 태그의 조회 결과와 관계없이 목록과 동작을 제공하는 기준은 [TagDetail 화면 스펙](./tag-detail.md)의 `목록 탭 공통`을 따른다.

### 메모 추가

사용자가 메모 추가를 선택하면 MemoAdd 화면으로 이동한다. 추가를 시작할 수 있는 조건, 화면의 표시와 돌아오기, 최초 선택은 [TagDetail 화면 스펙](./tag-detail.md)의 `목록 탭 공통`을 따른다. 메모 탭에서 진입한 메모 추가 화면은 상세 대상 태그를 대표 태그로도 지정한 상태로 시작하며, 사용자는 저장 전까지 대표 태그를 바꿀 수 있다.

### 목록 표시

목록에는 현재 사용자 계정과 연결된 메모 중 표시 범위 안 태그 하나 이상과 해제되지 않은 연결을 가지며 완료되지도 삭제되지도 않은 메모만 표시한다. 표시 범위가 무엇을 정하는지는 [TagDetail 화면 스펙](./tag-detail.md)의 `표시 범위`를 따른다.

여러 태그와 연결된 메모를 한 번만 보여 주는 기준과 표시 범위를 바꿨을 때의 결과는 [TagDetail 화면 스펙](./tag-detail.md)의 `목록 탭 공통`을 따른다.

기간이 없는 메모는 날짜 그룹 없이 먼저 표시한다. 기간이 있는 메모는 시작 날짜별로 묶어 표시한다. 정렬과 날짜 그룹은 [MemoHome 목록 스펙](./memo-home.md)을 따른다.

아직 준비되지 않은 자리의 처리는 [페이지 조회 목록의 자리 표시 스펙](./paged-list-placeholder.md)을 따른다.

조회에 실패했을 때의 목록은 [페이지 조회 목록의 자리 표시 스펙](./paged-list-placeholder.md)의 `조회 실패`를 따르며, 별도 재시도 동작은 제공하지 않는다.

### 빈 상태

`목록 표시`의 노출 기준을 만족하는 메모가 하나도 없을 때의 빈 상태는 [TagDetail 화면 스펙](./tag-detail.md)의 `목록 탭 공통`을 따르며, 이 태그에 연결된 메모가 아직 없음을 알린다. 불러오는 중에는 빈 상태를 표시하지 않는다. 판정 시점, 빈 상태에서 할 수 있는 행동, 목록과의 전환은 [목록 빈 상태 스펙](./list-empty-state.md)을 따른다.

빈 상태에서도 사용자는 메모 추가와 완료된 메모 확인을 그대로 실행할 수 있으며, 추가한 메모가 이 목록의 노출 기준을 만족하면 빈 상태가 사라지고 목록에 나타난다.

### 완료된 메모 확인

사용자는 메모 탭에서 완료된 메모 확인을 선택해 같은 태그의 TagMemoFinishedList 화면으로 이동한다.

이 태그에 완료된 메모가 하나도 없어도 이 동작은 제공된다. 목록이 비어 있는지, 대상 태그를 조회했는지, 지금 표시 범위가 무엇인지는 이 동작을 막지 않는다.

이동한 화면에는 표시 범위를 적용하지 않는다. 표시 범위를 넓혀 두었어도 그 화면은 상세 대상 태그에 연결된 완료된 메모만 표시한다.

완료된 메모 확인은 메모 탭을 선택한 동안에만 제공한다. 다른 탭에서는 실행할 수 없다.

이동한 화면의 내용과 행동은 [TagMemoFinishedList 화면 스펙](./tag-memo-finished-list.md)을 따른다. 사용자가 그 화면에서 뒤로 가면 메모 탭이 선택된 같은 태그의 TagDetail 화면으로 돌아온다.

### 메모 상세 확인

사용자가 메모를 선택하면 선택한 메모의 MemoDetail 화면으로 이동한다. 화면의 표시, 돌아오기와 돌아온 뒤의 목록은 [TagDetail 화면 스펙](./tag-detail.md)의 `목록 탭 공통`을 따르며, MemoDetail 화면에서 메모를 완료한 뒤 돌아와도 그 메모는 이 목록의 노출 기준에 따라 목록에서 사라진다.

### 완료·삭제와 실행 취소

사용자는 목록에서 메모를 완료하거나 삭제할 수 있다.

완료되거나 삭제된 메모는 목록에서 사라지고 해당 결과의 피드백과 실행 취소 동작을 제공한다. 완료한 메모는 [TagMemoFinishedList 화면 스펙](./tag-memo-finished-list.md)의 노출 기준을 만족해 그 화면의 목록에 나타난다.

사용자가 실행 취소하면 메모는 이전 상태로 돌아가 목록의 정렬 기준에 맞는 위치에 다시 나타난다.

안내를 표시하는 곳과 안내가 닫히는 결과는 [TagDetail 화면 스펙](./tag-detail.md)의 `목록 탭 공통`을 따른다.

### 새로고침

사용자는 메모 목록을 당겨 새로고침할 수 있으며, 목록이 비어 있을 때도 당길 수 있다. 새로고침 대상과 진행 표시, 새로고침 중에 다시 당겼을 때의 결과는 [새로고침 스펙](./sync-refresh.md)을 따른다.

다른 화면이나 다른 기기에서 바뀐 메모와 연결이 이 기기에 반영되면 사용자가 당기지 않아도 목록에 바로 나타나거나 사라진다.

### 오늘 갱신

화면이 다시 활성화될 때마다 사용자의 현재 시간대를 기준으로 오늘을 다시 정하고, 오늘에 해당하는 날짜 그룹 표시를 갱신한다.

### 정렬 선택

사용자는 목록 위에서 현재 정렬을 확인하고 다른 기준으로 바꿀 수 있다. 고를 수 있는 기준과 정렬 선택·반영·유지의 결과는 [목록 정렬 스펙](./list-sort.md)을 따른다.

## domain

### 상세 대상 태그와 연결

메모 탭의 상세 대상 태그와 목록에 담을 연결은 [TagDetail 화면 스펙](./tag-detail.md)의 `목록 탭의 대상과 추가의 초기값`을 따르며, 목록에 담는 연결은 메모와 태그의 연결이다.

### 메모 추가의 초기값

메모 추가의 초기값은 [TagDetail 화면 스펙](./tag-detail.md)의 `목록 탭의 대상과 추가의 초기값`을 따른다. 완료되었거나 삭제된 대상 태그는 태그 입력에서 선택한 것으로 보이지 않지만 선택은 남아, 추가할 때 그대로 연결되고 대표 태그로도 지정된다.

대상 태그는 메모 추가 화면의 최초 대표 태그일 뿐 고정된 대표 태그가 아니다. 대표 태그도 저장 시점에 사용자가 선택한 상태로 확정하므로, 다른 태그를 대표 태그로 선택하면 대상 태그를 대표 태그로 저장하지 않는다. 그 밖의 저장 규칙은 [MemoAdd 화면 스펙](./memo-add.md)을 따른다.

### 메모 노출과 정렬

표시 범위 안 태그와 연결된 메모 중 미완료·미삭제 메모만 노출한다. 표시 범위는 담을 태그만 정하고 이 노출 기준을 대체하지 않는다.

정렬, 날짜 그룹과 오늘의 기준은 [MemoHome 목록 스펙](./memo-home.md)을 따른다.

위 순서는 사용자가 정렬을 고르지 않았을 때의 순서이며, 사용자가 고를 수 있는 다른 기준과 그 순서는 [목록 정렬 스펙](./list-sort.md)이 정한다.

### 완료·삭제·실행 취소

상태 전이와 수정 시각 갱신은 [MemoHome 목록 스펙](./memo-home.md)을 따른다.

완료, 삭제와 실행 취소는 메모와 태그의 연결을 바꾸지 않는다. 따라서 완료한 메모는 대상 태그와의 연결을 유지한 채 [TagMemoFinishedList 화면 스펙](./tag-memo-finished-list.md)의 노출 기준을 만족하고, 그 화면에서 다시 시작하면 이 목록에 다시 나타난다.

메모 탭에서 실행하는 완료, 삭제와 실행 취소가 대상 태그와 태그 디테일 탭에 주는 영향은 [TagDetail 화면 스펙](./tag-detail.md)의 `목록 탭의 대상과 추가의 초기값`을 따른다.

## data

### 태그별 메모 조회

메모와 메모-태그 연결은 사용자가 목록을 내리는 만큼 나누어 불러온다. 조회 대상, 자동 갱신과 다른 탭 조회의 관계는 [TagDetail 화면 스펙](./tag-detail.md)의 `탭별 조회`를 따르며, 메모의 기간이 바뀐 것도 갱신 계기다. 바뀐 메모가 놓이는 자리는 [목록 정렬 스펙](./list-sort.md)의 `정렬 반영`을 따른다.

### 상태 변경의 저장

완료, 삭제와 실행 취소의 저장 흐름은 [MemoHome 목록 스펙](./memo-home.md)을 따른다.

메모 상태를 바꿔도 메모와 태그의 연결은 유지한다.

### 메모 추가 결과

메모 추가 결과의 저장과 표시는 [TagDetail 화면 스펙](./tag-detail.md)의 `탭별 조회`를 따르며, 메모 탭에서 시작한 메모 추가 화면은 `domain > 메모 추가의 초기값`에서 확정한 대표 태그도 새 메모와 함께 저장한다.
