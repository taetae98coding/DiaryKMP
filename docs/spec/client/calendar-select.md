# Calendar 날짜 선택 스펙

이 문서는 캘린더의 주 목록에서 하나 이상의 연속 날짜를 선택하는 행동과 정책을 다룬다. 선택 영역은 배치하는 화면이 지정한 연속한 주 목록이며, 한 달의 주를 모두 보여 주는 달 화면과 일부 기간의 주만 보여 주는 목록에 같은 규칙을 적용한다.

선택을 어느 화면에서 사용할지, 선택 영역에 어떤 주를 담을지와 선택 완료 후의 다음 행동은 배치하는 화면의 스펙에서 다룬다. 선택은 화면 안에서만 유지되는 일시적 상호작용으로 사용자 데이터의 생성이나 저장이 없어 `data` 영역은 생략한다.

디자인: [Calendar 날짜 선택 디자인](../../design/calendar-select.md)

## feature

### 선택 시작

사용자가 선택 영역에 표시된 날짜 하나에서 선택을 시작하면 해당 날짜 하루가 선택된다.

### 기간 확장

사용자는 선택을 완료하기 전에 현재 가리키는 날짜를 바꿔 선택 기간을 늘리거나 줄일 수 있다.

현재 가리키는 날짜가 처음 선택한 날짜보다 이후이면 처음 선택한 날짜부터 현재 날짜까지가 선택된다. 현재 날짜가 처음 선택한 날짜보다 이전이면 현재 날짜부터 처음 선택한 날짜까지가 선택된다.

현재 가리키는 날짜가 바뀌면 선택된 기간도 즉시 갱신된다. 선택 기간은 주 경계를 넘어 여러 주에 걸칠 수 있다.

### 선택 피드백

기기와 시스템 설정에서 촉각 피드백을 제공하는 경우, 사용자가 날짜 선택을 시작하면 시작 시점에 한 번 촉각 피드백을 받는다.

선택이 시작된 뒤 드래그하는 동안 선택 기간이 다른 범위로 갱신될 때마다 추가 촉각 피드백을 한 번 받는다. 선택 기간이 그대로이면 추가 촉각 피드백을 받지 않는다.

### 선택 표시

선택이 진행되는 동안 사용자는 현재 선택된 기간을 선택 영역에서 확인할 수 있다. 구체적인 표현은 [Calendar 날짜 선택 디자인](../../design/calendar-select.md)의 선택 표시를 따른다.

### 선택 중 달 이동

한 달의 주를 모두 보여 주며 달을 넘겨 보는 화면에서, 사용자는 선택을 유지한 채 선택 영역의 좌우 가장자리 영역으로 현재 가리키는 위치를 옮겨 이전 달이나 다음 달로 이동할 수 있다. 가장자리 영역에 머무는 동안 달 이동은 반복된다.

달이 이동해도 선택은 중단되지 않는다. 처음 선택한 날짜는 그대로 유지되고, 이동한 달에서 가리키는 날짜를 기준으로 선택 기간이 갱신된다.

### 선택 완료

사용자가 선택을 완료하면 그 시점에 선택된 기간이 배치하는 화면에 전달된다. 기간을 확장하지 않고 완료하면 하루짜리 기간이 전달된다.

선택 완료 후의 다음 행동은 배치하는 화면이 정한다.

### 선택 중단

사용자가 선택을 완료하기 전에 시스템이 선택 조작을 중단하면, 그 시점에 선택된 기간으로 선택이 완료된다. 앱이 백그라운드로 이동하거나 다른 화면이 위에 나타나 조작이 끊기는 경우가 여기에 해당한다. 완료된 기간은 사용자가 선택을 완료했을 때와 같이 배치하는 화면에 한 번 전달되며, 그 뒤의 행동도 배치하는 화면이 정한다.

화면이 회전하거나 시스템에 의해 재생성되어 조작이 끊기는 경우는 선택 중단에 해당하지 않고, `domain > 유지 경계`에 따라 선택이 취소된다.

배치하는 화면은 진행 중인 선택을 언제든 해제할 수 있으며, 해제되면 선택된 기간이 없는 상태가 된다.

## domain

### 선택 기간

선택 기간은 시작일과 종료일을 가지는 연속한 날짜 범위다. 시작일은 종료일보다 늦지 않고, 하루만 선택하면 시작일과 종료일이 같다.

### 선택 가능한 날짜

선택 영역에 보이는 모든 날짜 칸을 선택할 수 있다. 이웃 달에 속한 날짜 칸도 실제 날짜 그대로 선택된다.

선택 영역을 벗어난 위치는 선택 영역 안에서 가장 가까운 날짜 칸을 가리키는 것으로 본다. 따라서 선택 기간은 선택 영역에 보이는 주의 범위를 넘지 않는다.

### 선택 중 달 이동 기준

선택 영역의 주가 고정된 화면에서는 선택이 진행되는 동안 화면이 이동하지 않는다.

달을 넘겨 보는 화면에서 달 이동은 좌우 가장자리 영역에 머무는 경우에만 일어난다. 가장자리 영역 밖에서는 선택을 위한 드래그로 달이 이동하지 않는다.

왼쪽 가장자리 영역은 이전 달로, 오른쪽 가장자리 영역은 다음 달로 이동한다. 이동할 수 있는 달의 범위는 [Calendar 컴포넌트 스펙](./calendar.md)의 이동 범위를 따르며, 범위를 벗어나는 방향으로는 이동하지 않으며, 선택은 중단되지 않고 현재 달에서 가리키는 날짜를 기준으로 갱신된다.

가장자리 영역의 크기와 반복 이동 시점은 [Calendar 날짜 선택 디자인](../../design/calendar-select.md)의 선택 중 달 이동을 따른다.

### 선택 사용 여부

날짜 선택은 배치하는 화면이 사용할 때만 동작한다. 사용하지 않는 화면에서는 날짜 선택이 시작되지 않는다.

### 유지 경계

선택은 진행 중인 상호작용으로, 화면이 재생성되거나 화면을 벗어나거나 앱이 백그라운드로 이동하면 유지되지 않는다. 앱을 다시 실행해도 이전 선택을 복원하지 않는다.

선택하는 도중에 화면을 벗어나거나 앱이 백그라운드로 이동해 조작이 끊기면 `선택 중단`에 따라 그 시점의 기간으로 선택이 완료되어 배치하는 화면에 전달된다.

선택하는 도중에 화면이 재생성되면 진행 중이던 선택은 취소되고, 선택 완료는 배치하는 화면에 전달되지 않는다. 재생성된 화면에는 선택된 기간이 없다.
