# 연락처 태그 앱 스펙

이 문서는 연락처와 태그의 연결 가운데 이 연결이 앱의 목록에 주는 영향을 다룬다. 연락처와 태그의 연결이 공통으로 지키는 규칙은 [연락처 태그 스펙](../common/contact-tag.md)을, 태그 연결이 공통으로 지키는 규칙은 [항목 태그 연결 공통 스펙](../common/entity-tag.md)을, 앱이 기기에 저장된 연결로 대상 항목의 태그와 태그의 대상 항목을 조회하는 규칙은 [항목 태그 연결 앱 스펙](./entity-tag.md)을 따른다.

사용자가 태그를 고르고 해제하는 조작과 조회 결과를 보여 주는 화면은 각 입력 컴포넌트 스펙과 화면 스펙이 소유하므로 이 문서에는 `feature` 영역을 두지 않는다.

## domain

### 연결의 의미

[항목 태그 연결 공통 스펙](../common/entity-tag.md)의 `연결의 의미`는 연락처에서 다음 목록에 적용된다.

- [ContactHome 화면 스펙](./contact-home.md)의 목록 노출 기준과 정렬. 유무 필터의 축에도 태그 연결은 쓰이지 않는다.
- [캘린더 연락처 생일 표시 스펙](./calendar-contact-birthday.md)의 노출 기준. [CalendarHome 스펙](./calendar-home.md)에서 사용자가 고른 태그 필터도 생일 표시에는 적용하지 않는다.
- 메모와 연락처의 연결. 자세한 기준은 [메모 연락처 앱 스펙](./memo-contact.md)을 따른다.

연락처는 [SearchHome 화면 스펙](./search-home.md)의 검색 대상이 아니므로 태그 연결이 검색 결과에 주는 영향도 없다.

태그로 연락처를 조회하는 [TagDetail 연락처 탭 스펙](./tag-detail-contact.md)의 목록은 이 연결을 노출 기준으로 쓴다.
