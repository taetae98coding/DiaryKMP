# 제목 입력 스펙

이 문서는 사용자가 항목의 제목을 한 줄로 입력하는 제목 입력의 사용자 관점 동작과 정책을 다룬다. 이 입력을 어느 화면에 두는지, 진입할 때 입력 초점을 제목에 두는지, 제목이 비어 있을 때 추가나 수정을 막는지, 입력한 제목을 언제 저장하는지는 이 문서의 범위가 아니며 제목 입력을 쓰는 화면 스펙에서 다룬다. 제목 입력 자체는 사용자 데이터를 저장하지 않으므로 `data` 영역은 생략한다.

## feature

### 제목 입력

사용자는 제목을 한 줄로 입력하고 수정할 수 있다. 엔터를 눌러도 줄이 나뉘지 않는다. 입력한 제목이 입력 칸의 폭보다 길어도 입력 칸이 여러 줄로 늘어나지 않고, 사용자는 입력 칸 안에서 제목을 가로로 옮겨 가며 확인한다.

입력 칸은 제목을 입력하는 자리임을 알리는 이름을 늘 함께 보여 준다. 값이 필요한 화면이어도 입력 칸에 필수임을 알리는 표시는 두지 않는다. 제목이 필요한지와 비어 있을 때의 안내는 각 화면 스펙이 정한다.

### 제목 지우기

입력한 제목이 있으면 사용자는 입력한 제목 전체를 한 번에 지울 수 있다. 지운 뒤에도 입력 초점은 제목 입력에 남아 사용자가 곧바로 새 제목을 입력할 수 있다. 제목이 비어 있으면 지우는 동작은 제공하지 않는다.

지우는 것은 입력 칸의 제목을 비우는 것일 뿐이며, 이미 저장된 제목을 바로 지우지 않는다. 비운 제목이 언제 반영되는지는 각 화면 스펙의 저장 시점을 따른다.

### 다음 입력으로 초점 옮기기

제목 입력 바로 뒤에 [설명 입력](./description-input.md)이 있는 화면에서, 사용자는 제목 입력에서 키보드로 다음 입력으로 초점을 옮길 수 있다. 초점이 어디로 옮겨 가는지는 `domain > 제목 다음 초점`이 정한다.

## domain

### 제목 다음 초점

제목 입력 바로 뒤에 설명 입력이 있을 때 제목 입력에서 다음 입력으로 옮겨 가는 초점은 설명 입력이 보여 주는 상태에 따라 정한다. 제목을 쓴 뒤 곧바로 설명을 이어 쓰는 흐름을 우선하되, 설명을 입력할 수 없는 상태에서는 화면에 놓인 순서를 그대로 따른다.

| 설명 입력이 보여 주는 상태 | 다음 초점 |
| --- | --- |
| 설명 입력 | 제목 지우기를 건너뛰고 설명 입력 |
| 마크다운 미리보기 | 화면에 놓인 순서의 다음. 제목 지우기가 제공되면 제목 지우기 |

제목 입력 바로 뒤에 설명 입력이 없는 화면에서는 화면에 놓인 순서를 따른다.

### 처음 입력 초점

화면 스펙이 진입할 때 입력 초점을 제목에 두도록 정했으면, 화면이 사용자에게 보이게 된 뒤 한 번만 초점을 둔다. 화면이 회전하거나 창 크기가 바뀌어도 초점을 다시 옮기지 않으므로, 사용자가 그사이 다른 입력으로 옮겨 둔 초점이 제목으로 되돌아가지 않는다.

### 진행 상태 유지

화면이 회전하거나 창 크기가 바뀌어도 입력 중이던 제목은 유지된다. 시스템이 앱을 메모리에서 정리한 뒤 화면을 복원할 때 입력 중이던 제목을 복원하는지는 각 화면 스펙을 따른다.
