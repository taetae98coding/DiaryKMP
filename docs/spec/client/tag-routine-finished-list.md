# TagRoutineFinishedList 화면 스펙

이 문서는 사용자가 TagDetail 화면의 루틴 탭에서 그 태그의 완료된 루틴을 모아 확인하는 TagRoutineFinishedList 화면 가운데 [RoutineFinishedList 화면](./routine-finished-list.md)과 다른 부분만 다룬다. 진입과 이동, 내용 갱신, 새로고침, 불러오기 실패, 빈 상태, 추가 미제공, 상세 확인, 다시 시작과 삭제, 노출 기준과 실행 경계의 공통 규칙은 [완료 목록 공통 스펙](./finished-list.md)을 따르며, 이 화면의 상세 대상 항목은 태그이고 짝이 되는 목록은 같은 태그의 [TagDetail 루틴 탭](./tag-detail-routine.md)이다.

루틴 카드의 내용, 빠른 기록·보기 전환·정렬 선택 미제공, 순서와 오늘, 다시 시작과 삭제의 상태 전이와 저장은 [RoutineFinishedList 화면 스펙](./routine-finished-list.md)을 따른다. 루틴과 태그 연결의 성질은 [항목 연결 공통 스펙](../common/entity-link.md)과 [루틴 태그 스펙](../common/routine-tag.md)을, 상세 확인은 [RoutineDetail 화면 스펙](./routine-detail.md)을 따른다. 목록과 루틴 상세를 함께 사용할 때의 선택 상태와 뒤로가기는 [TagRoutineFinishedList 목록·상세 배치 스펙](./tag-routine-finished-list-detail.md)에서 다룬다.

이 문서에서 `상세 대상 항목`은 진입한 TagDetail 화면이 보여 주는 태그를 가리킨다. [완료 목록 공통 스펙](./finished-list.md)의 `대상 항목`은 이 목록이 모으는 루틴을 가리킨다.

계정의 완료된 루틴 전체를 확인하는 화면은 [RoutineFinishedList 화면 스펙](./routine-finished-list.md)에서 다룬다.

디자인: [TagRoutineFinishedList 화면 디자인](../../design/tag-routine-finished-list.md)

## feature

### 진입과 이동

사용자는 TagDetail 화면의 루틴 탭에서 완료된 루틴 확인을 선택해 같은 태그의 TagRoutineFinishedList 화면으로 이동한다. 대상 태그의 완료 여부, 삭제 여부와 조회 결과는 이동을 막지 않는다. 그 기준은 [TagDetail 루틴 탭 스펙](./tag-detail-routine.md)의 `완료된 루틴 확인`을 따른다.

완료된 루틴 목록만 사용하는 동안 사용자가 뒤로가면 루틴 탭이 선택된 같은 태그의 TagDetail 화면으로 돌아간다. TagDetail 화면이 태그 목록과 함께 표시되던 배치에서 이동했으면 그 배치로 돌아가고, 상세 영역에는 루틴 탭이 선택된 같은 태그의 상세가 남아 있다.

### 화면 제목

화면 제목에는 대상 태그의 최신 저장 이모지와 제목을 표시하고, 완료된 루틴을 모아 보여 주는 목록임을 함께 알린다. 이모지 표시 규칙, 화면이 열려 있는 동안의 갱신, 대상 태그를 아직 조회하지 못했거나 조회할 수 없는 동안의 화면 제목과 한 줄 표시는 [TagMemoFinishedList 화면 스펙](./tag-memo-finished-list.md)의 `화면 제목`과 같으며, 그 절의 완료된 메모는 이 화면에서 완료된 루틴으로 읽는다.

### 목록 표시

카드의 내용과 카드 문구는 [RoutineFinishedList 화면 스펙](./routine-finished-list.md)의 `목록 표시`를 따른다.

### 빈 상태 문구

대상 태그에 연결된 완료된 루틴이 하나도 없으면 목록 자리에 이 태그에서 완료한 루틴이 아직 없음을 알린다.

대상 태그를 조회하지 못해 이모지와 제목을 표시하지 못하는 것은 빈 상태 판정에 영향을 주지 않는다.

### 루틴 상세 확인

사용자가 상세 화면에서 대상 태그와의 연결을 해제한 뒤 돌아온 루틴도 이 목록의 노출 기준에 따라 목록에서 사라진다.

### 다시 시작과 삭제

목록에서 루틴을 다시 시작하거나 삭제한 결과와 안내, 실행 취소는 [완료 목록 공통 스펙](./finished-list.md)의 `다시 시작과 삭제`를 따르고, 바뀌는 상태는 `domain > 다시 시작·삭제·실행 취소`가 정한다.

## domain

### 상세 대상 태그

이 화면의 대상 태그는 진입한 TagDetail 화면의 상세 대상과 같은 태그이며, 대상이 결정되는 기준은 [TagDetail 루틴 탭 스펙](./tag-detail-routine.md)의 `상세 대상 태그와 연결`을 따른다.

대상 태그를 조회할 수 없거나 조회에 실패하면 이모지와 제목을 표시하지 않고, 그 밖의 화면 행동은 바뀌지 않는다.

대상 태그가 완료되거나 삭제되어도 기존 루틴 연결은 유지되므로 이미 열린 완료된 루틴 목록의 노출 기준은 바뀌지 않는다.

### 태그 연결과 노출 기준

[완료 목록 공통 스펙](./finished-list.md)의 `노출 기준`에 대상 태그와 해제되지 않은 연결을 가진 루틴이라는 조건을 더한다. 연결을 판정하는 규칙과 담을 연결의 종류는 짝이 되는 루틴 탭 스펙과 같다.

짝이 되는 루틴 탭과 달리 TagDetail 화면의 표시 범위는 이 목록에 적용하지 않는다. 그 기준은 [TagDetail 루틴 탭 스펙](./tag-detail-routine.md)의 `완료된 루틴 확인`을 따른다.

RoutineHome의 태그 필터 선택은 이 목록에 적용하지 않는다.

### 다시 시작·삭제·실행 취소

상태 전이와 수정 시각 갱신은 [RoutineFinishedList 화면 스펙](./routine-finished-list.md)의 `다시 시작과 삭제의 상태 전이`를 따른다.

다시 시작, 삭제와 실행 취소는 루틴과 태그의 연결을 바꾸지 않는다. 대상 태그의 저장 내용과 완료 여부, 삭제 여부도 바꾸지 않는다.

다시 시작한 루틴은 대상 태그와의 연결을 그대로 유지하므로 짝이 되는 루틴 탭의 노출 기준을 만족해 그 탭의 목록에 나타난다. 삭제한 루틴은 두 목록 모두에 나타나지 않는다.

### 실행 경계

루틴 상세 선택의 유지와 초기화는 [TagRoutineFinishedList 목록·상세 배치 스펙](./tag-routine-finished-list-detail.md)의 `유지와 초기화 기준`을 따른다.

## data

### 태그별 완료 루틴 조회

조회 흐름은 [완료 목록 공통 스펙](./finished-list.md)의 `목록 조회`를 따르며, 현재 사용자 계정과 연결된 루틴 및 루틴-태그 연결 중 `태그 연결과 노출 기준`을 만족하는 항목만 조회한다. 이 조회는 대상 태그 자체의 조회와 서로 독립이다.

루틴의 제목이나 시작 날짜, 태그 연결 상태가 바뀔 때도 목록을 노출 기준과 순서 기준에 따라 자동 갱신한다.

연결이 해제된 루틴은 목록에서 사라지고, 연결이 복구되면 노출 기준을 만족할 때 순서 기준에 맞는 위치에 다시 나타난다.

### 상태 변경의 저장

다시 시작, 삭제와 실행 취소의 저장 흐름은 [RoutineFinishedList 화면 스펙](./routine-finished-list.md)의 `상태 변경의 저장`을 따른다.

루틴 상태를 바꿔도 루틴과 태그의 연결은 유지한다.
