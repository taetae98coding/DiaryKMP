# 메모 연락처 입력 컴포넌트 스펙

이 문서는 MemoAdd 화면과 MemoDetail 화면에서 함께 사용하는 연락처 입력의 사용자 행동과 정책을 다룬다. 두 화면에서 연락처 입력은 같은 행동과 선택 규칙을 제공하며, 구체적인 구성과 조작 수단은 [메모 연락처 입력 컴포넌트 디자인](../../design/memo-contact-input.md)에서 다룬다.

연락처 입력은 [메모 항목 선택 입력 공통 스펙](./memo-entity-input.md)을 따른다. 그 문서의 `대상 항목`은 연락처, `항목 입력`은 연락처 입력, `선택 목록`은 연락처 선택 목록, `추가 화면`은 [ContactAdd 화면](./contact-add.md), `상세 화면`은 [ContactDetail 화면](./contact-detail.md)이다. 이 문서에는 연락처 입력에서만 정하는 값과 기준을 둔다.

메모와 연락처의 연결 규칙은 [메모 연락처 스펙](../common/memo-contact.md)을, 연락처가 갖는 정보는 [ContactAdd 화면 스펙](./contact-add.md)의 `연락처의 정보`를, 선택 대상이 되는 연락처의 노출 기준은 [ContactHome 화면 스펙](./contact-home.md)을 따른다.

디자인: [메모 연락처 입력 컴포넌트 디자인](../../design/memo-contact-input.md)

## feature

### 선택 상태 표시

선택한 연락처와 연락처 선택 목록의 연락처는 이름으로 구분해 표시하고, 이름이 다른 경로로 바뀌면 바뀐 이름이 표시된다. 나머지 기준은 [메모 항목 선택 입력 공통 스펙](./memo-entity-input.md)의 `선택 상태 표시`를 따른다.

### 연락처 상세 이동

연락처 입력에 표시된 연락처를 누르면 그 연락처의 ContactDetail 화면으로 이동한다. 이동과 돌아왔을 때의 기준은 [메모 항목 선택 입력 공통 스펙](./memo-entity-input.md)의 `항목 상세 이동`을 따른다.

### 연락처 선택 목록

연락처 선택 목록의 행동은 [메모 항목 선택 입력 공통 스펙](./memo-entity-input.md)의 `선택 목록`을 따른다.

### 연락처 검색

연락처 선택 목록의 검색은 [메모 항목 선택 입력 공통 스펙](./memo-entity-input.md)의 `항목 검색`을 따르며, 판정 대상 값은 `domain`의 `연락처 검색어`를 따른다.

### 연락처 추가 이동

연락처 입력이나 연락처 선택 목록에서 ContactAdd 화면으로 이동하는 기준과 돌아왔을 때 추가한 연락처가 선택되는 기준은 [메모 항목 선택 입력 공통 스펙](./memo-entity-input.md)의 `항목 추가 이동`과 `추가한 항목의 자동 선택`을 따른다.

### 연락처 선택과 해제

연락처의 선택과 해제는 [메모 항목 선택 입력 공통 스펙](./memo-entity-input.md)의 `항목 선택과 해제`를 따른다.

## domain

### 선택할 수 있는 연락처

선택할 수 있는 연락처의 기준은 [메모 항목 선택 입력 공통 스펙](./memo-entity-input.md)의 `선택할 수 있는 항목`을 따르며, 연락처는 이름 오름차순으로 정렬한다. 이름이 같은 연락처끼리의 순서는 정하지 않는다.

연락처의 즐겨찾기 여부는 이 정렬에 영향을 주지 않는다. [ContactHome 화면 스펙](./contact-home.md)의 `목록 정렬`이 즐겨찾기를 앞세우는 것은 그 목록의 규칙이며, 같은 문서의 정렬 선택도 연락처 입력에 적용하지 않는다.

### 연락처 선택 목록에 나타나는 연락처

연락처 선택 목록에 나타나는 연락처는 [메모 항목 선택 입력 공통 스펙](./memo-entity-input.md)의 `선택 목록에 나타나는 항목`을 따른다.

### 연락처 검색어

검색어 판정의 기준은 [메모 항목 선택 입력 공통 스펙](./memo-entity-input.md)의 `항목 검색어`를 따른다. 연락처의 판정 대상 값은 [검색어 일치 판정 스펙](./search-match.md)이 정한 대로 이름과 설명이다.

### 추가한 연락처의 자동 선택

ContactAdd 화면에서 추가한 연락처의 자동 선택은 [메모 항목 선택 입력 공통 스펙](./memo-entity-input.md)의 `추가한 항목의 자동 선택`을 따른다.

### 선택한 것으로 표시하는 연락처

연락처 입력과 연락처 선택 목록에 선택한 것으로 표시하는 연락처는 [메모 항목 선택 입력 공통 스펙](./memo-entity-input.md)의 `선택한 것으로 표시하는 항목`을 따른다.

### 진행 상태 유지

화면 구성 변경, 메모리 정리 뒤 복원, 상세 대상 메모의 변경에서 연락처 입력이 유지하는 상태는 [메모 항목 선택 입력 공통 스펙](./memo-entity-input.md)의 `진행 상태 유지`를 따른다.

## data

### 연락처 목록 조회

연락처 선택 목록과 선택 상태의 조회는 [메모 항목 선택 입력 공통 스펙](./memo-entity-input.md)의 `항목 목록 조회`를 따른다. MemoDetail 화면의 선택 상태는 [MemoDetail 화면 스펙](./memo-detail.md)의 `연락처 입력의 조회`를 따른다.

### 내용 갱신

연락처가 추가되거나 저장된 연락처의 이름·전화번호·상태가 바뀌면 연락처 입력과 열려 있는 연락처 선택 목록에 바로 반영된다. 반영 기준과 새로고침이 없다는 점은 [메모 항목 선택 입력 공통 스펙](./memo-entity-input.md)의 `내용 갱신`을 따른다.
