# 장소 태그 앱 스펙

이 문서는 장소와 태그의 연결 가운데 이 연결이 앱의 목록과 검색 결과에 주는 영향과, 앱이 장소를 표시할 때 쓰는 컬러를 다룬다. 장소와 태그의 연결이 공통으로 지키는 규칙은 [장소 태그 스펙](../common/place-tag.md)을, 태그 연결이 공통으로 지키는 규칙은 [항목 태그 연결 공통 스펙](../common/entity-tag.md)을, 앱이 기기에 저장된 연결로 대상 항목의 태그와 태그의 대상 항목을 조회하는 규칙은 [항목 태그 연결 앱 스펙](./entity-tag.md)을 따른다.

사용자가 태그를 고르고 해제하는 조작과 조회 결과를 보여 주는 화면은 각 입력 컴포넌트 스펙과 화면 스펙이 소유하므로 이 문서에는 `feature` 영역을 두지 않는다.

## domain

### 연결의 의미

[항목 태그 연결 공통 스펙](../common/entity-tag.md)의 `연결의 의미`는 장소에서 다음 목록에 적용된다.

- [PlaceHome 화면 스펙](./place-home.md)의 목록·지도 핀 노출 기준과 정렬
- [SearchHome 화면 스펙](./search-home.md)의 장소 검색 결과
- 메모와 장소의 연결. 자세한 기준은 [메모 장소 앱 스펙](./memo-place.md)을 따른다.

### 장소 컬러

장소는 [장소 태그 스펙](../common/place-tag.md)의 `대표 태그`에 따라 대표 태그를 갖지 않으므로, 앱은 장소 자신의 컬러로 카드와 지도 핀을 표시하고 태그의 컬러를 빌려 오지 않는다. 태그를 연결하거나 해제해도 장소의 컬러와 지도 핀 색은 바뀌지 않는다.
