# ProfileImageViewer 화면 스펙

이 문서는 사용자가 자기 프로필 이미지를 크게 보는 ProfileImageViewer 화면의 내용과 행동을 다룬다. 이 화면으로 진입하는 프로필 이미지 선택은 [MoreHome 화면 스펙](./more-home.md)에서, 프로필 이미지를 바꾸는 흐름은 [프로필 이미지 변경 스펙](./profile-image.md)에서, 세부 화면에서의 공통 내비게이션 노출 규칙은 [TopLevelNavigation 스펙](./top-level-navigation.md)에서 다룬다.

디자인: [ProfileImageViewer 화면 디자인](../../design/profile-image-viewer.md)

## feature

### 진입

사용자는 MoreHome 화면에서 프로필 이미지를 선택해 ProfileImageViewer 화면으로 이동한다. 진입 조건은 [MoreHome 화면 스펙](./more-home.md)의 `domain > 프로필 이미지 보기 진입 조건`을 따른다.

이 화면은 선택한 순간 MoreHome 화면에 표시하던 프로필 이미지를 보여 준다. 이 화면을 보는 동안 프로필 이미지가 바뀌어도 보여 주는 이미지를 바꾸지 않는다.

### 이미지 표시

화면에 들어오면 이미지 전체가 화면 안에 들어오도록 맞춰 보여 준다.

이미지를 불러오는 동안에는 불러오는 중임을 표시한다. 불러오기가 끝나면 이미지를 표시하고, 불러오지 못하면 이미지를 불러올 수 없음을 표시한다. 이 화면에는 다시 불러오는 동작과 새로고침이 없으며, 사용자는 뒤로갔다가 다시 진입해 다시 불러올 수 있다.

### 확대와 이동

이미지를 표시하는 동안 사용자는 이미지를 확대·축소하고, 확대한 이미지를 움직여 다른 부분을 볼 수 있다. 확대·축소 범위와 이동 범위는 `domain > 확대 범위`를 따른다.

불러오는 중이거나 불러오지 못한 동안에는 확대와 이동을 할 수 없다.

### 뒤로가기

사용자가 뒤로가면 MoreHome 화면으로 돌아간다.

## domain

### 확대 범위

처음 상태의 배율은 이미지 전체가 화면 안에 들어오는 배율이며, 이를 가장 작은 배율로 둔다. 사용자는 처음 배율보다 작게 줄일 수 없고, 처음 배율의 5배까지 확대할 수 있다.

이미지는 화면 밖으로 완전히 벗어나도록 움직일 수 없다. 확대한 이미지의 가장자리가 화면 가장자리를 넘어 안쪽으로 들어오지 않는 범위에서만 움직인다. 이미지가 화면보다 작은 방향으로는 움직이지 않고 가운데에 둔다.

### 계정 상태가 바뀔 때

이 화면은 이미 받은 프로필 이미지를 보여 주기만 하므로 계정 상태가 바뀌어도 화면을 닫지 않는다.

### 실행 경계

화면이 회전하거나 시스템에 의해 재생성되면 보여 주던 이미지는 유지하고, 배율과 위치는 처음 상태로 돌아간다. 사용자가 이 화면을 떠난 뒤 다시 진입해도 처음 상태에서 시작한다.
