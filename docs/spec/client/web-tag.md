# 웹 태그 앱 스펙

이 문서는 웹 항목과 태그의 연결 가운데 이 연결이 앱의 목록과 검색 결과에 주는 영향을 다룬다. 웹 항목과 태그의 연결이 공통으로 지키는 규칙은 [웹 태그 스펙](../common/web-tag.md)을, 태그 연결이 공통으로 지키는 규칙은 [항목 태그 연결 공통 스펙](../common/entity-tag.md)을, 앱이 기기에 저장된 연결로 대상 항목의 태그와 태그의 대상 항목을 조회하는 규칙은 [항목 태그 연결 앱 스펙](./entity-tag.md)을 따른다.

사용자가 태그를 고르고 해제하는 조작과 조회 결과를 보여 주는 화면은 각 입력 컴포넌트 스펙과 화면 스펙이 소유하므로 이 문서에는 `feature` 영역을 두지 않는다.

## domain

### 연결의 의미

[항목 태그 연결 공통 스펙](../common/entity-tag.md)의 `연결의 의미`는 웹 항목에서 다음 목록에 적용된다.

- [WebHome 화면 스펙](./web-home.md)의 목록 노출 기준과 정렬
- [SearchHome 화면 스펙](./search-home.md)의 웹 검색 결과
