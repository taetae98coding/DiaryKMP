# Memo 목록·상세 배치 스펙

이 문서는 메모 주요 목적지에서 목록과 상세가 함께 표시될 때 이 배치에만 해당하는 상세 영역 구성, 뒤로가기와 초기화 경계를 다룬다. 함께 사용과 단독 사용, 추가 진입 수단, 표시 비율 조절, 배치에 참여하는 화면과 유지·초기화의 공통 기준은 [목록·상세 배치 공통 스펙](./list-detail-pane.md)을 따른다. 목록 화면과 상세 영역 각 화면의 내용과 행동은 해당 화면 스펙([MemoAdd 화면 스펙](./memo-add.md) 등)에서 다룬다. TagMemoFinishedList에서 사용하는 목록·상세 배치는 [TagMemoFinishedList 목록·상세 배치 스펙](./tag-memo-finished-list-detail.md)에서 다룬다.

디자인: [Memo 목록·상세 배치 디자인](../../design/memo-list-detail.md)

크기 조절 결과는 화면 표시 상태일 뿐 사용자 데이터의 생성이나 저장이 없어 `data` 영역은 생략한다.

## feature

### 상세 영역의 구성

목록과 상세 영역을 함께 표시하는 상태에서 상세 영역에는 사용자가 선택한 메모의 상세 화면이 표시되고, 선택한 메모가 없으면 메모 추가 화면이 표시된다.

선택한 메모가 없는 동안 사용자는 목록을 떠나지 않고 곧바로 새 메모를 작성한다. 추가에 성공한 뒤에도 상세 영역은 메모 추가로 남으므로 사용자는 다음 메모를 이어서 작성하고, 방금 추가한 메모가 목록에 나타나는 것을 같은 화면에서 확인한다. 추가 뒤 입력이 어떻게 남는지는 [MemoAdd 화면 스펙](./memo-add.md)을 따른다.

목록에서 메모를 선택하면 상세 영역이 그 메모의 상세로 바뀐다. 상세 영역에 메모 상세가 놓여 있는 동안 다른 메모를 선택하면 상세 영역은 새로 선택한 메모로 바뀌고, 앞서 보던 메모로 돌아가는 기록은 남기지 않는다.

상세 영역에 메모 상세가 놓여 있는 동안 목록에서 메모 추가를 실행하면 상세 영역이 메모 추가로 바뀐다. 상세 영역에 이미 메모 추가가 놓여 있으면 목록에서 메모 추가를 제공하지 않으며, 그 기준은 [목록·상세 배치 공통 스펙](./list-detail-pane.md)의 `추가 진입 수단`을 따른다.

상세 영역의 메모 상세에서 메모를 복사하면 상세 영역은 복사한 메모의 상세로 바뀐다. 메모를 삭제하면 상세 영역은 `뒤로가기`와 같이 그 전에 놓였던 화면으로 되돌아간다.

상세 영역의 메모에서 태그, 웹 항목, 연락처, 장소의 상세나 추가로 이동한 화면은 이 배치에 참여하지 않고 단독으로 표시한다. 그 화면에서 뒤로가면 이 배치로 돌아오며, 상세 영역에는 떠나기 전의 메모가 그대로 놓여 있다.

메모 목록이 아닌 곳에서 진입한 MemoAdd 화면과 MemoDetail 화면은 이 배치에 참여하지 않고 단독으로 표시한다. 캘린더 홈과 황금연휴 화면, TagDetail 메모 탭, ContactDetail·PlaceDetail·WebDetail 메모 탭, MemoFinishedList 화면, SearchHome 화면에서 진입한 경우가 여기에 해당한다.

한 영역만 표시되는 상태에서는 해당 화면 스펙의 행동을 그대로 제공한다.

### 뒤로가기

상세 영역에서 시스템 뒤로가기를 사용하면 목록은 그대로 유지되고 상세 영역만 그 전에 놓였던 화면으로 되돌아간다. 되돌아갈 화면이 없으면 선택한 메모가 없을 때의 화면인 메모 추가가 놓인다.

선택한 메모가 없어 상세 영역에 메모 추가만 놓여 있으면 시스템 뒤로가기는 상세 영역을 바꾸지 않고, 메모 목록에서 뒤로가기를 사용한 것과 같은 결과를 낸다. 그 결과는 [TopLevelNavigation 스펙](./top-level-navigation.md)을 따른다.

### 정렬과 필터

목록의 정렬 선택과 필터는 배치와 관계없이 [MemoHome 목록 스펙](./memo-home.md)을 따른다. 상세 영역에 메모 추가나 메모 상세가 놓여 있어도 목록의 정렬과 필터를 그대로 사용할 수 있고, 필터를 여는 동안에도 상세 영역에 놓인 화면은 바뀌지 않는다.

## domain

### 유지와 초기화 기준

메모는 주요 목적지이므로 공통 내비게이션에서 다른 주요 목적지로 이동하는 것을 이 배치를 떠난 것으로 본다. 다른 주요 목적지에 다녀와 메모로 돌아오거나 앱을 종료하고 다시 실행하면 [목록·상세 배치 공통 스펙](./list-detail-pane.md)의 `유지와 초기화 기준`에 따라 상세 선택을 선택 전 상태로, 표시 비율을 기본 비율로 초기화한다. 상세 선택이 초기화되면 상세 영역은 메모 추가로 돌아가고, 떠나기 전에 보던 메모 상세로 돌아가는 뒤로가기 기록도 남지 않는다.

선택한 메모가 없을 때 상세 영역에 놓이는 메모 추가의 작성 내용도 이 배치의 기준을 따른다. 이 배치를 떠나기 전까지는 상세 영역에서 메모 상세를 보고 돌아오거나 메모 추가에서 연 연결 항목 화면에 다녀와도, 입력하던 제목, 설명, 컬러, 기간과 고른 태그와 대표 태그 지정, 웹 항목, 연락처, 장소가 그대로 남는다. 다른 주요 목적지에 다녀와 메모로 돌아오면 상세 영역의 메모 추가는 제목과 설명이 비어 있고 기간과 태그, 대표 태그 지정, 웹 항목, 연락처, 장소 선택이 하나도 없는 상태로 시작하며, 컬러에는 새 무작위 값이 제시된다. 화면 재생성과 시스템이 앱을 메모리에서 정리한 뒤의 복원에서 무엇이 남는지는 [MemoAdd 화면 스펙](./memo-add.md)의 `진행 상태 유지`를 따른다.

상세 영역의 메모에서 이어 연 화면에 다녀오는 것은 이 배치를 떠난 것으로 보지 않으며, 그 결과는 `feature > 상세 영역의 구성`을 따른다.
