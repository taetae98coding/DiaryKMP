# Memo 목록·상세 배치 스펙

이 문서는 메모 주요 목적지에서 목록과 상세가 함께 표시될 때 이 배치에만 해당하는 상세 영역 구성, 뒤로가기와 초기화 경계를 다룬다. 함께 사용과 단독 사용, 상세 선택과 교체, 선택이 없을 때의 추가, 추가 진입 수단, 뒤로가기, 표시 비율 조절, 배치에 참여하는 화면과 유지·초기화의 공통 기준은 [목록·상세 배치 공통 스펙](./list-detail-pane.md)을 따른다. 목록 화면과 상세 영역 각 화면의 내용과 행동은 해당 화면 스펙([MemoAdd 화면 스펙](./memo-add.md) 등)에서 다룬다. TagMemoFinishedList에서 사용하는 목록·상세 배치는 [TagMemoFinishedList 목록·상세 배치 스펙](./tag-memo-finished-list-detail.md)에서, ContactMemoFinishedList·PlaceMemoFinishedList·WebMemoFinishedList에서 사용하는 목록·상세 배치는 [항목 완료 메모 목록·상세 배치 스펙](./entity-memo-finished-list-detail.md)에서, MemoFinishedList에서 사용하는 목록·상세 배치는 [MemoFinishedList 목록·상세 배치 스펙](./memo-finished-list-detail.md)에서 다룬다.

디자인: [Memo 목록·상세 배치 디자인](../../design/memo-list-detail.md)

크기 조절 결과는 화면 표시 상태일 뿐 사용자 데이터의 생성이나 저장이 없어 `data` 영역은 생략한다.

## feature

### 상세 영역의 구성

목록과 상세 영역을 함께 표시하는 상태에서 상세 영역에는 사용자가 선택한 메모의 상세 화면이 표시되고, 선택한 메모가 없으면 메모 추가 화면이 표시된다.

선택, 교체, 삭제 뒤의 상세 영역과 선택이 없을 때의 추가는 [목록·상세 배치 공통 스펙](./list-detail-pane.md)의 `상세 선택과 교체`와 `선택이 없을 때의 추가`를 따른다. 추가 뒤 입력이 어떻게 남는지는 [MemoAdd 화면 스펙](./memo-add.md)을 따른다.

목록과 함께 표시되는 메모 추가는 진입할 때 입력 초점을 두지 않는다.

상세 영역에 메모 상세가 놓여 있는 동안 목록에서 메모 추가를 실행한 결과는 [목록·상세 배치 공통 스펙](./list-detail-pane.md)의 `추가 진입 수단`을 따른다.

상세 영역의 메모 상세에서 메모를 복사하면 상세 영역은 복사한 메모의 상세로 바뀐다.

상세 영역의 메모에서 태그, 웹 항목, 연락처, 장소의 상세나 추가로 이동한 화면은 이 배치에 참여하지 않고 단독으로 표시한다. 그 화면에서 돌아온 결과는 [목록·상세 배치 공통 스펙](./list-detail-pane.md)의 `배치에 참여하는 화면`을 따른다.

메모 목록이 아닌 곳에서 진입한 MemoAdd 화면과 MemoDetail 화면은 이 배치에 참여하지 않고 단독으로 표시한다. 캘린더 홈과 캘린더 시간표 화면, 황금연휴 화면, TagDetail 메모 탭, ContactDetail·PlaceDetail·WebDetail 메모 탭, SearchHome 화면에서 진입한 경우가 여기에 해당한다.

MemoFinishedList 화면에서 진입한 MemoDetail 화면은 이 배치 대신 [MemoFinishedList 목록·상세 배치 스펙](./memo-finished-list-detail.md)을 따른다.

한 영역만 표시되는 상태에서는 해당 화면 스펙의 행동을 그대로 제공한다.

### 뒤로가기

뒤로가기의 결과는 [목록·상세 배치 공통 스펙](./list-detail-pane.md)의 `뒤로가기`를 따른다. 이 배치를 떠나는 결과, 즉 메모 목록에서 뒤로가기를 사용한 결과는 [TopLevelNavigation 스펙](./top-level-navigation.md)을 따른다.

### 정렬과 필터

목록의 정렬 선택과 필터는 배치와 관계없이 [MemoHome 목록 스펙](./memo-home.md)을 따른다. 상세 영역에 메모 추가나 메모 상세가 놓여 있어도 목록의 정렬과 필터를 그대로 사용할 수 있고, 필터를 여는 동안에도 상세 영역에 놓인 화면은 바뀌지 않는다.

## domain

### 유지와 초기화 기준

메모는 주요 목적지이므로 공통 내비게이션에서 다른 주요 목적지로 이동하는 것을 이 배치를 떠난 것으로 본다. 다른 주요 목적지에 다녀와 메모로 돌아오거나 앱을 종료하고 다시 실행하면 [목록·상세 배치 공통 스펙](./list-detail-pane.md)의 `유지와 초기화 기준`에 따라 초기화하며, 떠나기 전에 보던 메모 상세로 돌아가는 뒤로가기 기록도 남지 않는다.

선택한 메모가 없을 때 상세 영역에 놓이는 메모 추가의 작성 내용은 같은 절을 따른다. 이 배치를 떠나기 전까지는 메모 추가에서 연 연결 항목 화면이나 MemoFinishedList 화면에 다녀와도, 입력하던 제목, 설명, 컬러, 기간과 고른 태그와 대표 태그 지정, 웹 항목, 연락처, 장소가 그대로 남는다. 다른 주요 목적지에 다녀와 메모로 돌아오면 상세 영역의 메모 추가는 제목과 설명이 비어 있고 기간과 태그, 대표 태그 지정, 웹 항목, 연락처, 장소 선택이 하나도 없는 상태로 시작하며, 컬러에는 새 무작위 값이 제시된다. 화면 재생성과 시스템이 앱을 메모리에서 정리한 뒤의 복원에서 무엇이 남는지는 [MemoAdd 화면 스펙](./memo-add.md)의 `진행 상태 유지`를 따른다.

앱이 백그라운드에 있는 동안 시스템이 앱을 정리했다가 다시 만드는 것도 이 배치를 떠난 것으로 보지 않는다. 상세 선택과 표시 비율은 [목록·상세 배치 공통 스펙](./list-detail-pane.md)의 `유지와 초기화 기준`에 따라 떠나기 전 그대로 다시 보인다.

메모 목록에서 완료된 메모 확인을 선택해 MemoFinishedList 화면에 다녀오는 것도 이 배치를 떠난 것으로 보지 않는다. MemoFinishedList 화면에서 메모 목록으로 돌아오면 이 배치의 상세 선택과 표시 비율, 상세 영역에서 그 전에 놓였던 화면으로 돌아가는 뒤로가기 기록은 MemoFinishedList로 떠나기 전 그대로다. MemoFinishedList 화면 자체의 배치는 [MemoFinishedList 목록·상세 배치 스펙](./memo-finished-list-detail.md)을 따른다.
