# 메모 웹 입력 컴포넌트 스펙

이 문서는 MemoAdd 화면과 MemoDetail 화면에서 함께 사용하는 웹 입력의 사용자 행동과 정책을 다룬다. 두 화면에서 웹 입력은 같은 행동과 선택 규칙을 제공하며, 구체적인 구성과 조작 수단은 [메모 웹 입력 컴포넌트 디자인](../../design/memo-web-input.md)에서 다룬다.

웹 입력은 [메모 항목 선택 입력 공통 스펙](./memo-entity-input.md)을 따른다. 그 문서의 `대상 항목`은 웹 항목, `항목 입력`은 웹 입력, `선택 목록`은 웹 선택 목록, `추가 화면`은 [WebAdd 화면](./web-add.md), `상세 화면`은 [WebDetail 화면](./web-detail.md)이다. 이 문서에는 웹 입력에서만 정하는 값과 기준을 둔다.

메모와 웹 항목의 연결 규칙은 [메모 웹 스펙](../common/memo-web.md)을, 웹 항목이 갖는 정보는 [WebAdd 화면 스펙](./web-add.md)의 `웹 항목의 정보`를, 선택 대상이 되는 웹 항목의 노출 기준은 [WebHome 화면 스펙](./web-home.md)을 따른다.

웹 입력은 웹 페이지를 불러와 보여 주지 않는다. 메모 화면에서 웹 페이지를 확인하려면 웹 상세로 이동해야 하며, 웹 페이지 표시 방식과 불러오기 규칙은 [WebDetail 화면 스펙](./web-detail.md)이 소유한다.

디자인: [메모 웹 입력 컴포넌트 디자인](../../design/memo-web-input.md)

## feature

### 선택 상태 표시

선택한 웹 항목과 웹 선택 목록의 웹 항목은 제목으로 구분해 표시하고, 제목이 다른 경로로 바뀌면 바뀐 제목이 표시된다. 나머지 기준은 [메모 항목 선택 입력 공통 스펙](./memo-entity-input.md)의 `선택 상태 표시`를 따른다.

### 웹 상세 이동

웹 입력에 표시된 웹 항목을 누르면 그 웹 항목의 WebDetail 화면으로 이동한다. 이동과 돌아왔을 때의 기준은 [메모 항목 선택 입력 공통 스펙](./memo-entity-input.md)의 `항목 상세 이동`을 따른다.

### 웹 선택 목록

웹 선택 목록의 행동은 [메모 항목 선택 입력 공통 스펙](./memo-entity-input.md)의 `선택 목록`을 따른다.

### 웹 검색

웹 선택 목록의 검색은 [메모 항목 선택 입력 공통 스펙](./memo-entity-input.md)의 `항목 검색`을 따르며, 판정 대상 값은 `domain`의 `웹 검색어`를 따른다.

### 웹 추가 이동

웹 입력이나 웹 선택 목록에서 WebAdd 화면으로 이동하는 기준과 돌아왔을 때 추가한 웹 항목이 선택되는 기준은 [메모 항목 선택 입력 공통 스펙](./memo-entity-input.md)의 `항목 추가 이동`과 `추가한 항목의 자동 선택`을 따른다.

### 웹 선택과 해제

웹 항목의 선택과 해제는 [메모 항목 선택 입력 공통 스펙](./memo-entity-input.md)의 `항목 선택과 해제`를 따른다.

## domain

### 선택할 수 있는 웹 항목

선택할 수 있는 웹 항목의 기준은 [메모 항목 선택 입력 공통 스펙](./memo-entity-input.md)의 `선택할 수 있는 항목`을 따르며, 웹 항목은 제목 오름차순으로 정렬한다. 제목이 같은 웹 항목끼리의 순서는 정하지 않는다. [WebHome 화면 스펙](./web-home.md)의 정렬 선택은 웹 입력에 적용하지 않는다.

### 웹 선택 목록에 나타나는 웹 항목

웹 선택 목록에 나타나는 웹 항목은 [메모 항목 선택 입력 공통 스펙](./memo-entity-input.md)의 `선택 목록에 나타나는 항목`을 따른다.

### 웹 검색어

검색어 판정의 기준은 [메모 항목 선택 입력 공통 스펙](./memo-entity-input.md)의 `항목 검색어`를 따른다. 다만 이 목록의 일치 판정에는 웹 항목의 제목과 설명만 쓰고, [검색어 일치 판정 스펙](./search-match.md)이 웹 항목의 판정 대상으로 정한 URL은 쓰지 않는다. 요청 헤더도 쓰지 않는다.

### 추가한 웹 항목의 자동 선택

WebAdd 화면에서 추가한 웹 항목의 자동 선택은 [메모 항목 선택 입력 공통 스펙](./memo-entity-input.md)의 `추가한 항목의 자동 선택`을 따른다.

### 선택한 것으로 표시하는 웹 항목

웹 입력과 웹 선택 목록에 선택한 것으로 표시하는 웹 항목은 [메모 항목 선택 입력 공통 스펙](./memo-entity-input.md)의 `선택한 것으로 표시하는 항목`을 따른다.

### 진행 상태 유지

화면 구성 변경, 메모리 정리 뒤 복원, 상세 대상 메모의 변경에서 웹 입력이 유지하는 상태는 [메모 항목 선택 입력 공통 스펙](./memo-entity-input.md)의 `진행 상태 유지`를 따른다.

## data

### 웹 목록 조회

웹 선택 목록과 선택 상태의 조회는 [메모 항목 선택 입력 공통 스펙](./memo-entity-input.md)의 `항목 목록 조회`를 따른다. MemoDetail 화면의 선택 상태는 [MemoDetail 화면 스펙](./memo-detail.md)의 `웹 입력의 조회`를 따른다.

### 내용 갱신

웹 항목이 추가되거나 저장된 웹 항목의 제목·상태가 바뀌면 웹 입력과 열려 있는 웹 선택 목록에 바로 반영된다. 반영 기준과 새로고침이 없다는 점은 [메모 항목 선택 입력 공통 스펙](./memo-entity-input.md)의 `내용 갱신`을 따른다.
