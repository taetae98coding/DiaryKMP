# WebAdd 화면 스펙

이 문서는 사용자가 새 웹 항목을 작성해 추가하는 WebAdd 화면의 내용과 행동, 그리고 추가되는 웹 항목이 갖는 정보와 정책을 다룬다. WebAdd로 진입하는 흐름과 저장한 웹 항목의 목록 표시는 [WebHome 화면 스펙](./web-home.md)에서, 이 태그에 연결된 웹 항목을 확인하다가 진입하는 흐름은 [TagDetail 웹 탭 스펙](./tag-detail-web.md)에서, 메모에 연결할 웹 항목을 고르다가 진입하는 흐름은 [메모 웹 입력 컴포넌트 스펙](./memo-web-input.md)에서, 저장한 웹 항목의 상세 확인과 수정, 그 URL과 요청 헤더로 웹 페이지를 불러오는 행동은 [WebDetail 화면 스펙](./web-detail.md)에서, 설명 입력의 행동은 [설명 입력 컴포넌트 스펙](./description-input.md)에서 다룬다. 제목 입력 자체의 동작은 [제목 입력 스펙](./title-input.md)을 따른다.

작성 상태 유지, 뒤로가기, 태그 입력의 반영 시점, 추가 요청 제한, 계정 연결과 저장·동기화 계약은 [항목 추가 화면 공통 스펙](./entity-add.md)을 따른다. 연결할 태그의 선택과 해제, 선택 목록의 행동과 정책은 [항목 태그 입력 컴포넌트 스펙](./entity-tag-input.md)을 따르고, 웹 항목과 태그의 연결 규칙은 [웹 태그 스펙](../common/web-tag.md)을 따른다. 이 문서에서는 WebAdd 화면에서만 다른 시작 상태와 추가 결과를 다룬다.

이번 범위는 사용자가 제목, 설명, URL과 요청 헤더를 입력하고 태그를 연결해 웹 항목을 추가하는 것까지다. 웹 항목의 수정과 삭제는 [WebDetail 화면 스펙](./web-detail.md)에서 다룬다.

디자인: [WebAdd 화면 디자인](../../design/web-add.md)

## feature

### 진입과 입력

사용자는 WebHome 화면에서 웹 추가를 선택해 WebAdd 화면으로 이동한다. 목록과 상세를 함께 사용할 수 있는 환경에서는 이동하지 않고 웹 목록과 함께 표시된 상세 영역에서 같은 입력을 사용하며, 그 기준은 [Web 목록·상세 배치 스펙](./web-list-detail.md)을 따른다.

메모 웹 입력과 웹 선택 목록에서 웹 추가로 이동하는 경우에도 WebAdd 화면으로 이동하며, 그 진입 경로와 돌아왔을 때의 결과는 [메모 웹 입력 컴포넌트 스펙](./memo-web-input.md)의 `웹 추가 이동`을 따른다. 이 경로로 이동한 WebAdd 화면은 웹 목록과 함께 표시하지 않는다.

사용자는 제목, 설명, URL, 요청 헤더와 연결할 태그를 입력하거나 바꿀 수 있다. 제목과 URL은 각각 한 줄 분량을 입력할 수 있다.

화면에 처음 진입하면 제목, 설명, URL이 비어 있고 요청 헤더도 하나도 없는 상태로 시작한다. 사용자가 제목부터 바로 입력할 수 있도록 입력 초점을 제목 입력에 둔다.

WebHome이나 메모 웹 입력에서 진입하면 태그를 하나도 고르지 않은 상태로 시작한다. [TagDetail 웹 탭](./tag-detail-web.md)에서 진입하면 그 태그를 최초 선택한 상태로 시작하며, 기준은 그 문서의 `웹 항목 추가의 초기값`을 따른다.

### 요청 헤더 입력

사용자는 요청 헤더를 여러 개 입력할 수 있다. 헤더 하나는 이름과 값으로 이루어지며, 사용자는 각각을 한 줄 분량으로 입력한다.

사용자는 헤더 항목을 추가해 입력할 자리를 늘리고, 이미 입력한 헤더 항목을 삭제할 수 있다. 헤더 항목을 삭제해도 다른 헤더 항목과 제목, 설명, URL 입력은 그대로 유지된다.

헤더 항목은 사용자가 배치한 순서대로 다루며, 항목을 추가하면 마지막 자리에 놓인다. 헤더 항목을 추가하거나 삭제해도 입력 초점은 옮기지 않는다.

### 웹 항목 추가

사용자는 입력한 내용으로 웹 항목 추가를 실행할 수 있다.

웹 항목 추가를 처리하는 동안에는 진행 상태를 표시한다.

추가에 성공하면 화면을 유지한 채 제목, 설명, URL을 비우고 입력한 헤더 항목을 모두 없앤다. 사용자가 다음 웹 항목 입력을 바로 이어갈 수 있도록 입력 초점을 제목 입력으로 옮기고 성공 피드백을 제공한다.

태그 선택은 비우지 않고 그대로 유지한다. 사용자가 같은 태그의 웹 항목을 이어서 추가할 수 있게 하기 위한 것이며, 기준은 [MemoAdd 화면 스펙](./memo-add.md)의 `추가 성공`에서 태그 선택을 유지하는 것과 같다.

### 제목 미입력

제목이 비어 있거나 공백만 있는 상태에서 추가를 실행하면 웹 항목을 추가하지 않고 제목 입력이 필요하다는 피드백을 제공한다.

입력 중이던 설명, URL과 헤더는 유지하고 입력 초점을 제목 입력으로 옮기므로, 사용자는 제목을 바로 입력한 뒤 다시 시도할 수 있다.

### URL 미입력

URL이 비어 있거나 공백만 있는 상태에서 추가를 실행하면 웹 항목을 추가하지 않고 URL 입력이 필요하다는 피드백을 제공한다.

입력 중이던 제목, 설명과 헤더는 유지하고 입력 초점을 URL 입력으로 옮기므로, 사용자는 URL을 바로 입력한 뒤 다시 시도할 수 있다.

### 헤더 이름 미입력

이름이 비어 있거나 공백만 있는 헤더 항목이 하나라도 있는 상태에서 추가를 실행하면 웹 항목을 추가하지 않고 헤더 이름 입력이 필요하다는 피드백을 제공한다.

입력 중이던 제목, 설명, URL과 헤더 항목은 모두 그대로 유지하므로 사용자는 헤더 이름을 입력하거나 그 헤더 항목을 삭제한 뒤 다시 시도할 수 있다.

이름이 비어 있는 헤더 항목은 여러 개일 수 있고 사용자가 이름을 채우는 대신 그 항목을 삭제할 수도 있으므로, 입력 초점은 옮기지 않고 사용자가 보고 있던 입력에 그대로 둔다.

### 작성 상태 유지 대상

[항목 추가 화면 공통 스펙](./entity-add.md)의 `작성 상태 유지`가 유지하는 대상은 입력 중이던 제목, 설명, URL과 헤더 항목의 이름·값·순서, 그리고 고른 태그다.

시스템이 앱을 메모리에서 정리한 뒤 화면을 복원하면 입력 중이던 제목, 설명, URL과 헤더 항목은 복원하지만 고른 태그는 복원하지 않는다. 이때 태그 선택은 `진입과 입력`의 시작 상태로 돌아가므로, TagDetail 웹 탭에서 진입했으면 그 태그만 선택된 상태가 되고 다른 경로로 진입했으면 태그를 하나도 고르지 않은 상태가 된다.

## domain

### 웹 항목의 정보

웹 항목 하나는 다음 정보를 갖는다.

- 제목: 웹 항목을 가리키는 이름.
- 설명: 웹 항목에 대한 부가 설명으로, 비어 있을 수 있다.
- URL: 웹 항목이 가리키는 주소.
- 요청 헤더: 그 주소를 불러올 때 함께 보낼 이름과 값의 쌍 목록으로, 비어 있을 수 있다.

웹 항목과 태그의 연결은 웹 항목이 가지는 값이 아니라 웹 항목과 태그 사이의 별개 항목이다. 그 규칙은 [웹 태그 스펙](../common/web-tag.md)을 따른다.

### 요청 헤더

요청 헤더 하나는 이름과 값을 함께 갖는다. 값은 비어 있을 수 있지만 이름은 비어 있을 수 없다.

요청 헤더 목록은 순서를 가지며, 사용자가 배치한 순서를 그대로 유지한다.

이름이 같은 헤더가 여러 개 있어도 하나로 합치거나 뒤의 것으로 덮어쓰지 않고 모두 각각의 헤더로 다룬다.

이번 범위에서는 헤더의 이름과 값이 특정 형식을 만족하는지 검사하지 않는다.

### 추가 성립 조건

웹 항목은 제목을 가져야 추가할 수 있다. 제목이 비어 있거나 공백 문자로만 이루어져 있으면 추가하지 않는다.

웹 항목은 URL을 가져야 추가할 수 있다. URL이 비어 있거나 공백 문자로만 이루어져 있으면 추가하지 않는다. 이번 범위에서는 URL이 주소 형식을 만족하는지는 검사하지 않는다.

웹 항목은 이름이 없는 요청 헤더를 가질 수 없다. 이름이 비어 있거나 공백 문자로만 이루어진 헤더 항목이 하나라도 있으면 추가하지 않는다. 이름이 없는 헤더 항목을 조용히 빼고 추가하지 않으며, 사용자가 입력한 헤더가 그대로 기록되지 않는 상태를 만들지 않는다.

설명과 요청 헤더는 비어 있어도 웹 항목을 추가할 수 있다.

여러 조건이 함께 성립하지 않으면 제목, URL, 헤더 이름 순으로 판단하고 먼저 성립하지 않은 조건 하나의 결과만 알린다.

### 추가되는 웹 항목의 내용

기록되는 공통 값은 [항목 추가 화면 공통 스펙](./entity-add.md)의 `추가되는 항목의 내용`을 따른다.

웹 항목에는 사용자가 입력한 제목, 설명, URL과 요청 헤더를 기록한다. 설명을 입력하지 않으면 빈 설명으로 기록한다.

헤더 항목은 사용자가 배치한 순서대로 모두 기록한다.

## data

### 웹 항목 생성과 저장

저장 흐름은 [항목 추가 화면 공통 스펙](./entity-add.md)의 `생성과 저장`을 따른다. 이때 함께 반영되는 것은 새 웹 항목, 현재 사용자 계정의 연결, 그리고 고른 태그와의 연결이다.

요청 헤더는 웹 항목에 딸린 순서 있는 목록으로 함께 저장한다.
