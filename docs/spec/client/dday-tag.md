# 디데이 태그 앱 스펙

이 문서는 디데이와 태그의 연결 가운데 이 연결이 앱의 목록과 검색 결과에 주는 영향을 다룬다. 디데이와 태그의 연결이 공통으로 지키는 규칙은 [디데이 태그 스펙](../common/dday-tag.md)을, 태그 연결이 공통으로 지키는 규칙은 [항목 태그 연결 공통 스펙](../common/entity-tag.md)을, 앱이 기기에 저장된 연결로 대상 항목의 태그와 태그의 대상 항목을 조회하는 규칙은 [항목 태그 연결 앱 스펙](./entity-tag.md)을 따른다.

사용자가 태그를 고르고 해제하는 조작과 조회 결과를 보여 주는 화면은 각 입력 컴포넌트 스펙과 화면 스펙이 소유하므로 이 문서에는 `feature` 영역을 두지 않는다.

## domain

### 연결의 의미

[항목 태그 연결 공통 스펙](../common/entity-tag.md)의 `연결의 의미`는 디데이에서 다음에 적용된다.

- [DDayHome 화면 스펙](./dday-home.md)의 목록 노출 기준과 정렬. 사용자가 고른 태그 필터는 예외이며, 그 판정은 같은 문서의 `태그 필터 기준`을 따른다.
- [캘린더 디데이 표시 스펙](./calendar-dday.md)의 노출 기준. 캘린더를 배치하는 화면이 태그 필터를 디데이 표시에 더하는지는 [CalendarHome 스펙](./calendar-home.md)을 따른다.
- [SearchHome 화면 스펙](./search-home.md)의 디데이 검색 결과. 연결된 태그의 제목은 디데이의 검색 일치 판정에 쓰이지 않는다.

태그로 디데이를 조회하는 [TagDetail 디데이 탭 스펙](./tag-detail-dday.md)의 목록은 이 연결을 노출 기준으로 쓴다.
