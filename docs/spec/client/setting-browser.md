# SettingBrowser 화면 스펙

이 문서는 사용자가 설정 화면의 `브라우저` 항목에서 진입하는 SettingBrowser 화면의 내용과 행동을 다룬다. 기기에 보관하는 설정 화면의 공통 행동과 저장 영역은 [기기 설정 화면 공통 스펙](./device-setting.md)을 따르고, 이 문서에는 이 설정에만 해당하는 내용을 둔다. 설정 항목의 표시와 선택은 [SettingHome 화면 스펙](./setting-home.md)에서, 설정 목록과 함께 사용할 때의 선택·뒤로가기 정책은 [Setting 목록·상세 배치 스펙](./setting-list-detail.md)에서, 세부 화면에서의 공통 내비게이션 노출 규칙은 [TopLevelNavigation 스펙](./top-level-navigation.md)에서 다룬다. 고른 프로필의 로그인 정보를 앱 안 웹 페이지가 가져오는 규칙과 프로필 목록의 출처는 [Chrome 로그인 이어받기 스펙](./chrome-session-import.md)에서 다룬다.

디자인: [SettingBrowser 화면 디자인](../../design/setting-browser.md)

이번 범위는 사용자가 로그인 정보를 이어받을 Chrome 프로필을 고르거나 고르지 않기로 하고, 그 선택이 기기에 유지되는 것까지다.

## feature

### 진입과 이동

사용자는 설정 화면의 `브라우저` 항목을 선택해 SettingBrowser 화면으로 이동한다.

표시 관계는 [기기 설정 화면 공통 스펙](./device-setting.md)의 `표시 관계`를 따른다.

이 화면은 [Chrome 로그인 이어받기 스펙](./chrome-session-import.md)의 `제공 환경`에서만 진입할 수 있다. 제공하지 않는 환경에서는 SettingHome이 `브라우저` 항목을 제공하지 않으므로 이 화면으로 이동하는 경로가 없다.

### Chrome 프로필 선택

사용자는 `Chrome 로그인 이어받기` 설정에서 `선택 안 함`과 이 기기의 Chrome 프로필 중 현재 선택을 확인하고 하나를 고를 수 있다. 프로필은 [Chrome 로그인 이어받기 스펙](./chrome-session-import.md)의 `Chrome 프로필`이 정한 목록과 순서로 제공하며, `선택 안 함`을 맨 앞에 둔다.

항목을 고르는 행동과 저장 실패는 [기기 설정 화면 공통 스펙](./device-setting.md)의 `고르면 바로 저장하는 설정`을 따른다. 다만 저장된 프로필이 있는데 `선택 안 함`이 선택된 것으로 표시되는 경우(아래의 프로필 목록을 읽지 못한 경우와 `domain > 목록에 없는 프로필`)에는 이미 선택된 것으로 보이는 `선택 안 함`을 다시 골라도 저장된 프로필을 지운다.

저장된 선택을 확인하기 전이거나 읽지 못했을 때는 [기기 설정 화면 공통 스펙](./device-setting.md)의 `저장된 값을 확인하기 전`에 따라 선택 기능을 제공하지 않으며, `Chrome 로그인 이어받기` 설정 이름도 표시하지 않는다.

Chrome 프로필이 하나도 없으면 `선택 안 함`만 제공한다. 이때도 사용자는 화면에서 설정 이름과 `선택 안 함`을 확인할 수 있다.

프로필 목록을 읽지 못하면 프로필 항목 없이 `선택 안 함`만 제공하고, 프로필을 조회할 수 없다는 안내를 함께 표시한다. 사용자는 이 상태에서도 `선택 안 함`을 고를 수 있으며, 저장된 프로필이 있어도 `선택 안 함`이 선택된 것으로 표시한다. 사용자가 고르기 전에는 저장된 값을 지우지 않고, 저장된 프로필이 있는 채로 `선택 안 함`을 고르면 저장된 값을 지운다.

선택을 바꾸면 앱 안 웹 표시 수단에 남아 있던 로그인 정보가 지워지고, 프로필을 골랐으면 그 프로필의 로그인 정보를 새로 가져온다. 무엇을 지우고 가져오는지와 가져오는 동안의 상태는 [Chrome 로그인 이어받기 스펙](./chrome-session-import.md)의 `가져오는 계기`를 따른다. 이 화면은 가져오는 진행 상태나 실패를 따로 표시하지 않으며, 실패 안내는 같은 스펙의 `가져오기 실패`에 따라 앱이 알린다.

### 내용의 갱신

Chrome 프로필 목록은 화면에 들어올 때 읽는다. 화면을 보는 동안 Chrome에서 프로필을 추가하거나 지워도 목록은 바뀌지 않으며, 목록을 당겨서 새로고침하는 수단도 두지 않는다. 사용자가 화면을 떠났다가 다시 들어오면 목록을 다시 읽는다. 다른 앱에 다녀올 때는 떠난 지 5초가 지나 돌아오면 목록을 다시 읽고, 5초 안에 돌아오면 읽어 둔 목록을 그대로 둔다.

현재 선택은 [기기 설정 화면 공통 스펙](./device-setting.md)의 `화면에 보이는 값`을 따른다.

### 뒤로가기

뒤로가기 결과와 바꾼 선택의 유지는 [기기 설정 화면 공통 스펙](./device-setting.md)의 `뒤로가기`를 따른다.

## domain

### Chrome 로그인 이어받기 설정

Chrome 로그인 이어받기는 이 기기의 Chrome 중 어느 프로필에 저장된 로그인 정보를 앱 안 웹 표시 수단이 이어받을지 정하는 설정이다. 값은 `선택 안 함` 또는 Chrome 프로필 하나다.

사용자가 한 번도 고르지 않았으면 `선택 안 함`이다. Chrome의 로그인 정보를 읽는 것은 사용자가 직접 허용해야 하는 일이므로 기본으로 프로필을 고르지 않는다.

### 목록에 없는 프로필

저장된 프로필이 현재 Chrome 프로필 목록에 없으면 `선택 안 함`으로 다룬다. 화면에서도 `선택 안 함`이 선택된 것으로 표시하고 로그인 정보를 가져오지 않는다. 이렇게 `선택 안 함`으로 다루는 것은 사용자가 선택을 바꾼 것이 아니므로 앱 안 웹 표시 수단의 로그인 정보를 지우지 않는다.

저장된 값은 지우지 않으므로 그 프로필이 다시 목록에 나타나면 이전 선택이 그대로 되살아난다. 사용자가 다른 프로필을 고르면 저장된 값이 새 선택으로 바뀐다. 사용자가 `선택 안 함`을 고르면 화면에 이미 `선택 안 함`이 선택된 것으로 표시되어 있어도 저장된 값을 지운다. 이는 사용자가 `선택 안 함`으로 되돌린 것이므로 앱 안 웹 표시 수단의 로그인 정보를 지우며, 이후 그 프로필이 목록에 나타나도 이전 선택은 되살아나지 않는다.

설정이 적용되는 범위와 가져오는 규칙은 [Chrome 로그인 이어받기 스펙](./chrome-session-import.md)을 따른다.

## data

### 저장 시점과 유지

사용자가 항목을 고르면 그 선택이 기기에 저장된다. 사용자가 한 번도 고르지 않았으면 저장된 값이 없고, 이때는 `선택 안 함`으로 다룬다. 저장된 값의 유지와 읽지 못했을 때의 구분은 [기기 설정 화면 공통 스펙](./device-setting.md)의 `저장 시점과 유지`를 따른다.

### 기기별 보관

선택은 [기기 설정 화면 공통 스펙](./device-setting.md)의 `기기별 보관`을 따른다.

### 환경별 저장 영역

설정을 제공하는 데스크톱 앱은 [기기 설정 화면 공통 스펙](./device-setting.md)의 `환경별 저장 영역`이 정한 데스크톱 앱의 저장 영역을 쓴다.
