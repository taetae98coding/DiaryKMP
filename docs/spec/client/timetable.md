# Timetable 컴포넌트 스펙

이 문서는 하루 또는 한 주의 날짜를 시간대별로 보여 주는 공용 컴포넌트 Timetable의 사용자 관점 동작과 정책을 다룬다. 이 컴포넌트를 어느 화면에 배치하는지, 어떤 아이템을 어느 자리에 지정하는지, 아이템을 선택했을 때의 다음 행동은 배치하는 화면의 스펙에서 다룬다. 사용자 데이터의 생성이나 저장이 없어 `data` 영역은 생략한다.

디자인: [Timetable 컴포넌트 디자인](../../design/timetable.md)

## feature

### 형식

배치하는 화면은 Timetable을 하루 형식과 주간 형식 중 하나로 표시한다.

- 하루 형식은 날짜 하나를 표시한다.
- 주간 형식은 일요일부터 토요일까지 한 주의 일곱 날짜를 표시한다.

형식별 날짜 구성은 `domain`의 표시 날짜를 따른다. 형식은 배치하는 화면이 정하며, Timetable 안에서 사용자가 형식을 바꾸지 않는다.

### 시작 날짜

배치하는 화면이 지정한 날짜를 먼저 표시한다. 주간 형식은 지정한 날짜가 속한 주를 먼저 표시한다.

### 날짜 안내

사용자는 표시된 각 날짜의 요일과 일을 확인할 수 있다.

배치하는 화면이 현재 시각을 지정하면 그 시각이 속한 날짜를 주요 날짜로 강조한다. 현재 시각을 지정하지 않으면 강조하는 날짜가 없다.

### 시간대 안내

Timetable은 하루 24시간의 시간대를 한 시간 간격으로 안내하고, 날짜마다 그 시간대에 놓인 아이템을 표시한다.

하루 전체를 한 번에 볼 수 없으면 사용자는 위아래로 스크롤해 나머지 시간대를 확인한다. 시간대 안내는 아이템과 함께 스크롤되어 항상 같은 높이의 시간대를 가리킨다.

Timetable이 처음 표시되면 오전 8시부터 보인다. 다른 날짜로 이동해도 사용자는 보던 시간대를 그대로 이어서 본다.

### 아이템 표시

배치하는 화면은 두 종류의 아이템을 여러 개 지정할 수 있다.

- 시각 아이템은 날짜 하나와 그 날의 시작 시각, 종료 시각을 가진다. 그 날짜의 열에서 시작 시각부터 종료 시각까지의 시간대를 차지한다.
- 종일 아이템은 날짜 기간을 가진다. 시간대 위의 종일 영역에서 기간에 해당하는 날짜에 걸쳐 하나로 이어 표시하므로, 여러 날에 걸친 종일 아이템은 어느 날짜 부분을 눌러도 같은 아이템이 선택된다.

시간대가 겹치는 시각 아이템은 서로 가리지 않고 같은 날짜의 열을 나누어 나란히 표시한다. 종일 영역에서 기간이 겹치는 아이템은 서로 다른 줄에 표시한다. 배치 기준은 `domain`의 시각 아이템 배치와 종일 영역 배치를 따른다.

지정이 바뀌면 사용자가 별도 조작을 하지 않아도 표시가 갱신된다. 배치하는 화면이 아이템을 지정하지 않으면 시간대 안내와 빈 시간표만 표시하고, 빈 상태 안내는 따로 표시하지 않는다.

### 날짜 이동

사용자는 Timetable을 좌우로 넘겨 표시 날짜를 옮길 수 있다. 오른쪽에서 왼쪽으로 넘기면 다음, 왼쪽에서 오른쪽으로 넘기면 이전으로 이동한다.

- 하루 형식은 한 번에 하루씩 이동한다.
- 주간 형식은 한 번에 한 주씩 이동한다.

이동할 수 있는 범위는 `domain`의 이동 범위를 따른다.

### 날짜 이동 요청

배치하는 화면은 Timetable이 이전이나 다음으로 이동하도록 요청할 수 있다. 요청하면 사용자가 별도 조작을 하지 않아도 이동한 날짜가 표시된다. 이동 범위의 처음에서 이전을 요청하면 표시 날짜가 그대로 유지된다.

배치하는 화면은 Timetable이 지금 표시 중인 날짜를 알 수 있다.

### 현재 시각 표시

배치하는 화면이 현재 시각을 지정하고 표시 중인 날짜에 그 시각의 날짜가 있으면, 사용자는 그 날짜의 열에서 현재 시각의 위치를 확인할 수 있다. 지정한 현재 시각이 바뀌면 사용자가 별도 조작을 하지 않아도 위치가 따라 움직인다.

그 날짜가 표시되지 않거나 현재 시각을 지정하지 않으면 현재 시각 위치를 표시하지 않는다.

## domain

### 표시 날짜

하루 형식의 표시 날짜는 날짜 하나다.

주간 형식의 표시 날짜는 일요일에 시작해 토요일에 끝나는 7일이다. 주의 구성은 [CalendarWeekOfMonth 컴포넌트 스펙](./calendar-week-of-month.md)의 `주의 구성 기준`과 같다. 한 주가 두 달에 걸쳐도 그 주의 일곱 날짜를 모두 표시한다.

### 이동 범위

하루 형식은 1년 1월 1일이 속한 주의 일요일보다 이전 날짜로, 주간 형식은 1년 1월 1일이 속한 주보다 이전 주로 이동할 수 없다. [Calendar 컴포넌트 스펙](./calendar.md)의 `이동 범위`에 따라 가장 이른 달인 1년 1월의 캘린더에도 그 주의 일요일부터 보이므로, 캘린더에 보이는 날짜는 모두 Timetable의 시작 날짜로 지정할 수 있다. 다음 방향으로는 사실상 제한 없이 이동할 수 있다. 배치하는 화면이 이동 범위보다 이른 날짜를 시작 날짜로 지정하면 이동 범위의 처음을 표시한다.

### 시각 아이템 시간대

시각 아이템은 그 날짜의 열에서 시작 시각부터 종료 시각까지를 차지한다. 예를 들어 10시부터 11시 30분까지인 아이템은 10시 위치에서 시작해 11시 30분 위치에서 끝난다.

시작 시각과 종료 시각이 같거나 기간이 아주 짧아도 사용자가 알아보고 선택할 수 있는 최소 길이인 30분을 차지한다. 최소 길이 때문에 하루의 끝을 넘어가면 하루의 끝에서 끝나도록 앞으로 당긴다.

### 시각 아이템 배치

같은 날짜에서 `시각 아이템 시간대`로 정한 차지하는 시간대가 겹치는 시각 아이템은 나란히 놓는다. 최소 길이로 늘어난 부분도 차지하는 시간대에 포함한다. 한 아이템이 차지하는 시간대의 끝과 다른 아이템이 차지하는 시간대의 시작이 같으면 겹치지 않는 것으로 본다.

서로 직접 또는 다른 아이템을 거쳐 겹치는 시각 아이템을 한 묶음으로 본다. 묶음 안에서는 다음 순서로 아이템을 놓는다.

1. 차지하는 시간대의 시작이 이른 아이템부터 놓는다.
2. 시작이 같으면 차지하는 시간대의 끝이 늦은 아이템부터 놓는다.
3. 그래도 같으면 배치하는 화면이 먼저 지정한 아이템부터 놓는다.

각 아이템은 이미 놓인 아이템과 시간이 겹치지 않는 가장 왼쪽 칸에 놓는다. 묶음이 쓰는 칸의 수만큼 날짜 열의 너비를 똑같이 나누므로, 한 묶음의 아이템은 모두 같은 너비를 가진다. 겹치는 아이템이 없는 시각 아이템은 날짜 열의 너비 전체를 쓴다.

### 종일 영역 배치

종일 아이템은 표시 중인 날짜와 겹치는 부분만 차지한다. 주간 형식에서 기간이 그 주 밖으로 이어지면 그 주 안쪽 날짜까지만 표시하고, 하루도 겹치지 않는 아이템은 표시하지 않는다.

줄 배치는 [CalendarWeekOfMonth 컴포넌트 스펙](./calendar-week-of-month.md)의 `아이템 줄 배치`를 표시 중인 날짜 범위에 그대로 적용한다. 기간이 겹치지 않는 아이템은 같은 줄에, 하루라도 겹치는 아이템은 서로 다른 줄에 놓인다.

표시 중인 날짜와 겹치는 종일 아이템이 없으면 종일 영역을 두지 않는다.

### 보던 날짜와 시간대 유지

화면 회전처럼 화면이 재생성되어도 사용자는 보던 형식과 날짜, 시간대를 그대로 본다. 시스템이 앱을 정리했다가 다시 만들어도 마찬가지다.
