# Playlist 목록·상세 배치 스펙

이 문서는 곡 목록과 상세 영역을 함께 사용할 때 이 배치에만 해당하는 상세 영역 구성, 뒤로가기와 초기화 경계를 다룬다. 함께 사용과 단독 사용, 추가 진입 수단, 표시 비율 조절, 배치에 참여하는 화면과 유지·초기화의 공통 기준은 [목록·상세 배치 공통 스펙](./list-detail-pane.md)을 따른다. 각 화면의 내용과 행동은 [PlaylistHome 화면 스펙](./playlist-home.md), [MusicAdd 화면 스펙](./music-add.md), [MusicDetail 화면 스펙](./music-detail.md)에서 다룬다.

디자인: [Playlist 목록·상세 배치 디자인](../../design/playlist-list-detail.md)

표시 비율은 화면 표시 상태일 뿐 사용자 데이터를 만들거나 저장하지 않으므로 `data` 영역은 생략한다.

## feature

### 상세 영역의 구성

목록과 상세 영역을 함께 표시하는 상태에서 상세 영역에는 사용자가 선택한 곡의 상세가 표시되고, 선택한 곡이 없으면 곡 추가가 표시된다.

선택한 곡이 없는 동안 사용자는 목록을 떠나지 않고 곧바로 링크, 제목과 가수를 입력한다. 추가에 성공한 뒤에도 상세 영역은 곡 추가로 남으므로 사용자는 다음 곡을 이어서 작성하고, 방금 추가한 곡이 목록에 나타나는 것을 같은 화면에서 확인한다. 추가 성공 후의 입력 상태는 [MusicAdd 화면 스펙](./music-add.md)의 `곡 추가`를 따른다.

목록에서 곡을 선택하면 상세 영역이 그 곡의 상세로 바뀐다. 상세 영역에서 뒤로가기를 실행하거나 그 곡을 삭제하면 상세 영역은 선택한 곡이 없을 때의 화면인 곡 추가로 되돌아간다.

상세 영역에 곡 상세가 놓여 있는 동안 사용자가 목록에서 곡 추가를 실행하면 상세 영역이 곡 추가로 바뀌고 선택한 곡이 없는 상태가 된다. 그 기준은 [목록·상세 배치 공통 스펙](./list-detail-pane.md)의 `추가 진입 수단`을 따른다. 이렇게 연 곡 추가에서 뒤로가기를 실행하면 상세 영역은 곡 추가를 열기 전에 보던 곡 상세로 돌아간다.

한 영역만 표시되는 상태에서는 해당 화면 스펙의 행동을 그대로 제공하며, 화면 사이의 이동은 [PlaylistHome 화면 스펙](./playlist-home.md)의 `곡 추가로 이동`과 `곡 상세로 이동`을 따른다.

### 뒤로가기

상세 영역에서 시스템 뒤로가기를 사용하면 목록은 그대로 유지되고 상세 영역만 `상세 영역의 구성`이 정한 대로 되돌아간다.

곡 목록의 뒤로가기 동작을 사용하면 상세 영역에 어떤 화면이 놓여 있는지와 관계없이 이 배치 전체를 떠나 `더보기` 화면으로 돌아간다. 상세 영역만 되돌아가지 않으며, 결과는 [PlaylistHome 화면 스펙](./playlist-home.md)의 `뒤로가기`를 따른다.

### 정렬 선택

목록에서 정렬 기준을 고르는 행동은 배치와 관계없이 [PlaylistHome 화면 스펙](./playlist-home.md)의 `정렬 선택`을 따른다. 상세 영역에 곡 추가나 곡 상세가 함께 놓여 있어도 목록의 정렬 줄은 그대로 사용할 수 있다.

## domain

### 유지와 초기화 기준

사용자가 `더보기` 화면으로 돌아가는 것을 이 배치를 떠난 것으로 본다. 그 뒤 플레이리스트 화면에 다시 진입하거나 앱을 종료하고 다시 실행하면 [목록·상세 배치 공통 스펙](./list-detail-pane.md)의 `유지와 초기화 기준`에 따라 상세 선택을 선택 전 상태로, 표시 비율을 기본 비율로 초기화한다. 상세 선택이 초기화되면 상세 영역은 곡 추가로 돌아간다.

선택한 곡이 없을 때 상세 영역에 놓이는 곡 추가의 작성 내용도 이 배치의 기준을 따른다. 이 배치를 떠나기 전까지는 상세 영역에서 곡 상세를 보고 돌아와도 입력하던 링크, 제목과 가수가 그대로 남는다. `더보기` 화면으로 돌아갔다가 플레이리스트 화면에 다시 진입하면 상세 영역의 곡 추가는 링크, 제목과 가수가 비어 있는 상태로 시작한다.

그 밖에 상세 영역에서 작성 중이던 내용을 어디까지 유지하는지는 [MusicAdd 화면 스펙](./music-add.md)의 `작성 상태 유지 대상`과 [MusicDetail 화면 스펙](./music-detail.md)의 `진행 상태 유지 기준`을 따른다.
