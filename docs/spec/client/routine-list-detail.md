# Routine 목록·상세 배치 스펙

이 문서는 루틴 주요 목적지에서 루틴 목록과 상세 영역을 함께 사용할 때 이 배치에만 해당하는 상세 영역 구성과 초기화 경계를 다룬다. 함께 사용과 단독 사용, 추가 진입 수단, 표시 비율 조절, 배치에 참여하는 화면과 유지·초기화의 공통 기준은 [목록·상세 배치 공통 스펙](./list-detail-pane.md)을 따른다. 각 화면의 내용과 행동은 [RoutineHome 화면 스펙](./routine-home.md)과 [RoutineAdd 화면 스펙](./routine-add.md)에서 다룬다.

디자인: [Routine 목록·상세 배치 디자인](../../design/routine-list-detail.md)

표시 비율은 화면 표시 상태일 뿐 사용자 데이터를 만들거나 저장하지 않으므로 `data` 영역은 생략한다.

## feature

### 상세 영역의 구성

루틴 상세는 아직 제공하지 않으므로 상세 영역에는 언제나 루틴 추가가 놓인다. 사용자는 목록을 떠나지 않고 곧바로 제목과 설명을 입력한다.

한 화면만 제공하는 환경에서 화면 사이의 이동은 [RoutineHome 화면 스펙](./routine-home.md)의 `루틴 추가로 이동`을 따른다.

## domain

### 유지와 초기화 기준

루틴은 주요 목적지이므로 공통 내비게이션에서 다른 주요 목적지로 이동하는 것을 이 배치를 떠난 것으로 본다. 다른 주요 목적지에 다녀와 루틴으로 돌아오거나 앱을 종료하고 다시 실행하면 [목록·상세 배치 공통 스펙](./list-detail-pane.md)의 `유지와 초기화 기준`에 따라 표시 비율을 기본 비율로 초기화한다.

상세 영역에 놓인 루틴 추가의 작성 내용도 이 배치의 기준을 따른다. 다른 주요 목적지에 다녀와 루틴으로 돌아오면 상세 영역의 루틴 추가는 제목과 설명이 비어 있는 상태로 시작한다. 화면 재생성에서 무엇이 남는지는 [RoutineAdd 화면 스펙](./routine-add.md)의 `작성 상태 유지`를 따른다.
