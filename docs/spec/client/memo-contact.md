# 메모 연락처 앱 스펙

이 문서는 메모와 연락처의 연결 가운데 앱이 기기에 저장된 연결로 메모의 연락처와 연락처의 메모를 조회하는 규칙과, 이 연결이 앱의 목록과 검색 결과에 주는 영향을 다룬다. 메모와 연락처의 연결이 공통으로 지키는 규칙은 [메모 연락처 스펙](../common/memo-contact.md)을, 연결의 성질과 동기화 계약은 [항목 연결 공통 스펙](../common/entity-link.md)을, 연결을 기기에 저장하는 규칙은 [항목 연결 앱 스펙](./entity-link.md)을 따른다.

사용자가 연락처를 고르고 해제하는 조작과 조회 결과를 보여 주는 화면은 각 입력 컴포넌트 스펙과 화면 스펙이 소유하므로 이 문서에는 `feature` 영역을 두지 않는다.

## domain

### 연결된 연락처의 정렬

메모를 기준으로 조회한 연락처는 이름 오름차순으로 놓는다. 이름이 같은 연락처끼리의 순서는 정하지 않는다.

연락처의 즐겨찾기 여부는 이 정렬에 영향을 주지 않는다. 즐겨찾기를 앞세우는 순서는 [ContactHome 화면 스펙](./contact-home.md)의 `목록 정렬`이 그 목록에만 정한 것이다.

조회에 포함되는 연결과 연락처의 기준은 [항목 연결 공통 스펙](../common/entity-link.md)의 `연결된 항목의 조회`를 따른다.

### 연결의 의미

[항목 연결 공통 스펙](../common/entity-link.md)의 `연결의 의미`는 메모와 연락처의 연결에서 다음 목록에 적용된다.

- [MemoHome 목록 스펙](./memo-home.md)의 목록 노출 기준과 정렬. 연락처 연결 여부는 [태그 필터 스펙](./tag-filter.md)과 MemoHome의 유무 필터 대상도 아니다.
- [ContactHome 화면 스펙](./contact-home.md)의 목록 노출 기준과 정렬
- [SearchHome 화면 스펙](./search-home.md)의 메모 검색 결과
- [캘린더 연락처 생일 표시 스펙](./calendar-contact-birthday.md)의 노출 기준
- 태그로 메모를 조회한 결과

연락처로 메모를 조회하는 [ContactDetail 메모 탭 스펙](./contact-detail-memo.md)의 목록은 이 연결을 노출 기준으로 쓴다.

연락처를 메모에 연결해도 그 연락처가 연결된 메모의 기간에 나타나지 않고, 그 메모가 연락처의 생일에 나타나지도 않는다.

## data

### 메모별 연락처 표시

메모로 연락처를 조회할 때는 현재 사용자 계정과 연결된 연락처와 메모-연락처 연결만 사용한다. 조회에 포함되는 연결과 연락처의 기준은 [항목 연결 공통 스펙](../common/entity-link.md)의 `연결된 항목의 조회`를 따른다.

연결이 만들어지거나 해제되거나 복구되면 그 메모의 연락처를 표시하는 화면과 그 연락처의 메모를 표시하는 화면은 변경된 연결 상태를 반영한다.

### 연락처별 메모 표시

연락처로 메모를 조회할 때는 현재 사용자 계정과 연결된 메모와 메모-연락처 연결만 사용한다. 조회에 포함되는 연결과 메모의 기준은 [항목 연결 공통 스펙](../common/entity-link.md)의 `연결된 항목의 조회`를 따르며, 그 위에 더하는 노출 기준과 정렬은 [항목 상세 메모 탭 공통 스펙](./entity-detail-memo.md)이 정한다.
