# SettingMcp 화면 스펙

이 문서는 사용자가 설정 화면의 `MCP` 항목에서 진입하는 SettingMcp 화면의 내용과 행동을 다룬다. 기기에 보관하는 설정 화면의 공통 행동과 저장 영역은 [기기 설정 화면 공통 스펙](./device-setting.md)을 따르고, 이 문서에는 이 설정에만 해당하는 내용을 둔다. 설정 항목의 표시와 선택은 [SettingHome 화면 스펙](./setting-home.md)에서, 설정 목록과 함께 사용할 때의 선택·뒤로가기 정책은 [Setting 목록·상세 배치 스펙](./setting-list-detail.md)에서, 세부 화면에서의 공통 내비게이션 노출 규칙은 [TopLevelNavigation 스펙](./top-level-navigation.md)에서 다룬다. 연결 주소와 연결 상태는 [AI 도구 연결 스펙](./mcp-server.md)에서, AI 도구에 제공하는 기능은 [AI 도구 제공 공통 스펙](./ai-tool.md)에서 다룬다.

디자인: [SettingMcp 화면 디자인](../../design/setting-mcp.md)

이번 범위는 사용자가 AI 도구 연결을 켜고 끄며, 연결 상태와 주소를 확인하고 주소를 복사하는 것까지다.

## feature

### 진입과 이동

사용자는 설정 화면의 `MCP` 항목을 선택해 SettingMcp 화면으로 이동한다.

표시 관계는 [기기 설정 화면 공통 스펙](./device-setting.md)의 `표시 관계`를 따른다.

이 화면은 데스크톱 앱에서만 진입할 수 있다. 제공 환경은 [AI 도구 연결 스펙](./mcp-server.md)의 `제공 환경`을 따른다.

### 연결 켜고 끄기

사용자는 AI 도구 연결이 켜져 있는지 확인하고 켜거나 끌 수 있다. 처음에는 꺼져 있다.

켜고 끄는 행동, 저장 실패와 화면에 보이는 값은 [기기 설정 화면 공통 스펙](./device-setting.md)의 `고르면 바로 저장하는 설정`과 `화면에 보이는 값`을 따른다. 저장되면 연결이 바로 시작되거나 끝나며, 앱을 다시 시작할 필요가 없다.

화면은 연결을 켜면 같은 Mac의 AI 도구가 확인 없이 현재 계정의 메모와 항목을 조회하고, 추가, 수정, 삭제할 수 있다는 것을 알린다. 이 안내는 연결이 켜져 있든 꺼져 있든 항상 보인다.

저장된 설정을 확인하기 전이거나 읽지 못했을 때는 [기기 설정 화면 공통 스펙](./device-setting.md)의 `저장된 값을 확인하기 전`에 따라 켜고 끄는 기능과 연결 상태를 표시하지 않는다.

### 연결 상태 확인

사용자는 지금 연결 상태를 확인한다. 연결 상태는 [AI 도구 연결 스펙](./mcp-server.md)의 `연결 동작 상태`를 따른다.

| 연결 상태 | 표시 |
| --- | --- |
| 꺼짐 | 연결이 꺼져 있다는 것 |
| 동작 중 | 연결이 동작 중이라는 것과 연결 주소 |
| 시작 실패, 주소를 다른 프로그램이 쓰고 있음 | 연결 주소를 다른 프로그램이 쓰고 있어 시작하지 못했다는 것과 그 주소 |
| 시작 실패, 그 밖의 이유 | 연결을 시작하지 못했다는 것 |

연결 상태가 바뀌면 새로고침하지 않아도 바로 바뀐 상태를 보여 준다. 화면을 당겨서 새로고침하는 수단은 두지 않는다.

시작에 실패했을 때 사용자는 연결을 껐다가 다시 켜서 다시 시도할 수 있다.

### 주소 복사

연결이 동작 중일 때 사용자는 연결 주소를 복사할 수 있다. 복사하면 복사되었다는 피드백을 제공한다. 사용자는 복사한 주소를 AI 도구에 등록한다.

### 뒤로가기

뒤로가기 결과와 바꾼 설정의 유지는 [기기 설정 화면 공통 스펙](./device-setting.md)의 `뒤로가기`를 따른다. 화면을 떠나도 연결은 설정에 따라 계속 동작한다.

## domain

### 연결 사용 설정

연결 사용 설정은 앱이 실행되는 동안 AI 도구 연결을 동작시킬지 정하는 값이며, 켬과 꺼짐 중 하나다.

사용자가 한 번도 바꾸지 않았으면 꺼짐이다. 사용자가 모르는 사이에 데이터가 AI 도구에 열리지 않게 하기 위한 것이다.

## data

### 저장 시점과 유지

사용자가 켜거나 끄면 그 값이 기기에 저장된다. 사용자가 한 번도 바꾸지 않았으면 저장된 값이 없고, 이때는 꺼짐으로 다룬다. 저장된 값의 유지와 읽지 못했을 때의 구분은 [기기 설정 화면 공통 스펙](./device-setting.md)의 `저장 시점과 유지`를 따른다.

### 기기별 보관

연결 사용 설정은 [기기 설정 화면 공통 스펙](./device-setting.md)의 `기기별 보관`과 `환경별 저장 영역`을 따른다. 개발용 앱과 운영용 앱은 이 설정을 따로 가진다.
