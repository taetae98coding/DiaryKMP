# 앱 이름 스펙

이 문서는 빌드 환경마다 사용자에게 보이는 앱 이름을 다룬다. 사용자가 직접 수행하는 행동은 없고 저장하는 데이터도 없으므로 `feature`와 `data` 영역은 생략한다.

## domain

### 빌드 환경별 앱 이름

앱 이름은 개발·운영 환경과 내부 확인용·배포용 빌드의 조합으로 정한다. 같은 기기에 여러 환경의 앱을 함께 설치해도 이름만으로 구분할 수 있어야 한다.

| 환경 | 빌드 | 앱 이름 |
| --- | --- | --- |
| 개발 | 내부 확인용 | `DiaryDev` |
| 개발 | 배포용 | `DiaryDev` |
| 운영 | 내부 확인용 | `DiaryRealDebug` |
| 운영 | 배포용 | `Diary` |

Android와 iOS는 위 표를 따른다. 내부 확인용과 배포용 빌드를 나누지 않는 데스크톱 앱과 웹은 환경만으로 정한다. 개발 환경은 `DiaryDev`, 운영 환경은 `Diary`를 쓴다.

### 앱 이름이 보이는 곳

- Android: 런처와 시스템 설정에 표시되는 앱 이름
- iOS: 홈 화면과 시스템 설정에 표시되는 앱 이름
- 데스크톱 앱: 창 제목과 설치 파일의 앱 이름
- 웹: 브라우저 탭 제목

앱 이름은 앱 데이터를 저장하는 위치를 정하지 않는다. 데스크톱 앱의 저장 위치는 [데스크톱 앱 데이터 저장 위치 스펙](./jvm-database-storage.md)을 따른다.
