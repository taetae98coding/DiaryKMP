# 파일 올리기 알림 스펙

이 문서는 파일을 올리는 동안과 올리기가 끝났을 때 앱이 기기에 보내는 알림과, 알림으로 앱을 여는 규칙을 다룬다. 올리기가 언제 시작되고 어떻게 끝나는지는 [파일 보관 스펙](./file-storage.md)이, 올리기를 시작하는 FileAdd 화면은 [FileAdd 화면 스펙](./file-add.md)이, 올린 파일을 확인하는 FileHome 화면은 [FileHome 화면 스펙](./file-home.md)이 소유한다.

알림을 보려면 알림 권한이 필요하고, 권한을 언제 어떻게 요청하는지는 [알림 권한 요청 스펙](./notification-permission.md)이 소유한다. 알림에 표시하는 문구와 표현은 [파일 올리기 알림 디자인](../../design/file-upload-notification.md)이 소유한다.

알림은 기기 안에서 만들어 보내며 서버를 거치지 않는다. 저장하거나 동기화하는 데이터가 없으므로 `data` 영역은 생략한다.

## feature

### 제공 범위

| 플랫폼 | 진행 알림 | 결과 알림 |
| --- | --- | --- |
| Android | 제공한다 | 제공한다 |
| iOS | 제공하지 않는다 | 제공한다 |
| 데스크톱 앱, 웹 | 제공하지 않는다 | 제공하지 않는다 |

iOS는 앱이 올리는 중인 파일의 진행을 알림으로 계속 보여 주는 수단을 제공하지 않으므로 결과만 알린다. 데스크톱 앱과 웹은 알림을 보내지 않으며, 알림을 제공하지 않는다는 안내도 표시하지 않는다. 두 환경에서 파일 화면을 보고 있지 않을 때 끝난 올리기의 결과는 다음에 목록을 처음부터 다시 불러올 때 목록으로 확인한다.

### 진행 알림

Android에서는 파일을 올리는 동안 올리는 파일의 이름과 진행을 보여 주는 알림이 표시된다. FileHome 화면을 보고 있는 동안에도 표시된다.

진행은 [파일 보관 스펙](./file-storage.md)의 `domain > 올리기 상태`가 정한 백분율로 보여 준다. 아직 보낸 양이 없으면 백분율 없이 올리는 중임만 보여 준다.

진행 알림은 올리기가 끝나거나 중단될 때까지 남아 있다. 올리기가 성공, 실패, 중단 중 무엇으로 끝나든 진행 알림은 사라진다.

시스템이 앱을 정리하거나 연결이 끊긴 뒤 같은 파일을 처음부터 다시 올리면 진행 알림도 다시 나타나고 백분율은 처음부터 다시 센다.

Android 시스템은 다음 경우에 진행 알림을 보여 주지 않거나 사용자가 지우게 둔다. 이때도 올리기는 [파일 보관 스펙](./file-storage.md)에 따라 그대로 진행되고, FileHome 화면의 진행 중 표시는 그대로 보인다.

- 앱이 화면 뒤에 있는 동안 올리기가 시작되면 시스템이 진행 알림을 띄우지 못하게 할 수 있다. 이때는 진행 알림 없이 올린다.
- Android 14 이상에서는 사용자가 진행 알림을 지울 수 있다. 지워도 올리기는 멈추지 않는다.

### 결과 알림

올리기가 성공하거나 실패로 끝났을 때 사용자가 파일 화면을 보고 있지 않으면 결과 알림을 보낸다. 파일 화면을 보고 있으면 결과 알림을 보내지 않고 보고 있는 화면에서 알린다. FileHome은 [FileHome 화면 스펙](./file-home.md)의 `feature > 올리기 결과`를, FileAdd는 [FileAdd 화면 스펙](./file-add.md)의 `feature > 올리기 결과`를 따른다.

| 결과 | 알림 내용 |
| --- | --- |
| 성공 | 파일을 올렸다는 안내와 올린 파일의 이름 |
| 고른 파일이 올릴 수 있는 크기를 넘어 실패 | 파일을 올리지 못했다는 안내와 올릴 수 있는 최대 크기 |
| 그 밖의 이유로 실패 | 파일을 올리지 못했다는 안내와 고른 파일의 이름. 파일 이름을 알 수 없으면 안내만 담는다 |

올리기가 중단되면 결과 알림을 보내지 않는다.

결과 알림은 하나만 남는다. 앞선 올리기의 결과 알림이 남아 있는 동안 다른 올리기가 끝나면 앞의 알림을 새 결과로 바꾼다.

### 앱을 사용하는 중에 받은 알림

앱을 화면에 띄워 파일 화면이 아닌 다른 화면을 보고 있는 동안 올리기가 끝나도, 앱을 사용하지 않을 때와 같은 방식으로 결과 알림이 표시된다. 앱 화면 안에는 따로 안내를 표시하지 않고, 보고 있던 화면도 바뀌지 않는다.

### 알림에서 앱 열기

사용자가 진행 알림이나 결과 알림을 선택하면 앱이 열리고 FileHome 화면이 보인다. 선택한 결과 알림은 알림 목록에서 사라진다. 진행 알림은 선택해도 올리기가 끝날 때까지 남는다.

FileHome 화면은 `더보기`에서 `파일` 바로가기를 선택한 것과 같은 자리에 열린다. 다른 주요 목적지를 보고 있었다면 [TopLevelNavigation 스펙](./top-level-navigation.md)의 `목적지 이동과 화면 상태`에 따라 `더보기`로 이동한 뒤 FileHome을 열고, 뒤로가면 `더보기`로 돌아간다. `더보기` 위에 FileHome이 아닌 다른 화면을 열어 두었으면 그 화면을 닫고 `더보기` 위에 FileHome을 연다. 이미 FileHome 화면을 보고 있었다면 그 화면을 그대로 유지하고 새로 열지 않는다. FileHome에서 연 FileAdd 화면을 보고 있었다면 FileAdd 화면과 적어 둔 내용을 그대로 유지한다. 앱이 화면 뒤에 있었고 마지막으로 보던 화면이 FileHome이나 FileHome에서 연 FileAdd였을 때도 같다.

앱이 실행 중이 아니었으면 앱이 시작되면서 FileHome 화면을 연다. 이때 FileHome 화면에서 보이는 내용은 [FileHome 화면 스펙](./file-home.md)의 `domain > 계정 상태에 따른 화면`을 따른다.

사용자가 알림을 선택하지 않고 지우거나 그대로 두어도 앱에서 달라지는 것은 없다.

## domain

### 파일 화면을 보고 있는 상태

파일 화면은 FileHome 화면과, FileHome에서 연 FileAdd 화면을 가리킨다. 앱이 기기의 화면 앞에 있고, 앱이 파일 화면 중 하나를 표시하고 있을 때 그 화면을 보고 있는 것으로 본다. 앱이 화면 뒤에 있거나, 시스템이 앱을 정리했거나, 앱이 파일 화면이 아닌 화면을 표시하고 있으면 보고 있지 않은 것으로 본다.

앱이 화면 앞에 있는지는 플랫폼마다 다음으로 판정한다.

| 플랫폼 | 앱이 화면 앞에 있음 |
| --- | --- |
| Android, iOS | 앱이 기기 화면에 보이고 있다 |
| 데스크톱 앱 | 앱 창이 최소화되어 있지 않다. 다른 창 뒤에 가려 있어도 화면 앞에 있는 것으로 본다 |
| 웹 | 앱을 연 탭이 보이고 있다 |

이 판정은 올리기가 끝나는 순간을 기준으로 한다. 올리기를 시작할 때 파일 화면을 보고 있었는지는 판정에 쓰지 않는다.

### 알림 권한

알림 권한이 허용되어 있어야 사용자에게 알림이 보인다. 권한이 허용되어 있지 않으면 알림은 사용자에게 보이지 않으며, 앱은 이를 사용자에게 따로 안내하지 않는다. 알림이 보이지 않아도 올리기는 [파일 보관 스펙](./file-storage.md)에 따라 그대로 진행된다.

### 알림 그만 받기

앱은 이 알림을 끄는 설정을 제공하지 않는다. 사용자가 알림을 그만 받으려면 시스템의 알림 설정에서 이 앱의 알림을 끈다. Android에서는 파일 올리기 알림만 따로 끌 수도 있다. 시스템에서 알림을 끄면 알림이 보이지 않고, 그 밖에 앱에서 할 수 있는 행동은 줄어들지 않는다.
