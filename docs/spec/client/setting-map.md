# SettingMap 화면 스펙

이 문서는 사용자가 설정 화면의 `지도` 항목에서 진입하는 SettingMap 화면의 내용과 행동을 다룬다. 설정 항목의 표시와 선택은 [SettingHome 화면 스펙](./setting-home.md)에서, 설정 목록과 함께 사용할 때의 선택·뒤로가기 정책은 [Setting 목록·상세 배치 스펙](./setting-list-detail.md)에서, 세부 화면에서의 공통 내비게이션 노출 규칙은 [TopLevelNavigation 스펙](./top-level-navigation.md)에서 다룬다. 지도 자체의 표시와 지도 위에서의 제공자 전환은 [DiaryMap 컴포넌트 스펙](./diary-map.md)에서, 기본 지도 설정을 지도 화면이 사용하는 방식은 [PlaceHome 화면 스펙](./place-home.md)에서 다룬다.

디자인: [SettingMap 화면 디자인](../../design/setting-map.md)

이번 범위는 사용자가 기본 지도를 고르고 그 선택이 기기에 유지되는 것까지다.

## feature

### 진입과 이동

사용자는 설정 화면의 `지도` 항목을 선택해 SettingMap 화면으로 이동한다.

SettingMap 화면은 설정 목록과 함께 표시되거나 단독으로 표시될 수 있다. 두 상태 모두 공통 내비게이션을 제공하지 않으며, 표시 관계는 [Setting 목록·상세 배치 스펙](./setting-list-detail.md)을 따른다.

### 기본 지도 선택

사용자는 `네이버`, `Google` 순서로 제공되는 지도 중 현재 기본 지도를 확인하고 하나를 고를 수 있다.

선택하지 않은 지도를 고르면 기본 지도가 즉시 저장되고 선택 상태가 바뀐다. 이미 선택한 지도를 다시 고르면 아무것도 바뀌지 않는다.

화면의 선택 상태는 저장된 기본 지도를 따른다. 저장에 실패하면 이전 선택을 유지하며 별도 오류 상태로 전환하지 않는다.

저장된 기본 지도를 확인하기 전이거나 읽지 못했으면 기본 지도 선택 기능을 제공하지 않으며 별도 로딩 또는 오류 상태로 전환하지 않는다.

이 화면에서는 지도를 직접 표시하지 않는다.

현재 선택은 저장된 기본 지도를 따르므로 사용자가 고르면 새로고침 없이 바로 바뀐 선택을 보여 준다. 이 화면에는 당겨서 새로고침하는 수단이 없다.

### 뒤로가기

단독으로 표시될 때와 설정 목록과 함께 표시될 때의 뒤로가기 결과는 모두 [Setting 목록·상세 배치 스펙](./setting-list-detail.md)의 `뒤로가기`를 따른다.

바꾼 기본 지도는 뒤로가기로 화면을 떠나도 그대로 유지되며, 되돌리기 위한 별도 동작은 제공하지 않는다.

## domain

### 기본 지도

기본 지도는 지도를 보여 주는 화면이 처음 표시할 지도 제공자를 정하는 설정이다.

고를 수 있는 지도는 [DiaryMap 컴포넌트](./diary-map.md)가 제공하는 네이버 지도와 Google 지도 두 가지이며, 같은 시점에 기본 지도는 하나다.

사용자가 한 번도 기본 지도를 고르지 않았으면 네이버 지도를 기본으로 사용한다.

두 지도는 어느 환경에서든 기본 지도로 고를 수 있다. 특정 환경에서 지도가 표시되지 않는 것은 선택 가능 여부와 무관하다.

### 설정 적용 범위

기본 지도는 지도를 보여 주는 화면에 처음 들어올 때 적용된다.

사용자가 지도 화면에서 제공자를 일시적으로 전환해도 기본 지도 설정은 바뀌지 않는다. 기본 지도를 바꾸는 방법은 SettingMap 화면에서 고르는 것뿐이다.

## data

### 저장 시점과 유지

사용자가 지도를 고르면 그 선택이 기기에 저장된다. 사용자가 한 번도 고르지 않았으면 저장된 값이 없고, 이때는 네이버 지도를 기본으로 다룬다.

저장된 기본 지도는 화면을 떠나거나 화면이 재생성되어도, 앱이 백그라운드에 다녀와도, 앱을 종료하고 다시 시작해도 유지된다.

저장된 값을 읽을 수 없으면 기본 지도를 아직 확인하지 못한 상태로 다룬다. 이는 저장된 값이 없어 네이버 지도를 기본으로 다루는 것과 구분된다.

### 기기별 보관

기본 지도는 사용자 계정이 아니라 기기에 보관하며 서버와 동기화하지 않는다. 로그인, 로그아웃, 계정 전환으로 바뀌지 않으며 다른 기기에도 반영되지 않는다.

기본 지도는 [데이터 동기화 스펙](../common/data-sync.md)의 동기화 대상이 아니다.

### 환경별 저장 영역

각 환경에서 기본 지도를 보관하는 영역은 다음과 같다.

| 환경 | 저장 영역 | 사라지는 경우 |
| --- | --- | --- |
| Android | 앱 저장 영역 | 앱을 삭제하거나 앱 데이터를 지우면 |
| iOS | 앱 저장 영역 | 앱을 삭제하면 |
| 데스크톱 앱 | 기기에 저장한 자료와 같은, 개발용 앱과 운영용 앱을 나눈 저장 영역 | 저장 영역을 지우면 |
| 웹 | 브라우저의 사이트 저장 영역 | 브라우저의 사이트 저장 영역을 지우면 |

데스크톱 앱은 [데스크톱 앱 데이터 저장 위치 스펙](./jvm-database-storage.md)이 정한, 개발용 앱과 운영용 앱을 나눈 저장 위치를 사용하므로 두 앱은 서로 다른 기본 지도를 가진다.

웹에서는 같은 브라우저의 페이지 새로 고침이나 탭 재진입을 넘어 설정이 유지된다. 다른 브라우저나 시크릿 모드처럼 사이트 저장 영역이 분리된 환경에서는 기본 지도를 따로 가진다.
