# TagFinishedList 목록·상세 배치 스펙

이 문서는 TagFinishedList 화면에서 완료된 태그 목록과 상세를 함께 사용할 때 이 배치에만 해당하는 상세 선택 상태, 뒤로가기와 초기화 경계를 다룬다. 함께 사용과 단독 사용, 표시 비율 조절, 배치에 참여하는 화면과 유지·초기화의 공통 기준은 [목록·상세 배치 공통 스펙](./list-detail-pane.md)을 따른다. 목록 화면 자체의 내용과 행동은 [TagFinishedList 화면 스펙](./tag-finished-list.md)을, 상세 영역에 표시되는 화면의 내용과 행동은 [TagDetail 화면 스펙](./tag-detail.md)을 따른다.

TagHome에서 사용하는 목록·상세 배치는 [Tag 목록·상세 배치 스펙](./tag-list-detail.md)에서 다룬다. 이 화면은 TagHome 목록과 함께 표시하지 않으며, TagHome 목록의 배치 대신 이 배치를 사용한다.

디자인: [TagFinishedList 목록·상세 배치 디자인](../../design/tag-finished-list-detail.md)

선택 상태와 표시 비율은 화면 표시 상태일 뿐 사용자 데이터를 만들거나 저장하지 않으므로 `data` 영역은 생략한다.

## feature

### 상세 영역의 구성

아직 태그를 선택하지 않았으면 상세는 선택 전 상태다. 선택 전 상태에서는 목록에서 태그를 선택하라는 안내만 제공하고 사용자가 실행할 수 있는 동작은 제공하지 않는다.

사용자가 목록에서 태그를 선택하면 그 태그의 상세 화면이 현재 상세가 된다. 상세 영역에 이미 태그 상세가 놓여 있으면 그 자리를 새로 고른 태그의 상세로 바꾸며, 앞서 본 태그 상세들을 뒤에 쌓아 두지 않는다. 상세 영역에서 이어 연 태그 상세와 태그 추가도 함께 정리되므로, 목록에서 고른 태그의 상세에서 뒤로가면 선택 전 상태로 돌아간다.

상세 영역의 태그 상세에서 연결 입력으로 연 태그 추가와 연결한 태그의 상세는 상세 영역에 놓인다. 이 중 이전 상세로 돌아가는 동작을 제공하는 화면은 [TagDetail 화면 스펙](./tag-detail.md)의 `뒤로가기`가 정하며, 그 결과는 [Tag 목록·상세 배치 스펙](./tag-list-detail.md)에서 태그 상세가 상세 영역에 놓였을 때와 같다.

상세 영역의 태그 상세에서 메모·웹·장소 탭으로 연 화면과 완료된 메모 목록은 이 배치에 참여하지 않는다. 그 화면을 어떻게 표시하는지는 [TagDetail 메모 탭 스펙](./tag-detail-memo.md), [TagDetail 웹 탭 스펙](./tag-detail-web.md), [TagDetail 장소 탭 스펙](./tag-detail-place.md)과 [TagMemoFinishedList 목록·상세 배치 스펙](./tag-memo-finished-list-detail.md)을 따르며, [Tag 목록·상세 배치 스펙](./tag-list-detail.md)에서 태그 상세가 상세 영역에 놓였을 때와 같다. 그 화면에서 뒤로가면 이 배치로 돌아오며, 상세 영역에는 떠나기 전의 태그 상세가 그대로 놓여 있다.

상세 영역의 태그 상세에서 태그를 다시 시작하면 그 태그는 [완료 목록 공통 스펙](./finished-list.md)의 `노출 기준`에 따라 목록에서 사라지지만, 상세 영역의 태그 상세는 [TagDetail 화면 스펙](./tag-detail.md)의 `완료와 다시 시작`에 따라 그대로 남는다.

상세 영역의 태그 상세에서 태그를 삭제하면 상세 영역은 `뒤로가기`와 같이 그 전에 놓였던 상태로 되돌아간다.

이 화면에서는 태그를 추가할 수 없으므로 선택 전 상태에 태그 추가 화면이 표시되지 않고, 목록에서 추가를 실행하는 수단도 두지 않는다. 그 기준은 [완료 목록 공통 스펙](./finished-list.md)의 `추가 미제공`을 따른다.

### 함께 사용할 때의 행동

목록과 상세를 함께 사용하는 동안에도 주요 목적지의 공통 내비게이션은 제공하지 않는다.

### 뒤로가기

상세가 선택된 상태에서 뒤로가면 목록은 유지되고 상세는 직전 상태로 돌아간다.

태그 상세 화면을 다른 태그의 상세 화면으로 교체한 뒤 뒤로가면 이전에 선택했던 태그의 상세 화면으로 돌아가지 않고 선택 전 상태가 된다.

상세가 선택 전 상태일 때 뒤로가면 목록 화면 전체를 떠나 TagHome 목록으로 돌아간다.

목록 화면이 제공하는 뒤로가기 동작을 사용하면 상세 선택 여부와 관계없이 TagHome 목록으로 돌아간다.

## domain

### 배치에 참여하는 화면

이 배치에는 TagFinishedList 화면과 그 화면에서 진입한 태그 상세, 그리고 그 상세 영역에서 연결 입력으로 이어 연 태그 추가와 태그 상세만 참여한다. TagHome 목록, 메모 태그 입력, 태그 필터, 다른 항목의 태그 입력, SearchHome처럼 다른 곳에서 진입한 태그 상세와 태그 추가는 이 배치에 참여하지 않고 각 진입 화면의 기준을 따른다.

### 상세 선택

상세 영역이 가질 수 있는 상태는 선택 전 상태와 태그의 상세뿐이다. 태그의 상세는 목록에서 선택한 태그의 상세이며, 그 위에 연결 입력으로 이어 연 태그 추가와 태그 상세가 놓일 수 있다.

### 유지와 초기화 기준

사용자가 목록 화면을 떠나 TagHome 목록으로 돌아가는 것을 이 배치를 떠난 것으로 본다. 이 화면에서는 공통 내비게이션을 제공하지 않지만, 파일 올리기 알림을 선택해 `더보기` 위에 FileHome 화면이 열리는 것처럼 앱이 다른 주요 목적지를 여는 것도 이 배치를 떠난 것으로 본다. 그 이동의 결과는 [파일 올리기 알림 스펙](./file-upload-notification.md)의 `알림에서 앱 열기`와 [TopLevelNavigation 스펙](./top-level-navigation.md)의 `목적지 이동과 화면 상태`를 따르며, 그 뒤 태그로 돌아오면 TagHome 목록이 보인다. 그 뒤 목록 화면에 다시 진입하거나 앱을 종료하고 다시 실행하면 [목록·상세 배치 공통 스펙](./list-detail-pane.md)의 `유지와 초기화 기준`에 따라 상세 선택은 선택 전 상태로, 표시 비율은 기본 상태로 초기화한다.

상세 영역의 태그 상세에서 이어 연 화면에 다녀오는 것은 이 배치를 떠난 것으로 보지 않으며, 그 결과는 `feature > 상세 영역의 구성`을 따른다.
