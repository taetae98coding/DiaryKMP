# WebHome 화면 스펙

이 문서는 사용자가 `더보기`의 `웹` 메뉴에서 진입하는 WebHome 화면의 내용과 행동을 다룬다. 항목 목록 화면이 공통으로 따르는 노출 기준, 목록 갱신과 조회, 추가·상세로 이동, 목록에서의 삭제와 실행 취소, 화면 유지는 [항목 목록 화면 공통 스펙](./entity-home.md)를 따르며, 이 문서에는 웹 목록에만 있는 내용을 둔다. `더보기` 메뉴 영역의 표시와 선택은 [MoreHome 화면 스펙](./more-home.md)에서, 세부 화면에서의 공통 내비게이션 노출 규칙은 [TopLevelNavigation 스펙](./top-level-navigation.md)에서, 웹 항목을 작성해 추가하는 흐름과 웹 항목이 갖는 정보는 [WebAdd 화면 스펙](./web-add.md)에서, 선택한 웹 항목의 상세와 웹 페이지 불러오기는 [WebDetail 화면 스펙](./web-detail.md)에서, 웹 목록과 웹 추가를 함께 사용하는 배치는 [Web 목록·상세 배치 스펙](./web-list-detail.md)에서, 화면에서 검색으로 이동한 뒤의 내용과 행동은 [SearchHome 화면 스펙](./search-home.md)에서, 나누어 불러오는 목록이 나타나는 순서와 아직 준비되지 않은 자리의 처리는 [페이지 조회 목록의 자리 표시 스펙](./paged-list-placeholder.md)에서, 목록이 비어 있을 때의 안내는 [목록 빈 상태 스펙](./list-empty-state.md)에서, 목록을 당겨 새로고침하는 행동과 동기화 진행 표시는 [새로고침 스펙](./sync-refresh.md)에서, 웹 항목을 서버와 맞추는 규칙은 [데이터 동기화 스펙](../common/data-sync.md)에서 다룬다.

디자인: [WebHome 화면 디자인](../../design/web-home.md)

이번 범위는 `더보기`에서 WebHome으로 이동하고, 계정에 저장된 웹 항목을 기기에서 불러와 목록으로 표시하고, 목록을 당겨 새로고침하고, WebHome에서 웹 추가와 웹 상세와 검색으로 이동하고, 목록에서 웹 항목을 삭제하고 되돌리는 것까지다. 웹 항목을 수정하고 상세에서 삭제하는 흐름은 [WebDetail 화면 스펙](./web-detail.md)에서 다루며, 이 문서는 수정한 웹 항목이 목록에 반영되고 삭제한 웹 항목이 목록에서 사라지는 것을 다룬다.

## feature

### 진입

사용자는 `더보기` 화면의 메뉴 영역에서 `웹` 항목을 선택해 WebHome 화면으로 이동한다.

### 웹 목록

사용자는 WebHome에서 계정에 저장된 웹 항목 전체를 목록으로 볼 수 있다. 사용자는 각 항목의 제목과 URL을 확인한다.

웹 항목의 설명은 목록에 표시하지 않는다. 설명은 [WebAdd 화면 스펙](./web-add.md)의 `웹 항목의 정보`가 정의한 대로 웹 항목에 기록되지만, 목록에서는 어떤 웹 항목인지 알아보는 데 필요한 제목과 URL만 보여 준다.

목록이 나타나는 순서, 아직 준비되지 않은 자리와 추가한 웹 항목이 목록에 나타나는 조건은 [항목 목록 화면 공통 스펙](./entity-home.md)의 `목록 표시`를 따른다.

### 빈 상태

목록 불러오기가 끝났고 `domain`의 `목록에 노출하는 웹 항목`에 맞는 웹 항목이 하나도 없으면 목록 자리에 아직 웹 항목이 없으며 새로 추가할 수 있음을 알린다. 불러오는 중에는 빈 상태 대신 [페이지 조회 목록의 자리 표시 스펙](./paged-list-placeholder.md)의 자리 표시를 보여 준다. 판정 시점, 빈 상태에서 할 수 있는 행동, 목록과의 전환은 [목록 빈 상태 스펙](./list-empty-state.md)을 따른다.

빈 상태에서도 사용자는 웹 추가, 검색, 당겨서 새로고침을 그대로 실행할 수 있다.

### 새로고침

목록을 당겨 새로고침하는 행동과 결과는 [항목 목록 화면 공통 스펙](./entity-home.md)의 `새로고침`을 따른다.

### 웹 추가로 이동

사용자는 WebHome에서 웹 추가를 선택해 [WebAdd 화면](./web-add.md)으로 이동한다. 언제 제공하는지, 추가 단축키와 돌아왔을 때의 결과는 [항목 목록 화면 공통 스펙](./entity-home.md)의 `추가로 이동`을 따른다.

목록과 상세를 함께 사용할 수 있는 환경에서는 이미 상세 영역에서 웹 항목을 작성할 수 있으므로 목록에서 웹 추가로 이동하지 않는다. 판단 기준은 [목록·상세 배치 공통 스펙](./list-detail-pane.md)의 `추가 진입 수단`을 따른다.

### 검색으로 이동

사용자는 WebHome에서 검색을 선택해 [SearchHome 화면](./search-home.md)으로 이동한다.

이동한 화면은 웹 검색 결과부터 보여 준다. 시작 유형의 기준은 [SearchHome 화면 스펙](./search-home.md)의 `진입 경로와 시작 유형`을 따른다.

검색은 목록의 내용과 무관하게 언제나 실행할 수 있다. 사용자가 목록을 얼마나 내려 확인했는지도 검색 결과를 좁히지 않으므로, 사용자는 아직 목록에서 보지 못한 웹 항목도 검색으로 찾는다.

사용자가 검색 화면에서 뒤로 가면 WebHome으로 돌아오며, 검색으로 떠나기 전 상태의 목록을 그대로 본다.

### 웹 상세로 이동

사용자는 목록의 웹 항목을 선택해 그 웹 항목의 [WebDetail 화면](./web-detail.md)으로 이동한다. 준비되지 않은 자리와 돌아왔을 때의 목록은 [항목 목록 화면 공통 스펙](./entity-home.md)의 `상세로 이동`을 따른다.

### 뒤로가기

뒤로가기의 결과는 [항목 목록 화면 공통 스펙](./entity-home.md)의 `뒤로가기`를 따른다.

### 삭제

사용자는 목록의 웹 항목을 삭제할 수 있다. 웹 항목에는 완료 여부가 없으므로 삭제 방향만 제공하며, 삭제와 실행 취소의 결과는 [항목 목록 화면 공통 스펙](./entity-home.md)의 `삭제`를 따른다.

### 안내와 실행 취소

삭제의 안내와 실행 취소는 [항목 목록 화면 공통 스펙](./entity-home.md)의 `안내와 실행 취소`를 따른다. [WebDetail 화면 스펙](./web-detail.md)의 `삭제`가 여기에 해당하는 상세 화면의 삭제다.

### 정렬 선택

사용자는 목록 위에서 현재 정렬을 확인하고 다른 기준으로 바꿀 수 있다. 고를 수 있는 기준과 정렬 선택·반영·유지의 결과는 [목록 정렬 스펙](./list-sort.md)을 따른다.

## domain

### 목록에 노출하는 웹 항목

노출 기준은 [항목 목록 화면 공통 스펙](./entity-home.md)의 `목록에 노출하는 항목`을 따른다. 웹 항목에는 더하는 상태 조건이 없다.

### 목록 정렬

목록은 제목 오름차순으로 정렬한다. 제목이 같은 웹 항목끼리의 순서는 정하지 않는다.

위 순서는 사용자가 정렬을 고르지 않았을 때의 순서이며, 사용자가 고를 수 있는 다른 기준과 그 순서는 [목록 정렬 스펙](./list-sort.md)이 정한다.

### 목록 갱신

목록의 자동 갱신은 [항목 목록 화면 공통 스펙](./entity-home.md)의 `목록 갱신`을 따른다.

### 삭제와 실행 취소의 상태 전이

목록의 삭제와 실행 취소는 [항목 목록 화면 공통 스펙](./entity-home.md)의 `삭제와 실행 취소의 상태 전이`를 따른다. 제목, 설명, URL, 요청 헤더와 태그 연결은 바꾸지 않는다.

### 화면 유지

목록 위치와 정렬 선택의 유지는 [항목 목록 화면 공통 스펙](./entity-home.md)의 `화면 유지`를 따른다. 검색에서 돌아와도 같다.

## data

### 삭제와 실행 취소의 저장

삭제와 실행 취소의 저장과 동기화는 [항목 목록 화면 공통 스펙](./entity-home.md)의 `삭제와 실행 취소의 저장`을 따른다. 요청 헤더와 태그 연결은 기기에서 지우지 않는다.

### 목록 조회

목록의 조회, 조회 실패와 서버에서 다시 가져오는 계기는 [항목 목록 화면 공통 스펙](./entity-home.md)의 `목록 조회`를 따른다.
