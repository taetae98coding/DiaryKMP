# TagFinishedList 화면 스펙

이 문서는 사용자가 TagHome 목록에서 완료된 태그를 모아 확인하는 TagFinishedList 화면 가운데 이 화면에만 해당하는 부분을 다룬다. 진입과 이동, 빈 상태, 추가 미제공, 상세 확인, 정렬 선택, 노출 기준과 실행 경계의 공통 규칙은 [완료 목록 공통 스펙](./finished-list.md)을 따른다. 이 화면의 짝이 되는 목록은 [TagHome 목록](./tag-home.md)이다.

태그 카드의 내용, 이모지 표시와 정렬은 [TagHome 목록 스펙](./tag-home.md)을 따르고, 상세 확인과 상세에서 태그를 다시 시작하거나 삭제하는 행동은 [TagDetail 화면 스펙](./tag-detail.md)을 따른다. 목록 카드에서 다시 시작·삭제를 실행하는 상호작용의 공통 규칙은 [SwipeToFinishAndDelete 컴포넌트 스펙](./swipe-to-finish-and-delete.md)을 따른다.

디자인: [TagFinishedList 화면 디자인](../../design/tag-finished-list.md)

## feature

### 목록 표시

사용자는 각 태그의 이모지, 제목과 저장된 컬러를 확인할 수 있다. 카드의 표시 방식과 이모지 표시는 [TagHome 목록 스펙](./tag-home.md)의 `목록 표시`와 `태그 이모지 표시`를 따른다.

### 빈 상태 문구

완료된 태그가 하나도 없으면 목록 자리에 완료한 태그가 아직 없음을 알린다.

### 다시 시작

사용자는 목록의 태그를 다시 시작할 수 있다. 다시 시작을 실행하기 전에 확인을 되묻지 않는다.

다시 시작하면 태그가 이 목록에서 사라지고 다시 시작되었음을 안내하며, 실행 취소 동작을 제공한다.

사용자가 실행 취소를 선택하면 태그는 완료된 상태로 되돌아가 이 목록의 정렬 기준에 맞는 위치에 다시 나타난다.

### 삭제

사용자는 목록의 태그를 삭제할 수 있다. 삭제를 실행하기 전에 확인을 되묻지 않는다.

삭제하면 태그가 이 목록에서 사라지고 삭제되었음을 안내하며, 실행 취소 동작을 제공한다.

사용자가 실행 취소를 선택하면 태그는 삭제되지 않은 상태로 되돌아가 이 목록의 정렬 기준에 맞는 위치에 다시 나타난다.

아직 준비되지 않은 자리는 다시 시작하거나 삭제할 수 없다.

TagDetail 화면에서 다시 시작하거나 삭제한 태그도 노출 기준에 따라 이 목록에서 사라진다.

### 안내와 실행 취소

다시 시작과 삭제의 안내와 실행 취소는 [MemoHome 목록 스펙](./memo-home.md)의 `안내와 실행 취소` 절 전체를 메모를 태그로, 완료를 다시 시작으로 바꿔 그대로 따른다. [TagDetail 화면 스펙](./tag-detail.md)의 `삭제`는 화면을 떠나는 동작이므로 실행 취소를 제공하지 않으며, 이 절은 그 규칙을 바꾸지 않는다.

## domain

### 다시 시작과 삭제의 상태 전이

다시 시작은 태그의 완료 여부를 미완료로, 삭제는 삭제 여부를 삭제로 바꾸는 것이며 기준은 [TagDetail 화면 스펙](./tag-detail.md)의 `완료·다시 시작·삭제`와 같다. 두 동작 모두 태그 자체를 지우지 않는다.

실행 취소는 직전에 바꾼 상태를 원래 상태로 되돌린다. 다시 시작의 실행 취소는 완료 여부를 완료로, 삭제의 실행 취소는 삭제 여부를 미삭제로 되돌린다.

다시 시작, 삭제와 실행 취소는 모두 태그의 수정 시각을 동작 시점으로 갱신한다. 이모지, 제목, 설명, 컬러와 태그 연결을 바꾸지 않는 기준과 적용 계정은 [TagHome 목록 스펙](./tag-home.md)의 `완료와 삭제의 상태 전이`와 같다.

### 필터

TagHome 목록의 최상위 태그 필터는 이 목록에 적용하지 않는다. 필터를 켜 두어도 완료된 태그는 향해 오는 연결과 관계없이 모두 표시하며, 그 기준은 [TagHome 목록 스펙](./tag-home.md)의 `필터 적용 범위`를 따른다.

### 정렬

목록은 [TagHome 목록 스펙](./tag-home.md)의 `정렬`을 따라 제목 오름차순으로 정렬한다.

## data

### 목록 조회

조회 흐름은 [완료 목록 공통 스펙](./finished-list.md)의 `목록 조회`를 따르며, 태그의 제목이 바뀔 때도 목록을 갱신한다.

### 상태 변경의 저장

목록에서 태그를 다시 시작하거나 삭제하거나 실행 취소하면 저장과 동기화, 저장 실패의 결과는 [TagHome 목록 스펙](./tag-home.md)의 `상태 변경의 저장`과 같다.
