# 목록 추가 단축키 스펙

이 문서는 물리 키보드를 쓰는 환경에서 목록 화면의 항목 추가를 단축키로 실행하는 행동을 다룬다. 추가로 무엇이 열리고 언제 추가를 실행할 수 있는지는 각 화면 스펙의 추가 절이 정하고, 목록과 상세를 함께 사용하는 동안 목록에서 추가를 실행하는 기준은 [목록·상세 배치 공통 스펙](./list-detail-pane.md)의 `추가 진입 수단`이 정한다. 상세 화면의 탭 안에서 그 탭의 항목을 추가하는 단축키는 각 상세 화면 디자인이 다룬다.

디자인: [목록 추가 단축키 디자인](../../design/list-add-shortcut.md)

## feature

### 단축키로 추가 실행

사용자는 적용 대상 화면에서 추가 단축키를 눌러 그 화면의 추가를 실행할 수 있다. 단축키로 실행한 결과는 그 화면에서 추가를 선택했을 때와 같다. 지도 모드의 PlaceHome에서 단축키를 누르면 추가를 선택했을 때처럼 보고 있던 지도 위치에서 장소 추가가 시작된다.

적용 대상은 모두 같은 키 조합을 쓴다. 사용자는 화면이 달라도 같은 조합으로 항목을 추가한다. 단축키를 한 번 누르면 추가도 한 번만 실행된다.

### 실행하지 않는 경우

그 화면에서 추가를 실행할 수 없는 동안에는 단축키를 눌러도 아무 일도 일어나지 않는다. 화면마다 추가를 실행할 수 없는 조건은 각 화면 스펙의 추가 절을 따른다. 예를 들어 목록과 상세를 함께 보는 동안 상세 영역에 이미 추가가 놓여 있을 때, FileHome에서 로그인하지 않았거나 올리는 중인 파일이 있을 때가 그렇다.

목록과 상세를 함께 보는 동안 상세 영역의 화면이 같은 단축키로 자기 탭의 항목 추가를 실행하면 목록의 추가는 함께 실행하지 않는다. 한 번 누른 단축키로 두 추가가 함께 열리지 않게 하기 위해서다.
