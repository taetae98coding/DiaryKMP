# 캘린더 메모 표시 스펙

이 문서는 캘린더에 표시할 메모를 정하는 기준을 다룬다. 어떤 메모가 캘린더에 나타나는지, 어떤 기간을 차지하는지, 어떤 색상으로 표시되는지를 정한다.

메모를 캘린더의 어느 자리에 어떤 모양으로 배치하는지는 [Calendar 컴포넌트 디자인](../../design/calendar.md)과 [CalendarWeekOfMonth 컴포넌트 디자인](../../design/calendar-week-of-month.md)의 아이템 배치를 따르며, 메모를 캘린더에 실제로 배치하는 화면 구성은 [CalendarHome 디자인](../../design/calendar-home.md)에서 다룬다. 이 문서에는 직접 수행하는 사용자 조작이 없어 `feature` 영역을 두지 않는다.

메모의 기간과 상태 개념은 [MemoAdd 화면 스펙](./memo-add.md)을, 대표 태그 개념은 [메모 대표 태그 스펙](../common/memo-primary-tag.md)을 따른다.

## domain

### 캘린더 메모

캘린더 메모는 캘린더에 표시할 수 있는 형태로 정리한 메모다.

캘린더 메모는 어떤 메모인지 알아볼 수 있는 식별값, 제목, 표시 색상, 기간을 가진다.

캘린더 메모의 기간은 항상 존재한다. 기간이 없는 메모는 캘린더에 놓을 자리가 없으므로 캘린더 메모가 되지 않는다.

### 표시 대상 기간

캘린더는 표시할 기간을 시작일과 종료일로 지정하고, 그 기간과 겹치는 메모만 표시한다.

메모의 기간이 표시 대상 기간과 하루라도 겹치면 표시 대상이며, 하루도 겹치지 않으면 표시 대상이 아니다. 메모의 기간이 표시 대상 기간 전체를 감싸는 경우도 표시 대상이다.

겹침은 날짜 단위로 판단한다. 시각이 있는 기간도 시각을 무시하고 시작일과 종료일만으로 비교한다.

표시 대상 기간은 캘린더가 사용자에게 보여 주는 날짜의 범위이며, 표시 중인 달에 속하지 않더라도 함께 보이는 이웃 달의 날짜를 포함한다.

### 노출 기준

캘린더에는 현재 사용자 계정과 연결된 메모 중 기간이 있고 삭제되지 않은 메모를 표시한다.

완료된 메모도 캘린더에 표시한다. 사용자가 이미 끝낸 일도 그 기간에 무엇이 있었는지 캘린더에서 돌아볼 수 있어야 하기 때문이다.

이 기준은 캘린더에만 적용한다. 메모 목록의 노출 기준은 [MemoHome 목록 스펙](./memo-home.md)의 메모 상태와 노출 기준을 따르며, 완료된 메모를 목록에서 감추는 규칙은 그대로 유지된다.

캘린더를 배치하는 화면은 이 기준 위에 태그 필터 같은 표시 조건을 더할 수 있다. 더하는 조건의 규칙은 그 화면의 스펙을 따르며, 이 문서의 노출 기준을 완화하지 않는다.

완료된 메모는 완료되지 않은 메모와 같은 방식으로 표시한다. 완료 여부는 그 기간에 무엇이 있었는지를 바꾸지 않으므로 표시로 구분하지 않으며, 캘린더를 배치하는 화면도 완료 여부에 따라 다른 표시를 더하지 않는다.

### 기간 형태

캘린더 메모의 기간은 메모에 기록된 형태를 그대로 유지한다.

종일 기간인 메모는 종일 기간으로, 시각까지 있는 기간인 메모는 시각이 있는 기간으로 전달된다. 두 형태를 하나로 합치거나 시각을 버리지 않는다.

이는 캘린더가 기간 형태에 따라 아이템을 구분해 표시하거나 기간의 시각을 함께 보여 줄 때 다시 조회하지 않아도 되도록 하기 위한 것이다. 기간 형태를 구분해 표시할지는 캘린더를 배치하는 화면이 정하며, 캘린더 홈의 구분은 [CalendarHome 스펙](./calendar-home.md)의 메모 기간 형태 구분을 따른다.

### 표시 색상

캘린더 메모의 표시 색상은 [메모 대표 태그 앱 스펙](./memo-primary-tag.md)의 `캘린더 표시 색상`을 따른다.

메모에 대표 태그가 있고 그 태그를 기기에서 찾을 수 있으며 삭제되지 않았으면 대표 태그의 컬러를, 그렇지 않으면 메모 자신의 컬러를 표시 색상으로 삼는다.

캘린더 메모는 이미 정해진 표시 색상만 가진다. 캘린더는 대표 태그를 따로 확인하지 않고 전달받은 표시 색상을 그대로 사용한다.

### 조회 결과 정렬

종일 기간인 메모는 시각이 있는 기간인 메모보다 앞에 온다.

종일 기간인 메모끼리는 시작이 이른 순으로 정한다. 시작이 같으면 종료가 늦은 메모가 앞에 오고, 시작과 종료가 모두 같으면 제목의 오름차순으로 정한다.

시각이 있는 기간인 메모끼리는 시각을 포함한 시작이 이른 순으로 정한다. 시작이 같으면 시각을 포함한 종료가 이른 메모가 앞에 오고, 시작과 종료가 모두 같으면 제목의 오름차순으로 정한다.

같은 표시 대상 기간을 다시 조회하면 결과의 순서도 같게 유지한다.

이 순서는 캘린더 메모 조회 결과를 안정적으로 전달하기 위한 데이터 정렬이다. 종일 메모를 캘린더의 위쪽 줄에 먼저 놓는다는 뜻은 아니다.

캘린더 안의 줄 위치는 종일 여부가 아니라 기간의 시작일을 기준으로 하는 [CalendarWeekOfMonth 컴포넌트 스펙](./calendar-week-of-month.md)의 `아이템 줄 배치`를 따른다. 메모와 공휴일의 기간이 모두 같을 때의 배치만 [CalendarHome 디자인](../../design/calendar-home.md)의 공휴일과 메모 아이템을 따른다.

### 표시 갱신

표시 대상 기간이 바뀌면 그 기간을 기준으로 표시할 메모가 다시 정해진다.

표시 대상 기간이 그대로인 동안 메모가 추가·수정·완료·삭제되거나 대표 태그의 컬러가 바뀌면, 사용자가 별도 조작을 하지 않아도 캘린더의 메모 표시가 갱신된다.

로그인이나 로그아웃으로 현재 사용자 계정이 바뀌면 바뀐 계정을 기준으로 표시할 메모가 다시 정해진다.

### 표시할 메모가 없을 때

표시 대상 기간에 겹치는 메모가 없으면 메모 없이 캘린더가 표시되고 사용자에게 별도로 알리지 않는다.

메모를 가져오지 못하면 실패한 것으로 알린다. 실패를 표시할 메모가 없는 것으로 다룰지 사용자에게 알릴지는 캘린더를 배치하는 화면이 정하며, 실패가 캘린더의 다른 표시를 막지는 않는다.

## data

### 캘린더 메모 조회

캘린더 메모는 기기에 저장된 메모에서 조회한다. 표시 대상 기간을 조회할 때 원격에서 따로 받아 오지 않으며, 원격 데이터가 기기에 반영되는 시점은 [데이터 동기화 스펙](../common/data-sync.md)을 따른다.

조회는 현재 사용자 계정과 연결된 메모 중 기간이 있고 삭제되지 않았으며 표시 대상 기간과 겹치는 메모만 대상으로 한다. 완료 여부는 조회 조건에 넣지 않아 완료된 메모도 함께 조회된다.

조회 결과에는 캘린더가 표시에 필요한 값만 담기며, 결과 정렬은 `domain`의 조회 결과 정렬을 따른다.

### 표시 색상 해석

표시 색상은 메모를 조회할 때 대표 태그를 함께 확인해 정해진 값으로 전달한다. 캘린더가 색상을 정하려고 태그를 다시 조회하지 않는다.

대표 태그가 기기에 아직 저장되어 있지 않거나 삭제된 상태면 메모 자신의 컬러를 전달한다. 대표 태그가 완료된 상태인지는 색상 결정에 영향을 주지 않는다.

### 저장된 내용 변경의 반영

같은 표시 대상 기간을 계속 보고 있는 동안 기기에 저장된 메모나 대표 태그가 바뀌면, 바뀐 내용이 반영된 조회 결과가 이어서 전달된다.

메모가 표시 대상 기간과 겹치지 않게 바뀌거나 삭제되면 조회 결과에서 빠지고, 겹치도록 바뀌면 조회 결과에 들어온다.

### 조회 실패

기기에서 메모를 조회하지 못하면 결과를 비워서 전달하지 않고 실패로 전달한다. 실패를 어떻게 표시할지는 `domain`의 표시할 메모가 없을 때를 따른다.
