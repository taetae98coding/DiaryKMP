# 항목 태그 연결 앱 스펙

이 문서는 메모, 장소, 웹 항목이 태그와 맺는 연결 가운데 앱이 기기에 저장된 연결로 태그와 대상 항목을 조회하는 규칙을 다룬다. 태그 연결이 공통으로 지키는 규칙은 [항목 태그 연결 공통 스펙](../common/entity-tag.md)을, 연결을 기기에 저장하는 규칙은 [항목 연결 앱 스펙](./entity-link.md)을 따른다.

이 문서에서 `대상 항목`은 태그와 연결되는 메모, 장소 또는 웹 항목 하나를 가리킨다.

사용자가 태그를 고르고 해제하는 조작은 [태그 선택 입력 공통 스펙](./tag-select-input.md)과 각 입력 컴포넌트 스펙이 소유하므로 이 문서에는 `feature` 영역을 두지 않는다.

## domain

### 연결된 태그의 조회

대상 항목을 기준으로 그 대상 항목과 연결된 태그를 조회한다. 조회에 포함되는 연결과 태그의 기준은 [항목 연결 공통 스펙](../common/entity-link.md)의 `연결된 항목의 조회`를 따르므로, 완료된 태그는 포함되고 삭제된 태그는 포함되지 않는다.

조회 결과는 태그 제목 오름차순으로 놓인다.

## data

### 태그별 대상 항목 표시

태그로 대상 항목을 조회할 때는 현재 사용자 계정과 연결된 대상 항목과 그 대상 항목의 태그 연결만 사용한다.

해제되지 않은 연결의 대상 항목은 그 목록의 노출 기준을 만족하면 표시되고, 해제된 연결의 대상 항목은 표시되지 않는다.

연결이 만들어지거나 해제되거나 복구되면 그 태그의 목록은 변경된 연결 상태를 반영한다.

어느 목록이 이 조회를 사용하는지는 [TagDetail 메모 탭 스펙](./tag-detail-memo.md), [TagDetail 웹 탭 스펙](./tag-detail-web.md), [TagDetail 장소 탭 스펙](./tag-detail-place.md)에서 다룬다.
