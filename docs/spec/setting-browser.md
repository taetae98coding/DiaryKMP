# SettingBrowser 화면 스펙

이 문서는 사용자가 설정 화면의 `브라우저` 항목에서 진입하는 SettingBrowser 화면의 내용과 행동을 다룬다. 설정 항목의 표시와 선택은 [SettingHome 화면 스펙](./setting-home.md)에서, 설정 목록과 함께 사용할 때의 선택·뒤로가기 정책은 [Setting 목록·상세 배치 스펙](./setting-list-detail.md)에서, 세부 화면에서의 공통 내비게이션 노출 규칙은 [TopLevelNavigation 스펙](./top-level-navigation.md)에서 다룬다. 고른 프로필의 로그인 정보를 앱 안 웹 페이지가 가져오는 규칙과 프로필 목록의 출처는 [Chrome 로그인 이어받기 스펙](./chrome-session-import.md)에서 다룬다.

디자인: [SettingBrowser 화면 디자인](../design/setting-browser.md)

이번 범위는 사용자가 로그인 정보를 이어받을 Chrome 프로필을 고르거나 고르지 않기로 하고, 그 선택이 기기에 유지되는 것까지다.

## feature

### 진입과 이동

사용자는 설정 화면의 `브라우저` 항목을 선택해 SettingBrowser 화면으로 이동한다.

SettingBrowser 화면은 설정 목록과 함께 표시되거나 단독으로 표시될 수 있다. 두 상태 모두 공통 내비게이션을 제공하지 않으며, 표시 관계는 [Setting 목록·상세 배치 스펙](./setting-list-detail.md)을 따른다.

이 화면은 [Chrome 로그인 이어받기 스펙](./chrome-session-import.md)의 `제공 환경`에서만 진입할 수 있다. 제공하지 않는 환경에서는 SettingHome이 `브라우저` 항목을 제공하지 않으므로 이 화면으로 이동하는 경로가 없다.

### Chrome 프로필 선택

사용자는 `Chrome 로그인 이어받기` 설정에서 `선택 안 함`과 이 기기의 Chrome 프로필 중 현재 선택을 확인하고 하나를 고를 수 있다. 프로필은 [Chrome 로그인 이어받기 스펙](./chrome-session-import.md)의 `Chrome 프로필`이 정한 목록과 순서로 제공하며, `선택 안 함`을 맨 앞에 둔다.

선택하지 않은 항목을 고르면 즉시 저장되고 선택 상태가 바뀐다. 이미 선택한 항목을 다시 고르면 아무것도 바뀌지 않는다.

화면의 선택 상태는 저장된 선택을 따른다. 저장에 실패하면 이전 선택을 유지하며 별도 오류 상태로 전환하지 않는다.

저장된 선택을 확인하기 전이거나 읽지 못했으면 선택 기능을 제공하지 않으며 별도 로딩 또는 오류 상태로 전환하지 않는다.

Chrome 프로필이 하나도 없으면 `선택 안 함`만 제공한다. 이때도 사용자는 화면에서 설정 이름과 `선택 안 함`을 확인할 수 있다.

프로필 목록을 읽지 못하면 프로필 항목 없이 `선택 안 함`만 제공하고, 프로필을 조회할 수 없다는 안내를 함께 표시한다. 사용자는 이 상태에서도 `선택 안 함`을 고를 수 있으며, 저장된 프로필이 있어도 `선택 안 함`이 선택된 것으로 표시한다. 저장된 값은 지우지 않는다.

선택을 바꾸면 앱 안 웹 표시 수단에 남아 있던 로그인 정보가 지워지고, 프로필을 골랐으면 그 프로필의 로그인 정보를 새로 가져온다. 무엇을 지우고 가져오는지와 가져오는 동안의 상태는 [Chrome 로그인 이어받기 스펙](./chrome-session-import.md)의 `가져오는 계기`를 따른다. 이 화면은 가져오는 진행 상태나 실패를 따로 표시하지 않는다.

### 뒤로가기

단독으로 표시될 때와 설정 목록과 함께 표시될 때의 뒤로가기 결과는 모두 [Setting 목록·상세 배치 스펙](./setting-list-detail.md)의 `뒤로가기`를 따른다.

바꾼 선택은 뒤로가기로 화면을 떠나도 그대로 유지되며, 되돌리기 위한 별도 동작은 제공하지 않는다.

## domain

### Chrome 로그인 이어받기 설정

Chrome 로그인 이어받기는 이 기기의 Chrome 중 어느 프로필에 저장된 로그인 정보를 앱 안 웹 표시 수단이 이어받을지 정하는 설정이다. 값은 `선택 안 함` 또는 Chrome 프로필 하나다.

사용자가 한 번도 고르지 않았으면 `선택 안 함`이다. Chrome의 로그인 정보를 읽는 것은 사용자가 직접 허용해야 하는 일이므로 기본으로 프로필을 고르지 않는다.

### 목록에 없는 프로필

저장된 프로필이 현재 Chrome 프로필 목록에 없으면 `선택 안 함`으로 다룬다. 화면에서도 `선택 안 함`이 선택된 것으로 표시하고 로그인 정보를 가져오지 않는다. 이렇게 `선택 안 함`으로 다루는 것은 사용자가 선택을 바꾼 것이 아니므로 앱 안 웹 표시 수단의 로그인 정보를 지우지 않는다.

저장된 값은 지우지 않으므로 그 프로필이 다시 목록에 나타나면 이전 선택이 그대로 되살아난다. 사용자가 다른 항목을 고르면 저장된 값이 새 선택으로 바뀐다.

설정이 적용되는 범위와 가져오는 규칙은 [Chrome 로그인 이어받기 스펙](./chrome-session-import.md)을 따른다.

## data

### 저장 시점과 유지

사용자가 항목을 고르면 그 선택이 기기에 저장된다. 사용자가 한 번도 고르지 않았으면 저장된 값이 없고, 이때는 `선택 안 함`으로 다룬다.

저장된 선택은 화면을 떠나거나 화면이 재생성되어도, 앱이 백그라운드에 다녀와도, 앱을 종료하고 다시 시작해도 유지된다.

저장된 값을 읽을 수 없으면 선택을 아직 확인하지 못한 상태로 다룬다. 이는 저장된 값이 없어 `선택 안 함`으로 다루는 것과 구분된다.

### 기기별 보관

선택은 사용자 계정이 아니라 기기에 보관하며 서버와 동기화하지 않는다. 로그인, 로그아웃, 계정 전환으로 바뀌지 않으며 다른 기기에도 반영되지 않는다.

선택은 [데이터 동기화 스펙](./data-sync.md)의 동기화 대상이 아니다.

### 환경별 저장 영역

설정을 제공하는 JVM 데스크톱은 [SettingMap 화면 스펙](./setting-map.md)의 `환경별 저장 영역`이 정한 JVM 데스크톱의 저장 영역을 그대로 쓴다. 개발 flavor와 운영 flavor는 서로 다른 선택을 가진다.
