# 메모 연락처 스펙

이 문서는 하나의 메모가 여러 연락처와 연결될 수 있다는 규칙 가운데 메모와 연락처의 연결에만 해당하는 부분을 다룬다. 연결의 성질과 저장·동기화 계약은 [항목 연결 공통 스펙](./entity-link.md)을 따른다.

연락처 자체의 추가와 연락처가 갖는 정보는 [ContactAdd 화면 스펙](./contact-add.md)을, 연락처의 수정과 삭제는 [ContactDetail 화면 스펙](./contact-detail.md)을 따른다.

사용자가 연락처를 고르고 해제하는 조작은 이 문서에서 다루지 않는다. 연락처 선택의 행동과 정책은 [메모 연락처 입력 컴포넌트 스펙](./memo-contact-input.md)에서, 구체적인 표현과 조작 수단은 [메모 연락처 입력 컴포넌트 디자인](../design/memo-contact-input.md)에서 다룬다. 메모를 추가하면서 연락처를 연결하는 행동은 [MemoAdd 화면 스펙](./memo-add.md)에서, 이미 저장된 메모의 연락처 연결을 바꾸는 행동은 [MemoDetail 화면 스펙](./memo-detail.md)에서, 연락처로 메모를 찾아보는 목록은 [ContactDetail 메모 탭 스펙](./contact-detail-memo.md)에서 다룬다. 이 문서에는 사용자 조작이 없어 `feature` 영역을 생략한다.

메모와 태그의 연결은 이 문서가 다루는 연결과 별개이며 [메모 태그 스펙](./memo-tag.md)이 소유한다.

## domain

### 메모와 연락처의 연결

메모는 여러 연락처와 연결될 수 있고, 하나의 연락처도 여러 메모와 연결될 수 있다.

연결은 메모와 연락처 사이의 관계이며, 메모의 제목·설명·컬러·기간이나 연락처의 이름·설명·키·신발 사이즈·생일·고향·전화번호·즐겨찾기 여부를 바꾸지 않는다.

연락처에는 태그를 연결하지 않으므로, 메모와 연락처가 같은 태그를 통해 이어지는 경로는 없다.

### 대표 연락처를 두지 않음

메모는 연결된 연락처 중 하나를 대표로 갖지 않는다. 연결된 연락처는 모두 같은 자격의 연결이며, 그 사이에 순위나 대표 관계를 두지 않는다.

메모의 표시에 연락처의 값을 쓰지 않으므로 대표 연락처가 필요하지 않다. 메모가 갖는 대표 태그의 규칙은 [메모 대표 태그 스펙](./memo-primary-tag.md)이 소유하며 연락처 연결에는 적용하지 않는다.

### 연결된 연락처의 정렬

메모를 기준으로 조회한 연락처는 이름 오름차순으로 놓는다. 이름이 같은 연락처끼리의 순서는 정하지 않는다.

연락처의 즐겨찾기 여부는 이 정렬에 영향을 주지 않는다. 즐겨찾기를 앞세우는 순서는 [ContactHome 화면 스펙](./contact-home.md)의 `목록 정렬`이 그 목록에만 정한 것이다.

조회에 포함되는 연결과 연락처의 기준은 [항목 연결 공통 스펙](./entity-link.md)의 `연결된 항목의 조회`를 따른다.

### 연결의 의미

[항목 연결 공통 스펙](./entity-link.md)의 `연결의 의미`는 메모와 연락처의 연결에서 다음 목록에 적용된다.

- [MemoHome 목록 스펙](./memo-home.md)의 목록 노출 기준과 정렬. 연락처 연결 여부는 [태그 필터 스펙](./tag-filter.md)과 MemoHome의 존재 필터 대상도 아니다.
- [ContactHome 화면 스펙](./contact-home.md)의 목록 노출 기준과 정렬
- [SearchHome 화면 스펙](./search-home.md)의 메모 검색 결과
- [캘린더 연락처 생일 표시 스펙](./calendar-contact-birthday.md)의 노출 기준
- 태그로 메모를 조회한 결과

연락처로 메모를 조회하는 [ContactDetail 메모 탭 스펙](./contact-detail-memo.md)의 목록은 이 연결을 노출 기준으로 쓴다.

연락처를 메모에 연결해도 그 연락처가 연결된 메모의 기간에 나타나지 않고, 그 메모가 연락처의 생일에 나타나지도 않는다.

## data

### 메모별 연락처 표시

메모로 연락처를 조회할 때는 현재 사용자 계정과 연결된 연락처와 메모-연락처 연결만 사용한다. 조회에 포함되는 연결과 연락처의 기준은 [항목 연결 공통 스펙](./entity-link.md)의 `연결된 항목의 조회`를 따른다.

연결이 만들어지거나 해제되거나 복구되면 그 메모의 연락처를 표시하는 화면과 그 연락처의 메모를 표시하는 화면은 변경된 연결 상태를 반영한다.

### 연락처별 메모 표시

연락처로 메모를 조회할 때는 현재 사용자 계정과 연결된 메모와 메모-연락처 연결만 사용한다. 조회에 포함되는 연결과 메모의 기준은 [항목 연결 공통 스펙](./entity-link.md)의 `연결된 항목의 조회`를 따르며, 그 위에 더하는 노출 기준과 정렬은 [항목 상세 메모 탭 공통 스펙](./entity-detail-memo.md)이 정한다.
