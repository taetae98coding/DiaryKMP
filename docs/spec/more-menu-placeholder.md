# 더보기 준비 중 화면 공통 스펙

이 문서는 `더보기`의 기능 바로가기로 진입하지만 아직 기능을 제공하지 않는 화면이 공통으로 보장하는 내용과 행동을 다룬다. 바로가기 항목의 표시와 선택은 [MoreHome 화면 스펙](./more-home.md)에서, 세부 화면의 뒤로가기와 공통 내비게이션 노출은 [TopLevelNavigation 스펙](./top-level-navigation.md)에서 다룬다.

디자인: [더보기 준비 중 화면 공통 디자인](../design/more-menu-placeholder.md)

## feature

### 진입

사용자는 `더보기` 화면의 기능 바로가기에서 항목을 선택해 그 항목의 화면으로 이동한다.

### 화면 내용

사용자는 화면에서 자신이 어느 기능으로 들어왔는지 알 수 있는 제목을 확인한다.

사용자가 확인하거나 조작할 내용은 아직 없다. 화면은 제목과 뒤로가기 외에 어떤 정보도 표시하지 않고 어떤 동작도 제공하지 않는다.

기능이 아직 없다는 사실을 별도 문구로 안내하지 않는다. 준비 상태를 알리는 문구는 기능이 채워지면 지워야 하고, 그때까지 사용자가 할 수 있는 일을 바꾸지도 않는다.

### 뒤로가기

사용자가 뒤로가기를 실행하면 `더보기` 화면으로 돌아간다. 이는 [TopLevelNavigation 스펙](./top-level-navigation.md)의 `더보기 하위 화면의 뒤로가기`를 따른다.

돌아간 `더보기` 화면은 사용자가 떠나기 전 상태를 그대로 유지한다.

## domain

### 적용 대상

이 문서는 다음 바로가기 항목과 화면에 적용한다.

| 기능 바로가기 항목 | 화면 | 화면 스펙 |
| --- | --- | --- |
| `QR` | QrHome | [QrHome 화면 스펙](./qr-home.md) |
| `디데이` | DDayHome | [DDayHome 화면 스펙](./dday-home.md) |
| `체크리스트` | ChecklistHome | [ChecklistHome 화면 스펙](./checklist-home.md) |
| `파일` | FileHome | [FileHome 화면 스펙](./file-home.md) |
| `플레이리스트` | PlaylistHome | [PlaylistHome 화면 스펙](./playlist-home.md) |

각 화면은 서로 독립된 화면이며, 한 화면에서 다른 화면으로 이동하지 않는다.

기능이 채워진 화면은 이 문서의 적용 대상에서 빠지고 그 화면 스펙이 내용과 행동을 직접 소유한다.

### 화면 제목

각 화면의 제목은 그 화면으로 들어온 기능 바로가기 항목과 같은 이름을 쓴다. 사용자가 고른 이름과 도착한 화면의 이름이 같아야 어디에 왔는지 분명해지기 때문이다. 사용자 언어별 실제 문구는 디자인이 소유한다.

### 유지할 사용자 진행 상태

이 화면에는 사용자가 만든 진행 상태가 없다. 화면 재생성, 앱 재실행, 백그라운드 복귀 뒤에도 복원하거나 초기화할 상태가 없으며, 사용자는 언제 들어와도 같은 화면을 본다.
