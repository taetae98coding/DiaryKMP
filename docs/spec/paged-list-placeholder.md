# 페이지 조회 목록의 자리 표시 스펙

이 문서는 저장소에서 페이지 단위로 조회하는 목록에서, 아직 준비되지 않은 자리를 사용자에게 어떻게 제공하는지를 다룬다. 목록에 무엇을 노출하고 어떤 순서로 정렬하는지는 각 화면과 컴포넌트의 스펙이 다룬다.

디자인: [페이지 조회 목록의 자리 표시 디자인](../design/paged-list-placeholder.md)

## feature

### 목록이 나타나는 순서

목록은 정렬 순서의 앞부분부터 나타나고, 사용자가 목록의 끝으로 이동하면 그다음 항목이 이어서 나타난다. 사용자는 목록을 계속 이동해 노출 기준을 만족하는 항목을 모두 확인할 수 있다.

### 자리 표시

아직 준비되지 않은 자리는 자리 표시 상태로 제공한다. 사용자는 자리 표시 상태의 자리를 선택할 수 없고, 그 자리에서 항목의 상태를 바꾸거나 선택 여부를 바꿀 수 없다.

준비를 기다리는 동안에도 이미 나타난 항목은 그대로 선택하고 조작할 수 있다.

내용이 준비되면 같은 자리에 항목이 나타난다.

### 준비 중 표시

목록을 준비하는 동안에는 별도의 진행 안내를 표시하지 않는다. 준비 중임을 알리는 표시는 자리 표시 자체가 대신한다.

목록을 당겨 새로고침할 때의 진행 표시는 [새로고침 스펙](./sync-refresh.md)을 따르며, 자리 표시와 함께 나타날 수 있다.

### 빈 상태 판정

빈 상태는 목록이 준비된 뒤에 판정한다. 준비하는 동안에는 항목이 하나도 나타나지 않아도 빈 상태를 표시하지 않는다.

화면 본문을 차지하는 목록이 빈 상태에서 무엇을 표시하고 어떤 동작을 제공하는지는 [목록 빈 상태 스펙](./list-empty-state.md)을 따른다. 그 문서의 적용 대상이 아닌 목록은 각 화면과 컴포넌트의 스펙이 정한다.

## data

### 페이지 조회

목록은 저장소에서 각 스펙의 노출 기준과 정렬 순서로 페이지 단위로 조회한다. 사용자가 목록의 끝에 다가가면 다음 페이지를 이어서 조회한다.

사용자가 목록을 얼마나 확인했는지는 조회 범위에만 영향을 주며, 항목의 노출 기준이나 정렬 순서를 바꾸지 않는다.

저장된 항목이 추가되거나 노출 기준과 정렬에 영향을 주는 값이 바뀌면 조회 결과를 자동으로 갱신한다.
