# PlaceHome 화면 스펙

이 문서는 사용자가 `더보기`의 `장소` 메뉴에서 진입하는 PlaceHome 화면의 내용과 행동을 다룬다. `더보기` 메뉴 영역의 표시와 선택은 [MoreHome 화면 스펙](./more-home.md)에서, 세부 화면에서의 공통 내비게이션 노출 규칙은 [TopLevelNavigation 스펙](./top-level-navigation.md)에서 다룬다.

보기 모드 전환, 지도와 지도 위 핀의 표시, 두 모드의 목록과 빈 상태, 장소 추가와 장소 상세로 이동할 때 넘기는 것, 목록 정렬과 새로고침의 공통 기준은 [장소 보기 모드 스펙](./place-view-mode.md)이 소유한다. 이 문서에는 PlaceHome이 정하는 기본 보기 모드, 노출 대상 장소, 현재 위치 확인 시점과 보기 모드 밖에서 함께 제공하는 행동만 둔다.

본문에 표시되는 지도의 표시와 지도 제공자 전환은 [DiaryMap 컴포넌트 스펙](./diary-map.md)에서, 기본 지도를 고르고 저장하는 흐름은 [SettingMap 화면 스펙](./setting-map.md)에서, 장소를 작성해 추가하는 흐름은 [PlaceAdd 화면 스펙](./place-add.md)에서, 선택한 장소의 상세를 확인하고 수정하고 삭제하는 흐름은 [PlaceDetail 화면 스펙](./place-detail.md)에서, 화면에서 검색으로 이동한 뒤의 내용과 행동은 [SearchHome 화면 스펙](./search-home.md)에서, 현재 위치를 확인하는 규칙은 [현재 위치 확인 스펙](./current-location.md)에서, 당겨서 새로고침하는 조작과 진행 표시의 공통 기준은 [새로고침 스펙](./sync-refresh.md)에서, 페이지 단위로 조회하는 목록이 나타나는 순서와 아직 준비되지 않은 자리의 처리는 [페이지 조회 목록의 자리 표시 스펙](./paged-list-placeholder.md)에서, 장소를 서버와 맞추는 규칙은 [데이터 동기화 스펙](./data-sync.md)에서 다룬다.

이번 범위는 `더보기`에서 PlaceHome으로 이동하고, PlaceHome 화면 본문에 장소 보기 모드를 배치해 계정의 장소를 목록과 지도로 확인하고, 장소 추가와 장소 상세, 검색으로 이동하는 것까지다. 위치 권한 요청, 지도에서 장소를 찾는 검색과 경로 안내 같은 부가 기능은 이번 범위에 포함하지 않는다. 지도 위 현 위치 표시는 [DiaryMap 컴포넌트 스펙](./diary-map.md)의 현 위치 표시를 따른다. 저장된 항목을 찾는 검색으로 이동하는 것은 이번 범위에 포함하며, 이동한 뒤의 행동은 [SearchHome 화면 스펙](./search-home.md)이 다룬다.

디자인: [PlaceHome 화면 디자인](../design/place-home.md)

## feature

### 진입

사용자는 `더보기` 화면의 메뉴 영역에서 `장소` 항목을 선택해 PlaceHome 화면으로 이동한다.

화면에 진입하면 지도 모드로 시작한다. 진입한 뒤 사용자가 보기 모드를 바꾸고 지도와 목록을 다루는 행동은 [장소 보기 모드 스펙](./place-view-mode.md)을 따른다.

### 검색으로 이동

사용자는 PlaceHome에서 검색을 선택해 [SearchHome 화면](./search-home.md)으로 이동한다.

이동한 화면은 장소 검색 결과부터 보여 준다. 시작 유형의 기준은 [SearchHome 화면 스펙](./search-home.md)의 `진입 경로와 시작 유형`을 따른다.

검색은 지도 기능의 표시 여부와 보기 모드에 무관하게 언제나 실행할 수 있다. 지도가 보고 있는 영역은 검색 결과를 좁히지 않으므로, 사용자는 지도 밖에 있는 장소도 검색으로 찾는다.

사용자가 검색 화면에서 뒤로 가면 PlaceHome으로 돌아오며, 검색으로 떠나기 전의 보기 모드와 지도가 보고 있던 위치, 확대 수준, 고른 지도 제공자를 그대로 본다.

### 뒤로가기

사용자가 뒤로가기를 실행하면 [TopLevelNavigation 스펙](./top-level-navigation.md)의 `더보기 하위 화면의 뒤로가기`에 따라 `더보기`로 돌아간다.

## domain

### 기본 보기 모드

PlaceHome의 기본 보기 모드는 지도 모드다. 화면에 진입하면 지도 모드에서 시작하고, 화면을 떠난 뒤 다시 들어와도 지도 모드에서 다시 시작한다.

보기 모드가 무엇을 노출하는지와 어떤 경계에서 유지되고 초기화되는지는 [장소 보기 모드 스펙](./place-view-mode.md)의 `보기 모드`와 `보기 모드의 유지`를 따른다.

### 노출 대상 장소

PlaceHome의 노출 대상 장소는 현재 사용자 계정과 연결되어 있고 삭제되지 않은 장소다. 두 보기 모드가 이 집합을 함께 사용하며, 지도 모드는 여기에 보이는 영역 기준을 더한다.

두 모드가 이 집합을 어떻게 쓰는지는 [장소 보기 모드 스펙](./place-view-mode.md)의 `목록 모드에 노출하는 장소`와 `지도 모드에 노출하는 장소`를 따른다.

### 현재 위치 확인 시점

PlaceHome은 화면에 진입할 때 현재 위치를 한 번 확인한다. 화면에 진입하면 지도 모드로 시작하므로 진입 시점이 곧 지도가 필요한 시점이다.

확인 방법과 확인하지 못했을 때의 표시, 재확인하지 않는 경계는 [장소 보기 모드 스펙](./place-view-mode.md)의 `초기 지도 위치`를 따른다.

### 검색 결과의 범위

검색으로 이동하는 것은 보기 모드와 지도가 보고 있는 영역에 영향을 받지 않는다. 검색이 어떤 항목을 찾는지는 [SearchHome 화면 스펙](./search-home.md)이 정한다.

### 새로고침 대상

PlaceHome의 새로고침 대상은 계정 데이터의 서버 동기화 하나다. 대상과 진행 표시 기준, 중복 요청 처리는 [새로고침 스펙](./sync-refresh.md)을 따르고, 두 보기 모드에서 당길 수 있는 자리는 [장소 보기 모드 스펙](./place-view-mode.md)의 `장소 목록 새로고침`을 따른다.

새로고침 대상 자체는 지도 표시 여부와 보기 모드로 달라지지 않는다.

로그인하지 않은 상태에서 당기면 서버 동기화가 시작되지 않고 진행 표시도 나타나지 않는다. 이때 목록에 노출하는 장소가 없는 것은 `노출 대상 장소`가 따르는 계정 기준의 결과이며 새로고침이 만드는 결과가 아니다.

## data

### 목록 조회

두 보기 모드의 목록과 지도 핀에 표시할 장소는 `노출 대상 장소`를 기준으로 로컬 저장소에서 조회한다. 조회 방식과 갱신 기준은 [장소 보기 모드 스펙](./place-view-mode.md)의 `목록 조회`를 따른다.
