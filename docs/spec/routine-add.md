# RoutineAdd 화면 스펙

이 문서는 사용자가 새 루틴을 작성하는 RoutineAdd 화면의 내용과 행동을 다룬다. RoutineAdd로 진입하는 흐름은 [RoutineHome 화면 스펙](./routine-home.md)에서, 설명 입력의 행동은 [설명 입력 컴포넌트 스펙](./description-input.md)에서, 루틴 목록과 함께 표시하는 배치는 [Routine 목록·상세 배치 스펙](./routine-list-detail.md)에서 다룬다.

디자인: [RoutineAdd 화면 디자인](../design/routine-add.md)

작성 상태 유지와 뒤로가기는 [항목 추가 화면 공통 스펙](./entity-add.md)을 따른다.

이번 범위는 사용자가 제목과 설명을 입력하는 것까지다. 입력한 내용으로 루틴을 추가해 저장하는 흐름은 이번 범위에 포함하지 않으므로 루틴이 갖는 정보, 추가 성립 조건과 저장 계약은 이 문서에서 다루지 않는다.

## feature

### 진입과 입력

사용자는 RoutineHome 화면에서 루틴 추가를 선택해 RoutineAdd 화면으로 이동한다.

사용자는 제목과 설명을 입력하거나 바꿀 수 있다. 제목은 한 줄 분량을 입력할 수 있다.

화면에 처음 진입하면 제목과 설명이 비어 있는 상태로 시작한다. 사용자가 제목부터 바로 입력할 수 있도록 입력 초점을 제목 입력에 둔다.

### 루틴 추가

루틴을 추가해 저장하는 흐름은 후속 범위에서 다룬다.

이번 범위에서 사용자가 추가를 실행해도 루틴은 저장되지 않고 입력 내용과 화면 상태도 바뀌지 않으며, 성공이나 실패 피드백도 제공하지 않는다.

### 작성 상태 유지

화면이 회전하거나 시스템에 의해 재생성되어도 입력 중이던 제목과 설명을 유지한다.

앱을 종료한 뒤 RoutineAdd 화면에 새로 진입하면 이전 작성 내용을 복원하지 않고 새로운 입력 상태로 시작한다.

### 뒤로가기

사용자가 뒤로가면 RoutineAdd 화면에 진입하기 전 화면으로 돌아간다.

목록과 상세를 함께 사용하는 동안에는 루틴 추가가 목록과 함께 놓이므로 이 화면만 따로 닫지 않는다. 그 기준은 [목록·상세 배치 공통 스펙](./list-detail-pane.md)의 `함께 사용과 단독 사용`를 따른다.
