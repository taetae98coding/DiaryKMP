# Memo 목록·상세 배치 스펙

이 문서는 메모 주요 목적지에서 목록과 상세가 함께 표시될 때 이 배치에만 해당하는 상세 영역 구성과 초기화 경계를 다룬다. 함께 사용과 단독 사용, 추가 진입 수단, 표시 비율 조절, 배치에 참여하는 화면과 유지·초기화의 공통 기준은 [목록·상세 배치 공통 스펙](./list-detail-pane.md)을 따른다. 목록 화면과 상세 영역 각 화면의 내용과 행동은 해당 화면 스펙([MemoAdd 화면 스펙](./memo-add.md) 등)에서 다룬다. TagMemoFinishedList에서 사용하는 목록·상세 배치는 [TagMemoFinishedList 목록·상세 배치 스펙](./tag-memo-finished-list-detail.md)에서 다룬다.

디자인: [Memo 목록·상세 배치 디자인](../design/memo-list-detail.md)

크기 조절 결과는 화면 표시 상태일 뿐 사용자 데이터의 생성이나 저장이 없어 `data` 영역은 생략한다.

## feature

### 상세 영역의 구성

목록과 상세 영역을 함께 표시하는 상태에서 상세 영역에는 사용자가 선택한 메모의 상세 화면이 표시되고, 선택한 메모가 없으면 메모 추가 화면이 표시된다.

한 영역만 표시되는 상태에서는 해당 화면 스펙의 행동을 그대로 제공한다.

## domain

### 유지와 초기화 기준

메모는 주요 목적지이므로 다른 주요 목적지로 이동했다가 메모로 돌아오는 것은 이 배치를 떠난 것으로 보지 않는다. 따라서 상세 선택과 조절한 비율은 목적지 이동을 넘어 유지하고, 앱을 종료하고 다시 실행할 때만 [목록·상세 배치 공통 스펙](./list-detail-pane.md)의 `유지와 초기화 기준`에 따라 초기화한다.
