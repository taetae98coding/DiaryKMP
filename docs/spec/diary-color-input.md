# DiaryColorInput 컴포넌트 스펙

이 문서는 사용자가 컬러를 확인하고 변경할 수 있는 공용 컴포넌트 DiaryColorInput의 사용자 관점 동작과 정책을 다룬다. 이 컴포넌트를 어느 화면에 배치할지와 선택한 컬러를 저장하는 동작은 이 문서의 범위가 아니다. 컴포넌트는 선택 상태만 다루고 사용자 데이터의 생성이나 저장이 없어 `data` 영역은 생략한다.

디자인: [DiaryColorInput 컴포넌트 디자인](../design/diary-color-input.md)

## feature

### 선택 컬러 확인

사용자는 현재 선택된 컬러와 그 컬러의 Hex 코드 및 R, G, B 채널 값을 확인할 수 있다.

### 컬러 편집

사용자는 현재 컬러를 기준으로 컬러 편집을 시작할 수 있다.

편집 중에는 다음 방법으로 컬러를 바꿀 수 있으며, 유효한 변경은 미리보기와 다른 편집 값에 함께 반영된다.

- R, G, B 각 채널 값 조절
- Hex 코드 직접 입력
- 무작위 컬러 생성

유효하지 않은 Hex 내용이 입력된 동안에는 편집 중인 컬러가 바뀌지 않고 마지막으로 유효했던 컬러를 유지한다.

### 확인과 취소

사용자가 편집을 확인하면 편집 화면이 닫히고 선택 컬러와 그 표시 값이 마지막으로 유효했던 편집 컬러로 바뀐다.

사용자가 편집을 취소하면 편집 중이던 컬러는 버려지고 기존 선택 컬러를 유지한다.

## domain

### 컬러 표현

컬러는 R, G, B 세 채널로 표현하며 투명도는 다루지 않는다.

각 채널 값의 범위는 0부터 255까지다.

Hex 코드는 `#`과 대문자 16진수 여섯 자리로 구성된 `#RRGGBB` 형식으로 표현한다.

### 유효한 Hex 입력 기준

Hex 입력은 16진수 여섯 자리를 유효한 것으로 본다. 맨 앞의 `#`은 있어도 되고 없어도 되며, 16진수 알파벳은 대소문자를 구분하지 않는다.

여섯 자리가 아니거나 16진수가 아닌 문자가 포함되면 유효하지 않은 것으로 보고 편집 중인 컬러에 반영하지 않는다.

### 초기 컬러

처음 선택되는 컬러는 컴포넌트를 배치하는 화면이 지정할 수 있다.

배치하는 화면이 초기 컬러를 지정하지 않으면 무작위로 정해진 컬러를 초기 컬러로 사용한다. 무작위로 정해진 초기 컬러도 지정된 초기 컬러와 동일하게 다뤄져, 화면이 재생성되어도 유지된다.

### 컬러 확정 기준

선택 컬러는 사용자가 편집을 확인했을 때만 바뀐다. 편집 중인 컬러는 확인 전까지 선택 컬러에 반영되지 않는다.

확인 시점에 적용되는 컬러는 마지막으로 유효했던 편집 컬러다. Hex 입력에 유효하지 않은 내용이 남아 있어도 마지막 유효 컬러가 적용된다.

### 진행 상태 유지

화면이 회전하거나 시스템에 의해 화면이 재생성되어도 선택 컬러는 유지된다.

컬러 편집 중 화면이 재생성되면 편집 상태와 편집 중이던 컬러도 유지된다.
