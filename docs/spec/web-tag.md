# 웹 태그 스펙

이 문서는 하나의 웹 항목이 여러 태그와 연결될 수 있다는 규칙 가운데 웹 항목에만 해당하는 부분을 다룬다. 태그 연결이 공통으로 지키는 규칙은 [항목 태그 연결 공통 스펙](./entity-tag.md)을, 연결의 성질과 저장·동기화 계약은 [항목 연결 공통 스펙](./entity-link.md)을 따른다.

웹 항목 자체의 추가·수정·삭제는 [WebAdd 화면 스펙](./web-add.md)과 [WebDetail 화면 스펙](./web-detail.md)을, 태그 자체의 추가·완료·삭제는 [TagAdd 화면 스펙](./tag-add.md)과 [TagDetail 화면 스펙](./tag-detail.md)을 따른다.

사용자가 태그를 고르고 해제하는 조작은 이 문서에서 다루지 않는다. 태그 선택의 행동과 정책은 [항목 태그 입력 컴포넌트 스펙](./entity-tag-input.md)에서, 구체적인 표현과 조작 수단은 [항목 태그 입력 컴포넌트 디자인](../design/entity-tag-input.md)에서 다룬다. 웹 항목을 추가하면서 태그를 연결하는 행동은 [WebAdd 화면 스펙](./web-add.md)에서, 이미 저장된 웹 항목의 태그 연결을 바꾸는 행동은 [WebDetail 화면 스펙](./web-detail.md)에서, 태그로 웹 항목을 찾아보는 목록은 [TagDetail 웹 탭 스펙](./tag-detail-web.md)에서 다룬다. 이 문서에는 사용자 조작이 없어 `feature` 영역을 생략한다.

## domain

### 연결이 바꾸지 않는 내용

연결은 웹 항목과 태그 사이의 관계이며, 웹 항목의 제목·설명·URL·요청 헤더나 태그의 이모지·제목·설명·컬러를 바꾸지 않는다.

### 대표 태그를 두지 않음

웹 항목은 [항목 태그 연결 공통 스펙](./entity-tag.md)의 `대표 태그`에 따라 대표 태그를 갖지 않는다. 웹 항목의 표시에 태그의 컬러를 쓰지 않으므로 대표 태그가 필요하지 않다.

### 연결의 의미

[항목 태그 연결 공통 스펙](./entity-tag.md)의 `연결의 의미`는 웹 항목에서 다음 목록에 적용된다.

- [WebHome 화면 스펙](./web-home.md)의 목록 노출 기준과 정렬
- [SearchHome 화면 스펙](./search-home.md)의 웹 검색 결과
