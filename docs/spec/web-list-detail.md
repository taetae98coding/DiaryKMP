# Web 목록·상세 배치 스펙

이 문서는 웹 목록과 상세 영역을 함께 사용할 때 이 배치에만 해당하는 상세 영역 구성과 초기화 경계를 다룬다. 함께 사용과 단독 사용, 추가 진입 수단, 표시 비율 조절, 배치에 참여하는 화면과 유지·초기화의 공통 기준은 [목록·상세 배치 공통 스펙](./list-detail-pane.md)을 따른다. 각 화면의 내용과 행동은 [WebHome 화면 스펙](./web-home.md), [WebAdd 화면 스펙](./web-add.md), [WebDetail 화면 스펙](./web-detail.md)에서 다룬다.

디자인: [Web 목록·상세 배치 디자인](../design/web-list-detail.md)

표시 비율은 화면 표시 상태일 뿐 사용자 데이터를 만들거나 저장하지 않으므로 `data` 영역은 생략한다.

## feature

### 상세 영역의 구성

상세 영역에는 언제나 웹 추가가 놓인다. 사용자는 목록을 떠나지 않고 곧바로 제목, 설명, URL과 요청 헤더를 입력한다.

추가에 성공한 뒤에도 상세 영역은 웹 추가로 남으므로 사용자는 다음 웹 항목을 이어서 작성하고, 방금 추가한 웹 항목이 목록에 나타나는 것을 같은 화면에서 확인한다.

한 화면만 제공하는 환경에서 화면 사이의 이동은 [WebHome 화면 스펙](./web-home.md)의 `웹 추가로 이동`을 따른다.

### 웹 항목 선택

사용자가 목록에서 웹 항목을 선택하면 [WebDetail 화면](./web-detail.md)으로 이동한다. 웹 상세는 배치에 참여하지 않으므로, 이동한 뒤에는 목록과 상세 영역을 함께 표시하지 않고 웹 상세만 사용한다.

웹 상세에서 뒤로 돌아오면 다시 웹 목록과 웹 추가를 함께 사용하는 상태로 돌아오고, 사용자가 보고 있던 목록을 그대로 본다.

### 검색으로 이동

목록에서 검색으로 이동하는 행동은 배치와 관계없이 [WebHome 화면 스펙](./web-home.md)의 `검색으로 이동`을 따른다. 검색 화면은 목록과 함께 표시하지 않는다.

## domain

### 배치에 참여하지 않는 화면

웹 상세는 배치에 참여하지 않는다. 웹 상세는 저장된 웹 항목의 수정 입력과 그 주소로 불러온 웹 페이지를 함께 제공하므로, 목록과 나란히 두지 않고 언제나 단독으로 표시한다.

### 유지와 초기화 기준

사용자가 `더보기` 화면으로 돌아가는 것을 이 배치를 떠난 것으로 본다. 그 뒤 웹 화면에 다시 진입하거나 앱을 종료하고 다시 실행하면 [목록·상세 배치 공통 스펙](./list-detail-pane.md)의 `유지와 초기화 기준`에 따라 기본 비율로 초기화한다.
