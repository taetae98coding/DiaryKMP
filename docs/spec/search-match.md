# 검색어 일치 판정 스펙

이 문서는 사용자가 입력한 검색어로 항목을 좁힐 때, 어떤 값을 판정에 쓰고 무엇을 일치로 보며 입력을 언제 반영하는지를 다룬다.

검색어를 어디에서 입력하고 결과를 어떻게 보여 주는지, 검색어가 비어 있을 때 무엇을 노출하는지, 결과를 어떤 순서로 정렬하는지는 이 문서를 참조하는 각 문서가 소유한다.

## domain

### 검색어

검색어는 사용자가 입력한 문자열이다. 검색어의 앞뒤 공백은 판정에 쓰지 않으며, 앞뒤 공백을 뺀 결과가 비어 있으면 빈 검색어로 본다.

앞뒤 공백을 빼는 것은 목록을 좁히는 규칙이 맡는다. 검색어를 입력받는 화면은 사용자가 입력한 값을 그대로 넘기고, 넘겨받은 쪽이 판정에 쓸 값을 만든다. 외부 서비스로 보내는 검색도 같은 기준을 쓰므로, 제품이 어떤 값으로 좁혔는지가 검색어를 어디에서 입력했는지에 따라 달라지지 않는다.

빈 검색어에서 무엇을 노출하는지는 이 문서가 정하지 않는다. 목록마다 빈 검색어의 의미가 다르므로 각 문서가 소유한다.

### 일치 판정

항목은 자신의 판정 대상 값 중 하나 이상이 검색어를 포함하면 검색어를 만족한다. 값 전체가 검색어와 같을 필요는 없으며, 대소문자는 구분하지 않는다.

대소문자를 구분하지 않는 범위는 ASCII 영문자다. 악센트가 붙은 라틴 문자처럼 ASCII 밖의 글자는 대소문자를 맞추지 않고 글자 그대로 비교한다. 한글에는 대소문자가 없어 이 구분이 영향을 주지 않으며, 제품이 다루는 검색어는 한글과 ASCII 영문자가 대부분이므로 그 밖의 글자까지 맞추지 않는다.

유형별 판정 대상 값은 다음과 같다.

| 유형 | 판정 대상 값 |
| --- | --- |
| 메모 | 제목, 설명 |
| 태그 | 이모지, 제목, 설명 |
| 장소 | 제목, 설명, 주소 |
| 웹 | 제목, 설명, URL |

컬러, 기간, 좌표, 웹 항목의 요청 헤더, 생성 시각과 수정 시각은 판정에 쓰지 않는다. 메모와 태그, 메모와 장소의 연결도 판정에 쓰지 않으므로, 연결된 태그의 제목이 검색어를 포함해도 그 메모는 검색어를 만족하지 않는다.

검색어를 만족하는 항목 가운데 무엇을 노출할지는 각 문서의 노출 기준을 함께 따른다. 일치 판정은 노출 순서를 정하지 않는다.

### 검색어 반영 시점

검색어는 사용자가 입력을 멈춘 뒤에 목록에 반영한다. 입력하는 동안 글자마다 목록을 다시 조회하지 않으므로, 사용자는 검색어를 끝까지 입력한 뒤 그 결과를 받는다.

검색어를 비우는 것은 기다리지 않고 곧바로 반영한다. 좁히기를 취소하는 조작이므로 사용자는 지우는 즉시 좁히지 않은 목록으로 돌아간다.

반영하기 전까지는 직전에 반영한 검색어의 결과를 그대로 둔다. 목록이 비었다가 다시 차지 않으며, 반영을 기다리는 중임을 따로 알리지 않는다.

입력을 멈췄다고 보는 기준과 기다리는 시간은 [입력 정지 대기 시간 스펙](./input-idle-delay.md)을 따른다.

### 검색 결과 없음 판정

목록은 다음을 모두 만족할 때만 검색어에 맞는 항목이 없다고 알린다.

- 검색어가 비어 있지 않다. 비어 있는지의 기준은 `검색어`를 따른다.
- 목록을 준비하는 것이 끝났고 노출할 항목이 하나도 없다. 준비 여부의 기준은 [페이지 조회 목록의 자리 표시 스펙](./paged-list-placeholder.md)의 `빈 상태 판정`을 따른다.

조회하지 못한 것은 노출할 항목이 없는 것과 같게 본다.

무엇을 알리고 그 자리에서 어떤 행동을 제공하는지는 각 문서가 소유한다.
