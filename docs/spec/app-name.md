# 앱 이름 스펙

이 문서는 빌드 환경마다 사용자에게 보이는 앱 이름을 다룬다. 사용자가 직접 수행하는 행동은 없고 저장하는 데이터도 없으므로 `feature`와 `data` 영역은 생략한다.

## domain

### 빌드 환경별 앱 이름

앱 이름은 개발·운영 환경과 디버그·릴리스 빌드 조합으로 정한다. 같은 기기에 여러 환경의 앱을 함께 설치해도 이름만으로 구분할 수 있어야 한다.

| 환경 | 빌드 | 앱 이름 |
| --- | --- | --- |
| 개발 | 디버그 | `DiaryDev` |
| 개발 | 릴리스 | `DiaryDev` |
| 운영 | 디버그 | `DiaryRealDebug` |
| 운영 | 릴리스 | `Diary` |

디버그와 릴리스를 나누지 않는 플랫폼은 환경만으로 정한다. 개발 환경은 `DiaryDev`, 운영 환경은 `Diary`를 쓴다.

### 앱 이름이 보이는 곳

- Android: 런처와 시스템 설정에 표시되는 앱 이름
- iOS: 홈 화면과 시스템 설정에 표시되는 앱 이름
- JVM 데스크톱: 창 제목과 배포 패키지의 앱 이름
- 웹: 브라우저 탭 제목

앱 이름은 저장 영역 이름을 정하지 않는다. JVM 데스크톱의 저장 영역은 [JVM 데이터베이스 저장 스펙](./jvm-database-storage.md)을 따른다.
