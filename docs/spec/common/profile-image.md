# 프로필 이미지 변경 스펙

이 문서는 프로필 이미지를 반영할 때 앱이 서버에 올리는 이미지와 서버가 돌려주는 결과의 약속을 다룬다.

앱이 사진을 바꿔 올리고 결과를 읽는 흐름은 [프로필 이미지 변경 스펙(client)](../client/profile-image.md)이, 서버가 이미지를 검증하고 보관해 계정에 반영하는 처리는 [프로필 이미지 변경 스펙(server)](../server/profile-image.md)이 소유한다.

## data

### 올리는 이미지

앱은 반영 한 번에 이미지 하나를 올린다.

| 약속 | 내용 |
| --- | --- |
| 형식 | JPEG 하나. 앱이 JPEG로 바꾼 뒤 올리고, 서버는 JPEG만 받는다. |
| 크기 | 5MB 이하. 앱은 크기를 미리 거르지 않고 올리며, 서버가 넘는 이미지를 거절한다. |
| 로그인 | 인증된 로그인 세션으로 올린다. 반영 대상 계정은 세션의 계정이다. |

### 반영 결과

반영에 성공하면 서버는 새 프로필 이미지의 주소를 돌려주고, 같은 주소가 계정의 프로필 이미지와 인증 제공자가 알리는 사용자 정보의 프로필 이미지가 된다. 반영에 실패하면 서버는 실패를 돌려주고 두 곳의 프로필 이미지는 바뀌지 않는다.

프로필 이미지 주소는 로그인 없이 그 주소만으로 이미지를 볼 수 있는 주소다.
