# 태그 연결 스펙

이 문서는 하나의 태그가 다른 태그로 향하는 단방향 연결을 가질 수 있다는 규칙 가운데 태그와 태그의 연결에만 해당하는 부분을 다룬다. 연결의 성질과 동기화 계약은 [항목 연결 공통 스펙](./entity-link.md)을, 앱이 연결을 기기에 저장하는 규칙은 [항목 연결 앱 스펙](../client/entity-link.md)을 따른다. 앱이 기기에 저장된 연결로 연결된 태그와 하위 태그를 조회하는 규칙, 향해 오는 연결의 존재 판정, 태그의 상태 변화가 그 조회와 판정에 주는 영향, 아래 `연결의 의미`가 앱의 목록에 적용되는 범위와 예외는 [태그 연결 앱 스펙](../client/tag-link.md)이 소유한다.

태그 자체의 추가·수정·완료·삭제는 [TagAdd 화면 스펙](../client/tag-add.md), [TagDetail 화면 스펙](../client/tag-detail.md), [TagHome 목록 스펙](../client/tag-home.md), [TagFinishedList 화면 스펙](../client/tag-finished-list.md)을 따르고, 메모·웹 항목·장소와 태그의 연결은 [항목 태그 연결 공통 스펙](./entity-tag.md)과 각 연결 스펙을 따른다.

사용자가 연결을 만들고 해제하는 조작과 연결된 태그를 화면에 보여 주는 방법은 [태그 연결 입력 컴포넌트 스펙](../client/tag-link-input.md)이 소유하므로 이 문서에는 `feature` 영역을 두지 않는다.

## domain

### 태그와 태그의 연결

태그 연결은 한 태그에서 다른 태그로 향하는 단방향 관계다. 연결은 출발 태그 하나와 도착 태그 하나를 가진다.

하나의 태그는 여러 태그로 향하는 연결을 가질 수 있고, 여러 태그로부터 향해 오는 연결을 받을 수 있다.

출발 태그와 도착 태그를 바꾼 반대 방향의 연결은 별개의 연결이다. 두 방향의 연결이 함께 있어도 허용하며, 한 방향을 해제해도 반대 방향은 해제되지 않는다.

태그를 자기 자신과 연결할 수 없다. 출발 태그와 도착 태그가 같은 연결은 만들 수 없다.

연결은 태그 사이의 관계이며, 어느 쪽 태그의 이모지·제목·설명·컬러도 바꾸지 않는다.

### 연결의 의미

태그 연결은 태그 사이의 관계를 나타내는 것으로 끝난다. [항목 연결 공통 스펙](./entity-link.md)의 `연결의 의미`에 따라 연결을 따라 다른 태그의 메모나 웹 항목이나 장소가 함께 모이지 않는다. 앱에서 이 규칙이 적용되는 목록과 예외는 [태그 연결 앱 스펙](../client/tag-link.md)의 `연결의 의미`를 따른다.

태그를 연결해도 메모와 태그의 연결, 웹 항목과 태그의 연결, 장소와 태그의 연결은 바뀌지 않으며, 그 항목들에 연결된 태그는 늘어나지 않는다. 각 연결의 규칙은 [항목 태그 연결 공통 스펙](./entity-tag.md)을 따른다.

순환하는 연결과 여러 단계로 이어지는 연결에 별도의 제한을 두지 않는다. 연결을 따라 항목을 모으지 않으므로 순환은 결과에 영향을 주지 않으며, 앱의 예외 목록이 연결을 따라갈 때 순환에서 어떻게 끝나는지는 [태그 연결 앱 스펙](../client/tag-link.md)의 `하위 태그의 조회`를 따른다.
