# 항목 태그 연결 공통 스펙

이 문서는 메모, 장소, 웹 항목이 태그와 맺는 연결이 공통으로 지키는 규칙을 다룬다. 연결이 공통으로 가지는 성질과 동기화 계약은 [항목 연결 공통 스펙](./entity-link.md)을 따르고, 이 문서는 그 위에서 태그 연결에만 적용되는 규칙을 소유한다. 앱이 기기에 저장된 연결로 대상 항목의 태그와 태그의 대상 항목을 조회하는 규칙은 [항목 태그 연결 앱 스펙](../client/entity-tag.md)이 소유한다.

이 문서를 따르는 연결 스펙은 다음과 같다.

- [메모 태그 스펙](./memo-tag.md)
- [웹 태그 스펙](./web-tag.md)
- [장소 태그 스펙](./place-tag.md)

태그와 태그를 잇는 연결은 대상이 태그이므로 이 문서가 아니라 [태그 연결 스펙](./tag-link.md)이 소유한다.

사용자가 태그를 고르고 해제하는 조작은 이 문서에서 다루지 않는다. 태그 선택의 행동과 정책은 [태그 선택 입력 공통 스펙](../client/tag-select-input.md)과 각 입력 컴포넌트 스펙에서, 항목을 추가하거나 수정하면서 연결을 바꾸는 행동은 각 화면 스펙에서 다룬다. 이 문서에는 사용자 조작이 없어 `feature` 영역을 생략한다.

이 문서에서 `대상 항목`은 태그와 연결되는 메모, 장소 또는 웹 항목 하나를 가리킨다.

## domain

### 대상 항목과 태그의 연결

대상 항목은 여러 태그와 연결될 수 있고, 하나의 태그도 여러 대상 항목과 연결될 수 있다.

연결된 태그가 없는 것이 대상 항목의 기본 상태이며, 같은 대상 항목과 같은 태그 사이의 연결이 하나만 존재한다는 규칙은 [항목 연결 공통 스펙](./entity-link.md)의 `연결의 성질`을 따른다.

대상 항목의 종류마다 연결이 바꾸지 않는 항목의 내용은 각 연결 스펙에서 밝힌다.

### 연결할 수 있는 태그

대상 항목에 연결할 수 있는 태그는 그 대상 항목을 변경하는 계정과 연결된 태그다. 계정과 연결되지 않은 태그는 대상 항목에 연결할 수 없다.

새로 연결할 수 있는 태그를 완료 여부와 삭제 여부로 좁히는 기준은 [태그 선택 입력 공통 스펙](../client/tag-select-input.md)의 `선택할 수 있는 태그`를 따른다.

### 대표 태그

대상 항목은 연결된 태그 중 하나를 대표 태그로 갖지 않는다. 연결된 태그는 모두 같은 자격의 연결이며, 그 사이에 순위나 대표 관계를 두지 않는다.

메모만 예외로 대표 태그를 가진다. 그 규칙은 [메모 대표 태그 스펙](./memo-primary-tag.md)이 소유하며, 메모가 아닌 대상 항목에는 적용하지 않는다.

대표 태그를 두지 않는 대상 항목은 표시에 태그의 컬러를 빌려 오지 않는다. 태그를 연결하거나 해제해도 그 대상 항목의 표시 색은 바뀌지 않는다.

### 태그와 대상 항목의 상태 변화

태그를 완료하거나 삭제해도, 대상 항목을 완료하거나 삭제해도 연결은 해제되지 않는다. 자세한 기준은 [항목 연결 공통 스펙](./entity-link.md)의 `항목의 상태 변화와 연결`을 따른다.

대상 항목의 내용 수정은 태그 연결을 바꾸지 않고, 태그의 이모지·제목·설명·컬러 수정도 연결을 바꾸지 않는다.

### 연결의 의미

대상 항목과 태그의 연결은 두 항목의 관계를 나타내는 것으로 끝난다. 이 연결은 다음을 바꾸지 않는다.

- 대상 항목이 자기 목록에 나타나는 기준과 정렬. 태그 연결 여부는 그 목록의 노출과 순서를 바꾸지 않는다. 사용자가 고른 태그 필터와 유무 필터의 태그 축, 태그를 기준으로 대상 항목을 모아 보여 주는 TagDetail 화면의 탭은 예외이며, 그 기준은 [항목 연결 공통 스펙](./entity-link.md)의 `연결의 의미`를 따른다.
- [SearchHome 화면 스펙](../client/search-home.md)의 검색 결과. 연결된 태그의 제목은 대상 항목의 검색 일치 판정에 쓰이지 않는다.
- 다른 종류의 연결. 대상 항목과 태그의 연결은 종류마다 서로 별개이며, 한 종류의 연결을 만들어도 다른 종류의 연결은 늘어나지 않는다.

태그와 태그의 연결을 따라 대상 항목이 함께 조회되지 않는다. 이 규칙은 [태그 연결 스펙](./tag-link.md)의 `연결의 의미`가, 앱에서의 적용 목록과 예외는 [태그 연결 앱 스펙](../client/tag-link.md)의 `연결의 의미`가 소유한다.
