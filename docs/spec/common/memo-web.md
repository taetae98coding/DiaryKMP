# 메모 웹 스펙

이 문서는 하나의 메모가 여러 웹 항목과 연결될 수 있다는 규칙 가운데 메모와 웹 항목의 연결에만 해당하는 부분을 다룬다. 연결의 성질과 동기화 계약은 [항목 연결 공통 스펙](./entity-link.md)을 따르고, 앱이 기기에 저장된 연결로 메모의 웹 항목과 웹 항목의 메모를 조회하는 규칙과 이 연결이 앱의 목록과 검색 결과에 주는 영향(`연결의 의미`)은 [메모 웹 앱 스펙](../client/memo-web.md)이 소유한다.

웹 항목 자체의 추가와 웹 항목이 갖는 정보는 [WebAdd 화면 스펙](../client/web-add.md)을, 웹 항목의 수정과 삭제는 [WebDetail 화면 스펙](../client/web-detail.md)을 따른다.

사용자가 웹 항목을 고르고 해제하는 조작은 이 문서에서 다루지 않는다. 웹 항목 선택의 행동과 정책은 [메모 웹 입력 컴포넌트 스펙](../client/memo-web-input.md)에서, 구체적인 표현과 조작 수단은 [메모 웹 입력 컴포넌트 디자인](../../design/memo-web-input.md)에서 다룬다. 메모를 추가하면서 웹 항목을 연결하는 행동은 [MemoAdd 화면 스펙](../client/memo-add.md)에서, 이미 저장된 메모의 웹 연결을 바꾸는 행동은 [MemoDetail 화면 스펙](../client/memo-detail.md)에서, 웹 항목으로 메모를 찾아보는 목록은 [WebDetail 메모 탭 스펙](../client/web-detail-memo.md)에서 다룬다. 이 문서에는 사용자 조작이 없어 `feature` 영역을 생략한다.

메모와 태그의 연결은 이 문서가 다루는 연결과 별개이며 [메모 태그 스펙](./memo-tag.md)이, 웹 항목과 태그의 연결은 [웹 태그 스펙](./web-tag.md)이 소유한다.

## domain

### 메모와 웹 항목의 연결

메모는 여러 웹 항목과 연결될 수 있고, 하나의 웹 항목도 여러 메모와 연결될 수 있다.

연결은 메모와 웹 항목 사이의 관계이며, 메모의 제목·설명·컬러·기간이나 웹 항목의 제목·설명·URL·요청 헤더를 바꾸지 않는다.

### 대표 웹 항목을 두지 않음

메모는 연결된 웹 항목 중 하나를 대표로 갖지 않는다. 연결된 웹 항목은 모두 같은 자격의 연결이며, 그 사이에 순위나 대표 관계를 두지 않는다.

메모의 표시에 웹 항목의 값을 쓰지 않으므로 대표 웹 항목이 필요하지 않다. 메모가 갖는 대표 태그의 규칙은 [메모 대표 태그 스펙](./memo-primary-tag.md)이 소유하며 웹 연결에는 적용하지 않는다.
