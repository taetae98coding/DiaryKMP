# 메모 태그 스펙

이 문서는 하나의 메모가 여러 태그와 연결될 수 있다는 규칙 가운데 메모에만 해당하는 부분을 다룬다. 태그 연결이 공통으로 지키는 규칙은 [항목 태그 연결 공통 스펙](./entity-tag.md)을, 연결의 성질과 동기화 계약은 [항목 연결 공통 스펙](./entity-link.md)을 따른다. 이 연결이 앱의 목록과 검색 결과에 주는 영향(`연결의 의미`)은 [메모 태그 앱 스펙](../client/memo-tag.md)이 소유한다.

메모가 태그 하나를 대표 태그로 가지는 규칙과, 대표 태그 지정과 연결이 동기화에서 어긋날 수 있는 범위는 [대표 태그 공통 스펙](./primary-tag.md)을 따르고, 태그 자체의 추가·완료·삭제는 [TagAdd 화면 스펙](../client/tag-add.md)과 [TagDetail 화면 스펙](../client/tag-detail.md)을 따른다.

사용자가 태그를 고르고 해제하는 조작은 이 문서에서 다루지 않는다. 태그 선택의 행동과 정책은 [대표 태그 입력 컴포넌트 스펙](../client/primary-tag-input.md)에서, 구체적인 표현과 조작 수단은 [대표 태그 입력 컴포넌트 디자인](../../design/primary-tag-input.md)에서 다룬다. 메모를 추가하면서 태그를 연결하는 행동은 [MemoAdd 화면 스펙](../client/memo-add.md)에서, 이미 저장된 메모의 태그 연결을 바꾸는 행동은 [MemoDetail 화면 스펙](../client/memo-detail.md)에서, 태그로 메모를 찾아보는 목록은 [TagDetail 메모 탭 스펙](../client/tag-detail-memo.md)에서 다룬다. 이 문서에는 사용자 조작이 없어 `feature` 영역을 생략한다.

메모와 장소의 연결은 이 문서가 다루는 연결과 별개이며 [메모 장소 스펙](./memo-place.md)이 소유한다.

## domain

### 연결이 바꾸지 않는 내용

연결은 메모와 태그 사이의 관계이며, 메모의 제목·설명·컬러·기간이나 태그의 이모지·제목·설명·컬러를 바꾸지 않는다.

### 대표 태그

메모는 [항목 태그 연결 공통 스펙](./entity-tag.md)의 `대표 태그`에 따라 대표 태그를 가질 수 있다. 그 규칙은 [대표 태그 공통 스펙](./primary-tag.md)을 따른다.
