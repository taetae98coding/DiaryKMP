# 일일 메모 알림 스펙

이 문서는 서버가 보내고 기기가 표시하는 일일 메모 알림에 담기는 정보와 그 의미를 다룬다. 서버와 앱은 이 문서의 의미대로 알림을 만들고 표시한다.

무엇을 언제 누구에게 보내는지는 [일일 메모 알림 스펙(server)](../server/daily-memo-notification.md)이, 기기가 알림을 표시하고 사용자가 알림으로 앱을 여는 것은 [일일 메모 알림 스펙(client)](../client/daily-memo-notification.md)이 소유한다. 문구와 아이콘, 알림 분류의 이름은 [일일 메모 알림 디자인](../../design/daily-memo-notification.md)이 소유한다.

## domain

### 알림 내용

알림 내용은 오늘의 메모를 정한 결과에 따라 다음 세 가지 중 하나다. 오늘의 메모의 기준은 [일일 메모 알림 스펙(server)](../server/daily-memo-notification.md)의 `오늘의 메모`를 따른다.

| 내용 | 뜻 | 제목 | 본문 |
| --- | --- | --- | --- |
| 목록 | 오늘의 메모가 1개 이상 있다 | 오늘의 메모 개수를 알리는 문구 | 오늘의 메모 제목 목록 |
| 없음 | 오늘의 메모가 하나도 없다 | 메모가 없다는 문구 | 없음 |
| 확인 안내 | 서버가 오늘의 메모를 정하지 못했다 | 오늘의 메모를 확인하라는 문구 | 없음 |

제목과 본문은 서버가 기기의 등록 언어로 완성해 보낸다. 앱은 받은 제목과 본문을 고치거나 다시 만들지 않고 그대로 표시한다.

### 알림에 담기는 정보

알림에는 제목과 본문 외에 다음 정보를 함께 담는다.

| 정보 | 뜻 |
| --- | --- |
| 같은 날 알림 식별 값 | 모든 일일 메모 알림이 같은 값을 가진다. 기기는 같은 값을 가진 알림이 새로 오면 앞서 표시한 알림을 새 알림으로 대신한다. |
| 도착 기한 | 알림이 발생한 날이 기기 시간대로 끝나는 시각. 이 시각까지 기기에 도착하지 못한 알림은 버린다. |
| 알림 분류 | Android에서 이 알림을 표시할 알림 분류. 앱이 같은 분류를 미리 만들어 두며, 사용자가 시스템 설정에서 이 분류만 끌 수 있다. |
| 알림 아이콘 | Android에서 알림에 쓸 작은 아이콘. 앱이 같은 아이콘을 가지고 있다. |

알림에는 앱이 읽어 화면을 정하는 추가 정보를 담지 않는다. 알림으로 앱을 열어도 특정 화면으로 이동하지 않는 것은 이 때문이다.
