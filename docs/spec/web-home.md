# WebHome 화면 스펙

이 문서는 사용자가 `더보기`의 `웹` 메뉴에서 진입하는 WebHome 화면의 내용과 행동을 다룬다. `더보기` 메뉴 영역의 표시와 선택은 [MoreHome 화면 스펙](./more-home.md)에서, 세부 화면에서의 공통 내비게이션 노출 규칙은 [TopLevelNavigation 스펙](./top-level-navigation.md)에서, 웹 항목을 작성해 추가하는 흐름과 웹 항목이 갖는 정보는 [WebAdd 화면 스펙](./web-add.md)에서, 선택한 웹 항목의 상세와 웹 페이지 불러오기는 [WebDetail 화면 스펙](./web-detail.md)에서, 웹 목록과 웹 추가를 함께 사용하는 배치는 [Web 목록·상세 배치 스펙](./web-list-detail.md)에서, 화면에서 검색으로 이동한 뒤의 내용과 행동은 [SearchHome 화면 스펙](./search-home.md)에서, 페이지 단위로 조회하는 목록이 나타나는 순서와 아직 준비되지 않은 자리의 처리는 [페이지 조회 목록의 자리 표시 스펙](./paged-list-placeholder.md)에서, 목록이 비어 있을 때의 안내는 [목록 빈 상태 스펙](./list-empty-state.md)에서, 목록을 당겨 새로고침하는 행동과 동기화 진행 표시는 [새로고침 스펙](./sync-refresh.md)에서, 웹 항목을 서버와 맞추는 규칙은 [데이터 동기화 스펙](./data-sync.md)에서 다룬다.

디자인: [WebHome 화면 디자인](../design/web-home.md)

이번 범위는 `더보기`에서 WebHome으로 이동하고, 계정에 저장된 웹 항목을 저장소에서 조회해 목록으로 표시하고, 목록을 당겨 새로고침하고, WebHome에서 웹 추가와 웹 상세와 검색으로 이동하는 것까지다. 웹 항목을 수정하고 삭제하는 흐름은 [WebDetail 화면 스펙](./web-detail.md)에서 다루며, 이 문서는 수정한 웹 항목이 목록에 반영되고 삭제한 웹 항목이 목록에서 사라지는 것까지만 다룬다.

## feature

### 진입

사용자는 `더보기` 화면의 메뉴 영역에서 `웹` 항목을 선택해 WebHome 화면으로 이동한다.

### 웹 목록

사용자는 WebHome에서 계정에 저장된 웹 항목 전체를 목록으로 볼 수 있다. 사용자는 각 항목의 제목과 URL을 확인한다.

웹 항목의 설명은 목록에 표시하지 않는다. 설명은 [WebAdd 화면 스펙](./web-add.md)의 `웹 항목의 정보`가 정의한 대로 웹 항목에 기록되지만, 목록에서는 어떤 웹 항목인지 알아보는 데 필요한 제목과 URL만 보여 준다.

목록이 나타나는 순서와 아직 준비되지 않은 자리의 처리는 [페이지 조회 목록의 자리 표시 스펙](./paged-list-placeholder.md)을 따른다. 사용자는 목록을 계속 내려 계정의 웹 항목을 모두 확인할 수 있다.

웹 항목을 추가하면 그 항목이 목록에 나타난다.

### 빈 상태

표시할 웹 항목이 하나도 없으면 목록 자리에 아직 웹 항목이 없으며 새로 추가할 수 있음을 알린다. 판정 시점, 빈 상태에서 할 수 있는 행동, 목록과의 전환은 [목록 빈 상태 스펙](./list-empty-state.md)을 따른다.

빈 상태에서도 사용자는 웹 추가, 검색, 당겨서 새로고침을 그대로 실행할 수 있다.

### 새로고침

사용자는 목록을 아래로 당겨 계정 데이터를 서버와 다시 맞추도록 요청할 수 있다. 당기는 조작이 시작하는 동기화, 진행 표시 기준과 실패 처리는 [새로고침 스펙](./sync-refresh.md)을 따른다.

새로고침으로 내려받은 웹 항목은 사용자가 별도 조작을 하지 않아도 목록에 반영된다.

### 웹 추가로 이동

사용자는 WebHome에서 웹 추가를 선택해 [WebAdd 화면](./web-add.md)으로 이동한다.

웹 추가는 목록의 내용과 무관하게 언제나 실행할 수 있다. 노출할 웹 항목이 없어 목록이 비어 있는 상태에서도 사용자는 웹 추가로 이동할 수 있다.

목록과 상세를 함께 사용할 수 있는 환경에서는 이미 상세 영역에서 웹 항목을 작성할 수 있으므로 목록에서 웹 추가로 이동하지 않는다. 판단 기준은 [목록·상세 배치 공통 스펙](./list-detail-pane.md)의 `추가 진입 수단`을 따른다.

웹 추가에서 뒤로 돌아오면 WebHome으로 돌아오고, 추가한 웹 항목이 반영된 목록을 본다.

### 검색으로 이동

사용자는 WebHome에서 검색을 선택해 [SearchHome 화면](./search-home.md)으로 이동한다.

이동한 화면은 웹 검색 결과부터 보여 준다. 시작 유형의 기준은 [SearchHome 화면 스펙](./search-home.md)의 `진입 경로와 시작 유형`을 따른다.

검색은 목록의 내용과 무관하게 언제나 실행할 수 있다. 사용자가 목록을 얼마나 내려 확인했는지도 검색 결과를 좁히지 않으므로, 사용자는 아직 목록에서 보지 못한 웹 항목도 검색으로 찾는다.

사용자가 검색 화면에서 뒤로 가면 WebHome으로 돌아오며, 검색으로 떠나기 전 상태의 목록을 그대로 본다.

### 웹 상세로 이동

사용자는 목록의 웹 항목을 선택해 그 웹 항목의 [WebDetail 화면](./web-detail.md)으로 이동한다.

웹 상세에서 뒤로 돌아오면 WebHome으로 돌아오고, 사용자가 보고 있던 목록을 그대로 본다.

아직 준비되지 않은 자리는 선택할 수 없다. 자리 표시 상태의 자리를 다루는 규칙은 [페이지 조회 목록의 자리 표시 스펙](./paged-list-placeholder.md)의 `자리 표시`를 따른다.

### 뒤로가기

사용자가 뒤로가기를 실행하면 [TopLevelNavigation 스펙](./top-level-navigation.md)의 `더보기 하위 화면의 뒤로가기`에 따라 `더보기`로 돌아간다.

### 정렬 선택

사용자는 목록 위에서 현재 정렬을 확인하고 다른 기준으로 바꿀 수 있다. 고를 수 있는 기준과 정렬 선택·반영·유지의 결과는 [목록 정렬 스펙](./list-sort.md)을 따른다.

## domain

### 목록에 노출하는 웹 항목

목록에는 현재 사용자 계정과 연결되어 있고 삭제되지 않은 웹 항목을 모두 노출한다. 계정 조회 규칙은 [계정 조회 스펙](./account.md)을 따르며, 현재 계정을 확인할 수 없으면 노출하는 웹 항목은 없다.

목록은 사용자가 확인하는 만큼 이어서 준비한다. 아직 준비되지 않은 구간의 웹 항목도 노출 기준을 만족하는 항목에 포함되며, 사용자가 목록을 얼마나 확인했는지는 노출 기준과 정렬 기준을 바꾸지 않는다.

### 목록 정렬

목록은 제목 오름차순으로 정렬한다. 제목이 같은 웹 항목끼리의 순서는 정하지 않는다.

위 순서는 사용자가 정렬을 고르지 않았을 때의 순서이며, 사용자가 고를 수 있는 다른 기준과 그 순서는 [목록 정렬 스펙](./list-sort.md)이 정한다.

### 목록 갱신

웹 항목이 추가되거나 저장 상태가 바뀌면 목록을 노출 기준과 정렬 기준에 따라 자동 갱신한다. 서버에서 내려받은 웹 항목이 기기에 반영된 것도 저장 상태가 바뀐 것으로 보고 같은 기준으로 갱신한다.

## data

### 목록 조회

목록에 표시할 웹 항목은 현재 사용자 계정을 기준으로 로컬 저장소에서 `domain`의 노출 기준과 정렬 순서로 페이지 단위로 조회한다. 페이지를 이어서 조회하는 기준은 [페이지 조회 목록의 자리 표시 스펙](./paged-list-placeholder.md)의 `페이지 조회`를 따른다.

저장된 웹 항목이 바뀌면 조회 결과도 그에 맞게 갱신되어 목록에 반영된다.

목록을 조회하지 못하면 웹 항목이 없는 것과 같게 다루고 별도의 오류 안내는 제공하지 않는다. 이때의 표시는 [목록 빈 상태 스펙](./list-empty-state.md)의 `빈 상태 판정 기준`을 따른다.

WebHome에 진입하는 것만으로는 서버에서 웹 항목을 다시 가져오지 않는다. 서버와 맞추는 조회는 사용자가 목록을 당겨 새로고침했을 때와 [데이터 동기화 스펙](./data-sync.md)이 정한 계기에서만 일어난다.
