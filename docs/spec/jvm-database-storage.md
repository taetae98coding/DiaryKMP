# JVM 데이터베이스 저장 스펙

이 문서는 JVM 앱의 flavor별 로컬 데이터베이스 저장 영역을 다룬다. 화면에 표시되는 기능이나 사용자가 직접 수행하는 행동은 없으므로 `feature`와 `domain` 영역은 생략한다.

## data

### flavor별 저장 영역

JVM 앱의 개발 환경과 운영 환경은 서로 다른 로컬 데이터베이스 저장 영역을 사용한다.

- 개발 flavor는 사용자의 Application Support 아래 `DiaryDev` 영역에 데이터베이스를 저장한다.
- 운영 flavor는 사용자의 Application Support 아래 `Diary` 영역에 데이터베이스를 저장한다.

한 flavor에서 생성하거나 변경한 로컬 데이터는 다른 flavor에서 조회하거나 변경하지 않는다.

### 저장 영역 변경

앱은 flavor에 지정된 저장 영역이 없으면 처음 데이터베이스를 사용할 때 생성한다.

기존 저장 영역의 데이터베이스를 다른 flavor의 저장 영역으로 자동 이동하거나 복사하지 않는다.
