# TagMemoFinishedList 화면 스펙

이 문서는 사용자가 TagDetail 화면의 메모 탭에서 그 태그의 완료된 메모를 모아 확인하는 TagMemoFinishedList 화면 가운데 이 화면에만 해당하는 부분을 다룬다. 진입과 이동, 빈 상태, 추가 미제공, 상세 확인, 정렬 선택, 노출 기준과 실행 경계의 공통 규칙은 [완료 목록 공통 스펙](./finished-list.md)을 따른다. 이 화면의 짝이 되는 목록은 같은 태그의 [TagDetail 메모 탭](./tag-detail-memo.md)이다.

메모 카드의 내용, 기간 표시, 정렬과 날짜 그룹은 [MemoHome 목록 스펙](./memo-home.md)을 따르고, 다시 시작·삭제의 상태 전이도 같은 문서를 따른다. 완료·삭제 상호작용의 공통 규칙은 [SwipeToFinishAndDelete 컴포넌트 스펙](./swipe-to-finish-and-delete.md)을, 메모와 태그 연결의 의미는 [메모 태그 스펙](./memo-tag.md)을, 상세 확인은 [MemoDetail 화면 스펙](./memo-detail.md)을 따른다. 목록과 메모 상세를 함께 사용할 때의 선택 상태와 뒤로가기는 [TagMemoFinishedList 목록·상세 배치 스펙](./tag-memo-finished-list-detail.md)에서 다룬다.

태그와 무관하게 계정의 완료된 메모 전체를 확인하는 화면은 [MemoFinishedList 화면 스펙](./memo-finished-list.md)에서 다룬다.

디자인: [TagMemoFinishedList 화면 디자인](../design/tag-memo-finished-list.md)

## feature

### 진입과 이동

사용자는 TagDetail 화면의 메모 탭에서 완료된 메모 확인을 선택해 같은 태그의 TagMemoFinishedList 화면으로 이동한다. 대상 태그의 완료 여부, 삭제 여부와 조회 결과는 이동을 막지 않는다.

완료된 메모 목록만 사용하는 동안 사용자가 뒤로가면 메모 탭이 선택된 같은 태그의 TagDetail 화면으로 돌아간다.

### 화면 제목

화면 제목에는 대상 태그의 최신 저장 이모지와 제목을 표시하고, 완료된 메모를 모아 보여 주는 목록임을 함께 알린다.

대상 태그를 아직 조회하지 못한 동안에는 태그의 이모지와 제목을 표시하지 않고, 완료된 메모 목록이라는 사실만 알린다.

태그의 이모지와 제목은 한 줄로 표시한다. 표시할 수 있는 폭보다 길면 전체를 확인할 수 있도록 가로로 반복해서 이동한다.

### 목록 표시

각 메모에는 제목이 표시되고, 기간이 있으면 기간도 함께 표시된다. 카드의 표시 방식은 [MemoHome 목록 스펙](./memo-home.md)의 `목록 표시`를 따른다.

기간이 없는 메모는 날짜 그룹 없이 먼저 표시한다. 기간이 있는 메모는 시작 날짜별로 묶어 표시한다. 정렬과 날짜 그룹은 [MemoHome 목록 스펙](./memo-home.md)을 따른다.

### 빈 상태 문구

대상 태그에 연결된 완료된 메모가 하나도 없으면 목록 자리에 이 태그에서 완료한 메모가 아직 없음을 알린다.

대상 태그를 조회하지 못해 태그의 이모지와 제목을 표시하지 못하는 것은 빈 상태 판정에 영향을 주지 않는다.

### 메모 상세 확인

사용자가 상세 화면에서 태그 연결을 해제한 뒤 돌아온 메모도 이 목록의 노출 기준에 따라 목록에서 사라진다.

### 다시 시작

사용자는 목록의 메모를 다시 시작할 수 있다.

다시 시작하면 메모가 이 목록에서 사라지고 다시 시작되었음을 안내하며, 실행 취소 동작을 제공한다.

사용자가 실행 취소를 선택하면 메모는 완료된 상태로 되돌아가 이 목록의 정렬 기준에 맞는 위치에 다시 나타난다.

### 삭제

사용자는 목록의 메모를 삭제할 수 있다.

삭제하면 메모가 목록에서 사라지고 삭제되었음을 안내하며, 실행 취소 동작을 제공한다.

사용자가 실행 취소를 선택하면 메모는 삭제되지 않은 상태로 되돌아가 이 목록의 정렬 기준에 맞는 위치에 다시 나타난다.

## domain

### 대상 태그와 연결

이 화면의 대상 태그는 진입한 TagDetail 화면의 상세 대상 태그와 같은 태그다.

화면 제목의 이모지 표시 규칙은 [TagHome 목록 스펙](./tag-home.md)의 `태그 이모지 표시`를 따른다. 화면이 열려 있는 동안 대상 태그의 저장 이모지나 제목이 다른 경로에서 바뀌면 화면 제목을 최신 저장 내용으로 갱신한다.

대상 태그를 조회할 수 없거나 조회에 실패하면 태그의 이모지와 제목을 표시하지 않고, 그 밖의 화면 행동은 바뀌지 않는다.

태그가 완료되거나 삭제되어도 기존 메모 연결은 유지되므로 이미 열린 TagMemoFinishedList의 메모 노출 기준은 바뀌지 않는다.

### 태그 연결과 노출 기준

[완료 목록 공통 스펙](./finished-list.md)의 `노출 기준`에 대상 태그와 해제되지 않은 연결을 가진 메모라는 조건을 더한다. 태그 연결을 판정하는 규칙은 짝이 되는 [TagDetail 메모 탭 스펙](./tag-detail-memo.md)과 같다.

### 정렬과 날짜 그룹

정렬, 날짜 그룹과 오늘의 기준은 [MemoHome 목록 스펙](./memo-home.md)을 따른다.

### 다시 시작·삭제·실행 취소

상태 전이와 수정 시각 갱신은 [MemoHome 목록 스펙](./memo-home.md)의 `완료와 삭제의 상태 전이`를 따른다.

다시 시작, 삭제와 실행 취소는 메모와 태그의 연결을 바꾸지 않는다.

다시 시작한 메모는 대상 태그와의 연결을 그대로 유지하므로 [TagDetail 메모 탭 스펙](./tag-detail-memo.md)의 노출 기준을 만족해 그 탭의 목록에 나타난다. 삭제한 메모는 두 목록 모두에 나타나지 않는다.

### 실행 경계

메모 상세 선택의 유지와 초기화는 [TagMemoFinishedList 목록·상세 배치 스펙](./tag-memo-finished-list-detail.md)의 `유지와 초기화 기준`을 따른다.

## data

### 태그별 완료 메모 조회

조회 흐름은 [완료 목록 공통 스펙](./finished-list.md)의 `목록 조회`를 따르며, 현재 사용자 계정과 연결된 메모 및 메모-태그 연결 중 `태그 연결과 노출 기준`을 만족하는 항목만 조회한다.

메모의 기간이나 태그 연결 상태가 바뀔 때도 목록을 노출 기준과 정렬 기준에 따라 자동 갱신한다.

연결이 해제된 메모는 목록에서 사라지고, 연결이 복구되면 노출 기준을 만족할 때 정렬 기준에 맞는 위치에 다시 나타난다.

### 상태 변경의 저장

다시 시작, 삭제와 실행 취소의 저장 흐름은 [MemoHome 목록 스펙](./memo-home.md)의 `상태 변경의 저장`을 따른다.

메모 상태를 바꿔도 메모와 태그의 연결은 유지한다.
