# TagDetail 장소 탭 스펙

이 문서는 사용자가 TagDetail 화면의 장소 탭에서 표시 범위 안 태그에 연결된 장소를 목록이나 지도로 확인하고, 상세 대상 태그를 초기값으로 사용해 장소를 추가하는 행동을 다룬다. 화면 전체의 구성, 탭 전환과 유지, 화면 제목, 태그 디테일 탭의 행동과 세 목록 탭이 함께 쓰는 표시 범위는 [TagDetail 화면 스펙](./tag-detail.md)이 소유한다.

보기 모드 전환, 지도와 지도 위 핀의 표시, 두 모드의 목록과 빈 상태, 장소 추가와 장소 상세로 이동할 때 넘기는 것, 목록 정렬과 새로고침의 공통 기준은 [장소 보기 모드 스펙](./place-view-mode.md)이 소유한다. 이 문서에는 장소 탭이 정하는 기본 보기 모드, 노출 대상 장소, 현재 위치 확인 시점과 장소 추가의 초기값만 둔다.

목록의 장소 표시는 [PlaceHome 화면 스펙](./place-home.md)을, 장소 추가 행동은 [PlaceAdd 화면 스펙](./place-add.md)을, 장소와 태그 연결의 의미는 [장소 태그 스펙](./place-tag.md)을, 선택한 장소의 상세는 [PlaceDetail 화면 스펙](./place-detail.md)을 따른다. 지도의 표시와 지도 제공자 전환, 핀 표시와 핀 선택은 [DiaryMap 컴포넌트 스펙](./diary-map.md)을, 기본 지도를 고르고 저장하는 흐름은 [SettingMap 화면 스펙](./setting-map.md)을, 현재 위치를 확인하는 규칙은 [현재 위치 확인 스펙](./current-location.md)을 따른다. 아직 준비되지 않은 자리의 처리는 [페이지 조회 목록의 자리 표시 스펙](./paged-list-placeholder.md)을, 목록이 비어 있을 때의 안내는 [목록 빈 상태 스펙](./list-empty-state.md)을, 목록을 당겨 새로고침하는 행동과 동기화 진행 표시는 [새로고침 스펙](./sync-refresh.md)을 따른다.

장소 탭의 지도 모드는 이 태그에 연결된 장소를 지도와 지도 위 핀으로 확인하는 것까지 제공한다. 위치 권한 요청, 지도에서 장소를 찾는 검색과 경로 안내, 저장된 항목을 찾는 검색 진입은 이 탭에서 제공하지 않는다.

디자인: [TagDetail 장소 탭 디자인](../design/tag-detail-place.md)

## feature

### 진입

사용자는 TagDetail 화면에서 장소 탭을 선택해 표시 범위 안 태그에 연결된 장소를 확인한다. 탭을 선택하는 방법과 선택한 탭의 유지 기준은 [TagDetail 화면 스펙](./tag-detail.md)의 `탭 전환`과 `선택한 탭`을 따른다.

장소 탭을 선택하면 목록 모드로 시작한다. 선택한 뒤 사용자가 보기 모드를 바꾸고 지도와 목록을 다루는 행동은 [장소 보기 모드 스펙](./place-view-mode.md)을 따른다.

상세 대상 태그를 아직 조회하지 못했거나 조회에 실패해도 장소 탭의 목록, 지도와 동작은 그대로 제공한다.

### 보기 모드와 탭 전환

보기 모드는 장소 탭에만 적용한다. 다른 탭에 다녀와도 바꿔 둔 보기 모드와 지도가 보고 있던 위치, 확대 수준, 고른 지도 제공자는 그대로 남아 있다.

다른 탭을 선택한 동안에는 지도와 지도 제공자를 바꾸는 기능을 사용할 수 없다.

### 장소 추가

사용자는 어느 보기 모드에서든 장소 추가를 시작할 수 있다. 상세 대상 태그의 완료 여부, 삭제 여부와 조회 결과는 장소 추가 시작을 막지 않는다.

사용자가 장소 추가를 선택하면 PlaceAdd 화면으로 이동한다. PlaceAdd 화면은 창 너비와 관계없이 단독으로 표시하고, 그 화면에서는 주요 목적지의 공통 내비게이션을 제공하지 않는다. PlaceAdd로 넘기는 지도 위치는 [장소 보기 모드 스펙](./place-view-mode.md)의 `장소 추가로 이동`을 따른다.

장소 탭에서 진입한 장소 추가 화면은 상세 대상 태그를 최초 선택한 상태로 시작한다. 사용자는 저장 전까지 태그 선택을 추가하거나 해제할 수 있다.

사용자가 장소 추가 화면에서 뒤로가면 장소 탭이 선택된 같은 태그의 TagDetail 화면으로 돌아간다.

장소 추가는 장소 탭을 선택한 동안에만 제공한다. 다른 탭에서는 장소 추가를 실행할 수 없다.

### 장소 상세 확인

사용자가 목록의 장소를 선택하거나 지도 모드에서 지도 위 핀을 누르면 그 장소의 PlaceDetail 화면으로 이동한다. PlaceDetail 화면은 창 너비와 관계없이 단독으로 표시하고, 그 화면에서는 주요 목적지의 공통 내비게이션을 제공하지 않는다.

PlaceDetail 화면에서 뒤로가면 장소 탭이 선택된 같은 태그의 TagDetail 화면으로 돌아간다.

사용자가 PlaceDetail 화면에서 장소를 삭제하거나 이 태그와의 연결을 해제한 뒤 돌아오면, 그 장소는 두 보기 모드의 노출 기준에 따라 목록과 핀에서 사라진다. PlaceDetail에서 삭제에 성공하면 뒤로가기와 같은 결과로 장소 탭이 선택된 TagDetail 화면으로 돌아온다.

### 빈 상태

대상 태그를 조회하지 못해 화면 제목을 표시하지 못하는 것은 빈 상태 판정에 영향을 주지 않는다. 두 보기 모드가 각각 무엇을 알리는지는 [장소 보기 모드 스펙](./place-view-mode.md)의 `빈 상태`를 따른다.

## domain

### 상세 대상 태그와 연결

장소 탭의 상세 대상은 TagDetail 화면의 상세 대상 태그와 같은 태그다. 대상이 결정되는 기준은 [TagDetail 화면 스펙](./tag-detail.md)의 `상세 대상과 내용 표시`를 따른다.

집합 안 태그가 완료되거나 삭제되어도 기존 장소 연결은 유지되므로 장소 탭의 노출 기준은 바뀌지 않는다. 다만 삭제된 태그는 집합에 들어가지 않으므로, 상세 대상 태그가 아닌 하위 태그가 삭제되면 그 태그로만 연결된 장소는 목록과 핀에서 사라진다.

상세 대상이 다른 태그로 바뀌면 목록과 핀을 새 대상 태그를 기준으로 만든 집합의 장소로 바꾼다.

### 기본 보기 모드

장소 탭의 기본 보기 모드는 목록 모드다. 장소 탭은 태그에 연결된 장소를 목록으로 확인하는 자리이므로, 지도 모드에서 시작하는 [PlaceHome 화면 스펙](./place-home.md)의 `기본 보기 모드`와 다르다.

보기 모드가 무엇을 노출하는지와 어떤 경계에서 유지되고 초기화되는지는 [장소 보기 모드 스펙](./place-view-mode.md)의 `보기 모드`와 `보기 모드의 유지`를 따른다. 사용자가 TagDetail 화면을 떠난 뒤 다시 진입하면 목록 모드로 초기화한다.

상세 대상이 다른 태그로 바뀌어도 보기 모드는 유지하고 목록과 핀만 새 대상 태그의 장소로 바꾼다. 사용자는 지도 모드를 유지한 채 대상을 바꿔 같은 지역에서 태그별 장소를 이어서 확인한다.

### 노출 대상 장소

장소 탭의 노출 대상 장소는 현재 사용자 계정과 연결된 장소 중 표시 범위 안 태그 하나 이상과 해제되지 않은 연결을 가지며 삭제되지 않은 장소다. 표시 범위가 무엇을 정하는지는 [TagDetail 화면 스펙](./tag-detail.md)의 `표시 범위`를 따르며, 표시 범위는 담을 태그만 정하고 이 노출 기준을 대체하지 않는다.

한 장소가 표시 범위 안 여러 태그와 연결되어 있어도 목록에는 한 번만 나타나고 지도에도 핀 하나로만 나타난다.

두 보기 모드가 이 집합을 함께 사용하며, 지도 모드는 여기에 보이는 영역 기준을 더한다. 사용자가 표시 범위를 바꾸면 두 보기 모드의 목록과 핀을 새 범위 기준으로 다시 표시하고, 보기 모드와 지도가 보고 있던 위치와 확대 수준은 바꾸지 않는다.

두 모드가 이 집합을 어떻게 쓰는지는 [장소 보기 모드 스펙](./place-view-mode.md)의 `목록 모드에 노출하는 장소`와 `지도 모드에 노출하는 장소`를 따른다.

장소에는 완료 여부가 없으므로 완료된 장소를 모아 보는 목록도 두지 않는다.

### 현재 위치 확인 시점

장소 탭은 사용자가 처음 지도 모드로 바꿀 때 현재 위치를 한 번 확인한다. 목록 모드에 머무르는 동안에는 확인하지 않으므로, 지도를 한 번도 보지 않은 사용자에게는 위치 확인이 일어나지 않는다. 이 기준은 화면에 진입할 때 확인하는 [PlaceHome 화면 스펙](./place-home.md)의 `현재 위치 확인 시점`과 다르다.

목록 모드로 되돌린 뒤 다시 지도 모드로 바꿀 때는 다시 확인하지 않고 그때까지 보고 있던 지도를 이어서 본다. 사용자가 TagDetail 화면을 떠난 뒤 다시 들어오면 목록 모드에서 시작하므로, 그 뒤 처음 지도 모드로 바꿀 때 현재 위치를 새로 확인한다.

확인 방법과 확인하지 못했을 때의 표시, 재확인하지 않는 경계는 [장소 보기 모드 스펙](./place-view-mode.md)의 `초기 지도 위치`를 따른다.

### 장소 추가의 초기값

장소 추가 시작은 상세 대상 태그의 상태와 보기 모드에 무관하게 항상 허용한다.

대상 태그는 장소 추가 화면의 최초 선택 태그일 뿐, 저장해야 하는 필수 관계가 아니다. 대상 태그를 선택한 것으로 표시할 수 있는지는 [항목 추가 화면 공통 스펙](./entity-add.md)의 `태그 선택과 추가 성립 조건`을 따르므로, 완료되었거나 삭제된 대상 태그는 선택되지 않은 상태로 시작한다.

최종 장소-태그 관계는 저장 시점에 사용자가 선택한 상태로 확정한다. 따라서 대상 태그를 해제하면 새 장소와 연결하지 않는다. 그 밖의 저장 규칙은 [PlaceAdd 화면 스펙](./place-add.md)을 따른다.

### 태그 연결의 변경과 목록

장소 탭은 목록에서 장소의 태그 연결을 바꾸는 동작을 제공하지 않는다. 사용자는 장소를 선택해 [PlaceDetail 화면](./place-detail.md)에서 연결을 바꾼다.

장소 탭이 목록과 핀에 담을 장소를 고를 때 사용하는 연결은 장소와 태그의 연결이며 그 기준은 [장소 태그 스펙](./place-tag.md)을 따른다. 태그와 태그의 연결은 장소에 연결된 태그를 늘리지 않고 표시 범위가 정하는 집합에만 쓰이므로, 표시 범위가 `이 태그만`이면 이 목록에 영향을 주지 않는다.

## data

### 태그별 장소 조회

두 보기 모드의 목록과 지도 핀에 표시할 장소는 `노출 대상 장소`를 기준으로 로컬 저장소에서 조회한다. 조회 방식과 갱신 기준은 [장소 보기 모드 스펙](./place-view-mode.md)의 `목록 조회`를 따른다.

장소의 태그 연결 상태가 바뀌면 두 조회 결과를 노출 기준과 정렬 기준에 따라 자동 갱신한다. 표시 범위 안 태그를 정하는 태그와 태그의 연결이 바뀐 것도 같은 기준으로 갱신한다. 서버에서 내려받은 장소와 연결이 기기에 반영된 것도 같은 기준으로 갱신한다.

연결이 해제된 장소는 두 모드의 목록과 핀에서 사라지고, 연결이 복구되면 노출 기준을 만족할 때 정렬 기준에 맞는 위치에 다시 나타난다.

### 탭별 조회

장소 탭의 목록 조회는 태그 디테일 탭의 태그 조회, 메모 탭의 메모 조회, 웹 탭의 웹 항목 조회와 서로 독립이다. 어느 한쪽이 실패해도 다른 쪽의 표시 기준은 바뀌지 않는다.

### 장소 추가 결과

장소 탭에서 시작한 장소 추가 화면은 `domain > 장소 추가의 초기값`에서 확정한 관계를 새 장소와 함께 저장한다. 저장 방식은 [항목 연결 공통 스펙](./entity-link.md)의 `연결의 저장`을 따른다.

추가된 장소가 상세 대상 태그와 연결되고 지금 보기 모드의 노출 기준을 만족하면 현재 목록의 정렬 기준에 맞는 위치에 나타난다.
