# MemoDetail 화면 스펙

이 문서는 사용자가 메모 목록에서 선택한 메모의 상세를 확인하고 수정하고, 태그 연결과 대표 태그, 웹 연결과 연락처 연결과 장소 연결을 바꾸고, 복사하거나 완료하거나 삭제하는 MemoDetail 화면의 내용과 행동을 다룬다. MemoHome 목록과 상세가 함께 표시되는 상태는 [Memo 목록·상세 배치 스펙](./memo-list-detail.md)을 따르고, TagDetail 메모 탭과 TagMemoFinishedList 화면에서 진입하는 흐름은 [TagDetail 메모 탭 스펙](./tag-detail-memo.md)과 [TagMemoFinishedList 화면 스펙](./tag-memo-finished-list.md)을 따른다. 설명 입력, 컬러 입력, 날짜·시간 입력, 태그 입력 자체의 동작은 [설명 입력 컴포넌트 스펙](./description-input.md), [DiaryColorInput 컴포넌트 스펙](./diary-color-input.md), [DiaryDateTimeInput 컴포넌트 스펙](./diary-date-time-input.md), [메모 태그 입력 컴포넌트 스펙](./memo-tag-input.md)을 따른다. 메모가 가질 수 있는 기간의 개념은 [MemoAdd 화면 스펙](./memo-add.md)의 `메모의 기간`을 따른다.

메모와 태그의 연결 규칙은 [메모 태그 스펙](./memo-tag.md)을, 메모가 태그 하나를 대표 태그로 가지는 규칙은 [메모 대표 태그 스펙](./memo-primary-tag.md)을 따른다. 본문에 배치되는 웹 입력의 행동과 정책은 [메모 웹 입력 컴포넌트 스펙](./memo-web-input.md)을, 메모와 웹 항목의 연결 규칙은 [메모 웹 스펙](./memo-web.md)을 따른다. 본문에 배치되는 연락처 입력의 행동과 정책은 [메모 연락처 입력 컴포넌트 스펙](./memo-contact-input.md)을, 메모와 연락처의 연결 규칙은 [메모 연락처 스펙](./memo-contact.md)을 따른다. 본문에 배치되는 장소 카드의 행동과 정책은 [메모 장소 카드 컴포넌트 스펙](./memo-place-card.md)을, 메모와 장소의 연결 규칙은 [메모 장소 스펙](./memo-place.md)을 따른다.

내용 수정의 반영과 성공 결과, 태그 입력의 반영, 요청 제한과 저장 계약은 [항목 상세 화면 공통 스펙](./entity-detail.md)을 따른다. Gemini로 제목, 설명, 기간을 생성해 반영하는 작성 도우미의 행동과 정책은 [메모 Gemini 작성 도우미 스펙](./memo-gemini.md)을 따른다.

디자인: [MemoDetail 화면 디자인](../design/memo-detail.md)

## feature

### 진입

사용자는 MemoHome 목록, TagDetail 메모 탭 또는 TagMemoFinishedList 화면에서 메모를 선택해 그 메모의 MemoDetail 화면으로 이동한다.

캘린더 홈 화면에서 캘린더에 표시된 메모 제목을 선택해서도 같은 메모의 MemoDetail 화면으로 이동하며, 이때의 선택과 배치는 [CalendarHome 스펙](./calendar-home.md)의 메모 선택을 따른다.

MemoHome 목록에서 진입한 MemoDetail 화면의 목록 동시 표시와 단독 표시 상태는 [Memo 목록·상세 배치 스펙](./memo-list-detail.md)을, TagDetail 메모 탭에서 진입한 MemoDetail 화면은 [TagDetail 메모 탭 스펙](./tag-detail-memo.md)의 `메모 상세 확인`에 따라 단독으로 표시하고, TagMemoFinishedList 화면에서 진입한 MemoDetail 화면의 상태는 [TagMemoFinishedList 목록·상세 배치 스펙](./tag-memo-finished-list-detail.md)을 따른다.

### 첫진입 시 내용 표시

MemoDetail 화면이 처음 나타나면 선택한 메모를 조회하는 동안 로딩 상태를 표시한다.

선택한 메모 조회가 완료되면 사용자는 저장된 제목, 설명, 컬러, 기간, 태그 연결과 대표 태그, 웹 연결과 연락처 연결을 확인할 수 있다.

화면 상단의 제목은 한 줄로 표시한다. 제목이 표시할 수 있는 폭보다 길면 전체 제목을 확인할 수 있도록 가로로 반복해서 이동한다.

메모에 기간이 있으면 저장된 기간의 시작과 종료를 종일 여부와 함께 표시하고, 기간이 없으면 기간을 사용하지 않는 상태로 표시한다.

선택한 메모를 조회할 수 없거나 조회에 실패하면 로딩 상태를 유지한다.

### 태그 연결과 대표 태그 변경

태그 선택·해제와 대표 태그 지정의 행동은 [메모 태그 입력 컴포넌트 스펙](./memo-tag-input.md)을 따르고, 구체적인 표현과 조작 수단은 [메모 태그 입력 컴포넌트 디자인](../design/memo-tag-input.md)을 따른다. 태그 입력에는 상세 대상 메모에 저장된 태그 연결과 대표 태그가 나타난다.

완료된 태그와 연결되어 있으면 그 태그도 태그 입력에 연결된 상태로 나타나고, 대표 태그로 저장되어 있으면 대표 태그로 나타난다. 삭제된 태그는 연결이 남아 있어도 태그 입력에 나타나지 않는다.

태그 입력에 나타나는 완료된 태그는 태그 선택 목록에도 함께 나타나므로 사용자는 목록에서 그 태그의 선택을 해제하거나 대표 태그 지정을 바꿀 수 있다. 목록에서는 완료된 태그도 다른 태그와 구분 없이 표시된다.

완료된 태그의 선택을 해제하면 그 태그는 태그 입력과 태그 선택 목록에서 사라지고, 태그를 다시 시작하기 전에는 목록에서 다시 선택할 수 없다. 연결되지 않은 완료된 태그도 목록에 나타나지 않아 새로 연결할 수 없다.

사용자가 태그 선택 목록에서 태그를 선택하거나 해제하면 그 즉시 상세 대상 메모의 태그 연결이 바뀐다. 대표 태그를 지정하거나 지정을 해제하면 그 즉시 상세 대상 메모의 대표 태그가 바뀐다. 별도의 수정이나 확정 동작은 필요하지 않으며, 반영된 결과가 태그 입력에 나타난다.

태그 연결과 대표 태그의 변경은 저장된 내용을 곧바로 바꾸므로 제목, 설명, 컬러와 기간의 수정 가능 여부에 영향을 주지 않는다.

태그 변경에 성공해도 별도로 안내하지 않는다. 태그 변경에 실패해도 오류나 재시도 동작을 별도로 제공하지 않으며, 저장된 태그 연결과 대표 태그를 그대로 표시한다.

### 웹 표시와 연결 변경

본문에는 상세 대상 메모에 연결된 웹 항목을 보여 주는 웹 입력이 표시된다. 웹 선택 목록에서의 웹 선택·해제, 웹 항목을 눌러 웹 상세로 이동하는 흐름과 웹 추가 이동의 행동과 정책은 [메모 웹 입력 컴포넌트 스펙](./memo-web-input.md)을 따른다. 웹 입력에는 상세 대상 메모에 저장된 웹 연결이 나타난다.

삭제된 웹 항목은 연결이 남아 있어도 웹 입력에 나타나지 않고, 웹 선택 목록에도 나타나지 않으므로 다시 연결할 수 없다.

사용자가 웹 선택 목록에서 웹 항목을 선택하거나 해제하면 그 즉시 상세 대상 메모의 웹 연결이 바뀐다. 별도의 수정이나 확정 동작은 필요하지 않으며, 반영된 결과가 웹 입력에 나타난다.

### 장소 표시와 연결 변경

### 수정 가능 상태

현재 입력한 제목, 설명, 컬러, 기간이 저장된 내용과 하나라도 다를 때만 사용자가 수정 내용을 반영할 수 있다. 입력한 내용이 저장된 내용과 같으면 수정 동작을 제공하지 않는다.

### 내용 수정과 반영

사용자는 제목, 설명, 컬러와 기간을 수정해 함께 반영할 수 있다. 태그 입력의 조작은 `태그 연결과 대표 태그 변경`에 따라, 웹 입력의 조작은 `웹 표시와 연결 변경`에 따라, 연락처 입력의 조작은 `연락처 표시와 연결 변경`에 따라 이 수정과 무관하게 즉시 반영된다.

수정을 처리하는 동안에는 진행 중인 상태를 표시한다.

사용자가 제목을 수정 중이어도 화면 제목에는 저장된 메모 제목이 표시되며, 수정에 성공한 뒤에 새로 저장된 제목으로 바뀐다.

### Gemini 작성 도우미

사용자는 Gemini 작성 도우미를 시작해 제목, 설명, 기간을 생성하고 각각 따로 반영할 수 있다. 도우미의 행동과 정책은 [메모 Gemini 작성 도우미 스펙](./memo-gemini.md)을 따른다.

반영한 내용은 수정 중인 입력으로만 들어가며, 저장된 메모에 반영되는 시점은 사용자가 수정을 반영할 때다. 반영한 내용이 저장된 내용과 다르면 `수정 가능 상태`에 따라 수정 동작이 나타난다.

### 수정 성공

메모 수정에 성공하면 화면과 수정 중이던 내용은 그대로 유지되고, 메모가 수정되었음을 안내한다.

### 제목 미입력

사용자가 제목을 비우거나 공백만 입력한 상태로 수정을 반영하면, 제목은 기존에 저장되어 있던 제목을 그대로 유지하고 설명, 컬러, 기간만 수정된 내용으로 반영된다.

### 완료와 다시 시작

메모의 저장된 완료 상태에 따라 완료되지 않은 메모에는 완료 동작을, 완료된 메모에는 다시 시작 동작을 제공한다.

사용자는 완료되지 않은 메모를 완료할 수 있다. 완료에 성공하면 화면과 수정 중이던 내용은 그대로 유지되고, 이후 다시 시작 동작을 사용할 수 있다.

사용자는 완료된 메모를 완료되지 않은 상태로 되돌릴 수 있다. 다시 시작에 성공하면 화면과 수정 중이던 내용은 그대로 유지되고, 이후 완료 동작을 사용할 수 있다.

완료나 다시 시작을 처리하는 동안에는 진행 중인 상태를 표시한다.

### 복사

사용자는 상세 대상 메모와 같은 내용을 가진 새 메모를 만들 수 있다.

복사를 처리하는 동안에는 진행 중인 상태를 표시한다.

복사에 성공하면 MemoDetail 화면은 그대로 유지되고 상세 대상이 복사본 메모로 바뀐다. 화면 제목과 제목, 설명, 컬러, 기간, 태그 입력, 웹 입력, 연락처 입력에는 복사본 메모의 저장된 내용이 표시되며, 이어서 메모가 복사되었음을 안내한다.

복사한 뒤 사용자가 하는 수정, 완료, 다시 시작, 삭제와 태그·웹·연락처 연결 변경은 원본이 아닌 복사본을 대상으로 한다. 복사본은 완료되지 않은 상태이므로 완료 동작을 사용할 수 있으며, 사용자는 복사본을 다시 복사할 수도 있다.

복사 직전에 원본에서 수정 중이던 내용은 복사에 반영되지 않고 복사본으로도 이어지지 않는다.

복사한 뒤 뒤로가기를 실행하면 원본의 상세로 돌아가지 않고 MemoDetail 화면에 진입하기 전 화면으로 돌아간다.

복사에 실패하면 상세 대상은 원본 메모로 그대로 유지되고, 별도의 오류 안내나 재시도 동작을 제공하지 않는다.

### 삭제

사용자는 메모를 삭제할 수 있다.

삭제를 처리하는 동안에는 진행 중인 상태를 표시한다.

삭제에 성공하면 뒤로가기와 같은 동작으로 MemoDetail 화면에서 빠져나간다. 목록과 상세 영역을 함께 표시하는 상태에서는 상세 영역이 선택한 메모가 없을 때의 상태로 되돌아가며, 그 상태는 각 목록·상세 배치 스펙을 따른다.

삭제된 메모에서 수정 중이던 내용은 유지되지 않는다.

### 같은 메모의 변경

MemoDetail 화면이 열려 있는 동안 같은 메모의 저장된 제목이 다른 경로로 변경되면 화면 제목에 변경된 제목을 표시한다.

제목 입력 칸, 설명 입력, 컬러 입력, 날짜·시간 입력은 저장된 내용으로 다시 채우지 않고 사용자가 보고 있거나 수정 중인 내용을 유지한다.

같은 메모의 저장된 태그 연결이나 대표 태그가 다른 경로로 변경되면 태그 입력에 변경된 내용을 표시한다. 같은 메모의 저장된 웹 연결이 다른 경로로 변경되면 웹 입력에, 저장된 연락처 연결이 다른 경로로 변경되면 연락처 입력에, 저장된 장소 연결이 다른 경로로 변경되면 장소 카드에 변경된 내용을 표시한다.

### 다른 메모 선택

MemoDetail 화면이 열려 있는 동안 사용자가 목록에서 다른 메모를 선택하면, 화면 제목과 제목, 설명, 컬러, 기간, 태그 입력, 웹 입력, 연락처 입력과 장소 카드를 새로 선택한 메모의 내용으로 바꾼다.

기존 메모에서 수정 중이던 내용은 새로 선택한 메모로 이어지지 않는다.

### 뒤로가기

사용자가 뒤로가기를 실행하면 MemoDetail 화면에 진입하기 전 화면으로 돌아간다.

목록과 상세 영역을 함께 표시하는 상태에서 뒤로가기를 실행하면 상세 영역은 선택한 메모가 없을 때의 화면인 메모 추가 화면으로 되돌아간다.

## domain

### 상세 대상 메모

MemoDetail 화면은 목록에서 선택한 메모 하나를 대상으로 하며, 대상 메모는 현재 사용자 계정과 연결된 메모다.

### 내용 표시 기준

화면 제목에는 상세 대상 메모의 최신 저장 제목을 표시한다.

제목 입력 칸, 설명 입력, 컬러 입력, 날짜·시간 입력은 상세 대상 메모마다 처음 조회한 내용으로 한 번만 채운다. 같은 메모의 저장 내용이 변경되어도 다시 채우지 않지만, 상세 대상이 다른 메모로 바뀌면 새 대상의 내용을 채운다.

태그 입력은 저장된 내용을 한 번만 채우지 않고 상세 대상 메모의 최신 저장 태그 연결과 대표 태그를 계속 표시한다. 사용자의 조작이 곧바로 저장되므로 화면이 보여 줄 중간 상태가 따로 없고, 저장된 내용이 어느 경로로 바뀌어도 태그 입력이 그 내용을 그대로 나타낸다. 웹 입력과 연락처 입력도 같은 기준으로 최신 저장 웹 연결과 연락처 연결을 계속 표시한다.

상세 내용은 로딩 상태와 내용 표시 상태 중 하나다. 화면에 처음 진입하면 로딩 상태이고, 상세 대상 메모 조회에 성공하면 내용 표시 상태로 바뀐다. 상세 대상 메모를 조회할 수 없거나 조회에 실패하면 로딩 상태로 처리한다.

### 수정 반영 가능 기준

사용자가 입력 중인 제목, 설명, 컬러, 기간이 대상 메모의 저장된 제목, 설명, 컬러, 기간과 하나라도 다를 때만 수정 내용을 반영할 수 있다. 입력 내용이 저장된 내용과 모두 같으면 수정 동작을 제공하지 않는다.

기간의 비교는 기간의 유무, 종일 여부, 시작과 종료를 함께 본다.

### 제목 미입력 시 처리

수정 시점에 제목이 비어 있거나 공백 문자로만 이루어져 있으면, 대상 메모에 저장되어 있던 기존 제목을 그대로 사용한다. 이 경우에도 설명, 컬러, 기간은 사용자가 수정한 내용으로 반영된다.

### 수정되는 내용

수정은 상세 대상 메모의 제목, 설명, 컬러, 기간을 반영할 내용으로 바꾼다. 기간을 사용하지 않는 상태로 반영하면 메모의 기간은 없는 것으로 바뀐다.

수정 시점이 메모의 수정 시각으로 기록된다. 메모의 완료 여부, 삭제 여부, 생성 시각과 계정·그룹 연결은 수정으로 바뀌지 않는다. 수정은 태그 연결과 대표 태그 지정, 웹 연결, 연락처 연결도 바꾸지 않는다.

### 태그 입력에 표시하는 태그

태그 입력에 연결된 상태로 표시하는 태그는 상세 대상 메모의 해제되지 않은 연결이 가리키는 태그 중 현재 사용자 계정과 연결되고 삭제되지 않은 태그다.

태그의 완료 여부는 표시 기준에 영향을 주지 않는다. 완료된 태그도 저장된 연결이 있으면 연결된 상태로 표시한다. 저장된 연결은 태그를 완료해도 해제되지 않으므로, 표시에서 태그를 완료 여부로 걸러 내면 사용자가 저장된 연결을 확인할 수 없기 때문이다. 연결이 해제되지 않는 규칙은 [항목 연결 공통 스펙](./entity-link.md)의 `항목의 상태 변화와 연결`를 따른다.

삭제된 태그는 연결이 남아 있어도 표시하지 않는다. 저장된 대표 태그는 그 태그가 표시하는 태그에 포함될 때만 대표 태그로 표시한다.

이 기준은 태그 입력의 표시에만 적용되며, 저장된 연결과 대표 태그를 바꾸지 않는다.

### 태그 연결과 대표 태그 변경 기준

상세 대상 메모에 새로 연결할 수 있는 태그는 [메모 태그 입력 컴포넌트 스펙](./memo-tag-input.md)의 `선택할 수 있는 태그`를 따른다.

표시하는 태그 가운데 선택할 수 있는 태그에 없는 태그도 [메모 태그 입력 컴포넌트 스펙](./memo-tag-input.md)의 `태그 선택 목록에 나타나는 태그`에 따라 태그 선택 목록에 나타나므로, 그 태그의 연결 해제와 대표 태그 지정 변경은 목록에서 할 수 있다. 연결을 해제하면 그 태그는 표시하는 태그에서 빠져 목록에서도 사라지므로 다시 연결할 수는 없다.

태그를 선택하면 상세 대상 메모와 그 태그의 연결을 만들고, 선택을 해제하면 그 연결을 해제한다. 대표 태그를 지정하면 그 태그를 상세 대상 메모의 대표 태그로 기록하고, 지정을 해제하면 대표 태그가 없는 상태로 되돌린다.

연결을 해제하면 그 태그의 대표 태그 지정도 함께 해제되고, 연결되지 않은 태그를 대표 태그로 지정하면 연결도 함께 만들어진다. 기기 저장이 성공하면 이 두 결과는 같은 저장 작업으로 함께 반영되며, 한쪽만 반영된 기기 상태로 남지 않는다. 규칙의 근거는 [메모 태그 스펙](./memo-tag.md)의 `대표 태그와의 관계`를 따른다.

연결의 생성·해제와 대표 태그 지정·해제 시점이 각각 연결의 수정 시각과 메모의 수정 시각으로 기록된다. 자세한 규칙은 [항목 연결 공통 스펙](./entity-link.md)의 `연결의 상태와 시각`과 [메모 대표 태그 스펙](./memo-primary-tag.md)의 `대표 태그의 저장`을 따른다.

태그 연결과 대표 태그의 변경은 상세 대상 메모의 제목, 설명, 컬러, 기간, 완료 여부, 삭제 여부, 생성 시각을 바꾸지 않는다.

상세 대상 메모가 완료되었거나 삭제되어도 태그 연결과 대표 태그를 바꿀 수 있다.

### 웹 입력에 표시하는 웹 항목

웹 입력에 연결된 상태로 표시하는 웹 항목은 상세 대상 메모의 해제되지 않은 연결이 가리키는 웹 항목 중 현재 사용자 계정과 연결되고 삭제되지 않은 웹 항목이다.

삭제된 웹 항목은 연결이 남아 있어도 표시하지 않는다. 이 기준은 웹 입력의 표시에만 적용되며, 저장된 연결을 바꾸지 않는다.

웹 항목에는 완료 상태가 없으므로 이 기준은 [메모 웹 입력 컴포넌트 스펙](./memo-web-input.md)의 `선택할 수 있는 웹 항목`과 같다. 태그 입력과 달리 표시하지만 새로 연결할 수 없는 웹 항목은 생기지 않는다.

### 웹 연결 변경 기준

상세 대상 메모에 새로 연결할 수 있는 웹 항목은 [메모 웹 입력 컴포넌트 스펙](./memo-web-input.md)의 `선택할 수 있는 웹 항목`을 따른다.

웹 항목을 선택하면 상세 대상 메모와 그 웹 항목의 연결을 만들고, 선택을 해제하면 그 연결을 해제한다.

연결의 생성·해제 시점이 연결의 수정 시각으로 기록된다. 자세한 규칙은 [항목 연결 공통 스펙](./entity-link.md)의 `연결의 상태와 시각`을 따른다.

웹 연결의 변경은 상세 대상 메모의 제목, 설명, 컬러, 기간, 완료 여부, 삭제 여부, 생성 시각, 수정 시각을 바꾸지 않는다.

상세 대상 메모가 완료되었거나 삭제되어도 웹 연결을 바꿀 수 있다.

### 연락처 입력에 표시하는 연락처

연락처 입력에 연결된 상태로 표시하는 연락처는 상세 대상 메모의 해제되지 않은 연결이 가리키는 연락처 중 현재 사용자 계정과 연결되고 삭제되지 않은 연락처다.

삭제된 연락처는 연결이 남아 있어도 표시하지 않는다. 이 기준은 연락처 입력의 표시에만 적용되며, 저장된 연결을 바꾸지 않는다.

연락처에는 완료 상태가 없으므로 이 기준은 [메모 연락처 입력 컴포넌트 스펙](./memo-contact-input.md)의 `선택할 수 있는 연락처`와 같다. 태그 입력과 달리 표시하지만 새로 연결할 수 없는 연락처는 생기지 않는다.

연락처의 즐겨찾기 여부는 표시 기준과 순서 어느 쪽에도 영향을 주지 않는다. 순서는 [메모 연락처 스펙](./memo-contact.md)의 `연결된 연락처의 정렬`을 따른다.

### 연락처 연결 변경 기준

상세 대상 메모에 새로 연결할 수 있는 연락처는 [메모 연락처 입력 컴포넌트 스펙](./memo-contact-input.md)의 `선택할 수 있는 연락처`를 따른다.

연락처를 선택하면 상세 대상 메모와 그 연락처의 연결을 만들고, 선택을 해제하면 그 연결을 해제한다.

상세 대상 메모가 완료되었거나 삭제되어도 연락처 연결을 바꿀 수 있다.

### 장소 카드에 표시하는 장소

장소 카드에 연결된 상태로 표시하는 장소는 상세 대상 메모의 해제되지 않은 연결이 가리키는 장소 중 현재 사용자 계정과 연결되고 삭제되지 않은 장소다.

삭제된 장소는 연결이 남아 있어도 표시하지 않는다. 이 기준은 장소 카드의 표시에만 적용되며, 저장된 연결을 바꾸지 않는다.

### 장소 연결 변경 기준

상세 대상 메모에 새로 연결할 수 있는 장소는 [메모 장소 카드 컴포넌트 스펙](./memo-place-card.md)의 `선택할 수 있는 장소`를 따른다.

장소를 선택하면 상세 대상 메모와 그 장소의 연결을 만들고, 선택을 해제하면 그 연결을 해제한다.

연결의 생성·해제 시점이 연결의 수정 시각으로 기록된다. 자세한 규칙은 [항목 연결 공통 스펙](./entity-link.md)의 `연결의 상태와 시각`을 따른다.

장소 연결의 변경은 상세 대상 메모의 제목, 설명, 컬러, 기간, 완료 여부, 삭제 여부, 생성 시각, 수정 시각을 바꾸지 않는다.

상세 대상 메모가 완료되었거나 삭제되어도 장소 연결을 바꿀 수 있다.

### 복사되는 내용

복사는 상세 대상 메모의 제목, 설명, 컬러, 기간, 태그 연결과 대표 태그 지정, 웹 연결, 연락처 연결을 그대로 가진 새 메모를 만든다. 복사 시점에 사용자가 입력 중인 내용이 아니라 대상 메모에 저장된 내용을 복사한다.

복사본은 원본과 겹치지 않는 고유 식별자를 새로 부여받고, 완료되지 않고 삭제되지 않은 상태로 만들어지며, 복사 시점이 생성 시각과 수정 시각으로 함께 기록된다. 원본이 완료되었거나 삭제되어 있어도 복사본은 완료되지 않고 삭제되지 않은 상태다. 그 밖의 초기 상태와 계정 연결은 [MemoAdd 화면 스펙](./memo-add.md)의 `추가되는 메모의 초기 상태`와 `메모의 연결`을 따른다.

복사본에는 원본의 연결된 태그가 모두 연결된다. 원본에서 이미 해제된 연결은 복사본에 만들지 않는다. 원본의 대표 태그 지정은 복사본의 대표 태그가 되며, 대표 태그가 연결에도 포함되는 규칙은 [메모 태그 스펙](./memo-tag.md)의 `대표 태그와의 관계`를 따른다. 연결의 시각 기록은 [항목 연결 공통 스펙](./entity-link.md)의 `연결의 상태와 시각`을 따르므로 복사 시점이 복사본 연결의 생성 시각과 수정 시각이 된다.

복사본에는 원본의 연결된 웹 항목이 모두 연결된다. 원본에서 이미 해제된 연결은 복사본에 만들지 않으며, 연결의 시각 기록은 [항목 연결 공통 스펙](./entity-link.md)의 `연결의 상태와 시각`을 따르므로 복사 시점이 복사본 연결의 생성 시각과 수정 시각이 된다. 원본의 연결이 가리키는 웹 항목이 삭제되어 웹 입력에 나타나지 않아도 그 연결은 복사본에 그대로 만들어진다.

복사본에는 원본의 연결된 연락처가 모두 연결된다. 원본에서 이미 해제된 연결은 복사본에 만들지 않으며, 연결의 시각 기록은 [항목 연결 공통 스펙](./entity-link.md)의 `연결의 상태와 시각`을 따르므로 복사 시점이 복사본 연결의 생성 시각과 수정 시각이 된다. 원본의 연결이 가리키는 연락처가 삭제되어 연락처 입력에 나타나지 않아도 그 연결은 복사본에 그대로 만들어진다.

복사본에는 원본의 장소 연결이 복사되지 않는다. 복사본은 연결된 장소가 없는 상태로 만들어지며, 복사 시 장소 연결의 복사는 후속 범위에서 다룬다.

복사는 원본 메모를 바꾸지 않는다. 원본의 제목, 설명, 컬러, 기간, 완료 여부, 삭제 여부, 생성 시각, 수정 시각, 태그 연결과 대표 태그 지정, 웹 연결과 연락처 연결은 그대로 유지된다.

### 복사 후의 상세 대상

복사에 성공하면 상세 대상이 복사본 메모로 바뀐다. 상세 대상이 바뀔 때 화면 내용을 채우는 기준과 수정 중이던 내용을 유지하지 않는 기준은 `내용 표시 기준`과 `진행 상태 유지`의 상세 대상 변경 규칙을 그대로 따른다.

복사 이전의 상세 대상인 원본 메모는 화면 이력에 남지 않으므로, 복사한 뒤의 뒤로가기는 MemoDetail 화면에 진입하기 전 화면으로 돌아간다.

복사에 실패하면 상세 대상은 바뀌지 않는다.

### 완료·다시 시작·삭제의 상태 전이

완료, 다시 시작, 삭제는 [MemoHome 목록 스펙](./memo-home.md)의 상태 전이 규칙을 따른다. 완료는 완료 여부를 완료 상태로, 다시 시작은 완료 여부를 미완료 상태로, 삭제는 삭제 여부를 삭제 상태로 바꾸며, 모두 메모의 수정 시각을 동작 시점으로 갱신한다.

완료 상태 전환 동작은 상세 대상 메모의 저장된 완료 여부로 정한다. 완료, 다시 시작, 삭제는 제목, 설명, 컬러, 기간을 바꾸지 않는다.

### 요청 제한

수정, 완료·다시 시작, 복사, 삭제는 종류별로 요청을 제한한다. 한 종류의 동작을 처리하는 동안에는 같은 화면에서 전달된 같은 종류의 요청을 처리하지 않으며, 다른 종류의 요청은 제한하지 않는다. 완료와 다시 시작은 같은 종류로 본다.

이 제한은 한 번의 의도로 같은 동작이 중복 실행되는 것을 막기 위한 것이며, 처리가 끝나면 사용자는 다시 요청할 수 있다.

Gemini 작성 도우미의 생성은 이들과 다른 종류의 동작이므로 서로의 요청을 제한하지 않으며, 생성의 요청 제한은 [메모 Gemini 작성 도우미 스펙](./memo-gemini.md)의 `요청 제한`을 따른다.

태그 연결과 대표 태그 변경, 웹 연결 변경, 연락처 연결 변경, 장소 연결 변경에는 이 제한을 두지 않는다. 각 조작은 사용자가 고른 태그나 웹 항목이나 연락처나 장소를 대상으로 하는 서로 다른 요청이므로 중복 실행으로 보지 않으며, 사용자는 여러 태그와 웹 항목과 연락처와 장소를 이어서 바꿀 수 있다.

### 진행 상태 유지

같은 메모를 대상으로 화면이 회전하거나 시스템에 의해 화면이 재생성되면 제목 입력 칸, 설명 입력, 컬러 입력, 날짜·시간 입력에서 수정 중이던 내용은 유지되며, 조회한 내용으로 다시 덮어쓰지 않는다.

태그 입력에는 유지할 수정 중인 내용이 없다. 화면이 재생성되거나 앱을 다시 실행해도 태그 입력은 저장된 태그 연결과 대표 태그를 다시 표시한다. 웹 입력과 연락처 입력, 장소 카드도 마찬가지로 저장된 웹 연결과 연락처 연결, 장소 연결을 다시 표시한다.

상세 대상이 다른 메모로 바뀌면 이전 메모에서 수정 중이던 내용은 유지하지 않는다.

## data

### 메모 수정과 저장

사용자가 수정을 반영하면 상세 대상 메모의 제목, 설명, 컬러, 기간과 수정 시각이 공유되는 메모에 저장되어 기존 값을 덮어쓴다. 제목을 비운 채 수정하면 저장된 기존 제목은 그대로 유지된다.

수정은 대상 메모의 완료 여부, 삭제 여부, 생성 시각을 바꾸지 않는다.

### 완료·다시 시작·삭제의 저장

완료, 다시 시작, 삭제를 실행하면 해당 메모의 공유 상태 변경이 저장소에 즉시 반영된다. 완료와 삭제 모두 메모 자체나 계정·그룹 연결을 저장소에서 제거하지 않는다.

### 복사본의 생성과 저장

사용자가 복사를 실행하면 복사본 메모, 복사본과 현재 사용자 계정의 연결, 원본에서 가져온 태그 연결과 웹 연결과 연락처 연결이 기기의 하나의 저장 작업으로 함께 반영된다. 저장 방식과 일부만 저장된 기기 상태를 남기지 않는 규칙은 [MemoAdd 화면 스펙](./memo-add.md)의 `메모 생성과 저장`을 따른다.

복사는 원본 메모와 원본의 태그 연결, 웹 연결, 연락처 연결을 저장소에서 바꾸지 않으므로, 복사 뒤에도 원본은 복사 이전과 같은 내용으로 조회된다.

복사본과 그 태그 연결, 웹 연결, 연락처 연결을 서버와 맞추기 위한 동기화가 시작된다. 동기화의 대기 상태, 업로드 순서, 실패 처리는 [데이터 동기화 스펙](./data-sync.md)을 따른다.

### 태그 입력의 조회

태그 입력에 연결된 상태로 표시하는 태그는 상세 대상 메모의 저장된 연결을 조회해 가져온다. 이 조회는 선택할 수 있는 태그의 조회와 분리되어 있으므로, 완료된 태그도 저장된 연결이 있으면 조회 결과에 포함된다.

조회 대상은 `domain`의 `태그 입력에 표시하는 태그` 기준을 만족하는 태그이며, 정렬은 [메모 태그 입력 컴포넌트 스펙](./memo-tag-input.md)의 정렬 기준을 따른다.

태그 선택 목록은 선택할 수 있는 태그와 이 조회의 대상 태그를 함께 만족하는 조건으로 조회해 [메모 태그 입력 컴포넌트 스펙](./memo-tag-input.md)의 `태그 선택 목록에 나타나는 태그`를 구성한다. 이 목록 조회는 [메모 태그 입력 컴포넌트 스펙](./memo-tag-input.md)의 `태그 목록 조회`에 따라 페이지 단위로 이루어지므로, 태그 입력에 연결된 상태로 표시하는 태그의 조회와는 별도로 이루어진다.

저장된 연결이나 태그의 이모지·제목·컬러·상태가 바뀌면 조회 결과가 갱신되어 태그 입력에 반영된다.

### 태그 연결과 대표 태그의 저장

사용자가 태그를 선택하거나 해제하면 상세 대상 메모와 그 태그의 연결 변경이 저장소에 즉시 반영된다. 대표 태그를 지정하거나 지정을 해제하면 대표 태그 값의 변경이 상세 대상 메모에 즉시 반영된다.

연결 해제와 그 태그의 대표 태그 지정 해제, 대표 태그 지정과 그 태그의 연결 생성은 각각 하나의 저장 작업으로 함께 반영된다. 연결은 해제되었는데 대표 태그 지정이 남아 있거나, 대표 태그로만 지정되고 연결이 없는 중간 상태는 저장소에 남지 않는다.

연결의 저장 방식과 해제된 연결이 저장소에 남는 규칙은 [항목 연결 공통 스펙](./entity-link.md)의 `연결의 저장`과 `연결의 상태와 시각`을 따른다.

### 웹 입력의 조회

웹 입력에 연결된 상태로 표시하는 웹 항목은 상세 대상 메모의 저장된 연결을 조회해 가져온다. 이 조회는 선택할 수 있는 웹 항목의 조회와 분리되어 있다.

조회 대상은 `domain`의 `웹 입력에 표시하는 웹 항목` 기준을 만족하는 웹 항목이며, 정렬은 [메모 웹 입력 컴포넌트 스펙](./memo-web-input.md)의 정렬 기준을 따른다.

웹 선택 목록은 선택할 수 있는 웹 항목의 조회 결과를 사용하며, 구성 기준은 [메모 웹 입력 컴포넌트 스펙](./memo-web-input.md)의 `웹 선택 목록에 나타나는 웹 항목`을 따른다.

저장된 연결이나 웹 항목의 제목·상태가 바뀌면 조회 결과가 갱신되어 웹 입력에 반영된다.

### 웹 연결의 저장

사용자가 웹 항목을 선택하거나 해제하면 상세 대상 메모와 그 웹 항목의 연결 변경이 저장소에 즉시 반영된다.

연결의 저장 방식과 해제된 연결이 저장소에 남는 규칙은 [항목 연결 공통 스펙](./entity-link.md)의 `연결의 저장`과 `연결의 상태와 시각`을 따른다.

웹 연결을 바꾸면 저장소를 조회해 표시하는 곳에 함께 반영된다.

### 태그 변경 결과의 표시와 동기화

태그 연결과 대표 태그를 바꾸면 저장소를 조회해 표시하는 곳에 함께 반영된다. 연결을 해제하면 그 태그의 TagDetail 메모 탭에서 해당 메모가 사라지고, 연결을 만들면 그 태그의 TagDetail 메모 탭에 노출 기준에 맞게 나타난다. 대표 태그를 바꾸면 캘린더에서 그 메모를 표시하는 색상이 [메모 대표 태그 스펙](./memo-primary-tag.md)의 `캘린더 표시 색상`에 따라 바뀐다.

태그 연결이나 대표 태그를 바꾸면 그 변경을 서버와 맞추기 위한 동기화가 시작된다. 동기화의 대기 상태, 업로드 순서, 실패 처리는 [데이터 동기화 스펙](./data-sync.md)을 따른다.

동기화는 백그라운드에서 진행되므로 화면은 기기 저장소의 내용을 기준으로 표시되고, 동기화가 진행 중이거나 실패해도 사용자가 바꾼 태그 연결과 대표 태그는 되돌아가지 않는다. 화면에는 동기화 진행 상태나 대기 여부를 표시하지 않는다.

### 수정 결과의 표시

수정한 내용은 메모 목록 화면과 MemoDetail 화면 제목처럼 해당 메모를 조회해 표시하는 곳에 반영된다.

복사본은 완료되지 않고 삭제되지 않았으므로 [MemoHome 목록 스펙](./memo-home.md)의 노출 기준에 따라 메모 목록에 나타나고, 복사된 연결에 따라 해당 태그의 TagDetail 메모 탭에도 나타난다. 복사본의 캘린더 표시 색상은 [메모 대표 태그 스펙](./memo-primary-tag.md)의 `캘린더 표시 색상`을 따른다.

메모를 완료하거나 삭제하면 [MemoHome 목록 스펙](./memo-home.md)의 노출 기준에 따라 메모 목록에서 해당 메모가 사라진다. 완료된 메모의 MemoDetail 화면은 그대로 유지되어 사용자는 완료된 메모를 계속 확인하거나 다시 시작할 수 있다.
