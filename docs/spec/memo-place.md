# 메모 장소 스펙

이 문서는 하나의 메모가 여러 장소와 연결될 수 있다는 규칙 가운데 메모와 장소의 연결에만 해당하는 부분을 다룬다. 연결의 성질과 저장·동기화 계약은 [항목 연결 공통 스펙](./entity-link.md)을 따른다.

장소 자체의 추가와 장소가 갖는 정보는 [PlaceAdd 화면 스펙](./place-add.md)을, 장소의 수정과 삭제는 [PlaceDetail 화면 스펙](./place-detail.md)을 따른다.

사용자가 장소를 고르고 해제하는 조작은 이 문서에서 다루지 않는다. 장소 선택의 행동과 정책은 [메모 장소 카드 컴포넌트 스펙](./memo-place-card.md)에서, 구체적인 표현과 조작 수단은 [메모 장소 카드 컴포넌트 디자인](../design/memo-place-card.md)에서 다룬다. 메모를 추가하면서 장소를 연결하는 행동은 [MemoAdd 화면 스펙](./memo-add.md)에서, 이미 저장된 메모의 장소 연결을 바꾸는 행동은 [MemoDetail 화면 스펙](./memo-detail.md)에서, 장소로 메모를 찾아보는 목록은 [PlaceDetail 메모 탭 스펙](./place-detail-memo.md)에서 다룬다. 이 문서에는 사용자 조작이 없어 `feature` 영역을 생략한다.

메모와 태그의 연결은 이 문서가 다루는 연결과 별개이며 [메모 태그 스펙](./memo-tag.md)이 소유한다.

## domain

### 메모와 장소의 연결

메모는 여러 장소와 연결될 수 있고, 하나의 장소도 여러 메모와 연결될 수 있다.

연결은 메모와 장소 사이의 관계이며, 메모의 제목·설명·컬러·기간이나 장소의 제목·설명·컬러·좌표를 바꾸지 않는다.

## data

### 메모별 장소 표시

메모로 장소를 조회할 때는 현재 사용자 계정과 연결된 장소와 메모-장소 연결만 사용한다. 조회에 포함되는 연결과 장소의 기준은 [항목 연결 공통 스펙](./entity-link.md)의 `연결된 항목의 조회`를 따른다.

연결이 만들어지거나 해제되거나 복구되면 그 메모의 장소를 표시하는 화면과 그 장소의 메모를 표시하는 화면은 변경된 연결 상태를 반영한다.

### 장소별 메모 표시

장소로 메모를 조회할 때는 현재 사용자 계정과 연결된 메모와 메모-장소 연결만 사용한다. 조회에 포함되는 연결과 메모의 기준은 [항목 연결 공통 스펙](./entity-link.md)의 `연결된 항목의 조회`를 따르며, 그 위에 더하는 노출 기준과 정렬은 [항목 상세 메모 탭 공통 스펙](./entity-detail-memo.md)이 정한다.
