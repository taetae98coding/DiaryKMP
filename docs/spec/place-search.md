# 장소 검색 공통 스펙

이 문서는 검색어로 장소를 원격에서 찾아오는 조회가 제공자와 무관하게 지키는 계약을 다룬다. 제공자마다 다른 결과 개수, 장소 정보의 구성, 위치 기준, 사용 제약은 각 제공자 스펙에서 다룬다.

이 문서를 따르는 제공자 스펙은 다음과 같다.

- [Google 장소 검색 스펙](./google-place-search.md)
- [네이버 장소 검색 스펙](./naver-place-search.md)

사용자에게 직접 노출되는 화면이나 사용자 행동은 없으므로 `feature` 영역은 생략한다. 검색 결과를 사용자에게 어떻게 보여주고 무엇에 쓰는지, 어떤 제공자로 검색할지 고르는 규칙은 [장소 검색 다이얼로그 컴포넌트 스펙](./place-search-dialog.md)에서 다룬다. 지도 표시와 지도 제공자 전환은 [DiaryMap 컴포넌트 스펙](./diary-map.md)에서 다루며, 이 문서와 겹치지 않는다.

## domain

### 검색어

장소 검색은 검색어 하나를 대상으로 수행한다. 검색어는 비어 있지 않은 문자열이어야 한다.

### 결과 개수

한 번의 검색으로 받을 수 있는 장소 수는 제공자 정책이 정한 상한을 따르며, 검색은 언제나 그 상한만큼 요청한다. 상한을 넘는 결과를 이어서 받는 기능은 이번 범위에 포함하지 않는다.

상한 값은 각 제공자 스펙에서 정한다.

### 장소 정보

검색된 장소 하나가 어떤 정보를 갖는지는 제공자마다 다르므로 각 제공자 스펙에서 정한다. 어느 제공자든 장소의 이름과 좌표는 반드시 포함한다.

### 인증

장소 검색은 제공자가 발급한 인증 정보가 있어야 수행된다. 인증 정보가 없거나 유효하지 않으면 검색은 실패한다.

## data

### 원격 조회

검색을 요청하면 검색어로 제공자에게 장소 목록을 조회한다.

조회가 성공하면 받은 장소 목록을 그대로 전달한다. 검색어와 일치하는 장소가 없어 빈 목록을 받으면 빈 목록을 그대로 전달하며, 이는 실패가 아니다.

검색 결과는 저장하지 않고 검색할 때마다 새로 조회한다. 제공자가 결과의 보관을 제한하면 그 제약은 각 제공자 스펙에서 정한다.

### 실패 처리

원격 조회에 실패하면 실패를 그대로 알린다. 실패를 빈 목록 같은 정상 결과로 바꾸지 않는다. 실패를 어떻게 사용자에게 보여줄지는 검색을 사용하는 화면의 스펙에서 다룬다.
