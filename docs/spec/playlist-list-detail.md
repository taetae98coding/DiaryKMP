# Playlist 목록·상세 배치 스펙

이 문서는 곡 목록과 상세 영역을 함께 사용할 때 이 배치에만 해당하는 상세 영역 구성, 뒤로가기와 초기화 경계를 다룬다. 함께 사용과 단독 사용, 추가 진입 수단, 표시 비율 조절, 배치에 참여하는 화면과 유지·초기화의 공통 기준은 [목록·상세 배치 공통 스펙](./list-detail-pane.md)을 따른다. 각 화면의 내용과 행동은 [PlaylistHome 화면 스펙](./playlist-home.md)과 [MusicAdd 화면 스펙](./music-add.md)에서 다룬다.

디자인: [Playlist 목록·상세 배치 디자인](../design/playlist-list-detail.md)

표시 비율은 화면 표시 상태일 뿐 사용자 데이터를 만들거나 저장하지 않으므로 `data` 영역은 생략한다.

## feature

### 상세 영역의 구성

곡 상세는 아직 제공하지 않으므로 상세 영역에는 언제나 곡 추가가 놓인다. 사용자는 목록을 떠나지 않고 곧바로 링크, 제목과 가수를 입력한다.

추가에 성공한 뒤에도 상세 영역은 곡 추가로 남으므로 사용자는 다음 곡을 이어서 작성하고, 방금 추가한 곡이 목록에 나타나는 것을 같은 화면에서 확인한다. 추가 성공 후의 입력 상태는 [MusicAdd 화면 스펙](./music-add.md)의 `곡 추가`를 따른다.

한 영역만 표시되는 상태에서는 해당 화면 스펙의 행동을 그대로 제공하며, 화면 사이의 이동은 [PlaylistHome 화면 스펙](./playlist-home.md)의 `곡 추가로 이동`을 따른다.

### 뒤로가기

곡 목록의 뒤로가기 동작을 사용하면 상세 영역에 곡 추가가 함께 놓여 있는지와 관계없이 이 배치 전체를 떠나 `더보기` 화면으로 돌아간다. 상세 영역만 닫히지 않으며, 결과는 [PlaylistHome 화면 스펙](./playlist-home.md)의 `뒤로가기`를 따른다.

### 정렬 선택

목록에서 정렬 기준을 고르는 행동은 배치와 관계없이 [PlaylistHome 화면 스펙](./playlist-home.md)의 `정렬 선택`을 따른다. 상세 영역에 곡 추가가 함께 놓여 있어도 목록의 정렬 줄은 그대로 사용할 수 있다.

## domain

### 유지와 초기화 기준

사용자가 `더보기` 화면으로 돌아가는 것을 이 배치를 떠난 것으로 본다. 그 뒤 플레이리스트 화면에 다시 진입하거나 앱을 종료하고 다시 실행하면 [목록·상세 배치 공통 스펙](./list-detail-pane.md)의 `유지와 초기화 기준`에 따라 표시 비율을 기본 비율로 초기화한다.

상세 영역이 언제나 곡 추가이므로 이 배치에는 초기화할 상세 선택이 없다. 상세 영역에서 작성 중이던 내용을 어디까지 유지하는지는 [MusicAdd 화면 스펙](./music-add.md)의 `작성 상태 유지 대상`을 따른다.
