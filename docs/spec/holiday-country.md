# 공휴일 국가 설정 스펙

이 문서는 어느 국가의 공휴일을 앱에서 다룰지 사용자가 고르는 국가 설정의 규칙을 다룬다. 국가를 고르는 화면과 조작 방식은 [SettingHoliday 화면 스펙](./setting-holiday.md)에서 다룬다. 고른 국가 안에서 공휴일 하나하나를 숨기는 규칙은 [공휴일 노출 설정 스펙](./holiday-visibility.md)을 따른다.

이 설정을 적용하는 곳은 다음과 같다.

- [공휴일 동기화 스펙](./holiday-fetch.md)의 동기화 대상 국가
- [공휴일 노출 설정 스펙](./holiday-visibility.md)의 캘린더 공휴일 조회
- [SettingHoliday 화면 스펙](./setting-holiday.md)의 공휴일 항목 구성과 일괄 선택
- [HolidayHome 화면 스펙](./holiday-home.md)의 황금연휴 판단 대상

화면에서의 행동과 반응은 SettingHoliday 화면 스펙에서 다루므로 이 문서에서는 `feature` 영역을 생략한다.

## domain

### 국가 선택지

국가 설정의 선택지는 `기기값`, `한국`, `미국` 세 가지다.

세 선택지는 서로 독립이며 사용자는 원하는 만큼 함께 고를 수 있다. 하나도 고르지 않은 상태도 허용한다.

### 기본값

국가 설정을 한 번도 건드리지 않은 사용자는 `기기값`만 고른 상태다.

### 적용 국가

고른 선택지를 다음과 같이 국가로 바꾼 뒤 합친 집합을 적용 국가로 본다.

| 선택지 | 적용 국가 |
| --- | --- |
| `한국` | 한국 |
| `미국` | 미국 |
| `기기값` | 기기 지역이 한국이면 한국, 미국이면 미국, 그 밖의 지역이면 없음 |

같은 국가가 두 번 들어가도 한 번만 적용한다. 예를 들어 기기 지역이 한국인 기기에서 `기기값`과 `한국`을 함께 고르면 적용 국가는 한국 하나다.

적용 국가가 비어 있으면 앱은 어떤 국가의 공휴일도 다루지 않는다. 선택지를 하나도 고르지 않았을 때와 `기기값`만 골랐는데 기기 지역이 한국·미국이 아닐 때가 여기에 해당한다.

기기 지역은 기기의 언어 설정이 아니라 지역 설정을 기준으로 한다. 기기 지역이 바뀌면 그 뒤 공휴일을 다시 조회하거나 동기화할 때 바뀐 지역을 기준으로 적용 국가를 정한다.

### 여러 국가의 공휴일

적용 국가가 둘 이상이면 각 국가의 공휴일을 모두 합쳐 다룬다. 같은 날에 여러 국가의 공휴일이 있으면 각각을 별도 공휴일로 다룬다.

공휴일은 국가가 달라도 이름 key가 같으면 [공휴일 노출 설정 스펙](./holiday-visibility.md)의 같은 항목이다.

### 설정 유지

국가 설정은 화면이 재생성되거나 앱이 백그라운드에 다녀와도, 앱을 종료하고 다시 시작해도 유지된다.

## data

### 저장 시점

사용자가 선택지 하나를 고르거나 해제하면 별도 확인 동작 없이 바로 기기에 저장한다. 한 선택지를 바꿔도 다른 선택지의 상태는 그대로 유지한다.

저장하는 것은 사용자가 고른 선택지이고, 적용 국가는 저장하지 않는다. `기기값`이 가리키는 국가는 조회할 때마다 기기 지역으로 다시 정한다.

국가 설정을 바꿔도 이미 저장된 공휴일 캐시와 공휴일 노출 설정은 바뀌지 않는다. 적용 국가에서 빠진 국가의 공휴일은 캐시에 남아 있어도 다루지 않고, 다시 적용 국가에 들어오면 남아 있던 캐시를 그대로 사용한다.

### 설정 변경 반영

국가 설정이 바뀌면 사용자가 별도 조작을 하지 않아도 캘린더, 황금연휴와 SettingHoliday 화면이 바뀐 적용 국가의 저장된 공휴일로 다시 표시된다. 새로 들어온 국가의 공휴일을 원격에서 받아오는 시점은 각 화면의 공휴일 동기화 계기를 따른다.

### 읽기 실패

저장된 국가 설정을 읽을 수 없으면 어느 국가의 공휴일을 다뤄야 하는지 알 수 없으므로 공휴일 조회와 동기화를 실패로 끝낸다.

### 기기별 보관

국가 설정은 사용자 계정이 아니라 기기에 보관하며 서버와 동기화하지 않는다. 보관 영역, 계정 전환 시 유지와 사라지는 경우는 [공휴일 노출 설정 스펙](./holiday-visibility.md)의 `기기별 보관`과 같다.
